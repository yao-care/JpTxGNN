# エルロチニブ：非小細胞肺癌・膵癌からユーイング肉腫へ

## 一言要約

エルロチニブは EGFR チロシンキナーゼ阻害薬で、元々 EGFR 遺伝子変異陽性の非小細胞肺癌と膵癌の治療に使用されていました。
TxGNN モデルは**ユーイング肉腫 (Ewing sarcoma)** に有効である可能性を予測していますが、裏付けとなるのは**取り下げられた Phase 2 試験 1 件**と**前臨床・総説の文献 2 編**のみで、エビデンスは限定的です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 非小細胞肺癌（EGFR 遺伝子変異陽性）、膵癌 |
| 予測新規適応症 | ユーイング肉腫 (Ewing sarcoma) |
| TxGNN 予測スコア | 95.77% |
| エビデンスレベル | L4 |
| 日本市販状況 | 承認整理済みのみ（現在有効な承認なし） |
| 承認番号数 | 6 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、エルロチニブは受容体型チロシンキナーゼ阻害薬に分類され、EGFR のチロシンキナーゼシグナルを阻害します。EGFR 変異陽性の非小細胞肺癌と膵癌で有効性が確立されています。

ユーイング肉腫を含む小児肉腫では、EGFR/ERBB 経路の関与が検討されてきました。患者由来の異種移植モデルで、EGFR 阻害薬を細胞傷害性薬剤と併用する評価が行われています。そのため、機序的には適用可能性が考えられます。

ただし、この裏付けは前臨床で間接的なものにとどまります。ユーイング肉腫に特化したヒトでの有効性データはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
ユーイング肉腫に対する裏付けは、取り下げられた試験 1 件と前臨床・総説の文献のみで、ヒトでの有効性データがありません。日本ではエルロチニブの承認がすべて整理済みであることも考慮し、現時点では研究課題の段階にとどめるのが妥当です。

**進める場合に必要なもの：**
- ユーイング肉腫の細胞株・動物モデルでの EGFR 依存性と、エルロチニブの有効性の検証
- 小児固形腫瘍を対象とした臨床試験の再設計（EGFR 変異などによる患者選択を含む）
- 添付文書の警告・禁忌の確認（安全性スクリーニングの前提）
- 詳細な作用機序データの補充
- 日本での供給状況（承認整理済み）の確認と、小児での用量・安全性の検討

---

**補足：** 予測順位 2〜10 位（歯肉線維腫症、肺線維腫、肺過誤腫、肺良性腫瘍、肺門部癌、肺胚細胞腫瘍、肺溝腫瘍、VCP 関連封入体ミオパチー、接合部型表皮水疱症）は、いずれも直接の臨床エビデンスがなく、機序上の裏付けも間接的か乏しい状態です。特に接合部型表皮水疱症では、エルロチニブの既知の皮膚毒性が懸念されます。

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

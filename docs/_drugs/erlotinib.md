# エルロチニブ：非小細胞肺癌・膵癌から Ewing 肉腫へ

## 一言要約

エルロチニブは EGFR チロシンキナーゼ阻害薬で、日本では EGFR 遺伝子変異陽性の非小細胞肺癌と膵癌の治療に使われています。
TxGNN モデルは **Ewing 肉腫 (Ewing sarcoma)** に有効である可能性を予測しています。ただし裏づけは **臨床試験 1 件（中止、登録 0 例）** と **文献 2 編（総説と前臨床研究）** だけで、臨床での有効性データはありません。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報では、エルロチニブは「抗悪性腫瘍薬・受容体型チロシンキナーゼ阻害薬」に分類され、EGFR 遺伝子変異陽性の非小細胞肺癌と膵癌での有効性が確立しています。

EGFR/HER ファミリーのシグナルは、小児肉腫でも標的候補として検討されてきました。実際に、抗 HER3 抗体パトリツマブとエルロチニブを標準的な細胞毒性薬（シスプラチン、ビンクリスチン、シクロホスファミド）と併用した小児肉腫の異種移植モデル研究があります。

ただし、この裏づけは前臨床の段階にとどまります。Ewing 肉腫に対するヒトでの有効性や安全性のデータはなく、機序上の可能性がある、という位置づけです。

## 結論と次のステップ

**決定：Hold**

**理由：**
関連する臨床試験は登録 0 例で中止されており、ヒトでの有効性データがありません。裏づけは前臨床研究と総説だけなので、現時点では研究上の問いの段階です。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を確認する（現時点で未取得）
- 詳細な作用機序データ（MOA）の取得
- Ewing 肉腫での EGFR/HER 経路の関与を示す前臨床データの追加
- 小児への適用を想定した安全性の検討（皮膚障害、下痢など）
- 実際に患者が登録された臨床試験の確認

※本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床での検証が必要です。

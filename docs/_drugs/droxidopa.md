# ドロキシドパ：パーキンソン病から変異型プロテアーゼ感受性プリオン病へ

## 一言要約

ドロキシドパは体内でノルアドレナリンに変換される薬で、日本ではパーキンソン病、シャイドレーガー症候群、家族性アミロイドポリニューロパチーの治療に使われています。
TxGNN モデルは**変異型プロテアーゼ感受性プリオン病 (variably protease-sensitive prionopathy)** に有効な可能性を予測していますが、現在この予測を裏づける**臨床試験も文献も見つかっていません**。

## この予測が妥当である理由

ドロキシドパはプロドラッグで、DOPA デカルボキシラーゼによりノルアドレナリンに変換されます。ノルアドレナリンを補うことで、神経原性起立性低血圧などの症状を和らげます。

変異型プロテアーゼ感受性プリオン病は、まれな孤発性のプリオン病です。ドロキシドパの作用機序とこの疾患の病態との間に、確立した機序的なつながりは見つかっていません。既存適応症との関連も示せていません。

TxGNN スコアは 99.33% と高い値ですが、これはモデルによる予測にすぎません。現時点では、実際の研究による裏づけがない仮説段階の候補として扱うべきです。

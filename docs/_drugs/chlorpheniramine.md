# クロルフェニラミン：アレルギー性鼻炎からアレルギー性蕁麻疹へ

## 一言要約

クロルフェニラミンは第一世代の H1 受容体拮抗薬で、日本では元々アレルギー性鼻炎などのアレルギー疾患に使用されてきました。
TxGNN モデルは**アレルギー性蕁麻疹 (Allergic Urticaria)** に有効である可能性を予測しています。
関連する **3 件の臨床試験**と **20 編の文献**がありますが、いずれも蕁麻疹に対する本剤単独の試験ではなく、間接的な支持にとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし日本の承認情報では、本剤は抗アレルギー薬・H1 受容体拮抗薬に分類されています。

蕁麻疹の膨疹と紅斑は、肥満細胞から放出されたヒスタミンが H1 受容体に作用して生じます。クロルフェニラミンはこの受容体を遮断するため、機序の面ではアレルギー性蕁麻疹に適用できる可能性があります。既存適応のアレルギー性鼻炎も同じヒスタミン介在性の疾患であり、疾患間の関連性は高いといえます。

裏付けとなる文献の多くは、総説や抗ヒスタミン薬全般についてのデータです。参考として、別の予測である寒冷蕁麻疹では、本剤を含む小規模な二重盲検比較試験 (PMID 334082、1977 年) があります。ただし規模が小さく、古い試験です。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

参考として、文献にはクロルフェニラミン自体によるアナフィラキシーなど過敏反応の症例報告があります (PMID 31852144、26240795)。また、第一世代抗ヒスタミン薬として、鎮静作用と抗コリン作用が主な注意点です。

## 結論と次のステップ

**決定：Hold**

**理由：**
機序上は妥当で、TxGNN スコアも高い予測です。しかし、蕁麻疹に対する本剤単独の試験はなく、支持する文献も総説と抗ヒスタミン薬全般のデータが中心です。加えて、日本の添付文書の警告・禁忌が未取得のため、安全性の初期評価に進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（必須。安全性評価の前提）
- DrugBank からの作用機序 (MOA) データ取得
- 蕁麻疹に対するクロルフェニラミンの比較試験またはシステマティックレビューの調査
- 第二世代抗ヒスタミン薬との位置づけの整理
- 剤形・投与経路の適合性の確認

なお、本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床的な検証を経て初めて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# クロルフェニラミン：アレルギー性鼻炎からアレルギー性蕁麻疹へ

## 一言要約

クロルフェニラミンは第一世代の H1 受容体拮抗薬で、日本では元々アレルギー性鼻炎の治療に使用されていました。
TxGNN モデルは**アレルギー性蕁麻疹 (Allergic Urticaria)** に有効である可能性を予測しています。
ただし、この予測を直接支持する臨床試験の登録はなく、文献も主に総説で、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、クロルフェニラミンはアルキルアミン系の第一世代 H1 抗ヒスタミン薬で、ヒスタミンによる膨疹、紅斑、掻痒を抑えます。アレルギー性鼻炎での使用実績があります。

アレルギー性鼻炎とアレルギー性蕁麻疹は、どちらも肥満細胞から放出されるヒスタミンが症状の中心にある IgE 介在性の疾患です。H1 受容体を遮断するという同じ機序が、蕁麻疹の膨疹や痒みにも働くと考えられます。蕁麻疹では抗ヒスタミン薬が標準治療の柱でもあります。

ただし、今回提供された文献は総説が中心で、クロルフェニラミン自体を検証した対照データは含まれていません。機序的な妥当性は高い一方、臨床的な裏付けは今後の確認が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 機序的な妥当性は高いものの、アレルギー性蕁麻疹に対するクロルフェニラミン固有の臨床試験登録はなく、文献も他剤の総説が中心で、エビデンスは L4 にとどまります。
- 日本では販売中の承認がなく、添付文書の警告・禁忌データも未取得のため、安全性評価に進めません。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と、安全性スクリーニングの実施
- 詳細な作用機序データ（MOA）の補充
- クロルフェニラミンを対象にした蕁麻疹の対照臨床データの収集、または新規試験の計画
- 参考として、より進んだ候補は寒冷蕁麻疹（二重盲検試験が 1 件あり、L2）と鼻炎（L2、ただし登録試験は取り下げ・早期終了が中心）です。これらを優先的に検討する価値があります。
- 日本での販売再開または剤形の方針の確認

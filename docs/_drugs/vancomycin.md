# バンコマイシン：MRSA感染症からびまん性強皮症へ

## 一言要約

バンコマイシンはグリコペプチド系の抗生物質で、元々はメチシリン耐性黄色ブドウ球菌（MRSA）感染症などの治療に使用されていました。
TxGNN モデルは**びまん性強皮症 (Diffuse Scleroderma)** に有効である可能性を予測していますが、支持する臨床試験は **0 件**、関連文献は **1 編**（症例報告、内容も無関係）にとどまります。
機序面でも関連が見当たらず、この予測は偽陽性の可能性が高いと考えられます。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、バンコマイシンは細菌の細胞壁合成を阻害するグリコペプチド系抗生物質で、グラム陽性菌に作用します。

強皮症は線維化と免疫異常を特徴とする自己免疫疾患で、細菌感染症ではありません。バンコマイシンに抗線維化作用や免疫調節作用は知られておらず、既存適応症と新規適応症の間に機序的な接点は確認できません。予測スコアは高いものの、機序面からは妥当とは言えません。

## 結論と次のステップ

**決定：Hold**

**理由：**
びまん性強皮症に対する臨床試験はなく、文献も無関係な症例報告 1 編のみです。バンコマイシンの作用機序から見ても関連を説明できないため、モデル予測のみの段階（L5）で、進める根拠がありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現状は安全性スクリーニングに進めない）
- DrugBank からの作用機序データの補完
- 強皮症に対する機序的仮説と前臨床データ（現時点では見当たらない）

**参考：**
同じ予測リストの中では、肺炎球菌性肺炎（rank 9、L4）のほうが機序的に妥当です。ただし、これはグラム陽性菌に対する既存の抗菌スペクトルの範囲内であり、新規適応症と呼べるものではありません。

# バンコマイシン：細菌感染症（MRSA・C. difficile 腸炎など）から全身性強皮症（びまん型）へ

## 一言要約

バンコマイシンは細胞壁合成を阻害するグリコペプチド系抗生物質で、元々メチシリン耐性黄色ブドウ球菌（MRSA）感染症やクロストリジウム・ディフィシル腸炎などの治療に使用されていました。
TxGNN モデルは**びまん型強皮症 (diffuse scleroderma)** に有効である可能性を予測していますが、臨床試験は **0 件**、関連文献も **1 編**（症例報告で、薬効を支持する内容ではありません）にとどまります。
機序的な裏付けもなく、現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、バンコマイシンはペプチドグリカン前駆体の D-Ala-D-Ala 末端に結合して細菌の細胞壁合成を阻害するグリコペプチド系抗生物質で、グラム陽性菌に対して有効性が確立されています。

一方、強皮症は線維化・血管障害・自己免疫を特徴とする疾患です。バンコマイシンには、強皮症に関連する抗線維化作用や免疫調節作用は知られていません。そのため、今回の予測は機序的に支持されません。

TxGNN のスコアは高い（99.92%）ものの、これは知識グラフ上の関連性に基づくモデル出力にすぎません。実際の研究による裏付けは確認できませんでした。

なお、予測上位の他の候補（パラチフス、サルモネラ症、腸チフスなど）も、グラム陰性菌はバンコマイシンの抗菌スペクトル外であり、同様に機序的根拠がありません。肺炎球菌肺炎は機序的に妥当ですが、既存適応（ペニシリン耐性肺炎球菌感染症）と重複しており、真の再利用シグナルではありません。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の関連疾患）**：腎疾患、膿尿管症、好中球減少症、無顆粒球症、聴覚障害、聴覚系疾患。これらは添付文書の記載ではなく、知識グラフ上の禁忌関連情報です。
- **薬物相互作用**：100 件の相互作用が検出されています。
  - **重大 (Major)**：ヒト免疫グロブリン G（静注）、ヒトボツリヌス神経毒素 A/B 免疫グロブリン、コレラ生ワクチン（CVD 103-HgR 株）
  - **中等度 (Moderate)**：アミノグリコシド系のアミカシン、アムホテリシン B、カプレオマイシン、カルボプラチン、NSAIDs（ケトロラク、イブプロフェン、ジクロフェナク、セレコキシブ）、コレスチラミンなど。腎毒性や聴器毒性の増強、吸収への影響が懸念されます。

詳細な警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 臨床試験がなく、文献も薬効を支持するものではありません。作用機序上も強皮症との関連が見いだせず、モデル予測のみ（L5）の段階です。
- 日本の承認はすべて取消済みで、市販品がない点も再利用の障壁となります。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と解析（安全性スクリーニングの前提）
- DrugBank からの作用機序（MOA）データの取得
- 強皮症に対する抗線維化・免疫調節作用を示す前臨床研究（機序の裏付け）
- 肺炎球菌肺炎など、既存適応と重複しない候補の再検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ドンペリドン：制吐・消化管運動改善から腎性抗利尿ホルモン不適切分泌症候群へ

## 一言要約

ドンペリドンは末梢性ドパミン D2 受容体拮抗薬で、日本では制吐薬・消化管運動改善薬として使用されています。
TxGNN モデルは**腎性抗利尿ホルモン不適切分泌症候群 (nephrogenic syndrome of inappropriate antidiuresis)** に有効である可能性を予測していますが、
**臨床試験 0 件・文献 0 編**で、裏付けとなるエビデンスはありません（モデル予測のみ）。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ドンペリドンは末梢性ドパミン D2 受容体拮抗薬で、悪心・嘔吐と上部消化管運動低下の改善に使われています。

一方、腎性 SIAD はバソプレシン V2 受容体 (AVPR2) の機能獲得型変異で起こる疾患です。D2 受容体拮抗とは標的も病態も異なり、機序的に妥当な関連は確認できません。今回のスコアはナレッジグラフ上の近接性に基づくもので、治療効果を示すものではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
最上位の予測（腎性 SIAD）には臨床試験も文献もなく、機序的にも妥当な関連がありません。10 位までの予測はいずれも L5 が中心で、実質的な裏付けがありません。

**参考：** 4 位の「頭痛性疾患」には約 20 編の文献（L3）があります。ただし内容は片頭痛に伴う悪心・嘔吐や胃うっ滞に対する補助的な制吐・消化管運動改善であり、頭痛そのものへの直接効果ではありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現時点で最優先のブロッキング項目。安全性スクリーニング S1 に進めない）
- DrugBank からの作用機序 (MOA) データの取得
- 頭痛を優先候補として再評価する場合は、QT 延長リスクと薬物相互作用（未確認）の確認
- 腎性 SIAD を追う場合は、AVPR2 経路との機序的関連を示す前臨床データの確認

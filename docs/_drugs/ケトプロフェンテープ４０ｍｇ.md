## 一言要約

ケトプロフェンテープ４０ＭＧはケトプロフェン（NSAID）を含む経皮吸収型テープ剤と考えられますが、今回の照会では PMDA データベースの該当レコードが **0 件**であり、DrugBank ID も未確定のため TxGNN モデルへの統合が未完了です。その結果、新規適応症の予測が実施されず、老薬新用としての評価を進めることができません。本レポートは現状の課題整理と次アクションの提示を目的としています。

## この予測が妥当である理由

**予測が実施されていないため、機序的関連性の評価はできません。**

ケトプロフェン（ketoprofen）は一般薬理学的に COX-1/COX-2 阻害薬（非ステロイド性抗炎症薬）として知られており、プロスタグランジン合成を抑制することで抗炎症・鎮痛・解熱効果を発揮します。経皮吸収テープ剤は、全身性副作用を軽減しながら局所組織に有効成分を届ける剤形として日本で広く使用されています。

しかし、本 Evidence Pack には以下の重大な問題があります。

1. **薬物名の形式問題**：入力値「ケトプロフェンテープ４０ＭＧ」は製品名（全角文字混在）であり、INN ではありません。PMDA の照会に失敗した原因と考えられます。
2. **DrugBank ID 未取得**：DrugBank の照会では 1 件ヒットしたものの、DrugBank ID が Evidence Pack に反映されておらず、TxGNN 知識グラフへの統合が未完了です。
3. **予測未実施**：上記 2 点の影響で、TxGNN による新規適応症スコアが算出されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による新規適応症の予測が未実施であり、規制当局データも取得できていないため、老薬新用評価の基盤となるデータが揃っていません。現段階での前進は不可です。

**進める場合に必要なもの：**

- **薬物名の正規化**：入力名を製品名からINN「ケトプロフェン（ketoprofen）」に変換し、PMDA および DrugBank を再照会する
- **DrugBank ID の確定**：DrugBank の照会結果（1 件ヒット済み）から正式 ID（例：DB01009）を確認し、Evidence Pack に記録する
- **TxGNN 予測の再実行**：DrugBank ID が確定したうえで、`run_kg_prediction.py` および DL 予測を再実行する
- **PMDA 再照会**：半角 INN またはヨミガナ（ケトプロフェン）を用いて PMDA データベースを再照会し、承認情報・仿単を取得する
- **MOA および安全性データの取得**：DrugBank API または PMDA 仿単 PDF から作用機序・警告・禁忌を抽出し、DG001・DG002 の Data Gap を解消する

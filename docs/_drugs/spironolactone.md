# スピロノラクトン：高血圧症・原発性アルドステロン症から頭皮の単純性乏毛症へ

## 一言要約

スピロノラクトンは、日本では高血圧症と原発性アルドステロン症の治療に使われているアルドステロン拮抗薬です。
TxGNN モデルは**頭皮の単純性乏毛症 (Hypotrichosis simplex of the scalp)** に有効である可能性を予測していますが、この疾患を直接支持する臨床試験・文献は **0 件**で、根拠はモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、スピロノラクトンはミネラルコルチコイド受容体拮抗薬（アルドステロン拮抗薬）で、抗アンドロゲン作用も持ちます。この抗アンドロゲン作用が、毛包の生物学に影響する可能性があります。

ただし、遺伝性の乏毛症との関連は推測の域を出ません。既存適応症（高血圧症・原発性アルドステロン症）は、アルドステロン経路の遮断による作用です。予測された疾患とは病態が大きく異なります。妥当性を裏付ける臨床データも機序データもなく、根拠は TxGNN の予測のみです。

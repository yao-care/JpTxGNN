# ロキソプロフェンNAテープ 50mg：データ不足により再利用評価保留

## データ品質の問題

通常の評価フローを完遂するために必要なデータが複数欠損しています：

| 問題 | 重要度 | 影響 |
|------|--------|------|
| PMDA クエリ結果 0 件 | 高 | 承認情報・既存適応症が不明 |
| DrugBank ID 未格納（クエリは 1 件ヒット） | 高 | 作用機序・安全性データが取得できない |
| TxGNN 予測結果なし | 致命的 | 新規適応症候補が存在しない |

**PMDA クエリ失敗の原因推定**：クエリに使用した文字列 `ﾛｷｿﾌﾟﾛﾌｪﾝNAﾃｰﾌﾟ50MGﾀ`（半角カタカナ混在）がデータベースの表記と不一致になった可能性があります。DrugBank は 1 件ヒットしていますが、DrugBank ID が Evidence Pack に格納されておらず、後続処理（MOA 取得・TxGNN 予測）が実行されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN 予測が実行されておらず、既存適応症・DrugBank ID・安全性データがすべて未取得のため、薬物再利用の評価を実施できません。データパイプラインの修正が先決です。

**進める場合に必要なもの：**
- **PMDA 再クエリ**：全角カタカナ「ロキソプロフェンNAテープ」または INN「loxoprofen」で再実行
- **DrugBank ID の確認と格納**：クエリは 1 件ヒット済みのため、手動でID を特定し Evidence Pack を更新
- **TxGNN 予測の再実行**：DrugBank ID 取得後、KG 予測・DL 予測を実行
- **安全性データの取得**：PMDA 添付文書 PDF から警語・禁忌を解析（DG001 対応）
- **MOA データの取得**：DrugBank API から作用機序を取得（DG002 対応）

# ドンペリドン：データ不足により老薬新用予測不可

## 一言要約

ドンペリドン（Domperidone）はドパミン D2/D3 受容体拮抗薬に分類される制吐・消化管運動改善薬であり、世界各国で広く使用されています。
今回の Evidence Pack では、クエリ文字列「ﾄﾞﾝﾍﾟﾘﾄﾞﾝ5MG」に剤形規格情報が混在しているため薬物同定が不完全となり、**TxGNN 予測・承認情報・安全性データのいずれも取得できていません**。
現時点では老薬新用候補の評価を実施することができず、データ再取得が必要です。

## データ品質上の問題

本 Evidence Pack はデータ収集段階で以下の根本的な問題が発生しており、評価継続が困難な状態です。

### クエリ文字列の問題

PMDA・DrugBank ともに照合クエリが `ﾄﾞﾝﾍﾟﾘﾄﾞﾝ5MG` という形式で実行されました。この文字列には：

- **半角カタカナ**：PMDA・DrugBank の標準フォーマットと不一致
- **剤形規格情報（5MG）**：薬物名に規格が混入しており、薬名単独の照合が困難

DrugBank のクエリログは `result_count: 1` を返していますが `drugbank_id: null` のままであり、マッピングに失敗したことを示しています。

### 特定済みデータギャップ

| ギャップ ID | 項目 | 重要度 | 影響範囲 | 補完方法 |
|------------|------|--------|---------|---------|
| DG001 | 日本承認情報（警語・禁忌） | Blocking | 安全性初評が不可能 | PMDA 官サイトより仿単 PDF を取得・解析 |
| DG002 | 作用機序（MOA） | High | 機序関連性分析に影響 | DrugBank API で正規化名称で再クエリ |

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による老薬新用予測候補が 0 件であり、承認情報・安全性データいずれも取得されていません。薬物同定の失敗がすべての下流評価をブロックしており、現状では評価を進める根拠がありません。

**進める場合に必要なもの：**

1. **薬物名の正規化**：`ﾄﾞﾝﾍﾟﾘﾄﾞﾝ5MG` → `ドンペリドン`（全角カタカナ、規格情報を除外）、または INN 英語名 `Domperidone` でクエリを再実行
2. **DrugBank ID の確定**：正規化名称で DrugBank を再照合し、`DB01184`（Domperidone の標準 ID）を紐付け
3. **PMDA 再照合**：正規化した薬物名で承認番号・適応症・警語・禁忌を再取得
4. **TxGNN 予測の再実行**：確定した DrugBank ID を入力として KG 予測・DL 予測を実行
5. **Evidence Pack v5 再生成**：上記すべてが揃った段階で本レポートを再発行

# マグネシウム：電解質補充から偏頭痛 (Migraine Disorder) へ

## 一言要約

マグネシウムは体内で 300 以上の酵素反応に関与する必須ミネラルで、日本では医薬品として未承認ですが、電解質補充・代謝サポートとして広く知られています。TxGNN モデルは**偏頭痛 (Migraine Disorder)** に有効である可能性を **98.03%** の信頼スコアで予測しており、現在 **28 件の臨床試験**と **20 編の文献**がこの適応症を支持しています。国際的な頭痛学会ガイドラインへの収載済みかつ Phase 3 試験が完了していることから、エビデンスレベルは **L1** に達しています。

## この予測が妥当である理由

マグネシウムは神経興奮性の制御において中心的な役割を担っており、**NMDA 受容体の天然拮抗薬**として機能することが実証されています。偏頭痛の主要な発症機序とされる**皮質拡散抑制（cortical spreading depression; CSD）**は、低マグネシウム状態で開始閾値が低下し、発作が誘発されやすくなります。さらに、マグネシウムは血管平滑筋の弛緩を促すことで、偏頭痛に関連する血管収縮反応を抑制します。

複数の疫学研究において、偏頭痛患者では健常者と比較して血清・細胞内マグネシウム濃度が有意に低値であることが一貫して示されています。特に先兆を伴う偏頭痛では細胞内マグネシウムの低下が顕著であり、グルタミン酸系神経伝達の亢進（NMDA 受容体過活性）との相乗効果が病態を増悪させると考えられています。これらの機序的根拠を背景に、マグネシウム補充療法は複数の RCT およびメタ解析で有効性が実証されており、米国頭痛学会（AHS）および欧州神経学会（EAN）の偏頭痛予防ガイドラインにすでに収載されています。

なお、本 Evidence Pack 作成時点では DrugBank 由来の詳細な作用機序データ（MOA）は未取得（DG002: High 優先度のデータギャップ）です。上記の機序情報は既存の査読文献に基づくものです。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
偏頭痛に対するマグネシウムの有効性は Phase 3 試験を含む複数の RCT・メタ解析・系統的レビューで実証されており、AHS・EAN の国際ガイドラインにすでに予防薬として収載されています（エビデンスレベル L1）。ただし、日本での医薬品承認実績がなく、詳細な安全性データも未収集のため、規制整備と安全性確認を前提とした段階的な推進が必要です。

**進める場合に必要なもの：**
- 日本 PMDA 申請要件の確認（急性治療用静脈内製剤と予防用経口製剤それぞれの規格・用法用量の設定）
- DrugBank API を経由した詳細な作用機序データ（MOA）の取得（DG002 解消）
- TFDA 仿単の警語・禁忌データ収集（DG001: Blocking ステータス解消）
- 日本人集団に特化した安全性モニタリング計画の策定
- 投与経路（静脈内 vs 経口）ごとの製剤化戦略の確立

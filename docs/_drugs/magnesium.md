# マグネシウム：制酸・緩下から片頭痛へ

## 一言要約

マグネシウムは日本で酸化マグネシウム製剤として市販されており、制酸薬・緩下剤・吸着剤（胃・十二指腸潰瘍など）に使われてきました。
TxGNN モデルは**片頭痛 (Migraine Disorder)** に有効である可能性を予測しています（スコア 98.03%）。
片頭痛に関する臨床試験は 28 件、文献は 20 編ありました。マグネシウムを直接扱う試験は約 9 件で、うち Phase 3 の完了試験は 1 件です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、マグネシウムは酸化マグネシウム製剤として胃腸領域で使われています。一方、生体内では神経伝達や筋収縮に関わる必須ミネラルです。

片頭痛との関連は次のように整理できます。マグネシウムは NMDA 受容体拮抗作用とカルシウムチャネル調節作用を持ちます。これにより、片頭痛の病態に関わるとされる皮質拡延性抑制や神経の過興奮を抑える可能性があります。文献にも、マグネシウム欠乏が片頭痛の病態に関与するという報告があります。

ただし、片頭痛での試験の多くは静注の硫酸マグネシウムか、他成分（リボフラビン、CoQ10 など）との配合サプリメントです。日本で市販されている経口の酸化マグネシウム単剤の効果は、直接は検証されていません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
片頭痛では、静注マグネシウムの Phase 3 試験（完了 1 件、進行中を含め計 2 件）と、マグネシウム含有サプリの複数の RCT・観察研究があり、機序上の妥当性もあります。
ただし、直接の根拠は静注製剤や配合サプリが中心で、日本で市販されている経口の酸化マグネシウムの有効性は示されていません。日本の添付文書に基づく安全性確認もまだ終わっていません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（腎機能低下例での高マグネシウム血症リスクを含む。現時点で最優先）
- 詳細な作用機序データ（DrugBank など）の補充
- 経口酸化マグネシウム単剤での片頭痛予防・急性期効果を評価する臨床試験の検討
- 静注（試験の主流）と経口（日本の市販剤形）の投与経路の差を整理し、用量設計を確認
- 完了済み Phase 3 試験（NCT05967442）の結果と、進行中試験（NCT06904287）の結果の追跡

なお、本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的検証を経て初めて実用化できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

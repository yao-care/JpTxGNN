# マグネシウム：胃・十二指腸潰瘍から片頭痛へ

## 一言要約

マグネシウム（酸化マグネシウム製剤）は、元々制酸薬・緩下剤・吸着剤として胃・十二指腸潰瘍などに使用されていました。
TxGNN モデルは**片頭痛 (Migraine Disorder)** に有効である可能性を予測しており、現在 **8 件の臨床試験**と **20 編の文献**がこの方向性を支持しています。

## クイック概要

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、マグネシウムは酸化マグネシウム製剤として胃・十二指腸潰瘍などでの使用実績があります。

文献上、マグネシウムは NMDA 受容体拮抗作用とカルシウムチャネル調節作用を持つと考えられています。これにより、片頭痛の病態に関わる皮質拡延性抑制や神経の過興奮を抑える可能性があります。また、マグネシウム欠乏が片頭痛の発症に関与するとの報告も多くあります。

ただし、この機序の根拠は文献に基づくもので、薬物レベルの作用機序データによる裏付けではありません。消化器疾患から神経疾患への展開であるため、既存適応症との直接的な関連は限定的です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
片頭痛に対しては、完了した Phase 3 の無作為化二重盲検試験があり、メタ解析やシステマティックレビューも複数あります。そのためエビデンスは比較的厚いといえます。一方で、日本では販売中の承認がなく、薬物レベルの作用機序と安全性（添付文書の警告・禁忌）のデータが不足しています。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と安全性評価
- 薬物レベルの作用機序データ（DrugBank など）の補完
- 完了試験（NCT05967442 など）の結果と、メタ解析・Cochrane レビューの精査
- 投与経路・剤形（経口か静注か）の検討と、国内での制度上の位置づけ（承認再取得か、栄養補助としての扱いか）の整理
- 腎機能低下者など、高マグネシウム血症リスクのある集団に対する安全性モニタリング計画

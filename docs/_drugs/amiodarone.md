# アミオダロン：心房細動・肥大型心筋症からカテコラミン誘発多形性心室頻拍へ

## 一言要約

アミオダロンは抗不整脈薬（カリウムチャネル遮断薬）で、日本では心房細動や肥大型心筋症などの不整脈治療に使われています。
TxGNN モデルは**カテコラミン誘発多形性心室頻拍 (CPVT)** に有効である可能性を予測しています。ただし臨床試験は **0 件**で、関連文献 **10 編**もほとんどが症例報告やコホート研究です。アミオダロンの有効性を直接示す証拠は乏しい状況です。

## この予測が妥当である理由

アミオダロンはカリウム・ナトリウム・カルシウムの各チャネルを遮断し、抗アドレナリン作用も併せ持つ薬です。詳細な作用機序データは Evidence Pack に含まれていませんが、上記の多チャネル遮断作用は Evidence Pack の機序仮説に記載されています。

CPVT は、運動や交感神経刺激で誘発される遺伝性の致死的不整脈で、主に RYR2 変異が関与します。アミオダロンの多チャネル遮断作用と抗アドレナリン作用は、こうしたアドレナリン刺激で誘発される不整脈を抑える可能性があります。既存適応症（心房細動など）も同じ不整脈領域なので、機序面ではつながりがあります。

ただし、報告は症例レベルにとどまります。CPVT ではβ遮断薬とフレカイニドが標準治療で、アミオダロンの位置づけは確立していません。

## 結論と次のステップ

**決定：Hold**

**理由：**
CPVT に対する臨床試験はなく、文献は症例報告と疾患の記述的研究が中心で、アミオダロンの有効性を直接示すものはありません。標準治療（β遮断薬、フレカイニド）が確立しているため、現時点で進める根拠は不足しています。

なお、同じ予測リストの**心室頻拍（一般）**には RCT やメタ解析があり、エビデンスレベルは L1、推奨は Proceed with Guardrails です。再利用候補として優先度が高いのはこちらです。

**進める場合に必要なもの：**
- CPVT 患者でのアミオダロン使用に関する、より質の高い研究（コホート研究や比較試験）
- 日本の添付文書（警告・禁忌）の取得と確認
- 詳細な作用機序データ（MOA）の取得
- 相互作用（DDI）データの再取得。アミオダロンは相互作用が多い薬で、今回の 0 件は取得できなかっただけと考えられます

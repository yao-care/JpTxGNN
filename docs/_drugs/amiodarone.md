## Amiodarone: カテコラミン誘発性多形性心室頻拍 (catecholaminergic polymorphic ventricular tachycardia)
{: .text-alpha }

## 一言要約

アミオダロンは、日本で抗不整脈薬（カリウムチャネル遮断薬）として市販されている薬です。
TxGNN モデルは**カテコラミン誘発性多形性心室頻拍 (catecholaminergic polymorphic ventricular tachycardia)** への有効性を予測しています。
ただし、アミオダロンをこの疾患で直接検証した臨床試験や文献は見つかっておらず、エビデンスレベルは **L5（モデル予測のみ）** です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。アミオダロンは K⁺・Na⁺・Ca²⁺ チャネルを複数遮断し、抗アドレナリン作用も持つ薬剤として知られています。

この疾患は、交感神経刺激で誘発される RyR2 などのカルシウム調節異常による不整脈です。理論上は、アミオダロンのカテコラミン刺激を抑える作用が不整脈の抑制に働く可能性があります。

しかし、この疾患の確立した治療はβ遮断薬とフレカイニドです。アミオダロンを支持する直接的な根拠は、現時点で確認できていません。上記の機序は仮説の段階にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、アミオダロンをこの疾患で検証した臨床試験や文献がなく、エビデンスはモデル予測のみ（L5）です。
- 既存の標準治療（β遮断薬、フレカイニド）があり、アミオダロンが優先される根拠は示されていません。

**進める場合に必要なもの：**
- この疾患でのアミオダロンの有効性を直接検討した研究（前臨床・症例集積・臨床試験）の探索と整理
- 詳細な作用機序データ（MOA）の補充
- 添付文書に基づく警告・禁忌の確認と、安全性評価の実施
- 標準治療との位置づけの比較
- QT 延長を起こしうる併用薬を考慮した、相互作用の管理方針

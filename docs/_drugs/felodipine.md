# フェロジピン：高血圧症から肺疾患・低酸素に伴う肺高血圧症へ

## 一言要約

フェロジピンはカルシウムチャネル遮断薬で、日本では高血圧症の治療に使われています。
TxGNN モデルは**肺疾患・低酸素に伴う肺高血圧症 (pulmonary hypertension owing to lung disease and/or hypoxia)** に有効な可能性を予測しています。
ただし、**臨床試験は 0 件**で、取得された 20 編の文献もフェロジピンや肺高血圧症を扱っておらず、根拠は現時点でモデル予測のみです。

## この予測が妥当である理由

詳細な作用機序データはありません。ただし日本の承認情報では、フェロジピンは血圧降下薬・血管拡張薬・カルシウムチャネル遮断薬に分類されています。L-type カルシウムチャネルを遮断して血管平滑筋を弛緩させ、血管抵抗を下げる薬です。

肺高血圧症では肺血管の収縮が病態に関わるため、同じ血管拡張作用が肺血管の緊張を下げる可能性があり、この点が予測の機序的な根拠です。ただし、今回取得された文献は低酸素の一般的な生物学に関するもので、フェロジピンのデータは含まれていません。この機序仮説を直接裏付ける証拠は、現時点ではありません。

参考として、同じ Evidence Pack の別の予測（慢性肺性心）に、重症慢性閉塞性肺疾患 (COPD) 患者にフェロジピンを投与した 1988 年の小規模な血行動態研究 (PMID: 2838319) があります。この研究では、肺血管抵抗が 18% 低下し、心拍出量が増加しました。方向性は一致しますが、被験者は 11 名で、肺高血圧症そのものの評価ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
肺疾患・低酸素に伴う肺高血圧症については、臨床試験も直接関連する文献もなく、モデル予測のみ（L5）です。日本の添付文書に基づく安全性確認も未実施です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と確認（現在、安全性評価を進められない状態）
- 薬物相互作用データの取得
- 詳細な作用機序データ（DrugBank など）の補充
- フェロジピンと肺高血圧症（特に肺疾患に伴うもの）に絞った文献の再検索
- 1988 年の COPD 血行動態研究など、肺血管抵抗への作用を示す既存の知見の精査

なお、同じ Evidence Pack の別候補である**プリンツメタル狭心症**（予測スコア 99.07%）は、フェロジピンの無作為化比較試験を含む文献があり、エビデンスレベルは L2 です。優先的に検討する候補として、この方向性も確認する価値があります。

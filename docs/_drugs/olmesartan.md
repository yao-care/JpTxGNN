# オルメサルタン：血圧降下薬（アンジオテンシンII受容体拮抗薬）から片頭痛へ

## 一言要約

オルメサルタンは、元々高血圧治療に使われるアンジオテンシンII受容体拮抗薬（ARB）です。
TxGNN モデルの予測スコア最上位は**異型狭心症 (Prinzmetal angina)** ですが、この疾患には臨床試験も文献もありません。実際の研究エビデンスが最も揃っているのは**片頭痛 (migraine disorder)** で、**3 編の文献**（メタアナリシス 1 編、コホート研究 1 編、レビュー 1 編）があります。このレポートでは、エビデンスのある片頭痛を中心に評価します。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 血圧降下薬、アンジオテンシンII受容体拮抗薬（高血圧） |
| 予測新規適応症 | 異型狭心症 (Prinzmetal angina)（TxGNN 最上位）／エビデンス最多：片頭痛 (migraine disorder) |

| 日本市販状況 | 販売中の承認なし（20 件すべて承認整理済み） |
| 承認番号数 | 20 件（有効 0 件、整理済み 20 件） |
| 推奨決定 | 異型狭心症：Hold／片頭痛：Hold（研究課題として継続） |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、オルメサルタンは AT1 受容体を遮断し、アンジオテンシンII による血管収縮を抑える ARB です。高血圧での有効性が確立されています。

**片頭痛**：アンジオテンシンIIの遮断は、脳血管の緊張や神経性炎症を調節する可能性があります。ACE 阻害薬や ARB に片頭痛予防の兆候が報告されています。ただし、報告の多くは高血圧患者が対象です。効果の一部は血圧低下によるものかもしれません。

**異型狭心症**：AT1 遮断により、冠動脈攣縮に関わる血管収縮が軽減される可能性があります。しかし理論上の推測にとどまり、臨床・文献エビデンスはありません。

予測上位には毛髪疾患（低毛症、脱毛症など）も多く含まれます。AT1 遮断との明確な機序的関連は見当たらず、知識グラフ上の関連性による予測と考えられます。

## 臨床試験エビデンス

片頭痛に関連する臨床試験の登録はありません。

参考：予測順位 5 位の肺高血圧症では ARB に関する試験が 1 件ありましたが、COVID-19 患者での ACE 阻害薬/ARB 継続を調べるもので、肺高血圧症とも、オルメサルタン単独とも無関係です。

## 安全性に関する考慮事項

- **薬物相互作用**：94 件の相互作用が登録されています。
  - **重大 (Major)**：カリウム製剤（炭酸水素カリウム、塩化カリウム）。高カリウム血症のリスクに注意が必要です。
  - **中等度 (Moderate)**：ヒドロコルチゾン、エルクサドリン、エキセナチド、各種インスリン製剤、電解質入りポリエチレングリコールなど。
- **妊娠**：ARB は胎児の腎機能障害や羊水過少のリスクがあるため、妊娠中は避けるべき薬剤です。症例報告（PMID: 41815228）でも、オルメサルタン中止後に羊水量が速やかに正常化した例が示されています。

警告・禁忌の詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold（片頭痛は研究課題として継続）**

**理由：**
- TxGNN 最上位の異型狭心症は、実際の研究がなく L5 にとどまります。
- 片頭痛は文献があり L3 ですが、臨床試験がなく、報告の多くは高血圧患者対象です。血圧低下による二次的効果を否定できません。
- 日本では販売中の承認もありません。

**進める場合に必要なもの：**
- 片頭痛予防についてのオルメサルタン固有の臨床データ（非高血圧患者を含む RCT）
- 作用機序データの補充（DrugBank からの取得）
- 添付文書の警告・禁忌の取得と安全性評価（現状は未取得で、安全性審査を進める前に必須）
- 販売中の製剤や、再承認・販売経路の確認
- 片頭痛予防として使われている他の ARB（カンデサルタンなど）や既存の予防薬との比較検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# グリベンクラミド：2型糖尿病から骨異形成症（オプシスモ異形成症）へ

## 一言要約

グリベンクラミド（Glyburide）はスルホニル尿素系の血糖降下薬で、元々インスリン非依存型糖尿病の治療に使用されていました。
TxGNN モデルは**オプシスモ異形成症 (Opsismodysplasia)** に有効である可能性を予測していますが、この疾患に関する臨床試験・文献は現在ありません。
予測はモデルのスコアのみに基づいており、エビデンスは非常に限られています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | インスリン非依存型糖尿病（糖尿病治療薬、血糖降下薬） |
| 予測新規適応症 | オプシスモ異形成症 (Opsismodysplasia) |
| TxGNN 予測スコア | 97.24% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認は全件が取消済み（現在市販なし） |
| 承認番号数 | 14 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、グリベンクラミドは膵β細胞の KATP チャネル（SUR1/Kir6.2）を阻害し、インスリン分泌を促進するスルホニル尿素系薬剤です。

オプシスモ異形成症は INPPL1 遺伝子変異によって起こる骨格異形成症です。グリベンクラミドの作用機序との間に確立された関連はなく、この予測の妥当性を裏付ける機序的根拠は現時点で確認できていません。予測はナレッジグラフ上の関連に基づくモデル出力にとどまります。

参考として、他の上位予測（スコア順）も、いずれも臨床的裏付けがありません。

| 順位 | 予測疾患 | スコア | エビデンスレベル |
|------|---------|--------|----------------|
| 2 | 古典的スティッフパーソン症候群 | 96.90% | L5 |
| 3 | 限局性スティッフ肢症候群 | 96.90% | L5 |
| 4 | チアミン反応性機能障害症候群 | 96.77% | L5 |
| 5 | 薬剤性限局性リポジストロフィー | 95.22% | L5 |
| 9 | 膵無形成 | 94.34% | L4 |

膵無形成のみ、β細胞生理に関する間接的な基礎研究があります。ただし β 細胞が欠損する病態では、グリベンクラミドの作用機序そのものが成立しにくいと考えられます。

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、モデルのデータに基づく）：肝不全、腎疾患、肝疾患、胆嚢疾患、下垂体機能低下症、副腎皮質機能不全、アジソン病、感染症など。

血糖コントロールへの影響（低血糖・高血糖の増強）に注意が必要な組み合わせが含まれます。詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 上位の予測疾患はいずれも臨床試験・文献がなく、機序的な裏付けもありません（L5）。
- グリベンクラミドは日本での販売承認が全件取消されており、すぐに入手可能な製剤もありません。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と確認（安全性スクリーニングのため必須）
- 詳細な作用機序（MOA）データの補充
- 予測疾患（特にオプシスモ異形成症）に対する機序的仮説の構築と前臨床研究
- 日本での製剤入手性と投与経路の適合性の確認
## 免責事項

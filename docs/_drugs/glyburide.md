# グリベンクラミド：2型糖尿病から Opsismodysplasia へ

## 一言要約

グリベンクラミド (Glyburide) は膵β細胞の K-ATP チャネルを遮断してインスリン分泌を促す経口血糖降下薬で、日本ではインスリン非依存型糖尿病の治療に使われています。
TxGNN モデルは希少骨系統疾患の **Opsismodysplasia** に有効である可能性を予測していますが、現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データは取得できていません。ただし、既知の薬理から、グリベンクラミドは膵臓の K-ATP チャネル (SUR1/Kir6.2) を遮断してインスリン分泌を促す薬剤と整理できます。

Opsismodysplasia は *INPPL1* 遺伝子に関連する骨格異形成症です。K-ATP チャネル遮断との機序的な関連は、現時点で確認できていません。

したがって、97.24% という高スコアは、知識グラフ上の関連性に基づく統計的な予測にすぎず、機序面の裏付けはありません。この予測は仮説の段階にとどまり、妥当性を示す根拠は今のところありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
Opsismodysplasia に対する臨床試験も文献もなく、機序的な関連も確認できないため、L5（モデル予測のみ）にとどまります。日本の添付文書に基づく安全性情報も未取得のため、次の段階には進めません。

なお、上位 10 件の予測適応症はいずれも L5 で、臨床試験の裏付けはありません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。安全性スクリーニングに進むための必須条件です。
- DrugBank API による作用機序 (MOA) データの取得。
- K-ATP チャネル遮断と *INPPL1* 関連の病態との機序的関連の検証。まず前臨床データや文献を調査します。
- Opsismodysplasia に関する臨床試験・文献の再検索。

*本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床的な検証を経たものではありません。*

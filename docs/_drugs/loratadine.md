# ロラタジン：アレルギー性鼻炎からアレルギー性蕁麻疹へ

## 一言要約

ロラタジンは H1 受容体拮抗薬（抗アレルギー薬）で、元々アレルギー性鼻炎の治療に使用されていました。
TxGNN モデルは**アレルギー性蕁麻疹 (Allergic Urticaria)** に有効である可能性を予測しており、現在 **1 件の臨床試験**（市販後調査）と **17 編の文献**（主にレビュー）がこの方向性を支持しています。

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。ただし既知の薬理情報によると、ロラタジンは末梢 H1 受容体に選択的に作用する第二世代の抗ヒスタミン薬です。ヒスタミンによる膨疹・紅斑・かゆみを抑えるため、アレルギー性鼻炎で有効性が確認されています。

アレルギー性鼻炎とアレルギー性蕁麻疹は、どちらもヒスタミンが主要な介在物質となるアレルギー性疾患です。蕁麻疹ではヒスタミン放出が膨疹の中心的な原因であり、H1 拮抗薬は慢性特発性蕁麻疹の標準治療の柱とされています。このため、既存適応症と同じ作用経路が新規適応症にも当てはまり、機序的に適用可能と考えられます。

## 安全性に関する考慮事項

- **薬物相互作用**：100 件の相互作用情報が確認されています。主なものは以下のとおりです。
  - 中等度：グリセロールフェニル酪酸、トログリタゾン
  - 軽度：クラリスロマイシン、ミコナゾール
  - その他、プロトンポンプ阻害薬（オメプラゾール、ランソプラゾール、パントプラゾール）、メトホルミン、モルヒネなどで相互作用が報告されていますが、重要度は未確定です。
- **知識グラフ上の禁忌関連疾患**：高血圧、肝不全・肝疾患、腎疾患・腎機能障害、糖尿病・糖尿病性ケトアシドーシス、前立腺肥大症、冠動脈疾患・動脈硬化、閉塞隅角緑内障、甲状腺機能亢進症（バセドウ病）などが挙げられています。これは知識グラフ上の関連であり、添付文書の記載ではありません。

警告・禁忌の添付文書情報は取得できていないため、添付文書を確認してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- H1 拮抗による機序は蕁麻疹の病態と整合し、多数のレビュー文献が抗ヒスタミン薬の有効性を支持しています。一方、ロラタジンに特化した蕁麻疹の RCT や臨床試験はなく、エビデンスレベルは L3 にとどまります。
- 日本の販売承認はすべて取消のため、実用化には再承認や供給体制の確認が必要です。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを実施する（必須）
- 詳細な作用機序データ（MOA）を DrugBank から取得する
- 蕁麻疹を対象としたロラタジンの比較試験や、メタ解析の確認
- 日本での販売状況と再承認の要否の確認
- 糖尿病治療薬や肝腎機能障害のある患者など、特定集団の安全性モニタリング計画の策定

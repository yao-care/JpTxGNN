# ロラタジン：アレルギー性鼻炎からアレルギー性蕁麻疹へ

## 一言要約

ロラタジンは第二世代の抗ヒスタミン薬（H1受容体拮抗薬）で、日本ではアレルギー性鼻炎の治療に使われています。
TxGNN モデルは**アレルギー性蕁麻疹 (Allergic Urticaria)** に有効である可能性を予測しており、**3 件の臨床試験**と **19 編の文献**が関連情報として挙がっています。
ただし、ロラタジン自体を蕁麻疹で検証した試験は少なく、エビデンスの多くは同系統薬（デスロラタジンなど）や総説です。

## この予測が妥当である理由

ロラタジンは末梢性 H1 受容体の逆作動薬で、ヒスタミンによる膨疹、紅斑、かゆみを抑えます。詳細な作用機序データは現在ありませんが、この作用はアレルギー性蕁麻疹の中心的な病態経路と一致します。

アレルギー性鼻炎と蕁麻疹はどちらもヒスタミンが主な症状メディエーターです。第二世代抗ヒスタミン薬はこの両疾患を対象に評価されてきました。文献でも、ロラタジンは「アレルギー性鼻炎と慢性蕁麻疹に有益」とされています。したがって、鼻炎から蕁麻疹への拡張は機序の面で無理がありません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 作用機序が病態に合致し、ロラタジンを含む第二世代抗ヒスタミン薬は蕁麻疹で広く評価されています。
- 一方で、ロラタジン自体を蕁麻疹で検証した直接的な RCT はなく、エビデンスは総説と同系統薬の試験が中心です。
- 安全性の一次情報（添付文書）も未確認のため、条件付きで進めます。

**進める場合に必要なもの：**
- PMDA の添付文書から、警告・禁忌・相互作用を取得して確認する（現時点で最優先）
- 添付文書で承認適応症を確認する。蕁麻疹がすでに承認範囲に含まれている可能性もある
- DrugBank から詳細な作用機序データを取得する
- ロラタジン自体を蕁麻疹で評価した RCT やメタ解析を追加検索する
- 関連予測として、寒冷蕁麻疹 (Cold Urticaria、スコア 96.2%、L2) も同じ機序で並行して評価できる
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# アセトアミノフェン：鎮痛薬・解熱薬から片頭痛（脳幹性前兆を伴う片頭痛）へ

## 一言要約

アセトアミノフェンは、元々鎮痛薬・解熱薬として使用されてきた薬です。
TxGNN モデルは**脳幹性前兆を伴う片頭痛 (Migraine with Brainstem Aura)** に有効である可能性を予測していますが、臨床試験の登録はなく、関連文献 20 編はほぼすべてが総説・症例報告で、この亜型に特異的な根拠はありません。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 鎮痛薬、解熱薬 |
| 予測新規適応症 | 脳幹性前兆を伴う片頭痛 (Migraine with Brainstem Aura) |
| TxGNN 予測スコア | 99.15% |
| エビデンスレベル | L4（総説・機序的な根拠のみ。完了した RCT なし） |
| 日本市販状況 | 現在有効な承認なし（失効・取消のみ） |
| 承認番号数 | 20 件（すべて失効・取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アセトアミノフェンは中枢性の COX 阻害と、下行性セロトニン系・カンナビノイド系の疼痛抑制経路の調節を介して作用すると考えられています。これにより、片頭痛の痛みを和らげる可能性があります。

既存適応症（鎮痛・解熱）と片頭痛は、いずれも「痛みの緩和」という点でつながります。実際、複数の総説でアセトアミノフェンは片頭痛の急性期治療や妊娠中の頭痛の第一選択の対症療法として言及されています。

ただし、これらは片頭痛全般の対症療法としての位置づけです。脳幹性前兆を伴う片頭痛という亜型に特化した根拠は見つかっておらず、効果は痛みの軽減に限られる点に注意が必要です。

## 安全性に関する考慮事項

- **禁忌に関する知識グラフ情報**：知識グラフ上では、肝不全、肝疾患、胆嚢疾患、肝硬変、肝性脳症、肝性昏睡が禁忌関連疾患として示されています（添付文書の記載ではありません）。
- **薬物相互作用**：100 件の相互作用情報があります。主なものは次のとおりです。
  - 中等度：活性炭、グリセロールフェニル酪酸、ナルトレキソン
  - 軽度：アトロピン、シメチジン、ラニチジン、メトクロプラミド、スコポラミンなどの抗コリン薬
  - 不明：ビタミン A、カルシトリオール

添付文書の警告・禁忌の詳細は、本レポート作成時点では確認できていません。詳しくは添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 片頭痛全般の対症療法としての使用は総説で支持されていますが、脳幹性前兆を伴う片頭痛に特異的な臨床試験や文献はありません。
- 日本では現在有効な承認がなく、添付文書の安全性情報も未確認です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現状、安全性評価が進められない最重要の不足データ）
- DrugBank からの作用機序（MOA）データの補充
- 脳幹性前兆を伴う片頭痛を対象とした臨床データの収集
- 日本での販売・承認状況の再確認

# アセトアミノフェン：解熱鎮痛から脳幹性前兆を伴う片頭痛へ

## 一言要約

アセトアミノフェンは世界的に最も広く使用されている解熱鎮痛薬の一つで、一般的な頭痛・発熱・疼痛の標準的な管理薬として確立されています。TxGNN モデルは**脳幹性前兆を伴う片頭痛 (migraine with brainstem aura)** に有効である可能性を予測しており、現在 **0 件の専用臨床試験**と **20 編の関連文献**がこの方向性を支持しています。

## この予測が妥当である理由

現時点では DrugBank からの詳細な作用機序データ（MOA）は取得できていません。既存の薬理学的知見によれば、アセトアミノフェンは中枢前列腺素合成の選択的抑制（COX-3 経路）および脊髄・脳幹レベルの下行血清素抑制疼痛通路の調節を介して鎮痛作用を発揮します。この中枢性機序は三叉神経血管系の疼痛シグナル伝達を減弱させ、偏頭痛急性期の疼痛緩和に寄与すると考えられています。

「脳幹性前兆を伴う片頭痛」は国際頭痛分類（ICHD-3）第 1.2.2 項に分類される偏頭痛の特定亜型であり、脳幹由来の前兆症状（構音障害、眩暈、耳鳴、複視、運動失調など）を伴うことを特徴とします。一般的な偏頭痛と同じ三叉神経血管系の活性化・皮質拡延性抑制が病態の中核をなすため、アセトアミノフェンの中枢性鎮痛機序はこの亜型にも機序的に適用可能と考えられます。

実際、アセトアミノフェンは国際的な偏頭痛治療ガイドラインで急性期の一線薬（特に軽〜中等度発作）として推奨されており、妊娠期偏頭痛では安全性の観点から唯一の第一選択薬とされています（PMID 30470274, 39493026）。一方で「脳幹性前兆を伴う片頭痛」に特化した RCT は現時点で確認されておらず、現行のエビデンスは一般的偏頭痛治療からの外挿に依拠しています。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
アセトアミノフェンは一般的な偏頭痛急性期治療における有効性が複数の RCT および系統的レビューで実証されており（L3）、脳幹性前兆を伴う片頭痛は片頭痛の特定亜型として同一の三叉神経血管系病態を共有することから機序的外挿は合理的と判断されます。ただし当該亜型に特化した直接的エビデンスが存在しないため、ガードレール付きで進めることを推奨します。

**進める場合に必要なもの：**
- 脳幹性前兆を伴う片頭痛に特化した RCT の実施（あるいは既存偏頭痛 RCT での亜型別サブグループ解析）
- 詳細な作用機序データ（MOA）の取得（DrugBank API 照会）
- PMDA 添付文書の取得による日本市場での安全性・警告・禁忌情報の確認（Blocking データギャップ：DG001）
- 日本でのアセトアミノフェン承認状況の再調査（グローバルな普及度を考慮すると PMDA 検索結果の再確認が必要）

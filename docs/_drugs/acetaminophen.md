# アセトアミノフェン：鎮痛・解熱から脳幹性前兆を伴う片頭痛へ

## 一言要約

アセトアミノフェンは日本で鎮痛薬・解熱薬として広く市販されています。
TxGNN モデルは**脳幹性前兆を伴う片頭痛 (Migraine with Brainstem Aura)** に有効である可能性を予測しています。関連する臨床試験の登録はなく、**20 編の文献**は主に片頭痛全般を扱っており、この亜型に直接当てはまる研究は確認できていません。

## この予測が妥当である理由

現在、詳細な作用機序データ (DrugBank MOA) はありません。エビデンスパックの機序評価によると、アセトアミノフェンは COX 阻害と下行性セロトニン経路の調節を介して中枢性に鎮痛作用を示すと考えられており、片頭痛の痛みに関連しうる機序です。

既存適応症である鎮痛・解熱と、片頭痛の急性期の痛みの緩和は、機序的につながりがあります。実際に、片頭痛の急性期治療評価（米国頭痛学会）や妊娠中の頭痛管理の文献でも、アセトアミノフェンは第一選択の対症療法として言及されています。

ただし、これらの根拠は片頭痛全般に関するものです。脳幹性前兆を伴う片頭痛という亜型に特化した検討はなく、この点がこの予測の最大の限界です。

## 結論と次のステップ

**決定：Hold**

**理由：**
文献は片頭痛全般が中心で、脳幹性前兆を伴う片頭痛に直接当てはまる臨床試験も文献もなく、根拠はモデル予測と一般的な機序に依存しています。既存適応症の鎮痛・解熱とは近いものの、亜型特異的な有効性は未確認で、安全性データも未取得のため、現時点では進めるべきではありません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得する（安全性スクリーニングの前提となるブロッキング項目）
- DrugBank から詳細な作用機序 (MOA) を取得し、機序面の検討を補強する
- 脳幹性前兆を伴う片頭痛の患者を対象とした症例報告や観察研究を探索する
- アセトアミノフェン単剤と配合剤の効果を切り分けて評価する

なお、同じエビデンスパックの中では、坐骨神経障害 (sciatic neuropathy) に対して静注パラセタモールを検証した Phase 4 RCT（NCT02504996、NCT02777320）があり、エビデンスは L2 です。別の候補として優先的に検討する価値があります。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# アンピシリン：抗生物質から喉頭炎へ

## 一言要約

アンピシリンはペニシリン系の広域抗生物質で、日本では注射剤・経口剤・スルバクタム配合剤として承認され、細菌感染症の治療に使われています。
TxGNN モデルは**喉頭炎 (Laryngitis)** に有効である可能性を予測していますが、根拠は間接的です。関連する臨床試験は **1 件**（類縁薬の市販後調査）、文献は **20 編**で、アンピシリン自体の有効性を直接示す研究はありません。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アンピシリンはペニシリン結合タンパク質に結合して細菌の細胞壁合成を阻害する β-ラクタム系抗生物質です。

喉頭炎の多くはウイルス性で、抗菌薬は効きません。細菌が関与するのは、急性喉頭蓋炎や喉頭膿瘍などの一部に限られます。したがって、機序上は細菌性の喉頭感染に限って適用可能と考えられます。

関連する手がかりとして、類縁薬のアモキシシリン/クラブラン酸の日本の小児市販後調査では、喉頭炎が対象疾患の一つに含まれています。ただし、これはアンピシリン自体の根拠ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
喉頭炎の大半はウイルス性であり、アンピシリンが有効なのは細菌性の一部に限られます。得られた根拠は類縁薬の観察研究と症例報告が中心で、アンピシリン自体を検証した研究がありません。加えて、日本の添付文書に基づく安全性評価が未完了です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングに必須）
- 詳細な作用機序データ（DrugBank の MOA）
- 細菌性喉頭感染（喉頭蓋炎、喉頭膿瘍など）に対象を絞った、アンピシリン自体の有効性データ
- 日本の起因菌の薬剤感受性データ（β-ラクタマーゼ産生菌の割合を含む）

なお、同じ予測リストのうち淋菌性尿道炎（L2）、慢性副鼻腔炎（L3）、慢性篩骨洞炎（L3）、細菌性関節炎（L3）は、喉頭炎より根拠が厚く、研究課題（Research Question）として優先度が高い候補です。

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて適用できます。*

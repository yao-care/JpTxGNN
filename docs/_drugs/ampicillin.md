# アンピシリン：細菌感染症から喉頭炎へ

## 一言要約

アンピシリンは細菌の細胞壁合成を阻害するペニシリン系広域スペクトル抗生物質で、様々な細菌感染症の治療に国際的に使用されてきました。
TxGNN モデルは**喉頭炎 (Laryngitis)** への有効性を予測しており（スコア 99.97%）、
現在 **1 件の臨床試験**と **20 編の文献**がこの方向性に関連するエビデンスを提供しています。

## この予測が妥当である理由

アンピシリンはペニシリン結合タンパク質（PBP）に結合し、細菌の細胞壁ペプチドグリカン合成を不可逆的に阻害することで殺菌作用を発揮します。細菌性喉頭炎および関連感染症（急性会厭炎・喉頭膿瘍）の主要な病原体である *Haemophilus influenzae* および A 群β溶血性連鎖球菌（*Streptococcus pyogenes*）に対して直接的な抗菌活性を持ちます。

喉頭炎と細菌感染症適応症の関連性については、上気道粘膜における同様の病態生理学的メカニズムが共通しており、機序的な適用可能性は認められます。同属の aminopenicillin 系薬である amoxicillin/clavulanate（CLAVAMOX）は、日本の小児上気道感染症（咽頭炎・喉頭炎・扁桃炎を含む）の治療において標準的に使用されており、これが間接的エビデンスとして参照できます（NCT01406275）。

ただし、アンピシリン単薬での喉頭炎治療に対する直接的な RCT エビデンスは現在存在しません。現代の臨床環境では β-lactamase 産生菌（*Staphylococcus aureus*・*Bacteroides* 属など）が広く蔓延しており、アンピシリン単薬の有効性は実臨床において限定的と見られます。作用機序に関する詳細データも現時点では未取得であり、より踏み込んだ機序分析が今後の評価課題となります。

## 結論と次のステップ

**決定：Hold**

**理由：**
アンピシリンは喉頭炎の主要な細菌性病原体（*H. influenzae*・A 群連鎖球菌）に対する機序的根拠を持つものの、喉頭炎適応症への直接的な RCT エビデンスが皆無であり（エビデンスレベル L4）、日本において未承認・未上市であること、さらに現代の β-lactamase 産生菌の広がりを考慮するとアンピシリン単薬での有効性は限定的と判断される。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（PMDA 官サイトより PDF を取得・解析）
- DrugBank API による詳細な作用機序（MOA）データの補充
- アンピシリン単薬 vs amoxicillin/clavulanate の喉頭炎・上気道感染症における直接比較エビデンスの収集
- 日本国内における喉頭炎病原体の β-lactamase 産生菌流行率の調査
- 日本での新規承認申請に向けた規制戦略の立案と規制当局との事前相談

# プロパフェノン：抗不整脈薬から躁病（双極性感情障害）へ

## 一言要約

プロパフェノンはクラス1C の抗不整脈薬（ナトリウムチャネル遮断薬）で、日本では心臓の不整脈治療に使われています。
TxGNN モデルは**躁病型の双極性感情障害 (manic bipolar affective disorder)** への有効性を高スコアで予測しました。しかし、臨床試験は **0 件**で、文献 **3 編**はいずれも治療効果を支持せず、むしろ躁状態や精神症状を**誘発**した報告です。

## この予測が妥当かどうか

現在、詳細な作用機序データはありません。既知の情報によると、プロパフェノンはクラス1C のナトリウムチャネル遮断薬で、不整脈での有効性が確立しています。

一方、躁病に対する抗躁作用の機序は確立していません。今回の文献は、プロパフェノンによる躁状態の誘発と、ベンラファキシンとの相互作用による精神病症状を報告しています。1985 年の症例報告は、化学構造が抗うつ薬ブプロピオンに近いため、感情面の副作用が起こりうると指摘しています。つまり、文献が示す方向は治療効果ではなく安全性上のシグナルであり、TxGNN の高スコアは機序的な裏付けを得られていません。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

なお、上記文献からは、プロパフェノンによる躁状態の誘発と、ベンラファキシン併用時の精神病症状という懸念が読み取れます。双極性障害の患者への使用は特に慎重な検討が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
臨床試験がなく、文献も治療効果ではなく躁状態・精神症状の誘発を報告しています。エビデンスは実質的にモデル予測のみ（L5）で、機序的な根拠もないため、この適応症での開発は進めません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。これが未取得のため安全性スクリーニングに進めません
- DrugBank からの作用機序 (MOA) データの取得
- 躁病に対する抗躁作用を示す前臨床データまたは臨床データ

**参考：**同じ予測リストには、より裏付けのある候補があります。カテコラミン誘発多形性心室頻拍 (CPVT) は、RyR2 抑制という機序と観察研究があり (L3)、乳児持続性心室頻拍にも小児の観察報告があります (L3)。これらを優先して検討する方が合理的です。

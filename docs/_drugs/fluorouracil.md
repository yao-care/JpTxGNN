# フルオロウラシル：胃癌などの悪性腫瘍から膣のぶどう状胚芽型横紋筋肉腫へ

## 一言要約

フルオロウラシルは代謝拮抗薬に分類される抗悪性腫瘍薬で、日本では胃癌、結腸・直腸癌、乳癌などの治療に使われています。
TxGNN モデルは**膣のぶどう状胚芽型横紋筋肉腫 (botryoid-type embryonal rhabdomyosarcoma of the vagina)** に有効である可能性を予測しています。
ただし、この予測を裏付ける**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データは登録されていません。既知の情報によると、フルオロウラシルはフルオロピリミジン系の代謝拮抗薬で、幅広い固形がんでの有効性が確立しています。

一般に知られている作用は、チミジル酸合成酵素の阻害と、RNA/DNA への取り込みです。これらにより、増殖の速い腫瘍細胞の DNA 合成が妨げられます。この細胞毒性の考え方は、胚芽型横紋筋肉腫のような急速に増殖する肉腫細胞にも理論上あてはまります。

ただし、この亜型についての臨床的・文献的な裏付けはなく、根拠は TxGNN の予測だけです。既存適応症（主に上皮系の消化器がんなど）と、間葉系由来の横紋筋肉腫との類似性の評価も未実施です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験も文献もなく、モデル予測のみ（L5）です。日本の添付文書に基づく安全性の確認も未完了のため、現時点では次の段階に進めません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。これが安全性スクリーニングの前提条件です。
- 詳細な作用機序（MOA）データの補充
- 横紋筋肉腫（膣・胚芽型）に特化した臨床試験・文献の再検索
- 参考情報：同じ予測リストのうち、一般の「横紋筋肉腫」は L4（文献は古い報告や症例報告のみ）、「肝肉腫」は L3（観察研究あり）で、いずれもこの予測より根拠が多い状況です。優先順位を見直す際の候補になります。
- 既存適応症との類似性評価と投与経路の適合性確認

本レポートは研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的な検証を経て初めて適用できます。

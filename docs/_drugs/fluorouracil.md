# フルオロウラシル：各種固形癌から横紋筋肉腫へ

## 一言要約

フルオロウラシルは代謝拮抗薬タイプの抗悪性腫瘍薬で、元々胃癌、結腸・直腸癌、乳癌など多くの固形癌の治療に使用されてきました。
TxGNN モデルは**胚性横紋筋肉腫（膣のブドウ状型）(botryoid-type embryonal rhabdomyosarcoma of the vagina)** に有効である可能性を予測していますが、この疾患に直接関連する臨床試験や文献はありません。
隣接する**横紋筋肉腫**については、間接的な文献 4 編（古い総説と症例報告が中心）があるのみで、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フルオロウラシルはチミジル酸合成酵素を阻害し、RNA/DNA に取り込まれる代謝拮抗薬であり、増殖の速い腫瘍細胞に作用すると考えられます。

横紋筋肉腫は増殖の速い肉腫であるため、この作用が理論上は有効に働く可能性があります。ただし、標準的な横紋筋肉腫の治療レジメンは 5-FU を中心としていません。したがって、この予測はモデルによる仮説の段階にとどまります。

同じ上位予測群には、横紋筋肉腫の他の亜型（傍髄膜性、肝外胆管、前立腺）や肝肉腫、鎌状赤血球症関連疾患も含まれています。これらもすべて予測のみ、または間接的な支持にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測上位の疾患には直接の臨床試験や文献がなく、エビデンスはモデル予測のみ（L5）です。隣接する横紋筋肉腫でも、支持するのは古い総説と症例報告だけです。さらに、日本での販売承認はすべて取り消されており、添付文書の安全性情報も未取得です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（必須）
- 作用機序（MOA）データの補完
- 横紋筋肉腫に対する 5-FU の前臨床・臨床データの体系的な調査
- 現行の標準レジメン（ビンクリスチン、アクチノマイシン D、シクロホスファミドなど）に対する上乗せ価値の評価
- DPD 欠損症の検査など、特定集団の安全性モニタリング計画
- 日本での販売状況（取り消し後の供給状況）の確認

# フルチカゾン：アレルギー性鼻炎 から 偏頭痛 へ

## 一言要約

フルチカゾンは強力な局所性糖皮質激素（コルチコステロイド）で、アレルギー性鼻炎・喘息などの炎症性疾患に国際的に広く使用されています。TxGNN モデルは**偏頭痛 (migraine disorder)** に有効である可能性を予測していますが、現在 **0 件の臨床試験**と **1 編の文献**（内容は副作用報告）のみが存在し、再利用を支持する直接的なエビデンスは極めて不十分です。

## この予測が妥当である理由

フルチカゾンは合成フルオロ化ステロイド系糖皮質激素で、糖皮質激素受容体（GR）に高親和性で結合します。本データセットには詳細な MOA データが存在しませんが、薬理学的に確立された知識として、フルチカゾンはプロスタグランジン・炎症性サイトカイン・ロイコトリエンなどの炎症性メディエーター産生を複数の経路で強力に抑制します。

偏頭痛の病態には三叉神経血管系の活性化・神経源性炎症・CGRP 放出・硬膜血管の拡張が関与しており、理論的には糖皮質激素の抗炎症作用がこれらの一部を修飾する可能性があります。実際に、急性偏頭痛に対する短期経口コルチコステロイドの補助的使用は臨床でも知られています。

ただし、本データセットの唯一の関連文献（PMID 18681087）は、鼻内コルチコステロイド使用時の**神経精神副作用**（頭痛・うつ・不安等）を WHO 薬物監視データから検討したレビューであり、偏頭痛の治療効果を示すものではありません。機序的根拠は仮説的な段階に留まり、現時点では支持するエビデンスがほぼ皆無です。

## 結論と次のステップ

**決定：Hold**

**理由：**
偏頭痛に対するフルチカゾンの有効性を支持する臨床試験が皆無であり、唯一の関連文献はむしろ神経精神系副作用（頭痛を含む）を示す報告です。機序的連関は仮説的な段階に留まり、現時点での再利用開発には根拠が不十分です。

**進める場合に必要なもの：**
- 前臨床研究（偏頭痛動物モデルにおける糖皮質激素の効果検証）
- 三叉神経炎症に対する局所コルチコステロイドの機序研究（in vitro/in vivo）
- 詳細な MOA データの収集（DrugBank API 照会）
- 安全性情報（添付文書警語・禁忌）の取得（PMDA より仿単 PDF を解析）
- 日本国内未承認であることを踏まえた規制戦略の整理

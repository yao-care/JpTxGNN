# フルチカゾン：アレルギー性鼻炎・喘息用ステロイドから片頭痛へ

## 一言要約

フルチカゾンは副腎皮質ステロイド（グルココルチコイド）で、日本では点鼻液や吸入剤として使われてきました（製品名からの推定。承認適応症の文言は本レポート用データに含まれていません）。
TxGNN モデルは**片頭痛 (Migraine Disorder)** に有効である可能性を予測していますが、関連する臨床試験はなく、紐づく文献は 1 編のみです。しかもその文献は有効性を支持せず、**神経精神系の有害事象**を扱ったレビューです。現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フルチカゾンは抗炎症作用をもつグルココルチコイドです。アレルギー性炎症に対する局所ステロイドとして広く使われています。

片頭痛では神経原性炎症の関与が提唱されており、グルココルチコイドの抗炎症作用が理論上は関わり得ます。ただし、これは推測の域を出ません。唯一紐づく文献は、点鼻ステロイドの神経精神系の有害事象をまとめたものです。片頭痛への有効性を示すものではなく、予測の根拠は実質的に TxGNN スコアだけです。

## 結論と次のステップ

**決定：Hold**

**理由：**
片頭痛については、臨床試験がなく、紐づく文献も有効性を支持していません。機序的な裏付けも推測にとどまるため、モデル予測のみの L5 段階です。

**進める場合に必要なもの：**
- 片頭痛に対するフルチカゾンの有効性を直接検討した臨床・前臨床研究
- 詳細な薬物作用機序データ（MOA）と、片頭痛病態との機序的な関連の検証
- 添付文書の警告・禁忌の確認（安全性スクリーニングの前提）
- 日本の承認がすべて整理済みである点を踏まえた、製剤・投与経路の再検討

**参考（他の予測候補）：** 同じ予測リストの「眼疾患 (eye disease)」には、スコア 98.46%、エビデンスレベル L2 の根拠があります。点鼻フルチカゾンがアレルギー性鼻炎に伴う眼症状を改善することを示す、第 3 相を含む複数の試験と文献があります。ただし、この効果は原発性の眼疾患ではなくアレルギー性鼻炎での知見であり、間接的です。白内障・緑内障などの眼の安全性シグナルにも注意が必要です。再利用の検討は、片頭痛よりこちらの方向を優先する方が現実的です。

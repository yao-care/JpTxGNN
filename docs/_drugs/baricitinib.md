# バリシチニブ：関節リウマチから先天性肢・眼発達異常症候群（予測）へ

## 一言要約

バリシチニブは JAK1/JAK2 を選択的に阻害する薬で、元々は関節リウマチの治療に使用されていました。
TxGNN モデルは **コロボーマ性小眼球症-根性肢異形成症候群 (colobomatous microphthalmia-rhizomelic dysplasia syndrome)** に有効である可能性を予測していますが、関連する臨床試験や文献は **現時点で 0 件** で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 関節リウマチ |
| 予測新規適応症 | コロボーマ性小眼球症-根性肢異形成症候群 (colobomatous microphthalmia-rhizomelic dysplasia syndrome) |
| TxGNN 予測スコア | 99.94% |

| 承認番号数 | 3 件（すべて取消） |
| 推奨決定 | Hold |

なお、2 番目の予測候補は **合指趾症を伴う短指症症候群 (brachydactyly-syndactyly syndrome)**（スコア 99.94%）で、こちらも L5・Hold です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、バリシチニブは JAK1/JAK2 阻害薬であり、関節リウマチでの有効性が知られています。ただし、今回まとめたデータでは、この薬の作用経路と予測された希少な発生異常症候群を結ぶ根拠は確認できていません。

関節リウマチは自己免疫性の炎症性疾患です。一方、予測された疾患は先天性の発生異常で、病態の性質が大きく異なります。既存適応症との類似性は評価できていません。

TxGNN のスコアは高い値ですが、これは計算上の予測にすぎません。臨床試験や文献による裏付けはなく、妥当性は現時点で示されていません。

- **薬物相互作用**（DDI 照会で 100 件を確認。主なものを記載）：
  - **Major**：ヒドロコルチゾン、トリアムシノロン（眼科用を含む）、ベタメタゾン、ブデソニド、デキサメタゾン、プレドニゾロン、プレドニゾン（いずれもコルチコステロイド）、デフェリプロン、イブリツモマブ チウキセタン、イオベングアン (I-131)、トシツモマブ (I-131)
  - **Moderate**：モルヒネ（リポソーム製剤を含む）、アセチルサリチル酸、ニチシノン、アヘン
  - **Minor**：酢酸亜鉛、グルコン酸亜鉛、硫酸亜鉛

その他の警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測はモデルのみに基づき、臨床試験・文献がなく（L5）、作用機序と疾患を結ぶ根拠もありません。日本では承認がすべて取消となっており、添付文書の安全性情報も未取得のため、現時点で次の段階には進めません。

**進める場合に必要なもの：**
- 添付文書（PMDA）から警告・禁忌情報を取得する
- DrugBank から作用機序（MOA）データを取得し、JAK-STAT 経路と予測疾患の関連を検討する
- 予測疾患の病態に関する前臨床・機序研究、症例報告を調査する
- 投与経路の適合性（経口剤での適用可否）を確認する
- 日本での承認取消の経緯と現在の供給状況を確認する

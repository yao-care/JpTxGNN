# ミノサイクリン：細菌感染症・ざ瘡から点状表層角結膜炎へ

## 一言要約

ミノサイクリンはテトラサイクリン系抗菌薬で、元々は尿路感染症、気管支炎、ざ瘡（にきび）、歯周炎、淋病などの細菌感染症の治療に使用されてきました。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測しています（スコア 99.63%）。
ただし、現時点で裏付けとなる**臨床試験・文献はなく**、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 尿路感染症、気管支炎、ざ瘡、歯周炎、淋病、咽頭炎など（日本の承認適応症の記載はなし） |
| 予測新規適応症 | 点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis) |

| 承認番号数 | 3 件（有効 0 件、整理済み 3 件） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ミノサイクリンはテトラサイクリン系抗菌薬で、細菌感染症やざ瘡での使用実績があります。

ミノサイクリンには抗炎症作用とマトリックスメタロプロテアーゼ (MMP) 阻害作用があることが知られており、理論上は眼表面の炎症や角膜上皮の障害を抑える可能性があります。ざ瘡や歯周炎のように炎症が関わる疾患で使われてきた点も、この仮説と整合します。

ただし、これは理論的な推測にとどまります。この予測を支持する臨床データや文献は、今回まとめたデータには含まれていません。参考として、第 2 位の予測は**暴露性角膜炎 (Exposure Keratitis)**（スコア 99.20%）で、同様に MMP 阻害と抗炎症作用による角膜上皮障害の軽減が理論上の根拠ですが、こちらも臨床・文献エビデンスはありません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではありません）：腎疾患、膿尿管症、肝疾患、胆嚢疾患、クロストリジウム・ディフィシル腸炎、周産期壊死性腸炎、偽脳腫瘍、頭蓋内圧亢進症、食道運動障害
- **薬物相互作用**（合計 100 件のうち一部）：
  - 重大 (Major)：イソトレチノイン、アシトレチン（頭蓋内圧亢進のリスクに注意が必要）
  - 中等度 (Moderate)：エチニルエストラジオール、アモキシシリン、アンピシリン、クエン酸ナトリウム、カルシウム製剤、ビスマス製剤、バルサラジド、カンナビジオールなど
  - 軽度 (Minor)：アセタゾラミド、ヒドロクロロチアジド、アミロライド、ブメタニドなど

警告・禁忌の詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験も文献もなく、エビデンスはモデル予測のみ（L5）です。日本では承認がすべて整理済みで現在市販されておらず、添付文書の安全性情報も未確認のため、現段階で開発を進める根拠は不十分です。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌情報を取得し、安全性を確認する
- 詳細な作用機序データ (MOA) を DrugBank などから補充する
- 点状表層角結膜炎および暴露性角膜炎に対する前臨床・臨床研究、文献を調査する
- 眼科用途に必要な投与経路・剤形（点眼剤など）の適合性を評価する
- 日本での承認整理の経緯と、再導入の可能性を確認する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

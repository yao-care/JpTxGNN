# ミノサイクリン：テトラサイクリン系抗菌薬から点状表層角結膜炎へ

## 一言要約

ミノサイクリンはテトラサイクリン系の薬で、日本では「ミノマイシン」として顆粒・錠剤・カプセルが市販されています。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測しています。
ただし、現時点で支持する臨床試験・文献は **0 件**で、モデル予測のみの段階 (L5) です。

## この予測が妥当である理由

詳細な作用機序データは現在ありません。ミノサイクリンはテトラサイクリン系に属し、この系統はマトリックスメタロプロテイナーゼ (MMP) の阻害や炎症性サイトカインの抑制作用を持つとされます。こうした抗炎症作用が、眼表面の炎症や角結膜上皮の障害を和らげる可能性があります。

ただし、この関連づけは推論にとどまり、入力データ内に裏づけとなる試験や文献はありません。既存適応症との類似性の評価も未実施です。

同じ機序的な理由で、TxGNN は**露出性角膜炎 (Exposure Keratitis)**（スコア 99.20%）も予測しています。こちらも臨床試験・文献は 0 件で、L5 です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、裏づけとなる臨床試験・文献がなく、エビデンスはモデル予測のみです。安全性情報も未確認のため、次の段階に進める根拠が不足しています。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌情報を取得する（安全性スクリーニングの前提条件）
- DrugBank から作用機序データを取得し、機序的な関連づけを検証する
- 点状表層角結膜炎・露出性角膜炎に関する臨床試験と文献を調査する
- 眼疾患に必要な投与経路（点眼など）と、既存剤形（経口）との適合性を評価する

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床での検証を経て初めて応用できます。*
## 免責事項

# タクロリムス：免疫抑制薬としての既存適応症から脂漏性皮膚炎へ

## 一言要約

タクロリムスはカルシニューリン阻害薬で、元々は臓器移植における拒絶反応や自己免疫疾患の治療に使用されていました。
TxGNN モデルは**脂漏性皮膚炎 (Seborrheic Dermatitis)** に有効である可能性を予測しており、現在 **2 件の臨床試験**（うち Phase 3 が 1 件）と **20 編の文献**がこの方向性を支持しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 臓器移植における拒絶反応、移植片対宿主病、重症筋無力症、関節リウマチ、ループス腎炎、活動期潰瘍性大腸炎、多発性筋炎・皮膚筋炎、アトピー性皮膚炎 |
| 予測新規適応症 | 脂漏性皮膚炎 (Seborrheic Dermatitis) |
| TxGNN 予測スコア | 99.26% |
| エビデンスレベル | L1 |
| 日本市販状況 | 現在有効な承認なし（取消済みのみ） |
| 承認番号数 | 20 件（すべて取消済み） |
| 推奨決定 | Proceed with Guardrails |

> エビデンスレベルについて：L1 の基準は「完了した Phase 3 RCT が 2 件以上」ですが、脂漏性皮膚炎の完了済み Phase 3 は 1 件のみです。そのため、厳密に適用すると L2 相当になります。上記の L1 は、今回編纂したデータ上の判定をそのまま記載したものです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、タクロリムスはカルシニューリン阻害薬に分類される免疫抑制薬です。FKBP12 に結合してカルシニューリンを阻害し、NFAT を介した T 細胞の活性化と IL-2 などのサイトカイン産生を抑えます。

脂漏性皮膚炎は、皮脂分泌の多い部位に生じる慢性の炎症性皮膚疾患です。*Malassezia* 属真菌に対する異常な炎症反応が関与すると考えられています。タクロリムスは既にアトピー性皮膚炎（外用）で承認されており、皮膚の T 細胞性炎症を抑える作用が確立されています。この点で、脂漏性皮膚炎の炎症成分にも機序的に適用できると考えられます。

ただし、*Malassezia* に関連する炎症への作用は、もっともらしいものの確立はされていません。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の関連）**：添付文書の記載ではなく、知識グラフ上の薬物-疾患関係に基づく情報です。高血圧、QT 延長症候群、肝不全、腎疾患、糖尿病・高血糖、てんかん、感染症（単純ヘルペス、帯状疱疹、進行性多巣性白質脳症など）、悪性腫瘍・リンパ腫、後頭葉白質脳症症候群などが挙げられています。主に全身投与での懸念ですが、外用でも感染症や悪性腫瘍に関する注意は必要です。
- **薬物相互作用**：100 件が検出されています。主要（Major）なものは、アムホテリシン B、ロペラミド、メサラジン、オメプラゾール、バルサラジドです。中等度（Moderate）のものには、ファモチジン、ラベプラゾール、各種ステロイド（ヒドロコルチゾン、デキサメタゾンなど）、メトホルミン、アプレピタントなどがあります。外用では全身曝露が小さいため影響は限定的と考えられますが、確認が必要です。
- **関連する文献上の注意**：外用カルシニューリン阻害薬のがんリスクを評価したメタ解析（PMID: 36370744）があります。また、外用タクロリムス使用中の飲酒による皮膚刺激も報告されています。

警告・禁忌の添付文書情報は今回のデータに含まれていないため、添付文書で確認してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 脂漏性皮膚炎に対し、完了済みの Phase 3 試験（n=120）と Phase 4 試験（n=104）があります。維持療法を検討した文献や機序面の裏付けもあり、エビデンスは一定程度あります。
- 一方で、Phase 3 は 1 件のみで、結果の詳細は今回のデータに含まれていません。日本では脂漏性皮膚炎の適応がなく、現在有効な承認もありません。

**進める場合に必要なもの：**
- 作用機序データ（MOA）の補充
- 添付文書（PMDA）の警告・禁忌情報の取得と、安全性スクリーニングの実施
- NCT02004860 などの試験結果（有効性・再発抑制効果）の精査
- 日本での販売状況（承認取消の経緯と現在の供給）の確認
- 外用での長期使用に伴う感染症・悪性腫瘍リスクのモニタリング計画
- 外用剤形（軟膏）に限定した投与経路の検討

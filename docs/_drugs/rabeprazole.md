# ラベプラゾール：胃潰瘍・逆流性食道炎から Smouldering systemic mastocytosis へ

## 一言要約

ラベプラゾールはプロトンポンプ阻害薬で、元々は胃潰瘍、十二指腸潰瘍、逆流性食道炎などの胃酸関連疾患の治療に使用されていました。
TxGNN モデルは**くすぶり型全身性肥満細胞症 (Smouldering systemic mastocytosis)** に有効である可能性を予測していますが、この疾患に関する臨床試験・文献は**ともに 0 件**で、モデル予測のみの段階です。
なお、予測上位 10 件のうち、実際にエビデンスが蓄積しているのは、すでに承認されている胃酸関連疾患（胃潰瘍など）に近い項目です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ラベプラゾールは胃の壁細胞にある H+/K+ ATPase（プロトンポンプ）を阻害し、胃酸分泌を抑える薬です。

肥満細胞症では、肥満細胞から放出されるヒスタミンなどの影響で胃酸分泌が過剰になることがあります。そのため、ラベプラゾールは酸関連の症状（胃痛、逆流、潰瘍など）を和らげる可能性があります。

ただし、ラベプラゾールには肥満細胞の腫瘍性増殖そのものに作用する機序は知られていません。高い TxGNN スコアは予測にとどまり、疾患そのものの治療というより、対症的な支持療法としての位置づけにとどまると考えられます。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書ではなく、TxGNN の知識グラフ由来）：肝疾患、胆嚢疾患、骨粗鬆症、閉経後骨粗鬆症、骨折
- **薬物相互作用**（100 件を検出。主なもの）：
  - Major：アカラブルチニブ、アタザナビル
  - Moderate：アミカシン、アムホテリシン B、アプレピタント、アパルタミド、ボスチニブなど
  - Minor：アセチルサリチル酸、アキシチニブ

添付文書の警告・禁忌については、今回のデータでは確認できていないため、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 第 1 位の予測（くすぶり型全身性肥満細胞症）には臨床試験も文献もなく、エビデンスレベルは L5 です。また疾患修飾的な機序も知られていません。
- 日本での承認はすべて取消状態であり、現時点で市販されている製品はありません。

**参考（他の予測候補）：**
- 胃十二指腸炎、胃潰瘍は RCT を含むエビデンスがあり（L2）、「Proceed with Guardrails」ですが、胃潰瘍は既存適応症と重なり、真の再利用ではありません。
- 活動性消化性潰瘍も既存適応症に近く、L3 です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得（現状は未取得で、安全性審査に進めない）
- 作用機序（MOA）データの補充（DrugBank など）
- 肥満細胞症における酸関連症状へのラベプラゾール使用に関する臨床データの調査
- 現行の販売状況の再確認（取消のみの理由の確認）

# ラベプラゾール：消化性潰瘍・逆流性食道炎からくすぶり型全身性肥満細胞症へ

## 一言要約

ラベプラゾールはプロトンポンプ阻害薬（PPI）で、日本では胃潰瘍、十二指腸潰瘍、逆流性食道炎などの治療に使われています。
TxGNN モデルは**くすぶり型全身性肥満細胞症 (Smouldering systemic mastocytosis)** に有効である可能性を予測しました。
ただし、この予測を裏付ける**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データは登録されていません。既知の情報では、ラベプラゾールは胃壁細胞の H+/K+ ATPase（プロトンポンプ）を不可逆的に阻害し、胃酸分泌を強く抑える PPI です。消化性潰瘍や逆流性食道炎での有効性は確立されています。

肥満細胞症では、肥満細胞から放出されるヒスタミンが胃酸分泌を過剰にし、胃部症状を起こすことがあります。そのため、ラベプラゾールが症状の緩和に役立つ可能性は考えられます。

ただし、これは酸関連症状への対症的な効果にとどまります。疾患そのものを修飾する機序は見当たらず、この関連付けは TxGNN の予測だけに基づいています。既存適応症との類似性の評価も未完了です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高い（99.44%）ものの、臨床試験も文献もなく、根拠はモデル予測だけです。
- 機序的にも、酸関連症状の緩和にとどまり、疾患修飾効果は期待できません。
- 今回のデータに含まれる他の予測候補（活動性消化性潰瘍、胃潰瘍）は L1 でエビデンスが豊富です。ただし、これらは既存の適応症の範囲であり、新規の再利用候補ではありません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌情報を取得すること（現在の最重要の欠落データで、安全性スクリーニングに進めない原因です）
- DrugBank から詳細な作用機序（MOA）データを取得すること
- 肥満細胞症におけるラベプラゾールおよび PPI の臨床試験と文献を再調査すること
- 既存適応症との類似性評価と投与経路の適合性評価を完了すること

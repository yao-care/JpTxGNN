# インドメタシン：関節リウマチ・痛風発作から短指症・合指症症候群へ

## 一言要約

インドメタシンは COX 阻害作用を持つ非ステロイド性抗炎症薬で、日本では関節リウマチや痛風発作などに使われています。
TxGNN モデルは**短指症・合指症症候群 (Brachydactyly-Syndactyly Syndrome)** に有効である可能性を予測しています。ただし、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。
一方、予測リスト内の若年性特発性関節炎 (JIA) には 20 編の文献があり、こちらのほうが現実的な検討対象です。

## この予測が妥当かどうか

現在、詳細な作用機序データ (MOA) はデータベース上にありません。承認情報によると、インドメタシンは鎮痛・抗炎症・解熱作用を持つ COX-1/COX-2 阻害薬で、プロスタグランジン合成を抑えます。関節リウマチや痛風発作での有効性は確立されています。

しかし、短指症・合指症症候群は遺伝性の四肢形成異常です。COX 阻害によるプロスタグランジン抑制との機序的な関連は確認できず、この予測は TxGNN のスコアのみに基づいています。スコアは非常に高い (99.97%) ものの、臨床的な裏付けにはなりません。

なお、予測上位 10 件のうち 7 件は遺伝性の骨格・発生異常や希少疾患 (WHIM 症候群、ブラキオルミアなど) です。いずれも機序的な関連は示されていません。抗炎症作用と関連が見込めるのは、JIA とその亜型、リウマチ結節症に限られます。

## 結論と次のステップ

**決定：Hold**

**理由：**
短指症・合指症症候群については、臨床試験も文献もなく、機序的な関連も確認できません。TxGNN のスコアだけでは進める根拠にならないため、保留とします。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提となるため必須）
- DrugBank からの作用機序 (MOA) データの補完
- 予測疾患の病態と COX/プロスタグランジン経路との関連を裏付ける前臨床・機序研究
- 優先度の高い代替候補として、若年性特発性関節炎 (JIA) の検討。現行の標準治療との比較や小児での安全性の整理から始めるのが現実的です。

本レポートの内容は研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経てから適用する必要があります。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

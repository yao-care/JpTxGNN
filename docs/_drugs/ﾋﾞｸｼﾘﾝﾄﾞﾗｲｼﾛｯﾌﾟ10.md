# ビクシリンドライシロップ10%：評価データ不足により老薬新用評価不可

## 一言要約

ビクシリンドライシロップ10%（半角カタカナ：ﾋﾞｸｼﾘﾝﾄﾞﾗｲｼﾛｯﾌﾟ10%）は、日本市場で未上市であり、PMDA データベースでの照会結果も 0 件でした。DrugBank 照会では 1 件がヒットしたものの、有効な DrugBank ID が取得できなかったため、TxGNN モデルによる新規適応症予測が実行されておらず、**現時点では老薬新用評価を完了できません**。

## 評価不可の理由

今回の Evidence Pack は複数の重大なデータ欠如により、老薬新用の標準評価フローを完了できませんでした。

**DrugBank ID 未確定**：DrugBank への照会では 1 件がヒットしていますが、`drugbank_id` が null のまま確定していません。DrugBank ID がなければ TxGNN モデルへの入力ができず、新規適応症予測そのものが実行されません。`predicted_indications` が空配列であることがこれを示しています。

**PMDA 登録なし**：2026-03-26 時点での PMDA 照会（クエリ：`ﾋﾞｸｼﾘﾝﾄﾞﾗｲｼﾛｯﾌﾟ10%`）は 0 件でした。薬品名が半角カタカナ表記であるため、全角変換（ビクシリンドライシロップ）や INN（国際一般名）での再照会が必要な可能性があります。なお、「ビクシリン」はアンピシリン（Ampicillin）の日本国内ブランド名である可能性が高く、INN での再クエリを推奨します。

**作用機序データなし**：MOA が `[Data Gap]` のため、既存適応症と予測適応症の機序的関連性を分析できません（Data Gap DG002、重要度：High）。

**安全性データなし**：警告・禁忌ともに `[Data Gap]` であり、安全性初期評価（S1 スクリーニング）が未実施です（Data Gap DG001、重要度：Blocking）。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が未確定で TxGNN 予測が実行されておらず、安全性評価に必要な添付文書データも欠如しているため、老薬新用候補としての評価を開始できる段階にありません。

**進める場合に必要なもの：**

- **薬品名の正規化**：半角カタカナ `ﾋﾞｸｼﾘﾝﾄﾞﾗｲｼﾛｯﾌﾟ10%` を全角（ビクシリンドライシロップ10%）または INN（例：Ampicillin）に変換して PMDA・DrugBank を再照会する
- **DrugBank ID の確定**：DrugBank API または DrugBank ウェブサイトで正確な DrugBank ID を取得し、`drugbank_id` フィールドを補完する（DG002 解消）
- **PMDA 添付文書の取得**：PMDA 官ウェブサイトから仿単 PDF をダウンロードし、承認適応症・警告・禁忌・MOA を抽出する（DG001 解消）
- **TxGNN 予測の再実行**：上記 2 点が解消されたのち、TxGNN パイプラインで新規適応症予測を再実行し、Evidence Pack を v5 として更新する

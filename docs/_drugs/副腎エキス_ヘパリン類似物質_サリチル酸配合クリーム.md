## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が未特定のため TxGNN 知識グラフへのマッピングが行われておらず、新規適応症予測が実施できていません。日本での承認実績もなく、安全性データも未取得であるため、現時点では再利用候補としての評価を開始できる状態にありません。

**進める場合に必要なもの：**
- 各有効成分（副腎エキス、ヘパリン類似物質、サリチル酸）ごとの DrugBank ID 個別検索
- PMDA 仿単 PDF の取得と解析（警告・禁忌・既存適応症の補完）
- DrugBank マッピング完了後の TxGNN 予測（KG 予測 → DL 予測の順）
- 日本での承認状況の再確認（製品名・成分名での追加検索）

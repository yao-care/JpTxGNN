# リスペリドン：統合失調症から大うつ病性障害・双極性障害（気分障害）へ

> 注：TxGNN の予測スコア順位で最上位の疾患（家族性水平性注視麻痺・進行性側弯症）には裏付けとなる研究が一切ありません。そのため、本レポートでは臨床エビデンスが最も充実している「気分障害 (major affective disorder)」を主な評価対象としました。

## 一言要約

リスペリドンは非定型抗精神病薬で、元々統合失調症の治療に使用されていました。
TxGNN モデルは**気分障害 (Major affective disorder)** に有効である可能性を予測しており、
現在 **11 件の臨床試験**（うち Phase 3 が 4 件完了）と **20 編の文献**（メタアナリシス 4 編を含む）がこの方向性を支持しています。

|------|------|
| 既存適応症 | 統合失調症 |
| 予測新規適応症 | 気分障害 (Major affective disorder) |
| TxGNN 予測スコア | 99.11% |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、リスペリドンはセロトニン 5-HT2A 受容体とドパミン D2 受容体の拮抗薬です。統合失調症での有効性が証明されており、同じ受容体系は気分調節にも関わるため、機序的に気分障害にも適用可能である可能性があります。

臨床的には、治療抵抗性うつ病で抗うつ薬にリスペリドンを上乗せすると反応が改善することが示されています。また、双極性障害の躁状態・混合状態にも用いられます。Phase 3 の無作為化試験と複数のメタアナリシスがこれを支持しています。

## 安全性に関する考慮事項

- **禁忌（疾患との関連）**：TxGNN の知識グラフ上では、以下の疾患・状態との禁忌関連が示されています。添付文書の記載ではない点に注意してください。
  - 心血管系：起立性低血圧、心筋梗塞、脳血管障害・脳卒中、心伝導障害、心臓突然死
  - 代謝系：糖尿病、糖尿病性ケトアシドーシス、高血糖、高脂血症、肥満
  - 血液系：好中球減少症、無顆粒球症
  - 肝・その他：肝疾患・肝不全、胆嚢疾患、てんかん、乳癌
- **薬物相互作用**：100 件が確認されており、特に注意が必要なものは次のとおりです。
  - **重大 (Major)**：ブプロピオン、モルヒネ
  - **中等度 (Moderate)**：メトホルミン、アカルボース、アログリプチン、カナグリフロジン、アルビグルチド（血糖関連）、アトロピン、ヒヨスチアミン、グリコピロニウム（抗コリン作用）など
- 気分障害での使用では、代謝系の副作用（体重増加、血糖・脂質異常）とプロラクチン上昇に特に注意が必要です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 治療抵抗性うつ病に対する Phase 3 試験が複数あり、メタアナリシスも支持しています。エビデンスレベルは L1 に相当します。ただし日本の承認は現在すべて販売中止で、添付文書の警告・禁忌データも未取得のため、安全性の確認を前提に進める必要があります。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（現状は安全性審査に進めないブロッキング項目）
- 詳細な作用機序データ（DrugBank 等）の補充
- 代謝（体重・血糖・脂質）とプロラクチンのモニタリング計画
- 併用薬（特に血糖降下薬、抗コリン薬、オピオイド）の相互作用管理
- 日本での現行販売品目の確認

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による予測適応症が存在せず、DrugBank ID・MOA・承認情報・安全性データのいずれも取得できていないため、老薬新用評価を進める基礎データが整っていません。

**進める場合に必要なもの：**
- **DrugBank ID の特定**：`アセトアミノフェン`（Acetaminophen / Paracetamol）として DrugBank を再検索し、正式 ID（DB00316 等）を確認
- **MOA データの取得**：DrugBank API から作用機序・薬理分類を抽出
- **PMDA 承認情報の再確認**：半角カナ表記ではなく全角・INN・英語名（Acetaminophen）での再検索を実施
- **TxGNN 予測の実行**：DrugBank ID 確定後にパイプラインを再実行
- **安全性データの取得**：PMDA 添付文書 PDF から警告・禁忌・DDI 情報を抽出（DG001 解消）

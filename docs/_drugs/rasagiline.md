# ラサギリン：パーキンソン病から PLA2G6 関連神経変性症へ

## 一言要約

ラサギリンは不可逆的 MAO-B 阻害薬で、元々パーキンソン病の治療に使用されていました。
TxGNN モデルは **PLA2G6 関連神経変性症 (PLA2G6-associated neurodegeneration)** に有効である可能性を予測しています。
ただし、現時点で関連する臨床試験と文献はなく、**モデル予測のみ**の段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ラサギリンは MAO-B 阻害薬として、脳内ドパミンの分解を抑えてドパミン利用率を高め、パーキンソン病に使用されてきました。神経保護作用も提唱されています。

PLA2G6 関連神経変性症にはパーキンソニズム（PARK14）を呈する病型があります。そのため、パーキンソン病との症候の重なりが、予測の背景にあると考えられます。

ただし、この関連づけは TxGNN の予測のみに基づいています。臨床試験も文献もなく、機序的な妥当性は仮説の段階です。

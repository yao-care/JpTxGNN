# ビルダグリプチン：2型糖尿病から局所性硬直肢症候群へ

## 一言要約

ビルダグリプチンは DPP-4 阻害薬で、元々 2型糖尿病の治療に使用されています。
TxGNN モデルは**局所性硬直肢症候群 (Focal Stiff Limb Syndrome)** に有効である可能性を予測しましたが、この予測を支持する**臨床試験は 0 件、文献も 0 編**です。
現時点ではモデル予測のみで、機序的な裏付けも見つかっていません。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ビルダグリプチンは DPP-4 阻害薬に分類され、DPP-4 を阻害して活性型 GLP-1/GIP を増やし、高血糖時のグルカゴン分泌を抑えることで血糖を下げます。

局所性硬直肢症候群は自己免疫性の神経疾患です。DPP-4 阻害（インクレチン/グルカゴン系）とこの疾患の間に、妥当な機序的関連は確認できませんでした。この予測の根拠は TxGNN のスコアだけです。

スコアは 99.88% と高いものの、実際の研究による裏付けはありません。類似の予測（古典的スティッフパーソン症候群など）も同様です。スティッフパーソン症候群は 1型糖尿病を合併することがありますが、DPP-4 阻害薬が神経疾患を治療する根拠にはなりません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測はモデルのスコアのみに基づいており、臨床試験・文献はなく、機序的な関連も確認できません。エビデンスレベルは L5 で、現段階で検討を進める根拠はありません。

**進める場合に必要なもの：**
- 日本の添付文書（警告・禁忌）の取得。これが未取得のため、安全性スクリーニング（S1）に進めません。
- DrugBank からの作用機序（MOA）データの補完
- 局所性硬直肢症候群と DPP-4/インクレチン経路を結ぶ機序仮説の提示（前臨床データや症例報告など）
- 参考：同じ薬の別の予測候補である **1型糖尿病**（TxGNN スコア 99.37%）には、Phase 2 の RCT や複数の文献があり、エビデンスレベルは L2 です。ただし、ラパマイシン併用試験では明確な β 細胞機能の回復は示されていません。優先して検討するなら、こちらが現実的です。

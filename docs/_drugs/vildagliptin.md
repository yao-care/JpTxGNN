# ビルダグリプチン：2型糖尿病から限局性硬直肢症候群へ

## 一言要約

ビルダグリプチンは DPP-4 阻害薬で、元々は2型糖尿病の治療に使用されていました。
TxGNN モデルは**限局性硬直肢症候群 (Focal Stiff Limb Syndrome)** に有効である可能性を予測していますが、現時点で関連する**臨床試験は 0 件、文献も 0 編**です。
予測はモデル上のスコアにとどまり、裏付けとなる実際の研究はありません。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 2型糖尿病（DPP-4 阻害薬） |
| 予測新規適応症 | 限局性硬直肢症候群 (Focal Stiff Limb Syndrome) |
| TxGNN 予測スコア | 99.88% |
| エビデンスレベル | L5 |
| 日本市販状況 | ✗ 有効な承認なし（承認はすべて整理済み） |
| 承認番号数 | 16 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ビルダグリプチンは DPP-4 阻害薬に分類され、2型糖尿病での有効性が確立されています。DPP-4 を阻害して活性型 GLP-1/GIP を高め、グルカゴン分泌を抑えることで血糖を下げると考えられます。

一方、限局性硬直肢症候群は、GABA 作動性・グリシン作動性の神経伝達の異常と、それに伴う自己免疫性の過興奮が関わる神経疾患です。この病態と DPP-4 阻害・インクレチン経路との間に、確立した機序的なつながりは見当たりません。

そのため、この予測は機序面でも臨床面でも裏付けがなく、**モデル由来の仮説の域を出ていません**。スコアが高いことは、臨床的な妥当性を意味しません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測は TxGNN のスコアのみに基づき、臨床試験も文献もありません（L5）。
- 作用機序の面でも、この神経疾患との関連は確認できません。
- 日本では現在有効な承認がなく、新規適応症を進める基盤も弱い状態です。

**進める場合に必要なもの：**
- 疾患病態と DPP-4/インクレチン経路を結ぶ機序的根拠の提示（前臨床研究など）
- 詳細な作用機序データの補充
- 添付文書に基づく警告・禁忌の確認と安全性評価
- 日本での販売状況（承認整理の経緯）の確認

**参考：** 今回のデータでは、他の予測候補である**1型糖尿病**に最も多くのエビデンスがあります（Phase 2〜4 の臨床試験と、RCT を含む文献、エビデンスレベル L2）。ただし臨床的な有益性はまだ確認されておらず、検証すべき研究課題の段階です。再利用を検討するなら、この候補を別途評価する方が合理的です。

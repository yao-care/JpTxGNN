# ヒドロクロロチアジド：高血圧（利尿降圧薬）から悪性高血圧性腎疾患へ

## 一言要約

ヒドロクロロチアジドはチアジド系利尿薬で、主に降圧目的で使われてきました。日本では配合錠として多数販売されています。
TxGNN モデルは**悪性高血圧性腎疾患 (Malignant Hypertensive Renal Disease)** に有効である可能性を予測していますが、**臨床試験は 0 件、文献も 0 編**で、モデル予測のみが根拠です。

| 既存適応症 | 承認適応症のテキストはデータにありません（降圧利尿薬として使用） |
| 予測新規適応症 | 悪性高血圧性腎疾患 (Malignant Hypertensive Renal Disease) |
| TxGNN 予測スコア | 98.42% |

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。既知の情報では、ヒドロクロロチアジドは遠位尿細管の Na-Cl 共輸送体を阻害し、ナトリウム利尿によって血圧を下げます。

悪性高血圧は重度の高血圧が腎障害を起こす病態で、「血圧を下げる」という点で既存の薬効と関連します。ただし、悪性高血圧は通常、迅速な非経口降圧が必要です。チアジド系薬剤は第一選択になりにくく、機序的に自然な適合とは言えません。現時点では、モデルの予測スコアだけが支持の根拠です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 最上位の予測（悪性高血圧性腎疾患）には試験も文献もなく、L5 のモデル予測のみです。機序上も、チアジドが急性の重症病態に適するとは考えにくい状況です。
- PMDA 添付文書の警告・禁忌が未取得で、安全性の一次スクリーニングに進めません（ブロッキングのデータギャップ）。

**参考：他の予測候補**

上位候補より根拠のある候補が 2 件あり、いずれも L4 で「Research Question」と評価されています。ただし、根拠は心不全など近縁病態の間接的なものです。

| 予測適応症 | スコア | 主な根拠 |
|-----------|--------|---------|
| 慢性肺性心 (Chronic Pulmonary Heart Disease) | 97.80% | 利尿薬に関する総説・心不全の文献（間接的） |
| 急性肺性心 (Acute Pulmonary Heart Disease) | 93.17% | 急性心不全の Phase 3/NA 試験 2 件（間接的）、ループ利尿薬とヒドロクロロチアジドの併用 RCT (CLOROTIC) の副次解析 |

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析
- DrugBank からの作用機序 (MOA) データの補完
- 悪性高血圧性腎疾患に対する直接的な臨床・前臨床エビデンスの調査
- 有望な候補（肺性心）を優先して検討するか、チームで判断する

※本結果は研究参考用であり、医療上の助言ではありません。老藥新用候補は臨床的な検証が必要です。

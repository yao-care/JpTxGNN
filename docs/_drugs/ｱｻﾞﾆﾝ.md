# アザニン（ｱｻﾞﾆﾝ）：データ不足により評価保留

## 一言要約

アザニン（ｱｻﾞﾆﾝ）は PMDA データベースに承認記録が確認されておらず、日本未承認の薬物です。
DrugBank への照会で 1 件のクエリ結果は得られましたが、DrugBank ID の確定に至らず、TxGNN による新規適応症予測も実施されていません。
作用機序・安全性・適応症のいずれのデータも不足しており、現時点では老薬新用の評価を行うことができません。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が未確定であるため TxGNN 予測が実行されておらず、新規適応症候補・エビデンス・安全性のいずれも評価できる状態にありません。

**進める場合に必要なもの：**
- DrugBank ID の確定（DrugBank API での名称照合・成分確認）
- 作用機序（MOA）データの取得
- PMDA または他国薬監局での承認状況の再確認
- 安全性情報（警告・禁忌・DDI）の収集
- 上記が揃った後、TxGNN 予測パイプラインを再実行

# オキシブチニン：過活動膀胱からむずむず脚症候群へ

## 一言要約

オキシブチニンはムスカリン受容体拮抗薬で、日本では頻尿・過活動膀胱の治療薬として使われています。
TxGNN モデルは**むずむず脚症候群 (Restless Legs Syndrome)** に有効な可能性を予測していますが、
現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当かどうか

詳細な作用機序データは現在ありません。既知の情報によると、オキシブチニンは膀胱のムスカリン受容体を遮断する抗コリン薬で、過活動膀胱での有効性が確立しています。

むずむず脚症候群は、主にドパミン系と鉄代謝の経路に関わる疾患と考えられています。ムスカリン受容体拮抗作用との間に、確立した機序上のつながりは見つかっていません。この関連は TxGNN の予測にとどまります。スコアが高くても、機序面や臨床面の裏付けは現時点でありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
むずむず脚症候群に対する臨床試験も文献もなく、機序上のつながりも確認できません。エビデンスがモデル予測のみ（L5）のため、現段階で開発に進める根拠はありません。

**進める場合に必要なもの：**
- 予測を裏付ける前臨床研究または機序研究（ムスカリン受容体とむずむず脚症候群の関連の検討）
- 詳細な薬物作用機序データ（MOA）の補充
- PMDA 添付文書に基づく警告・禁忌の確認（現状、安全性審査に進めない状態）
- 薬物相互作用データの確認（検索では該当なし）

補足：同じ予測リストの「低コンプライアンス膀胱」はエビデンスが最も厚い候補です（Phase 3 試験 1 件、システマティックレビュー 1 件）。ただし既存の適応症に近く、再利用としての新規性は限定的です。

*本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証が必要です。*

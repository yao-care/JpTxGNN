## テオフィリン：気管支喘息・肺気腫から血栓性疾患へ
{: .text-alpha }

## 一言要約

テオフィリンは気管支拡張薬・ホスホジエステラーゼ阻害薬で、日本では気管支喘息と肺気腫の治療に使われています。
TxGNN モデルは**血栓性疾患 (thrombotic disease)** に有効である可能性を最上位で予測していますが、この疾患を直接検討した臨床試験は 0 件、文献にもテオフィリン固有の抗血栓エビデンスはなく、**予測のみの段階（L5）**です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし一般的な薬理学的知見として、テオフィリンはホスホジエステラーゼ（PDE）阻害作用とアデノシン受容体拮抗作用を持つ薬剤です。

PDE を阻害すると血小板内の cAMP が上昇し、理論上は血小板凝集が抑えられる可能性があります。これが、気道疾患向けの薬が血栓性疾患と結び付けられた機序的な背景と考えられます。

ただし今回収集した文献には、テオフィリンの抗血栓作用を直接検証したものはありません。上記は仮説の段階であり、実証された根拠ではありません。

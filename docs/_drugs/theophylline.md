# テオフィリン：気管支喘息・肺気腫から血栓性疾患へ

## 一言要約

テオフィリンは気管支拡張薬・ホスホジエステラーゼ阻害薬で、元々は気管支喘息と肺気腫の治療に使われていました。
TxGNN モデルは**血栓性疾患 (Thrombotic Disease)** に有効な可能性を予測していますが、関連する臨床試験は **0 件**です。文献 18 編も、テオフィリンの抗血栓作用を直接示すものはありません。現時点ではモデル予測のみの段階 (L5) です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、テオフィリンは非選択的ホスホジエステラーゼ (PDE) 阻害作用とアデノシン受容体拮抗作用を持つキサンチン系薬剤です。

PDE 阻害により血小板内の cAMP が上昇すると、血小板凝集が弱く抑制される可能性があります。これが予測の機序的な根拠です。

一方で、アデノシン受容体拮抗作用は、この抗凝集効果を打ち消す方向に働く可能性があります。喘息・肺気腫と血栓性疾患は病態が大きく異なります。既存適応症からの機序的な連続性は弱く、抗血栓薬としての臨床的な裏付けも現時点ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 血栓性疾患に対する臨床試験はなく、文献にもテオフィリンの抗血栓効果を支持するものはありません。根拠は TxGNN の予測スコアと、PDE 阻害による血小板 cAMP 上昇という理論的な推測だけです。
- 治療域が狭く、相互作用も多い薬剤です。国内の承認はすべて取り消し済みで、市販品もありません。

**進める場合に必要なもの：**
- 血小板凝集抑制や血栓モデルでの前臨床データ（in vitro・動物）
- 詳細な作用機序データ（アデノシン拮抗作用との差し引きの評価）
- 添付文書（警告・禁忌）の確認と、安全性スクリーニングの実施
- 国内で供給可能な製剤の有無の確認

**参考：** 同じ予測リストの「閉塞性肺疾患」は、完了済みの Phase 3 試験が複数あり L1 と評価されています。ただし既存適応症（喘息・肺気腫）と重なるため、真の再利用ではありません。アレルギー性鼻炎などの気道疾患 (L3〜L4) は、今後の研究課題として位置づけられます。

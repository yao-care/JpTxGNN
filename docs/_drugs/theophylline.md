# テオフィリン：気道疾患治療薬から血栓性疾患へ

## 一言要約

テオフィリンは、気管支喘息や慢性気管支炎などの気道疾患に用いられる気管支拡張薬として知られています。
TxGNN モデルは**血栓性疾患 (thrombotic disease)** に有効である可能性を予測しています。
ただし、**臨床試験は 0 件**で、抽出された 18 編の文献もテオフィリンの抗血栓作用を直接検証したものはなく、現時点のエビデンスはモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。テオフィリンは非選択的ホスホジエステラーゼ（PDE）阻害薬であり、アデノシン受容体拮抗薬でもあることが知られています。

PDE 阻害は血小板内の cAMP を上昇させ、血小板凝集を抑える方向に働く可能性があります。一方で、アデノシンの抗凝集作用を遮断する可能性もあります。そのため、血栓性疾患に対する正味の効果の方向は不明です。

したがって、この予測は機序的に否定はできないものの、妥当性が確認されたとは言えません。実際の抗血栓効果は検証が必要です。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

なお、テオフィリンは血中濃度が高いと毒性が出やすく、治療域が狭い薬です。薬物相互作用の登録件数は 0 件ですが、検索で該当なしとなっただけです。相互作用が無いことを意味しないため、確認が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
臨床試験は 0 件で、文献もテオフィリンの抗血栓作用を直接支持しておらず、エビデンスはモデル予測のみ（L5）です。さらに PDE 阻害とアデノシン拮抗で作用方向が相反するため、効果の方向自体が不明です。

なお、同じ予測リストのうち閉塞性肺疾患は、完了した Phase 3 試験（NCT01599871）を含み L1 と判定されています。ただし、これはテオフィリンの既存用途に近く、本来の意味での再利用候補とは言えません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現状は安全性審査に進めないブロッキング項目）
- 詳細な作用機序データ（MOA）の取得
- 血小板凝集や血栓モデルにおけるテオフィリンの前臨床データ
- 血栓性疾患の対象を絞った臨床試験の有無の再確認

本レポートは研究参考用であり、医療上の助言ではありません。老藥新用候補は臨床での検証を経て初めて適用できます。

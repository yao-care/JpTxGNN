# ドルゾラミド：緑内障領域から原発性遺伝性緑内障へ

## 一言要約

ドルゾラミドは炭酸脱水酵素阻害薬の点眼薬で、日本では「トルソプト点眼液」として市販されています。TxGNN モデルは**原発性遺伝性緑内障 (Primary Hereditary Glaucoma)** に有効である可能性を予測しています（スコア 99.99%）。この予測を直接支持するのは **1 件の臨床試験**（Phase 2、小児緑内障）だけで、関連する文献はありません。

## この予測が妥当である理由

ドルゾラミドは毛様体上皮の炭酸脱水酵素 II を阻害し、房水の産生を減らして眼圧を下げます。この作用は緑内障の病型を問わず共通の治療標的です。DrugBank の作用機序データ（MOA）は今回取得できておらず、上記は予測データに付随する機序説明に基づいています。

遺伝性緑内障も眼圧上昇が病態の中心にあるため、眼圧を下げる薬が機序的に適用できる可能性は高いと考えられます。ただし、遺伝性という病型に特有の有効性や安全性はまだ確認されていません。

**その他の予測候補（参考）**

- **開放隅角緑内障（2 件の予測）**：Phase 3/4 試験とメタアナリシスが多数あり、エビデンスは L1 です。ただし、これは本薬の本来の作用に近い領域で、新規の再利用とは言えません。
- **脱毛症・低毛症系（4 件）**：炭酸脱水酵素阻害と毛包との機序的な関連は認められず、モデルのスコアのみが根拠です（L4〜L5、Hold）。
- **うっ血性心不全・急性肺性心・呼吸不全**：点眼剤の全身曝露は小さく、治療エビデンスもありません（Hold）。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測を直接支持するのは小児緑内障の Phase 2 試験 1 件のみで、遺伝性という病型は未確認です。
- 添付文書の警告・禁忌情報が未取得で、安全性スクリーニングに進めない状態です（重大なデータ不足）。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・相互作用）の取得と確認
- DrugBank から作用機序データを取得し、機序の裏付けを補強
- NCT01527682 の詳細確認（ランダム化の有無、対象の病型、ドルゾラミドの位置づけ、結果）
- 遺伝性緑内障を対象とした症例報告や小児での安全性データの探索

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて適用できます。*

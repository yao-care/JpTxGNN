# ドルゾラミド：開放隅角緑内障・高眼圧症から原発性遺伝性緑内障へ

## 一言要約

ドルゾラミドは炭酸脱水酵素阻害薬の点眼薬で、元々は開放隅角緑内障と高眼圧症の治療に使われていました。
TxGNN モデルは**原発性遺伝性緑内障 (primary hereditary glaucoma)** に有効である可能性を予測しています。
ただし、この疾患に直接関連する臨床試験と文献は **0 件**で、現時点の根拠はモデル予測のみです。

## クイック概要

|------|------|
| 既存適応症 | 開放隅角緑内障、高眼圧症 |
| 予測新規適応症 | 原発性遺伝性緑内障 (primary hereditary glaucoma) |

## この予測が妥当である理由

現在、詳細な作用機序データは登録されていません。ただし既知の情報では、ドルゾラミドは炭酸脱水酵素 (CA) を阻害する局所用の薬剤です。毛様体の炭酸脱水酵素 II を阻害して房水の産生を減らし、眼圧を下げます。ヒトの CA1、CA7、CA12、CA14 にも結合することが報告されています。

原発性遺伝性緑内障も、眼圧上昇による視神経障害という点で、既存適応症の緑内障と病態が共通します。そのため、房水産生を抑える機序は理論上は適用可能です。

ただし、遺伝性緑内障に特化した臨床・文献の裏付けはありません。小児緑内障を対象にした第 2 相試験（ラタノプロストとの併用）は存在しますが、この予測疾患に直接紐づくものではありません。したがって、現時点の妥当性は機序面の推測にとどまります。

  - 重症筋無力症、成人発症重症筋無力症、神経筋接合部疾患
  - 甲状腺機能亢進症、バセドウ病、甲状腺中毒症
  - 房室ブロック
  - 肺気腫、気管支疾患
  - アナフィラキシー
- **薬物相互作用**：薬物間の相互作用データはありません。ドルゾラミドの薬理学的標的として、炭酸脱水酵素 1、7、12、14 が登録されているだけです。

警告と添付文書上の禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 原発性遺伝性緑内障については、臨床試験も文献もなく、モデル予測だけが根拠です（L5）。
- 日本の承認はすべて取消済みで、作用機序と添付文書の安全性情報も未取得です。
- なお、同じモデルが予測した「開放隅角緑内障」は既存適応症にあたります。第 3・4 相試験とシステマティックレビューがあり（L1）、再利用ではなく既存効能の確認にあたります。

**進める場合に必要なもの：**
- 遺伝性・小児緑内障でのドルゾラミドの有効性を示す臨床または前臨床データ
- 作用機序データの取得
- 添付文書（警告・禁忌）の確認
- 日本での販売状況の再確認（現行品や代替製剤の有無）
- 小児・遺伝性緑内障向けの用法と投与経路の適合性評価

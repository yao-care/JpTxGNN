## Vismodegib：基底細胞癌から色素性乾皮症へ
{: .text-alpha }

## 一言まとめ

Vismodegib（ビスモデギブ） は本来、転移性基底細胞癌の治療に用いられる薬剤である。
TxGNN モデルは、本剤が**色素性乾皮症 (Xeroderma Pigmentosum)** に有効である可能性を予測しており、
現在 **5 件の文献**がこの方向性を支持している。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 日本の承認適応症は本サイトのデータに未収載（知識グラフ上の適応症：skin carcinoma、basal cell carcinoma、sweat gland cancer、carcinoma、sebaceous adenocarcinoma） |
| 予測新適応症 | 色素性乾皮症 (Xeroderma Pigmentosum) |
| TxGNN 予測スコア | 99.91% |
| エビデンスレベル | L4 |
| 日本市販状況 | 本サイトのデータに未収載 |
| 承認番号数 | — |
| 推奨判断 | Research Question |

## この予測が妥当な理由

現時点では、詳細な作用機序に関するデータが不足している。既知の情報によれば、Vismodegib は Hedgehog シグナル伝達経路阻害薬であり、
その成分は基底細胞癌において有効性が確認されている。作用機序上、色素性乾皮症患者の基底細胞癌に適用できる可能性がある。

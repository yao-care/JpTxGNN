# Vismodegib：從基底細胞癌到著色性乾皮症

## 一言まとめ

Vismodegib 原本用於治療轉移性基底細胞癌。
TxGNN 模型預測它可能對**著色性乾皮症 (Xeroderma Pigmentosum)** 有效，
目前有 **5 篇文獻**支持這個方向。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 日本の承認適応症は本サイトのデータに未収載（知識グラフ上の適応症：skin carcinoma、basal cell carcinoma、sweat gland cancer、carcinoma、sebaceous adenocarcinoma） |
| 予測新適応症 | 色素性乾皮症 (Xeroderma Pigmentosum) |
| TxGNN 予測スコア | 99.91% |
| エビデンスレベル | L4 |
| 日本市販状況 | 本サイトのデータに未収載 |
| 承認番号数 | — |
| 推奨判断 | Research Question |

## この予測が妥当な理由

目前缺乏詳細的作用機轉資料。根據已知資訊，Vismodegib 是 Hedgehog 信號通路抑制劑，
其成分在基底細胞癌中的療效已被證實，機轉上可能適用於著色性乾皮症患者的基底細胞癌。

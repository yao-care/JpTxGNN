# ビクシリン：予測適応症なし — データ不足により評価保留

## 一言要約

ビクシリン（ﾋﾞｸｼﾘﾝ）は本評価パックにおいて既存適応症・作用機序・市販情報のいずれも確認できませんでした。TxGNN モデルによる新規適応症の予測結果も存在しないため、現時点では老薬新用の評価を行うことができません。DrugBank に 1 件のヒットが確認されており、薬物自体の存在は示唆されますが、詳細データの取得が先決です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による予測適応症が存在せず、既存適応症・MOA・市販情報・安全性データのすべてが欠落しているため、老薬新用候補としての評価を行う基盤がありません。まずデータギャップの解消が必要です。

**進める場合に必要なもの：**

- **【Blocking】** PMDA 仿単 PDF のダウンロードと解析による警語・禁忌の取得（DG001）
- **【High】** DrugBank API を用いた作用機序（MOA）・DrugBank ID の確認（DG002）
- DrugBank 1 件ヒット結果の精査：INN・DrugBank ID・適応症・分類の確認
- 薬物名 `ﾋﾞｸｼﾘﾝ`（ビクシリン）の正規化確認：別表記（アンピシリン等）の可能性を含め再クエリ
- PMDA データでの 0 件ヒットの原因調査：表記揺れ・半角カナ変換・製品廃止の可能性

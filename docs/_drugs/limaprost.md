# リマプロスト：閉塞性血栓血管炎・腰部脊柱管狭窄症から遺伝性フォンヴィレブランド病へ

## 一言要約

リマプロストはプロスタグランジンE1誘導体で、元々閉塞性血栓血管炎と腰部脊柱管狭窄症の治療に使用されていました。
TxGNN モデルは**遺伝性フォンヴィレブランド病 (hereditary von Willebrand disease)** に有効である可能性を予測していますが、
現在、関連する臨床試験・文献は**ありません**（モデル予測のみ）。
さらに、この予測は薬理作用と相反するため、安全性上の懸念があります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 閉塞性血栓血管炎、腰部脊柱管狭窄症（血小板凝集抑制薬・血管拡張薬・プロスタグランジンE1受容体作動薬） |
| 予測新規適応症 | 遺伝性フォンヴィレブランド病 (hereditary von Willebrand disease) |
| TxGNN 予測スコア | 99.88% |
| エビデンスレベル | L5 |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、リマプロストはプロスタグランジンE1 (PGE1) 誘導体（EP受容体作動薬）で、血小板凝集抑制作用と血管拡張作用を持ち、閉塞性血栓血管炎や腰部脊柱管狭窄症に使用されてきました。

ただし、フォンヴィレブランド病は一次止血の低下による出血性疾患です。リマプロストの血小板凝集抑制・血管拡張作用は、この疾患で必要とされる止血機能の回復とは**薬理学的に逆方向**であり、出血リスクを悪化させる可能性があります。TxGNN の高スコアは予測にすぎず、機序的な裏付けは確認できません。

参考として、同じ予測リストには次の候補もあります。いずれも臨床試験・文献はなく、モデル予測のみです。

| 順位 | 予測疾患 | スコア | 機序上の見方 |
|------|---------|--------|-------------|
| 2 | 小腸クローン病 | 99.62% | 粘膜血流や腸管炎症への関与は理論上あり得るが、直接的な根拠なし |
| 3 | 胃炎 | 99.57% | E型プロスタグランジンの胃粘膜保護作用（粘液・重炭酸分泌、粘膜血流）から、もっともらしいが未検証 |
| 4 | X連鎖型フォンヴィレブランド病 | 99.28% | 順位1と同様、止血機能と相反し安全性上の懸念 |
| 5 | 静脈不全 | 99.27% | 血管拡張・微小循環改善作用から間接的な根拠はあるが、試験・文献なし |

## 安全性に関する考慮事項

- **出血リスク（薬理作用に基づく懸念）**：リマプロストは血小板凝集を抑制するため、フォンヴィレブランド病のような出血性疾患では出血を悪化させる可能性があります。

その他の警告・禁忌・薬物相互作用については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 臨床試験・文献がなく、エビデンスはモデル予測のみ（L5）です。
- 最上位の予測疾患（フォンヴィレブランド病）は、薬理作用と相反し安全性上の懸念があります。
- 日本の承認はすべて取消されており、現時点で供給・使用の基盤もありません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得と確認（安全性スクリーニングの前提）
- 詳細な作用機序データ（MOA）の補充
- 機序的に妥当性の高い候補（胃炎、静脈不全など）の優先的な再評価と、前臨床・文献調査
- 投与経路の適合性の評価
- 日本での承認取消の経緯の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# Carbenoxolone：消化性潰瘍から非症候群性食道奇形へ

## 一言まとめ
Carbenoxolone（カルベノキソロン） はもともと胃潰瘍および口腔内潰瘍の治療に用いられるグリチルレチン酸誘導体であり、TxGNN は非症候群性食道奇形(non-syndromic esophageal malformation)に対する治療可能性を予測しています。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 胃潰瘍、十二指腸潰瘍、口内炎性潰瘍 |
| 予測新適応症 | 非症候群性食道奇形 (non-syndromic esophageal malformation) |
| TxGNN 予測スコア | 99.9988% |
| エビデンスレベル | L5 (予測のみ) |
| 日本市販状況 | 本サイトのデータに未収載 |
| 承認番号数 | — |
| 推奨判断 | Hold |

## この予測が妥当な理由
Carbenoxolone はグリチルレチン酸(glycyrrhetinic acid)のコハク酸エステル誘導体です。

1. **粘膜保護作用**：胃粘膜の粘液および重炭酸塩の分泌を増加させる
2. **抗炎症作用**：プロスタグランジン代謝を抑制する
3. **潰瘍治癒の促進**：上皮の再生を増強する

ただし、この予測には慎重な検討が必要です。
- 非症候群性食道奇形は先天性の構造異常であり、食道閉鎖や食道気管瘻などが含まれる
- この種の疾患は主に外科手術による矯正が必要であり、薬物治療の対象ではない
- Carbenoxolone の粘膜保護の機序は、先天性奇形の病態機序とは直接の関連がない

## 臨床試験エビデンス
carbenoxolone による食道奇形の治療を対象とした臨床試験はありません。

## 文献エビデンス
PubMed 検索で見つかった間接的に関連する文献は1件のみでした。

**Mall A ら (1991)** - *American Journal of Medicine*

- Carbenoxolone は対照薬として用いられた
- スクラルファートは carbenoxolone より潰瘍治癒の促進に優れていたことが示された
- この研究は食道奇形とは直接の関連がない

carbenoxolone の食道奇形への使用を支持するその他の文献エビデンスはありません。

## 安全性に関する考慮事項
### 主な副作用
- 水・ナトリウム貯留
- 低カリウム血症
- 高血圧

### ミネラルコルチコイド様作用
- Carbenoxolone は 11-beta-hydroxysteroid dehydrogenase を阻害する
- コルチゾールが蓄積し、アルドステロン過剰に類似した作用を生じる
- 長期使用時は電解質と血圧のモニタリングが必要

### 禁忌
- 心不全
- 重症高血圧
- 低カリウム血症
- 腎機能障害

### 薬物相互作用
bundle には、既知の有意な相互作用の記録はありません。

## 結論と次のステップ
**エビデンスレベル**：L5 (TxGNN の予測のみで、臨床的・薬理学的な裏付けなし)

**推奨**：Hold (当面は推奨しない)
1. 非症候群性食道奇形は先天性の構造異常であり、外科的処置が必要である
2. Carbenoxolone の粘膜保護の機序では先天性奇形を修復できない
3. この予測は、知識グラフ上で食道と消化管が関連付けられていることに由来する可能性があり、真の治療可能性によるものではない

**考えられる妥当な応用場面**：
- 食道奇形の術後における粘膜修復の補助(あくまで推測)
- 食道手術後の吻合部潰瘍に対する補助療法(さらなるエビデンスが必要)

**次のステップの提案**：
- 食道奇形を対象とした臨床的探索は推奨しない
- Carbenoxolone の口腔内潰瘍への使用は既知の用途：知識グラフまたは承認情報に記録済みです。日本での市販状況は本サイトのデータに未収載です（承認番号数：—）
- より新しく副作用の少ない他の薬剤による代替案を検討できる

**特記事項**：この予測は、TxGNN のアルゴリズムが解剖学的位置や疾患分類の関連に基づいて生成した偽陽性である可能性が極めて高い。非症候群性食道奇形は手術適応であり、薬物治療で外科的矯正に代えることはできない。

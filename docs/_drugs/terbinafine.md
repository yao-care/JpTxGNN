# テルビナフィン：白癬から移動性ハエ幼虫症（Creeping Myiasis）へ

## 一言要約

テルビナフィンは経口・外用の抗真菌薬で、日本では白癬やカンジダ症などの治療に使われています。
TxGNN モデルは**移動性ハエ幼虫症 (Creeping Myiasis)** に有効である可能性を予測していますが、この疾患を直接支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。パック内の機序評価によると、テルビナフィンは真菌のスクアレンエポキシダーゼを阻害する抗真菌薬です。ハエ幼虫に対する抗寄生虫作用は知られていません。

そのため、この予測の根拠は TxGNN モデルのスコアだけです。既存適応症（真菌感染症）とハエ幼虫症は病原体の種類が異なり、機序面の接点が確認できません。

ハエ幼虫症関連の他の予測（創傷ハエ幼虫症、癤腫性ハエ幼虫症、ハエ幼虫症）でも状況は同じです。取得された文献は 3 件の症例報告で、真菌症や癤にハエ幼虫症が併発した例、あるいはテルビナフィンが効かなかった例です。テルビナフィンがハエ幼虫症を治療した報告はありません。予測は、クロモミコーシスとの同時報告に引きずられた可能性があります。

## 結論と次のステップ

**決定：Hold**

**理由：**
最上位の予測（移動性ハエ幼虫症）にはエビデンスが 1 件もなく、機序上の根拠もありません。ハエ幼虫症関連の他の予測も同様です。安全性の基礎資料（PMDA 添付文書）も未取得のため、次の段階に進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現時点で進行を止めている項目）
- DrugBank からの詳細な MOA データの補完
- ハエ幼虫症予測が共起報告による偽陽性かどうかの確認
- 参考候補（表在性真菌症・手白癬など）を検討する場合は、既存適応症との重複による再利用としての新規性の評価と、耐性菌動向の確認

*本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証が必要です。*

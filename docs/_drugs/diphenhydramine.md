# ジフェンヒドラミン：アレルギー性鼻炎から酒さ性結膜炎へ

## 一言要約

ジフェンヒドラミンは第一世代の H1 受容体拮抗薬（抗アレルギー薬）で、日本ではアレルギー性鼻炎などに使用されています。
TxGNN モデルは**酒さ性結膜炎 (Rosacea Conjunctivitis)** に有効である可能性を予測していますが、現時点で裏付けとなる臨床試験や文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

ジフェンヒドラミンは H1 受容体拮抗薬で、ヒスタミンが介在する炎症やかゆみを抑えます。
そのため、眼表面のヒスタミン性の炎症やかゆみを和らげる可能性があります。

ただし、酒さに伴う結膜炎の主な原因は自然免疫や血管系の経路であり、ヒスタミン経路との関連は間接的です。この機序上のつながりは推測にとどまります。

現在、詳細な作用機序データはありません。既知の情報によると、ジフェンヒドラミンは H1 受容体拮抗薬に分類され、アレルギー性鼻炎での使用実績があります。そのため、ヒスタミン関与の眼症状には機序的に適用できる可能性はありますが、酒さ性結膜炎への有効性は実証されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験も文献もなく、エビデンスはモデル予測のみ (L5) です。機序上のつながりも間接的で、安全性評価に必要な添付文書情報も未確認のため、現段階では次に進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（安全性スクリーニングの前提条件）
- 詳細な作用機序データ（DrugBank など）の取得と、酒さ性結膜炎との機序的関連の検証
- 酒さ性結膜炎に関する臨床試験・文献の調査（前臨床・観察研究を含む）
- 投与経路の適合性確認（国内の剤形は経口、注射、皮膚外用が中心で、眼科用製剤は確認できていません）

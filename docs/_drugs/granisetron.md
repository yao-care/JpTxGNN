# グラニセトロン：悪心・嘔吐から双極性感情障害（躁状態）へ

## 一言要約

グラニセトロンは選択的 5-HT3 受容体拮抗薬で、化学療法・放射線療法に伴う悪心・嘔吐の予防・管理に広く使用されている薬物です。
TxGNN モデルは**双極性感情障害（躁状態）(manic bipolar affective disorder)** への有効性を予測していますが、
現時点では関連する**臨床試験も支持文献も存在せず**、モデル推論のみに基づく段階（エビデンスレベル L5）です。

## この予測が妥当である理由

グラニセトロンは選択的 5-HT3 受容体拮抗薬であり、腸管および中枢神経系の 5-HT3 受容体を遮断することで悪心・嘔吐を抑制します。5-HT3 受容体は腸管のみならず、中枢神経系——特に中脳辺縁系——にも広く分布しており、この受容体の活性化がドーパミン放出を調節することが基礎研究で示されています。

TxGNN モデルはこの 5-HT3–ドーパミン経路の接点を識別し、双極性感情障害（躁状態）を予測適応症として挙げています。Evidence Pack 内の機序分析によると、「5-HT3 受容体が中脳辺縁系ドーパミン放出を調節することで躁症状に理論上影響しうる」とされていますが、この推論は極めて間接的であり、臨床的・前臨床的な支持証拠は現在まったく存在しません。

既存適応症（悪心・嘔吐）と予測適応症（双極性障害躁状態）は疾患カテゴリとして大きく異なります。悪心・嘔吐は末梢・中枢の 5-HT3 受容体を介した反射系の急性問題であるのに対し、双極性障害は複雑な神経可塑性・回路異常を背景とする慢性精神疾患です。知識グラフ上のネットワーク近接性が予測の根拠である可能性が高く、機序的関連性は現時点で仮説の域を超えません。

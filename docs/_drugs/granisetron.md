# グラニセトロン：悪心・嘔吐（制吐）から躁病へ

## 一言要約

グラニセトロンは選択的 5-HT3 受容体拮抗薬で、制吐薬として使われる薬剤です。
TxGNN モデルは**躁病性双極性感情障害 (manic bipolar affective disorder)** に有効である可能性を予測しています。
ただし、支持する臨床試験と文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

グラニセトロンは選択的 5-HT3 受容体拮抗薬です。詳細な作用機序データは入力に含まれていません。

躁病との関連は、セロトニン系・ドパミン系の調節を介した**推測的な links** にとどまります。臨床的な裏付けはなく、スコアは TxGNN の予測値のみに基づきます。5-HT3 拮抗薬の本来の用途（制吐）と躁病の間に、直接の適応症の連続性は確認できません。

参考として、他の上位予測もすべて L5 です。

- **機序の推測ができるもの**：トゥレット症候群、抜毛症、蕁麻疹（アレルギー性・寒冷）、血管性浮腫。いずれも間接的な仮説です。
- **根拠が乏しいもの**：急性伝染性結膜炎（グラフ上の近接性による可能性）と腎性尿崩症の逆の病態である抗利尿ホルモン不適切分泌症候群（NSIAD、バソプレシン V2 受容体の遺伝子変異。5-HT3 拮抗との関連なし）。

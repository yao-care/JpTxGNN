# エチゾラム：既存適応症の情報なしから 不眠症 へ

## 一言要約

エチゾラムはチエノジアゼピン系の薬で、日本では「デパス細粒1%」として市販されています。ただし、今回のデータには元の承認適応症の記載がありません。
TxGNN モデルは**不眠症 (insomnia)** に有効な可能性を予測していますが、現時点で**臨床試験は 0 件**、関連文献は **4 編**です。うち不眠症への効果を直接示すのは動物実験 1 編のみで、エビデンスは限定的です。

## この予測が妥当である理由

エチゾラムはチエノジアゼピン系の薬で、GABA-A 受容体のベンゾジアゼピン結合部位に作用する正のアロステリックモジュレーターと考えられます。GABA の抑制性シグナルを強めることで鎮静・催眠作用を示すため、不眠症との機序的な関連はもっともらしいといえます。

なお、現在、詳細な作用機序データはありません。上記はベンゾジアゼピン系の一般的な薬理に基づく推定です。元の適応症との類似性の評価も未実施です。

動物実験では、エチゾラムがラットで入眠潜時を短縮し、ノンレム睡眠時間を増やしたと報告されています。この結果は予測を機序面から裏付けるものですが、ヒトでの有効性を示すものではありません。

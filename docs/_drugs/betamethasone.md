# ベタメタゾン：乾癬などの皮膚疾患から円形脱毛症へ

## 一言要約

ベタメタゾンは合成グルココルチコイドで、日本では乾癬や掌蹠膿疱症などの炎症性皮膚疾患を中心に承認されています。
TxGNN モデルは**円形脱毛症 (Alopecia Areata)** に有効である可能性を予測しています。
関連する **7 件の臨床試験**と **20 編の文献**があり、完了した Phase 2 のランダム化比較試験が 1 件含まれます。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報では、ベタメタゾンは「抗炎症薬・鎮痒薬・グルココルチコイド受容体作動薬」に分類されています。既存適応症での有効性は確立されており、この分類から、機序的に円形脱毛症にも適用できる可能性があります。

円形脱毛症は、毛包に対する T 細胞介在性の自己免疫反応による非瘢痕性脱毛です。強力なグルココルチコイドは、この免疫・炎症反応を抑える薬剤群にあたります。実際に、外用、病巣内注射、内服ミニパルスといった副腎皮質ステロイド療法が、すでに治療選択肢として使われています。

既存適応症の乾癬や天疱瘡も、免疫介在性の皮膚疾患です。抗炎症・免疫抑制作用という共通点が、この予測の背景にあります。ただし、この関連性の根拠は薬効群の薬理に基づくもので、ベタメタゾン固有の機序データではありません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
円形脱毛症では、ベタメタゾン内服ミニパルスを扱った完了済み Phase 2 RCT 1 件と、複数の RCT・レビューがあり、エビデンスは L2 に達しています。ただし、Phase 3 の RCT はなく、試験の多くは小規模です。ステロイドを比較対照としているだけの試験も多いため、条件付きで進めます。

**進める場合に必要なもの：**
- 日本の添付文書（PMDA）の警告・禁忌の取得（現在は未取得で、安全性スクリーニングに進めないブロッキング項目）
- DrugBank からの作用機序（MOA）データの補完
- 投与経路（外用、病巣内注射、内服ミニパルス）の選定と、日本の承認剤形との適合性の確認
- ベタメタゾンを直接検証した、より大規模で質の高い RCT のエビデンス
- 全身投与（内服パルス）を想定する場合の、長期安全性と再発率の確認

なお、他の予測候補のうち、特発性ステロイド感受性ネフローゼ症候群は L3（1981 年の日本の小児での報告のみ）で、研究課題の段階です。それ以外は L4〜L5 で保留です。

本結果は研究参考用であり、医療上の助言ではありません。予測は臨床での検証を経て初めて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ベタメタゾン：炎症性皮膚疾患・自己免疫疾患から円形脱毛症へ

## 一言要約

ベタメタゾンはグルココルチコイド受容体作動薬で、元々乾癬、掌蹠膿疱症、天疱瘡などの皮膚疾患や、関節リウマチ、潰瘍性大腸炎などの全身性炎症・自己免疫疾患の治療に使用されていました。
TxGNN モデルは**円形脱毛症 (Alopecia Areata)** に有効である可能性を予測しており、現在 **6 件の臨床試験**と **20 編の文献**がこの方向性に関連しています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、ベタメタゾンはグルココルチコイド受容体作動薬に分類される合成副腎皮質ステロイドで、強力な抗炎症作用と免疫抑制作用を持ちます。

円形脱毛症は、毛包の免疫特権が破綻し、T 細胞を介した自己免疫攻撃によって非瘢痕性の脱毛が起こる疾患です。ベタメタゾンの免疫抑制作用はこの攻撃を抑える方向に働くと考えられ、外用、局所注射、経口ミニパルス療法が実臨床で使われてきた根拠にもなっています。

既存適応症の乾癬、エリテマトーデス、天疱瘡などは、いずれも免疫異常を背景とする炎症性疾患です。円形脱毛症も自己免疫疾患であるため、同じ作用機序で効果が期待でき、予測には機序的な整合性があります。

## 安全性に関する考慮事項

- **禁忌（疾患知識グラフ上の関連）**：添付文書の記載ではなく、知識グラフ上の薬物-疾患禁忌関係として、高血圧、てんかん、高血糖、うっ血性心不全、麻疹、単純ヘルペスウイルス角膜炎、下垂体機能低下症（成長ホルモン欠損症、性腺機能低下症を含む）、尿素サイクル異常症（カルバモイルリン酸合成酵素 I 欠損症、高アルギニン血症、シトルリン血症）などが挙げられています。
- **薬物相互作用**：100 件の相互作用が検出されています（解析対象は上位 20 件）。重大（Major）なものとして**アダリムマブ**があります。中等度（Moderate）には、ジドブジン、イソトレチノイン、アカルボース、アセブトロール、アセタゾラミド、ケトロラク、ニフェジピン、イブプロフェン、エチニルエストラジオール、アルブテロール以外の多数の薬剤（アルデスロイキン、アレムツズマブ、フルボキサミン、ホスアンプレナビルなど）が含まれます。軽微（Minor）なものとしてホルモテロール、サルブタモールがあります。

警告・禁忌の正式な添付文書情報は今回のデータに含まれていないため、添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
円形脱毛症では、完了した Phase 2 の比較試験（経口ミニパルス）に加え、複数の RCT（外用、経口パルス、病変内注射）が存在します。ただし、Phase 3 RCT による確証はなく、多くの試験が小規模か比較対照型で、日本での販売承認も現在ありません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得と安全性スクリーニング（現時点では未確認で、ここが最優先の課題）
- 詳細な作用機序データ（MOA）の補完
- 円形脱毛症に対する Phase 3 RCT、またはプラセボ対照試験のエビデンスの確認
- 投与経路（外用、病変内注射、経口ミニパルス）ごとの適合性の整理と、日本で利用可能な製剤の確認
- 長期・反復投与による全身性副作用（高血糖、高血圧、感染症など）のモニタリング計画
- 他の予測疾患では、尋常性の候補（毛包性ムチン症、毛包炎性脱毛症、特発性ステロイド感受性ネフローゼ症候群）は文献が症例報告レベルにとどまり、追加の研究課題として扱うのが妥当です。

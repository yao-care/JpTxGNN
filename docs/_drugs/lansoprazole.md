# ランソプラゾール：消化性潰瘍・逆流性食道炎から十二指腸胃逆流へ

## 一言要約

ランソプラゾールはプロトンポンプ阻害薬で、元々胃潰瘍・十二指腸潰瘍・逆流性食道炎などの治療に使用されていました。
TxGNN モデルは**十二指腸胃逆流 (Duodenogastric Reflux)** に有効である可能性を予測していますが、現時点で関連する臨床試験の登録はなく、この疾患を直接扱った文献もありません。支持する文献は一般的なプロトンポンプ阻害薬のレビュー **1 編**のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ランソプラゾールはプロトンポンプ阻害薬に分類され、胃壁細胞の H+/K+-ATPase を阻害して胃酸分泌を抑えることが知られています。胃潰瘍や逆流性食道炎などの酸関連疾患で有効性が確立されています。

十二指腸胃逆流では、胆汁や十二指腸内容物が胃へ逆流し、粘膜が傷害されます。胃酸を抑えれば、この粘膜傷害の負荷を軽くできる可能性があります。ただし、ランソプラゾールは逆流そのものには作用しません。この疾患に特化したエビデンスもなく、機序上の関連は推測の域を出ません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、十二指腸胃逆流に対する臨床試験も直接的な文献もなく、エビデンスは機序の推測にとどまります。ランソプラゾールは逆流そのものを改善せず、日本では販売中の承認もありません。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と、安全性スクリーニングの実施
- 詳細な作用機序データ（MOA）の補充
- 十二指腸胃逆流に対する PPI の有効性を評価した臨床研究の調査（症状改善や粘膜傷害の抑制が目的）
- 日本での販売状況の再確認（現在は承認整理済みのみ）

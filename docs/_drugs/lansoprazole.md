# ランソプラゾール：胃潰瘍・逆流性食道炎から十二指腸胃逆流へ

## 一言要約

ランソプラゾールはプロトンポンプ阻害薬（PPI）で、日本では胃潰瘍、十二指腸潰瘍、逆流性食道炎などの治療に使われています。
TxGNN モデルは**十二指腸胃逆流 (Duodenogastric Reflux)** に有効な可能性を予測しています。ただし関連する**臨床試験は 0 件**で、文献は **2 編**のみです。疾患に特化した研究はラットの試験 1 件だけで、その結果はランソプラゾールが胃発癌を促進するという安全性シグナルでした。

## この予測が妥当である理由

現在、詳細な作用機序データ（MOA）は取得できていません。ただし予測の根拠として、ランソプラゾールは胃の H+/K+ ATPase（プロトンポンプ）を不可逆的に阻害し、胃酸を低下させると整理されています。

十二指腸胃逆流は、十二指腸内容物が胃へ逆流して粘膜を傷つける病態です。胃酸を下げれば、逆流物による粘膜障害が軽減する可能性があります。既存適応症の胃潰瘍や逆流性食道炎も酸関連の粘膜障害であるため、機序的には近い関係にあります。

ただし、この疾患を直接扱った研究は、十二指腸胃逆流を起こしたラットにランソプラゾールを投与した試験だけです。この試験では、ランソプラゾールが胃発癌を**促進**したと報告されています。機序的な妥当性はあるものの、現時点のエビデンスは有効性を支持しておらず、むしろ安全性上の懸念を示しています。

## 結論と次のステップ

**決定：Hold**

**理由：**
十二指腸胃逆流に対するヒトでの臨床試験や臨床研究がなく、唯一の疾患特異的研究であるラット試験は、発癌促進という安全性シグナルを示しています。TxGNN のスコアは高いものの、現時点で推進を支持するエビデンスはありません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌情報を取得し、安全性を確認する
- DrugBank などから詳細な作用機序データ（MOA）を補完する
- ヒトの十二指腸胃逆流に対する観察研究や臨床試験のデータを収集する
- ラットでの胃発癌促進所見が、ヒトでどの程度意味を持つかを評価する
- 参考として、他の予測候補（胃空腸潰瘍、十二指腸炎、胃十二指腸炎）は既承認の酸関連疾患に近く、エビデンスも比較的多い。優先的に検討する価値がある

# ゲンタマイシン：細菌感染症から関節リウマチへ

## 一言要約

ゲンタマイシン（Gentamicin）はアミノグリコシド系の広域スペクトル抗生物質であり、主に重症グラム陰性菌感染症の治療に使用されています。TxGNN モデルは**関節リウマチ (Rheumatoid Arthritis)** への有効性の可能性を予測しており、現在 **1 件の臨床試験**と **20 編の文献**が関連情報として収集されています。ただし、これらのエビデンスはゲンタマイシンが RA 自体を疾患修飾するものではなく、RA 患者の感染合併症管理や人工関節置換術における術後感染予防としての使用を記録したものがほとんどです。

## この予測が妥当である理由

ゲンタマイシンはアミノグリコシド系抗生物質として、細菌リボソームの 30S サブユニットに結合してタンパク質合成を阻害することで殺菌効果を発揮します（詳細な MOA データは現在取得できていません）。この抗菌作用機序は、関節リウマチの病態中心である自己免疫性炎症—T 細胞・B 細胞の異常活性化、TNF-α・IL-6 産生亢進、関節滑膜の破壊—とは直接的な関連性を持ちません。

関節リウマチ患者は DMARD や生物製剤による免疫抑制状態に置かれるため、重症細菌感染症を起こしやすく、ゲンタマイシンはこれら患者の感染症治療薬として使用されることがあります。また、RA 患者に多い人工関節置換術では、ゲンタマイシン含有骨セメント（局所抗菌）が術後感染予防の手段として用いられています。TxGNN の予測は、知識グラフ上で「RA 患者の感染管理・骨科手術」という間接的な共病ノードを介してゲンタマイシンと RA が結びついたことを反映している可能性が高いと考えられます。

なお、ゲンタマイシンにはプレマチュアストップコドンの読み通し（PTC readthrough）効果があり、無義変異を原因とする遺伝性疾患の一部でタンパク質産生を部分的に回復させる可能性が知られています。しかし関節リウマチは無義変異を主因とする遺伝性疾患ではないため、この機序が RA 再利用の直接的根拠となる可能性は低い状況です。

## 結論と次のステップ

**決定：Hold**

**理由：**
ゲンタマイシンと関節リウマチの結びつきは、RA 自体の疾患修飾ではなく、RA 患者の免疫抑制に伴う感染合併症管理および関節置換術の感染予防という間接的な文脈に限られます。ゲンタマイシンが RA 炎症経路（TNF-α・IL-6・JAK-STAT）を直接調節するという機序的根拠は現時点では存在せず、日本での市販実績もなく、安全性情報にも重大なデータ欠損があります。加えて、PMID 7019786 が示すように RA 患者でのゲンタマイシン使用は腎毒性リスクを伴うことが報告されており、安全性の観点からも積極的な再利用開発は推奨されません。

**進める場合に必要なもの：**
- ゲンタマイシンの詳細な作用機序（MOA）データの取得（DrugBank API 照会）
- RA 免疫炎症経路への直接的な影響を検証する in vitro / in vivo 前臨床研究の文献調査
- 日本での安全性情報（腎毒性・耳毒性を含む警語・禁忌事項）の収集（PMDA 添付文書 PDF 解析）
- PTC readthrough 機序が RA 関連の遺伝的サブタイプ（無義変異保有患者）に適用可能かどうかの仮説レベルでの検証

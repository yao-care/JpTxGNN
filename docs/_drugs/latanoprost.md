# ラタノプロスト：緑内障から原発性遺伝性緑内障へ

## 一言要約

ラタノプロストはプロスタグランジン F 受容体作動薬で、元々緑内障の治療に点眼薬として使用されていました。
TxGNN モデルは**原発性遺伝性緑内障 (primary hereditary glaucoma)** に有効である可能性を予測していますが、
現在、関連する臨床試験・文献は**ともに 0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 緑内障（抗緑内障薬、プロスタグランジン F 受容体作動薬） |
| 予測新規適応症 | 原発性遺伝性緑内障 (primary hereditary glaucoma) |
| TxGNN 予測スコア | 99.88% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売中の承認なし（承認はすべて整理・取消済み） |
| 承認番号数 | 20 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ラタノプロストはプロスタグランジン F2α 類縁体（FP 受容体作動薬）で、ぶどう膜強膜流出路を促進して眼圧を下げると考えられています。

緑内障と原発性遺伝性緑内障は、いずれも眼圧上昇を伴う視神経障害という共通点があります。眼圧を下げるという作用は、遺伝性の病型でも治療上の意味を持つ可能性があります。

ただし、この適応症に特化した臨床試験や文献は今回のデータにはなく、機序上の妥当性は推測の域を出ません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**：ぶどう膜炎、虹彩疾患、毛様体疾患、汎ぶどう膜炎、黄斑浮腫（嚢胞様黄斑浮腫を含む）、虹彩炎、結膜炎（急性伝染性結膜炎を含む）。これらは添付文書の記載ではなく、知識グラフ上の関連です。
- **薬物相互作用**：100 件の相互作用が検出されましたが、いずれも重症度は不明です（例：カルシトリオール、グリメピリド、ドキシサイクリン、アトロピン、モルヒネ、プレドニゾン）。

添付文書の警告・禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高い（99.88%）ものの、臨床試験・文献がなく、モデル予測のみ（L5）です。
- 日本では有効な承認が残っていません。

**進める場合に必要なもの：**
- 原発性遺伝性緑内障に対する臨床試験・文献の調査
- 詳細な薬物作用機序データ（MOA）の補充
- 添付文書（警告・禁忌）の確認
- 日本での販売・再承認状況の確認

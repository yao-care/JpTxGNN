# ラタノプロスト：緑内障から原発性遺伝性緑内障へ

## 一言要約

ラタノプロストはプロスタグランジン F 受容体作動薬で、元々緑内障の治療に使用されています。
TxGNN モデルは**原発性遺伝性緑内障 (Primary Hereditary Glaucoma)** に有効である可能性を予測しており、現在 **1 件の臨床試験**（文献は 0 編）がこの方向性を支持しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 緑内障 |
| 予測新規適応症 | 原発性遺伝性緑内障 (Primary Hereditary Glaucoma) |
| TxGNN 予測スコア | 99.88% |
| エビデンスレベル | L2（完了した Phase 2 試験 1 件。ただし RCT デザインかどうかは未確認） |
| 日本市販状況 | ✓ 市販中 |
| 承認番号数 | 20 件 |
| 推奨決定 | Hold |

## この予測が妥当である理由

ラタノプロストはプロスタグランジン F2α 誘導体で、FP 受容体に作用してぶどう膜強膜流出路からの房水流出を促進し、眼圧を下げます。眼圧低下は緑内障治療の中心的な目標です。

原発性遺伝性緑内障も緑内障の一型であり、眼圧の管理が治療の柱になります。そのため、既存適応症と同じ作用機序が適用できる可能性があります。ただし、今回提供されたデータだけでは、遺伝性という特定のサブタイプへの有効性は確認できていません。

なお、DrugBank の作用機序データは未取得です。上記は日本の承認情報にある薬効分類（プロスタグランジン F 受容体作動薬）と、予測の根拠となる機序説明に基づいています。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高く、緑内障という既存適応症との機序的な連続性もあります。一方、裏付けは併用療法の小児緑内障 Phase 2 試験 1 件のみで、文献はなく、ラタノプロスト単独の効果も確認できていません。さらに、日本の添付文書に基づく安全性情報が未取得のため、安全性スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析
- DrugBank から詳細な作用機序データ（MOA）の取得
- NCT01527682 の試験デザイン（RCT かどうか）、対象サブタイプ、ラタノプロスト単独の結果の確認
- 原発性遺伝性緑内障、特に小児での安全性と有効性に関する文献調査

補足：ランク 2 以降の予測（例：頭皮の単純性乏毛症）は、臨床試験も文献もなく、いずれも L5（モデル予測のみ）で Hold の扱いです。乏毛症については、プロスタグランジン類似薬に毛周期の成長期を延長させる作用が知られており、機序上の妥当性はありますが、現時点では検証データがありません。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

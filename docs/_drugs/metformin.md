# メトホルミン：2型糖尿病 から 局所性スティッフ四肢症候群 へ

## 一言要約

メトホルミン（Metformin）は世界中で広く使用されているビグアナイド系の経口血糖降下薬で、2型糖尿病治療の第一選択薬として半世紀以上の臨床実績を持ちます。
TxGNN モデルは**局所性スティッフ四肢症候群（Focal Stiff Limb Syndrome）**への有効性を予測していますが、
現在この方向性を支持する**臨床試験・文献はいずれも存在せず**、モデル予測のみの段階です。

## この予測が妥当である理由

詳細な作用機序データ（MOA）は今回のデータ収集では取得できていません。既知の情報によると、メトホルミンは AMPK（AMP 活性化プロテインキナーゼ）の活性化を介して肝臓での糖新生を抑制し、末梢組織のインスリン感受性を改善するビグアナイド系薬です。加えて、抗炎症・代謝調節作用や mTOR 経路の抑制効果も報告されており、糖尿病以外への応用研究が近年増加しています。

局所性スティッフ四肢症候群は抗 GAD65（グルタミン酸脱炭酸酵素 65）自己抗体が引き起こす局所性の神経-自己免疫疾患です。GABA 作動性神経の機能障害が主病態であり、痙縮・四肢固縮を特徴とします。メトホルミンの AMPK 活性化による免疫代謝調節が理論上この疾患に影響を与えうる可能性はありますが、GABAergic 神経障害との機序的連結を示す前臨床・臨床研究は現時点では存在しません。

本予測は TxGNN モデルの純粋な計算推定に基づくものであり、既存エビデンスによる裏付けはありません。有望性を評価するには、まず抗 GAD65 関連疾患モデルでの基礎実験が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
局所性スティッフ四肢症候群に対するメトホルミンの有効性を支持する臨床試験・文献がいずれも存在せず、機序的連結も高度に推測的です。TxGNN モデル予測スコアは高いものの、エビデンスが皆無の段階（L5）での開発推進は推奨されません。

**進める場合に必要なもの：**
- 作用機序データ（MOA）の取得（DrugBank API 照会）
- PMDA 仿単の取得・解析による日本市販状況と安全性情報の確認
- 抗 GAD65 関連神経疾患モデルを用いた前臨床探索研究
- AMPK 経路と GABAergic 神経機能の機序的関連性を検証する基礎研究
- 類似候補（classic stiff person syndrome、rank 2）との合同評価の検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

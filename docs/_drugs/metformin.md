# メトホルミン：2型糖尿病から Focal Stiff Limb Syndrome へ

## 一言要約

メトホルミンは、日本で2型糖尿病の治療に使われているビグアナイド系の経口血糖降下薬です。
TxGNN モデルは **Focal Stiff Limb Syndrome（局所性硬直肢症候群）** に有効である可能性を予測しましたが、この予測を支持する **臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階 (L5) です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報では、メトホルミンは「糖尿病治療薬・血糖降下薬・AMPキナーゼ活性化薬」に分類されています。肝臓での糖新生を抑え、インスリン感受性を改善する薬として、2型糖尿病での有効性は確立しています。

一方、Focal Stiff Limb Syndrome は自己免疫性または神経疾患による筋硬直を特徴とする疾患です。メトホルミンの作用機序との間に、妥当と言える関連は確立されていません。高スコアは、知識グラフ上の糖尿病との併存関係など、モデル内部の関連に由来する可能性があります。同じスコアで並ぶ古典的スティフパーソン症候群でも同様です。現時点では、機序的な裏付けのない仮説段階の予測と位置づけるのが適切です。

## 結論と次のステップ

**決定：Hold**

**理由：**
臨床試験も文献もなく、機序的にもメトホルミンとの関連が確認できません。エビデンスはモデル予測のみ (L5) で、日本の添付文書の安全性情報も未取得のため、次の段階には進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現時点でブロッキングの欠落データ）
- DrugBank からの作用機序 (MOA) データの取得
- Focal Stiff Limb Syndrome とメトホルミンの機序的関連についての文献調査
- 他の予測候補の確認。第10位のホモ接合体家族性高コレステロール血症は、培養ヒト線維芽細胞でコレステロール代謝を低下させたという in vitro 報告があり (L4)、「Research Question」として検討の余地があります。

本結果は研究参考用であり、医療上の助言ではありません。老藥新用の候補は、臨床検証を経て初めて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# クリゾチニブ：非小細胞肺癌から歯肉線維腫症へ

## 一言要約

クリゾチニブは ALK・ROS1・MET を阻害するチロシンキナーゼ阻害薬で、元々は非小細胞肺癌の治療に使われていました。
TxGNN モデルは **歯肉線維腫症 (Fibromatosis, gingival)** に有効である可能性を予測していますが、予測スコアは高いものの、今回まとめたデータでは**裏付けとなる臨床試験も文献も見つかっていません**（モデル予測のみ）。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 非小細胞肺癌（知識グラフ上の適応症情報による） |
| 予測新規適応症 | 歯肉線維腫症 (Fibromatosis, gingival) |
| TxGNN 予測スコア | 99.81% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は整理済み（有効な承認なし） |
| 承認番号数 | 2 件（いずれも整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データは薬物情報に登録されていません。既知の情報によると、クリゾチニブは ALK、ROS1、MET の各チロシンキナーゼを阻害する分子標的薬で、ALK 陽性・ROS1 陽性の非小細胞肺癌での有効性が確立されています。

一方、歯肉線維腫症とこれらのキナーゼとの間に確立された関連は見つかっていません。既存適応症（肺癌）と予測適応症（歯肉の線維性増殖性疾患）は病態が大きく異なります。そのため、今回の予測は機序的な裏付けのないモデル予測にとどまり、妥当性は現時点では検証されていません。

## 安全性に関する考慮事項

- **薬物相互作用**：相互作用は合計 100 件が登録されており、以下は取得できた 20 件の内訳です。
  - **Major（重大）**：クラリスロマイシン、シサプリド、ドラセトロン、エリグルスタット、グラニセトロン
  - **Moderate（中等度）**：ファモチジン、メトホルミン、ロペラミド、ブプロピオン、アプレピタント、デキサメタゾン、ビサコジル、ブデソニド、ピコスルファート、ポリエチレングリコール、ヒマシ油、クロトリマゾール、グリセリン、グリセロールフェニル酪酸エステルなど
  - Major の相手薬には QT 延長作用を持つ薬剤が多く含まれます。併用時は心電図などの注意が必要です。

警告・禁忌については添付文書を参照してください。

## 参考：他の予測候補

上位 10 件の予測のうち、歯肉線維腫症より裏付けがある候補を挙げます。

- **肺門部癌・肺良性腫瘍（L4）**：根拠は ALK/ROS1 陽性肺癌の症例報告、ならびに ALK 陽性非小細胞肺癌の Phase 3 RCT です。これらは既存の肺癌適応症の範囲内であり、真の新規適応症の根拠にはなりません。
- **肺胚細胞腫瘍（L3）**：ALK 異常を持つ固形腫瘍を対象とした Phase 1b 試験（NCT01121588）と、NCI-MATCH の Phase 2 バスケット試験（NCT02465060）があります。ただし胚細胞腫瘍に特化した根拠ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、臨床試験・文献ともに根拠がなく、機序的な関連も確立されていません（L5）。
- 日本の承認は整理済みで、添付文書上の警告・禁忌も確認できていません。

**進める場合に必要なもの：**
- 歯肉線維腫症の病態と ALK/ROS1/MET 経路との関連を示す機序研究・前臨床データ
- 詳細な作用機序データの補完
- 日本の添付文書（警告・禁忌）の確認と安全性評価
- 上記のうち、より根拠のある ALK 異常固形腫瘍など他の候補との優先順位付け

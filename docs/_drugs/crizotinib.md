# クリゾチニブ：ALK陽性非小細胞肺癌から歯肉線維腫症へ

## 一言要約

クリゾチニブは ALK・ROS1・MET を阻害するチロシンキナーゼ阻害薬で、元々は ALK 融合遺伝子陽性の非小細胞肺癌の治療に使われています。
TxGNN モデルは**歯肉線維腫症 (Fibromatosis, Gingival)** に有効である可能性を予測していますが、この疾患を直接支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

| 予測新規適応症 | 歯肉線維腫症 (Fibromatosis, Gingival) |

## この予測が妥当である理由

DrugBank の作用機序データは取得できていません。ただし文献によると、クリゾチニブは c-Met、ALK、ROS1 を標的とする ATP 競合的な低分子チロシンキナーゼ阻害薬です。EML4-ALK 再構成や ROS1 融合を持つ非小細胞肺癌では高い奏効率が報告されており、これらのキナーゼが発がんの原動力になっている腫瘍で効果を発揮します。

一方、歯肉線維腫症とクリゾチニブの間に、確立した機序上のつながりは見つかっていません。この予測の根拠は TxGNN のスコアだけです。既存適応症（悪性腫瘍）と予測適応症（歯肉の線維性増殖）は疾患の性質が大きく異なり、ALK/ROS1/MET の異常が関与するという報告もありません。そのため、機序面から妥当だと判断するのは現時点では難しいです。

## 結論と次のステップ

**決定：Hold**

**理由：**
歯肉線維腫症については臨床試験も文献もなく、機序上の関連も確認できません。根拠は TxGNN スコアのみ（L5）なので、現時点で開発や検証に進める根拠はありません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・承認適応症）を取得し、安全性スクリーニングの前提を整える
- 歯肉線維腫症でクリゾチニブの標的（ALK/ROS1/MET）が関与するかを、前臨床・機序研究で確認する
- 優先度を見直す場合は、エビデンスの厚い肺門部癌・肺胚細胞腫瘍の候補（L4、S1）を先に検討する

なお、本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて応用できます。

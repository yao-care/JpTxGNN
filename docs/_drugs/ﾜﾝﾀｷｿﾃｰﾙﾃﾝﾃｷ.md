# ワンタキソテールテンテキ：適応症データ不明・評価保留

## 一言要約

ワンタキソテールテンテキ（`ﾜﾝﾀｷｿﾃｰﾙﾃﾝﾃｷ`）は日本の規制データベースで承認実績が確認されておらず、既存適応症・作用機序のいずれも取得できていません。TxGNN モデルによる予測適応症は現時点で生成されておらず、**再利用候補としての評価を実施できる状態にありません**。DrugBank マッピングと規制情報の取得を優先してデータギャップを解消したうえで再評価が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN 予測適応症が生成されておらず、既存適応症・作用機序・安全性情報のいずれも確認できないため、再利用評価を進めるための基盤データが存在しません。なお、PMDA 検索では 0 件、DrugBank 検索では 1 件のヒットが記録されていますが、DrugBank ID の抽出に失敗しており、薬物同定が未完了の状態です。

**進める場合に必要なもの：**
- 半角カタカナ表記（`ﾜﾝﾀｷｿﾃｰﾙﾃﾝﾃｷ`）の正規化と INN 名称の確定
- DrugBank ID の特定（DrugBank API またはマニュアル照合）
- 作用機序（MOA）データの取得（DrugBank / 添付文書）
- PMDA または他国規制当局における承認情報の再検索
- TxGNN 予測の再実行（薬物マッピング成功後）
- 安全性情報（警告・禁忌）の取得（添付文書 PDF 解析）

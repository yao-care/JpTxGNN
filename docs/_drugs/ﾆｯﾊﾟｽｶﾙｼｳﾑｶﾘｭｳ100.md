# ニッパスカルシウム顆粒100%：データ不足により再利用評価不可

## 一言要約

ニッパスカルシウム顆粒100%（入力名：ﾆｯﾊﾟｽｶﾙｼｳﾑｶﾘｭｳ100%）は、日本での市販記録が確認されておらず、DrugBank ID も未特定の薬剤です。TxGNN モデルによる予測新規適応症が存在せず、既存の承認適応症も確認されていないため、現時点では再利用評価に必要な基盤データが揃っておらず、体系的な評価の実施が困難な状況です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN モデルによる予測適応症が存在せず、日本 PMDA での市販記録も確認されないため、再利用候補として評価を開始できる状態にありません。薬剤名が半角カタカナで入力されており、正規化・マッピング処理が正常に機能しなかった可能性もあります。

**進める場合に必要なもの：**
- 薬剤名の正規化（半角カタカナ → 全角 / INN / 一般名への変換）
- DrugBank ID の特定（有効成分の再マッピング）
- 作用機序（MOA）データの取得
- 日本 PMDA における承認情報の再確認
- 上記データ整備後の TxGNN モデル再予測

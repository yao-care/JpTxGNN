# イストラデフィリン：パーキンソン病から ラスムッセン亜急性脳炎 へ

## 一言要約

イストラデフィリンは選択的アデノシン A2A 受容体拮抗薬で、元々パーキンソン病およびその関連症候群の治療に用いられていました。
TxGNN モデルは **ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis)** に有効である可能性を予測していますが、現時点で裏付けとなる臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。ただし、イストラデフィリンは選択的アデノシン A2A 受容体拮抗薬として知られています。A2A シグナルは神経炎症やグルタミン酸性の神経興奮性を調節するため、理論的には、ラスムッセン脳炎で見られる T 細胞介在性の炎症過程やてんかん原性過程と関連する可能性があります。

ただし、この関連性は推測の域を出ません。パーキンソン病とラスムッセン脳炎は病態が大きく異なり、既存適応症との機序的な近さも現時点では評価できていません。この適応症を支持する臨床的・文献的な根拠はなく、TxGNN のスコア (0.99) が唯一の根拠です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測を支える臨床試験も文献もなく、エビデンスはモデル予測のみ (L5) です。作用機序データと添付文書の警告・禁忌も未確認で、日本の承認も取消済みのため、現段階で先に進める根拠はありません。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の取得と解析（安全性スクリーニングに必須）
- 作用機序 (MOA) データの補完（DrugBank など）
- A2A 拮抗とラスムッセン脳炎の病態（神経炎症・てんかん）を結ぶ前臨床・機序研究の調査
- 関連する臨床試験・文献の再検索
- 日本での承認取消の経緯の確認と、剤形・投与経路の適合性評価

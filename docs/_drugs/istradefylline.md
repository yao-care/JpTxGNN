# イストラデフィリン：既存適応症（データ未取得）からラスムッセン亜急性脳炎へ

## 一言要約

イストラデフィリンは日本で「ノウリアスト錠20mg」として市販されている経口薬ですが、今回のデータには既存適応症の記載がありません。
TxGNN モデルは**ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis)** に有効である可能性を高スコア (99.02%) で予測しています。
ただし、裏付けとなる**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

イストラデフィリンは選択的アデノシン A2A 受容体拮抗薬です。A2A シグナルは、神経炎症やグルタミン酸による興奮毒性を調節すると考えられています。この点が、脳の炎症性疾患への応用を考える唯一の手がかりです。

一方、ラスムッセン脳炎は主に T 細胞が関与する慢性の脳炎です。A2A 拮抗薬との直接的な関連を示す証拠は、今回のデータにはありません。この予測は、TxGNN の高いスコアだけを根拠にしています。

詳細な作用機序データ（MOA）は取得できていません。機序面の妥当性は仮説の段階で、試験や文献による裏付けが必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験も文献もなく、エビデンスは L5（モデル予測のみ）です。機序上の関連も仮説にとどまり、安全性の一次情報（添付文書）も未確認のため、現時点で先へ進める根拠がありません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・承認適応症）の取得と解析。これが完了するまで安全性スクリーニングに進めません。
- DrugBank からの作用機序データの取得
- A2A 阻害とラスムッセン脳炎の病態（T 細胞介在性の炎症）を結びつける前臨床・機序研究の調査
- 希少疾患であることを踏まえた、症例報告や小規模研究の文献調査
- 投与経路の適合性の評価（現在は経口剤のみ）

*本結果は研究参考用のモデル予測であり、医療上の助言ではありません。臨床での使用には臨床的検証が必要です。*

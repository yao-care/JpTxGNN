# リシノプリル：高血圧症から後下壁心筋梗塞へ

## 一言要約

リシノプリルは ACE（アンジオテンシン変換酵素）阻害薬で、元々高血圧症の治療に使用されていました。
TxGNN モデルは**後下壁心筋梗塞 (posteroinferior myocardial infarction)** に有効である可能性を予測していますが、この疾患に直接対応する臨床試験や文献は今回のデータにありません。現時点の根拠はモデル予測のみです。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 高血圧症（血圧降下薬、ACE 阻害薬） |
| 予測新規適応症 | 後下壁心筋梗塞 (posteroinferior myocardial infarction) |
| TxGNN 予測スコア | 99.90% |
| エビデンスレベル | L5 |
| 日本市販状況 | 市販中の承認なし（失効・取消のみ） |
| 承認番号数 | 18 件（すべて失効・取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、リシノプリルは ACE 阻害薬で、アンジオテンシン II の産生を抑えて血管を拡張し、心臓の後負荷を軽減します。高血圧症での有効性は確立されています。

心筋梗塞後には、心室のリモデリング（心筋の構造変化）が進みやすくなります。ACE 阻害薬はこの変化を抑えることが知られており、機序的には心筋梗塞にも適用できる可能性があります。ただし、今回のデータには後下壁という亜型を直接検討した試験や文献がなく、裏付けは予測のみです。

## 安全性に関する考慮事項

- **禁忌・注意すべき疾患（知識グラフ上の情報）**：添付文書の内容ではなく、知識グラフ上の薬物と疾患の関連に基づきます。血管性浮腫（遺伝性・後天性・RAS 阻害薬誘発性を含む）、腎疾患、肝疾患、膵炎、胆嚢疾患、糖尿病（糖尿病性ケトアシドーシスを含む）、好中球減少・無顆粒球症、大動脈弁狭窄、低血圧、全身性エリテマトーデス、カリウム欠乏症、副甲状腺機能亢進症、肝性脳症などが挙がっています。
- **予測疾患に関連する留意点**：悪性高血圧では ACE 阻害薬で急性腎障害のリスクがあります。両側腎動脈狭窄を伴う腎血管性高血圧では腎不全を誘発する可能性があります。
- **薬物相互作用**（100 件の記録のうち、一部を記載）：
  - **重大 (Major)**：クエン酸カリウム、炭酸水素カリウム（高カリウム血症のリスク）
  - **中等度 (Moderate)**：副腎皮質ステロイド（ヒドロコルチゾン、デキサメタゾン、ベタメタゾン、トリアムシノロン、ブデソニド）、血糖降下薬（メトホルミン、アログリプチン、サキサグリプチン、カナグリフロジン、ダパグリフロジン、エンパグリフロジン、クロルプロパミド）、アスピリン、モルヒネ、ブプロピオン、ドロナビノールなど

添付文書の警告・禁忌の情報は今回のデータに含まれていないため、詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測 1 位の後下壁心筋梗塞には臨床試験も文献もなく、エビデンスはモデル予測のみ（L5）です。日本では現在市販されている承認もなく、添付文書の安全性情報も未確認のため、次の段階に進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（安全性評価の前提となる必須項目）
- DrugBank からの作用機序（MOA）データの補充
- 心筋梗塞（後下壁を含む）における ACE 阻害薬の既存臨床エビデンス（大規模試験やガイドライン）の調査
- 日本での販売状況の再確認（現在は承認がすべて失効・取消）
- 予測 9 位の慢性肺性心など、エビデンスが比較的ある候補の優先評価の検討
- 投与経路の適合性の確認（現時点では未評価）

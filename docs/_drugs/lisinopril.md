# リシノプリル：高血圧症から後下壁心筋梗塞へ

## 一言要約

リシノプリルは ACE（アンジオテンシン変換酵素）阻害薬で、日本では高血圧症の治療に使用されています。
TxGNN モデルは**後下壁心筋梗塞 (Posteroinferior Myocardial Infarction)** に有効である可能性を予測していますが、
現時点でこの適応症を直接支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、リシノプリルは ACE 阻害薬に分類され、高血圧症での有効性が確立されています。

ACE を阻害するとアンジオテンシン II が減り、血管抵抗（後負荷）が下がります。このため、心筋梗塞後の心室リモデリングを抑える作用が機序的に期待できます。高血圧症と心筋梗塞はどちらもレニン・アンジオテンシン系が関わる循環器疾患であり、予測には一定の生物学的な妥当性があります。

ただし、後下壁という梗塞部位に特化した根拠は確認できていません。今回のデータは TxGNN の予測のみで、裏付けとなる試験や文献はありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
後下壁心筋梗塞については、TxGNN の予測スコアは高いものの、臨床試験・文献ともにありません。機序上の妥当性だけでは、次の段階に進む根拠として不十分です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提条件で、現在は未取得）
- 詳細な作用機序データ（DrugBank などから取得）
- 心筋梗塞後の ACE 阻害薬に関する既存の大規模試験やガイドラインの調査。後下壁という部位に限定せず、心筋梗塞全般として評価する方が現実的です。
- 参考として、同じ予測リストの「慢性肺性心」では、リシノプリルを用いた小規模な臨床研究が 2 件見つかっています（エビデンスレベル L3）。優先度を比較する価値があります。

なお、本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。

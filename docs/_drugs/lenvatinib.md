# レンバチニブ：腎細胞癌・甲状腺癌から脂肪肉腫へ

## 一言要約

レンバチニブは VEGFR や FGFR などを阻害するマルチキナーゼ阻害薬で、元々は腎細胞癌や甲状腺癌の治療に使われていました。
TxGNN モデルは**脂肪肉腫 (Liposarcoma)** に有効である可能性を予測しています。
現在 **1 件の臨床試験**（エリブリン併用の第 Ib/II 相単群試験）と **4 編の文献**がありますが、ランダム化比較試験はまだありません。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 腎細胞癌、甲状腺癌（承認適応症の記載がないため、知識グラフ上の適応症を記載） |
| 予測新規適応症 | 脂肪肉腫 (Liposarcoma) |
| TxGNN 予測スコア | 99.51% |
| エビデンスレベル | L3（完了した単群の第 Ib/II 相試験のみで、RCT はない） |
| 日本市販状況 | 承認整理のみ（現在有効な承認なし） |
| 承認番号数 | 2 件（いずれも承認整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。ただし既知の情報では、レンバチニブは VEGFR1-3、FGFR1-4、PDGFRα、KIT、RET を阻害します。これらの阻害により腫瘍血管新生が抑えられ、腫瘍微小環境も変化すると考えられています。

腎細胞癌は血管新生依存性が高い腫瘍で、レンバチニブの抗血管新生作用が既に臨床で活用されています。脂肪肉腫を含む軟部肉腫も血管新生を介して増殖するため、同じ機序が働く可能性があります。

ただし現時点の臨床的根拠は、エリブリンとの併用試験に限られます。レンバチニブ単独の寄与は不明で、機序的な妥当性は「あり得る」段階にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 脂肪肉腫での根拠は、30 例の単群・併用試験と少数の文献にとどまり、レンバチニブ単独の効果を判断できません。
- 添付文書上の警告・禁忌が未確認で、日本では有効な承認が確認できていません。現段階では研究課題として扱うのが妥当です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の確認と安全性スクリーニング
- 詳細な薬物作用機序データ（MOA）の補完
- LEADER 試験の詳細な有効性・安全性データの精査（奏効率、無増悪生存期間、有害事象）
- レンバチニブ単独またはエリブリン単独との比較が可能なランダム化試験の有無の確認
- 日本での承認・市販状況の再確認（現在のデータでは承認整理のみ）
- 併用薬（QT 延長リスクのある薬剤など）を考慮した相互作用管理計画

なお、今回の予測結果のうち腎細胞癌関連（腎癌など）は既存適応症に近く、新規の再利用候補としては扱いません。その他の希少疾患の予測は、モデル予測以外の根拠がありません。
## 免責事項

臨床応用の前に臨床的検証が必要です。

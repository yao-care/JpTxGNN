# レンバチニブ：脂肪肉腫への再利用可能性

## 一言要約

レンバチニブは VEGFR/FGFR/PDGFR などを阻害するマルチキナーゼ阻害薬で、日本ではレンビマカプセルとして市販されています。
TxGNN モデルは**脂肪肉腫 (Liposarcoma)** に有効である可能性を予測しています。
エビデンスは、完了した Phase Ib/II 単群試験 **1 件**と文献 **4 編**で、ランダム化比較試験のデータはありません。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データは取得できていません。ただしエビデンスパックの機序的考察によると、レンバチニブは VEGFR/FGFR/PDGFR を介した腫瘍血管新生を阻害します。

脂肪肉腫は血管新生の関与が想定される軟部肉腫です。エリブリンは有糸分裂を標的とする細胞毒性薬で、脂肪肉腫の治療に用いられています。血管新生阻害薬のレンバチニブは、この薬と作用点が異なるため、併用で補完的に働く可能性があります。

ただし、この根拠は単群の併用試験に基づく推測です。レンバチニブ単剤の有効性や、ランダム化試験での併用の優位性は確認されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
脂肪肉腫での根拠は、完了した単群 Phase Ib/II 試験 1 件と少数の文献にとどまり、ランダム化データがありません。加えて、日本の添付文書の警告・禁忌が未取得で、安全性スクリーニングに進めない状態です。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析
- DrugBank からの作用機序（MOA）データの補完
- LEADER 試験の有効性・安全性結果の詳細確認と、ランダム化試験の有無の調査
- 薬物相互作用（DDI）の確認

参考までに、同じ予測リストの腎細胞癌（renal carcinoma、順位 7）は Phase 3 RCT を含む豊富なエビデンスがあり、L1 と評価されています。別途評価する価値があります。

なお、本結果は研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的な検証を経てから適用する必要があります。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

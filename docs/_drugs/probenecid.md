## Probenecid：痛風から腎性低尿酸血症へ
{: .text-alpha }

## 一言まとめ

Probenecid（プロベネシド） は尿酸排泄促進薬であり、もともと痛風および痛風性関節炎の治療に用いられてきた。TxGNN モデルは、本剤が**腎性低尿酸血症 (Renal Hypouricemia)** に有効である可能性を予測しており、現在**複数の文献**がこの方向性を支持している。

## この予測が妥当な理由

Probenecid は尿酸の排泄を促進する薬剤で、主に腎尿細管に作用し、尿酸の再吸収を抑制することで尿酸排泄を増加させる。痛風患者では、血清尿酸値を低下させる目的で用いられる。

しかし、腎性低尿酸血症の患者では問題が正反対である。すなわち、腎臓がすでに尿酸を過剰に排泄しており、その結果として血清尿酸値が低くなっている。これは通常、URAT1（尿酸トランスポーター）遺伝子の変異による遺伝性疾患である。

このような状況において、probenecid の臨床での用途は、治療薬としてではなく、主に**診断ツール**としてのものである。probenecid 負荷試験により、医師は腎性低尿酸血症のサブタイプを判断しやすくなる。
- 正常反応：分泌後再吸収の欠損を示唆
- 減弱反応：分泌前再吸収の欠損を示唆

文献中の研究は、これらの患者における probenecid の薬理学的な反応特性の検討が中心であり、治療効果を検討したものではない。

## 結論と次のステップ

**判断：Hold**

**理由：**
Probenecid の腎性低尿酸血症患者に対する作用は、主に診断ツールとしてのものであり、治療薬としてのものではない。これらの患者はすでに尿酸を過剰に排泄しており、尿酸排泄促進薬を使用すると病態がさらに悪化するおそれがある。文献中の研究は薬理学的機序の検討が中心であり、治療効果を検討したものではない。

**推進に必要な事項：**
- 予測の目的が診断なのか治療なのかを明確にする
- 診断目的であれば、標準化された負荷試験プロトコルを確立する必要がある
- 治療目的での使用を検討する場合は、安全性評価を行う必要がある

# トホグリフロジン：SGLT2阻害薬（承認適応症データなし）からオプシスモディスプラジアへ

## 一言要約

トホグリフロジンは腎臓でのグルコース再吸収を抑える SGLT2 阻害薬で、日本ではデベルザ錠として市販されています。
TxGNN モデルは**オプシスモディスプラジア (opsismodysplasia)** に有効である可能性を予測していますが、関連する**臨床試験は 0 件、文献も 0 編**です。
現時点の根拠はモデル予測のみ（エビデンスレベル L5）です。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank）はありません。既知の情報では、トホグリフロジンは SGLT2 阻害薬で、腎臓でのグルコース再吸収を下げ、尿中への糖排泄を増やします。

オプシスモディスプラジアは INPPL1 遺伝子の変異による骨系統疾患で、SHIP2 / PI3K-Akt シグナルの異常が関わります。SGLT2 阻害とこの経路との間に、確立した機序的なつながりは報告されていません。したがって、この予測は知識グラフ上の関連に基づくもので、機序的な裏付けは現時点でありません。スコアが高くても、妥当性の根拠にはなりません。

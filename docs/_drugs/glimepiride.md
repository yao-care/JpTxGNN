# グリメピリド：2型糖尿病から古典的スティッフパーソン症候群 (Classic Stiff Person Syndrome) へ

## 一言要約

グリメピリドはスルホニル尿素系の血糖降下薬で、もともと2型糖尿病の治療に使われていました。
TxGNN モデルは**古典的スティッフパーソン症候群 (Classic Stiff Person Syndrome)** に有効である可能性を予測しています。ただし、この予測を支持する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 2型糖尿病（スルホニル尿素系血糖降下薬） |
| 予測新規適応症 | 古典的スティッフパーソン症候群 (Classic Stiff Person Syndrome) |
| TxGNN 予測スコア | 99.75% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は全件失効（市販中の承認なし） |
| 承認番号数 | 20 件（すべて失効） |
| 推奨決定 | Hold |

## この予測が妥当である理由

詳細な作用機序データは、今回まとめたデータには含まれていません。既知の薬理では、グリメピリドは膵β細胞の KATP チャネル (SUR1/Kir6.2) を閉鎖し、インスリン分泌を促進します。

スティッフパーソン症候群は、主に抗 GAD 抗体が関与する自己免疫性の GABA 作動性神経障害です。KATP チャネル閉鎖によるインスリン分泌促進と直接結びつく機序はありません。両者の接点は、自己免疫疾患と糖尿病が合併しやすいという点だけです。この予測は、知識グラフ上のネットワーク近接性による見かけの関連（アーティファクト）である可能性が高いと考えられます。

現時点では、機序面から予測を支持する根拠は乏しい状況です。

## 安全性に関する考慮事項

- **禁忌（知識グラフ由来、添付文書の記載ではありません）**：腎疾患、肝疾患、胆嚢疾患、うっ血性心不全、下垂体機能低下症（成長ホルモン欠損症、性腺機能低下症を含む）、骨粗鬆症、胸腺疾患、感染症などが関連疾患として挙げられています。
- **薬物相互作用**：100 件の相互作用が確認されています。主なものは次のとおりです。
  - 中等度：ヒドロクロロチアジド、イブプロフェン、ケトロラク、エタノール、エチニルエストラジオール、ヒドロコルチゾン、アセタゾラミド、ファモチジン、ラニチジン、アルビグルチド、アセブトロール、交感神経刺激薬・β刺激薬（エピネフリン、フェニレフリン、サルブタモール、ホルモテロール、プソイドエフェドリン）など
  - 軽度：局所ヒドロコルチゾン、局所アルクロメタゾン

警告や禁忌の詳細は、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高い一方、臨床試験・文献が 0 件で機序的な裏付けもなく、モデル予測のみの L5 段階です。
- 日本の承認もすべて失効しています。

**進める場合に必要なもの：**
- スティッフパーソン症候群との機序的関連を示す前臨床・機序研究
- 添付文書の警告・禁忌情報の確認
- 詳細な作用機序データの整備

**補足（他の予測候補）：** 今回の予測群のうち、1 型糖尿病（TxGNN 予測スコア 98.86%）は、小規模な思春期 RCT、前臨床データ、MODY など単一遺伝子性糖尿病の症例報告があり、エビデンスレベルは L3 です。ただし、関連試験の多くは2型糖尿病を対象としており、間接的な根拠にとどまります。再利用を検討する場合は、こちらの方向性のほうが現実的です。

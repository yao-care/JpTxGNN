# フルタミド：前立腺癌から前立腺癌・脳腫瘍の感受性（prostate cancer/brain cancer susceptibility）へ

## 一言要約

フルタミドは非ステロイド性のアンドロゲン受容体拮抗薬で、元々前立腺癌の治療に使用されていました。
TxGNN モデルは**前立腺癌・脳腫瘍の感受性 (prostate cancer/brain cancer susceptibility)** に有効である可能性を予測しています。ただし、この予測を直接支持する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、フルタミドはアンドロゲン受容体拮抗薬で、活性代謝物ヒドロキシフルタミドとともにアンドロゲン受容体を競合的に阻害し、アンドロゲン依存性の前立腺癌の増殖を抑えます。この作用が、前立腺癌での有効性の根拠です。

一方、今回の予測対象は「感受性」という表現型で、治療対象となる疾患そのものではありません。前立腺癌の部分には既存適応症との関連がありますが、脳腫瘍の部分にはアンドロゲン受容体を介した明確な機序上の根拠が見当たりません。そのため、機序面からの裏付けは限定的で、高いスコアはモデル上の関連性を反映したものにとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測された適応症は治療対象の疾患ではなく感受性の表現型であり、支持する試験・文献もないため、モデル予測のみ（L5）の段階です。さらに、日本の承認はすべて取消されており、肝毒性や多数の相互作用といった安全性上の課題もあります。

**進める場合に必要なもの：**
- 予測対象を、治療可能な具体的疾患に定義し直すこと
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを行うこと
- DrugBank から作用機序データを補充すること
- 他の予測候補の検討。良性生殖器系腫瘍（前立腺肥大症での前立腺体積・PSA 低下を示す小規模なヒト研究、組織学的研究、前臨床研究があり L3 相当）は、研究課題として優先度が高い候補です。男性生殖器癌は既存適応症（前立腺癌）に当たり、新たな再利用の根拠にはなりません。

# リボフラビン：ビタミンB2補充からビオチン代謝疾患へ

## 一言要約

リボフラビン（ビタミンB2）は、日本ではビタミンB2補充薬として使われています。
TxGNN モデルは**ビオチン代謝疾患 (biotin metabolic disease)** に有効である可能性を予測しています。ただし、リボフラビン単独でこの疾患を治療したことを示す直接の試験や文献はなく、エビデンスは**機序面の間接的な裏付けにとどまります**。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、リボフラビンは FAD/FMN の前駆体となる水溶性ビタミン（B群）で、ビタミンB2補充薬として日本で承認されています。

リボフラビンとビオチン（ビタミンB7）は、どちらもミトコンドリア代謝やカルボキシラーゼ反応を支える補酵素系のビタミンです。両者の欠乏が同時に起こり得ることを示す症例報告もあります。未熟児の双子が長期の完全静脈栄養中にリボフラビンとビオチンの両方が欠乏し、乳酸アシドーシス、発疹、多臓器不全を呈した例です。

ただし、この関連は「同じ代謝系を共有し、併発しやすい」という間接的なものです。リボフラビンがビオチン代謝疾患そのものを治療するという直接の証拠はありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
ビオチン代謝疾患に対する TxGNN のスコアは高い（94.88%）ものの、リボフラビンの有効性を直接示す試験や文献はなく、根拠は機序面の間接的なものと、欠乏の併発を示す症例報告に限られます。日本の添付文書に基づく安全性の確認も終わっておらず、現時点では次の段階に進めません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。これが未了のため安全性スクリーニングに進めません。
- DrugBank からの作用機序（MOA）データの補完
- ビオチン代謝疾患（ビオチニダーゼ欠損症、ホロカルボキシラーゼ合成酵素欠損症など）に対するリボフラビン併用の臨床データの調査
- 症例報告の追加検討（ビオチン単独治療との比較を含む）

**補足（他の予測候補）：**
角膜色素沈着（スコア 63.66%）には、リボフラビンを使う角膜クロスリンキング（CXL）の試験が多数あります。ただし対象は円錐角膜や角膜拡張症で、色素沈着そのものへの効果を示すものではありません。日焼け（サンバーン）については、リボフラビンが光増感作用を持つことから、治療効果より光線過敏のリスクを示唆する文献しかありません。その他の予測候補は、機序やエビデンスが乏しく Hold が妥当です。

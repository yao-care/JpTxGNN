# キニジン：不整脈から抗利尿ホルモン不適合分泌症候群（腎性）へ

## 一言要約

キニジンはナトリウムチャネル遮断薬（クラス IA 抗不整脈薬）で、元々期外収縮や心房細動、心房粗動の治療に使用されていました。
TxGNN モデルは **腎性抗利尿ホルモン不適合分泌症候群 (nephrogenic syndrome of inappropriate antidiuresis)** に有効である可能性を予測していますが、
現在、関連する臨床試験や文献は **ありません**（モデル予測のみ）。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、キニジンはクラス IA 抗不整脈薬に分類されるナトリウムチャネル遮断薬で、期外収縮や心房細動などの不整脈で使用されてきました。

腎性抗利尿ホルモン不適合分泌症候群は、バソプレシン V2 受容体（AVPR2）の機能獲得型変異により、水の再吸収が過剰になる疾患です。キニジンの作用（ナトリウムチャネル遮断）とこの受容体シグナルとの間に、確立した機序的なつながりは確認されていません。腎での水の扱いへの関与は推測にとどまり、この予測の根拠は現時点では TxGNN のモデル予測のみです。既存適応症との類似性についても、評価は未了です。

## 結論と次のステップ

**決定：Hold**

**理由：**
この予測は TxGNN のモデル予測のみに基づいており、臨床試験も文献もありません（L5）。キニジンと腎性抗利尿ホルモン不適合分泌症候群の間に機序的なつながりも確認できず、日本の承認もすべて取り消されています。さらに、QT 延長や心ブロックなど重大な心血管リスクがあります。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の取得（PMDA サイトから添付文書 PDF を入手して解析）。これがないと安全性スクリーニングに進めません。
- 詳細な作用機序データ（DrugBank API などから取得）
- キニジンと V2 受容体シグナル・腎での水再吸収との関連についての前臨床・機序研究の確認
- 関連する臨床試験・文献の系統的調査
- 投与経路の適合性評価（現在は未評価）
- 日本での供給状況の確認（承認が取り消されているため）

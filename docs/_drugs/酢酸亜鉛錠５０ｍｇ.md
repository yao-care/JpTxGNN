---

## 一言要約

酢酸亜鉛錠50MG は日本（PMDA）の収載薬剤データベースに登録が確認されておらず、既存適応症の特定ができない状態です。
TxGNN モデルによる新規適応症の予測結果がゼロ件のため、再利用候補の評価を実施できません。
DrugBank への問い合わせでは1件のヒットが得られていますが、必要な識別情報（DrugBank ID・MOA）がレポートに取り込まれておらず、**データ整備が完了するまで評価を保留します**。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN モデルによる予測適応症がゼロ件であり、作用機序（MOA）・承認情報・安全性データのいずれも取得できていないため、再利用候補としての評価を開始できる状態にありません。

**進める場合に必要なもの：**
- DrugBank ID の確定（DrugBank クエリで1件ヒット済み ─ 詳細データのインポートが必要）
- DrugBank から MOA・警告・禁忌データを取得し Evidence Pack に反映
- PMDA 添付文書 PDF の取得と安全性情報の整備
- DrugBank ID が確定したうえで TxGNN 予測を再実行し、予測適応症リストを生成
- 予測適応症が得られた後に臨床試験・文献エビデンスの収集を実施
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

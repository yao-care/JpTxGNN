## この評価が保留となっている理由

### 薬物名エンコーディング問題

入力された薬物名 `ﾋｭﾐﾗﾋｶﾁｭｳ40MGﾍﾟﾝ0.4M` は半角カタカナ（Shift-JIS 由来）です。各トークンを全角に変換すると次の通りです：

| 半角 | 全角 | 意味 |
|------|------|------|
| `ﾋｭﾐﾗ` | ヒュミラ | Humira（製品名） |
| `ﾋｶﾁｭｳ` | 皮下注 | 皮下注射 |
| `40MG` | 40mg | 含量 |
| `ﾍﾟﾝ` | ペン | ペン型デバイス |
| `0.4M` | 0.4mL | 容量 |

これは **TNF-α 阻害薬アダリムマブ（Adalimumab）** の日本市場における製品形態と一致します（DrugBank ID：DB00051）。

DrugBank クエリでは 1 件の結果が返されていますが（クエリログ #2）、`drugbank_id` フィールドへの格納に失敗しており、後続の TxGNN 予測パイプライン全体がブロックされています。PMDA クエリが 0 件となった原因も、同じ半角カタカナによる検索マッチング失敗と推定されます。

### データギャップの影響

| ギャップ ID | 項目 | 重大度 | 影響 |
|------------|------|--------|------|
| DG001 | PMDA 警語 / 禁忌 | Blocking | 安全性初評が実施不可 |
| DG002 | 作用機序（MOA） | High | 機序関連性分析が実施不可 |

いずれのギャップも、薬物名正規化が解決すれば DrugBank 経由で補完可能です。

---

## 結論と次のステップ

**決定：Hold**

**理由：**
薬物名の正規化エラーにより DrugBank ID の確定および TxGNN 予測パイプラインの実行が失敗しており、評価に必要な最低限のデータが揃っていません。アダリムマブ自体は既知の生物学的製剤であるため、正規化後に再実行すれば評価は完了できる見込みです。

**次のステップ（必須）：**

1. **薬物名の正規化**：`ﾋｭﾐﾗﾋｶﾁｭｳ40MGﾍﾟﾝ0.4M` → `ヒュミラ皮下注40mgペン0.4mL` へ全角変換し、パイプラインを再実行
2. **DrugBank ID の手動投入**：アダリムマブの DrugBank ID（`DB00051`）を `drugbank_id` フィールドに手動入力して Evidence Pack を再生成
3. **PMDA データの再取得**：正規化済み薬物名で PMDA を再照会し、承認情報・適応症・警語を取得
4. **TxGNN 予測の実行**：DrugBank ID 確定後、KG 予測（`run_kg_prediction.py`）および DL 予測（`txgnn_model.py`）を順次実行
5. **MOA データの補充**：DrugBank より TNF-α 阻害機序の詳細を取得し、DG002 を解消

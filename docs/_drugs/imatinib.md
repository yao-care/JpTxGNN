# イマチニブ：慢性骨髄性白血病から心臓線維肉腫へ

## 一言要約

イマチニブはチロシンキナーゼ阻害薬で、日本では慢性骨髄性白血病や消化管間質腫瘍 (KIT陽性) などの治療に使われています。
TxGNN モデルは**心臓線維肉腫 (Heart Fibrosarcoma)** に有効である可能性を予測していますが、この疾患を直接支える臨床試験は **0 件**、関連する文献も **1 編**（総説）にとどまります。
現時点ではモデル予測と機序上の推測が中心で、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) はありません。既知の情報によると、イマチニブは抗悪性腫瘍薬（チロシンキナーゼ阻害薬）に分類され、慢性骨髄性白血病や消化管間質腫瘍などで有効性が確立しています。

Evidence Pack の機序上の見立てでは、イマチニブは PDGFR、KIT、ABL キナーゼを阻害します。線維芽細胞系腫瘍の一つである隆起性皮膚線維肉腫 (DFSP) では、COL1A1-PDGFB 融合が PDGFRB シグナルを活性化します。このため、線維肉腫でも同様の経路が関与していれば、イマチニブが作用する可能性はあります。

ただし、**心臓に特化した線維肉腫のデータはなく**、この関連は推測の域を出ません。心臓線維肉腫という希少な部位で PDGFR/KIT 依存性が確認されたわけでもありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
心臓線維肉腫については、臨床試験が 0 件で、文献も直接の裏付けがない総説 1 編のみです。予測スコアは高いものの、エビデンスは機序上の推測にとどまります。

**進める場合に必要なもの：**
- 心臓原発の線維肉腫における PDGFR/KIT 依存性を示すデータ（症例報告、腫瘍の分子解析など）
- PMDA の添付文書から警告・禁忌情報を取得（安全性スクリーニングの前提となる未取得データ）
- DrugBank から作用機序 (MOA) データを補完
- 隆起性皮膚線維肉腫 (DFSP) など、エビデンスが比較的厚い近縁の線維芽細胞性腫瘍を優先して検討

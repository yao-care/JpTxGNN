# トシリズマブ：関節リウマチ・関節炎から強直性脊椎炎へ

## 一言要約

トシリズマブは IL-6 受容体を標的とする抗体医薬で、元々関節リウマチ、若年性特発性関節炎、側頭動脈炎、キャッスルマン病などの治療に使用されていました。
TxGNN モデルは**強直性脊椎炎 (Ankylosing Spondylitis)** に有効である可能性を予測していますが、専用の Phase 3 試験 2 件はいずれも早期に終了しており、有効性は確認されていません。
このデータでは、最上位の予測に対して **4 件の臨床試験**と **17 編の文献**が紐づいています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 関節リウマチ、若年性特発性関節炎、側頭動脈炎、キャッスルマン病など（日本の承認適応症テキストは未登録） |
| 予測新規適応症 | 強直性脊椎炎 (Ankylosing Spondylitis) |
| TxGNN 予測スコア | 99.99% |
| エビデンスレベル | L2 |
| 日本市販状況 | 販売承認はすべて整理済み（取消）で、現在市販されている承認はありません |
| 承認番号数 | 8 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、トシリズマブは IL-6 受容体のシグナルを遮断するヒト化モノクローナル抗体です。IL-6 は体軸性脊椎関節炎の炎症に関与するサイトカインと考えられており、関節リウマチなど既存の適応症と共通する炎症経路を持ちます。

強直性脊椎炎は関節リウマチと同じ慢性炎症性リウマチ性疾患で、機序の面では適用可能性があります。ただし、専用の Phase 3 試験（BUILDER-1/2）では症状改善効果が明確には示されませんでした。そのため、機序上の根拠は臨床的に確認されていません。

## 安全性に関する考慮事項

- **薬物相互作用**：100 件の相互作用が登録されています。主なものは次のとおりです。
  - **Major**：デフェリプロン
  - **Moderate**：ワルファリン、アピキサバン、リバーロキサバン、ジクマロール、シンバスタチン、ロスバスタチン、クロロキン、ヒドロキシクロロキン、ジスルフィラム、ナルトレキソン、メトロニダゾール、チニダゾール、リドカインなど
  - **Minor**：各種亜鉛製剤（硫酸亜鉛、酢酸亜鉛、グルコン酸亜鉛、塩化亜鉛）
- **文献から示唆される留意点**：感染リスク（結核、帯状疱疹を含む）、出血傾向、肝障害、血管炎様反応、脂質への影響が報告されています。

警告および禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
強直性脊椎炎に対する専用の Phase 3 試験 2 件はいずれも中止され、有効性を裏付ける明確な結果が得られていません。また、日本の販売承認はすべて取消となっており、現時点で進める根拠は不十分です。

**進める場合に必要なもの：**
- 中止された試験（BUILDER-1/2）の中止理由と最終結果の詳細確認
- 添付文書（警告・禁忌）の取得と安全性スクリーニング
- 詳細な作用機序データ（MOA）の補充
- 日本での現行の承認・販売状況（取消の背景を含む）の確認

# アルファカルシドール：副甲状腺機能亢進症などから家族性孤立性副甲状腺機能低下症へ

## 一言要約

アルファカルシドールは活性型ビタミン D 製剤で、元々副甲状腺機能亢進症、線維性骨炎、副甲状腺機能低下症、腎性骨異栄養症などの治療に関連する薬として知られています。
TxGNN モデルは**家族性孤立性副甲状腺機能低下症（PTH 分泌障害によるもの）**に有効である可能性を予測していますが、この疾患に直接関連する臨床試験や文献はなく、**モデル予測のみ**の段階です。

| 予測新規適応症 | 家族性孤立性副甲状腺機能低下症（PTH 分泌障害によるもの） |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アルファカルシドールは 1α 位が水酸化されたビタミン D のプロドラッグで、肝臓で活性型のカルシトリオールに変換されます。

この経路は、PTH に依存する腎臓での活性化ステップを経由しません。そのため、PTH 分泌が障害されている病態でも血清カルシウムを上げる働きが期待できます。既存の適応症にも副甲状腺機能低下症が含まれており、PTH 不足による低カルシウム血症という点で、新規適応症とは病態が近いといえます。

ただし、これは生物学的な推論にとどまり、この疾患に関する試験や文献による裏付けは今回のデータにはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、この疾患に対する臨床試験も文献もなく、エビデンスはモデル予測（L5）のみです。さらに、日本の承認はすべて取消済みで、添付文書の安全性情報も未確認です。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の入手と確認
- 詳細な作用機序データ（MOA）の補充
- 家族性孤立性副甲状腺機能低下症に対する活性型ビタミン D の臨床試験や症例報告の調査
- 日本での現在の供給状況と、投与経路・剤形の適合性の確認
- 高カルシウム血症や腎機能に関するモニタリング計画の策定

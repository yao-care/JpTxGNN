# アルファカルシドール：活性型ビタミン D から家族性孤立性副甲状腺機能低下症（PTH 分泌障害）へ

## 一言要約

アルファカルシドールは活性型ビタミン D の前駆体で、日本では内用液と散剤が市販されています。
TxGNN モデルは**家族性孤立性副甲状腺機能低下症（PTH 分泌障害によるもの）**に有効である可能性を予測しています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アルファカルシドールは体内で活性型ビタミン D（1,25-ジヒドロキシビタミン D）に変換されるプロドラッグです。腸管でのカルシウム吸収を高める作用があります。

副甲状腺機能低下症は PTH の分泌や作用が不足し、血中カルシウムが低下する疾患です。活性型ビタミン D はカルシウム吸収を促すため、機序的には PTH 活性の低下を補える可能性があります。

ただし、この関連性はモデル予測と一般的な薬理知識に基づく仮説です。この適応症を直接検証した試験や文献は、今回のデータには含まれていません。既存薬との類似性評価と投与経路の適合性評価も未実施です。

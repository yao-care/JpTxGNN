# カルバマゼピン：三叉神経痛・躁病から三叉神経腫瘍へ

## 一言要約

カルバマゼピンは日本で、抗てんかん薬・鎮痛薬として三叉神経痛、躁病・躁うつ病の躁状態、統合失調症に使われてきました。
TxGNN モデルは **三叉神経腫瘍 (Trigeminal Nerve Neoplasm)** に有効である可能性を予測しています。ただし、この薬に抗腫瘍作用はなく、期待できるのは腫瘍に伴う神経痛の緩和のみです。
関連する臨床試験は **1 件**（カルバマゼピンを検証した試験ではありません）、文献は **20 編**（ほとんどが症例報告・総説）で、実質的なエビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。ただし、カルバマゼピンは電位依存性ナトリウムチャネルを遮断する薬剤として知られ、三叉神経痛の標準的治療薬です。

三叉神経痛は、血管による圧迫のほか、腫瘍（神経鞘腫、髄膜腫、類上皮嚢胞、リンパ腫など）でも起こります。腫瘍に伴う神経痛に対しても、症状緩和の効果が機序的には期待できます。

一方、カルバマゼピンに腫瘍そのものを縮小・制御する機序はありません。この予測が示すのは「腫瘍関連の神経障害性疼痛の対症療法」であり、抗腫瘍治療としての再利用ではありません。実際、文献の症例報告には、カルバマゼピンで痛みが改善しなかった例、副作用で継続できなかった例、一時的に改善した後に腫瘍が判明した例が含まれます。

## 結論と次のステップ

**決定：Hold**

**理由：**
カルバマゼピンに抗腫瘍作用はなく、予測される効果は腫瘍関連神経痛の症状緩和に限られます。この用途を直接検証した臨床試験はなく、文献も症例報告と総説が中心で、症例では無効例も複数含まれます。三叉神経痛はすでに日本での承認適応症であるため、腫瘍に伴う場合も既存適応の範囲で対応できる可能性があります。新たな再利用候補として進める根拠は現時点では不足しています。

なお、予測順位 2〜8 位（驚愕てんかん、思考誘発発作、読書誘発発作などの反射性発作）は、カルバマゼピンの抗てんかん作用と整合的です。ただし、いずれもヒトでの直接的な有効性データはありません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・相互作用）の入手と解析。安全性スクリーニングの前提となります。
- 詳細な作用機序データの補完（DrugBank）。
- 「腫瘍に伴う神経障害性疼痛の緩和」という位置づけで評価するか、抗腫瘍目的の再利用として評価するかの方針決定。
- 腫瘍関連の三叉神経痛患者でカルバマゼピンの有効性を検証する観察研究・試験の探索。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

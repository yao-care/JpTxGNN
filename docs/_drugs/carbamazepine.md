# カルバマゼピン：三叉神経痛・躁病から三叉神経腫瘍（trigeminal nerve neoplasm）へ

## 一言要約

カルバマゼピンは、元々躁病・躁うつ病の躁状態、統合失調症、三叉神経痛の治療に使われてきた抗てんかん薬・鎮痛薬です。
TxGNN モデルは**三叉神経腫瘍 (trigeminal nerve neoplasm)** に有効である可能性を高いスコアで予測しています。ただし、この予測を直接支持する臨床試験は **0 件**、関連文献は **19 編**で、その大半は腫瘍に伴う二次性の三叉神経痛の症例報告や総説です。腫瘍そのものへの効果を示す証拠はなく、症状緩和の範囲にとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、カルバマゼピンは電位依存性ナトリウムチャネルを遮断する抗てんかん薬として知られています。三叉神経痛の標準的な第一選択薬でもあります。

三叉神経腫瘍では、腫瘍による神経の圧迫や浸潤で二次性の三叉神経痛が起こることがあります。ナトリウムチャネル遮断により、この神経痛を症状として和らげる可能性があります。文献でも、腫瘍に伴う三叉神経痛の患者にカルバマゼピンが処方された例が複数報告されています。

注意すべき点は、カルバマゼピンが腫瘍自体に作用するという根拠がないことです。機序的な妥当性は「腫瘍随伴性の神経痛に対する対症療法」としてのみ成り立ちます。実際、カルバマゼピンが効かなかった、または効果が続かなかったことで腫瘍が見つかった症例も報告されています。

## 結論と次のステップ

**決定：Hold**

**理由：**
腫瘍そのものへの効果を示す臨床試験も機序データもありません。文献は腫瘍随伴性の三叉神経痛に対する対症的な使用を示すにとどまり、エビデンスレベルは L4 です。また、日本では現在、有効な承認がありません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の確認（安全性スクリーニングの前提となるデータ）
- 詳細な作用機序データの補充
- 「腫瘍の抑制」ではなく「腫瘍随伴性神経痛の症状緩和」という位置づけに再定義したうえでの研究課題の設定
- 腫瘍に伴う三叉神経痛患者を対象とした観察研究または臨床試験の計画
- 日本での承認状況の再確認（現行の有効な製剤の有無）

なお、同じ予測リストには、てんかん関連の予測として startle epilepsy、反射てんかん関連の予測（thinking seizures、audiogenic seizures、reading seizures など）が上位にあります。いずれも症例報告や動物実験が中心で、L4 の「研究課題」にとどまります。orgasm-induced seizures、beta-ketothiolase deficiency、Rett 症候群先天型は文献・試験がなく L5（Hold）です。

# ニカルジピン：高血圧性緊急症から肺高血圧症へ

## 一言要約

ニカルジピンはジヒドロピリジン系のカルシウムチャネル遮断薬で、日本では高血圧性緊急症、急性心不全、本態性高血圧症の治療に使われています。
TxGNN モデルは**肺高血圧症（原因が多因子で不明確なもの、pulmonary hypertension with unclear multifactorial mechanism）**に有効である可能性を予測していますが、関連する臨床試験も文献も **0 件**で、根拠はモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ニカルジピンは血管平滑筋の L 型カルシウムチャネルを遮断して血管を拡張するジヒドロピリジン系薬剤です。この作用が、全身の動脈圧を下げる既存適応症での効果の基盤になっています。

同じ血管拡張作用は肺血管の緊張を下げる方向にも働くため、肺高血圧症への適用は機序的に考えられます。ただし、カルシウム拮抗薬が有益なのは、急性血管反応性試験で陽性となる一部の患者に限られます。

低酸素性肺疾患に伴う肺高血圧症では、血管拡張薬が換気血流不均衡を悪化させるおそれがあります。この予測は、あくまで仮説段階のものです。

## 結論と次のステップ

**決定：Hold**

**理由：**
肺高血圧症については TxGNN の予測スコアが高いだけで、臨床試験も文献もなく（L5）、根拠が不足しています。血管反応性のある患者に限られることや、低酸素性肺疾患での悪化リスクも懸念されます。

**進める場合に必要なもの：**
- 肺高血圧症でのニカルジピンに関する臨床試験・文献の調査（特に急性血管反応性試験や、カルシウム拮抗薬反応例のデータ）
- PMDA 添付文書の警告・禁忌の取得（現状は安全性スクリーニングに進めない）
- 詳細な作用機序データ（DrugBank）の取得
- 注射剤・経口剤のどちらが肺高血圧症に適するかの剤形適合性評価
- 予測 3〜4 位（悪性高血圧性腎疾患、悪性腎血管性高血圧）は既存適応症の高血圧に近い領域です。既存適応症との関係を別途整理することが望まれます。

# ニカルジピン：高血圧性緊急症・急性心不全・本態性高血圧症から肺高血圧症（原因不明の多因子性）へ

## 一言要約

ニカルジピンはカルシウムチャネル遮断薬（血管拡張薬）で、元々高血圧性緊急症、急性心不全、本態性高血圧症の治療に使用されていました。
TxGNN モデルは**原因不明の多因子性肺高血圧症 (pulmonary hypertension with unclear multifactorial mechanism)** に有効である可能性を予測していますが、この適応症に直接関連する臨床試験・文献は見つかっていません。
現時点の根拠はモデル予測のみ（**臨床試験 0 件、文献 0 編**）です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ニカルジピンはジヒドロピリジン系の L 型カルシウムチャネル遮断薬で、血管平滑筋を弛緩させて血管抵抗を下げます。

肺高血圧症は肺血管の緊張と抵抗の上昇を特徴とするため、血管拡張作用という点で既存適応症（高血圧）と理論上の接点があります。ただし、これは機序からの推測であり、肺高血圧症に対する直接的な裏付けはありません。

注意点として、全身性の血管拡張は肺疾患で換気血流のバランスを悪化させる可能性があります。この予測は仮説段階にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
根拠は TxGNN の予測のみ（L5）で、この適応症に対する臨床試験も文献もありません。また、日本の承認はすべて取消済みで、添付文書の安全性情報も未取得です。機序上の仮説はありますが、全身性血管拡張が肺の換気血流バランスを悪化させる懸念もあります。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（現在の最優先課題）
- 詳細な作用機序データ（DrugBank など）の補完
- 肺高血圧症に対する前臨床・臨床データの体系的な文献調査
- 肺血行動態への影響（肺血管抵抗、換気血流比）の評価
- 日本で承認が取消されている経緯と、現在の供給状況の確認

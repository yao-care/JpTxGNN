# デュルバルマブ：移行上皮癌から前立腺部尿道尿路上皮癌へ

## 一言要約

デュルバルマブは PD-L1 を標的とする抗体医薬で、元々は移行上皮癌（尿路上皮癌）の治療を対象としていました。
TxGNN モデルは**前立腺部尿道尿路上皮癌 (prostatic urethra urothelial carcinoma)** に有効である可能性を予測していますが、この疾患に対する臨床試験・文献は確認できていません。
なお、予測上位 10 件のうち、関連する臨床試験が確認できたのは腎盂肉腫様移行上皮癌、膀胱尿路上皮癌肉腫様亜型、子宮頸部癌の 3 疾患です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 移行上皮癌（TxGNN の知識グラフ上の適応症。日本の承認適応症テキストはデータなし） |
| 予測新規適応症 | 前立腺部尿道尿路上皮癌 (prostatic urethra urothelial carcinoma) |
| TxGNN 予測スコア | 99.98% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は取消済みのみ（現在有効な承認なし） |
| 承認番号数 | 2 件（いずれも取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、デュルバルマブは PD-L1 を阻害して T 細胞の抗腫瘍活性を回復させる免疫チェックポイント阻害薬です。

既存の対象である移行上皮癌と、予測された前立腺部尿道尿路上皮癌は、いずれも尿路上皮由来の腫瘍です。PD-L1 阻害は尿路上皮癌全般で機序的に妥当と考えられます。ただし、この亜部位に特化した試験や文献は提供されておらず、支持材料は TxGNN の予測のみです。

## 安全性に関する考慮事項

- **薬物相互作用**：相互作用は 81 件が報告されています。主なものは以下のとおりです。
  - **重大 (Major)**：アダリムマブ
  - **中等度 (Moderate)**：副腎皮質ステロイド（ヒドロコルチゾン、デキサメタゾン、プレドニゾロン、メチルプレドニゾロンなど）、ロフルミラスト、デフラザコルト、アレムツズマブ、アナキンラ、破傷風トキソイドなど
  - **軽微 (Minor)**：亜鉛製剤（酢酸亜鉛、グルコン酸亜鉛、硫酸亜鉛、塩化亜鉛）

警告・禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測 1 位の疾患には臨床試験も文献もなく、根拠は TxGNN の予測のみ（L5）です。
- 日本の承認もすべて取消済みで、添付文書の警告・禁忌情報も確認できていません。
- 一方、同じ尿路上皮癌系統の腎盂肉腫様移行上皮癌と膀胱尿路上皮癌肉腫様亜型には初期段階の試験があり（L3、Research Question）、これらの疾患を優先して検討する余地があります。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と安全性スクリーニング
- 詳細な作用機序データ（MOA）の補充
- 前立腺部尿道尿路上皮癌に関する臨床試験・文献の追加調査
- 日本での承認取消の経緯と現在の使用可否の確認
- アダリムマブなどの重大な相互作用に対するモニタリング計画

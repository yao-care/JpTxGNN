# オメプラゾール：胃潰瘍などの酸関連疾患から十二指腸胃逆流へ

## 一言要約

オメプラゾールはプロトンポンプ阻害薬で、日本では胃潰瘍、十二指腸潰瘍、逆流性食道炎などの治療に使われています。
TxGNN モデルは**十二指腸胃逆流 (Duodenogastric Reflux)** に有効である可能性を予測していますが、関連する臨床試験は **1 件**（診断画像の研究で、オメプラゾールは未検証）、文献は **20 編**（主にコホート研究と動物実験）にとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データ（MOA）は登録されていません。既知の情報では、オメプラゾールは胃の H+/K+ ATPase（プロトンポンプ）を不可逆的に阻害し、胃酸分泌を強く抑える薬です。

十二指腸胃逆流は、胆汁や十二指腸内容物が胃へ逆流する病態です。オメプラゾールは酸負荷を下げるため、酸が関わる症状や粘膜障害の軽減は期待できます。ただし、胆汁逆流そのものを減らす薬ではありません。バレット食道患者を対象とした研究には、オメプラゾールが十二指腸胃逆流を減らす可能性を示すものがあります。一方で、ラットの慢性十二指腸胃逆流モデルでは、酸抑制が胃発癌を促進する可能性が報告されています。

このため、この予測は「症状緩和の可能性はあるが、逆流自体を治療する根拠は弱く、長期の安全性に懸念が残る」という位置づけです。

## 結論と次のステップ

**決定：Hold**

**理由：**
十二指腸胃逆流に対して、オメプラゾールを直接評価した臨床試験はなく、エビデンスは観察研究と動物実験が中心です。オメプラゾールは逆流自体を減らす薬ではなく、動物実験では長期の酸抑制が発癌を促進する懸念も示されています。日本の添付文書に基づく安全性の確認も未完了です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と、安全性スクリーニング（S1）の実施
- DrugBank からの作用機序（MOA）データの補完
- 十二指腸胃逆流または胆汁逆流に対するオメプラゾールの比較試験の有無の確認
- 長期の酸抑制と胃発癌リスクの評価
- 症状緩和が目的か、逆流抑制が目的かの整理

なお、本結果は研究参考用であり、医療上の助言ではありません。臨床応用には臨床的な検証が必要です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

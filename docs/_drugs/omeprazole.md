# オメプラゾール：消化性潰瘍・逆流性食道炎から十二指腸胃逆流へ

## 一言要約

オメプラゾールはプロトンポンプ阻害薬で、元々胃潰瘍、十二指腸潰瘍、逆流性食道炎などの治療に使用されていました。
TxGNN モデルは**十二指腸胃逆流 (duodenogastric reflux)** に有効である可能性を予測していますが、この予測を直接検証する臨床試験はなく、関連文献 **15 編**も観察研究・動物実験・総説が中心です。
エビデンスは限定的で、現時点では研究課題の段階にあります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、オメプラゾールは胃壁細胞の H+/K+ ATPase（プロトンポンプ）を阻害して胃酸分泌を抑えるプロトンポンプ阻害薬で、消化性潰瘍や逆流性食道炎での有効性が確立されています。

十二指腸胃逆流は、十二指腸内容物（胆汁など）が胃へ逆流する病態です。胃酸を抑えることで、逆流した内容物による粘膜障害を軽減できる可能性があります。ただし、逆流そのものを減らす効果については結果が一定していません。

Barrett 食道患者を対象とした研究では、オメプラゾールが十二指腸胃逆流に与える影響について結果が混在しています。さらに、ラットの実験では、慢性的な逆流下で酸抑制が発がんを促進する可能性が示唆されています。機序的な関連は成り立つものの、有益性と懸念の両面があります。

## 安全性に関する考慮事項

- **薬物相互作用**：100 件の相互作用が確認されています。主なものは以下のとおりです。
  - 重大 (Major)：アカラブルチニブ、アタザナビル
  - 中等度 (Moderate)：アムホテリシン B、アミカシン、アルプラゾラム、アトルバスタチン、ヒドロクロロチアジド、フェノフィブラートなど
  - 軽微 (Minor)：リドカイン、ニフェジピン、アセチルサリチル酸など
- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、TxGNN の知識グラフに基づく）：肝不全、肝疾患、胆嚢疾患、うっ血性心不全、骨粗鬆症、閉経後骨粗鬆症、骨折、慢性萎縮性胃炎

警告・禁忌の詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
十二指腸胃逆流に対しては直接の臨床試験がなく、文献も観察研究、動物実験、総説が中心です。オメプラゾールが逆流自体を減らすかどうかは結果が一定せず、動物実験では酸抑制が発がんを促進する懸念も示されています。また、日本の承認はすべて取消済みです。

**進める場合に必要なもの：**
- 十二指腸胃逆流を対象とした、オメプラゾールの前向き比較試験（胆汁逆流の評価指標を含む）
- 作用機序データ（MOA）の補充
- 添付文書（警告・禁忌）の取得と安全性スクリーニング
- 長期酸抑制による発がんリスクの評価
- 日本での承認状況（取消の経緯と代替製剤の有無）の確認

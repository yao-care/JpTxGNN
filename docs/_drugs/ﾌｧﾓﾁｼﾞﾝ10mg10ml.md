## 一言要約

ファモチジン（Famotidine）は H2 受容体拮抗薬の一種で、胃酸分泌抑制を目的として広く使用されている薬剤です。
本 Evidence Pack では、DrugBank ID 未取得・日本市販情報なしのため、TxGNN モデルによる**新規適応症の予測が実施されていません**。
再利用評価を進めるには、まず基礎データの収集が必要な状況です。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が未取得のため TxGNN による適応症予測を実施できておらず、日本での承認実績も確認されていません。現状では再利用評価の前提条件を満たしていないため、まずデータ整備を優先する必要があります。

**進める場合に必要なもの：**

- **薬物名の正規化**：クエリ文字列 `ﾌｧﾓﾁｼﾞﾝ10MG10ML`（半角カタカナ）を全角 `ファモチジン` に変換し、INN（Famotidine）を確認した上で PMDA・DrugBank を再検索
- **DrugBank ID の特定**：正規化した薬物名で DrugBank API を再クエリし、DrugBank ID を取得
- **PMDA 仿単の取得**：適応症テキスト・警告・禁忌を解析し、安全性初評価を実施
- **作用機序（MOA）の確認**：DrugBank または文献から機序データを取得
- **TxGNN 予測の実施**：上記データが揃い次第、新規適応症予測パイプラインを再実行

> ⚠️ **注意**：PMDA クエリが 0 件となった原因として、半角カタカナ形式（`ﾌｧﾓﾁｼﾞﾝ`）が PMDA 検索システムで正しく照合されなかった可能性があります。全角カタカナに変換して再検索することで解消できる可能性が高いです。

# ジフルコルトロン・リドカイン配合坐剤：データ不足により評価不可

## 一言要約

ジフルコルトロン・リドカイン配合坐剤は、コルチコステロイド（ジフルコルトロン）と局所麻酔薬（リドカイン）を組み合わせた複合製剤です。
今回の評価では、TxGNN モデルによる新規適応症の予測結果が得られておらず、日本国内での承認情報も確認されていません。
現時点では再利用評価を進めるための基礎データが不足しており、**追加データ収集が先決**です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による新規適応症の予測が存在せず、日本国内における承認記録もないため、
薬物再利用候補としての評価を開始する基盤が整っていません。

**進める前に必要なもの：**

- **DrugBank ID の取得**：ジフルコルトロン（Diflucortolone）および成分単体の DrugBank エントリを特定し、知識グラフ上の薬物ノードとして正しくリンクされているか確認する
- **適応症データの補完**：PMDA 以外の海外規制機関（EMA、FDA 等）での承認情報を調査し、既存適応症テキストを確定する
- **MOA データの補完**：DrugBank API でジフルコルトロンおよびリドカイン各成分の作用機序を取得する
- **TxGNN 再実行**：DrugBank ID が確定した後、KG 予測および DL 予測を再実行して予測候補を生成する
- **安全性データの収集**：PMDA 仿単 PDF または EMA/FDA 添付文書から警告・禁忌を抽出する

# オセルタミビル：抗ウイルス薬（ノイラミニダーゼ阻害薬）から腎盂腎炎へ

## 一言要約

オセルタミビルはノイラミニダーゼ阻害薬で、元々はインフルエンザ治療に使われる抗ウイルス薬です。
TxGNN モデルは**腎盂腎炎 (Pyelonephritis)** に有効である可能性を予測しています（スコア 97.85%）。
ただし、この予測を直接支持する臨床試験は **0 件**、関連文献は **1 編**（妊娠中のインフルエンザに関するもので、腎盂腎炎は扱っていません）にとどまり、現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

オセルタミビルはウイルスのノイラミニダーゼを阻害し、ウイルスの放出と拡散を抑える薬です。現在、詳細な作用機序データは取得できていません。

腎盂腎炎は主に細菌による腎臓の感染症です。オセルタミビルには抗菌作用も腎臓に特異的な作用も知られておらず、既存適応症（インフルエンザ）との機序的なつながりは確認できません。この予測は TxGNN の計算上の関連性にのみ基づいています。

唯一見つかった文献は妊娠中のインフルエンザを論じたもので、腎盂腎炎への有効性を示すものではありません。現状では、予測の妥当性を裏付ける根拠は乏しいと判断します。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連**：せん妄（delirium）との関連が示されています。これはラベルの記載ではなく、知識グラフ（PrimeKG）上の薬物と疾患の関連に基づく情報です。
- **薬物相互作用**：66 件の相互作用候補が検出されました（パントプラゾール、バンコマイシン、プレドニゾン、メトホルミン、クラリスロマイシンなど）。いずれも重症度の分類は「不明」です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 腎盂腎炎に対する臨床試験も直接的な文献もなく、機序的な根拠もないため、モデル予測のみ（L5）の段階です。
- 現時点では評価を先に進める根拠がありません。

**進める場合に必要なもの：**
- 腎盂腎炎との機序的な関連を示す前臨床または臨床データ
- 詳細な作用機序データ（MOA）
- 添付文書の警告・禁忌の確認
- 日本での現在の販売状況の再確認（今回のデータでは承認がすべて取消済み）

**参考：同じ予測リスト内の他の候補**
今回のデータでは、**肺炎**（順位 8、スコア 92.14%）が最も根拠のある候補でした（L2、Proceed with Guardrails）。完了済みの Phase 3 試験（インフルエンザの臨床経過など）と複数のレビューがありますが、肺炎に関する試験の多くは COVID-19 を対象とし、オセルタミビルは比較対照や背景治療として登場するだけです。使用はインフルエンザ関連肺炎に限定すべきです。
黄色ブドウ球菌感染症と肺炎球菌性肺炎は、インフルエンザ後の二次細菌感染という観点で研究課題（Research Question）にとどまります。
その他の候補（チロシン代謝異常、フェニルアラニン代謝異常など）には機序的な根拠がなく、Hold 相当です。

# オセルタミビル：抗ウイルス薬（ノイラミニダーゼ阻害薬）から腎盂腎炎へ

## 一言要約

オセルタミビルはノイラミニダーゼ阻害薬に分類される抗ウイルス薬で、日本ではタミフルなどの製品名で市販されています。
TxGNN モデルは**腎盂腎炎 (Pyelonephritis)** に有効である可能性を予測しています（スコア 97.85%）。
ただし、この予測を支持する**臨床試験は 0 件**、関連文献も **1 編**（インフルエンザと妊娠に関する総説で、腎盂腎炎そのものは扱っていません）にとどまり、実質的にモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、オセルタミビルは活性体のオセルタミビルカルボン酸がウイルスのノイラミニダーゼを阻害する抗ウイルス薬です。ウイルスが感染細胞から放出されて広がるのを抑えることで効果を発揮します。

一方、腎盂腎炎は主に大腸菌などの尿路病原細菌による腎臓の感染症です。オセルタミビルカルボン酸にはこれらの細菌に対する既知の活性がなく、ウイルス性疾患と細菌性腎感染症を結ぶ機序的な接点は見当たりません。

したがって、今回の予測は知識グラフ上の関連付けに由来する偽陽性（アーティファクト）である可能性が高いと考えられます。スコアは高いものの、機序面の裏付けはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
腎盂腎炎に対する臨床試験も支持文献もなく、抗ウイルス薬であるオセルタミビルと細菌性感染症を結ぶ機序も見当たりません。予測は TxGNN スコアのみに依存しており、現時点で進める根拠はありません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（現状は安全性データが未取得で、安全性スクリーニングに進めない）
- DrugBank からの作用機序（MOA）データの補充
- 腎盂腎炎に対する機序的根拠の提示（前臨床データなど）。根拠が得られない場合は本候補を除外する

**参考：** 同じオセルタミビルの予測のうち、**肺炎**（TxGNN スコア 92.14%、エビデンスレベル L2、推奨は Research Question）は、インフルエンザ関連肺炎を中心に第 2 相・第 3 相試験や観察研究が確認されています。再利用候補として検討する場合は、こちらを優先して評価するほうが妥当です。

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床での検証を経て初めて応用できます。*

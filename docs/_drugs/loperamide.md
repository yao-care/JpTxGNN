# ロペラミド：止瀉薬から急性伝染性結膜炎へ

## 一言要約

ロペラミドは末梢性のオピオイド受容体作動薬で、元々は止瀉薬（下痢の治療）として使用されています。
TxGNN モデルは**急性伝染性結膜炎 (acute contagious conjunctivitis)** に有効である可能性を予測していますが、この予測を支持する**臨床試験は 0 件、文献も 0 編**です。予測スコアが高くても、モデル上の推定にとどまります。

## この予測が妥当かどうか

ロペラミドは末梢に作用が限られたμオピオイド受容体作動薬です。腸管の蠕動を抑え、分泌を減らすことで下痢を抑えます。DrugBank の詳細な作用機序データは現時点で取得できていません。

腸管に働くこの作用と、眼の感染性炎症である結膜炎との間に、確立した機序的な関連はありません。高いスコアは知識グラフ上で他の結膜炎関連ノードと近いことを反映した値で、薬理学的な裏付けとは言えません。したがって、この予測は妥当性が支持されていません。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

なお、文献上のシグナルとして、抗蠕動薬（ロペラミドを含む）は侵襲性の感染性腸炎で中毒性巨大結腸の一因となる可能性が報告されています。アメーバ性大腸炎などの侵襲性腸感染症では使用に注意が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
最上位の予測（急性伝染性結膜炎）には、機序的な根拠も臨床試験・文献もなく、モデル予測のみ（L5）です。結膜炎関連の候補はいずれも同様です。アメーバ赤痢では、有益性よりも安全性上の懸念が示されています。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（安全性スクリーニングの前提）
- DrugBank からの作用機序（MOA）データの補完
- 眼科領域への機序的根拠の検証（前臨床データなど）
- 投与経路の適合性評価（現行の日本製剤は経口剤のみで、眼科用製剤はなし）

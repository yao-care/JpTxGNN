アザチオプリン（`ｱｻﾞﾁｵﾌﾟﾘﾝ`）は免疫抑制薬として知られる既存薬ですが、今回の Evidence Pack には元の適応症・作用機序データが収録されていません。TxGNN モデルによる予測適応症も生成されておらず、DrugBank ID も未設定です。評価の前提となるデータが揃っていないため、現時点では **Hold** を推奨します。

## 評価保留の理由

現在の Evidence Pack には再利用評価に必要な基本データが欠落しています。`original_indications` が空配列、`original_moa` が未取得であるため、機序的関連性の分析が実施できません。また、**DrugBank ID が `null`** となっており、これが TxGNN 予測パイプライン未実行の直接原因と考えられます。

PMDA 検索（query_log ID: 1）は半角カタカナ `ｱｻﾞﾁｵﾌﾟﾘﾝ` で実行され、結果が 0 件でした。PMDA のデータベースは通常**全角カタカナ**（アザチオプリン）または INN 英語（azathioprine）での検索が必要であり、文字種の不一致が検索失敗の原因である可能性があります。

一方、DrugBank 検索（query_log ID: 2）では 1 件ヒットしており、薬物自体は DrugBank に登録されています。DrugBank からの ID 取得と MOA・安全性データの収集が評価再開の鍵となります。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が未設定のため TxGNN 予測が実行されておらず、適応症・MOA・安全性データのいずれも未取得です。評価の前提条件が満たされていません。

**進める場合に必要なもの：**
- DrugBank で「azathioprine」を検索し、**DrugBank ID**（例：DB00993）を確定させる
- DrugBank API から **MOA・適応症・副作用・DDI データ**を取得する（DG002 解消）
- PMDA を**全角カタカナ「アザチオプリン」または英語「azathioprine」**で再検索し、承認状況を確認する
- PMDA 添付文書 PDF から**警語・禁忌情報**を抽出する（DG001 解消）
- DrugBank ID 確定後に **TxGNN 予測パイプラインを再実行**し、予測候補を生成する

# トラニラスト：気管支喘息・アレルギー性疾患から脂漏性角化症へ

## 一言要約

トラニラストは、日本では抗アレルギー薬（メディエーター遊離抑制薬）として気管支喘息、アレルギー性鼻炎、アトピー性皮膚炎に使われてきました。
TxGNN モデルは**脂漏性角化症 (Seborrheic Keratosis)** に有効な可能性を予測していますが、現時点で関連する臨床試験も文献も見つかっていません。
根拠はモデル予測のみ（エビデンスレベル L5）です。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データはありません。ただしエビデンスパックの機序メモによると、トラニラストは肥満細胞安定化薬であり、TGF-β 経路の阻害を通じて抗線維化・抗炎症作用も示す薬剤です。既存適応症のアレルギー性疾患は、この肥満細胞のメディエーター遊離抑制によるものです。

脂漏性角化症は表皮の良性増殖性病変です。トラニラストとの機序的な関連は**推測の域を出ず**、TxGNN の予測だけが根拠です。アトピー性皮膚炎という皮膚疾患の適応があることは間接的な手がかりになりえますが、増殖性病変への効果を示すデータはありません。

なお、スコアは非常に高い（99.98%）ものの、他の予測候補もほぼ同じ水準（99.97〜99.98%）です。スコアだけでは候補間の優劣を判断できません。

## 結論と次のステップ

**決定：Hold**

**理由：**
脂漏性角化症について、臨床試験・文献ともなく、根拠は TxGNN の予測のみ (L5) です。機序的な関連も推測にとどまり、安全性の確認 (S1) に必要な添付文書情報も未取得のため、現段階では次に進められません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（安全性スクリーニングの前提条件）
- DrugBank からの作用機序データの取得
- 脂漏性角化症に対するトラニラストの文献・前臨床データの追加検索

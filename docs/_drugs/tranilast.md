# トラニラスト：気管支喘息・アレルギー性疾患から脂漏性角化症へ

## 一言要約

トラニラストは、元々気管支喘息、アレルギー性鼻炎、アトピー性皮膚炎の治療に使われてきた抗アレルギー薬（メディエーター遊離抑制薬）です。
TxGNN モデルは**脂漏性角化症 (Seborrheic Keratosis)** に有効である可能性を予測していますが、この予測を支持する臨床試験や文献は現在ありません。
したがって、エビデンスはモデル予測のみ（L5）の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 気管支喘息、アレルギー性鼻炎、アトピー性皮膚炎（抗アレルギー薬・喘息治療薬・メディエーター遊離抑制薬） |
| 予測新規適応症 | 脂漏性角化症 (Seborrheic Keratosis) |
| TxGNN 予測スコア | 99.98% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認は全て整理済み（現在、有効な承認なし） |
| 承認番号数 | 20 件（全て失効・整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、トラニラストは TGF-β シグナルの抑制とマスト細胞などからのメディエーター遊離抑制という作用を持つ抗アレルギー薬で、気管支喘息、アレルギー性鼻炎、アトピー性皮膚炎での使用実績があります。

一方、脂漏性角化症との機序的な関連を示すデータは確認されていません。この関連性は TxGNN の予測のみに基づいています。TGF-β 抑制による抗線維化作用が皮膚の増殖性病変に影響する可能性は理論上考えられますが、検証されていません。

参考として、同じ予測上位には以下の疾患が挙がっています。

| 順位 | 疾患 | スコア | エビデンスレベル | 備考 |
|------|------|--------|------------------|------|
| 2 | 脂漏性皮膚炎 | 99.98% | L5 | 抗アレルギー作用による皮膚炎症への理論的関連のみ |
| 3 | 声帯ポリープ | 99.98% | L5 | 声帯瘢痕に対するトラニラスト投与の症例報告が1件あるが、評価は不十分 |
| 7 | 歯肉腫（エプーリス） | 99.98% | L4 | 歯肉線維芽細胞での in vitro 研究あり |

## 安全性に関する考慮事項

- **薬物相互作用・薬理学的情報**：トラニラストはヒトの TRPV2 を標的とするリガンドとして記録されています。相互作用の重症度レベルは不明です。なお、気管支喘息のほか、ケロイドおよび肥厚性瘢痕の治療に承認されている国があるとの記載があります。

その他の警告・禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
脂漏性角化症に対する臨床試験も文献もなく、予測はモデルのスコアのみに基づいています。日本での有効な承認もなく、安全性情報（警告・禁忌）も未確認のため、現時点では開発を進められません。

**進める場合に必要なもの：**
- PMDA 添付文書から警告・禁忌を取得し、安全性スクリーニングを実施する（必須）
- DrugBank などから詳細な作用機序（MOA）を取得する
- TGF-β 抑制と脂漏性角化症の病態との関連を検証する前臨床研究・文献調査
- 投与経路（外用または経口）の適合性評価
- 現在有効な承認がないため、製造販売の再開や開発主体に関する規制面の確認
- エビデンスのより強い候補（例：エプーリスなど線維化関連疾患）との優先順位比較
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

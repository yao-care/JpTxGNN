# レボカバスチン：点鼻液からアレルギー性蕁麻疹へ

## 一言要約

レボカバスチンは選択的ヒスタミン H1 受容体拮抗薬で、日本では点鼻液（リボスチン）として市販されています。
TxGNN モデルは**アレルギー性蕁麻疹 (Allergic Urticaria)** に有効である可能性を予測していますが、根拠は間接的なものにとどまります。
関連する臨床試験の登録は **0 件**で、文献は **3 編**あります。いずれも標的疾患そのものを直接検証した研究ではありません。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、レボカバスチンは選択的ヒスタミン H1 受容体拮抗薬として知られています。

アレルギー性蕁麻疹では、肥満細胞から放出されたヒスタミンが膨疹と紅斑（発赤）を引き起こします。H1 受容体を遮断する薬は、この経路に作用します。第二世代 H1 拮抗薬がアレルギー性鼻結膜炎や慢性蕁麻疹の対症療法に広く使われていることも、機序面の妥当性を支持します。

一方で、レボカバスチンは局所投与（点鼻）の製剤として市販されています。蕁麻疹の治療に必要な全身曝露が得られるかは不明です。現時点の裏付けは、アレルギー性鼻炎の抗原誘発試験、H1 拮抗薬のクラス全体の薬理、市販後の副作用報告に限られます。

## 結論と次のステップ

**決定：Hold**

**理由：**
機序的には妥当ですが、アレルギー性蕁麻疹を直接検証した試験や文献はなく、根拠は間接的です。また、日本の添付文書に基づく警告・禁忌が未確認のため、安全性スクリーニングに進めません。

なお、予測第 2 位の「酒さ性結膜炎」（スコア 99.17%）は、臨床試験も文献もなくモデル予測のみ（L5）です。酒さ性結膜炎は主に瞼板腺機能不全と炎症が原因で、ヒスタミン主体の病態ではないため、現時点では保留とします。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（ブロッキング事項）
- 詳細な作用機序データ（MOA）の補充
- 点鼻製剤で蕁麻疹に必要な全身曝露が得られるかの評価（他の投与経路の検討を含む）
- 蕁麻疹を対象とした臨床データまたは前臨床データの収集

## PMDA クエリ結果についての注記

クエリログによると、`ｱｾﾄｱﾐﾉﾌｪﾝ`（アセトアミノフェン）の PMDA 検索が **0 件**を返しています。アセトアミノフェンは日本で複数の承認を持つ主要薬剤であるため、この結果は以下のいずれかが原因と考えられます：

- 検索文字列が半角カタカナのため、PMDA 側の正規化処理で不一致が発生している
- DrugBank クエリは 1 件成功しているため、薬物自体の識別はできている

**次のアクション**：PMDA を全角カタカナ `アセトアミノフェン` または INN `Acetaminophen` で再クエリしてデータを取得してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による予測適応症が存在せず、PMDA・安全性・MOA のいずれのデータも取得されていないため、老藥新用評価の前提条件を満たしていません。

**進める前に必要なもの：**

1. **PMDA 再クエリ**：全角カタカナ `アセトアミノフェン` または英語 `Acetaminophen` で再検索し、承認番号・適応症・剤形を取得
2. **DrugBank データ取得**：DrugBank クエリは成功（1 件）しているため、`drugbank_id` を確定し MOA・警告・禁忌を収集
3. **TxGNN 予測の再実行**：DrugBank ID が確定したら TxGNN パイプラインを再実行して予測適応症リストを生成
4. **Evidence Pack 再生成**：上記データが揃ってから Evidence Pack v5 を再生成し、本レポートを更新

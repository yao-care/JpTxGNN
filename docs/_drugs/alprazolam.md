# アルプラゾラム：抗不安薬から不眠症へ

## 一言要約

アルプラゾラムはベンゾジアゼピン系の薬で、日本では抗不安薬・マイナートランキライザー・催眠鎮静薬として使われてきました。
TxGNN モデルは**不眠症 (insomnia)** に有効である可能性を予測しています。ただし、不眠症に対する臨床試験の登録は **0 件**で、文献 17 編もほとんどが処方実態や安全性などの間接的な研究です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 抗不安薬、マイナートランキライザー、催眠鎮静薬 |
| 予測新規適応症 | 不眠症 (Insomnia) |
| TxGNN 予測スコア | 99.81% |
| エビデンスレベル | L4 |

| 承認番号数 | 14 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

アルプラゾラムは GABA-A 受容体を介した抑制性神経伝達を増強し、鎮静・催眠作用を示すベンゾジアゼピンです。詳細な作用機序データは今回の集計にはありません。上記は薬剤クラスに基づく一般的な理解です。

日本での承認区分にはすでに「催眠鎮静薬」が含まれています。不眠症は既存の薬理作用（鎮静・催眠）と近い領域にあり、機序の面では無理のない予測です。

ただし、不眠症の有効性を直接検証した試験は今回のデータにはありません。機序上の妥当性はあるものの、予測を裏づける実証データは不足しています。

## 安全性に関する考慮事項

添付文書の警告・禁忌は今回のデータに含まれていないため、必ず添付文書で確認してください。

- **禁忌・慎重投与が示唆される疾患（知識グラフ上の関係であり、添付文書の記載ではありません）**：閉塞隅角緑内障・開放隅角緑内障、睡眠時無呼吸症候群、肝疾患、腎疾患、胆嚢疾患、物質関連障害・依存症、肥満関連疾患など
- **薬物相互作用**（照会結果 100 件のうち主なもの）：
  - 重大（Major）：モルヒネ（リポソーム製剤を含む）。中枢神経・呼吸抑制の増強に注意が必要です
  - 中等度（Moderate）：アプレピタント、ブプロピオン、シメチジン、クラリスロマイシン、クロトリマゾール、ミコナゾール、ドロナビノール、エリグルスタット、メトクロプラミドなど。代謝（CYP 関連）や鎮静作用への影響が想定されます
  - 軽微（Minor）：制酸薬（水酸化アルミニウム、酸化マグネシウムなど）、ベタメタゾン、デキサメタゾンなど

## 結論と次のステップ

**決定：Hold**

**理由：**
- TxGNN スコアは高いものの、不眠症に対する臨床試験はなく、文献も間接的な研究にとどまります（L4）。
- 日本の承認はすべて整理済みで、依存・記憶障害・転倒などベンゾジアゼピン特有のリスクもあります。現時点では再利用候補として推進できません。

**進める場合に必要なもの：**
- 不眠症に対する RCT またはシステマティックレビューによる有効性・安全性の確認
- 添付文書（警告・禁忌）の取得と確認
- 作用機序データの補完
- 現行の不眠症治療薬との比較、および依存・離脱リスクの評価
- 日本での承認状況の確認（再承認や販売再開の可能性）

なお、同じ予測リストにある**広場恐怖症**（L1、複数の RCT とネットワークメタ解析あり）と**恐怖症性障害**（L2）は、不眠症よりエビデンスが充実しています。優先して評価する価値があります。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

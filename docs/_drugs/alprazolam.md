# アルプラゾラム：抗不安薬から不眠症へ

## 一言要約

アルプラゾラムは日本で抗不安薬・催眠鎮静薬として市販されているベンゾジアゼピン系薬剤です。TxGNN モデルは**不眠症 (insomnia)** に有効である可能性を予測しています（スコア 99.81%）。関連する臨床試験は 7 件、文献は 18 編ありますが、不眠症に対する有効性を直接検証した第 2/3 相 RCT はなく、エビデンスは限定的です。

| 項目 | 内容 |
|------|------|
| 既存適応症 | 抗不安薬、マイナートランキライザー、催眠鎮静薬（承認テキストは薬効分類の記載） |
| 予測新規適応症 | 不眠症 (insomnia) |
| TxGNN 予測スコア | 99.81% |

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）は取得できていません。既知の情報では、アルプラゾラムは GABA-A 受容体の陽性アロステリックモジュレーターです。神経の抑制性伝達を強め、抗不安作用と鎮静・催眠作用を示します。この鎮静・催眠作用は、短期的な入眠促進につながると考えられます。

日本の承認テキストには「催眠鎮静薬」という薬効分類が含まれており、睡眠に関わる薬理作用は既存の位置づけと近い関係にあります。ただし、これは薬効分類の記載です。不眠症が添付文書の効能・効果に含まれるかどうかは、今回のデータでは確認できません。

不眠症に対する直接的な根拠は、観察研究と比較研究にとどまります。提供された試験の中に、専用の第 2/3 相 RCT はありません。機序面の妥当性は高い一方、臨床的な裏づけは弱い状態です。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。警告・禁忌・薬物相互作用のデータは、今回のデータでは取得できていません。

参考として、提供された文献では、ベンゾジアゼピン系薬剤の長期使用に伴う依存、高齢者の転倒、記憶障害のリスクが指摘されています（PMID 37984023、35493764、37801512）。不眠症への適用を検討する場合は、特に慎重な評価が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
不眠症に対する予測スコアと機序面の妥当性は高い一方、直接的な臨床試験がなく、エビデンスは観察研究や比較研究にとどまります。安全性の一次情報である添付文書も未取得のため、進める判断はできません。

なお、同じ Evidence Pack 内の「広場恐怖症」は、複数の RCT とネットワークメタ解析に支えられており、エビデンスレベルは L1 です。優先的に検討する価値があります。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・相互作用）の取得と、不眠症が効能・効果に含まれるかの確認
- DrugBank からの作用機序（MOA）データの補完
- 不眠症を対象としたアルプラゾラムの RCT または系統的レビューの探索
- 高齢者・肝疾患患者など、依存や転倒のリスクが高い集団の安全性モニタリング計画

本レポートの結果は研究参考用であり、医療上の助言ではありません。老薬新用の候補は、臨床的な検証を経てから応用する必要があります。

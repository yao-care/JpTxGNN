# プリミドン：点頭てんかんから三叉神経腫瘍へ

## 一言要約

プリミドンは抗てんかん薬で、日本では点頭てんかんの治療に使われています。
TxGNN モデルは**三叉神経腫瘍 (Trigeminal Nerve Neoplasm)** に有効である可能性を予測しています。ただし、これを支持する臨床試験と文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。プリミドンは抗てんかん薬で、代謝物のフェノバルビタールと PEMA が GABA-A 受容体とナトリウムチャネルを調節すると考えられています。この作用は神経の興奮を抑えるもので、てんかん発作の抑制には合理的です。

一方、腫瘍に対する抗腫瘍作用の機序は確立されていません。既存適応症（てんかん）と予測適応症（神経腫瘍）は病態が大きく異なります。機序面の裏付けも弱く、このスコアはモデル上の関連性を示すだけで、臨床的な妥当性を示すものではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
三叉神経腫瘍については、臨床試験も文献もなく、抗腫瘍作用の機序的根拠も見当たりません。予測スコアは高くても、実質的な裏付けはない状態です。また、PMDA 添付文書の警告・禁忌が未取得のため、安全性の一次スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と整理
- 詳細な作用機序データ（DrugBank など）の補完
- 三叉神経腫瘍に対する前臨床または臨床研究の有無の再調査
- 参考：同じ予測リストには、反射てんかん系の候補（startle epilepsy、audiogenic seizures、reading seizures など）があります。これらは機序が既存適応症に近く、動物実験や症例報告がある候補が含まれ、エビデンスレベルは L4、推奨は「Research Question」です。優先して検討する価値があります。
- 三叉神経痛は、機序的には妥当ですが、文献が取得できていません。

本レポートは研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的な検証を経てから適用する必要があります。

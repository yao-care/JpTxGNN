# アリピプラゾール：統合失調症から大うつ病性障害（Major Affective Disorder）へ

## 一言要約

アリピプラゾールは、元々統合失調症の治療薬として使用され、日本では双極性障害の躁症状やうつ病・うつ状態にも適応を持っています。
TxGNN モデルは**大うつ病性障害 (Major Affective Disorder)** に有効である可能性を予測しており、今回まとめたデータでは **36 件の臨床試験**と **19 編の文献**がこの方向性に関連しています。ただし、日本の既存ラベルがすでにうつ病・うつ状態を含むため、本件は真の再利用というより、適応内またはそれに近いシグナルです。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank 由来）は取得できていません。ただし、今回の解析では、アリピプラゾールはドパミン D2 受容体およびセロトニン 5-HT1A 受容体の部分作動薬であり、5-HT2A 受容体の拮抗薬として、モノアミン神経伝達を調節すると整理されています。

この作用により、既存の抗うつ薬で効果が不十分な治療抵抗性うつ病に対して、増強療法（上乗せ）として効果を示すと考えられます。日本の既存ラベルにもうつ病・うつ状態が含まれており、統合失調症や双極性障害の躁症状で確立された薬理作用が、気分障害にも適用できる点で機序的な整合性があります。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**：起立性低血圧、てんかん、高血糖・糖尿病（糖尿病性ケトアシドーシスを含む）、好中球減少症・無顆粒球症・白血球減少症、脂質異常症、肥満、心筋梗塞・冠動脈疾患、心伝導障害、脳血管障害、悪性症候群などが挙げられています。これは知識グラフ由来の情報で、添付文書の記載ではありません。
- **薬物相互作用**：100 件が検出されました。重大（Major）はブプロピオンです。中等度には、血糖降下薬（メトホルマン、ピオグリタゾン、アカルボース、アログリプチン、カナグリフロジンなど）、抗コリン薬（アトロピン、ヒヨスチアミン）、CYP 阻害薬（クラリスロマイシン、シメチジン）、エピネフリン、シサプリドなどが含まれます。

添付文書の警告・禁忌の正式な情報は取得できていないため、添付文書を必ず確認してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
大うつ病性障害の補助療法として、完了した複数の Phase 3 二重盲検試験と、メタ解析を含む多数の文献があり、エビデンスは強固です（L1）。ただし、日本の既存ラベルがすでにうつ病・うつ状態を含むため、新規性は限定的で、安全性データも不足しています。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを完了すること
- 詳細な作用機序データ（DrugBank）の補完
- 現在有効な日本の承認がないため、販売状況と承認の現状を確認すること
- 血糖、脂質、体重、好中球数などのモニタリング計画、および併用薬（特にブプロピオン）の管理方針

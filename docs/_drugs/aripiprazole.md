# アリピプラゾール：統合失調症から大うつ病性障害（major affective disorder）へ

## 一言要約

アリピプラゾールは、日本で統合失調症、双極性障害における躁症状、うつ病・うつ状態を適応とするドパミン受容体部分作動薬です。
TxGNN モデルは **major affective disorder（大うつ病性障害を含む気分障害）** に有効である可能性を予測しています。
この方向性については **50 件の臨床試験**と **20 編の文献**が登録されており、大うつ病性障害での Phase 3 ランダム化比較試験（RCT）も完了しています。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データはありません。ただし日本の承認情報では、アリピプラゾールは「ドパミン受容体部分作動薬、セロトニン受容体作動/拮抗薬」に分類されています。
Evidence Pack の機序説明では、ドパミン D2 / セロトニン 5-HT1A の部分作動作用と 5-HT2A 拮抗作用を持つとされています。

この薬理プロファイルは、抗うつ薬への上乗せ（増強療法）や双極性障害での使用と整合します。
補足として、日本の既存適応症にはすでに「うつ病・うつ状態」が含まれています。予測された適応症のうち、うつ病領域は実質的に既承認範囲と重なります。
本当に「新規」と言えるかどうかは、承認範囲の精査が必要です。

大うつ病性障害での増強療法については、システマティックレビュー、ネットワークメタ解析、Phase 3/4 試験が支持しています。特に完了済みの Phase 3 RCT（VAST-D、ASC-01）が根拠になっています。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
大うつ病性障害では、完了済みの Phase 3 RCT（VAST-D、ASC-01）が 2 件あり、複数のメタ解析も増強療法を支持しているため、エビデンスは L1 です。
一方、PMDA 添付文書の警告・禁忌が未取得で、機序データも不足しています。そのため無条件の Go にはせず、ガードレール付きとしました。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌・相互作用情報の取得と、安全性スクリーニング（現状は未実施）
- 日本の既承認適応症（うつ病・うつ状態）と予測適応症の重なりの精査、および未承認部分の切り分け
- DrugBank からの詳細な作用機序（MOA）データの補充
- 中止された Phase 3 試験（エスシタロプラム併用）の中止理由の確認

**その他の予測候補について：**
抜毛症（trichotillomania）は L3 で、小規模な非盲検試験と症例報告があり、Phase 2 RCT は募集前です。アリピプラゾール自体が衝動制御・強迫行動を誘発した報告もあるため、研究課題として扱います。
それ以外の予測（希少先天性症候群など）は、試験も文献もないか機序上の関連が不明で、L5 の Hold です。

本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的検証を経て初めて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ニロチニブ：皮膚線維肉腫 (Dermatofibrosarcoma protuberans) への再利用可能性

## 一言要約

ニロチニブは日本で「タシグナカプセル50mg」として市販されている薬です。ただし、今回のデータには既存適応症の記載がありません。
TxGNN モデルは**皮膚線維肉腫 (Dermatofibrosarcoma protuberans, DFSP)** に有効である可能性を予測しています。
現時点のエビデンスは **臨床試験 0 件**、**文献 1 編**（総説）で、モデル予測と機序上の推論が中心です。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) はありません。ただし予測の機序的根拠は次のように整理されています。

DFSP は COL1A1-PDGFB 融合遺伝子により、PDGFRB が恒常的に活性化することで生じる腫瘍です。ニロチニブは PDGFR のほか BCR-ABL と KIT を阻害するため、この経路を遮断できる可能性があります。DFSP の承認適応症では、同様に PDGFR を阻害するイマチニブが使われています。

この機序上の推論が、TxGNN の高スコアと整合しています。ただし、ニロチニブ自体の DFSP に対する臨床データは今回の Evidence Pack にはありません。

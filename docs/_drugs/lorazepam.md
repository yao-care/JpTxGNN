# ロラゼパム：神経症における不安から三叉神経腫瘍へ

## 一言要約

ロラゼパムはベンゾジアゼピン系の抗不安薬で、元々は神経症における不安の治療に使用されていました。
TxGNN モデルの第 1 位予測は**三叉神経腫瘍 (trigeminal nerve neoplasm)** ですが、臨床試験も文献もなく、**モデル予測のみ**で機序的な裏付けもありません。
一方、第 2 位の**不眠症 (insomnia)** には 18 編の文献があり、検討に値する候補です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 神経症における不安（抗不安薬、抗けいれん薬、マイナートランキライザー） |
| 予測新規適応症 | 三叉神経腫瘍 (trigeminal nerve neoplasm) |
| TxGNN 予測スコア | 99.87% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認はすべて取り消し済み（現在市販なし） |
| 承認番号数 | 7 件（すべて取り消し） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データは収録されていません。ただし既知の情報では、ロラゼパムは GABA-A 受容体の正のアロステリックモジュレーターで、抗不安・鎮静・抗けいれん作用を持ちます。

第 1 位の三叉神経腫瘍については、抗腫瘍作用につながる機序は知られていません。この予測は機序的に裏付けられておらず、せいぜい症状緩和の示唆にとどまります。

一方、下位の予測には機序的に説明しやすいものがあります。不眠症は GABA-A を介した鎮静と入眠潜時の短縮、反射てんかん系（読書誘発発作、驚愕てんかんなど）は GABA 作用による発作閾値の上昇で説明できます。ただし、これらは症状への対処であり、疾患そのものの治療ではありません。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の情報）**：添付文書の記載ではなく、知識グラフ由来の情報です。肝不全、肝性脳症・肝性昏睡、腎疾患、急性閉塞隅角緑内障を含む緑内障、閉塞性睡眠時無呼吸症候群を含む睡眠時無呼吸、呼吸不全、ポルフィリン症、物質依存・乱用などが挙げられています。
- **薬物相互作用**：100 件の相互作用が記録されています。重大（Major）なものはモルヒネ、リポソーム化モルヒネで、中等度（Moderate）にはブプロピオン、ドロナビノール、ナビロン、メトクロプラミド、アヘン、シブトラミン、テデュグルチドなどがあります。制酸薬（酸化マグネシウム、水酸化アルミニウム、炭酸カルシウムなど）は軽度（Minor）です。
- **依存・耐性**：不眠症などへの長期使用では、依存や耐性に注意が必要です。

添付文書の警告・禁忌の内容は確認できていないため、詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 第 1 位の三叉神経腫瘍には臨床試験も文献もなく、抗腫瘍作用の機序的根拠もありません。モデル予測のみ（L5）で、日本の販売承認もすべて取り消されています。
- 参考までに、他の予測候補の状況は以下のとおりです。
  - 不眠症：L3、Research Question。ロラゼパムの RCT が 1 件あります。
  - 反射てんかん系（読書誘発発作、thinking seizures、micturation-induced seizures など）：L4、機序的には妥当ですが、エビデンスは間接的です。

**進める場合に必要なもの：**
- 三叉神経腫瘍については、機序の裏付けとなる前臨床・臨床データ（なければ追加検討は不要）
- 添付文書（PMDA）の警告・禁忌の取得と、安全性の事前確認
- DrugBank からの作用機序（MOA）データの補充
- 不眠症を優先候補として検討する場合は、現行の適応を持つ他の催眠薬と比較する文献精査と、依存・耐性・相互作用リスクの評価
- 市販が取り消されているため、再導入や製剤供給の可否の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

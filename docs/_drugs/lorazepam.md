# ロラゼパム：神経症における不安から三叉神経腫瘍へ

## 一言要約

ロラゼパムは GABA-A 受容体に作用するベンゾジアゼピン系の抗不安薬で、日本では神経症における不安の治療に使われています。
TxGNN モデルは**三叉神経腫瘍 (trigeminal nerve neoplasm)** に有効である可能性を予測していますが、関連する臨床試験も文献も **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

ロラゼパムは GABA-A 受容体の陽性アロステリックモジュレーターです。GABA による抑制性シグナルを強め、抗不安・鎮静・抗けいれん作用を示します。詳細な作用機序データ（MOA）は現在登録されていません。

この作用機序に、既知の抗腫瘍メカニズムは見当たりません。既存適応症（神経症における不安）と三叉神経腫瘍にも、機序上の直接的なつながりは確認できません。高いスコアはグラフ構造に基づくモデル上の予測であり、機序面・臨床面の裏付けはありません。妥当性は現時点では低いと判断します。

## 結論と次のステップ

**決定：Hold**

**理由：**
三叉神経腫瘍については臨床試験・文献ともに 0 件で、モデル予測のみ（L5）です。ロラゼパムに抗腫瘍作用の機序も見当たらないため、現時点で進める根拠はありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現在ブロッキングの欠落データ）
- DrugBank からの作用機序（MOA）データの補完
- 三叉神経腫瘍に対する前臨床または機序研究の有無の調査
- 参考：同じ予測リストの 2 位「不眠症 (insomnia)」には、臨床試験 20 件と文献 17 編が紐づいています。優先的に検討する候補は、こちらのほうが適切です。

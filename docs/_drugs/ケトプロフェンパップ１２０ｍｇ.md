# ケトプロフェンパップ 120MG：基礎データ不足により評価保留

## 一言要約

「ケトプロフェンパップ 120MG」は外用消炎鎮痛薬（湿布剤）の剤形・規格を含む製品記述名ですが、本 Evidence Pack には原承認適応症・TxGNN 予測新規適応症・安全性データのいずれも含まれていません。PMDA データベース検索では登録が確認されず、DrugBank クエリは 1 件ヒットしたものの DrugBank ID の確定には至っていません。薬物再利用評価に必要な基礎情報が欠如しているため、現時点では評価を実施できない状態です。

## データ品質に関する背景

本評価が実施できない主な理由は、入力クエリの形式とデータ収集結果にあります。

**入力名称の問題：** `ケトプロフェンパップ１２０ＭＧ` は INN（一般名）ではなく、剤形（パップ剤）と規格（120MG）を含む製品記述形式の全角文字列です。PMDA・DrugBank のいずれのデータベースも INN または半角英字での照合を前提とするため、マッチング精度が著しく低下した可能性があります。

**クエリ結果の整合性：** PMDA クエリは 0 件（登録なし）、DrugBank クエリは 1 件ヒットしたにもかかわらず DrugBank ID が確定できていません。この不整合は、DrugBank 側で部分一致はあったが信頼度が閾値に達しなかったことを示唆します。

**TxGNN 予測なし：** DrugBank ID が確定していないため、TxGNN 予測パイプラインが実行されておらず、再利用候補の列挙も行われていません。

---

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN 予測適応症・原承認適応症・安全性データのいずれも取得できておらず、薬物再利用評価の前提となる基礎情報がすべて欠如しています。現状の Evidence Pack では有意な評価を行うことが不可能です。

**進める場合に必要なもの：**
- INN「Ketoprofen（ケトプロフェン）」の半角英字クエリで PMDA・DrugBank を再実行し、DrugBank ID（例：DB01009）を確定する
- PMDA 仿単 PDF を取得して承認適応症・警告・禁忌を抽出し、安全性 Gap（DG001）を解消する
- DrugBank ID 確定後に TxGNN 予測パイプラインを再実行し、予測新規適応症を生成する
- MOA データ（DG002）を DrugBank API から取得し、機序関連性分析を実施する

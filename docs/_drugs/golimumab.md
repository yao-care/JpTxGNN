# ゴリムマブ：関節リウマチから リウマチ性血管炎へ

## 一言要約

ゴリムマブは抗 TNF-α 完全ヒトモノクローナル抗体で、元々は関節リウマチなどの炎症性関節疾患に使われてきました。
TxGNN モデルは**リウマチ性血管炎 (Rheumatoid Vasculitis)** に有効である可能性を予測していますが、直接の裏付けは乏しく、関連する臨床試験は **1 件**（間接的な内容）、文献は **6 編**（症例報告・レビュー中心）にとどまります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 関節リウマチ（ほか乾癬性関節炎、強直性脊椎炎、潰瘍性大腸炎など） |
| 予測新規適応症 | リウマチ性血管炎 (Rheumatoid Vasculitis) |
| TxGNN 予測スコア | 99.73% |
| エビデンスレベル | L4 |
| 日本市販状況 | 承認は 2 件とも失効（取消）の状態 |
| 承認番号数 | 2 件 |
| 推奨決定 | Hold |

※ 既存適応症は、日本の承認情報に適応症の記載がなかったため、知識グラフ上の適応症情報に基づいています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ゴリムマブは可溶型・膜結合型の TNF-α を中和する抗体医薬で、関節リウマチなどの炎症性疾患で有効性が確認されています。

リウマチ性血管炎は、関節リウマチに伴う血管の炎症性合併症です。TNF-α は関節リウマチと血管炎症の両方で中心的なサイトカインとされており、TNF-α を阻害するゴリムマブは、機序的には適用可能と考えられます。

ただし、リウマチ性血管炎そのものを対象とした直接的な研究は見当たりません。現時点の根拠は、関節リウマチや他の血管炎に関する間接的な報告と、モデル予測にとどまります。

## 安全性に関する考慮事項

- **薬物相互作用**：相互作用は合計 100 件が確認されています。主なものは次のとおりです。
  - **重大 (Major)**：副腎皮質ステロイド（ヒドロコルチゾン、プレドニゾロン、プレドニゾン、デキサメタゾン、ベタメタゾン、トリアムシノロン、ブデソニド）、デフェリプロン、放射性医薬品・放射性標識抗体（イオベングアン (I-131)、イブリツモマブ チウキセタン、トシツモマブ）
  - **中等度 (Moderate)**：メトロニダゾール、チニダゾール、ロスバスタチン、シンバスタチン
  - **軽微 (Minor)**：亜鉛製剤（硫酸亜鉛、酢酸亜鉛、グルコン酸亜鉛）

警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
リウマチ性血管炎に対する直接的な臨床試験や研究はなく、根拠はモデル予測と間接的な症例報告・レビューに限られます（L4）。そのため、現段階では研究課題として保留とするのが妥当です。

なお、同じ予測リストの「炎症性脊椎症」と「多関節型若年性特発性関節炎」には、完了した第 3 相 RCT があります（L1）。これらは既承認の適応症と重なる領域です。

**進める場合に必要なもの：**
- リウマチ性血管炎患者を対象とした、ゴリムマブまたは抗 TNF 薬の直接的な臨床データ（症例集積、後ろ向きコホートなど）
- 詳細な薬物作用機序データ（MOA）
- 添付文書に基づく警告・禁忌の確認
- 日本での承認状況の再確認（現在のデータでは 2 件とも失効）
- ステロイド併用時の感染リスクを含む安全性モニタリング計画
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# テガフール：胃癌から大腸腫瘍へ

## 一言要約

テガフールは経口フッ化ピリミジン系の抗がん薬（5-FU のプロドラッグ）で、元々胃癌の治療に使用されていました。
TxGNN モデルは**大腸腫瘍 (Colonic Neoplasm)** に有効である可能性を予測しており、現在 **16 件の臨床試験**と **20 編の文献**がこの方向性に関連しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 胃癌（承認適応症の本文データはなし。胃癌・胃腫瘍・びまん性胃腺癌などが知識グラフ上の既存適応症） |
| 予測新規適応症 | 大腸腫瘍 (Colonic Neoplasm) |
| TxGNN 予測スコア | 99.90% |
| エビデンスレベル | L1 |
| 日本市販状況 | 承認は全て取消済み（市販中の承認なし） |
| 承認番号数 | 6 件（すべて取消） |
| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の薬理情報によると、テガフールは主に CYP2A6 で活性化される経口 5-FU プロドラッグです。代謝物がチミジル酸合成酵素を阻害し、RNA/DNA にも取り込まれます。なお、この説明はテガフールの既知の薬理に基づく推定です。

胃癌と大腸腫瘍はどちらも消化管の腺癌で、5-FU 系の治療が標準的な基盤となっています。そのため、機序的に大腸腫瘍にも適用できる可能性があります。

実際に、テガフール・ウラシル配合剤（UFT）や S-1 を用いた大腸癌の術後補助化学療法の大規模試験が多数行われています。ただし、これらは配合剤による試験であり、テガフール単剤の試験ではありません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
結腸直腸癌に対し、UFT や S-1 などテガフール含有レジメンの完了した Phase 3 RCT が複数あり、エビデンスレベルは L1 です。ただし、これらは配合剤での試験であり、テガフール単剤の試験ではありません。また、日本の承認は全て取消済みで、添付文書の安全性情報も取得できていません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の取得と、安全性スクリーニングの実施（現時点で最優先の不足データ）
- DrugBank などからの詳細な作用機序データ (MOA) の補充
- 単剤か配合剤か、既存の承認状況（取消済み）を踏まえた開発形態の整理
- 特定集団（高齢者、腎機能低下者など）の安全性モニタリング計画

なお、予測順位 2 位以下（盲腸の絨毛腺腫、盲腸神経内分泌腫瘍 G1、結腸脂肪腫など）は、モデル予測のみか間接的な症例報告のみで、機序的な裏付けも弱いため、現時点では Hold が妥当です。

# テガフール：既存適応症データなしから大腸腫瘍へ

## 一言要約

テガフールは 5-FU のプロドラッグで、UFT やティーエスワン配合剤の成分として日本で市販されています。ただし今回のデータには、承認適応症の文言が含まれていません。
TxGNN モデルは**大腸腫瘍 (Colonic Neoplasm)** に有効である可能性を予測しています。現在、**30 件の臨床試験**（完了した Phase 3 は 6 件）と **20 編の文献**がこの方向性に関連しています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、テガフールは経口の 5-フルオロウラシル (5-FU) プロドラッグで、主に肝臓の CYP2A6 で 5-FU に変換されます。生成された 5-FU がチミジル酸合成酵素を阻害し、腫瘍細胞の DNA/RNA 合成を妨げると考えられます。これが大腸癌への適用を機序面から支えています。

大腸癌は 5-FU 系薬剤が標準的に使われてきた領域です。収集された文献では、UFT/LV（テガフール・ウラシル + ロイコボリン）が日本で結腸癌の標準的な術後補助化学療法の一つとして広く使われていると述べられています（PMID 26347106）。関連する試験も、UFT 単独、UFT/LV、S-1（テガフール含有配合剤）と多様です。

なお、日本の承認適応症の文言がデータに含まれていないため、大腸癌がすでに承認範囲に入っているかは本レポートでは確認できません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
完了した Phase 3 試験が複数あり、UFT/LV や S-1 による大腸癌補助療法の試験が日本を中心に蓄積されているため、エビデンスレベルは L1 です。一方、日本の添付文書の警告・禁忌が未確認で、作用機序データと承認適応症の文言も欠けています。安全性の最終確認ができていないため、条件付きの推進としました。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（安全性スクリーニングを進めるうえでの必須項目）
- 承認適応症の文言の確認（大腸癌がすでに承認範囲かどうかの判断）
- DrugBank からの作用機序 (MOA) データ補完
- DPYD 欠損など特定集団の安全性モニタリング計画

**その他の予測適応症（参考）：**
- 盲腸疾患 (L4) は、盲腸癌・虫垂癌の症例報告のみです。広い病名で範囲が曖昧なため、研究課題として扱います。
- 直腸 S 状部移行部腫瘍 (L4) は、有害事象の症例報告 1 件のみで、有効性の根拠にはなりません。
- 盲腸絨毛腺腫、盲腸神経内分泌腫瘍 G1、結腸脂肪腫、結腸平滑筋腫、盲腸良性腫瘍、結腸リンパ管腫、結腸海綿状血管腫はいずれも L5 で、機序上も 5-FU 系化学療法の適用は考えにくく、Hold としました。

本レポートは研究参考用で、医療上の助言ではありません。老藥新用の候補は、臨床的な検証を経て初めて適用できます。
## 免責事項

臨床応用の前に臨床的検証が必要です。

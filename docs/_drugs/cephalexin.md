# Cephalexin：經典第一代頭孢黴素的評估

## 一言まとめ

Cephalexin 是第一代頭孢黴素類口服抗生素，廣泛用於治療細菌感染。
目前**無新適應症預測**，應繼續在核准適應症範圍內使用。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 淋菌感染症、歯周組織炎、猩紅熱 |
| 予測新適応症 | 無 |
| TxGNN 予測スコア | 無 |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認あり（有効 12 件） |
| 承認番号数 | 12 件 |
| 推奨判断 | Hold |

## この予測が妥当な理由

Cephalexin 是一種經典的第一代頭孢黴素類抗生素，其特性包括：

1. **作用機轉**：抑制細菌細胞壁肽聚糖合成，對革蘭氏陽性菌活性較強
2. **藥物動力學**：口服吸收良好，主要經腎臟排泄
3. **臨床定位**：常用於輕中度皮膚軟組織感染、泌尿道感染、呼吸道感染

由於 TxGNN 模型未預測到新適應症，這可能表示：
- Cephalexin 的藥理特性較為專一，主要限於抗菌作用
- 知識圖譜中未發現與其他疾病的顯著關聯
- 該藥物在其核准用途上已被充分研究和使用

## 安全性に関する考慮事項

**重要警語**：
- 對 cephalosporin 類藥物過敏者禁用
- 青黴素過敏者可能有交叉過敏反應（約 1-5%）
- 可能引起胃腸道不適（腹瀉、噁心、嘔吐）
- 長期使用可能導致菌群失調或二重感染

**藥物交互作用**：
- 與 Metformin（Moderate）：Cephalexin 可能增加 metformin 血中濃度，增加乳酸中毒風險
- 與 Balsalazide（Moderate）：可能影響 balsalazide 的代謝
- 與 Picosulfuric acid（Moderate）：可能降低瀉藥效果
- 與 Warfarin（需監測）：可能影響凝血功能
- 多種藥物具有未知等級交互作用（如 Calcitriol、Pantoprazole、Doxycycline、Morphine、Omeprazole 等）

**特殊族群注意事項**：
- 腎功能不全：需根據肌酸酐清除率調整劑量
- 妊娠分級 B 類：動物研究未顯示胎兒風險，但人類研究數據有限
- 哺乳期：可分泌至乳汁，但通常認為可安全使用

## 結論と次のステップ

**判断：Hold**

**理由：**
目前無新適應症預測。Cephalexin 作為經典的第一代頭孢黴素抗生素，其臨床定位清晰，主要用於敏感細菌引起的感染症。在沒有新的預測適應症的情況下，應繼續在現有核准範圍內使用。

**推進に必要な事項：**
- 維持現有適應症的臨床使用
- 持續監測抗藥性變化
- 關注抗生素管理原則（Antimicrobial Stewardship）
- 若有新的研究發現，可重新評估潛在新用途

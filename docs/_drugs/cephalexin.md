# Cephalexin：古典的な第一世代セフェム系抗生物質の評価

## 一言まとめ

Cephalexin（セファレキシン） は第一世代セフェム系の経口抗生物質で、細菌感染症の治療に広く用いられています。
現時点では**予測新適応症はなく**、承認された適応症の範囲内で引き続き使用すべきです。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 淋菌感染症、歯周組織炎、猩紅熱 |
| 予測新適応症 | なし |
| TxGNN 予測スコア | なし |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認あり（有効 12 件） |
| 承認番号数 | 12 件 |
| 推奨判断 | Hold |

## この予測が妥当な理由

Cephalexin は古典的な第一世代セフェム系抗生物質で、次の特性があります。

1. **作用機序**：細菌の細胞壁ペプチドグリカンの合成を阻害し、グラム陽性菌に対する活性が比較的強い
2. **薬物動態**：経口吸収が良好で、主に腎臓から排泄される
3. **臨床での位置づけ**：軽症から中等症の皮膚軟部組織感染症、尿路感染症、呼吸器感染症に多く用いられる

TxGNN モデルが新たな適応症を予測しなかったことから、次の可能性が考えられます。
- Cephalexin の薬理学的特性は特異性が高く、主に抗菌作用に限られる
- 知識グラフ上で他の疾患との顕著な関連は見つかっていない
- 本剤は承認された用途において十分に研究され、使用されている

## 安全性に関する考慮事項

**重要な警告**：
- cephalosporin 系薬剤に過敏症のある患者には禁忌
- ペニシリン過敏症の患者では交差過敏反応が起こる可能性がある（約 1-5%）
- 消化器症状（下痢、悪心、嘔吐）を起こすことがある
- 長期使用により菌交代症や二重感染を起こすことがある

**薬物相互作用**：
- Metformin（Moderate）：Cephalexin が metformin の血中濃度を上昇させ、乳酸アシドーシスのリスクを高める可能性がある
- Balsalazide（Moderate）：balsalazide の代謝に影響する可能性がある
- Picosulfuric acid（Moderate）：下剤の効果を低下させる可能性がある
- Warfarin（要モニタリング）：凝固機能に影響する可能性がある
- 多くの薬剤で重症度不明の相互作用がある（Calcitriol、Pantoprazole、Doxycycline、Morphine、Omeprazole など）

**特殊集団における注意事項**：
- 腎機能障害：クレアチニンクリアランスに応じた用量調整が必要
- 妊娠カテゴリーB：動物試験では胎児リスクは示されていないが、ヒトでのデータは限られている
- 授乳期：乳汁中に移行するが、通常は安全に使用できると考えられている

## 結論と次のステップ

**判断：Hold**

**理由：**
現時点では予測新適応症はありません。Cephalexin は古典的な第一世代セフェム系抗生物質であり、臨床での位置づけは明確で、主に感受性菌による感染症に用いられます。新たな予測適応症がない状況では、現行の承認範囲内で引き続き使用すべきです。

**推進に必要な事項：**
- 現行適応症での臨床使用を維持する
- 耐性菌の動向を継続的にモニタリングする
- 抗菌薬適正使用（Antimicrobial Stewardship）の原則に留意する
- 新たな研究知見があれば、潜在的な新用途を再評価できる

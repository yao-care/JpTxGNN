# ジソピラミド：抗不整脈薬からトゥレット症候群へ

## 一言要約

ジソピラミドはクラスIa の抗不整脈薬で、日本では複数の剤形が市販されています。
TxGNN モデルは**トゥレット症候群 (Tourette syndrome)** に有効である可能性を予測していますが、関連する臨床試験も文献もなく、根拠は**モデル予測のみ**です。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) は登録されていません。ジソピラミドはナトリウムチャネル遮断作用と抗コリン作用をもつクラスIa の抗不整脈薬であり、この位置づけは予測情報の説明に基づきます。

トゥレット症候群のチックには、ドパミン系と線条体の神経回路が関わると考えられています。ジソピラミドの薬理作用とこの回路との間に、確立した関連は見つかっていません。したがって、この予測はナトリウムチャネル遮断や抗コリン作用から説明できるものではなく、TxGNN のグラフ予測だけに支えられています。機序面の妥当性は現時点で示せません。

## 結論と次のステップ

**決定：Hold**

**理由：**
トゥレット症候群への適用は、臨床試験・文献・機序的根拠のいずれもなく、モデル予測だけの段階です（L5）。抗コリン作用による副作用の懸念もあり、現時点では進める根拠がありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現状は安全性スクリーニングに進めない状態）
- DrugBank からの作用機序 (MOA) データの取得
- トゥレット症候群との機序的関連を示す前臨床または臨床データ

**参考：** 同じ予測リストのうち、多源性心房頻拍（順位 9）と特発性新生児心房粗動（順位 7）は、心房性不整脈への薬理作用として説明がつきます。ただし、多源性心房頻拍で見つかった文献は別の薬（ロルカイニド）を扱った症例報告で、直接の根拠にはなりません（L4、Research Question）。新生児心房粗動は新生児のデータがなく、小児の安全性も未確立です。優先的に検討するなら、こちらの心房性不整脈の方向が現実的です。

*本結果は研究参考用であり、医療上の助言ではありません。老薬新用の候補は、臨床的な検証を経て初めて応用できます。*
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

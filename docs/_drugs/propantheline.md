# Propantheline：消化性潰瘍から胃十二指腸炎へ

## 一言まとめ

Propantheline（プロパンテリン）は副交感神経遮断薬であり、もともと胃潰瘍、十二指腸潰瘍および胃炎の治療に用いられています。TxGNN モデルは、本剤が**胃十二指腸炎 (Gastroduodenitis)** に有効である可能性を予測しており、現在この方向性を支持する文献が **5 件**あります。

## この予測が妥当な理由

プロパンテリンは抗コリン薬で、副交感神経の作用を遮断することにより、胃酸分泌を減少させ、消化管の蠕動と攣縮を抑えます。これらの作用機序により、消化性潰瘍や胃炎の治療に有効な薬剤となっています。

胃十二指腸炎とは、胃と十二指腸に同時に炎症が起こる病態であり、その病態生理は胃潰瘍および十二指腸潰瘍と密接に関連しています。プロパンテリンは、以下の機序により胃十二指腸炎の治療に役立つ可能性があります。

1. 胃酸分泌を抑制し、酸性環境による粘膜への刺激を軽減する
2. 消化管の蠕動を抑え、機械的な損傷を低減する
3. 消化管の攣縮を緩和し、疼痛症状を軽減する

もとの適応症と今回予測された新適応症は、解剖学的部位および病態生理の点で非常に類似しているため、この予測には高い妥当性があります。

# ソラフェニブ：肝細胞癌・腎細胞癌から脂肪肉腫へ

## 一言要約

ソラフェニブは RAF、VEGFR、PDGFR、KIT などを阻害するマルチキナーゼ阻害薬で、元々は肝細胞癌、腎細胞癌、甲状腺癌などの治療に使用されていました。
TxGNN モデルは**脂肪肉腫 (Liposarcoma)** に有効である可能性を予測しており、現在 **1 件の臨床試験**（軟部肉腫を対象とした Phase 2）と **8 編の文献**がこの方向性に関連しています。ただし、脂肪肉腫への臨床効果は限定的で、組織型によって異なると考えられます。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、ソラフェニブは RAF、VEGFR、PDGFR、KIT を標的とするマルチキナーゼ阻害薬として知られています。腫瘍の血管新生と MAPK シグナル伝達を抑制することで、抗腫瘍効果を示すと考えられます。

既存適応症の肝細胞癌や腎細胞癌は、血管新生と RAF/MAPK 経路が腫瘍増殖に深く関わる腫瘍です。軟部肉腫でも同じ経路が関与しうるため、機序的には適用の可能性があります。実際、脱分化型脂肪肉腫の細胞株では、ソラフェニブが増殖と MAPK シグナルを抑制したという前臨床報告があります。

一方で、脂肪肉腫での臨床活性は控えめで、組織型に依存すると考えられています。軟部肉腫を対象とした Phase 2 試験は完了していますが、脂肪肉腫に絞った有効性は確認されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 軟部肉腫を対象とした完了済み Phase 2 試験はありますが、脂肪肉腫に絞った有効性データはなく、臨床活性は限定的で組織型に依存するとされています。
- 日本の販売は取り消し済みで、添付文書に基づく安全性の確認（警告・禁忌）も完了していないため、現時点では先に進められません。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と解析による安全性スクリーニング
- 詳細な作用機序データ (MOA) の補充
- 軟部肉腫試験（NCT00217620、S0505）の脂肪肉腫サブグループ結果の確認
- 日本での販売状況の確認（販売中止の経緯と、他社の後発品や再承認の可能性）
- 投与経路の適合性の確認（経口剤のみ）
## 免責事項

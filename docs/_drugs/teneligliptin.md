# テネリグリプチン：DPP-4 阻害薬から オプシスモディスプラシア (Opsismodysplasia) へ

## 一言要約

テネリグリプチンは DPP-4 阻害薬で、日本では錠剤 (通常錠・OD 錠) として市販されています。
TxGNN モデルは**オプシスモディスプラシア (Opsismodysplasia)** に有効である可能性を予測していますが、
関連する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階 (L5) です。

| エビデンスレベル | L5 |
| 日本市販状況 | ✓ 市販中 |
| 承認番号数 | 4 件 |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、テネリグリプチンは DPP-4 阻害薬に分類され、インクレチンシグナルを介して血糖に作用する薬です。

オプシスモディスプラシアは INPPL1 関連の骨系統疾患です。DPP-4 阻害との機序的な接点は見当たらず、今回の予測はナレッジグラフ上の近接性のみに基づくものと考えられます。現時点では、機序的な裏付けは得られていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験も文献もなく、機序的な裏付けも確認できないため、モデル予測だけでは進める根拠が足りません。また、安全性スクリーニングに必要な添付文書情報が未取得です。

**進める場合に必要なもの：**
- PMDA 添付文書 (警告・禁忌) の取得と解析（安全性スクリーニングの前提、ブロッキング）
- DrugBank からの作用機序 (MOA) データの取得
- 各予測疾患について、DPP-4 阻害と疾患病態の機序的関連を示す前臨床・機序研究の探索
- ClinicalTrials.gov、ICTRP、PubMed での再検索による関連試験・文献の確認
- 既存適応症の承認テキストの補完

*本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証を経ていません。*

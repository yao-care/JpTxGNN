# テネリグリプチン：2型糖尿病から骨異形成症 (Opsismodysplasia) へ

## 一言要約

テネリグリプチンは DPP-4 阻害薬で、元々 2 型糖尿病の治療に使用されていました。
TxGNN モデルは **Opsismodysplasia（オプシスモ異形成症）** に有効である可能性を予測していますが、
現時点で関連する臨床試験や文献はなく、**モデル予測のみ**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 2 型糖尿病 |
| 予測新規適応症 | Opsismodysplasia（オプシスモ異形成症） |
| TxGNN 予測スコア | 99.45% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は全て失効（取消済み） |
| 承認番号数 | 4 件 |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、テネリグリプチンは DPP-4 阻害薬で、インクレチンシグナルを増強することで 2 型糖尿病の血糖コントロールを改善します。DPP-4 のほか、DPP8 や DPP9 にも作用することが示されています。

一方、Opsismodysplasia は INPPL1 (SHIP2) 変異による骨格異形成症です。DPP-4 阻害とこの経路との間に、確立した関連は見当たりません。この予測は TxGNN モデルの出力のみに基づいており、機序的な裏付けは現時点で弱いと考えられます。

なお、同時に予測された他の候補（thiamine-responsive dysfunction syndrome、classic stiff person syndrome、focal stiff limb syndrome、各種限局性リポジストロフィー）も、いずれも L5 で臨床試験・文献はありません。stiff person 症候群は糖尿病との合併が多く、これが予測に影響した可能性がありますが、DPP-4 阻害の治療的役割は示されていません。

## 安全性に関する考慮事項

- **薬理学的ターゲット**：DPP-4、DPP-8、DPP-9 に作用します。

その他の安全性情報については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測新規適応症にはモデル予測以外の根拠（臨床試験、文献、機序的関連）がなく、エビデンスレベルは L5 です。また、日本での承認は全て取消済みで、現在市販されていません。

**進める場合に必要なもの：**
- DPP-4 阻害と INPPL1/SHIP2 経路との機序的関連を検討する前臨床データ
- 詳細な作用機序データ（MOA）の補充
- PMDA 添付文書の警告・禁忌情報の取得と安全性評価
- 取消済み承認の経緯の確認（再申請や他国での承認状況を含む）
- 他の上位候補（stiff person 症候群など）を含めた優先順位の再検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

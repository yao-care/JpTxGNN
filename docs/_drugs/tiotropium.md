# チオトロピウム：（既存適応症の記載なし）から閉塞性肺疾患へ

## 一言要約

チオトロピウム (Tiotropium) は長時間作用型の吸入抗コリン薬で、日本ではスピリーバの名称で 3 件の承認を持ち、市販されています。ただし、入力データには既存適応症の記載がありません。
TxGNN モデルは**閉塞性肺疾患 (obstructive lung disease)** に有効である可能性を予測しています。関連する臨床試験は **50 件**、文献は **20 編**で、完了した Phase 3 の RCT も複数含まれます。
COPD への使用は既に確立しているため、この予測は「新規の再利用シグナル」というより、既存用途の裏づけと見るのが妥当です。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) は入力に含まれていません。ただし、チオトロピウムは長時間作用型ムスカリン受容体拮抗薬 (LAMA) として知られています。気道平滑筋の M3 受容体を遮断し、コリン作動性の気管支収縮を抑えて持続的な気管支拡張をもたらします。

閉塞性肺疾患は、気道のコリン作動性緊張などによる気流閉塞を特徴とします。そのため、気管支拡張作用という機序は、この疾患群に直接当てはまります。この機序は、COPD を対象とした Phase 3 の RCT やシステマティックレビューでも支持されています。

先に述べたとおり、この薬は既に COPD に使用されています。予測スコアは高いものの、新しい適応症の発見というより既知の用途の再確認です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
完了した Phase 3 の RCT が複数あり、システマティックレビューも揃っているため、エビデンスは十分です（L1）。一方で、予測対象は既に確立した COPD であり、新規性は低いと判断します。また、日本の添付文書に基づく安全性情報が未取得です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の入手と整理。これは進行を止める要因です。
- 日本での既存適応症の確認と、承認適応症テキストの取得。
- 詳細な作用機序データ (MOA) の補完。
- 新規性を主張する場合は、喘息や嚢胞性線維症など、承認外の閉塞性気道疾患に焦点を絞った評価。

同じ予測リストの他の候補（順位 2、3、6〜10）は、研究がなく、機序上の根拠も乏しい状態でした。順位 2 の呼吸器奇形は、COPD や喘息の試験が誤って紐づいたとみられます。これらは Hold が妥当です。

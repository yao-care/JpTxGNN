## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による疾病予測結果がゼロ件であり、DrugBank ID・作用機序・既存適応症のいずれも未取得のため、再利用候補としての評価を開始できる状態ではありません。

**進める場合に必要なもの：**

- **DrugBank 同定**：「水酸化カルシウム」の INN（Calcium hydroxide）で DrugBank を再クエリし、`DB番号` と `MoA` を確定する
- **PMDA 仿單確認**：外用液としての承認有無を PMDA 医療用医薬品データベースで再調査（製剤名・成分名の表記揺れを考慮）
- **予測実行可能性の確認**：DrugBank ID が存在しない場合、TxGNN KG 予測の前提が満たされないため、KG への収載状況を確認する
- **適応領域の再定義**：水酸化カルシウムは歯科領域（根管治療）での実績が知られているが、本 Evidence Pack ではその情報が反映されていないため、適応症データの入力元を再検討する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

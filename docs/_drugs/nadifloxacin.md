# ナジフロキサシン：外用フルオロキノロン系抗菌薬からマラリアへ

## 一言要約

ナジフロキサシンは外用のフルオロキノロン系抗菌薬で、日本では軟膏製剤（アクアチム軟膏1%）が市販されています。
TxGNN モデルは**マラリア (malaria)** に有効である可能性を予測していますが、現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**です。
エビデンスはモデル予測のみ（L5）のため、推奨は **Hold** です。

## この予測が妥当である理由

ナジフロキサシンは、細菌の DNA ジャイレースとトポイソメラーゼ IV を阻害するフルオロキノロン系抗菌薬です。詳細な作用機序データは現在ありません。以下は既知の薬理に基づく推測です。

マラリア原虫（*Plasmodium*）のアピコプラストには、ジャイレース様の酵素が存在します。フルオロキノロン系薬剤はこの酵素を試験管内で阻害すると報告されています。これが、機序的に成り立ちうる唯一の接点です。

ただし、この関連性は未検証です。ナジフロキサシンは外用のみで使われているため、抗マラリア作用に必要な全身曝露が得られるかどうかも疑わしい状況です。剤形とマラリアの治療経路との適合性も未評価です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測は TxGNN のスコア（99.16%）のみに基づいており、臨床試験も文献もありません。外用のみの製剤で全身曝露が得られにくく、マラリアへの適用可能性は疑わしい状況です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提）
- DrugBank から作用機序（MOA）データを取得し、機序面の関連性を再評価する
- 熱帯熱マラリア原虫などに対する試験管内・前臨床データの確認
- 全身投与が可能な製剤・投与経路の有無の検討（外用のみの場合、適用可能性は低い）
- 臨床試験・文献の再検索

本結果は研究参考用であり、医療上の助言ではありません。臨床での検証が必要です。

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。

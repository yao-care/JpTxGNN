# ピロカルピンエン：予測適応症なし — データ不足により評価保留

## 一言要約

ピロカルピンエン（INN: ピロカルピン系薬物と推定）は Evidence Pack に既存適応症の記録がなく、TxGNN による新規適応症予測も得られていません。日本国内での承認実績はなく、DrugBank ID・作用機序・安全性情報のいずれも未取得です。現時点では再利用評価に必要なデータが揃っておらず、**Hold** を推奨します。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による新規適応症予測が存在せず、既存適応症・作用機序・安全性のいずれのデータも取得できていないため、再利用候補としての評価を実施できません。

**進める場合に必要なもの：**

- **INN の確定**：`ﾋﾟﾛｶﾙﾋﾟﾝｴﾝ`（半角カタカナ）の正式 INN を確認し、DrugBank ID を特定する
- **MOA データの取得**：DrugBank API または添付文書から作用機序を抽出する
- **安全性情報の収集**：PMDA 仿単 PDF から警告・禁忌を解析する
- **TxGNN 再クエリ**：正規化された INN（英語名）で予測を再実行し、候補適応症を取得する

## トフィソパム：不安・催眠鎮静から不眠症へ
{: .text-alpha }

## 一言要約

トフィソパムは、元々抗不安薬・催眠鎮静薬として使用されていた薬です。
TxGNN モデルは**不眠症 (Insomnia)** に有効である可能性を予測していますが、
現時点で支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

| 項目 | 内容 |
|------|------|
| 既存適応症 | 抗不安薬、催眠鎮静薬 |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、トフィソパムは 2,3-ベンゾジアゼピン系の化合物で、一般的なベンゾジアゼピン系薬のように GABA-A 受容体のベンゾジアゼピン結合部位に作用する薬とは異なるとされています。

日本では抗不安薬・催眠鎮静薬として承認されていました。催眠鎮静作用が既に適応として認められていたことから、不眠症にも関連しうると考えられます。ただし、これは適応症の近さに基づく推測です。作用機序の裏付けや臨床的な裏付けは、今回のデータにはありません。

99% を超える TxGNN スコアは計算モデルによる予測にすぎません。実際の臨床試験や文献による裏付けは得られておらず、評価は慎重に行う必要があります。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、裏付けとなる臨床試験も文献もなく、エビデンスはモデル予測のみ (L5) です。さらに、日本ではすべての承認が失効しており、現在は市販されていません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得（現状は安全性評価に進めない）
- 作用機序（MOA）データの補充
- 不眠症に関する臨床試験・文献の検索と評価
- 市販が終了している経緯の確認と、再導入する場合の剤形・投与経路の検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

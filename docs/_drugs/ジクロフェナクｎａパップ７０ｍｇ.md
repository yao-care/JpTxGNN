## 一言要約

ジクロフェナクＮＡパップ７０ＭＧ（ジクロフェナクナトリウム外用貼付剤）は NSAID 系消炎鎮痛薬の局所製剤です。今回の Evidence Pack では TxGNN モデルによる新規適応症予測結果が含まれておらず、再利用候補の評価を実施できませんでした。PMDA データベースでの承認情報も取得できていないため、クエリの正規化を含むデータ補完が必要です。

## データ品質に関する注記

本 Evidence Pack は複数の重大なデータギャップを含んでいます。

**クエリ名称の問題：**  
入力された薬物名「ジクロフェナクＮＡパップ７０ＭＧ」は全角文字で記述された製品規格名であり、PMDA が認識する標準的な INN（一般名）ではありません。実際、PMDA クエリは 0 件を返していますが、ジクロフェナクナトリウム外用製剤（ボルタレン® テープ等）は日本で広く承認・市販されています。正規化した一般名（`ジクロフェナクナトリウム` または `Diclofenac sodium`）での再クエリが必要です。

**DrugBank クエリ：**  
DrugBank は 1 件ヒットを返しているにもかかわらず `drugbank_id` が null のままです。マッピング処理の確認が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**  
TxGNN による新規適応症予測が存在せず、既存適応症・安全性データもいずれも未取得のため、現時点では再利用可能性の評価が不可能です。なお、PMDA の 0 件ヒットは薬物の不存在ではなく、全角文字クエリによる検索不一致が原因である可能性が高いです。

**進める場合に必要なもの：**

- **クエリ正規化**：全角文字を半角に変換し、`ジクロフェナクナトリウム` または `Diclofenac sodium` で PMDA を再検索
- **DrugBank ID の確定**：DrugBank が 1 件返したヒットのマッピング処理を確認し、正式な `drugbank_id` を取得
- **MOA データの取得**：DrugBank API から作用機序情報を取得（DG002 対応）
- **安全性情報の取得**：PMDA 仿単 PDF から警告・禁忌を解析（DG001 対応）
- **TxGNN への再投入**：正規化済みの DrugBank ID を使って KG 予測および DL 予測を実行

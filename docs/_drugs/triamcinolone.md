# トリアムシノロン：副腎皮質ステロイドの既存適応症から粘液性脱毛症へ

## 一言要約

トリアムシノロンは合成グルココルチコイドで、日本では関節リウマチ、気管支喘息、各種皮膚炎などの抗炎症・免疫抑制目的で使われています。
TxGNN モデルは**粘液性脱毛症 (Alopecia Mucinosa)** に有効である可能性を予測していますが、裏付けは**臨床試験 0 件**、**文献 4 編**（いずれも症例報告・症例集積で、トリアムシノロンを直接評価したものはありません）にとどまります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 副腎皮質ステロイドとしての抗炎症・抗リウマチ用途（慢性副腎皮質機能不全、関節リウマチ、気管支喘息、各種皮膚炎など） |
| 予測新規適応症 | 粘液性脱毛症 (Alopecia Mucinosa) |
| TxGNN 予測スコア | 99.99% |
| エビデンスレベル | L4 |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、トリアムシノロンはグルココルチコイド受容体作動薬で、抗炎症作用と免疫抑制作用を持ちます。多くの炎症性・自己免疫性皮膚疾患で有効性が確立されており、粘液性脱毛症（毛包性ムチン症）にも機序的に適用できる可能性があります。

粘液性脱毛症は毛包周囲に炎症性細胞浸潤を伴うことがあります。グルココルチコイドの抗炎症作用がこの炎症を抑える、というのが予測の根拠です。ただし、これは薬剤クラスとしての推定です。取得できた文献に、トリアムシノロンの有効性を直接示したものはありません。

他の予測候補では、毛包炎性の瘢痕性脱毛症である**ケルスス禿瘡に類する Quinquaud 禿髪性毛包炎 (Folliculitis Decalvans)** に後ろ向きコホート研究が 2 件あり、エビデンス上は L3 です。ただし、これらもトリアムシノロンの効果を切り分けたものではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
臨床試験がなく、文献は症例報告のみで、トリアムシノロンを直接評価したものはありません。添付文書の警告・禁忌が未取得のため、安全性の一次確認もできていません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・相互作用）の取得と確認
- 作用機序（MOA）データの補充
- 粘液性脱毛症に対するトリアムシノロン（局所・病変内投与）の使用実績を調べる追加の文献検索
- 投与経路の適合性評価（現時点では未評価）
- 併せて、エビデンスが厚い Quinquaud 禿髪性毛包炎を優先候補として再評価

本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証が必要です。

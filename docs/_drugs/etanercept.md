# エタネルセプト：関節リウマチ・脊椎関節炎・若年性特発性関節炎から関節リウマチ性血管炎へ

## 一言要約

エタネルセプトは TNF-α を中和する可溶性受容体融合タンパク質で、元々は関節リウマチ、乾癬性関節炎、強直性脊椎炎、若年性特発性関節炎などの治療に使用されてきました。
TxGNN モデルは**関節リウマチ性血管炎 (Rheumatoid Vasculitis)** に有効である可能性を予測していますが、直接支持する臨床試験はなく、文献も限定的です。エビデンスは主にモデル予測と機序的な推論にとどまり、抗 TNF 薬が血管炎を誘発した報告もあるため、効果の方向性自体が不確実です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、エタネルセプトは TNF 受容体 (p75)–Fc 融合タンパク質で、TNF-α を中和します。関節リウマチなどの炎症性関節疾患で有効性が確立しています。

関節リウマチ性血管炎は関節リウマチのもっとも重篤な関節外病変の一つで、TNF-α を含む炎症経路が関与します。このため、TNF 阻害が血管の炎症を抑える可能性は機序的に考えられます。文献では、生物学的製剤による治療を扱ったシステマティックレビュー（2021 年）もあります。

ただし、エタネルセプトを含む抗 TNF 薬が皮膚血管炎や白血球破砕性血管炎などを誘発したという症例報告が複数あり、正味の効果は不明です。現時点では「検討すべき研究課題」の段階です。

## 安全性に関する考慮事項

- **薬物相互作用**：100 件の相互作用が登録されています。主なものは次のとおりです。
  - **Major**：ヒドロコルチゾン、トリアムシノロン、デキサメタゾン、ベタメタゾン、ブデソニド、プレドニゾン、プレドニゾロンなどのコルチコステロイド、デフェリプロン、イオベングアン (I-131)、イブリツモマブ チウキセタン、トシツモマブ
  - **Moderate**：メトロニダゾール、チニダゾール、ロスバスタチン、シンバスタチン
  - **Minor**：亜鉛製剤（硫酸亜鉛、酢酸亜鉛、グルコン酸亜鉛）

警告・禁忌については添付文書を参照してください。文献上は、抗 TNF 薬に関連する血管炎、ループス様症状、腎障害、感染症（帯状疱疹、結核の再活性化など）の報告があります。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 関節リウマチ性血管炎については、直接支持する臨床試験がなく、文献も症例報告と一般的なレビューが中心です。抗 TNF 薬が血管炎を誘発した報告もあり、効果の方向性が不確実です。
- 日本では現在有効な承認がなく、添付文書に基づく警告・禁忌の確認もできていません。

**進める場合に必要なもの：**
- 日本の添付文書（警告・禁忌）の取得と確認
- 作用機序データの補完
- 関節リウマチ性血管炎に対する生物学的製剤の既存システマティックレビュー（PMID 33058033）の詳細な精査。エタネルセプト単独の有効性と、薬剤誘発性血管炎のリスクを切り分ける
- 関節リウマチ性血管炎患者を対象とした前向き研究の設計検討
- 日本での承認状況（有効な承認の有無）の再確認

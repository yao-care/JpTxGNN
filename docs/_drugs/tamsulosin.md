# タムスロシン：前立腺肥大症に伴う排尿障害から Ambras 型先天性汎発性多毛症へ

## 一言要約

タムスロシンはα1A/1D アドレナリン受容体拮抗薬で、日本では前立腺肥大症に伴う排尿障害の治療薬として使われています（この既存適応症は Evidence Pack に記載がなく、一般的な添付文書情報に基づきます）。
TxGNN モデルは **Ambras 型先天性汎発性多毛症 (Ambras type hypertrichosis universalis congenita)** に有効である可能性を予測しています。ただし、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データは Evidence Pack にありません。タムスロシンはα1A/1D アドレナリン受容体を選択的に遮断する薬で、その作用は主に下部尿路の平滑筋弛緩です。

Ambras 型先天性汎発性多毛症は、染色体 8q22 の再配列に関連する遺伝性の疾患です。α1 遮断作用がこの遺伝的な発症機序や毛髪の成長制御に関与するという根拠は、現時点で確認されていません。したがって、この予測はモデルのスコアのみに依拠しており、機序的な裏付けは不十分です。

なお、上位 10 件の予測（多毛症、遺伝性毛幹異常、脱毛症、片頭痛など）はいずれも L5・Hold です。毛髪関連の疾患が多いものの、機序面の共通した説明は見つかっていません。

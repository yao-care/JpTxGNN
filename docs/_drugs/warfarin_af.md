# Warfarin - Atrial Fibrillation (AF) 適應症評估

## 一言まとめ

Warfarin 用於心房顫動（Atrial Fibrillation）**已是核准適應症**，
此為標準治療用途，非新適應症預測。

## 概要

| 項目 | 内容 |
|------|------|
| 藥品名稱 | Warfarin |
| 適應症 | 心房纖維顫動（Atrial Fibrillation） |
| 適應症狀態 | **已核准** |
| エビデンスレベル | L1（多個 RCT 支持） |
| 日本上市 | 已上市 |
| 推奨判断 | 標準治療 |

## 背景説明

本筆記針對 Warfarin 在心房顫動（AF）的應用進行評估。

**重要聲明：**
- Warfarin 用於預防心房纖維顫動引起的血栓性栓塞症，**已是台灣 TFDA 核准的適應症**
- 此非「老藥新用」候選，而是現有標準治療
- 完整的 Warfarin 藥物資訊請參考 [warfarin/drug_pharmacist_notes.md](../warfarin/drug_pharmacist_notes.md)

## 日本承認適応症

根據 TFDA 許可證資料（如欣服寧錠、可化凝錠）：

> 1. 預防及/或治療靜脈栓塞症及其相關疾病，以及肺栓塞
> 2. **預防或治療因心房纖維顫動及/或更換心臟瓣膜引起之血栓性栓塞症**

## 臨床応用のポイント

### 心房顫動中的角色

Warfarin 長期以來是心房顫動患者預防中風的標準抗凝血治療：

1. **CHA2DS2-VASc 評分**：用於評估 AF 患者的中風風險，決定是否需要抗凝治療
2. **INR 目標**：通常維持在 2.0-3.0
3. **監測需求**：需要定期監測 PT/INR

### 與 DOAC 的比較

近年來，直接口服抗凝血劑（DOAC）如 Dabigatran、Rivaroxaban、Apixaban、Edoxaban 已成為許多 AF 患者的首選：

| 項目 | Warfarin | DOAC |
|-----|---------|------|
| 監測需求 | 需要定期 INR | 不需常規監測 |
| 藥物交互作用 | 多 | 較少 |
| 飲食限制 | 有（維生素K） | 無 |
| 腎功能影響 | 較小 | 需考量 |
| 解毒劑 | Vitamin K | 部分有專用解毒劑 |
| 費用 | 較低 | 較高 |

### 仍適用 Warfarin 的情況

- 機械性心臟瓣膜患者
- 中度至重度二尖瓣狹窄
- 嚴重腎功能不全（eGFR < 15-30 mL/min）
- 經濟考量
- DOAC 禁忌症患者

## 安全性に関する考慮事項

請參考完整 Warfarin 藥師筆記中的安全性資訊：
- [Warfarin 藥師筆記](../warfarin/drug_pharmacist_notes.md)

**主要注意事項：**
- 出血風險
- 藥物交互作用（尤其是 Aspirin、NSAID、抗生素等）
- 飲食中維生素 K 攝取的一致性
- 定期 INR 監測

## 結論

**本筆記為參考性質說明**

Warfarin 用於心房顫動是已確立的適應症，具有充分的臨床試驗證據支持（L1 等級）。
此非 TxGNN 預測的新適應症，而是現有標準治療。

如需 Warfarin 其他 TxGNN 預測的新適應症資訊（如 Heparin Cofactor 2 Deficiency），
請參考 [Warfarin 主要藥師筆記](../warfarin/drug_pharmacist_notes.md)。

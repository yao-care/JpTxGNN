# タダラフィル：肺動脈性肺高血圧症からアンブラス型先天性汎発性多毛症へ

## 一言要約

タダラフィルは PDE5（ホスホジエステラーゼ5）阻害薬で、日本では肺動脈性肺高血圧症などの治療に使われています。
TxGNN モデルは**アンブラス型先天性汎発性多毛症 (Ambras type hypertrichosis universalis congenita)** に有効である可能性を予測しています。
ただし、この予測を支持する臨床試験と文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当かどうか

現在、詳細な作用機序データはありません。既知の情報では、タダラフィルは PDE5 を阻害して cGMP を増やし、血管を拡張させます。この作用が肺動脈性肺高血圧症での有効性の基盤です。

一方、アンブラス型先天性汎発性多毛症は、全身の過剰な毛髪成長を特徴とする先天性の疾患です。PDE5 阻害や cGMP 経路との確立した機序的関連は見つかっていません。血管拡張が毛包に影響する可能性は推測の域を出ず、既存適応症との関連性も現時点では評価できません。この予測は TxGNN のスコアのみに基づいています。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験も文献もなく、機序的な裏付けもありません。上位 10 件の予測はすべて L5（モデル予測のみ）です。なお、偏頭痛関連の予測では、タダラフィルが片頭痛のオーラを誘発したという有害事象の報告しか見つかっていません。

**進める場合に必要なもの：**
- 日本の添付文書（PMDA）の警告・禁忌の取得（現在は安全性審査に進めない状態）
- 詳細な作用機序（MOA）データの補充
- PDE5/cGMP 経路と多毛症・毛包生物学との関連を示す前臨床研究や機序研究
- 対象が先天性の希少疾患であることを踏まえた、症例報告や観察研究などの探索的エビデンスの収集

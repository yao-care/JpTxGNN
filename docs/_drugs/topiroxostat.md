# トピロキソスタット：高尿酸血症・痛風から腎性低尿酸血症へ

## 一言要約

トピロキソスタットはキサンチン酸化還元酵素（XOR）阻害薬で、元々高尿酸血症と痛風の治療に使用されていました。
TxGNN モデルは**腎性低尿酸血症 (hypouricemia, renal)** に有効である可能性を予測していますが、裏付けとなる臨床試験は **0 件**、文献は **1 編**（マウスを用いた動物実験）のみです。

## クイック概要

|------|------|
| 既存適応症 | 高尿酸血症、痛風 |
| 予測新規適応症 | 腎性低尿酸血症 (hypouricemia, renal) |
| TxGNN 予測スコア | 99.58% |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、トピロキソスタットは XOR を阻害して尿酸の産生を抑える薬剤で、高尿酸血症・痛風での使用実績があります。

ただし、腎性低尿酸血症は URAT1 や GLUT9 の機能異常により、もともと血清尿酸値が低い疾患です。尿酸を下げること自体は治療目標になりません。両者をつなぐのは間接的な関係のみです。XOR 阻害薬が尿中尿酸と酸化ストレスを抑え、この疾患の合併症である運動後急性腎障害（EIAKI）を軽減する可能性がある、という考え方です。

この仮説は、高 HPRT 活性の Urat1-Uox 二重ノックアウトマウスを用いた研究（2022 年）に基づいています。この研究では、XOR 阻害薬が EIAKI の発症を抑えたと報告されています。ただし、動物モデルでの結果であり、ヒトへの適用は確認されていません。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

なお、他の予測適応症（HPRT 部分欠損症、レッシュ・ナイハン症候群）では、XOR 阻害によりヒポキサンチンやキサンチンが蓄積し、キサンチン腎症のリスクが高まる可能性が指摘されています。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 腎性低尿酸血症では尿酸を下げること自体が治療目標にならず、機序的なつながりは間接的です。
- 支持するエビデンスはマウスの動物実験 1 編のみで、臨床試験はありません。
- 日本ではすべての承認が整理済みで、有効な承認がありません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌情報を取得し、安全性スクリーニングを実施すること
- DrugBank から詳細な作用機序データ（MOA）を取得すること
- 運動誘発性 AKI の抑制を検証する前臨床・臨床データを追加すること（対象を EIAKI のハイリスク患者に絞る）
- 現在の販売状況と、再開発の場合の承認手続きを確認すること
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

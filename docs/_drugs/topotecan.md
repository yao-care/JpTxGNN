# トポテカン：女性乳癌への再利用評価

## 一言要約

トポテカン (Topotecan) はトポイソメラーゼ I 阻害薬に分類される抗腫瘍薬ですが、今回のデータには既存適応症の記載がありません。
TxGNN モデルは**女性乳癌 (female breast carcinoma)** に有効である可能性を予測しています。
関連する臨床試験は **5 件**、文献は **20 編**ありますが、トポテカン単独での乳癌に対する大規模な確認試験はなく、主に小規模な第 II 相試験と前臨床研究です。

## この予測が妥当である理由

現在、DrugBank から詳細な作用機序 (MOA) データは取得できていません。
一方、トポテカンはトポイソメラーゼ I を阻害して DNA 鎖切断を起こし、増殖の速い腫瘍細胞の複製時に細胞死を誘導する薬剤として知られています。

前臨床研究では、トポイソメラーゼ I 阻害が MYC 駆動型がんや、トリプルネガティブ乳癌 (TNBC) のモデルで有効である可能性が示されています。
このため、機序の面では乳癌への適用に一定の根拠があります。

ただし、臨床での活性は限定的にとどまります。裏付けは小規模な第 II 相試験とパイロット試験のみで、トポテカン単独を対象に有効性を確認した第 3 相試験はありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
機序上の根拠と小規模な第 II 相試験はありますが、トポテカン単独で乳癌への有効性を確認した第 3 相試験はなく、臨床での活性も限定的です。
加えて、添付文書の警告・禁忌が未取得（Blocking）で、日本の承認情報にも成分の取り違えの疑いがあるため、現時点では次の段階に進められません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・相互作用）を取得し、安全性スクリーニングを行う
- 日本の承認番号 620919701 と 620919501 が、トポテカン（ハイカムチン）のものかイリノテカン（トポテシン）のものかを確認する
- 承認適応症のテキストを取得して、既存適応症を確定する
- DrugBank から作用機序データを取得する
- 乳癌を対象にトポテカンを評価した試験（特に NCT00006032 の結果と CALGB 試験の奏効率）を精査する
- トリプルネガティブ乳癌など、対象を絞った臨床仮説を立てる

※本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床での検証が必要です。

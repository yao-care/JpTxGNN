## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が未特定であり TxGNN モデルによる予測が実施されていないため、再利用候補を評価する基盤データが揃っていません。PMDA 照会も 0 件であり、クエリ文字列（全角・剤形付き商品名）の形式が検索精度に影響している可能性があります。

**進める場合に必要なもの：**
- INN（ケトプロフェン / Ketoprofen）を用いた PMDA 再検索（クエリ文字列を半角・成分名に変更）
- DrugBank ID の特定（DrugBank API クエリは result_count = 1 のため、IDを確定させること）
- DrugBank ID をキーとした TxGNN 予測パイプラインの実行
- PMDA 仿単 PDF からの警語・禁忌情報の抽出（DG001：Blocking）
- 確定した DrugBank ID から MOA データを取得（DG002：High）

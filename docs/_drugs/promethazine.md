# プロメタジン：パーキンソニズム・アレルギー性鼻炎から酒さ性結膜炎へ

## 一言要約

プロメタジンは第一世代の H1 受容体拮抗薬で、日本では主に抗アレルギー薬、制吐薬、パーキンソン病治療薬として配合剤に使われてきました。
TxGNN モデルは**酒さ性結膜炎 (Rosacea Conjunctivitis)** に有効である可能性を予測していますが、この疾患を直接支持する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、プロメタジンは H1 受容体拮抗作用と抗コリン作用をあわせ持つ第一世代抗ヒスタミン薬で、日本では配合剤の成分として市販されています。アレルギー性鼻炎での使用実績があり、ヒスタミンが関与する炎症・かゆみへの作用が期待されます。

酒さ性結膜炎は眼表面の炎症性疾患です。H1 遮断と抗コリン作用が、眼表面の炎症や症状を和らげる可能性は理論上考えられます。ただし、これはあくまで機序面の推測です。この疾患に対する臨床試験や文献は見つかっておらず、根拠は TxGNN の予測のみです。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高い（98.94%）ものの、酒さ性結膜炎を直接支持する臨床試験・文献がなく、エビデンスはモデル予測のみ (L5) です。安全性の一次情報（添付文書）も未確認のため、現時点では先へ進められません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングの前提）
- 詳細な薬物作用機序データ（MOA）
- 酒さ性結膜炎に関する文献・臨床試験の追加調査
- 眼科領域での投与経路（現在の日本の剤形は経口・顆粒のみ）の適合性確認
- 同じ予測リストのうち、アレルギー性蕁麻疹（L4）や鼻炎（L3）は、より根拠のある候補として優先的に検討する価値があります

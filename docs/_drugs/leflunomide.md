# レーフルノミド：乾癬性関節炎・関節リウマチから先端短指症・合指症症候群へ

## 一言要約

レーフルノミド (Leflunomide) は、元々**乾癬性関節炎**および**関節リウマチ**の治療に使用されていた薬です。
TxGNN モデルは**先端短指症・合指症症候群 (brachydactyly-syndactyly syndrome)** に有効である可能性を予測していますが、現時点で関連する臨床試験・文献はなく、**モデル予測のみ**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 乾癬性関節炎、関節リウマチ（知識グラフ上の情報。日本の承認書には記載なし） |
| 予測新規適応症 | 先端短指症・合指症症候群 (brachydactyly-syndactyly syndrome) |
| TxGNN 予測スコア | 99.93% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売終了（承認は整理済みのみ） |
| 承認番号数 | 3 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、レーフルノミドの活性代謝物テリフルノミドは、ジヒドロオロト酸脱水素酵素 (DHODH) を阻害してピリミジン合成を抑えることが知られており、増殖の速い細胞（活性化リンパ球など）に作用します。これが関節リウマチや乾癬性関節炎での効果の基盤と考えられます。

一方、先端短指症・合指症症候群は四肢の形成異常を特徴とする疾患です。今回まとめたデータでは、DHODH 阻害や既存の免疫関連適応症とこの疾患の四肢パターン形成不全を結びつける根拠は確認できません。TxGNN スコア (99.93%、順位 644) は計算上の予測であり、機序的な妥当性は未検証です。

なお、同じく予測された「眼コロボーマ性小眼球症・根性肢異形成症候群 (colobomatous microphthalmia-rhizomelic dysplasia syndrome)」（スコア 99.93%、順位 672）についても、臨床試験・文献はなく、同様に L5・Hold の評価です。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、予測モデルの知識グラフに基づく情報）：
  - 肝疾患：肝不全、肝疾患、胆嚢疾患、慢性 C 型・B 型肝炎ウイルス感染
  - 血液疾患：血小板減少症、好中球減少症（先天性を含む各種）、無顆粒球症、貧血、汎血球減少症
  - 腎疾患：腎疾患、膿尿管
  - 神経疾患：末梢神経系疾患、末梢神経障害
  - 呼吸器・感染症：間質性肺疾患、ニューモシスチス症、アスペルギルス症
- **薬物相互作用**（DDInter、全 100 件中、主なもの）：
  - **Major**：アカルボース、ヒドロコルチゾン、ピオグリタゾン、ブプロピオン、トリアムシノロン、アセチルサリチル酸、デキサメタゾン、ベタメタゾン、ブデソニド、ケノデオキシコール酸、クラリスロマイシン、ミノサイクリン、オキサンドロロン、オキシメトロン、ナルトレキソン
  - **Moderate**：メトロニダゾール、クロルプロパミド、アセトヘキサミド
  - **Minor**：硫酸亜鉛、酢酸亜鉛

添付文書の警告・禁忌の詳細は取得できていないため、安全性情報については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、関連する臨床試験・文献がなく、機序的な裏付けも確認できないため、エビデンスは L5（モデル予測のみ）にとどまります。
- 日本の承認はすべて整理済みで、添付文書の警告・禁忌も未取得のため、安全性評価に進めません。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と解析（必須）
- 詳細な作用機序データ (MOA) の補充（DrugBank など）
- DHODH 阻害と四肢形成異常（または眼・骨格異常）との機序的関連性に関する前臨床研究・文献の調査
- 希少疾患であることを踏まえた症例報告や患者レジストリの探索
- 肝障害・骨髄抑制など、知識グラフ上の禁忌疾患に関するリスク評価
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

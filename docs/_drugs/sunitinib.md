# スニチニブ：抗悪性腫瘍薬から脂肪肉腫へ

## 一言要約

スニチニブは血管新生阻害作用を持つ受容体型チロシンキナーゼ阻害薬で、日本では抗悪性腫瘍薬として市販されています。
TxGNN モデルは**脂肪肉腫 (Liposarcoma)** に有効である可能性を予測しています。関連する臨床試験は **3 件**（うち 1 件はレゴラフェニブの試験）、文献は **8 編**ありますが、いずれも単群 Phase 2 試験や総説、症例報告が中心で、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。ただし、Evidence Pack の情報からスニチニブは VEGFR・PDGFR・KIT を阻害する多標的キナーゼ阻害薬と考えられます。これにより腫瘍血管新生と増殖シグナルを抑えると見られます。

軟部肉腫は血管新生や PDGFR シグナルへの依存が報告されている腫瘍群で、脂肪肉腫もその一つです。そのため、既存の抗腫瘍薬としての作用機序が脂肪肉腫にも適用できる可能性があります。ただし、脂肪肉腫での臨床的な活性は控えめで、根拠は単群 Phase 2 のデータに限られます。

## 結論と次のステップ

**決定：Hold**

**理由：**
脂肪肉腫を直接支持する根拠は、複数組織型を含む単群 Phase 2 試験、総説、症例報告にとどまり、脂肪肉腫に絞った RCT はありません。加えて、日本の添付文書に基づく警告・禁忌が未取得（ブロッキング）のため、安全性の一次スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌・相互作用を取得する（ブロッキング）
- DrugBank から作用機序（MOA）を取得する
- NCT00400569 と NCT00474994 の結果を確認し、脂肪肉腫サブグループの奏効率・PFS を抽出する
- 組織型（脱分化型・粘液型など）別の有効性を整理する
- 参考：同じ Evidence Pack の腎細胞癌（renal carcinoma）は Phase 3 RCT（S-TRAC）に基づき L1 と判定されており、別途評価する価値があります

本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床検証を経て初めて臨床応用できます。

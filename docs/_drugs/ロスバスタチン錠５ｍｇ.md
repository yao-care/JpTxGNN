## 一言要約

ロスバスタチン錠５ＭＧは日本 PMDA データベースへの照会で承認記録が確認されず、DrugBank への照合では薬物 ID の特定に至りませんでした。TxGNN モデルは本薬物に対して再利用候補を予測していないため、**現時点では老藥新用評価を実施できません**。データギャップの解消が先決です。

## 結論と次のステップ

**決定：Hold**

**理由：**
PMDA データベースへの照会で承認記録が存在せず、DrugBank ID も未確定のため、TxGNN モデルへの入力が成立しておらず再利用候補が生成されていません。現データでは安全性・機序・適応症のいずれの評価軸も機能しません。

**進める場合に必要なもの：**

1. **薬物 ID 確定（優先度：Blocking）**
   - 検索クエリを一般名 `ロスバスタチン` (Rosuvastatin) に切り替えて PMDA を再照会
   - DrugBank API で `rosuvastatin` を検索し DrugBank ID（例：DB01098）を取得
   - 剤形・規格を含む商品名（ロスバスタチン錠５ＭＧ）と INN を分離して再クエリ

2. **作用機序データ取得（優先度：High）**
   - DrugBank の `mechanism_of_action` フィールドを取得
   - HMG-CoA 還元酵素阻害薬としての薬理情報を補充

3. **安全性情報取得（優先度：Blocking）**
   - PMDA 仿単 PDF をダウンロードし警語・禁忌を解析
   - DrugBank の `toxicity` および `drug_interactions` フィールドを取得

4. **TxGNN 再予測実行**
   - 上記 1〜3 完了後、正規化した INN でパイプラインを再実行
   - KG 予測・DL 予測の両モードで候補を生成

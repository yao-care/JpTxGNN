# ナフトピジル：排尿障害からアンブラス型先天性全身性多毛症へ

## 一言要約

ナフトピジルは α1 アドレナリン受容体拮抗薬で、もともと排尿障害の改善に使われてきました。
TxGNN モデルは**アンブラス型先天性全身性多毛症 (Ambras type hypertrichosis universalis congenita)** に有効である可能性を予測していますが、関連する臨床試験と文献はどちらも **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ナフトピジルは選択的 α1 アドレナリン受容体拮抗薬（α1D/α1A）で、排尿障害の改善に使われています。

アンブラス型先天性全身性多毛症は、ゲノム再構成が原因の先天性の毛髪成長異常です。α1 遮断で血管が拡張すると毛包に影響する可能性は推測できますが、ナフトピジルとこの疾患を結びつける臨床データも前臨床データもありません。機序的な裏付けは乏しく、この予測は計算モデルのスコアだけに基づいています。

なお、上位 5 件の予測（多毛症、歯・歯周組織を伴う奇形症候群、ダンディ・ウォーカー奇形を主徴とする症候群、遺伝性毛幹異常）でも、機序上の根拠は同様に確認できませんでした。

# Treprostinil：肺動脈性肺高血圧症から関連する合併症まで

## 一言まとめ

トレプロスチニル（Treprostinil）は、もともと特発性または遺伝性の肺動脈性肺高血圧症の治療に用いられる薬剤です。
TxGNN モデルは、本剤が**肺動脈性肺高血圧症に関連する複数の疾患**に有効である可能性を予測しており、
その中でも**結合組織病に伴う肺動脈性肺高血圧症**に対して最も強い臨床エビデンスの裏付けがあります。

## この予測が妥当な理由

Treprostinil はプロスタサイクリン類縁体であり、その作用機序は各種の肺動脈性肺高血圧症への応用を支持するものです。

1. **血管拡張**：肺血管および全身の血管を直接拡張する
2. **抗血小板作用**：血小板凝集を抑制する
3. **抗増殖作用**：血管平滑筋細胞の増殖を抑制する
4. **細胞保護作用**：内皮細胞の機能を保護する

これらの機序は、結合組織病、先天性心疾患、HIV 感染など、さまざまな原因による肺動脈性肺高血圧症に当てはまります。

## 安全性に関する考慮事項

- **投与経路**：皮下注射では注射部位の疼痛や反応が生じることがある
- **血圧への影響**：低血圧を起こす可能性がある
- **出血リスク**：抗血小板作用により出血リスクが増加する可能性がある
- **主な相互作用（Moderate）**：
  - アセチルサリチル酸（出血リスク増加）
  - SGLT2 阻害薬（カナグリフロジン、ダパグリフロジン、エンパグリフロジン）
  - エピネフリン（血圧調節に影響する可能性）

# イミペネム：細菌感染症から びまん性強皮症 へ

## 一言要約

イミペネムはカルバペネム系抗菌薬で、元々細菌性肺炎、腹膜炎、心内膜炎などの治療に使用されていました。
TxGNN モデルは**びまん性強皮症 (Diffuse Scleroderma)** に有効である可能性を予測していますが、関連する臨床試験・文献は**ありません**（モデル予測のみ）。
なお、同じ予測リストには感染症領域の候補（腸チフス、パラチフス、サルモネラ症、黄色ブドウ球菌感染症）があり、こちらは文献や臨床試験による一定の裏付けがあります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 細菌性肺炎、腹膜炎、感染性心内膜炎、細菌性関節炎、子宮内膜炎など（TxGNN 知識グラフ上の適応症） |
| 予測新規適応症 | びまん性強皮症 (Diffuse Scleroderma) |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、イミペネムは細菌のペニシリン結合タンパク質に結合して細胞壁合成を阻害するカルバペネム系抗菌薬です。

びまん性強皮症は線維化と免疫異常を特徴とする自己免疫疾患です。イミペネムには抗線維化作用や免疫調節作用は知られておらず、機序的な関連は見出せません。このスコアは根拠の乏しい予測と考えられます。

- **腸チフス・パラチフス・サルモネラ症**：広域のグラム陰性菌活性と β-ラクタマーゼへの安定性から、多剤耐性・広域耐性菌に対する予備薬として妥当です。ただし根拠は感受性サーベイランスや in vitro データが中心で、イミペネム固有の臨床転帰データは限られます。
- **黄色ブドウ球菌感染症**：最も根拠が充実しています。ホスホマイシン併用の MRSA 感染性心内膜炎の第 4 相試験（完了）があります。ただし既存の心内膜炎・肺炎適応と重なるため、純粋な再利用とは言えません。
- **副鼻腔炎・副鼻腔腫瘍・好酸球増多筋痛症候群**：機序的な裏付けは弱く、予測の根拠は不十分です。

- **主要な警告・禁忌（添付文書）**：添付文書由来の情報は今回のデータに含まれていません。安全性情報については添付文書を参照してください。

- **薬物相互作用**（計 15 件）：

  - **中等度 (Moderate)**：ワルファリン、ジクマロール、テオフィリン系（アミノフィリン、ジプロフィリン、オキストリフィリン、テオフィリン）、シクロスポリン、エチニルエストラジオール、ミコフェノール酸、ペメトレキセド、リンデン、ポリエチレングリコール（電解質配合）

## 結論と次のステップ

**決定：Hold**

**理由：**
- びまん性強皮症については臨床試験・文献が一切なく、機序的な関連も見出せないため、モデル予測のみ（L5）で進めるべきではありません。
- 日本での販売承認も取消済みで、添付文書の安全性情報も未取得のため、現時点では保留が妥当です。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得（PMDA 公開文書の解析）
- DrugBank からの作用機序データの補充
- 強皮症に対する前臨床・機序研究の有無の確認
- 優先的に検討するなら、腸チフス／パラチフス／サルモネラ症（広域耐性菌）と MRSA 感染症を、イミペネム固有の臨床転帰データを軸に評価し直す
- 日本での販売状況（取消の経緯、類似製剤の有無）の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

## Imipenem: びまん性強皮症 (diffuse scleroderma)
{: .text-alpha }

## 一言要約

イミペネムはカルバペネム系の注射用抗菌薬で、日本では「チエナム」として市販されています。
TxGNN モデルは**びまん性強皮症 (diffuse scleroderma)** に有効である可能性を予測していますが、この疾患を直接検討した臨床試験・文献は**ありません**。
現時点ではモデル予測のみで、エビデンスレベルは L5 です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、イミペネムはペニシリン結合タンパク質に結合して細菌の細胞壁合成を阻害するカルバペネム系抗菌薬です。

びまん性強皮症は、線維化と免疫異常を特徴とする自己免疫性の疾患です。イミペネムには、抗線維化作用や免疫調節作用など、強皮症に関連する既知の作用がありません。そのため、機序面から今回の予測を裏付ける根拠は見つかっていません。

TxGNN のスコアは高い値を示していますが、裏付けとなる研究や生物学的な説明がなく、現時点では根拠の乏しい予測と位置づけるのが妥当です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- びまん性強皮症を直接検討した臨床試験・文献がなく、機序的にも関連性が確認できないため、モデル予測のみの段階です。
- 現時点で開発や臨床応用を進める根拠はありません。

**進める場合に必要なもの：**
- 強皮症の線維化・免疫病態とイミペネムを結びつける機序的根拠（前臨床研究など）
- 詳細な作用機序（MOA）データの取得
- 添付文書（PMDA）の警告・禁忌情報の確認
- 強皮症患者での安全性評価（腎機能への配慮や、免疫抑制薬との併用時の相互作用を含む）

## 免責事項

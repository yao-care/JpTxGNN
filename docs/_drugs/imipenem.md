# イミペネム：細菌感染症から びまん性強皮症へ

## 一言要約

イミペネムはカルバペネム系抗菌薬で、元々は細菌感染症の治療に使用されています。
TxGNN モデルは**びまん性強皮症 (Diffuse Scleroderma)** に有効である可能性を予測していますが、この予測を支える臨床試験・文献は **0 件**で、モデル予測のみの段階です。
他の予測候補（チフス、サルモネラ症、黄色ブドウ球菌感染症など）は抗菌薬としての作用機序と整合し、文献や臨床試験の裏付けがあります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、イミペネムはカルバペネム系抗菌薬で、細菌のペニシリン結合タンパク質 (PBP) を阻害して細胞壁合成を妨げます。

びまん性強皮症は自己免疫性の線維化疾患です。イミペネムに抗線維化作用や免疫調節作用があるという根拠はなく、機序上の関連は確認できません。この予測は TxGNN のスコアのみに基づいており、妥当性は低いと判断します。

## 結論と次のステップ

**決定：Hold**

**理由：**
びまん性強皮症は予測スコアが高いものの、支持する臨床試験・文献がなく、機序上の根拠もありません。モデル予測のみのため保留とします。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得（未取得で、安全性スクリーニングの障壁となっています）
- 詳細な作用機序データ（DrugBank など）
- 感染症系の候補（チフス、黄色ブドウ球菌感染症など）を優先して評価し直すこと

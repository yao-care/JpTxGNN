# レゴラフェニブ：大腸癌・消化管間質腫瘍から脂肪肉腫へ

## 一言要約

レゴラフェニブは経口のマルチキナーゼ阻害薬で、文献上は元々転移性大腸癌と消化管間質腫瘍 (GIST) の治療に使われてきました。
TxGNN モデルは**脂肪肉腫 (Liposarcoma)** に有効である可能性を予測しています。しかし、**2 件の完了した Phase 2 プラセボ対照 RCT**（臨床試験 2 件、RCT 文献 4 編）では、脂肪肉腫での有効性は示されていません。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データはありません。文献では、レゴラフェニブは血管新生関連 (VEGFR1-3、TIE2)、間質関連 (PDGFR-β、FGFR)、がん遺伝子関連 (KIT、RET、RAF) の受容体型チロシンキナーゼを阻害する経口ジフェニルウレア系薬剤とされています。

軟部肉腫は血管新生や間質のシグナル伝達が腫瘍の進展に関わるため、機序的には脂肪肉腫にも適用できる可能性があります。TxGNN のスコアが高いのは、この機序上の近さを反映していると考えられます。

ただし、この機序上の予測は臨床データと一致していません。REGOSARC 試験では、平滑筋肉腫、滑膜肉腫、その他の非脂肪細胞性肉腫で有効性が示されました。一方、脂肪肉腫では示されませんでした。SARC024 の脂肪肉腫コホートも同様の結果でした。

## 結論と次のステップ

**決定：Hold**

**理由：**
脂肪肉腫に対する 2 件の Phase 2 プラセボ対照 RCT（REGOSARC、SARC024）は、いずれも有効性を支持していません。TxGNN の高スコアと機序上の妥当性だけでは、この否定的な結果を覆せません。Evidence Pack の自動判定は Proceed with Guardrails でしたが、日本の添付文書の安全性情報が未取得（Blocking）である点も踏まえ、Hold に変更しました。

**進める場合に必要なもの：**
- PMDA の添付文書（警告、禁忌）の取得と解析
- DrugBank の作用機序データと DDI の確認
- 脂肪肉腫の組織亜型（高分化型/脱分化型、粘液型など）別に、有効性を示す新たなデータがあるかの確認
- 併用療法（例：免疫チェックポイント阻害薬との併用）を検討する場合は、その根拠データの収集

なお、同じ Evidence Pack の予測順位 3 位の明細胞型腎細胞癌には、未治療の転移性・切除不能腎細胞癌を対象とした単群 Phase 2 試験（[PMID 22959186](https://pubmed.ncbi.nlm.nih.gov/22959186/)）があります。別の検討候補になり得ますが、Evidence Pack 上の判定は「Research Question」で、エビデンスは限定的です。

本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証が必要です。

# レゴラフェニブ：消化管間質腫瘍・肝細胞癌から脂肪肉腫へ

## 一言要約

レゴラフェニブは経口のマルチキナーゼ阻害薬で、元々は転移性大腸癌、肝細胞癌、消化管間質腫瘍 (GIST) などの治療に関連づけられていた薬です。
TxGNN モデルは**脂肪肉腫 (Liposarcoma)** に有効である可能性を予測していますが、**脂肪肉腫を対象とした無作為化試験では有効性が支持されませんでした**。
現在、**1 件の臨床試験**と **9 編の文献**がこの予測に関連しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 転移性大腸癌、肝細胞癌、消化管間質腫瘍 (GIST) など（日本の承認適応症の記載はなし） |
| 予測新規適応症 | 脂肪肉腫 (Liposarcoma) |
| TxGNN 予測スコア | 99.76% |
| エビデンスレベル | L2 |
| 日本市販状況 | 販売中の承認なし（承認整理済みのみ） |
| 承認番号数 | 1 件（整理済み） |
| 推奨決定 | Hold |

> データ上の評価は「Proceed with Guardrails」ですが、下記の否定的な RCT 結果を踏まえ、本レポートでは Hold を推奨します（理由は結論を参照）。

## この予測が妥当である理由

現在、詳細な作用機序データは薬物情報に登録されていません。文献情報によると、レゴラフェニブは血管新生関連キナーゼ (VEGFR1-3、TIE2)、間質関連キナーゼ (PDGFR、FGFR)、がん遺伝子関連キナーゼ (KIT、RET、RAF) を阻害するマルチキナーゼ阻害薬です。

既存の適応症である GIST や大腸癌、肝細胞癌では、この血管新生とがん化シグナルの阻害が有効性の基盤とされています。軟部肉腫でも血管新生が重要な役割を果たすため、脂肪肉腫を含む軟部肉腫への適用は機序的に考えられます。

ただし、臨床データでは様相が異なります。REGOSARC 試験では非脂肪細胞性肉腫（平滑筋肉腫、滑膜肉腫など）で有効性が示された一方、脂肪肉腫では示されませんでした。つまり、TxGNN の予測スコアは高いものの、脂肪肉腫に限ると実際の臨床結果とは合致していません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 脂肪肉腫を対象とした SARC024 および REGOSARC のプラセボ対照 Phase 2 試験で有効性が示されず、著者らも日常的使用を支持しないと結論づけています。
- 日本では販売中の承認がなく、警告・禁忌データも不足しているため、現時点での再利用推進は困難です。

**進める場合に必要なもの：**
- 脂肪肉腫の特定サブタイプ（例：脱分化型）や併用療法に絞った新たな仮説と、その検証データ
- PMDA 添付文書の警告・禁忌情報の取得
- 詳細な作用機序データ（MOA）の補充
- 日本での承認・供給状況の確認
- 参考：REGOSARC で有効性が示された非脂肪細胞性軟部肉腫（平滑筋肉腫、滑膜肉腫など）への検討の方が、エビデンス上は有望です。

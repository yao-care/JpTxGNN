## アバタセプト：T細胞共刺激阻害薬 → 強直性脊椎炎 (ankylosing spondylitis)
{: .text-alpha }

## 一言要約

アバタセプトは CD80/86–CD28 経路によるT細胞共刺激を阻害する CTLA-4-Ig 製剤で、日本では3件の承認が有効です。
TxGNN モデルは**強直性脊椎炎 (ankylosing spondylitis)** に有効である可能性を予測していますが、この疾患を直接検討した研究は小規模な非対照試験が中心で、効果に否定的な報告もあります。
このため、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただしアバタセプトは CTLA-4-Ig 融合蛋白として、CD80/86 と CD28 の結合を阻害し、T細胞の活性化を抑えることが知られています。この作用は、関節リウマチなど免疫介在性の関節疾患で利用されています。

強直性脊椎炎も免疫介在性の脊椎関節炎であるため、T細胞の活性化を抑えることで炎症が軽減する可能性は理論上あります。

ただし、強直性脊椎炎の病態は主に TNF/IL-17/IL-23 経路によって駆動されると考えられており、T細胞共刺激経路の寄与は限定的とされます。機序的な妥当性は「弱い」と評価するのが適切です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 強直性脊椎炎を直接検討した試験は小規模な非盲検パイロット試験のみで、対照を置いた有効性データがありません。
- レビュー文献では、アバタセプトを含む非TNF生物学的製剤は有効でないとされ、機序的な根拠も弱いため、現時点で開発を進める根拠は不十分です。

**進める場合に必要なもの：**
- 既存の非盲検パイロット試験（NCT00558506、PMID 21415053）の結果の詳細な確認
- ランダム化比較試験による有効性データ（実施する場合）
- 詳細な作用機序データ（MOA）
- 添付文書に基づく警告・禁忌の確認
- 併用薬（特に他の生物学的製剤や JAK 阻害薬）に関する安全性管理計画

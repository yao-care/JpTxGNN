# アバタセプト：関節リウマチ・若年性特発性関節炎から リウマチ性血管炎へ

## 一言要約

アバタセプトは CTLA4-Ig 融合タンパク質で、元々関節リウマチ、若年性特発性関節炎、脊椎関節症などの治療に使用されていました。
TxGNN モデルは**リウマチ性血管炎 (rheumatoid vasculitis)** に有効である可能性を予測していますが、裏付けとなるのは**症例報告・症例集積が中心の文献**と、関連性の低い **1 件の臨床試験**にとどまります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 関節リウマチ、若年性特発性関節炎、脊椎関節症（日本の承認適応症の記載は、今回compiledしたデータにはありません） |
| 予測新規適応症 | リウマチ性血管炎 (rheumatoid vasculitis) |

| 推奨決定 | Hold |

## この予測が妥当である理由

詳細な作用機序データは、今回のデータにはありません。ただし、アバタセプトは CTLA4-Ig であり、CD80/CD86 に結合して CD28 を介した T 細胞の共刺激を遮断することが知られています。

リウマチ性血管炎は、T 細胞・B 細胞が関与する免疫複合体性の炎症を伴います。そのため、共刺激遮断で炎症が抑えられる可能性は機序的には考えられます。関節リウマチという同じ基盤疾患を持つ点も、予測の背景にあります。

ただし、エビデンスは一貫していません。ある症例ではアバタセプトが速やかに奏効しましたが、別の症例ではアバタセプト投与中にリウマチ性血管炎が新たに発症し、リツキシマブで改善しています。

## 安全性に関する考慮事項

- **薬物相互作用**：73 件の相互作用が登録されています。重大度が高いものは、アダリムマブ、バリシチニブ、セルトリズマブ ペゴル、BCG 生ワクチン（Tice 株）です。いずれも免疫抑制の重複や生ワクチンの感染リスクに関わります。中等度には、アナキンラ、アザチオプリン、カナキヌマブ、アレムツズマブ、アレファセプト、ロフルミラストと、複数の生ワクチンや不活化ワクチンがあります。亜鉛製剤との相互作用は軽度です。
- 添付文書上の警告・禁忌については、今回のデータにはありません。添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
リウマチ性血管炎に対するエビデンスは、少数の症例報告に限られ、有効例と発症例が混在しています。血管炎を直接検証した臨床試験もありません。また、日本の承認はすべて取消であり、添付文書の警告・禁忌データも得られていません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを行う
- 詳細な作用機序データ（DrugBank など）の補充
- リウマチ性血管炎に特化した前向き研究、または症例の系統的な収集
- リツキシマブなど標準治療との比較における位置づけの整理

## 補足：他の予測候補

- **多関節型若年性関節炎**（スコア 99.83%、エビデンスレベル L1）：複数の Phase 3 試験が完了済みです。これは既存適応症の再確認であり、新規の再利用ではありません。
- **強直性脊椎炎**（スコア 99.91%、L3、Hold）：小規模なパイロット試験があるものの、TNF 阻害薬抵抗性の体軸性疾患では有効性が示されていません。
- **炎症性脊椎症**（スコア 99.84%、L3）：効果が示されていない領域であり、病型を限定した検討が必要です。
- **尾骨過可動性、クンメル病、ブラキダクチリー・合指症候群、コロボーマ性小眼球症・肢根性異形成症候群**：機序的な根拠がなく、予測のみに基づいています（L5）。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

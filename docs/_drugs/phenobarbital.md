# フェノバルビタール：不眠症から三叉神経腫瘍へ

## 一言要約

フェノバルビタールは、日本で抗不安薬・抗けいれん薬・催眠鎮静薬として、不眠症などに使用されてきた薬です。
TxGNN モデルは**三叉神経腫瘍 (Trigeminal Nerve Neoplasm)** に有効である可能性を予測していますが、この予測を支持する臨床試験は **0 件**、直接関連する文献もほぼなく、エビデンスはモデル予測のみの段階です。
一方、同じ薬が予測された反射性発作（聴原性発作など）については、動物実験を中心とした文献があり、より現実的な再利用候補です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フェノバルビタールはバルビツール酸系の抗けいれん薬・催眠鎮静薬で、GABA-A 受容体のクロライド電流を増強し、神経の興奮を抑える作用があると考えられています。

ただし、この作用は腫瘍そのものを抑えるものではありません。三叉神経腫瘍に対して抗腫瘍効果を示す根拠はなく、腫瘍に伴うけいれん発作を抑える程度の効果にとどまると考えられます。そのため、この予測は機序的には支持されていません。

なお、予測上位には聴原性発作、摂食誘発発作、startle てんかんなどの反射性発作が並んでいます。これらは GABA 作用による発作閾値の上昇という既知の機序と整合し、機序的にはより妥当です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 三叉神経腫瘍に対する臨床試験はなく、機序的な裏付けも乏しいため、現時点では再利用を進める根拠がありません。
- 日本の承認がすべて取消されている点も、実用化の障壁です。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の取得と解析（PMDA）
- 作用機序（MOA）データの補完（DrugBank）
- 反射性発作（聴原性発作など）に絞った再評価と、ヒトでのエビデンス収集
- 三叉神経腫瘍については、腫瘍関連発作の抑制という限定的な位置づけでの検討

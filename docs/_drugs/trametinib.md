# トラメチニブ：メラノーマから脈絡膜欠損症へ

## 一言要約

トラメチニブは MEK1/2 を阻害する分子標的薬で、元々は BRAF 変異を伴うメラノーマなどの治療に使われています。TxGNN モデルは**脈絡膜欠損症 (Choroideremia)** に有効である可能性を最上位で予測しています。しかしこの予測を支持する**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみです。

## この予測が妥当である理由

トラメチニブは MEK1/2 のアロステリック阻害薬で、MAPK シグナル伝達を遮断します。メラノーマでは BRAF や NRAS の変異による MAPK の過剰な活性化が発がんの主要な原動力であり、そこで効果を発揮します。

脈絡膜欠損症は、CHM/REP1 の機能喪失で起こる X 連鎖性の網膜変性疾患です。MAPK 活性化が病態の中心であるという確立した機序は知られていません。既存適応症との機序的な接点が見当たらないため、この予測を裏付ける臨床的・機序的な根拠は現在ありません。スコアは高いものの、モデル上の関連にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
脈絡膜欠損症に対しては、臨床試験も文献もなく、MAPK 経路との機序的な関連も確認できません。モデルスコアは高いものの、根拠はモデル予測のみです。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報（安全性スクリーニングを進めるうえで必須）
- DrugBank からの作用機序データ
- CHM/REP1 欠損モデルにおける MEK 阻害の前臨床エビデンス
- メラノーマ関連の予測（特に非皮膚メラノーマ）は、脈絡膜欠損症とは別の候補として個別に評価する。BRAF 変異メラノーマでは試験が豊富だが、非皮膚型への外挿は間接的である点に留意する

本結果は研究参考用であり、医療上の助言ではありません。予測は臨床での検証を経て初めて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

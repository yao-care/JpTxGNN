# トラメチニブ：転移性悪性黒色腫から脈絡膜欠損症 (Choroideremia) へ

## 一言要約

トラメチニブは MEK1/2 を阻害する分子標的薬で、元々は転移性悪性黒色腫の治療に使用されていました。
TxGNN モデルは**脈絡膜欠損症 (Choroideremia)** に有効である可能性を予測していますが、現時点で**臨床試験は 0 件、文献も 0 編**です。
この予測はモデル由来のシグナルのみで、実際の研究による裏付けはありません。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 転移性悪性黒色腫 |
| 予測新規適応症 | 脈絡膜欠損症 (Choroideremia) |
| TxGNN 予測スコア | 99.31% |

| 推奨決定 | Hold |

## この予測が妥当である理由

トラメチニブは MEK1 (MAP2K1) と MEK2 (MAP2K2) を阻害するアロステリック阻害薬です。MAPK シグナル経路を遮断することで、BRAF V600 変異陽性の悪性黒色腫などで抗腫瘍効果を示します。

一方、脈絡膜欠損症は CHM/REP1 の機能喪失で起こる X 連鎖性の網膜変性疾患です。既存適応症の黒色腫とは病態が大きく異なり、MEK 阻害との機序的なつながりも確立していません。したがって、この予測は機序に基づく仮説ではなく、**予測のみのシグナル**と位置づけるのが妥当です。

なお、同じ予測リストの 2 位以降は、黒色腫の亜型（非皮膚黒色腫、結節型黒色腫、表在拡大型黒色腫など）が中心です。これらは MAPK 経路との関連が明確で、観察研究や症例報告も一部あります。再利用の優先度を考えるなら、脈絡膜欠損症よりこれらのほうが現実的な検討対象です。

## 安全性に関する考慮事項

- **薬物相互作用**：17 件の相互作用情報のうち、15 件が中等度 (Moderate) です。
  - 併用される抗腫瘍薬：ダブラフェニブ、エンコラフェニブ、ブリガチニブ、ギルテリチニブ、ミドスタウリン、エルダフィチニブ、イデラリシブ、ツカチニブ
  - ホルモン関連薬：アパルタミド、エンザルタミド、エラゴリクス
  - その他：ホスタマチニブ、イサブコナゾニウム、ラスミジタン、サレサイクリン

  残りの 2 件は MEK1/MEK2 に対する標的情報で、相互作用ではありません。

警告・禁忌の詳細については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
脈絡膜欠損症については、臨床試験も文献もなく、機序的な根拠も乏しいため、モデル予測のみの段階です（L5）。さらに MEK 阻害薬には眼障害のリスクがあり、網膜変性疾患への適用には慎重な検討が必要です。

**進める場合に必要なもの：**
- CHM/REP1 欠損と MAPK 経路を結びつける前臨床データ（細胞・動物モデル）
- 網膜への影響を含む眼科的安全性の評価
- 日本の添付文書に基づく警告・禁忌の確認
- 日本では承認が整理済みのため、現在の供給・承認状況の確認
- 優先度の高い黒色腫亜型（非皮膚黒色腫など）を並行して検討すること

# コルヒチン：痛風発作・家族性地中海熱から熱帯熱マラリアへ

## 一言要約

コルヒチンは微小管重合阻害作用を持つ薬で、日本では痛風発作と家族性地中海熱の治療に使われています。
TxGNN モデルは**熱帯熱マラリア (Plasmodium falciparum malaria)** に有効である可能性を予測していますが、臨床試験は **0 件**です。文献は **6 編**あるものの、すべて in vitro 研究または症例集積で、コルヒチンそのものを検証した報告は含まれていません。

## この予測が妥当である理由

現在、詳細な作用機序データ (DrugBank の MOA) はありません。ただし日本の承認情報では、コルヒチンは「白血球（好中球）遊走阻害薬」「微小管重合阻害薬」に分類されています。チューブリンに結合して微小管の重合を妨げることが、この薬の中心的な作用です。

マラリア原虫の細胞骨格も、微小管などのチューブリン系タンパク質に依存しています。提供された in vitro 論文では、チューブリン結合性化合物が熱帯熱マラリア原虫の赤血球内発育を抑えたと報告されています。また、クルクミンが原虫の微小管を乱すという報告もあります。ここから、微小管を標的とする薬が抗マラリア作用を持つ可能性は機序的に考えられます。

ただし、これは間接的な根拠にとどまります。提供された文献のタイトルと要旨には、コルヒチンを直接検証したデータがありません。また、原虫のチューブリンは哺乳類のものと分子レベルで異なると論文が指摘しています。ヒトで抗マラリア作用を得られる用量が、コルヒチンの毒性域を下回るかどうかも不明です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験がなく、文献も間接的な in vitro 研究のみです。コルヒチンは治療域が狭く、中毒例の報告もあるため、現時点でマラリアへの再利用を進める根拠は足りません。

**進める場合に必要なもの：**
- コルヒチンそのものの熱帯熱マラリア原虫に対する in vitro 活性データ (IC50 と、ヒトで到達可能な血中濃度との比較)
- PMDA 添付文書の警告・禁忌の取得（現在は未取得で、安全性スクリーニングに進めない）
- 詳細な作用機序データ (DrugBank API から取得)
- 相互作用の再確認（DDI 検索は 0 件だが、CYP3A4/P-gp 関連の相互作用リスクは既知のため、検索が不完全な可能性がある）
- 既存治療（アルテミシニン系薬剤など）との比較と併用の検討

**補足：** 予測第 2 位の家族性地中海熱は、日本の承認適応症にすでに含まれています。新規適応症というより既存適応症の裏付けであり、予測第 3 位の隆起性皮膚線維肉腫 (DFSP) は TxGNN の予測のみで根拠がなく、Hold です。

なお、本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は、臨床的な検証を経てはじめて応用できます。

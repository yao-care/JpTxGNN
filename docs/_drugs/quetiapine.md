# クエチアピン：統合失調症から網膜ジストロフィーへ

## 一言要約

クエチアピンは非定型抗精神病薬で、元々は統合失調症と双極性障害におけるうつ症状の治療に使用されていました。
TxGNN モデルは**網膜ジストロフィー（retinal dystrophy with or without extraocular anomalies）**に有効である可能性を予測しています。ただし、現時点で支持する臨床試験・文献はなく、**モデル予測のみ（L5）**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 統合失調症、双極性障害におけるうつ症状 |
| 予測新規適応症 | 網膜ジストロフィー（眼外異常を伴う、または伴わない） |
| TxGNN 予測スコア | 99.57% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認はすべて整理済み（現在有効な承認なし） |
| 承認番号数 | 20 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。一般に知られているクエチアピンの薬理は、ドパミン D2、セロトニン 5-HT2A、ヒスタミン H1、α1 受容体に対する拮抗作用です。これらは精神症状の制御に関わる経路で、統合失調症と双極性障害のうつ症状での有効性が確認されています。

一方、遺伝性網膜変性の病態は、これらの受容体経路とは直接結びつきません。既存適応症との関連性も、機序の面から見て確立されていません。現時点で予測を支えているのは TxGNN のスコアだけで、機序的な裏付けは見当たりません。このため、予測は仮説の域を出ず、妥当性を裏付ける根拠は不足しています。

## 安全性に関する考慮事項

- **薬物相互作用**：100 件の相互作用が登録されています。
  - **重大（Major）**：ブプロピオン、モルヒネ
  - **中等度（Moderate）**：アカルボース、ファモチジン、エピネフリン、メトホルミン、ピオグリタゾン、アトロピン、デキサメタゾン、ロペラミドなど
  - 血糖降下薬、抗コリン薬、中枢抑制作用のある薬剤との併用には注意が必要です。
- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではありません）：
  - 循環器：高血圧、起立性低血圧、QT延長症候群、トルサード・ド・ポワント、心筋梗塞
  - 代謝・内分泌：糖尿病、糖尿病性ケトアシドーシス、高脂血症、肥満、甲状腺機能低下症
  - 血液：好中球減少症、無顆粒球症
  - 神経・肝胆：てんかん、肝疾患、胆嚢疾患

  添付文書の警告・禁忌は今回のデータに含まれていないため、実際の禁忌は添付文書で確認してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 臨床試験も文献もなく、根拠は TxGNN のスコアのみです。
- クエチアピンの受容体拮抗作用と遺伝性網膜変性の病態との間に機序的なつながりは確認できず、日本での有効な承認もありません。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の取得と安全性スクリーニング
- DrugBank からの作用機序データの補完
- 網膜変性に対する機序仮説の提示と、前臨床での検証
- 他の予測候補の優先的な検討。たとえば、同じ予測リストの**抜毛症（trichotillomania）**には症例報告とレビューが 6 件あり（L4）、強迫スペクトラムとの関連から機序的にも説明しやすく、研究課題として優先度が高い候補です。
## 免責事項

臨床応用の前に臨床的検証が必要です。

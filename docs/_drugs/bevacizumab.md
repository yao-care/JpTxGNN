# ベバシズマブ：抗VEGF抗体から喉頭蓋腫瘍 (Epiglottis Neoplasm) へ

## 一言要約

ベバシズマブは抗VEGF-Aモノクローナル抗体で、腫瘍の血管新生を阻害する薬です。日本では2つの承認番号で市販されています。
TxGNN モデルは**喉頭蓋腫瘍 (Epiglottis Neoplasm)** に有効である可能性を予測していますが、現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

ベバシズマブは VEGF-A を中和する抗体です。腫瘍が増殖するために必要な血管新生を抑えることで、抗腫瘍効果を発揮します。頭頸部の腫瘍は血管が豊富であるため、この作用機序は喉頭蓋腫瘍にも理論上は当てはまります。

ただし、詳細な作用機序データ (DrugBank の MOA) は今回の Evidence Pack にありません。また、既存適応症と新規適応症の類似性の評価は未実施です。上記の妥当性は、抗VEGF療法の一般的な作用に基づく推論であり、喉頭蓋腫瘍を直接検証した根拠ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
喉頭蓋腫瘍については、TxGNN の予測スコアが高いものの、臨床試験も文献もなく、エビデンスはモデル予測のみ (L5) です。さらに、添付文書の警告・禁忌が未取得で、安全性スクリーニングに進めない状態です。

なお、同じ Evidence Pack の中では「嚢胞性腫瘍 (Cystic Neoplasm)」が最も根拠が厚く、L3 で「Research Question」と判定されています。優先して検討するなら、こちらが候補になります。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析（ブロッキング項目）
- DrugBank からの作用機序 (MOA) データの取得
- 喉頭蓋腫瘍に関する臨床試験・文献の再検索（頭頸部扁平上皮癌を含む関連疾患の範囲で）
- 承認適応症テキストの補完と、既存適応症との類似性評価

本レポートは研究参考用であり、医療上の助言ではありません。予測された適応症は臨床的な検証を経て初めて応用可能となります。

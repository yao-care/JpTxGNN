# ベバシズマブ：卵巣癌・乳癌などの悪性腫瘍から嚢胞性腫瘍 (Cystic Neoplasm) へ

## 一言要約

ベバシズマブは VEGF-A を中和する抗体薬で、元々は卵巣癌、乳癌、結腸の転移性腫瘍、膠芽腫などの治療対象として知られています。
TxGNN モデルの予測順位第 1 位は**喉頭蓋腫瘍 (Epiglottis Neoplasm)** ですが、実際の研究が最も多いのは第 7 位の**嚢胞性腫瘍 (Cystic Neoplasm)** で、**5 件の臨床試験**と **20 編の文献**があります。ただし、これらの多くは既に確立している卵巣癌の研究であり、直接的な証拠は限定的です。

本レポートでは、予測第 1 位の喉頭蓋腫瘍を基準に概要を示し、エビデンスが最も充実している嚢胞性腫瘍を併せて評価します。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 腹膜癌、原発性腹膜癌、卵巣悪性上皮性腫瘍、乳癌、結腸の転移性腫瘍、膠芽腫など（日本の承認適応症の記載はなし） |
| 予測新規適応症 | 喉頭蓋腫瘍 (Epiglottis Neoplasm)（第 1 位）／嚢胞性腫瘍 (Cystic Neoplasm)（エビデンス最多） |
| TxGNN 予測スコア | 喉頭蓋腫瘍 99.90%／嚢胞性腫瘍 99.89% |
| エビデンスレベル | 喉頭蓋腫瘍 L5／嚢胞性腫瘍 L2 |
| 日本市販状況 | 取消済みのみ（現在市販中の承認なし） |
| 承認番号数 | 2 件（いずれも取消） |
| 推奨決定 | 喉頭蓋腫瘍 Hold／嚢胞性腫瘍 Hold（追加検証が必要） |

## この予測が妥当である理由

現在、詳細な作用機序データは登録されていません。ただし、ベバシズマブは VEGF-A を中和し、腫瘍の血管新生を抑えるモノクローナル抗体として知られています。

喉頭蓋腫瘍は頭頸部腫瘍であり、血管新生の関与が考えられるため、機序的には適用可能性があります。ただし、この疾患に特異的な試験や文献はなく、根拠はモデル予測のみです。

嚢胞性腫瘍については、漿液性・粘液性の卵巣嚢胞性腫瘍で VEGF 依存性の血管新生が関与するとされ、第 3 相試験と系統的レビューが存在します。しかしこれらは確立済みの卵巣癌のデータで、「嚢胞性腫瘍」という広い分類との直接性は限られます。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測第 1 位の喉頭蓋腫瘍は、モデル予測のみで臨床試験も文献もなく（L5）、現時点では評価できません。
- 嚢胞性腫瘍は L2 相当のデータがありますが、卵巣癌という既存用途の延長で、対象疾患との直接性が低いため、現時点での推進は難しい状況です。
- 日本ではアバスチンの承認が 2 件とも取消済みで、市販品がありません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを実施する（必須）
- DrugBank から作用機序 (MOA) データを取得し、機序的な関連性を分析する
- 喉頭蓋腫瘍および嚢胞性腫瘍の具体的な病型（悪性か良性か）を定義し直し、疾患特異的な文献・試験を再検索する
- 日本の現行の販売状況と承認適応症を確認する（取消の理由、他社製品や後続品の有無を含む）
- 予測順位上位の頭頸部領域の腫瘍について、前臨床・症例レベルのエビデンスを追加調査する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ジヒドロコデイン・ＤＬ－メチルエフェドリン等配合シロップ：評価不能（データ不足）

## 一言要約

ジヒドロコデイン・ＤＬ－メチルエフェドリン等配合シロップは、ジヒドロコデイン（鎮咳オピオイド）と DL-メチルエフェドリン（気管支拡張薬）を含む配合製剤と推定されます。
DrugBank との照合は実施されましたが、DrugBank ID の取得には至らず、**TxGNN モデルによる新規適応症予測は実施されていません**。
現時点では有効なエビデンスが存在しないため、再利用候補としての評価を進めることができません。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が確立されていないため TxGNN モデルへの投入ができず、新規適応症の予測候補が存在しません。安全性情報も未取得のため、再利用評価プロセスに進む条件が整っていません。

**進める前に必要なもの：**
- 配合成分（ジヒドロコデイン、DL-メチルエフェドリン等）それぞれの DrugBank ID を個別に確認し、成分単位で TxGNN 予測を実施
- PMDA 仿単（添付文書）PDFを取得し、承認適応症・警告・禁忌を抽出
- DrugBank API にて各有効成分の MOA・薬理分類を照合
- 上記データが揃った時点で Evidence Pack を再生成し、本評価フローを再実行

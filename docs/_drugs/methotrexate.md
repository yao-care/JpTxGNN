# メトトレキサート：白血病・固形癌・関節リウマチから肺芽腫へ

## 一言要約

メトトレキサートは代謝拮抗薬（葉酸拮抗薬）で、日本では慢性白血病、絨毛癌、乳癌などの悪性腫瘍と、関節リウマチ、乾癬などに使われています。
TxGNN モデルは**肺芽腫 (Pulmonary Blastoma)** に有効である可能性を予測しています（スコア 99.45%）。
ただし、この予測を裏付ける臨床試験は **0 件**、文献も **0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、メトトレキサートは葉酸拮抗型の代謝拮抗薬で、悪性腫瘍と自己免疫疾患の両方で有効性が確立されています。

一般に知られる作用は、ジヒドロ葉酸還元酵素の阻害です。これにより、チミジル酸とプリンの合成が低下します。DNA 合成が盛んな増殖の速い細胞ほど影響を受けやすいため、肺芽腫のように増殖の活発な上皮・間葉系の肺腫瘍にも作用しうると考えられます。

ただし、これは予測にとどまる機序的な推測です。肺芽腫での臨床試験や文献による裏付けは、今回のデータでは確認できていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
肺芽腫については、臨床試験も文献もなく、モデル予測（L5）のみです。日本の添付文書に基づく安全性情報も未確認で、現時点で先に進める根拠はありません。

参考として、同じ評価で予測された他の適応症には、原発性肺リンパ腫、小細胞肺癌、ホジキンリンパ腫、横紋筋肉腫があります。これらは臨床試験や文献が一定数あり、肺芽腫より検討の優先度は高い可能性があります。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と確認（安全性スクリーニングの前提条件）
- 作用機序（MOA）データの取得（DrugBank API など）
- 肺芽腫に関する症例報告、後ろ向き研究、前臨床データの調査
- 肺芽腫の希少性を踏まえた、実施可能な検証方法の検討

なお、本結果は研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて応用できます。

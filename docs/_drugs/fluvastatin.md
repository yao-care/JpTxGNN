# フルバスタチン：脂質異常症から家族性高コレステロール血症へ

## 一言要約

フルバスタチンは HMG-CoA 還元酵素阻害薬で、元々高コレステロール血症および家族性高コレステロール血症の治療に使用されていました。
TxGNN モデルは**高リポ蛋白血症 (hyperlipoproteinemia)** に有効である可能性を最上位で予測しています。ただしこれは既存適応症とほぼ重なるため、実質的な新規適応症としては**家族性高コレステロール血症 (familial hypercholesterolemia)** が最も根拠が厚く、**4 件の臨床試験**（うちフルバスタチン自体の Phase 3 は 1 件）と **20 編の文献**があります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 高コレステロール血症、家族性高コレステロール血症（脂質異常症治療薬、HMG-CoA 還元酵素阻害薬） |
| 予測新規適応症 | 高リポ蛋白血症 (hyperlipoproteinemia) |
| TxGNN 予測スコア | 99.99% |
| エビデンスレベル | L2（高リポ蛋白血症）。参考：家族性高コレステロール血症は L1 |
| 日本市販状況 | 販売承認はすべて整理済み（取消のみ） |
| 承認番号数 | 18 件 |
| 推奨決定 | Proceed with Guardrails |

> 注意：予測第 1 位の高リポ蛋白血症は、既存の承認適応症と同じ脂質異常症の範囲にあり、真の意味での再利用シグナルではありません。以降は、この第 1 位予測を基本としつつ、補足として他の予測にも触れます。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フルバスタチンは HMG-CoA 還元酵素阻害薬（スタチン系）に分類されます。肝臓でのコレステロール合成を抑え、LDL 受容体を増加させて LDL-C を下げます。これは承認済みの脂質低下作用と一致します。

高リポ蛋白血症は、既存適応症の高コレステロール血症と同じ脂質代謝異常の範囲にあります。そのため機序的に適用可能であり、予測の妥当性は高いといえます。

他の予測候補では妥当性に差があります。

- **家族性高コレステロール血症**：小児ヘテロ接合型での Phase 3 試験があり、直接的な裏付けがあります。
- **ホモ接合型家族性高コレステロール血症**：機能的な LDL 受容体がほとんどないため、効果は限定的と見込まれます。
- **HIV 感染症**：抗レトロウイルス療法に伴う脂質異常の管理が中心で、HIV 自体への効果を示す証拠ではありません。
- **その他（CETP 欠損症、7α-水酸化酵素欠損症、神経発達障害、SIV、ネコ AIDS、前立腺線維腫など）**：TxGNN の予測のみで、裏付けは見つかっていません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、TxGNN の知識グラフに基づく情報）：肝疾患、胆嚢疾患、ミオパチー、筋疾患、骨格筋疾患、家族性周期性四肢麻痺、低血圧性疾患、物質乱用・依存、横紋筋融解症、結節性筋膜炎、外傷
- **薬物相互作用**（DDInter、計 100 件の登録）：
  - 中等度：アプレピタント、メトロニダゾール、オキサンドロロン、ナルトレキソン、ナテグリニド、ニチシノン、ロスバスタチン、シンバスタチン、チニダゾール、グリブリド、ペクチン
  - 重症度不明：カルシトリオール、ドキシサイクリン、シメチジン、エピネフリン、マンニトール、ジシクロミン、ファモチジン、アセチルサリチル酸、パントプラゾール
  - 他のスタチンとの併用は、筋障害リスクの観点から特に注意が必要です。

警告・禁忌の添付文書情報は今回取得できていないため、実際の使用前に添付文書の確認が必要です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 第 1 位の予測（高リポ蛋白血症）は既存の脂質低下作用の範囲内で、機序的な妥当性は高い一方、新規性は乏しい状況です。
- 実質的に最も根拠が厚い家族性高コレステロール血症（小児ヘテロ接合型）には、フルバスタチンの Phase 3 試験と複数の RCT があります。
- 一方、ホモ接合型 FH、HIV 感染症、およびその他の予測は、エビデンスが間接的か、まったくありません。ホモ接合型 FH と HIV 感染症は研究課題の段階、それ以外は保留が妥当です。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の確認（今回は取得できていません）
- 詳細な作用機序データ（MOA）の補充
- 日本では販売承認がすべて取消済みのため、再申請や代替薬の位置づけなど、事業上の判断
- 筋障害・肝機能に対するモニタリング計画と、併用薬（特に他のスタチン）の管理方針
- 高リポ蛋白血症に対するフルバスタチン自体の直接的な試験データ（現状ではほぼありません）
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# フルバスタチン：高コレステロール血症から高リポ蛋白血症へ

## 一言要約

フルバスタチンは HMG-CoA 還元酵素阻害薬（スタチン）で、日本では高コレステロール血症と家族性高コレステロール血症の治療に承認されています。
TxGNN モデルは**高リポ蛋白血症 (Hyperlipoproteinemia)** に有効である可能性を予測しています。
これは既承認の脂質異常症と同じ疾患領域で、真の意味での再利用ではなく、承認済み用途に近い予測です。
現在 **5 件の臨床試験**と **20 編の文献**が関連していますが、フルバスタチン単独を直接検証した登録試験は含まれていません。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フルバスタチンはスタチン系脂質異常症治療薬の一つで、高コレステロール血症での有効性が確認されています。機序的にも高リポ蛋白血症に適用可能と考えられます。

スタチンは HMG-CoA 還元酵素を阻害して肝臓でのコレステロール合成を減らし、LDL 受容体の発現を高めて LDL-C を低下させます。これは高リポ蛋白血症の中心的な病態と一致します。なお、この作用機序の説明は薬物クラスの一般知識によるもので、DrugBank の MOA データに基づくものではありません。

既存適応症（高コレステロール血症）と予測適応症（高リポ蛋白血症）は、どちらも血中脂質代謝の異常です。したがって、この予測は新しい疾患領域への拡大ではなく、既承認の使い方に近い内容です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
フルバスタチンは日本で高コレステロール血症・家族性高コレステロール血症の適応を取得済みで、予測適応症は同じ脂質異常症の領域にあります。公表された RCT 文献もあり、追加のリスクは小さいと考えられます。ただし、登録試験の多くは他剤のものであり、安全性データも未確認のため、条件付きで進めます。

**進める場合に必要なもの：**
- PMDA の添付文書を取得し、警告・禁忌・相互作用を確認する（安全性スクリーニング前の必須事項）
- DrugBank から作用機序（MOA）データを補完する
- 高リポ蛋白血症に対するフルバスタチン単剤の試験を追加で確認する。今回の試験リストには含まれていない
- CYP2C9 基質としての薬物相互作用、および小児・特殊集団のモニタリング計画を作成する

**参考（同一薬物の他の予測適応症）：**
- 家族性高コレステロール血症（予測スコア 99.89%）には、小児ヘテロ接合体 FH を対象とした Phase 3 のフルバスタチン試験 [NCT00171236](https://clinicaltrials.gov/study/NCT00171236)（完了、84 例）があります。エビデンスレベルは L1 で、推奨は Proceed with Guardrails です。
- ホモ接合体家族性高コレステロール血症は L4 で、Research Question として位置づけられます。
- CYP7A1 欠損症による高コレステロール血症、HIV 感染症、CETP 欠損症など残りの予測は、モデル予測のみ（L5）で Hold です。

本結果は研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的検証を経て初めて応用できます。
## 免責事項

臨床応用の前に臨床的検証が必要です。

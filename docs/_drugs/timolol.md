# チモロール：緑内障（β遮断薬）から原発性遺伝性緑内障へ

## 一言要約

チモロールは非選択的β遮断薬の点眼薬で、元々緑内障の治療（眼圧下降）に使用されていました。
TxGNN モデルは**原発性遺伝性緑内障 (primary hereditary glaucoma)** に有効である可能性を最上位で予測していますが、この疾患には臨床試験も文献もなく、予測のみの段階です。
一方、同じ緑内障領域の**閉塞隅角緑内障**と**開放隅角緑内障**には、それぞれ臨床試験と複数の RCT 文献があり、実質的な評価はこの 2 疾患で行えます。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 抗緑内障薬、β遮断薬 |
| 予測新規適応症 | 原発性遺伝性緑内障 (primary hereditary glaucoma) |
| TxGNN 予測スコア | 98.64% |
| エビデンスレベル | L5（この疾患単独の場合） |
| 日本市販状況 | 販売承認は全て取消済み（現在市販なし） |
| 承認番号数 | 20 件（すべて取消） |
| 推奨決定 | Hold |

> 参考：同じ緑内障領域の他の予測では、閉塞隅角緑内障（スコア 97.23%）と開放隅角緑内障（スコア 86.50%）がいずれも L1、Proceed with Guardrails と判定されています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、チモロールは非選択的β遮断薬で、毛様体上皮のβ受容体を遮断して房水産生を減らし、眼圧を下げます。

眼圧の上昇は緑内障全般に共通する主要な危険因子です。そのため、既存適応症である緑内障の治療と、遺伝性の原発緑内障は、眼圧を下げるという点で機序的に結びつきます。ただし、この疾患に特化した試験や文献はなく、根拠は TxGNN の予測に限られます。

なお、閉塞隅角緑内障では、チモロールは房水産生を抑えるだけで、閉塞した隅角自体は開きません。レーザー虹彩切開術や手術などの補助療法の位置づけになります。

## 安全性に関する考慮事項

- **禁忌（疾患ネットワーク上の情報）**：TxGNN の知識グラフには、重症筋無力症、起立性低血圧、糖尿病、糖尿病性ケトアシドーシス、肝疾患、腎疾患、膵炎、全身性エリテマトーデスなど約 30 疾患との禁忌関係が登録されています。これは添付文書の記載ではないため、確認が必要です。
- **薬物相互作用**：100 件の相互作用が登録されています。重大（Major）なものはエピネフリンです。中等度（Moderate）にはヒドロコルチゾン、デキサメタゾン、ブプロピオン、モルヒネ、アトロピン、シメチジン、カナグリフロジン、ダパグリフロジンなどがあります。
- **文献上の注意**：全身性のβ遮断薬の禁忌（喘息、徐脈、心ブロック）への配慮が必要です。点眼後に間質性肺疾患が生じた症例報告（PMID 26236595）があります。

添付文書の警告・禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
原発性遺伝性緑内障は、TxGNN の予測スコアが高い一方、臨床試験も文献もなく L5 にとどまります。日本の承認がすべて取消されていることも、前進を難しくしています。

**進める場合に必要なもの：**
- 原発性遺伝性緑内障（先天・若年発症を含む）でのチモロールの有効性を示す臨床データ。評価対象を、エビデンスが厚い開放隅角緑内障（L1）や閉塞隅角緑内障（L1、補助療法）に切り替える選択肢もあります
- 添付文書の警告・禁忌の取得（PMDA 公開情報の解析）
- 作用機序（MOA）データの補完（DrugBank の照会）
- 取消済みの承認状況の確認（再承認や他剤形での入手可能性）
- 全身性β遮断薬の禁忌と薬物相互作用に基づく、対象患者の選定基準とモニタリング計画
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

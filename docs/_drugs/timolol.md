# チモロール：緑内障から原発性遺伝性緑内障へ

## 一言要約

チモロールは非選択的β遮断薬で、日本では点眼薬として緑内障の治療に使われています。
TxGNN モデルは**原発性遺伝性緑内障 (primary hereditary glaucoma)** に有効である可能性を予測していますが、この疾患に直接関係する臨床試験・文献は **0 件**です（登録されている 1 件の試験は無関係な疾患を対象としています）。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。ただし Evidence Pack の説明によると、チモロールは非選択的β遮断薬で、毛様体上皮のβ受容体を遮断して房水産生を減らし、眼圧を下げます。

既存の適応症がすでに緑内障のため、今回の予測は別の臓器・領域への展開というより、緑内障の中の病型を広げるものです。眼圧を下げるという作用は病型を問わず有用と考えられ、機序的には妥当です。

ただし、遺伝性緑内障に特有の根拠（試験・文献）は示されていません。妥当性の裏付けは機序の推論とモデルスコアにとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、原発性遺伝性緑内障に対する試験・文献がなく、モデル予測と機序の推論だけが根拠です。安全性データ（警告・禁忌）も未取得のため、現時点では進められません。

なお、同じ Evidence Pack には、より根拠の強い緑内障関連の予測があります。閉塞隅角緑内障（スコア 97.23%、慢性閉塞隅角緑内障でのチモロールとラタノプロストのRCT、メタアナリシスあり）、開放隅角緑内障（スコア 86.50%、多数の Phase 3 試験あり）、隅角閉塞緑内障（スコア 85.50%）は、いずれも L1 で Proceed with Guardrails と判定されています。優先して評価する場合は、これらが有力です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現在ブロッキングのデータ欠落）
- DrugBank からの作用機序 (MOA) データの取得
- 原発性遺伝性緑内障に特化した臨床試験・文献の探索
- 投与経路の適合性確認（現在は未評価）

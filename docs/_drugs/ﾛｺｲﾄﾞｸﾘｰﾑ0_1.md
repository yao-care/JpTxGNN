## 一言要約

## 結論と次のステップ

**決定：Hold**

**理由：**
薬物名が半角カタカナの品牌名（ﾛｺｲﾄﾞｸﾘｰﾑ0.1%）で入力されたため、DrugBank ID の確定および TxGNN 予測の実行に必要な前提条件が整っていません。PMDA 照会も 0 件であり、日本市販状況の正確な把握ができていない状態です。

> **補足**：「ロコイドクリーム」は一般にヒドロコルチゾン酪酸エステル（Hydrocortisone Butyrate）の外用製剤として知られており、日本では PMDA に承認実績がある可能性があります。INN または成分名での再照会を推奨します。

**進める場合に必要なもの：**
- 正式な INN の確認（例：Hydrocortisone Butyrate）
- DrugBank ID の取得（DrugBank API を成分名で再照会）
- PMDA 承認情報の再照会（INN または成分名「ヒドロコルチゾン酪酸エステル」で検索）
- TxGNN による再利用予測の実行
- 作用機序（MOA）データの補充（DG002 の解消）
- 添付文書（仿単）からの警語・禁忌情報の取得（DG001 の解消）

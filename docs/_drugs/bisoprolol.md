# ビソプロロール：高血圧・狭心症から悪性腎血管性高血圧へ

## 一言要約

ビソプロロールは β1 選択的遮断薬で、元々本態性高血圧症、狭心症、拡張型心筋症、頻脈性心房細動の治療に使用されていました。
TxGNN モデルは**悪性腎血管性高血圧 (malignant renovascular hypertension)** に有効である可能性を予測していますが、この疾患に直接関連する臨床試験や文献はありません。
予測はモデルのみに基づいており、エビデンスレベルは **L5** です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ビソプロロールは β1 選択的遮断薬として知られており、心拍数と血圧を低下させ、腎臓からのレニン放出も抑えます。

悪性腎血管性高血圧は、レニン・アンジオテンシン系の活性化が病態に関与する重症の高血圧です。ビソプロロールの既存適応症である高血圧症と病態が近く、β1 遮断によるレニン抑制は理論上、機序的に関連します。

ただし、この関連性は理論的なものにとどまります。支持する臨床試験も文献もなく、予測の根拠は TxGNN のスコアだけです。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測は TxGNN のスコアのみに基づき、悪性腎血管性高血圧に関する臨床試験も文献もありません。日本では現在、販売中の承認もありません。

**進める場合に必要なもの：**
- PMDA 添付文書から警告・禁忌を取得し、安全性スクリーニングを完了する
- DrugBank から作用機序（MOA）データを取得する
- 悪性腎血管性高血圧に対する β 遮断薬の臨床試験・文献を調査する
- 現在の日本での販売状況（取消の経緯を含む）を確認する
- 慢性肺性心など、エビデンスが比較的多い候補を優先して検討する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

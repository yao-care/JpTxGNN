# ビソプロロール：本態性高血圧症などから悪性腎血管性高血圧へ

## 一言要約

ビソプロロールは選択的β1遮断薬で、日本では本態性高血圧症、狭心症、拡張型心筋症、頻脈性心房細動に使用されています。
TxGNN モデルは**悪性腎血管性高血圧 (malignant renovascular hypertension)** に有効である可能性を予測しています（スコア 99.94%）。
ただし、この適応症を直接支持する臨床試験・文献は **0 件**で、現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ビソプロロールは選択的β1遮断薬で、レニン分泌を抑えて血圧を下げます。この作用は腎血管性高血圧の病態（レニン－アンジオテンシン系の亢進）と機序的に整合します。

一方で、悪性高血圧は緊急症であり、通常は用量調節しやすい注射薬で管理されます。経口のβ遮断薬が第一選択になるとは考えにくく、今回の予測は知識グラフ上の関連に基づく仮説の段階です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、悪性腎血管性高血圧を直接支持する臨床試験・文献がなく、エビデンスは L5 です。
- 悪性高血圧は注射薬での管理が標準のため、経口のビソプロロールを評価する臨床的な必然性も現時点では低いと考えられます。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得する（現状は欠落しており、安全性スクリーニングに進めません）
- DrugBank から作用機序（MOA）を取得し、機序面の解析を補う
- 腎血管性高血圧・悪性高血圧に対するβ遮断薬の文献を再検索する
- 優先候補を再検討する（慢性肺性心はエビデンスが最も多いが間接的。BICS 試験などの結果を精査する必要がある）

※本結果は研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて応用できます。

# クロトリマゾール：カンジダ症・白癬などの真菌感染症から ざ瘡（acne）へ

## 一言要約

クロトリマゾールは、日本ではクリームや腟錠として、カンジダ腟炎・外陰腟炎、白癬、カンジダ症、癜風、口腔カンジダ症などに使われている抗真菌薬です。
TxGNN モデルは**ざ瘡 (acne)** に有効である可能性を予測しています。
ただし裏付けは、**中断中の臨床試験 1 件**（3 剤配合クリーム）のみで、**文献は 0 編**です。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。日本の承認情報では、クロトリマゾールは「抗真菌薬、エルゴステロール合成阻害薬」に分類されています。アゾール系抗真菌薬として、真菌の細胞膜に必要なエルゴステロールの合成を妨げ、真菌の増殖を抑えます。

ざ瘡との機序的な接点は、次の 2 点です。
- マラセチアなどの酵母様真菌がざ瘡様の皮疹に関与する場合、抗真菌作用が効く可能性があります。
- クロトリマゾールには一定の抗炎症作用もあるとされています。

ただし、これは仮説の段階です。ざ瘡の主因は皮脂分泌、毛包の角化異常、アクネ菌、炎症であり、抗真菌作用だけでは中心的な病態に届きません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- ざ瘡についての裏付けは、中断中の 3 剤配合試験 1 件だけです。文献もなく、クロトリマゾール単独の効果は確認できません。
- 抗真菌作用がざ瘡の主な病態に対応するとは言いにくく、現時点で再利用を進める根拠はありません。

**参考（他の予測候補との関係）：**
- 外陰腟炎（予測 2 位、L1）と表在性真菌症（予測 9 位、L2）は、証拠が厚く Proceed with Guardrails の判定です。ただし、いずれも日本の既存適応症とほぼ重なります。新規の再利用というより、モデル予測の妥当性を裏付ける結果と見るのが適切です。
- 萎縮性腟炎、深在性の皮膚糸状菌症（深在性白癬、マヨッキー肉芽腫など）は、機序や剤形の面で外用クロトリマゾールに適さない可能性が高く、優先度は低いです。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現状、安全性審査に進めない阻害要因）
- DrugBank からの作用機序データの補完
- クロトリマゾール単独でのざ瘡に対する前臨床・臨床データ（マラセチア関与型ざ瘡など、対象の絞り込みを含む）

本レポートの内容は研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証が必要です。

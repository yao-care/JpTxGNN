# ジルチアゼム：狭心症・本態性高血圧症から脳血管障害へ

## 一言要約

ジルチアゼムはカルシウムチャネル遮断薬で、元々狭心症と本態性高血圧症の治療に使用されていました。
TxGNN モデルの予測スコア最上位は「obsolete susceptibility to ischemic stroke」ですが、これは廃止された疾患名で、裏付けとなるエビデンスはありません。そこで本レポートでは、臨床試験と文献が実際に紐づく最上位の予測である**脳血管障害 (Cerebrovascular Disorder)** を中心に評価します。
この予測に対しては **1 件の臨床試験**と **20 編の文献**が見つかっていますが、いずれもジルチアゼムの有効性を直接示すものではなく、間接的な情報にとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ジルチアゼムは L-type カルシウムチャネルを遮断するベンゾチアゼピン系のカルシウム拮抗薬です。血管平滑筋の緊張と血圧を下げ、房室結節の伝導を遅らせます。

脳血管障害は高血圧や血管トーヌスと深く関わるため、血管拡張と降圧が脳血管リスクの低減につながる可能性は機序的に考えられます。カルシウム流入が虚血性神経障害に関与することも、動物実験レベルで検討されています（ネコの急性脳卒中モデルでの検討など）。

ただし、現時点のエビデンスは間接的です。血圧管理試験、心房細動に関する文献、薬物相互作用の報告が中心で、脳血管障害に対するジルチアゼムの有効性を直接示すデータはありません。他の上位予測（脳幹梗塞、肺高血圧症、悪性高血圧性腎疾患など）も機序的な推測にとどまります。ABri アミロイドーシスと Braddock 症候群には、明確な機序的関連が確認できません。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の情報）**：添付文書の記載ではなく、知識グラフ上の薬物と疾患の禁忌関係です。腎疾患、肝疾患、大動脈弁狭窄症、低血圧、肥大型心筋症、心室頻拍、房室ブロック、洞不全症候群、WPW 症候群、Lown-Ganong-Levine 症候群、好中球減少症・無顆粒球症、血管性浮腫などが挙がっています。
- **薬物相互作用**：100 件の相互作用が確認されています。主要なものは次のとおりです。
  - **Major**：ロペラミド
  - **Moderate**：ヒドロコルチゾン、デキサメタゾン、ベタメタゾン、トリアムシノロン、ブデソニド、ピオグリタゾン、ブプロピオン、アプレピタント、モルヒネ、アセチルサリチル酸、カナグリフロジン、各種カルシウム製剤
- ジルチアゼムは CYP3A4 と P 糖タンパク質の阻害薬です。DOAC（アピキサバン、リバーロキサバン）との併用では出血リスクの上昇が懸念されます。脳血管疾患の患者では抗凝固薬を使用する場面が多いため、特に注意が必要です。
- 添付文書の警告・禁忌の詳細は取得できていません。詳しくは添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 脳血管障害に対するジルチアゼムの直接的な有効性を示す臨床エビデンスがなく、現在の裏付けは間接的な試験・文献と機序的な推測にとどまります。
- 最上位の予測は廃止された疾患名で、他の上位予測にもエビデンスがありません。
- 日本では販売中の承認がなく、承認整理後の状況も確認が必要です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と解析
- DrugBank からの作用機序 (MOA) データの補完
- 脳血管障害におけるジルチアゼムの有効性を直接評価する臨床研究、またはシステマティックレビュー
- 廃止された疾患名の予測を現行の疾患分類に対応づける整理
- 抗凝固薬との併用リスクを含む、対象集団の安全性モニタリング計画
- 投与経路と剤形の適合性評価（現在は未評価）
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ロルノキシカム：関節リウマチから片頭痛へ（主要な新規候補）

## 一言要約

ロルノキシカムはオキシカム系の NSAID（COX 阻害薬）で、日本では関節リウマチの鎮痛・抗炎症薬として承認されていました。TxGNN モデルの予測第 1 位は**関節リウマチ**ですが、これは既存適応症そのもので、新規の再利用シグナルではありません。実質的な新規候補として最も根拠が厚いのは**片頭痛 (migraine disorder)** で、完了済みの Phase 2 試験 1 件と総説 2 編があります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 関節リウマチ（鎮痛薬・抗炎症薬・シクロオキシゲナーゼ2阻害薬） |
| 予測新規適応症 | 予測第 1 位：関節リウマチ (rheumatoid arthritis)。既存適応症と同一。実質的な新規候補は片頭痛 (migraine disorder) |
| TxGNN 予測スコア | 99.90%（関節リウマチ）。片頭痛は 99.87% |
| エビデンスレベル | L3（関節リウマチ）。片頭痛は L2 |
| 日本市販状況 | 承認は全て整理済み（現在市販なし） |
| 承認番号数 | 6 件（全て整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。文献情報によると、ロルノキシカムは COX-1 と COX-2 を非選択的に阻害するオキシカム系 NSAID で、プロスタグランジン介在性の炎症と疼痛を抑えます。血中半減期が 3〜5 時間と比較的短いことも特徴です。

関節リウマチへの適用は、この作用がそのまま症状管理に当てはまる、既存適応症の再確認です。予測の妥当性を示すものではありますが、再利用の根拠にはなりません。

新規候補のうち片頭痛は、プロスタグランジンによる三叉神経血管系の炎症と疼痛が関わるため、NSAID が急性期治療に使われています。頭痛全般 (headache disorder) も同様に、鎮痛作用の面から間接的に関連します。一方、先天性の形態異常症候群などの候補には、COX 阻害との妥当な接点がなく、モデル予測のみの支持です。

## 他の予測候補

実質的な新規候補のうち、臨床試験があるものは以下のとおりです。

| 試験番号 | フェーズ | 状態 | 被験者数 | 主な知見 |
|---------|--------|------|----------|---------|
| [NCT00293657](https://clinicaltrials.gov/study/NCT00293657) | Phase 2 | 完了 | 150 | 片頭痛発作の頭痛に対する静注ロルノキシカム（8 mg または 16 mg）の単回投与を、プラセボと二重盲検で比較。結果は未確認 |

- **片頭痛 (migraine disorder)**：スコア 99.87%、L2。上記試験と総説 2 編（[8706598](https://pubmed.ncbi.nlm.nih.gov/8706598/)、[1495823](https://pubmed.ncbi.nlm.nih.gov/1495823/)）があります。
- **頭痛 (headache disorder)**：スコア 99.80%、L3。同じ試験と総説による間接的な支持です。
- **腱炎 (tendinitis)**：スコア 99.72%。肩峰下インピンジメント症候群の RCT（[27468823](https://pubmed.ncbi.nlm.nih.gov/27468823/)、2017）で、ロルノキシカム注射はベタメタゾンに劣りました。前進させる根拠にはなりません。
- **その他**：片頭痛（脳幹性前兆）、三叉神経・自律神経性頭痛、特発性肉芽腫性筋炎などは、臨床試験も文献もなく、モデル予測のみです。ブラキダクチリー合指症候群など先天性症候群は、機序上の関連が見出せません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測第 1 位の関節リウマチは既存適応症で、再利用の根拠になりません。
- 日本の承認は全て整理済みで、現行の添付文書ベースの安全性情報も確認できていません。
- 最有力の新規候補である片頭痛も、Phase 2 試験の結果が未確認で、総説は間接的な支持にとどまります。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と、安全性評価の実施
- 詳細な薬物作用機序データ（MOA）の補充
- NCT00293657 の結果（主要評価項目、有害事象）の確認
- 片頭痛に対する経口・静注の投与経路の適合性評価（日本の既存剤形は経口錠のみ）
- 承認整理の経緯の確認と、現在の供給状況の確認
- 薬物相互作用データの再調査（現状は該当データなし）

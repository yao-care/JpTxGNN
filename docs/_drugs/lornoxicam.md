## Lornoxicam: 片頭痛 (migraine disorder)
{: .text-alpha }

## 一言要約

ロルノキシカムはオキシカム系の非ステロイド性抗炎症薬（COX阻害薬）で、日本では経口錠剤として市販されています。
TxGNN モデルは**片頭痛 (migraine disorder)** に有効である可能性を予測しています。
関連する臨床試験は **1 件**（結果が公表されていない完了済み第2相試験）、文献は総説 **2 編**で、片頭痛に対するロルノキシカムの有効性を直接検証した公表研究はなく、エビデンスレベルは **L5** です。

## この予測が妥当である理由

ロルノキシカムは COX-1 と COX-2 を阻害し、プロスタグランジンの産生を抑える NSAID です。詳細な作用機序データは今回のデータにはありませんが、この薬理作用は広く知られています。

片頭痛発作では、プロスタグランジンが関与する神経原性炎症や痛覚過敏が痛みに寄与すると考えられています。そのため、COX 阻害薬が急性期治療の候補になるという機序的な筋道は成り立ちます。

ただし、これは機序上の推測とモデル予測にとどまります。ロルノキシカムが片頭痛に有効であることを、公表された研究で直接示したデータは今回確認できていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
片頭痛を対象としたロルノキシカム静注の第2相試験は完了していますが、結果が公表されておらず、公表済みの直接的な研究がないため、エビデンスレベルは L5 です。現時点ではモデル予測と機序的な推測が根拠の中心であり、先に進めるには追加の裏付けが必要です。

**進める場合に必要なもの：**
- NCT00293657 の結果の入手（試験実施者への照会や結果公表の確認）
- 片頭痛に対するロルノキシカムの有効性を直接検証した公表研究の確認
- 添付文書に基づく警告・禁忌の整理
- 詳細な作用機序データ（MOA）の補充
- 日本の経口剤形（静注製剤は国内の剤形一覧にありません）での適用可能性の検討

## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# クロバザム：レノックス・ガストー症候群から熱性感染関連てんかん症候群 (FIRES) へ

## 一言要約

クロバザムは 1,5-ベンゾジアゼピン系の抗てんかん薬で、元々レノックス・ガストー症候群などの治療に関連づけられている薬です。
TxGNN モデルは**熱性感染関連てんかん症候群 (Febrile infection-related epilepsy syndrome, FIRES)** に有効である可能性を予測しています。
ただし、臨床試験は **0 件**で、文献は **2 編**（いずれも症例報告・症例集積）にとどまり、クロバザム自体を評価した研究はありません。現時点ではモデル予測を主とする研究課題の段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、クロバザムは GABA-A 受容体を正に調節する 1,5-ベンゾジアゼピンです。GABA 作動性の抑制を強めることで、難治性のてんかん発作を抑える可能性があります。

FIRES は、それまで健康だった小児に発症する新規発症難治性てんかん重積状態 (NORSE) の一型です。通常の抗てんかん薬が効きにくく、高用量の麻酔薬が必要になることも多い疾患です。ベンゾジアゼピン系の GABA-A 調節は、発作抑制という点で機序的に整合します。

ただし、取得できた FIRES の文献が扱っているのはロラゼパム、ミダゾラム、ペランパネルです。クロバザム自体の有効性を示した報告はありません。今回の予測は、クラスレベルの機序的な推論にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
- FIRES に対するクロバザムの臨床試験はなく、文献も他剤の症例報告・症例集積 2 編のみです。TxGNN のスコアは高いものの、エビデンスは機序的推論とモデル予測にとどまります。
- 日本の承認はすべて整理済みで、現時点で国内に製剤の供給根拠がありません。

**進める場合に必要なもの：**
- FIRES におけるクロバザムの使用例（症例報告、レトロスペクティブ研究）の文献調査
- 添付文書（警告・禁忌）の入手と安全性評価
- 詳細な作用機序データ（MOA）の補完
- 日本での製剤の入手性、および剤形・投与経路の適合性の確認
- 小児での認知・行動面の有害事象と多数の薬物相互作用に対するモニタリング計画

**参考：**同じ予測リストの「小児期発症てんかん性脳症 (Childhood onset epileptic encephalopathy)」は、レノックス・ガストー症候群のガイドラインやレビューに支えられています。このため、エビデンスレベルは L2、推奨は Proceed with Guardrails と評価されており、優先的に検討する価値があります。

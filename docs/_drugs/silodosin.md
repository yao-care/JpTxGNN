# シロドシン：排尿障害からアンブラス型全身性多毛症（Ambras type hypertrichosis universalis congenita）へ

## 一言要約

シロドシンは α1 アドレナリン受容体拮抗薬で、日本では排尿障害改善薬として市販されています。
TxGNN モデルは **アンブラス型全身性多毛症** への有効性を高スコアで予測しましたが、裏付けとなる**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみです。機序面でも支持する根拠は見つかっていません。

## この予測が妥当性を欠く理由（機序の検討）

現在、詳細な作用機序データはありません。既知の情報では、シロドシンは α1A サブタイプに選択性の高いアドレナリン受容体拮抗薬で、排尿障害の改善に使われています。

アンブラス症候群は、8q22 の染色体再編成に関連する遺伝性の疾患です。全身の過剰な毛髪成長を特徴とし、毛包の発生異常が背景にあります。α1A 遮断がこの遺伝的基盤や毛髪成長に関わる経路に作用するという既知の機序はありません。

そのため、この予測はグラフベースのモデル出力にとどまり、機序的な裏付けはありません。同様に上位に挙がった多毛症、毛幹異常、低毛症などの毛髪関連疾患も、いずれも L5 で機序上の根拠がありません。

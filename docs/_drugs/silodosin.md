# シロドシン：排尿障害から Ambras 型先天性汎発性多毛症へ

## 一言要約

シロドシンは選択的α1アドレナリン受容体拮抗薬で、元々排尿障害の改善に使用されていました。
TxGNN モデルは **Ambras 型先天性汎発性多毛症 (Ambras type hypertrichosis universalis congenita)** に有効である可能性を予測していますが、
今回まとめたデータには関連する臨床試験も文献もなく、**モデル予測のみ**の段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、シロドシンはα1A アドレナリン受容体を選択的に遮断する薬剤で、排尿障害の改善に用いられてきました。

一方、予測された多毛症について、α1A 遮断と毛包の調節を結びつける確立した機序はありません。多毛症はむしろ血管拡張薬の副作用として知られており、α遮断薬の作用とは異なります。今回の予測は、ネットワーク上の関連性に基づく計算上のものと考えられ、機序面での裏付けは現時点で確認できません。

上位 10 件の予測（多毛症、毛幹異常、先天奇形症候群、肺高血圧症など）のいずれにも、臨床試験・文献の裏付けはありません。血管系の疾患（持続性胎児循環症、慢性血栓塞栓性肺高血圧症）では理論上α1遮断による血管抵抗低下が考えられますが、シロドシンは尿路選択性が高く血管への作用は限定的です。また、低血圧のリスクもあり、推測の域を出ません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、臨床試験・文献がなく（L5）、機序的な裏付けも見当たりません。
- 日本での販売承認はすべて取消済みで、添付文書の安全性情報も未確認です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングに必須）
- DrugBank からの作用機序（MOA）データの補充
- α1A 遮断と毛包・多毛症との関連を示す前臨床・機序研究の探索
- 予測上位疾患（多毛症、毛髪異常）が希少遺伝性疾患であることを踏まえた、実現可能性と必要性の再評価
- 販売承認が取消済みである点を踏まえた、供給・開発の見通しの確認

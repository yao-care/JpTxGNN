# ケトプロフェン：痛風発作・関節リウマチ（鎮痛・抗炎症）から末端中間肢異形成 Hunter-Thompson 型へ

## 一言要約

ケトプロフェンは非選択的シクロオキシゲナーゼ (COX) 阻害薬で、日本では鎮痛・抗炎症・解熱薬として、痛風発作や関節リウマチなどの疾患に使われてきました。
TxGNN モデルは**末端中間肢異形成 Hunter-Thompson 型 (acromesomelic dysplasia, Hunter-Thompson type)** に有効である可能性を予測しています。
ただし、支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ケトプロフェンは COX-1/COX-2 を阻害してプロスタグランジン合成を抑え、鎮痛・抗炎症作用を示す薬です。

一方、予測された疾患は CDMP1/GDF5 経路に関わる遺伝性の骨格異形成症です。COX を介した病態は知られていません。既存適応症との機序的な接点は乏しく、この関連はモデルのスコアだけに基づいています。仮に使えても、関節痛などの対症的な緩和にとどまり、疾患そのものを修飾する効果は期待しにくいと考えられます。

スコアは非常に高い (99.98%) ものの、上位候補の多くは骨格・先天奇形系の希少疾患です。この傾向はモデル特有のバイアスである可能性があり、スコアだけで有効性を判断することはできません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測疾患は遺伝性骨格異形成症で、COX 阻害との機序的な接点がなく、臨床試験も文献もありません。エビデンスはモデル予測のみ (L5) のため、現時点では研究を進める根拠が不足しています。

**進める場合に必要なもの：**
- PMDA の添付文書に基づく警告・禁忌の整理（安全性スクリーニングの前提）
- 詳細な作用機序データ (MOA) の取得と、予測疾患との機序的な関連の検討
- 予測疾患に対する前臨床研究や症例報告の調査
- 投与経路の適合性の確認（日本の主な剤形は外用貼付剤で、全身性の骨格疾患との整合性が未確認）
- 優先度の再検討：第 8 位の脊椎関節症 (L4) は NSAIDs が標準的な対症療法であり、こちらの方が検討しやすい候補です。ただし根拠は間接的なレビュー 1 編のみで、追加の文献確認が必要です。

※本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床的な検証を経て初めて応用できます。

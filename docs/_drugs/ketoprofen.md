# ケトプロフェン：痛風発作・関節リウマチから肢端中間異形成症（Hunter-Thompson 型）へ

## 一言要約

ケトプロフェンは、元々痛風発作や関節リウマチなどの鎮痛・抗炎症・解熱に使用されてきた COX 阻害薬（NSAID）です。
TxGNN モデルは**肢端中間異形成症 Hunter-Thompson 型 (acromesomelic dysplasia, Hunter-Thompson type)** に有効である可能性を予測していますが、関連する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 鎮痛薬・抗炎症薬・解熱薬（痛風発作、関節リウマチ） |
| 予測新規適応症 | 肢端中間異形成症 Hunter-Thompson 型 (acromesomelic dysplasia, Hunter-Thompson type) |
| TxGNN 予測スコア | 99.98% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認はすべて取り消し済み（有効な承認なし） |
| 承認番号数 | 20 件（すべて取り消し） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ケトプロフェンはシクロオキシゲナーゼ（COX）阻害作用を持つ NSAID で、プロスタグランジン合成を抑えることで鎮痛・抗炎症・解熱作用を示します。

一方、Hunter-Thompson 型の肢端中間異形成症は、GDF5 の異常による骨格形成異常です。COX 阻害との間に妥当な機序的関連は見つかっておらず、この予測は知識グラフ上の推論に基づくもので、臨床的・機序的な裏付けはありません。仮に使用するとしても、関節痛への対症的な効果にとどまると考えられます。

なお、予測上位 10 件には、機序的な妥当性が比較的高いものとして「脊椎関節症（感受性）」（スコア 99.86%）があります。NSAID は脊椎関節炎の標準的な対症療法ですが、これについても試験や文献は確認されておらず、エビデンスはモデル予測のみです。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書ではなくモデルの知識グラフに基づく）：高血圧、肝不全、腎疾患、消化性潰瘍（活動性を含む）、血液凝固障害、心筋梗塞、冠動脈血栓症、ヘモグロビン異常症、心血管疾患・心疾患など。
- **薬物相互作用**（合計 100 件のうち主なもの）：
  - 中等度：アセチルサリチル酸、副腎皮質ステロイド（ヒドロコルチゾン、デキサメタゾン、ベタメタゾン、トリアムシノロン、ブデソニド）、メトホルミン、グリメピリド、クロルプロパミド、メサラジン、バルサラジド、ナルトレキソン、クエン酸カリウム、炭酸水素カリウム など
  - 軽度：ファモチジン、ラニチジン、シメチジン、リナクロチド

警告・禁忌の詳細は、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測は TxGNN のモデルスコアのみに基づき、臨床試験・文献がなく、GDF5 欠損に起因する疾患と COX 阻害の間に機序的な関連も認められません。
- 日本の販売承認もすべて取り消されており、再利用を進める基盤が弱い状況です。

**進める場合に必要なもの：**
- 詳細な作用機序データ（MOA）の取得
- 添付文書の警告・禁忌情報の確認（PMDA）
- 機序的妥当性が比較的高い候補（脊椎関節症など）への優先順位の見直しと、文献・試験の調査
- 前臨床での機序検証と、剤形・投与経路の適合性評価
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

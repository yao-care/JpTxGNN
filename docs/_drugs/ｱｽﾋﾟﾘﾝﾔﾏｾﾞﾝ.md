# アスピリンヤマゼン：評価データ不足により再利用候補の評価不可

## 一言要約

アスピリンヤマゼン（`ｱｽﾋﾟﾘﾝﾔﾏｾﾞﾝ`）は日本において市販実績がなく、DrugBank ID・作用機序・承認適応症のいずれも取得できていません。TxGNN モデルによる予測適応症もゼロ件であり、現時点では薬物再利用の可能性を評価するための最低限のデータが揃っていません。判断を下すには追加情報収集が不可欠です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN 予測適応症がゼロ件であり、既存適応症・DrugBank ID・作用機序・安全性データのいずれも揃っていないため、再利用評価を進める根拠がありません。まず薬物同定と基礎データ収集を完了させる必要があります。

**進める前に必要なもの：**
- **薬物名の確認**：半角カタカナ表記 `ｱｽﾋﾟﾘﾝﾔﾏｾﾞﾝ` の INN（国際一般名）を特定し、DrugBank ID を紐付ける
- **PMDA データ再照会**：クエリログで結果件数 0 件。検索クエリの正規化（全角カタカナ・英字など）を試みる
- **DrugBank 補完**：クエリログでは 1 件ヒットしているが Evidence Pack に反映されていない。DrugBank API レスポンスを確認し、MOA・ATC コード・既存適応症を取得する
- **TxGNN 再実行**：DrugBank ID が確定した後、DL 予測を再実行して適応症候補を生成する
- **安全性情報取得**：PMDA 添付文書から警告・禁忌・薬物相互作用を抽出する

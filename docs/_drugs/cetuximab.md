# セツキシマブ：EGFR 陽性の大腸癌・頭頸部癌から軟骨性過誤腫 (Chondroid Hamartoma) へ

## 一言要約

セツキシマブは抗 EGFR モノクローナル抗体で、文献上は主に大腸癌・頭頸部扁平上皮癌の治療に使われています。TxGNN モデルは**軟骨性過誤腫 (Chondroid Hamartoma)** に有効な可能性を高スコアで予測していますが、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。既知の情報では、セツキシマブは EGFR（上皮成長因子受容体）を阻害する抗体医薬で、EGFR 依存性の上皮性腫瘍で有効性が示されています。

しかし、EGFR 依存性とこの良性病変を結び付けるデータは、今回の Evidence Pack にありません。軟骨性過誤腫は良性病変であり、既存適応症の悪性腫瘍とは性質が異なります。予測は TxGNN のスコアのみに基づいており、機序的な裏付けは確認できていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
軟骨性過誤腫に対する臨床試験も文献もなく、機序上の根拠もありません。良性病変に抗悪性腫瘍薬を使うリスクとベネフィットの検討にも進めない状態です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提）
- DrugBank からの作用機序データ取得
- 軟骨性過誤腫における EGFR 発現・依存性の前臨床データ

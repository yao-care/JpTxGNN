# セツキシマブ：結腸直腸癌・頭頸部扁平上皮癌から軟骨様過誤腫へ

## 一言要約

セツキシマブは抗 EGFR モノクローナル抗体で、元々は結腸直腸癌や頭頸部の扁平上皮癌の治療に使用されてきました。
TxGNN モデルは、予測スコア上位に**軟骨様過誤腫 (Chondroid Hamartoma)** を挙げていますが、この疾患に関する臨床試験・文献はなく、モデル予測のみに基づいています。
なお、予測上位 10 件の中では、**前悪性腫瘍 (Pre-malignant Neoplasm)** に **4 件の臨床試験**と **2 編の文献**があり、最も裏付けが進んでいます。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 結腸直腸癌、頭頸部扁平上皮癌（咽頭・喉頭の扁平上皮癌を含む） |
| 予測新規適応症 | 軟骨様過誤腫 (Chondroid Hamartoma) |
| TxGNN 予測スコア | 99.95% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認は取消済み（2 件とも取消） |
| 承認番号数 | 2 件 |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、セツキシマブは上皮成長因子受容体 (EGFR) を標的とする抗体医薬で、EGFR を発現する転移性結腸直腸癌や、放射線療法併用の頭頸部扁平上皮癌で使用されてきました。

ただし、軟骨様過誤腫に EGFR 依存性があることを示す根拠は確認されていません。この予測は TxGNN の知識グラフ上の関連に基づくもので、機序的な裏付けは現時点で不十分です。

参考として、予測上位 10 件のうち一部は機序的にもっともらしい候補です。
- **前悪性腫瘍**：EGFR は上気道消化管の発がん初期から過剰発現するため、化学予防的な役割の可能性があります。
- **嚢胞性腫瘍**：EGFR を発現する腺様嚢胞癌などの唾液腺癌で検討されていますが、有効性は限定的です。
- **歯原性嚢胞**：嚢胞から生じる原発性骨内癌（扁平上皮癌）での EGFR 阻害に関連しますが、嚢胞自体の治療根拠ではありません。

## 安全性に関する考慮事項

- **薬物相互作用**：20 件が確認されています。
  - **Major**：アミノレブリン酸、サリドマイド
  - **Moderate**：プロトンポンプ阻害薬（オメプラゾール、エソメプラゾール、ランソプラゾール、パントプラゾール、ラベプラゾールなど）、フルオロウラシル、カペシタビン、シスプラチン、カルボプラチン、オキサリプラチン、イデラリシブ、メトキサレン、ベルテポルフィンなど

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測第 1 位の軟骨様過誤腫には、臨床試験・文献がなく、機序的な根拠もありません（L5）。
- また、日本での承認は 2 件とも取消済みです。上位候補の中では前悪性腫瘍（L2）が最も進んでいますが、結果が未報告で長期投与の毒性も懸念されます。

**進める場合に必要なもの：**
- 作用機序（MOA）データの補完
- PMDA 添付文書の警告・禁忌の取得と安全性評価
- 軟骨様過誤腫における EGFR 発現・依存性の基礎的な検証
- 前悪性腫瘍を優先候補とする場合、NCT00524017 の結果データの確認
- 日本での販売状況（承認取消の経緯を含む）と、供給可能性の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

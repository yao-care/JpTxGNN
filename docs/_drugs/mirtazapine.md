# ミルタザピン：抗うつ薬から Ohdo 症候群およびその亜型へ

## 一言要約

ミルタザピンは、日本で抗うつ薬（セロトニン受容体拮抗薬）として市販されている薬です。
TxGNN モデルは **Ohdo 症候群およびその亜型 (Ohdo syndrome and variants)** に有効な可能性を予測しました。
ただし、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

ミルタザピンは、α2 アドレナリン受容体、5-HT2/5-HT3 受容体、H1 受容体を拮抗する抗うつ薬です。ノルアドレナリンとセロトニンの神経伝達を高めることで、うつ病に効果を示します。

一方、Ohdo 症候群は KAT6B 遺伝子に関連する先天性の発達症候群です。ミルタザピンの受容体薬理とこの疾患を結ぶ、妥当な機序は見当たりません。この関連は知識グラフに基づく予測にとどまり、臨床的な裏付けもありません。したがって、スコアが高くても、機序面から妥当だと判断することはできません。

現在、詳細な作用機序データは取得できていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
最上位の予測（Ohdo 症候群）には、臨床試験も文献もなく、機序的に妥当な説明もありません。モデル予測のみ（L5）であり、現時点で進める根拠はありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報（安全性スクリーニングの前提となる不足データ）
- ミルタザピンの詳細な作用機序データ（DrugBank から取得）
- 薬物相互作用データの確認（特にセロトニン系薬剤との併用。現状は照会結果なし）
- 順位 9（メランコリー）など、エビデンスのある候補への優先順位の見直し

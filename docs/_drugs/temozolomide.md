# テモゾロミド：膠芽腫・星細胞腫から成人星細胞性腫瘍へ

## 一言要約

テモゾロミドは経口のアルキル化剤で、元々退形成性星細胞腫、星細胞腫（膠芽腫を除く）、脳膠芽腫の治療に使用されていました。
TxGNN モデルは**成人星細胞性腫瘍 (Adult Astrocytic Tumour)** に有効である可能性を予測しており、現在 **2 件の臨床試験**と **20 編の文献**がこの方向性に関連しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 退形成性星細胞腫、星細胞腫（膠芽腫を除く）、脳膠芽腫 |
| 予測新規適応症 | 成人星細胞性腫瘍 (Adult Astrocytic Tumour) |
| TxGNN 予測スコア | 99.36% |
| エビデンスレベル | L1 |
| 日本市販状況 | 市販なし（本レポート用に集計したデータ上） |
| 承認番号数 | 0 件 |
| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、テモゾロミドは経口アルキル化プロドラッグで、MTIC に変換されて DNA（グアニンの O6 位）をメチル化し、ミスマッチ修復を介した細胞傷害性の DNA 損傷を腫瘍細胞に引き起こします。効果は MGMT プロモーターのメチル化状態に左右されます。

今回の予測適応症である成人星細胞性腫瘍は、既存の適応症（退形成性星細胞腫、膠芽腫）と大きく重なります。膠芽腫は星細胞系腫瘍の中で最も悪性度の高いものであり、同じ細胞系譜・同じ作用機序が適用できるため、機序的にも妥当性があります。ただし、この重なりが大きいため、「新規」適応症というより既存適応症の周辺領域・範囲整理に近い予測である点に注意が必要です。

なお、2 位の予測として**馬尾腫瘍 (Cauda Equina Neoplasm)**（スコア 99.30%）があります。脊髄粘液乳頭状上衣腫の再発例で効果を示した症例報告が 1 件ある程度で、臨床試験はなく、エビデンスレベルは L4（研究課題段階）です。

## 安全性に関する考慮事項

- **関連する禁忌・注意疾患（知識グラフ上の情報であり、添付文書の記載ではありません）**：肝不全、血小板減少症、好中球減少症、無顆粒球症、貧血、大球性貧血、ニューモシスチス症、汎血球減少症、リンパ球減少症、骨髄異形成症候群、特発性再生不良性貧血、再生不良性貧血
- **薬物相互作用**：100 件が検出され、うち主なものは以下のとおりです。
  - 中等度：ナルトレキソン
  - 軽度：レボフロキサシン
  - 重症度不明：カルシトリオール、パントプラゾール、ドキシサイクリン、クロトリマゾール、モルヒネ、メトホルミン、オメプラゾール、ランソプラゾール、プレドニゾンなど
- ニューモシスチス肺炎については、化学放射線療法中の予防投与が推奨される一方、予防なしでの発症率を検討した報告もあります。

警告および禁忌の正式な情報（添付文書）は、今回のデータには含まれていません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 成人星細胞性腫瘍（膠芽腫を含む）に対して、完了した Phase 3 RCT（NCT00052455）と、複数の大規模ランダム化試験の文献があり、エビデンスは十分です。ただし、予測適応症が既存適応症と大きく重なっているため、真に新しい適応拡大かどうかの整理が必要です。
- 日本では市販状況が確認されておらず、重大な骨髄抑制リスクもあるため、安全性の確認を条件に進めるのが妥当です。

**進める場合に必要なもの：**
- 日本の添付文書（PMDA）の警告・禁忌情報の取得（現状は安全性スクリーニングを進められない状態です）
- 詳細な作用機序データ（MOA）の補充
- 日本での承認・市販状況の再確認
- 血液毒性（CBC モニタリング）および PJP 予防を含む安全性管理計画
- MGMT プロモーターのメチル化状態に基づく対象患者の選定方針
- 馬尾腫瘍については、追加の臨床データが得られるまで研究課題として扱う

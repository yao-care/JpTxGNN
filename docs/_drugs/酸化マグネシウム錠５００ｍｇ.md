# 酸化マグネシウム錠５００ＭＧ：評価対象薬物（予測適応症なし）

## 一言要約

酸化マグネシウム（Magnesium Oxide）は制酸薬・緩下薬として広く知られる無機化合物ですが、本 Evidence Pack では **TxGNN による新規適応症の予測結果が存在せず**、日本市場での承認情報も取得できていません。入力された薬物名「酸化マグネシウム錠５００ＭＧ」は製品規格表記（剤形＋含量）であり、INN（酸化マグネシウム）ではないため、PMDA クエリで 0 件という結果になった可能性があります。現時点では再利用評価を進めるための基礎データが不足しており、追加データ収集が先決です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による予測適応症が存在しないため、再利用評価の対象候補がなく、報告すべきエビデンスがありません。また、クエリに用いた薬物名が製品規格表記（「酸化マグネシウム錠５００ＭＧ」）であったため、PMDA・DrugBank いずれも正確なマッチングが行われなかった可能性があります。

**進める場合に必要なもの：**
- **INN で再クエリ**：「酸化マグネシウム」または英語 INN「Magnesium Oxide」で PMDA・DrugBank を再検索
- **DrugBank ID の確定**：DrugBank クエリは 1 件ヒットしているが、ID が未取得のため確認と記録が必要
- **MOA データの取得**：DrugBank API から作用機序（緩下・制酸・尿路結石予防）を取得し Evidence Pack に反映
- **TxGNN 予測パイプラインの再実行**：正しい INN と DrugBank ID を用いて予測を実行
- **安全性情報の収集**：PMDA 仿単 PDF から警告・禁忌を取得

> ⚠️ **クエリ品質に関する注記**
> `predicted_indications` が空である主因は、入力薬物名が INN ではなく製品規格名（剤形＋含量表記）である点にあると考えられます。酸化マグネシウムは日本国内で多数の承認製品を持つ既収載薬であり、正規 INN で再実行すれば PMDA 承認情報・TxGNN 予測ともに取得できる可能性が高いです。

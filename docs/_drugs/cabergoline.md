# カベルゴリン：高プロラクチン血症から下垂体癌へ

## 一言要約

カベルゴリンはドパミン D2 受容体作動薬で、元々高プロラクチン血症やプロラクチン産生下垂体腫瘍の治療に使用されていました。
TxGNN モデルは**下垂体癌 (Pituitary Cancer)** に有効である可能性を予測しており、現在 **13 件の臨床試験**と **20 編の文献**が関連する方向性を示しています。ただし、これらは主に下垂体腺腫（良性）を対象としたもので、癌そのものを対象とした直接的な証拠は限られています。

## クイック概要

|------|------|
| 既存適応症 | 高プロラクチン血症、プロラクチン産生下垂体腫瘍 |
| 予測新規適応症 | 下垂体癌 (Pituitary Cancer) |

※ 予測スコア上位の疾患のうち、下垂体癌が最も裏付けとなる証拠が多いため、本レポートでは下垂体癌を主な評価対象としています。

## この予測が妥当である理由

詳細な作用機序データは現在ありません。既知の情報によると、カベルゴリンはドパミン D2 受容体作動薬であり、下垂体腫瘍細胞の D2 受容体を活性化することでホルモン分泌を抑え、腫瘍の増殖を抑える可能性があります。

既存適応症であるプロラクチン産生下垂体腫瘍と下垂体癌は、同じ下垂体由来の腫瘍です。カベルゴリンは腺腫に対して腫瘍縮小効果が報告されており、最近の総説では抗腫瘍作用の新たな機序（増殖抑制や細胞死の誘導）も示されています。

ただし、臨床的な裏付けは主に腺腫（プロラクチノーマや非機能性腺腫）に由来します。癌への適用は間接的な外挿であり、癌そのものについては症例レベルの報告にとどまります。

## 安全性に関する考慮事項

- **関連する禁忌疾患（知識グラフ由来、添付文書の記載ではありません）**：肝疾患、胆嚢疾患、心臓弁膜症、肺線維症、炎症後肺線維症、IgG4 関連後腹膜線維症、重症妊娠高血圧腎症、妊娠高血圧腎症
- **薬物相互作用**：全 60 件が報告されています。主なものは次のとおりです。
  - **重大 (Major)**：ロルカセリン、クラリスロマイシン
  - **中等度 (Moderate)**：メトクロプラミド
- **その他の留意点**：文献で、カベルゴリン長期使用に伴う心臓弁膜症の症例報告や、閉塞隅角緑内障の症例報告があります。長期・高用量使用では心エコーによる監視が重要です。

添付文書に基づく警告・禁忌の情報は今回得られていないため、添付文書の確認が必要です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 同じ下垂体腫瘍（腺腫）に対して、完了した Phase 3 試験を含む複数の臨床試験があり、機序的な妥当性も示されています。一方で、癌そのものを対象とした直接の証拠は症例報告レベルにとどまるため、慎重な条件付きでの進行が妥当です。
- 日本では販売承認が取り消されており、実際の導入には供給面の確認も必要です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と確認
- 詳細な作用機序データ（MOA）の補充
- 下垂体癌（侵襲性・転移性）を対象とした症例集積または探索的試験の設計
- 腺腫から癌へのエビデンス外挿の妥当性に関する専門家レビュー
- 心臓弁膜症のモニタリング計画（心エコー）と、相互作用薬（クラリスロマイシンなど）の管理方針
- 日本での入手可能性（承認取り消しの経緯と代替供給）の確認

### 他の予測適応症について

- **下垂体腺癌 (Pituitary Adenocarcinoma)**（スコア 99.06%、L4）：症例レベルの文献のみで、さらなる調査が必要な研究課題の段階です。
- **緑内障 (Glaucoma)**（スコア 99.01%、L4）：前臨床では眼圧調節に関する知見がありますが、カベルゴリンによる閉塞隅角緑内障の報告があり、安全性上の懸念から保留（Hold）とします。
- **早老・低身長・色素性母斑症候群**、**痙性四肢麻痺型脳性麻痺**：臨床・文献の裏付けがなく、機序的根拠も確認できないため保留（Hold）とします。

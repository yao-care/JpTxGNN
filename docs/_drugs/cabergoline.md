# カベルゴリン：下垂体腺癌（Pituitary Adenocarcinoma）への薬物再利用評価

## 一言要約

カベルゴリンはドパミン D2 受容体作動薬で、日本では「カバサール錠」として市販されています。ただし、今回のデータには承認適応症の記載がありません。
TxGNN モデルは**下垂体腺癌 (Pituitary Adenocarcinoma)** に有効である可能性を予測しています。
裏付けとなるのは**症例報告・症例集積 3 編**のみで、この疾患に直接対応する臨床試験はありません。

## この予測が妥当である理由

カベルゴリンは D2 ドパミン受容体作動薬です。ドパミン反応性の下垂体腫瘍では、ホルモン分泌を抑え、腫瘍の増殖も抑えることが知られています。現在、詳細な作用機序データは Evidence Pack に含まれていません。以下は、機序の要約として提供された情報に基づく説明です。

下垂体腺腫での作用が、腺癌にも及ぶ可能性があるというのが予測の根拠です。ただし、今回の文献は間接的な症例レベルの裏付けにとどまります。

- 異所性 ACTH 分泌症例でのカベルゴリン長期投与の報告
- 下垂体腺腫でカベルゴリンを服用中に膵腺癌が見つかった症例の報告
- MEN1 の症例報告

したがって、腺腫から癌への外挿は未検証です。

## 結論と次のステップ

**決定：Hold**

**理由：**
下垂体腺癌に対しては、症例レベルの間接的な報告しかなく、有効性を示す臨床試験がありません。予測スコアは高いものの、モデル予測に依存した状態です。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提条件）
- 詳細な作用機序データ（DrugBank など）の補充
- 下垂体腺癌そのものを対象とした症例・前臨床エビデンスの追加調査
- 参考情報として、同じ Evidence Pack の予測 3 位「下垂体癌 (Pituitary Cancer)」には、完了済みの Phase 3 試験（NCT03271918、NCT00889525）を含む臨床試験と系統的レビュー・メタ解析があります。次の評価はこちらを優先して検討する価値があります。

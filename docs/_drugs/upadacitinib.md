# ウパダシチニブ：既存適応症（データ未取得）から コロボーマ性小眼球症・近位肢異形成症候群へ

## 一言要約

ウパダシチニブは選択的 JAK1 阻害薬で、日本では「リンヴォック」として市販されています。
TxGNN モデルは**コロボーマ性小眼球症・近位肢異形成症候群 (colobomatous microphthalmia-rhizomelic dysplasia syndrome)** に有効である可能性を予測しています（スコア 99.61%）。
ただし、この予測を支持する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ウパダシチニブは JAK1 を選択的に阻害し、JAK-STAT 経路のサイトカインシグナルを抑える薬です。

一方、予測された疾患は先天性の発生異常を伴う稀少症候群です。炎症や JAK-STAT 経路が病態に関与するという根拠は知られておらず、既存適応症との機序的なつながりは確認できません。この予測の根拠は TxGNN のスコアだけで、裏付けとなるエビデンスはありません。

同じモデルの第 2 位の予測は**合指趾症を伴う短指症候群 (brachydactyly-syndactyly syndrome)**（スコア 99.58%）です。これも先天性の四肢奇形で、JAK-STAT 経路との関連は知られておらず、エビデンスもありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測を支持する臨床試験・文献がなく、疾患の性質から JAK 阻害の機序的な妥当性も見いだせません。TxGNN のスコアだけでは先へ進む根拠にならないため、保留とします。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提条件）
- 作用機序（MOA）データの補完（DrugBank API で照会）
- 既存適応症の確認（承認適応症の記載が空欄のため）
- 予測疾患の病態と JAK-STAT 経路の関連を示す前臨床・機序研究の探索
- 投与経路の適合性評価（現在は保留）

*本結果は研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的な検証を経て初めて応用できます。*

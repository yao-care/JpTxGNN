# ビラノア：評価データ不足により予測分析未実施

## 一言要約

ビラノア（ﾋﾞﾗﾉｱ）について PMDA および DrugBank への照会を実施しましたが、日本国内の承認記録が確認できず、既存適応症・作用機序のデータも取得できませんでした。TxGNN による新規適応症の予測候補は現時点でゼロ件であり、再利用評価を進めるための基礎情報が不足しています。本レポートは現状のデータギャップを整理し、次のアクションを示すものです。

---

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
日本 PMDA での承認記録が見つからず、DrugBank ID も未取得のため DrugBank 上の MOA・安全性データへのアクセスが不完全です。TxGNN 予測候補が 0 件の状態では再利用可能性の評価を実施できません。

**進める場合に必要なもの：**

| 優先度 | アクション | 詳細 |
|--------|-----------|------|
| 🔴 高 | 薬物名の確認・正規化 | 半角カタカナ「ﾋﾞﾗﾉｱ」を全角「ビラノア」または INN 英名（例：bilastine）に統一し、PMDA・DrugBank を再照会 |
| 🔴 高 | DrugBank ID の取得 | DrugBank API で INN 英名または CAS 番号により検索し、正式 ID を特定 |
| 🔴 高 | 作用機序（MOA）の補填 | DrugBank ID 確定後、`mechanism_of_action` フィールドを取得（DG002 対応） |
| 🟡 中 | PMDA 仿単警語・禁忌の取得 | PMDA 官網より仿単 PDF をダウンロードし解析（DG001 対応、承認済の場合） |
| 🟡 中 | TxGNN 予測の再実行 | DrugBank ID 確定後、KG 予測および DL 予測を再実行して候補リストを生成 |
| 🟢 低 | 市販状況の再確認 | 日本未承認であれば、他国（EU・アジア）の承認状況を参照し再利用先市場を検討 |

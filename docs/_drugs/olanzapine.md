# オランザピン：統合失調症・双極性障害から乳児良性発作性斜頸へ

## 一言要約

オランザピンは元々、統合失調症と双極性障害の治療に使われていた抗精神病薬です。
TxGNN モデルは**乳児良性発作性斜頸 (Benign Paroxysmal Torticollis of Infancy)** に有効である可能性を予測しています（スコア 99.54%）。
ただし、この方向性を支持する臨床試験も文献も **0 件**で、根拠はモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、オランザピンはドパミン D2 受容体とセロトニン 5-HT2A 受容体の拮抗薬で、統合失調症と双極性障害での有効性が確立されています。

乳児良性発作性斜頸は、乳児期に発作的な首の傾きを繰り返す運動障害です。ドパミン系やセロトニン系がこの疾患に関与するという見方は、現時点では推測にとどまります。既存適応症との機序的な関連は弱く、裏付けとなるのは TxGNN の予測だけです。

## 結論と次のステップ

**決定：Hold**

**理由：**
乳児良性発作性斜頸については、臨床試験・文献ともになく、機序的な裏付けも乏しいため、モデル予測だけでは先に進められません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析
- DrugBank からの作用機序 (MOA) データの補完
- この疾患に対する症例報告や前臨床研究の探索
- 乳児への使用に関する安全性の評価
- 投与経路の適合性評価

なお、同じ Evidence Pack には、より根拠の強い予測候補があります。**神経症性うつ病**と**メランコリア**は、いずれもエビデンスレベル L1 で、抗うつ薬の増強療法に関する複数のシステマティックレビューとネットワークメタアナリシスが支持しています。ただし、これらは広い意味でのうつ病を対象にした研究で、両疾患に特化した根拠ではありません。次に評価するなら、この 2 件を優先する価値があります。

# オランザピン：統合失調症・双極性障害 から 良性発作性乳児斜頸 へ

## 一言要約

オランザピン（Olanzapine）は非定型抗精神病薬として、世界的に統合失調症・双極性障害の治療に使用されていますが、台湾では現在未承認・未上市の状態です。
TxGNN モデルは**良性発作性乳児斜頸 (Benign Paroxysmal Torticollis of Infancy)** に有効である可能性を予測していますが、現在関連する臨床試験・文献は**いずれも存在せず**、エビデンスはモデル予測のみに留まります。

## この予測が妥当である理由

現在、詳細な作用機序データ（MOA）は取得できていません。オランザピンはD2受容体・5-HT2A受容体を主な標的とする非定型抗精神病薬であり、ドパミン・セロトニン・ヒスタミン・ムスカリン系の複数受体を拮抗することで抗精神病作用および気分安定作用を発揮することが広く知られています。

良性発作性乳児斜頸（BPTI）は偏頭痛等位症（migraine equivalent）の一種であり、乳幼児に発作性の頸部斜位を来す神経疾患です。その病態はカルシウムチャンネル機能異常や三叉神経血管系の過敏性と関連していると考えられており、ドパミン・セロトニン受体の直接的な機能異常とは病理学的に乖離しています。

TxGNN モデルがこの予測を生成した背景として、知識グラフ上で運動障害・発作性疾患に対する広域的な関連付けが行われた可能性が考えられます。しかし、BPTIは乳幼児（小児科領域）を対象とする疾患であり、オランザピンの錐体外路作用・代謝系副作用は当該年齢層において特に懸念され、現時点で機序的合理性および安全性プロファイルの両面から直接的な再利用根拠は認められません。

## 結論と次のステップ

**決定：Hold**

**理由：**
良性発作性乳児斜頸に対するオランザピンのエビデンスは臨床試験・文献ともに皆無であり（L5）、機序的合理性も乏しく、対象が乳幼児であることによる安全性リスクが高いため、現時点での再利用探索は推奨されません。

**補充が必要なデータ：**
- 作用機序（MOA）の正式取得（DrugBank API またはメーカー資料参照）
- 台湾における安全性警告・禁忌情報の取得（TFDA 仿単 PDF 解析）
- BPTI の分子病態とオランザピン薬理の交差点を示す前臨床データの有無確認
- 乳幼児への投与安全性プロファイルの独立したレビュー

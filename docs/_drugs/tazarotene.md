# Tazarotene：乾癬から脂漏性皮膚炎へ

## 一言まとめ

Tazarotene（タザロテン） はレチノイド誘導体で、もともと乾癬および尋常性痤瘡の治療に用いられています。TxGNN モデルは、本剤が**脂漏性皮膚炎 (Seborrheic Dermatitis)** に有効である可能性を予測しており、現在この方向性を支持する**臨床試験が 1 件**あります。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 乾癬及び尋常性痤瘡 |
| 予測新適応症 | 脂漏性皮膚炎 (Seborrheic Dermatitis) |
| TxGNN 予測スコア | 99.79% |
| エビデンスレベル | L5 |
| 日本市販状況 | 本サイトのデータに未収載 |
| 承認番号数 | — |
| 推奨判断 | Hold |

## この予測が妥当な理由

Tazarotene は合成レチノイド系薬剤で、レチノイン酸受容体（RAR）に結合することにより、表皮細胞の分化と増殖を調節します。薬理学データによると、レチノイン酸受容体ベータ（RARB）に対する親和性が最も高いとされています。

乾癬と脂漏性皮膚炎は、いずれも表皮の角化異常を伴う皮膚疾患です。乾癬では角化細胞の過剰増殖が特徴ですが、脂漏性皮膚炎では皮脂腺機能の異常とマラセチア感染が関与します。両者は病態機序に一部重なる点があり、特に表皮分化の調節において共通しています。

Tazarotene は角化細胞の分化を調節する作用を持つため、理論上は脂漏性皮膚炎の角化異常に対して有用な可能性がありますが、現時点ではこの適応症を支持する直接的なエビデンスはありません。

## 安全性に関する考慮事項

**薬物相互作用**：多くの薬剤との相互作用が知られています（出典：DDInter）。主なものは以下のとおりです。
- Doxycycline、Minocycline（テトラサイクリン系抗菌薬）
- Tretinoin、Adapalene（その他のレチノイド系薬剤）
- Tacrolimus（免疫抑制薬）
- Clobetasol、Fluticasone など多数の外用ステロイド

皮膚刺激性の増加を避けるため、他のレチノイド系薬剤との併用は避けてください。

## 結論と次のステップ

**判断：Hold**

**理由：**
現時点では、Tazarotene の脂漏性皮膚炎への使用を支持するのはモデルによる予測のみで、直接的な臨床試験や文献のエビデンスはありません。薬理機序には合理性があるものの、エビデンスレベルが低すぎます（L5）。

**推進に必要な事項：**
- 脂漏性皮膚炎を対象としたパイロット臨床試験の実施
- 使用者における効果の観察的データの収集
- 脂漏性角化症の文献エビデンスとの区別および比較

## セフトリアキソン：胆嚢炎・淋菌感染症から多クローン性高粘稠度症候群へ
{: .text-alpha }

## 一言要約

セフトリアキソンは細胞壁合成を阻害する抗生物質で、日本では胆嚢炎や淋菌感染症などの治療に使われてきました。
TxGNN モデルは**多クローン性高粘稠度症候群 (polyclonal hyperviscosity syndrome)** に有効な可能性を予測していますが、この疾患に対する**臨床試験は 0 件、文献も 0 編**で、裏付けはモデル予測のみです。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 胆嚢炎、淋菌感染症（抗生物質・細胞壁合成阻害薬） |
| 予測新規適応症 | 多クローン性高粘稠度症候群 (Polyclonal Hyperviscosity Syndrome) |
| TxGNN 予測スコア | 99.39% |
| エビデンスレベル | L5 |

| 承認番号数 | 17 件（すべて失効・整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

セフトリアキソンは第三世代セフェム系抗生物質で、細菌の細胞壁合成を阻害して殺菌的に働きます。詳細な作用機序データは、現在ありません。上記は既存適応症の分類（細胞壁合成阻害薬）から確認できる範囲の情報です。

多クローン性高粘稠度症候群は、免疫グロブリンの増加によって血液の粘稠度が上がる病態です。細菌の細胞壁合成を阻害する作用とは、機序上の接点が見当たりません。既存の感染症適応症との関連性も示せないため、この予測は TxGNN のスコアだけに依拠しています。スコアが高くても、機序面の裏付けは現時点で得られていません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、TxGNN 知識グラフの薬物－疾患関係に基づく）：肝疾患、胆嚢疾患、新生児黄疸、クロストリジウム・ディフィシル大腸炎、周産期壊死性腸炎、溶血性貧血
- **薬物相互作用**（照会結果は計 100 件。主なもの）：
  - 重大 (Major)：塩化カルシウム、グルコヘプトン酸カルシウム、グルコン酸カルシウム
  - 中等度 (Moderate)：カナマイシン、ネオマイシン、ストレプトマイシン、ピコスルファート

警告・禁忌の詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 多クローン性高粘稠度症候群に対する臨床試験・文献が一件もなく、機序的な接点も見つかりません。根拠は TxGNN の予測スコア（L5）のみです。
- 日本での承認 17 件はすべて失効・整理済みで、現行の供給体制も確認できません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得（現状は安全性スクリーニングに進めない状態）
- 詳細な作用機序データの整備と、本疾患との機序的関連の検討
- 前臨床または観察研究レベルの根拠の収集
- 現行の国内供給状況の確認

**参考：同じ予測リスト内の他候補**
- **感染性中耳炎**（予測スコア 99.26%）は、小児急性中耳炎で、セフトリアキソンとトリメトプリム・スルファメトキサゾール (TMP-SMZ) を比較した RCT（PMID: 8989332、1997 年）を含む文献があります。この候補はエビデンスレベル L2 で、Proceed with Guardrails と評価されています。ただし、関連づけられた臨床試験 NCT02567825 はチューブ留置術の試験で、セフトリアキソンを検証したものではありません。
- 中耳炎に対する単回筋注はすでに確立した使い方です。新規性は限定的で、優先的に検討する候補としては、こちらの方が現実的です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# プレガバリン：神経障害性疼痛・線維筋痛症から腱炎へ

## 一言要約

プレガバリンは抗けいれん薬・疼痛治療薬で、日本では神経障害性疼痛と線維筋痛症に使用されています。
TxGNN モデルは**腱炎 (Tendinitis)** に有効である可能性を予測していますが、腱炎を直接対象とした臨床試験は **0 件**です。関連する文献 **6 編**も、腱炎そのものの治療効果を示すものではありません。

## この予測が妥当である理由

DrugBank から詳細な作用機序 (MOA) データは取得できていません。一方、候補の機序解析では、プレガバリンは電位依存性カルシウムチャネルの α2-δ サブユニットに結合し、興奮性神経伝達物質の放出を抑えるとされています。これにより痛みのシグナルが弱まる可能性があります。

既存適応症の神経障害性疼痛や線維筋痛症は、いずれも中枢性の疼痛過敏が関わる疾患です。腱炎は疼痛を主症状とするため、この鎮痛作用が症状緩和に役立つ可能性はあります。

ただし、現時点のデータは肩腱板修復術後の周術期疼痛に関するものです。腱炎そのものへの効果ではなく、あるとしても疼痛の緩和にとどまり、腱の炎症や修復を改善する根拠はありません。

## 臨床試験エビデンス

現在、関連する臨床試験の登録はありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
腱炎を直接対象とした臨床試験がなく、文献も周術期疼痛など間接的な内容にとどまるため、TxGNN のスコアが高くても臨床的な裏付けはありません。日本の添付文書に基づく安全性の確認も未完了です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（現在、安全性スクリーニングに進めない要因）
- DrugBank からの作用機序 (MOA) データの取得
- 腱炎・腱障害を対象とした臨床試験、または症例研究の収集

なお、同じ予測リストの**片頭痛、変形性関節症、頭痛性疾患**では、臨床試験と RCT を含む文献があり、エビデンスレベルは L2 でした。優先的に検討する価値があるのは、こちらの方向性です。

*本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床的な検証を経て初めて応用できます。*
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# プレガバリン：神経障害性疼痛・線維筋痛症から変形性関節症へ

## 一言要約

プレガバリンは、元々神経障害性疼痛と線維筋痛症の治療に使われてきた抗けいれん薬・疼痛治療薬です。
TxGNN モデルの予測順位 1 位は**腱炎 (Tendinitis)** ですが、実際の研究が最も充実しているのは**変形性関節症 (Osteoarthritis)** で、**10 件の臨床試験**と **18 編の文献**があります。腱炎自体を直接検証した臨床試験はなく、モデル予測と文献による間接的な示唆にとどまります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 神経障害性疼痛、線維筋痛症 |
| 予測新規適応症 | 腱炎 (Tendinitis)（最上位予測）。エビデンスが最も豊富な候補は変形性関節症 (Osteoarthritis) |
| TxGNN 予測スコア | 99.71%（腱炎）、98.58%（変形性関節症） |
| エビデンスレベル | L4（腱炎）／L1（変形性関節症） |
| 日本市販状況 | 販売承認は 20 件ありますが、すべて取り消し済みです |
| 承認番号数 | 20 件（有効 0 件、取り消し 20 件） |
| 推奨決定 | Hold（腱炎）／Proceed with Guardrails（変形性関節症、片頭痛、頭痛性疾患） |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし確立された薬理学によると、プレガバリンは電位依存性カルシウムチャネルの α2δ サブユニットに結合し、グルタミン酸、サブスタンス P、CGRP などの興奮性伝達物質の放出を抑えます。この作用が神経障害性疼痛と線維筋痛症での効果の基盤です。

腱炎については、腱手術後の周術期疼痛でのデータがあるだけで、腱炎そのものを対象にした研究はありません。変形性関節症では、中枢性感作や神経障害性の痛みの成分に作用する可能性があり、その効果は症状緩和（疼痛・機能）に限られ、疾患修飾ではありません。

片頭痛や頭痛性疾患でも、皮質拡延性抑制の抑制や神経過興奮の低下という機序が支持されています。一方、筋炎系疾患（特発性肉芽腫性筋炎、線維性筋炎、封入体筋炎）、変形性関節症感受性、蛇行状皮膚萎縮症については、α2δ 調節との妥当な機序的関連は見つかっておらず、モデル予測のみです。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の関連）**：添付文書の記載ではなく、知識グラフ上の薬物-疾患関係に基づく情報です。不安障害、神経症、気分変調症、血小板減少症、血管性浮腫（後天性・遺伝性など）、ミオパチー・筋疾患、横紋筋融解症、家族性周期性四肢麻痺、結節性筋膜炎、腎機能障害、房室ブロックが挙げられています。
- **薬物相互作用**：相互作用は 100 件が確認されています。重要度が高い（Major）ものはモルヒネ、リポソーム化モルヒネで、中枢神経抑制の増強に注意が必要です。中等度（Moderate）にはピオグリタゾン、ロシグリタゾン、トログリタゾン、ジフェノキシン、ジフェノキシレート、ドロナビノール、ナビロン、メトクロプラミド、アヘン、シブトラミンなどがあります。

主要な警告と添付文書上の禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：腱炎は Hold、変形性関節症・片頭痛・頭痛性疾患は Proceed with Guardrails**

**理由：**
- 最上位予測の腱炎には臨床試験がなく、周術期疼痛の間接的なデータしかないため、現時点では評価を保留します。
- 変形性関節症（Phase 3 RCT 複数とメタ解析あり）、片頭痛、頭痛性疾患（硬膜穿刺後頭痛の Phase 3 試験完了）には一定の支持があります。ただし効果は症状緩和に限られ、安全性と作用機序の文書も不完全です。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の取得（現在は欠落しており、安全性スクリーニングの前提条件です）
- DrugBank からの作用機序データの補完
- 腱炎そのものを対象とした臨床試験または観察研究の有無の確認
- 日本の承認がすべて取り消し済みである点の確認と、再承認または適応拡大の可能性の評価
- 中枢神経抑制（オピオイド併用）、依存・乱用、腎機能低下例での用量調整に関する安全性モニタリング計画
- 筋炎系疾患、変形性関節症感受性、蛇行状皮膚萎縮症は、根拠がなく優先度は低いと判断します
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

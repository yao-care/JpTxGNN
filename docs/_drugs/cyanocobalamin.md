# シアノコバラミン：貧血・ビタミンB12補充から ビオチン代謝疾患へ

## 一言要約

シアノコバラミン（ビタミンB12）は、元々貧血治療・造血・ビタミンB12補充に使用されていた薬です。
TxGNN モデルは**ビオチン代謝疾患 (biotin metabolic disease)** に有効である可能性を予測していますが、この方向性を直接支持する臨床試験はなく、関連文献は **1 編**（生物工学的ビタミン生産に関する総説）のみです。実質的にはモデル予測の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 貧血治療薬、造血薬、ビタミンB12補充薬（甲状腺機能亢進症、広節裂頭条虫症に関連） |
| 予測新規適応症 | ビオチン代謝疾患 (biotin metabolic disease) |
| TxGNN 予測スコア | 99.60% |
| エビデンスレベル | L5 |
| 日本市販状況 | 取消のみ（現在有効な承認なし） |
| 承認番号数 | 12 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、シアノコバラミンはメチルマロニルCoAムターゼとメチオニン合成酵素の補酵素（コバラミン）として働きます。一方、ビオチンはカルボキシラーゼ類の補酵素です。

両者はビタミン代謝やプロピオン酸・一炭素代謝を通じて緩やかに関連するのみです。直接的な臨床的裏付けはありません。この予測は、知識グラフ上でビタミン代謝の近傍にあることを反映している可能性が高く、機序的な妥当性は限定的です。

なお、他の上位予測（ビオチン代謝先天異常、食道奇形、各種炎症性筋疾患、CD59欠損症など）も、機序上の根拠が乏しいか、モデルの副産物と考えられます。ビオチン代謝先天異常（ビオチニダーゼ欠損症、ホロカルボキシラーゼ合成酵素欠損症）の治療はビオチン補充であり、コバラミンの役割は確立していません。

## 臨床試験エビデンス

## 安全性に関する考慮事項

- **薬物相互作用**（100 件の相互作用が登録）：主なものは以下のとおりです。
  - 軽微（Minor）：H2 受容体拮抗薬（ファモチジン、ラニチジン、シメチジン、ニザチジン）、プロトンポンプ阻害薬（オメプラゾール、エソメプラゾール、ランソプラゾール、ラベプラゾール、パントプラゾールなど）、塩化カリウム。いずれも吸収低下が関連する可能性があります。
  - 重症度不明（Unknown）：メトホルミン、グリメピリド、アカルボース、ロシグリタゾン、モルヒネ、ドキシサイクリン、メサラジン、スクラルファート

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測新規適応症に対する臨床試験はなく、文献も直接的な裏付けにならない総説 1 編のみで、エビデンスはモデル予測（L5）にとどまります。
- 機序的な関連も弱く、日本では現在有効な承認がありません。

**進める場合に必要なもの：**
- 作用機序（MOA）データの補完
- 添付文書の警告・禁忌情報の取得と安全性スクリーニング
- ビオチン代謝疾患に対するコバラミンの役割を示す前臨床・臨床データ
- 日本での販売状況（承認の再取得の要否）と、剤形・投与経路の適合性の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

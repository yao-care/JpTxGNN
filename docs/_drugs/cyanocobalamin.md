# シアノコバラミン：貧血（ビタミンB12補充）からビオチン代謝疾患へ

## 一言要約

シアノコバラミン（ビタミンB12）は、元々貧血の治療、造血、ビタミンB12の補充に使用されていました。
TxGNN モデルは**ビオチン代謝疾患 (biotin metabolic disease)** に有効である可能性を予測しています。ただし、関連する **15 件の臨床試験**と **20 編の文献**は、いずれもシアノコバラミンの有効性を直接検証したものではありません。エビデンスは間接的なものにとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、シアノコバラミンは体内でメチルコバラミンとアデノシルコバラミンに変換される補酵素前駆体で、ビタミンB12欠乏に基づく貧血の治療に有効性が確立されています。

ビオチン代謝疾患との接点はプロピオン酸代謝経路です。アデノシルコバラミンは、ビオチン依存性のプロピオニルCoAカルボキシラーゼより下流で働きます。ビタミン反応性の先天代謝異常症をまとめた総説にも、コバラミンとビオチンが並んで取り上げられています。このため、TxGNN が両者の関連を高く評価したことには一定の根拠があります。

ただし、ビオチン代謝の異常は通常ビオチンそのもので治療します。シアノコバラミンがビオチン代謝の欠陥を補正するという直接的な証拠はなく、現時点の裏付けは総説レベルの一般論にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN のスコアは高いものの、シアノコバラミンがビオチン代謝疾患に有効であることを直接示す臨床試験や文献はありません。現在の裏付けは一般的なビタミン反応性疾患の総説にとどまり、ビオチン代謝異常の標準治療はビオチンです。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と安全性スクリーニング（現状ではブロッキング項目）
- DrugBank からの作用機序データの補完
- プロピオン酸代謝経路におけるシアノコバラミンの役割を、ビオチン代謝異常の病態に照らして精査する機序検討
- 対象疾患の絞り込み。例えば、ビオチン依存性カルボキシラーゼ欠損症とB12 反応性有機酸血症の切り分け
- 予測順位 8 位のタンパク尿（Imerslund-Gräsbeck 症候群に関する報告あり）は、別の研究課題として検討可能

※本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的検証を経て初めて適用できます。
## 免責事項

臨床応用の前に臨床的検証が必要です。

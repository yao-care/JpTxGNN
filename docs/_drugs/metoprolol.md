# メトプロロール:本態性高血圧症・狭心症から悪性高血圧性腎疾患へ

## 一言要約

メトプロロールは β1 選択性遮断薬で、日本では本態性高血圧症と狭心症の治療に使われています。
TxGNN モデルは**悪性高血圧性腎疾患 (malignant hypertensive renal disease)** に有効である可能性を予測していますが、
この適応症を直接支持する**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、メトプロロールは β1 選択性遮断薬で、心拍数と血圧を下げるほか、レニン分泌も抑えます。すでに本態性高血圧症と狭心症で使用されています。

悪性高血圧性腎疾患は、重度の高血圧が腎臓を傷めることで起こります。レニンを介した血圧上昇を抑えるという点で、機序的にはメトプロロールが適用できる可能性があります。

ただし、この予測を裏付ける臨床試験も文献もなく、根拠は TxGNN のスコアと機序上の推測だけです。

## 結論と次のステップ

**決定:Hold**

**理由:**
悪性高血圧性腎疾患については、臨床試験も文献もなく、L5(モデル予測のみ)の段階です。日本の添付文書の警告・禁忌データも未取得のため、安全性の確認に進めません。

**進める場合に必要なもの:**
- PMDA の添付文書(警告・禁忌)の取得と解析(安全性スクリーニングの前提条件)
- DrugBank からの詳細な作用機序(MOA)データの取得
- 悪性高血圧性腎疾患に関する臨床試験と文献の再検索
- 他の予測候補の追加検討:
  - 中隔心筋梗塞と後側壁心筋梗塞は L3 で、小規模なヒト研究があります。
  - 慢性肺性心疾患では、COPD を対象にした Phase 3 試験(メトプロロール)で有効性が示されず、COPD 増悪による入院が増えたと報告されています。この試験は途中で終了しており、安全性上の注意が必要です。

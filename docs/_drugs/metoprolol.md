# メトプロロール：本態性高血圧症・狭心症から悪性高血圧性腎疾患へ

## 一言要約

メトプロロールはβ1選択的遮断薬で、日本では本態性高血圧症と狭心症の治療に使われてきました。
TxGNN モデルは**悪性高血圧性腎疾患 (malignant hypertensive renal disease)** に有効である可能性を予測していますが、この予測を直接支持する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 本態性高血圧症、狭心症 |
| 予測新規適応症 | 悪性高血圧性腎疾患 (malignant hypertensive renal disease) |
| TxGNN 予測スコア | 99.91% |
| エビデンスレベル | L5 |

| 承認番号数 | 14 件（有効 0 件、失効 14 件） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。ただし、メトプロロールはβ1選択的遮断薬として知られています。心拍数と心拍出量を下げ、レニンの分泌も抑えるため、降圧作用を持ちます。

高血圧症は既存適応症であり、悪性高血圧性腎疾患も高血圧に関連する病態です。このため、血圧を下げるという点では機序的にあり得る予測です。ただし、メトプロロールは高血圧緊急症の第一選択薬ではありません。この適応症を直接裏づけるデータも今回は得られていません。

したがって、この予測の根拠は現時点ではモデルのスコアと一般的な薬理学的な推論にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 悪性高血圧性腎疾患について、臨床試験も文献も見つかっておらず、エビデンスはモデル予測のみ（L5）です。
- メトプロロールは高血圧緊急症の主要な薬剤ではなく、現在日本で有効な承認もありません。
- 参考として、同じ薬物の他の予測候補には、より根拠のあるものがあります。中隔心筋梗塞（L3）は、心筋梗塞後のβ遮断薬という確立した根拠があり、優先して検討する価値があります。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを行う（最優先）。
- DrugBank から作用機序データを補う。
- 悪性高血圧・高血圧性腎障害に対するβ遮断薬の臨床試験や文献を再検索する。
- 日本で有効な承認がないため、供給・承認の位置づけを確認する。

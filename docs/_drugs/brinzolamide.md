# ブリンゾラミド：緑内障から原発性遺伝性緑内障へ

## 一言要約

ブリンゾラミドは炭酸脱水酵素阻害薬で、元々緑内障の治療に使用されていた点眼薬です。
TxGNN モデルは**原発性遺伝性緑内障 (Primary Hereditary Glaucoma)** に有効である可能性を予測していますが、
現在、この方向性を直接支持する**臨床試験・文献の登録はありません**。予測はモデルのみに基づいています。

## クイック概要

| 既存適応症 | 緑内障（抗緑内障薬、炭酸脱水酵素阻害薬） |
| 予測新規適応症 | 原発性遺伝性緑内障 (Primary Hereditary Glaucoma) |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ブリンゾラミドは炭酸脱水酵素 II を阻害する薬剤で、房水の産生を抑えて眼圧を下げます。緑内障での有効性は確立されています。

原発性遺伝性緑内障も眼圧上昇が病態の中心となる緑内障の一型であり、眼圧を下げる機序は機序的に適用可能と考えられます。

ただし、この予測は既存の緑内障適応症とほぼ重なっており、真の意味での新規再利用候補とは言えません。この疾患に特化した試験や文献もなく、支持材料は TxGNN の予測スコアのみです。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測は TxGNN のスコアのみに基づき、この疾患に対する臨床試験や文献がありません。既存の緑内障適応症と重なるため、新規再利用としての意義も限定的です。さらに、日本の承認はすべて整理済みで、現在市販されていません。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と解析
- 詳細な薬物作用機序データ（MOA）の補完
- 原発性遺伝性緑内障に特化した臨床試験・文献の調査
- 既存の緑内障適応症との差分整理（真の新規性があるかの確認）
- 日本での市販状況の再確認（承認整理の経緯を含む）
- 投与経路の適合性評価（点眼剤であることを前提に）

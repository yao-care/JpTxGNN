# パゾパニブ：未分類の腎細胞癌へ

## 一言要約

パゾパニブは VEGFR・PDGFR・c-Kit を阻害するマルチキナーゼ阻害薬で、日本では「ヴォトリエント錠200mg」として市販されています。
TxGNN モデルは**未分類の腎細胞癌 (unclassified renal cell carcinoma)** に有効である可能性を予測しています。
支持するエビデンスは**臨床試験 1 件**（完了した Phase 3、進行性・転移性腎細胞癌全般）のみで、この予測に直接対応する文献はありません。

## この予測が妥当である理由

詳細な作用機序データは、現在ありません。一般的な薬理学によると、パゾパニブは VEGFR-1/2/3、PDGFR-α/β、c-Kit を標的とするチロシンキナーゼ阻害薬です。腫瘍の血管新生を抑える働きがあります。

腎細胞癌は血管新生への依存度が高い腫瘍です。そのため、VEGF 経路を阻害する薬剤が機序的に適用可能と考えられます。

ただし、今回の予測対象は「未分類」という特定のサブタイプです。支持する試験は腎細胞癌全般を対象としており、このサブタイプに絞った検証は行われていません。既存適応症の情報も今回のデータにはなく、既存適応症との関連性は評価できません。

なお、薬物相互作用の検索結果は 0 件でした。パゾパニブは CYP3A4 の基質と考えられ、0 件は不自然なため、この結果は信頼できません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 支持する試験は 1 件のみで、腎細胞癌全般が対象です。予測された「未分類」サブタイプに特化したエビデンスはなく、文献もありません。
- 添付文書の警告・禁忌が未取得で、安全性の確認がブロックされています。相互作用の検索結果も信頼できません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）を取得して解析する（最優先）。
- DrugBank から作用機序（MOA）データを取得する。
- DDI を再検索し、CYP3A4 関連の相互作用を確認する。
- 未分類腎細胞癌のサブタイプに特化した試験や文献を調べる。

**参考：**
同じ薬物の別の予測には、より直接的な根拠があります。
- **脂肪肉腫**：単剤の完了済み Phase 2 が 2 件（NCT01506596、NCT01692496）あります。
- **隆起性皮膚線維肉腫 (DFSP)**：Phase 2 の試験と文献があります。

これらは、今回の候補より優先して評価する価値があります。

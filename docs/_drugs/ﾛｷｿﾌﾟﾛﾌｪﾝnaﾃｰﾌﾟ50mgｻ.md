## この評価が保留となった理由

### 1. 薬物識別の問題

クエリに使用された文字列 `ﾛｷｿﾌﾟﾛﾌｪﾝNAﾃｰﾌﾟ50MGｻ` は、半角カタカナ表記に剤形（テープ）・含量（50mg）・分類コード（ｻ）を含んだ**製品固有の商品コード**です。TxGNN パイプラインおよび DrugBank は**INN（国際一般名）または DrugBank ID** でエントリーを特定するため、この形式では正確な薬物マッチングが困難です。

> **正規 INN**：Loxoprofen Sodium（ロキソプロフェンナトリウム）  
> **DrugBank 候補**：DB04571（Loxoprofen）

### 2. 予測適応症がゼロ件

`predicted_indications` が空配列のため、TxGNN 知識グラフ（KG）・深層学習（DL）いずれの予測も実行されていないか、有効な薬物ノードに紐付かなかった可能性があります。DrugBank クエリは「1 件ヒット」を返しているものの（`query_log[1].result_count: 1`）、その結果が予測パイプラインに引き渡されていません。

### 3. ロキソプロフェンについての既知情報（背景参考）

ロキソプロフェンナトリウムはプロピオン酸系 NSAIDs であり、COX-1/COX-2 阻害によりプロスタグランジン合成を抑制します。日本では経口剤・外用テープ剤がともに市販されており、外用テープ剤の主な適応は変形性関節症・腰痛・筋肉痛などの局所疼痛です。本来ならこの情報を基に再利用候補（例：術後疼痛管理の別経路、神経因性疼痛など）を評価できますが、Evidence Pack にデータが存在しない以上、本レポートでの評価対象外とします。

## 結論と次のステップ

**決定：Hold**

**理由：**
薬物識別子が製品コード形式であり INN に変換されていないため、TxGNN 予測が実行されておらず、再利用評価に必要なエビデンスが一切存在しない。DrugBank クエリは 1 件ヒットしているにもかかわらず予測に繋がっていない点も要確認。

**進める前に必要なアクション：**

1. **薬物 ID の正規化**：`ﾛｷｿﾌﾟﾛﾌｪﾝNAﾃｰﾌﾟ50MGｻ` → INN `Loxoprofen Sodium`、DrugBank ID `DB04571` に変換してパイプラインを再投入
2. **DrugBank ヒット結果の確認**：`query_log[1]` が返した 1 件の DrugBank エントリが正しく `drugbank_id` にマッピングされているか検証
3. **PMDA クエリの再設計**：INN または成分名（「ロキソプロフェンナトリウム」）で再検索し、既存適応症テキストを取得
4. **TxGNN 予測の再実行**：正規化された DrugBank ID を用いて KG 予測・DL 予測を実行
5. **安全性データの収集**（DG001 の解消）：PMDA 仿単 PDF を取得・解析して警告・禁忌を補完
6. **MOA データの収集**（DG002 の解消）：DrugBank API から作用機序を取得

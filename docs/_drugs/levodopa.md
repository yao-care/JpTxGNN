# レボドパ：パーキンソン病からラスムッセン亜急性脳炎へ

## 一言要約

レボドパはドパミンの前駆物質で、元々パーキンソン病をはじめとするパーキンソニズム関連疾患の治療に使用されてきました。
TxGNN モデルは**ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis)** に有効である可能性を予測していますが、現時点で関連する臨床試験も文献もなく、**モデル予測のみ**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | パーキンソン病（承認適応症の記載データはなし。知識グラフ上の元適応症） |
| 予測新規適応症 | ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis) |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、レボドパはドパミン前駆物質で、脳内でドパミンに変換されてドパミン作動性経路に作用し、パーキンソン病などで運動症状を改善します。

一方、ラスムッセン脳炎は、片側大脳皮質の炎症と難治性てんかんを特徴とする免疫介在性の慢性限局性脳炎です。ドパミン作動性機序と疾患病態を結ぶ確立した関連は見当たりません。

TxGNN のスコアは高い（0.99）ものの、計算上の予測にすぎません。既存適応症との機序的な類似性も未評価です。したがって、この予測の妥当性は現時点では仮説の域を出ず、慎重な検証が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、臨床試験・文献がなく、機序的な関連も確立していないため、エビデンスはモデル予測のみ（L5）です。
- 日本では現在販売中の承認がなく、添付文書の安全性情報も未取得です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得と安全性スクリーニング
- 詳細な作用機序データ（MOA）の取得
- ドパミン作動性経路とラスムッセン脳炎の病態（免疫介在性炎症、難治性てんかん）との機序的関連の検討
- 前臨床研究または文献によるエビデンスの収集
- 投与経路の適合性評価と、既存適応症との類似性の評価
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

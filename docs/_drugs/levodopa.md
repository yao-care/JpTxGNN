# レボドパ：パーキンソン病からラスムッセン亜急性脳炎へ

## 一言要約

レボドパはドパミン前駆体で、日本ではマドパー配合錠やスタレボ配合錠などの成分として市販されています。既存適応症は Evidence Pack に記載がなく、パーキンソン病という理解は一般的な知識に基づくものです。
TxGNN モデルは**ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis)** に有効な可能性を予測していますが、現時点で裏付けとなる臨床試験と文献は **0 件**で、**モデル予測のみ**の段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。レボドパはドパミン前駆体であり、日本ではマドパー配合錠、スタレボ配合錠といった配合剤の成分として承認されています。ただし、承認適応症の記載は今回のデータに含まれていません。

ラスムッセン脳炎は、T 細胞が介在する炎症性のてんかんで、片側の大脳皮質が障害されます。Evidence Pack では、レボドパとの間に直接的な機序上の関連は確認されていません。0.99 という高いスコアは、知識グラフに基づく予測にすぎず、この予測を支持する試験や文献も入力データにはありません。

したがって、現段階で機序的な妥当性を裏付ける根拠はありません。仮説として扱い、まず文献調査と機序面の検討で裏付けを探す必要があります。

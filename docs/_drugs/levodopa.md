## レボドパ：ドパミン前駆体 → ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis)
{: .text-alpha }

## 一言要約

レボドパはドパミンの前駆体で、ドパミン作動性の経路に作用する薬剤です。
TxGNN モデルは**ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis)** に有効である可能性を予測していますが、現時点で関連する臨床試験や文献はなく、**モデル予測のみ**の段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。レボドパはドパミン前駆体として脳内でドパミンに変換され、ドパミン作動性の経路に作用する薬剤として知られています。

一方、ラスムッセン脳炎は、片側大脳皮質の炎症と難治性てんかんを特徴とする免疫介在性の慢性局所性脳炎です。レボドパのドパミン作動性の作用と、この疾患の病態との間に、確立された機序的なつながりは認められていません。

TxGNN の予測スコア 0.9906 は計算上の予測値にすぎず、機序面の裏付けは今後の検討課題です。薬剤との類似性についても評価は未実施です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- ラスムッセン亜急性脳炎に関する臨床試験・文献が一件もなく、エビデンスはモデル予測のみ（L5）です。
- レボドパのドパミン作動性の作用と、免疫介在性の脳炎という病態との間に、確立された機序的関連が見当たりません。

**進める場合に必要なもの：**
- 詳細な作用機序データ（MOA）の補充
- ラスムッセン脳炎に対する前臨床研究や症例報告の調査
- 添付文書（PMDA）に基づく警告・禁忌の確認と安全性評価
- 投与経路の適合性の確認
## 免責事項

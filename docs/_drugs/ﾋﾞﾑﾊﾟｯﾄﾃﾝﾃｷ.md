# ビムパット点滴：評価データ不足により判定保留

## 一言要約

ビムパット点滴（ラコサミド注射剤）は半角カタカナ形式の薬品名で照会されたため、PMDA データベースとのマッチングに失敗し、承認情報を取得できませんでした。TxGNN モデルによる新規適応症の予測結果が存在しないため、再利用候補としての評価を実施できる状態にありません。現時点では **Hold（保留）** が妥当な判定です。

DrugBank では 1 件がヒットしているにもかかわらず `drugbank_id` が `null` のままです。DrugBank API からの ID 取得・MOA 抽出が完了していないため、TxGNN 予測パイプラインへの入力が行われませんでした。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank への照会でエントリが存在することは確認されているが、DrugBank ID の未取得により TxGNN 予測が実行されておらず、新規適応症の候補が一件も生成されていない。PMDA の照会結果も 0 件であり、薬品の基本プロファイルが確立されていない状態では安全性・有効性の評価を開始できない。

**進める前に必要なもの：**

1. **薬品名の正規化**：半角カタカナ `ﾋﾞﾑﾊﾟｯﾄﾃﾝﾃｷ` を全角カタカナ「ビムパット点滴」または英語 INN「Lacosamide」に変換し、PMDA・DrugBank を再照会する
2. **DrugBank ID の取得**：DrugBank API から `drugbank_id`（推定：DB06218）を確定し、MOA・カテゴリ情報を補完する
3. **TxGNN 予測の再実行**：DrugBank ID が確定次第、KG 予測および DL 予測パイプラインを実行し、候補疾病リストを生成する
4. **PMDA 仿単の取得**：承認適応症・警告・禁忌情報を PMDA 官網から PDF ダウンロードし解析する（DG001 解消）
5. **Evidence Pack の再生成**：上記が揃った段階で Evidence Pack v5 以降を生成し、本レポートを更新する

# アセトアミノフェン細粒20%JG：評価データ不足により再評価が必要

## 一言要約

アセトアミノフェン細粒20%JG（ｱｾﾄｱﾐﾉﾌｪﾝｻｲﾘｭｳ20%JG）は解熱鎮痛成分であるアセトアミノフェンを含む細粒製剤です。本 Evidence Pack には TxGNN による予測適応症が含まれておらず、PMDA 検索でも承認情報が取得できていません。現時点では老薬新用評価を完結することができず、データ補完後の再評価が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による予測適応症が存在せず、かつ PMDA での承認情報も確認できないため、老薬新用評価の根拠が成立しません。DrugBank クエリでは 1 件のヒットがありましたが、DrugBank ID の取得に至っておらず、MOA・安全性データも欠損しています。

**進める場合に必要なもの：**
- **DrugBank ID の確定**：DrugBank から INN（アセトアミノフェン）に基づく ID を正規取得し、MOA・安全性データを補完する
- **PMDA 検索の再実施**：半角カタカナ表記（ｱｾﾄｱﾐﾉﾌｪﾝｻｲﾘｭｳ20%JG）ではなく、全角一般名「アセトアミノフェン」で再検索し、承認情報を確認する
- **candidate_id の見直し**：`TW-UNKNOWN-multi` は台湾由来の候補 ID であり、日本 PMDA への照合対象として適切かどうかを確認する
- **TxGNN 予測の再実行**：正規化された DrugBank ID を用いて予測パイプラインを再実行し、適応症候補を取得する

# サルメテロール：喘息・COPD から気管支炎へ

## 一言要約

サルメテロールは長時間作用型β2刺激薬（LABA）で、文献上は喘息や COPD の維持療法に使われています。日本の承認データには適応症の記載がありません。
TxGNN モデルは**気管支炎 (Bronchitis)** に有効である可能性を予測しており、**16 件の臨床試験**と **20 編の文献**が関連しています。ただし、その大半は COPD（慢性気管支炎を含む）の研究で、気管支炎そのものを対象にした研究は限られます。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、サルメテロールはβ2アドレナリン受容体を刺激して気道平滑筋を弛緩させ、持続的な気管支拡張をもたらす LABA です。

慢性気管支炎は COPD の主要な病型の一つで、気流閉塞と粘液クリアランスの低下を伴います。サルメテロールの気管支拡張作用と、粘液線毛クリアランスの改善が期待される点は、この病態に機序的に適合します。慢性気管支炎患者を対象に、サルメテロールが粘液線毛クリアランスと咳によるクリアランスに与える影響を調べた RCT（PMID 15970448）もあります。

注意点として、この予測は既存の COPD・喘息での使用と重なる部分が大きく、新規性は限定的です。急性気管支炎への有効性を示す直接的なエビデンスは、今回の資料には含まれていません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
COPD（慢性気管支炎を含む）では、完了した Phase 3 試験が複数あり、日本でも市販されています。一方、気管支炎そのものを対象にした直接的な証拠は少数の小規模研究にとどまります。安全性の根拠となる添付文書情報も未取得のため、条件付きで進めるのが妥当です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現状は安全性審査に進めない阻害要因）
- DrugBank からの作用機序（MOA）データの補完
- 日本での既存適応症の確認（承認適応症の記載が空欄のため）
- 対象を慢性気管支炎（COPD 含む）に限るか、急性気管支炎も含めるかの定義
- 未評価の 6 件の試験（関連性グレード未判定）の精査
- 相互作用（DDI）の情報が空であるため、追加確認
## 免責事項

# ワソラン：予測適応症なし・評価保留

## 一言要約

ワソラン（ｶﾀｶﾅ表記：ﾜｿﾗﾝ）は INN フィールドに商品名と思われる名称が入力されており、DrugBank ID の特定ができませんでした。その結果、TxGNN モデルによる新規適応症の予測は実行されておらず、**予測候補はゼロ件**です。PMDA での承認も確認されておらず、安全性・作用機序データも未取得のため、現時点では正式な再利用評価を実施できません。

## 結論と次のステップ

**決定：Hold**

**理由：**
`inn` フィールドに「ワソラン」という商品名と思われる名称が入力されているため、DrugBank ID のマッピングに失敗し、TxGNN 予測パイプラインへの入力データが作成できませんでした。DrugBank クエリでは 1 件のヒットがあるものの（`query_log` 参照）、ID が紐付けられておらず、下流の予測・証拠収集・安全性評価のすべてが実行されていない状態です。

**進める場合に必要なもの：**
- **INN の確認**：「ワソラン」は商品名の可能性が高い（日本ではベラパミルの商品名として知られる）。INN（国際一般名）を特定し、`drug.inn` フィールドを修正する
- **DrugBank ID の取得**：DrugBank クエリで 1 件ヒット済みのため、マッピング処理を確認し `drugbank_id` を確定する
- **PMDA 仿単の取得**：承認情報・安全性警告・禁忌の抽出（PMDA 公式サイトから PDF ダウンロード）
- **作用機序（MOA）データの取得**：DrugBank API または文献から MOA を補完する
- **再予測の実行**：上記データ補完後、TxGNN パイプラインを再実行して予測候補を生成する

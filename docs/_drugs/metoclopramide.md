# メトクロプラミド：制吐・胃運動促進から胃潰瘍へ

## 一言要約

メトクロプラミドはドパミン D2 拮抗薬・消化管運動促進薬として、悪心・嘔吐や胃不全麻痺（gastroparesis）の症状緩和に広く使用されてきました。
TxGNN モデルは**胃潰瘍 (Gastric Ulcer)** に有効である可能性を予測しており、
現在 **2 件の臨床試験**と **20 編の文献**がこの方向性を支持しています。

## この予測が妥当である理由

詳細な作用機序データは現時点では収集できていませんが、利用可能な文献に基づくと、メトクロプラミドは主にドパミン D2 受容体を拮抗し、さらに 5-HT4 受容体を刺激することで消化管平滑筋の収縮を促進します。これにより胃幽門部の蠕動が増強されて胃排空が加速されるとともに、十二指腸液・胆汁の胃内逆流（幽門逆流）が抑制されます。

胃潰瘍の発症・維持には胃排空遅延が寄与しており、胃酸が粘膜と長時間接触することで粘膜障害が進行します。メトクロプラミドによる胃排空促進は胃酸接触時間の短縮につながり、潰瘍形成を抑制できる可能性があります。動物実験レベルでは、ラットのアスピリン誘発・幽門結紮モデル（PMID 2730234）および天竺鼠の 3 種類の実験的胃潰瘍モデル（PMID 6436177）において、メトクロプラミドが胃酸分泌を変化させることなく潰瘍形成を直接抑制することが確認されています。

ただし、メトクロプラミド自体には制酸作用も H. pylori 除菌効果もなく、H2 拮抗薬・PPI・除菌療法が主役となる現代の潰瘍治療に対して補助的な位置づけにとどまります。ヒトを対象とした潰瘍癒合を主要エンドポイントとした RCT は確認されておらず、エビデンスは前臨床データに限られている点が現状の課題です。

## 結論と次のステップ

**決定：Hold**

**理由：**
現時点のエビデンスは動物実験と機序的総説に限られており（L4）、ヒトを対象とした潰瘍癒合を主要エンドポイントとする臨床試験が存在しません。加えて、日本での承認実績がなく（0 件）、安全性情報・作用機序データともに未収集の状態であるため、再利用候補として積極的に進める根拠が現段階では不十分です。

**進める場合に必要なもの：**
- 日本の安全性情報の取得（PMDA 添付文書 PDF の解析による警語・禁忌・副作用の確認）
- 詳細な MOA データの補充（DrugBank API クエリによる薬理分類・作用標的の特定）
- 薬物相互作用（DDI）データの確認
- 現代標準治療（PPI・H. pylori 除菌療法）との併用における付加価値の評価
- 潰瘍癒合を主要エンドポイントとする概念実証（PoC）臨床試験の設計

# レボフロキサシン：細菌感染症から点状表層角結膜炎へ

## 一言要約

レボフロキサシンは DNA ジャイレースとトポイソメラーゼ IV を阻害するニューキノロン系抗菌薬で、元々は結膜炎、肺炎マイコプラズマ、コレラ、ペスト、結核症などの細菌感染症に使用されていました。
TxGNN モデルは **点状表層角結膜炎 (punctate epithelial keratoconjunctivitis)** に有効である可能性を予測しています。
ただし、この方向性を支持するのは**臨床試験 0 件**、**文献 1 編**（微胞子虫性角結膜炎の集団発生に関する症例報告）のみで、エビデンスは非常に限られています。

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。既知の情報によると、レボフロキサシンは細菌の DNA ジャイレースとトポイソメラーゼ IV を阻害するキノロン系抗菌薬です。すでに細菌性結膜炎や眼瞼炎に使用されており、点眼液（0.5%、1.5%）も承認されていました。

眼表面の感染性疾患という点では、既存適応症と予測適応症は関連しています。しかし、今回の唯一の関連文献は**微胞子虫（真核生物）**による角結膜炎の報告です。微胞子虫にはレボフロキサシンの標的である細菌型トポイソメラーゼがないため、機序面の裏付けは弱いと判断します。点状表層角結膜炎は、ウイルスなど非細菌性の原因でも起こります。細菌が関与する場合や二次感染予防の場合に限り、部分的に説明がつく可能性があります。

  - 中等度 (Moderate)：アビラテロン、アカルボース、ファモチジン、ホルモテロール、ケトロラク、イブプロフェン、メトホルミン、ピオグリタゾン、アルフゾシンなど

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、裏付けは微胞子虫性角結膜炎の症例集積 1 編のみで、臨床試験はありません。機序面でも標的が合致せず、国内の承認もすべて取消済みです。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の確認（安全性スクリーニングの前提となる未取得データ）
- 作用機序データ（DrugBank）の補完
- 点状表層角結膜炎に対する直接的な臨床・前臨床エビデンスの収集
- 細菌性の病因が関与する亜型に限定した適用可能性の検討
- 眼科用製剤（点眼液）の再承認・供給状況の確認

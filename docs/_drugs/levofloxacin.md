# レボフロキサシン：細菌感染症（眼瞼炎・結膜炎など）から点状表層角結膜炎へ

## 一言要約

レボフロキサシンはフルオロキノロン系の広域抗菌薬で、日本では眼瞼炎や結膜炎などの細菌感染症に使われています。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測していますが、裏付けとなる臨床試験は **0 件**、文献は **1 編**（レボフロキサシンの有効性データを含まない集団発生の報告）のみで、エビデンスは実質的にモデル予測に限られます。

## この予測が妥当である理由

レボフロキサシンは細菌の DNA ジャイレースとトポイソメラーゼ IV を阻害し、殺菌的に作用します。詳細な作用機序データは入力に含まれていませんが、この作用は細菌感染症に対するものです。

点状表層角結膜炎は、主にウイルス性やミクロスポリジア性で、細菌感染が原因の場合は多くありません。そのため、抗菌活性から予測を機序的に説明することは難しく、TxGNN の高スコアは知識グラフ上の関連に基づく計算上の予測と考えるべきです。細菌性の結膜炎と眼表面疾患としての近さが背景にある可能性はありますが、現時点で裏付けはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
点状表層角結膜炎に対するレボフロキサシンの臨床試験はなく、唯一の文献は有効性データを含まない集団発生報告です。原因がウイルスやミクロスポリジアであることが多く、抗菌薬としての機序的根拠も乏しいため、モデル予測のみの段階です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の入手と確認
- 点状表層角結膜炎の原因別（細菌性かどうか）にレボフロキサシンの有効性を調べる文献・試験の探索
- 承認適応症と作用機序データの正式な確認

なお、同じ予測リストの 7 位「単クローン性ガンマグロパチー」には、多発性骨髄腫患者を対象とした Phase 3 RCT（TEAMM 試験）があり、感染予防効果が示されています（エビデンスレベル L1、Proceed with Guardrails）。優先度の高い候補としては、こちらを別途評価する価値があります。

*本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証を経て初めて応用できます。*

# Berberine：從腹瀉到重度子癲前症

## 一言まとめ

Berberine 原本用於治療腹瀉、急慢性腸炎和細菌性痢疾。
TxGNN 模型預測它可能對**重度子癲前症 (Severe Pre-eclampsia)** 有效，
但目前僅有模型預測的潛力，缺乏臨床試驗和文獻支持。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 腹瀉、急慢性腸炎、腸內異常醱酵、細菌性痢疾 |
| 予測新適応症 | 重度子癲前症 (Severe Pre-eclampsia) |

## この予測が妥当な理由

目前缺乏詳細的作用機轉資料。根據已知資訊，Berberine 是一種生物鹼，廣泛用於治療腸道感染。
其在腹瀉和腸道疾病中的療效已被證實，但在重度子癲前症中的應用仍需更多研究支持。

## 結論と次のステップ

**判断：Hold**

**理由：**
目前缺乏任何臨床試驗和文獻證據支持 Berberine 用於重度子癲前症，
僅有模型預測顯示其潛力。

**推進に必要な事項：**
- 詳細的藥物作用機轉資料（MOA）
- 進一步的臨床試驗以驗證其在重度子癲前症中的療效

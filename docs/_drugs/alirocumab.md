# Alirocumab：降脂薬から コレステロール代謝疾患への潜在的新適応症

## 一言まとめ

Alirocumab は PCSK9 モノクローナル抗体であり、主に LDL-C の低下および心血管イベントの予防に用いられます。TxGNN は、黄色腫症およびコレステロール代謝疾患に対する治療の可能性を予測しています。

## この予測が妥当な理由

Alirocumab は PCSK9 阻害薬であり、PCSK9 と LDL 受容体の結合を阻止することで肝臓の LDL 受容体密度を増加させ、血中 LDL-C 濃度を 50-60% 顕著に低下させます。

**予測される機序のつながり：**

1. **黄色腫症（Xanthomatosis）**：黄色腫はコレステロールが皮膚や腱に沈着して形成される病変で、家族性高コレステロール血症の患者によくみられます。Alirocumab は LDL-C を大幅に低下させ、PCSK9 阻害薬が黄色腫を有効に減少させたとする症例報告がすでにあります。

2. **コレステロール異化障害**：PCSK9 はコレステロール代謝において重要な役割を担っており、alirocumab は LDL 受容体活性を高めることで、さまざまなコレステロール代謝異常を改善しうると考えられます。

## 安全性に関する考慮事項

- **薬物相互作用**：Alirocumab はモノクローナル抗体であり、PCSK9 と結合します
- **主な副作用**：注射部位反応（約 1.7%）
- **安全性データ**：ODYSSEY OUTCOMES 試験で 47,000 患者年の観察が行われ、安全性はプラセボと同程度でした

安全性情報は添付文書をご参照ください。

## 結論と次のステップ

**判断：Consider**

**理由：**
Alirocumab の黄色腫症およびコレステロール代謝疾患に対する予測は、機序の面で強い合理性があります。PCSK9 阻害薬が黄色腫を合併する高コレステロール血症患者を有効に治療できたとする症例報告がすでにあります。薬剤の安全性は大規模臨床試験によって裏付けられています。

**推進に必要な事項：**
- 黄色腫症を対象とした前向き臨床試験
- 長期使用による黄色腫の退縮効果の確認
- 費用対効果の評価（PCSK9 阻害薬の高価格を考慮）

# Alirocumab：從降血脂到膽固醇代謝疾病的潛在新適應症

## 一言まとめ

Alirocumab 是 PCSK9 單株抗體，主要用於降低 LDL-C 及預防心血管事件，TxGNN 預測其可能對黃色瘤病及膽固醇代謝疾病有治療潛力。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 預防心血管事件、原發性高血脂症、異合子家族性高膽固醇血症 |
| 予測新適応症 | 黃色瘤病（Xanthomatosis）、膽固醇分解代謝疾病 |
| TxGNN 予測スコア | 0.994（黃色瘤病）、0.994（膽固醇代謝疾病） |
| エビデンスレベル | L3（有文獻支持） |
| 日本上市 | 已上市 |
| 承認数 | 13 張 |
| 推奨判断 | Consider |

## この予測が妥当な理由

Alirocumab 是一種 PCSK9 抑制劑，通過阻止 PCSK9 與 LDL 受體結合，增加肝臟 LDL 受體密度，從而顯著降低血液中 LDL-C 濃度達 50-60%。

**預測的機轉連結：**

1. **黃色瘤病（Xanthomatosis）**：黃色瘤是由於膽固醇沉積於皮膚和肌腱所形成的病變，常見於家族性高膽固醇血症患者。Alirocumab 能大幅降低 LDL-C，已有病例報告顯示 PCSK9 抑制劑可有效減少黃色瘤。

2. **膽固醇分解代謝疾病**：PCSK9 在膽固醇代謝中扮演關鍵角色，alirocumab 透過增加 LDL 受體活性，可改善多種膽固醇代謝異常。

## 安全性に関する考慮事項

- **藥物交互作用**：Alirocumab 作為單株抗體，與 PCSK9 結合
- **常見副作用**：注射部位反應（約 1.7%）
- **安全性資料**：ODYSSEY OUTCOMES 試驗顯示 47,000 病人年觀察，安全性與安慰劑相當

安全性情報は添付文書をご参照ください。

## 結論と次のステップ

**判断：Consider**

**理由：**
Alirocumab 對黃色瘤病和膽固醇代謝疾病的預測具有強烈的機轉合理性。已有病例報告顯示 PCSK9 抑制劑可有效治療合併黃色瘤的高膽固醇血症患者。藥物安全性已有大型臨床試驗支持。

**推進に必要な事項：**
- 針對黃色瘤病的前瞻性臨床試驗
- 確認長期使用對黃色瘤消退的效果
- 評估成本效益，考量 PCSK9 抑制劑的高價格

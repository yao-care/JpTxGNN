# エソメプラゾール：胃酸関連疾患（消化性潰瘍薬）から十二指腸胃逆流へ

## 一言要約

エソメプラゾールはプロトンポンプ阻害薬（PPI）で、日本では胃酸分泌抑制薬・消化性潰瘍薬として市販されています。
TxGNN モデルは**十二指腸胃逆流 (Duodenogastric Reflux)** に有効である可能性を予測していますが、この適応症を直接支持する臨床試験は **0 件**、文献は総説 **1 編**のみで、エビデンスは限定的です。

## この予測が妥当である理由

エソメプラゾールは、胃壁細胞の H+/K+-ATPase（プロトンポンプ）を阻害して胃酸分泌を抑えます。この作用は、逆流した内容物による粘膜障害を軽減する可能性があります。

ただし、十二指腸胃逆流は胆汁などの逆流が中心で、主な原因は胃酸ではありません。そのため、機序上のつながりは間接的です。詳細な作用機序データ（DrugBank）は現時点で取得できていません。上記の説明は Evidence Pack 内の機序的根拠に基づくものです。

## 結論と次のステップ

**決定：Hold**

**理由：**
十二指腸胃逆流については、直接の臨床試験がなく、文献も一般的な PPI 総説 1 編のみです。加えて、胆汁逆流は酸主体の病態ではなく、機序上のつながりも間接的です。

なお、同じ Evidence Pack の「十二指腸潰瘍」「活動性消化性潰瘍」は、複数の Phase 3 試験と RCT があり、エビデンスレベルは L1 です。ただし、これらは既存適応症の範囲に近く、再利用というより承認済み用途の確認にあたります。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現状、安全性スクリーニングの阻害要因）
- DrugBank からの作用機序（MOA）データ取得
- 十二指腸胃逆流に対する直接的な臨床エビデンス（観察研究や小規模試験など）の収集
- 既存適応症の承認内容（効能・効果）の確認

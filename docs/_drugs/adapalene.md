# アダパレン：尋常性ざ瘡から血漿亜鉛高値へ

## 一言要約

アダパレンはレチノイン酸受容体（RAR）作動薬で、元々**尋常性ざ瘡（ニキビ）**の治療に使用されていました。
TxGNN モデルは **血漿亜鉛高値 (zinc, elevated plasma)** に有効である可能性を予測していますが、
現在、この方向性を支持する**臨床試験・文献はいずれもなく**、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 尋常性ざ瘡 |
| 予測新規適応症 | 血漿亜鉛高値 (zinc, elevated plasma) |
| TxGNN 予測スコア | 99.51% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売中の製品なし（承認はすべて整理済み／取り消し） |
| 承認番号数 | 14 件（有効 0 件、取り消し 14 件） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アダパレンは RAR（β/γ 選択性）作動薬で、尋常性ざ瘡の治療薬として使用されてきました。

ただし、RAR 作動作用と血漿亜鉛値の調節を結びつける確立した機序は見当たりません。ざ瘡と血漿亜鉛高値の間にも、明確な病態上の関連性は確認できません。

TxGNN のスコアは高いものの（99.51%）、ネットワークに基づく推論にすぎず、裏付けとなる臨床試験や文献はありません。現時点では仮説の段階であり、妥当性は限定的です。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、TxGNN 知識グラフに基づく）：光感受性疾患、光突発反応、剥脱性皮膚炎、皮膚炎
- **薬物相互作用**：58 件が検出されています。主なものはパントプラゾール、ドキシサイクリン、オメプラゾール、トリアムシノロン、プレドニゾン、テトラサイクリン、ミノサイクリン、メトロニダゾールなどです。重症度は未分類です。

警告・禁忌の詳細については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測を支持する臨床試験や文献がなく、エビデンスはモデル予測のみ（L5）です。RAR 作動作用と血漿亜鉛高値を結ぶ機序も確認できません。
- 日本では有効な承認が残っておらず、添付文書の警告・禁忌情報も未取得です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と安全性スクリーニング
- 作用機序（MOA）データの補充（DrugBank など）
- RAR 作動作用と亜鉛代謝の関連を示す前臨床・機序研究の調査
- 外用剤である本剤の投与経路と、予測適応症（全身性の血中亜鉛異常）との適合性の確認
- 血漿亜鉛高値の疾患定義と臨床的意義の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# アダパレン：尋常性ざ瘡から血漿亜鉛高値へ

## 一言要約

アダパレンはレチノイン酸受容体（RAR）作動薬で、元々は尋常性ざ瘡（ニキビ）の治療に使われています。
TxGNN モデルは**血漿亜鉛高値 (zinc, elevated plasma)** に有効である可能性を予測していますが、その根拠はモデル予測のみです。
現在、この方向性を支持する**臨床試験は 0 件、文献も 0 編**です。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。日本の承認情報では、アダパレンは抗ニキビ薬、RAR 作動薬に分類されています。外用レチノイドとして RAR-β/γ に作用し、角化細胞の分化と炎症を調節すると考えられます。

一方で、この作用と血漿中の亜鉛の恒常性を結ぶ既知のメカニズムは確認できません。既存適応症（尋常性ざ瘡）と予測疾患（血漿亜鉛高値）の間にも、明確な病態上の関連は見当たりません。

したがって、今回の予測は TxGNN のスコア（0.995、モデル内順位 3257 位）だけに支えられています。スコアが高くても、機序面と臨床面の裏付けはまだありません。既存薬と予測疾患の類似性の評価や、投与経路の適合性の評価も未実施です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測はモデルスコアのみに基づいており、臨床試験も文献もありません。アダパレンの作用機序と血漿亜鉛の調節を結ぶ既知の関連も確認できないため、現時点で先へ進める根拠は不足しています。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングに必須）
- DrugBank からの作用機序（MOA）データの取得
- 血漿亜鉛高値との機序的関連を裏付ける前臨床・文献エビデンスの調査
- 外用薬であるアダパレンと、予測疾患に必要な投与経路の適合性評価

本レポートはモデル予測に基づく研究参考情報であり、医療上の助言ではありません。臨床応用には臨床的検証が必要です。

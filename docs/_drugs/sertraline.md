# セルトラリン：うつ病・パニック障害から演技性パーソナリティ障害へ

## 一言要約

セルトラリンは選択的セロトニン再取り込み阻害薬（SSRI）で、日本では元々うつ病・うつ状態とパニック障害の治療に使われています。
TxGNN モデルは**演技性パーソナリティ障害 (Histrionic Personality Disorder)** に有効である可能性を予測していますが、この疾患を直接検証した**臨床試験は 0 件**です。関連文献は **1 編**のみで、内容もうつ病患者を対象とした研究です。実質的にはモデル予測の段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、セルトラリンはセロトニン再取り込みを阻害する SSRI 系抗うつ薬で、うつ病・うつ状態とパニック障害での有効性が確立されています。

セルトラリンはシナプス間隙のセロトニンを増やすことで、併存するうつ症状や不安症状を和らげる可能性があります。ただし、演技性パーソナリティ障害そのものに対する効果を支持するエビデンスはありません。この予測は、モデルが算出した関連性の高さ（スコア 99.93%）によるものです。

なお、今回取得できた 1 編の文献は、うつ病患者を対象にした薬物治療後の MMPI-2 尺度（心気症・抑うつ・ヒステリー）の変化を調べた研究です。演技性パーソナリティ障害への有効性を直接示すものではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
演技性パーソナリティ障害に対する臨床試験はなく、文献も直接の裏付けになりません。エビデンスはモデル予測のみ（L5）のため、現時点で開発を進める根拠は不十分です。

**進める場合に必要なもの：**
- 演技性パーソナリティ障害を対象とした臨床研究または症例報告の調査
- 詳細な薬物作用機序データ（MOA）の取得（DrugBank API など）
- PMDA の添付文書（警告・禁忌）の取得と、安全性スクリーニングの実施
- 本レポートの予測以外に、同じ薬物で予測されたパニック障害を伴う広場恐怖症と大うつ病性障害は既承認または確立済みの用途です。新規再利用候補というより、既存適応症の裏付けとして扱うのが適切です。

※ 本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床的な検証を経て初めて応用できます。

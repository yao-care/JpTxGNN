# セルトラリン：うつ病・パニック障害から演技性パーソナリティ障害へ

## 一言要約

セルトラリンは選択的セロトニン再取り込み阻害薬 (SSRI) で、日本ではうつ病・うつ状態とパニック障害の治療に使われてきました。
TxGNN モデルは**演技性パーソナリティ障害 (histrionic personality disorder)** に有効である可能性を予測しています。
ただし、この疾患を直接支持する臨床試験・文献は**どちらも 0 件**で、現時点ではモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、セルトラリンは SSRI に分類され、セロトニンの再取り込みを阻害します。うつ病・パニック障害での有効性は確立しています。

この作用により、感情の不安定さや衝動性が和らぐ可能性があります。演技性パーソナリティ障害は感情の変動が大きいことが特徴の一つで、機序上は関連づけられます。

ただし、この関連は TxGNN の予測に基づく仮説です。この疾患に対する臨床試験も文献も見つかっていません。治療効果を示す根拠は現時点でありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高い (99.93%) ものの、この疾患を支持する臨床試験・文献が 1 件もなく、根拠はモデル予測のみ (L5) です。
- 日本での承認はすべて取消済みで、添付文書の警告・禁忌も未確認です。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と確認
- 詳細な作用機序データ (MOA) の補充
- 演技性パーソナリティ障害に関する文献と臨床試験の再調査
- 症例報告や小規模な探索的研究による予備的な有効性の確認
- 双極性障害の併存例や併用薬（セロトニン症候群リスク）に配慮した安全性モニタリング計画

**参考：他の予測候補について**
上位 4 件（演技性、失調型、妄想性、シゾイドの各パーソナリティ障害）は予測スコアが同一 (99.93%) で、順位の差は根拠になりません。

今回のデータには、エビデンスが厚い候補も含まれています。

- **広場恐怖（パニック障害に伴うもの）**：RCT やネットワークメタ解析が多数あります (L1)。ただし既存適応症のパニック障害に近く、新規性は限定的です。
- **大うつ病性障害・内因性うつ病**：既存適応症と重なります。

これらは「再利用」というより既存適応症の裏づけと位置づけるのが適切です。

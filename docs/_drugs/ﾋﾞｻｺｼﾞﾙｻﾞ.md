# ビサコジルザ：評価レポート（データ不足）

## 一言要約

ビサコジルザ（`ﾋﾞｻｺｼﾞﾙｻﾞ`）は日本市場での承認情報が確認されておらず、DrugBank への照会では 1 件がヒットしたものの DrugBank ID の取得には至りませんでした。
TxGNN モデルによる新規適応症の予測は実施されておらず、安全性・作用機序データもいずれも未取得です。
現時点では評価を進めるために必要な基礎データが揃っていないため、追加のデータ収集が必要です。

## この予測が妥当である理由

現時点では TxGNN による適応症予測が存在しないため、このセクションは評価対象外です。

作用機序データ（MOA）も未取得であり、DrugBank ID が不明のため既知の薬理学的プロファイルとの照合も行えていません。薬物名クエリ `ﾋﾞｻｺｼﾞﾙｻﾞ`（ビサコジルザ）について PMDA 検索では結果 0 件、DrugBank 検索では 1 件ヒットしたものの、ID が確定していない状況です。

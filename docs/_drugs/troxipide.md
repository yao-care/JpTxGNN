# トロキシピド：胃潰瘍から食道炎へ

## 一言要約

トロキシピドは胃粘膜保護作用をもつ消化性潰瘍治療薬で、日本では胃潰瘍の治療に使用されていました。
TxGNN モデルは**食道炎 (Esophagitis)** に有効である可能性を予測しています。ただし、この予測を裏付ける臨床試験と文献は **0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 消化性潰瘍薬（胃潰瘍） |
| 予測新規適応症 | 食道炎 (Esophagitis) |
| TxGNN 予測スコア | 99.94% |
| エビデンスレベル | L5 |
| 日本市販状況 | 取消のみ（現在有効な承認なし） |
| 承認番号数 | 1 件（取消済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、トロキシピドは胃粘膜保護薬で、抗炎症作用をもつとされます。胃潰瘍での使用実績があり、炎症を起こした食道粘膜にも有益である可能性があります。

胃と食道はどちらも上部消化管粘膜であり、粘膜保護や抗炎症という作用は両者に共通して関わりうるため、機序的な関連は想定できます。ただし、これは TxGNN の予測に基づく推測にすぎず、臨床的・文献的な裏付けはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
食道炎については TxGNN の予測スコアが高いものの、臨床試験も文献もなく、エビデンスは L5（モデル予測のみ）です。また、日本の承認は取消済みで、現在市販されている製品はありません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の入手（現状では安全性スクリーニングに進めない）
- 詳細な作用機序データ（MOA）の補充
- 食道炎に関する前臨床・臨床研究の調査
- 経路適合性（投与経路）の評価
- 前臨床エビデンスのある活動性消化性潰瘍や胃空腸潰瘍を、優先的な研究課題として検討すること
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

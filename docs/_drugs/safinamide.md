# サフィナミド：既存適応症データなしから Rasmussen 亜急性脳炎へ

## 一言要約

サフィナミドは日本で「エクフィナ錠50mg」として市販されている経口薬です。ただし今回の入力データには、承認適応症の記載がありません。
TxGNN モデルは **Rasmussen 亜急性脳炎 (Rasmussen subacute encephalitis)** に有効な可能性を予測しています。しかし裏付けとなる臨床試験・文献は **0 件** で、**モデル予測のみ (L5)** の段階です。

## この予測が妥当である理由

現在、詳細な作用機序データ (original_moa) は入力に含まれていません。以下は一般的な薬理学に基づく推論で、臨床的な裏付けはありません。

サフィナミドは MAO-B 阻害薬で、電位依存性ナトリウムチャネルの遮断とグルタミン酸放出の抑制も報告されています。Rasmussen 亜急性脳炎は難治性のてんかん発作を特徴とする炎症性脳疾患です。そのため、発作活動や興奮毒性を抑える方向に働く可能性が理論上は考えられます。

ただし、この関連づけは TxGNN の予測と一般的な薬理知識のみに基づいています。臨床データも前臨床データも確認できていません。

## サフィナミド：パーキンソン病からラスムッセン亜急性脳炎へ
{: .text-alpha }

## 一言要約

サフィナミドは MAO-B 阻害作用をもつ薬で、元々パーキンソン病およびその関連症候群の治療に使用されていました。
TxGNN モデルは**ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis)** に有効である可能性を予測していますが、
現時点で支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

詳細な作用機序データは、今回まとめたデータには含まれていません。ただし、サフィナミドは可逆的 MAO-B 阻害薬であり、電位依存性ナトリウムチャネルの遮断とグルタミン酸放出の調節作用も知られています。これらの作用は、神経の過興奮や興奮毒性を抑える可能性が理論上あります。

ラスムッセン脳炎は、てんかん発作と進行性の神経障害を特徴とする疾患です。パーキンソン病は神経変性疾患であり、病態は異なりますが、神経の過興奮の抑制という点で理論的な接点はあります。

ただし、ラスムッセン脳炎の主な病態は T 細胞が関与する自己免疫性の炎症です。この機序に対するサフィナミドの有効性を示す臨床データも前臨床データもなく、この関連は TxGNN の予測に基づく仮説にとどまります。

## 安全性に関する考慮事項

- **薬物相互作用**：相互作用データベースで 100 件が登録されています。主なものは以下のとおりです。
  - **重大 (Major)**：ブプロピオン
  - **中等度 (Moderate)**：

    - 交感神経刺激薬・食欲抑制薬（フェンテルミン、ジエチルプロピオン、イソメテプテン）
    - その他（メトクロプラミド、ロスバスタチン）

詳細な警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、臨床試験も文献もなく、エビデンスはモデル予測のみ (L5) です。
- 作用機序と、ラスムッセン脳炎の自己免疫性炎症という主病態との間にも明確なつながりがありません。
- 添付文書の警告・禁忌情報が未取得で、安全性評価を進められない状態です。
- 日本では承認が整理されており、現在は市販されていません。

**進める場合に必要なもの：**
- 添付文書（PMDA）から警告・禁忌を取得し、安全性評価を行う
- DrugBank から詳細な作用機序 (MOA) データを取得する
- ラスムッセン脳炎に対する前臨床研究（てんかんモデル、神経炎症モデルなど）や症例報告の調査
- 疾患の主病態（自己免疫性炎症）との機序的整合性の再評価
- 上位 3 候補（ラスムッセン脳炎、脊髄炎、PLA2G6 関連神経変性症）の優先順位づけ。実現性の面では、パーキンソン症状を伴う PLA2G6 関連神経変性症を先に検討する余地があります。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

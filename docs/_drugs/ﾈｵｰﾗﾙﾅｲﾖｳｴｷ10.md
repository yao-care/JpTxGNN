## 一言要約

ネオーラル内用液10%（シクロスポリン内用液）は免疫抑制薬として広く知られており、臓器移植後の拒絶反応抑制や自己免疫疾患に使用される製剤です。
本 Evidence Pack では TxGNN による予測新規適応症が**検出されておらず**、既承認適応症・安全性データも取得できていないため、通常の再利用評価レポートを生成できない状態です。
データ補完後に改めて評価を実施することを推奨します。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN モデルによる予測適応症が検出されておらず、既承認適応症・安全性データもいずれも未取得のため、再利用評価に必要な最低限のエビデンスが揃っていません。なお、クエリログ上では DrugBank 照合が 1 件ヒットしているにもかかわらず Evidence Pack に `drugbank_id: null` と記録されており、パイプライン上のマッピング漏れが疑われます。

**進める場合に必要なもの：**
- **薬物名の正規化**：半角カタカナ → 全角カタカナまたは一般名（Cyclosporine / シクロスポリン）に変換して PMDA・DrugBank を再照合
- **DrugBank ID の確定**：クエリログ上のヒット結果（1 件）をパイプラインに正しく反映させ、`drugbank_id` を確定
- **MOA データの取得**：DrugBank API 経由でカルシニューリン阻害薬としての作用機序を補完（DG002）
- **添付文書の解析**：PMDA 公式サイトからネオーラル仿單 PDF をダウンロードし、警告・禁忌を抽出（DG001）
- **TxGNN 予測の再実行**：上記データ補完後に `run_kg_prediction.py` および DL モデルを再実行して予測候補を生成

# ヒドロコルチゾンリン：評価レポート（予測適応症なし）

---

## 一言要約

ヒドロコルチゾンリン（Hydrocortisone Phosphate）はコルチコステロイド系薬物であり、一般的に炎症・アレルギー反応・副腎皮質機能不全などの治療に使用されることが知られています。
今回の Evidence Pack では **TxGNN による予測適応症が存在せず**、DrugBank ID・作用機序・安全性データもいずれも未取得の状態です。
現時点では再利用候補として評価できる状態になく、**Hold** を推奨します。

## この予測が妥当である理由

TxGNN モデルによる予測適応症が存在しないため、機序的関連性の評価は現時点では実施できません。

`ﾋﾄﾞﾛｺﾙﾁｿﾞﾝﾘﾝ`（ヒドロコルチゾンリン）は「ヒドロコルチゾン（Hydrocortisone）」に「リン酸基」が付加された誘導体と考えられますが、DrugBank ID が未同定であるため、知識グラフ上での薬物ノードを特定できず、予測計算が実行されていない可能性があります。薬名の正規化（半角カタカナ → INN 英語名）を行ったうえで再クエリすることが先決です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN 予測結果が存在せず、DrugBank ID・MOA・安全性データがいずれも未取得であるため、再利用候補として評価できる状態にありません。まずデータギャップの解消が必要です。

**進める場合に必要なもの：**
- `ﾋﾄﾞﾛｺﾙﾁｿﾞﾝﾘﾝ` の INN 正規化（例：Hydrocortisone Sodium Phosphate）および DrugBank ID の特定
- DrugBank API による作用機序（MOA）データの取得
- PMDA 添付文書 PDF の解析による警告・禁忌情報の収集
- DrugBank ID 特定後に TxGNN 予測を再実行し、予測適応症を確認

# ケトチフェンシロップ 0.02%：評価保留 — 予測新規適応症なし

## 一言要約

ケトチフェンシロップ 0.02% は抗ヒスタミン薬・肥満細胞安定薬として知られるケトチフェンの小児用シロップ製剤です。
今回の Evidence Pack では **PMDA 照会で登録ゼロ件**、予測新規適応症も得られなかったため、老薬新用の評価対象候補が存在しない状態です。
データギャップが複数残っており、現段階では本格的な再利用評価を進めることができません。

## 結論と次のステップ

**決定：Hold**

**理由：**
PMDA への照会で本製剤の承認記録が確認されず、TxGNN による予測新規適応症も生成されていないため、再利用候補の評価を開始できる状態にありません。DrugBank では 1 件ヒットしているものの、MOA・承認適応症・安全性警告のすべてがデータギャップとなっており、評価の基礎情報が揃っていません。

**進める場合に必要なもの：**
- **INN 単独での再照会**：「ケトチフェンシロップ０．０２％」という剤形込みの名称ではなく、INN「Ketotifen（ケトチフェン）」で PMDA・DrugBank を再クエリし、承認適応症と承認番号を取得する
- **DrugBank MOA の取得**：DrugBank API から作用機序（H1 拮抗・肥満細胞安定作用）を取得し、予測エンジンへ入力する
- **TxGNN 予測の再実行**：正しい DrugBank ID が取得できた後、KG 予測および DL 予測を実行して候補疾患リストを生成する
- **安全性情報の取得**：PMDA 仿単 PDF またはドラッグインフォメーションから主要警告・禁忌を抽出する（現状 DG001 Blocking）
## 免責事項

臨床応用の前に臨床的検証が必要です。

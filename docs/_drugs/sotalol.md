# ソタロール：抗不整脈薬から脳卒中（予測）へ

## 一言要約

ソタロールは β 遮断作用とカリウムチャネル（IKr）遮断作用を併せ持つ抗不整脈薬で、元々は不整脈の治療に使われていました。
TxGNN モデルの予測上位は洞不全症候群 2 型（常染色体優性）ですが、機序的には妥当性が低く、むしろ安全性上の懸念があります。そのため本レポートでは、臨床試験と文献が存在する**脳卒中 (stroke disorder)** も併せて評価しました。
脳卒中については **1 件の臨床試験**と **20 編の文献**がありますが、いずれも心房細動の治療に関するもので、ソタロールが脳卒中そのものを減らすという直接的な証拠はありません。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 抗不整脈薬、β遮断薬、カリウムチャネル遮断薬 |
| 予測新規適応症 | 洞不全症候群 2 型、常染色体優性 (sick sinus syndrome 2, autosomal dominant)（予測順位 1 位） |
| TxGNN 予測スコア | 99.76%（脳卒中 (stroke disorder) は 99.44%） |

| 日本市販状況 | 市販中の承認なし（取消のみ） |
| 承認番号数 | 7 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ソタロールは非選択的 β 遮断作用とクラス III（IKr カリウムチャネル遮断）作用を併せ持つ抗不整脈薬です。

予測順位 1 位の洞不全症候群 2 型は、HCN4 に関連する洞結節のチャネル異常症です。ソタロールの徐拍化作用・陰性変時作用は洞結節機能をさらに悪化させるおそれがあります。したがってこの予測は薬理学的に妥当とは言えず、むしろ禁忌に近い関係と考えられます。

脳卒中については、心房細動のリズムコントロールを介した間接的な関連があります。心房細動は心原性脳塞栓の主要な危険因子だからです。ただし、ソタロール自体が脳卒中の発症を減らしたという証拠は示されていません。

その他の予測（Wildervanck 症候群、サルコグリカン異常症、双極性障害の躁状態、大頭症を伴う顔貌異常と精神運動発達遅滞、旧称の虚血性脳卒中感受性）には、機序的な裏付けも臨床的な裏付けもありません。モデルのスコアのみに基づく予測です。

  中等度（Moderate）にはファモチジン、アトロピン、モルヒネ、ブプロピオン、カナグリフロジン、ダパグリフロジン、シメチジン、クロルプロパミドなどがあります。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測順位 1 位の洞不全症候群 2 型は、ソタロールの徐拍化作用により悪化する可能性があり、安全性上不適切です。脳卒中については心房細動治療を介した間接的な関連しかなく、ソタロール単独で脳卒中を減らす証拠もありません。さらに日本では現在有効な承認がありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングに必須）
- DrugBank からの作用機序（MOA）データの取得
- 脳卒中予防を主要評価項目とした、ソタロールと他の抗不整脈薬の比較データ
- 日本での販売状況（承認取消の経緯）と供給可能性の確認
- 洞不全症候群 2 型の予測は、禁忌との重複を踏まえて除外を検討

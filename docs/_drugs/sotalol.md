# ソタロール：抗不整脈治療から洞不全症候群 2 型（常染色体優性）へ

## 一言要約

ソタロールは β 遮断作用とカリウムチャネル（IKr）遮断作用を併せ持つ抗不整脈薬で、日本では不整脈治療に使われています。
TxGNN モデルは**洞不全症候群 2 型・常染色体優性 (sick sinus syndrome 2, autosomal dominant)** への有効性を予測していますが、**臨床試験も文献も 0 件**です。
既知の薬理作用から見ると、この予測は徐脈を悪化させる方向に働く可能性があり、妥当性は低いと考えられます。

## この予測が妥当である理由（妥当性は低い）

現在、詳細な作用機序データはありません。ただし、日本の承認情報から、ソタロールは β 遮断薬かつカリウムチャネル遮断薬であることが分かっています。この 2 つの作用は洞調律と房室伝導を遅くします。

洞不全症候群 2 型は、HCN4 遺伝子の変異による徐脈性疾患です。ソタロールの作用は徐脈を悪化させる可能性があり、既存の不整脈治療との間に治療上の接点は見いだせません。TxGNN の高スコアは、知識グラフ上の関連から生じたもので、臨床的な裏付けはないと考えるのが妥当です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測は L5（モデル予測のみ）で、臨床試験も文献もありません。ソタロールの徐脈作用は洞不全症候群にとって有害となり得るため、現時点で進める根拠はありません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の入手と内容の確認。これが未了のため、安全性スクリーニングに進めません
- DrugBank からの作用機序 (MOA) データの取得
- 洞不全症候群 2 型に対するソタロールの安全性に関する機序的な再評価（徐脈・房室ブロックのリスク）
- 別の予測適応症を追う場合は、脳卒中（心房細動を介した間接効果）を研究課題として優先的に検討する

# カルボプラチン：白金系抗悪性腫瘍薬から女性乳癌へ

## 一言要約

カルボプラチンは白金系の抗悪性腫瘍薬で、日本では複数の注射剤として市販されています。
TxGNN モデルは**女性乳癌 (female breast carcinoma)** に有効である可能性を予測しています。
乳癌領域では、確認できた範囲でカルボプラチンを含む臨床試験が約 30 件、関連文献が 20 編あります。完了した Phase 3 の無作為化試験は 2 件です。

Evidence Pack 内の自動判定は L2 です。本レポートは判定ルールを字義どおりに適用して L1 としました。根拠の 2 試験（NCT02003209、NCT02125344）は、いずれもカルボプラチン単独の効果を検証する設計ではありません。実質的な確度は L1 と L2 の中間と考えるのが妥当です。

## この予測が妥当である理由

カルボプラチンは白金-DNA 架橋を形成し、DNA 複製を阻害してアポトーシスを誘導します。DrugBank の作用機序データは今回取得できていません。ここでの説明は、Evidence Pack に記載された機序的リンクに基づきます。

この作用は、DNA 修復能が低下したサブタイプで特に重要です。代表例がトリプルネガティブ乳癌 (TNBC) です。GeparSixto 試験の抄録にも、TNBC は鎖間架橋剤に感受性があるという前臨床データが、カルボプラチン追加の根拠として書かれています。

乳癌でのカルボプラチンは、多くの場合パクリタキセルやドセタキセルなどのタキサン、抗 HER2 療法との併用で使われます。そのため、カルボプラチン単独の寄与を切り出すのは難しい点に注意が必要です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
乳癌、特に TNBC と HER2 陽性乳癌では、カルボプラチンを含む Phase 2〜3 の試験と RCT、メタ解析が多数あります。市販薬としての承認実績もあり、エビデンスは比較的充実しています。一方で、多くは併用療法での検証で、カルボプラチン単独の寄与は限定的にしか評価できません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（現状は取得できておらず、安全性スクリーニングの前提条件）
- 日本での承認適応症テキストの確認（今回のデータには含まれていません）
- DrugBank からの作用機序データの補完
- サブタイプ別（TNBC、HER2 陽性、BRCA 変異）の有効性と、カルボプラチン単独の寄与の整理
- 骨髄抑制を中心とした安全性モニタリング計画

本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は、臨床的な検証を経てから応用する必要があります。

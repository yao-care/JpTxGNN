## カルボプラチン：白金系抗悪性腫瘍薬 → 直腸粘液腺癌 (rectum mucinous adenocarcinoma)
{: .text-alpha }

## 一言要約

カルボプラチンは、DNA 架橋によって腫瘍細胞の増殖を抑える白金系の抗悪性腫瘍薬です。
TxGNN モデルは**直腸粘液腺癌 (rectum mucinous adenocarcinoma)** に有効な可能性を予測しています（スコア 0.9928）。
ただし、この疾患を直接検討した臨床試験や文献は、今回まとめたデータには含まれておらず、エビデンスはモデル予測のみ（L5）です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。一般に、カルボプラチンは白金系薬剤として DNA 鎖間・鎖内に架橋を作り、細胞の複製を妨げてアポトーシスを誘導します。この細胞傷害作用は、増殖の速い腺癌であれば原理的に働きうると考えられます。

一方で、粘液性の組織型は一般に化学療法への感受性が低いとされています。そのため、機序上は成り立つとしても、実際の効果は未確認です。直腸粘液腺癌でのカルボプラチンの有効性を示す臨床データは、今回のデータにはありません。

# カルボプラチン：頭頸部癌・卵巣癌などから女性乳癌へ

## 一言要約

カルボプラチンは白金系の抗悪性腫瘍薬で、元々頭頸部癌、肺小細胞癌、卵巣癌、子宮頸癌、悪性リンパ腫などの治療に使用されていました。
TxGNN モデルは**女性乳癌 (Female Breast Carcinoma)** に有効である可能性を予測しており、現在 **約 50 件の臨床試験**と **20 編の文献**がこの方向性を支持しています。この中には Phase 3 の RCT も含まれます。

|------|------|
| 既存適応症 | 頭頸部癌、肺小細胞癌、睾丸腫瘍、卵巣癌、子宮頸癌、悪性リンパ腫、非小細胞肺癌、乳癌、子宮体癌、神経芽腫、網膜芽腫、肝芽腫、ユーイング肉腫ファミリー腫瘍、腎芽腫 |

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank 登録の MOA）はありません。既知の情報によると、カルボプラチンは白金系抗悪性腫瘍薬で、白金-DNA 架橋を形成して DNA 複製を阻害し、アポトーシスを誘導します。

乳癌は既存の承認適応症一覧にもすでに含まれています。そのため今回の予測は、まったく新しい疾患への展開というより、特定のサブタイプでの位置づけの裏付けと捉えるのが適切です。特に DNA 修復機能が低下した腫瘍、すなわちトリプルネガティブ乳癌や BRCA 関連乳癌では、DNA 架橋剤への感受性が高いと考えられます。

実際に、トリプルネガティブ乳癌の術前化学療法へのカルボプラチン上乗せを検討した BrighTNess（Phase 3）、GeparSixto、CALGB 40603（いずれもランダム化 Phase 2）などの試験があります。TxGNN の予測は、これらの臨床的知見と整合しています。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書ではなくモデルの知識グラフに基づく情報）：腎疾患、肝疾患、胆嚢疾患、膿尿管症、血小板減少症、好中球減少症、無顆粒球症、白血球減少症、貧血、血液凝固障害、末梢神経障害、聴覚障害、機能性視力低下
- **薬物相互作用**（合計 100 件、主なもの）：
  - 中等度：プロトンポンプ阻害薬（ラベプラゾール、オメプラゾール、エソメプラゾール、ランソプラゾール、デクスランソプラゾール、パントプラゾール）、アミノグリコシド系（カナマイシン、ネオマイシン、ストレプトマイシン）、バンコマイシン、メトロニダゾール、チニダゾール、ロスバスタチン、シンバスタチン
  - 軽度：レボフロキサシン

主要な警告と正式な禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 乳癌、特にトリプルネガティブ乳癌では、Phase 3 の RCT を含む複数のランダム化試験があり、エビデンスレベルは L1 です。
- ただし、サブタイプごとに結果が分かれており（NRG-BR003 では上乗せ効果なし、HER2 陽性ではカルボプラチン省略可の報告）、日本では現在有効な市販承認がありません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の取得と確認（現時点で未取得、安全性評価の前提条件）
- 作用機序（MOA）データの補充
- サブタイプ別（トリプルネガティブ、BRCA 変異、HER2 陽性）の有効性と適用範囲の整理
- 骨髄抑制、腎機能、聴覚、末梢神経障害に関するモニタリング計画
- 日本での供給状況・承認状態の確認（承認整理済みのため）

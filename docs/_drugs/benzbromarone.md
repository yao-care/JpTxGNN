# ベンズブロマロン：痛風から腎性低尿酸血症へ

## 一言要約

ベンズブロマロンは尿酸排泄促進薬で、元々痛風の治療に使用されていました。
TxGNN モデルは**腎性低尿酸血症 (Hypouricemia, Renal)** に有効である可能性を予測していますが、作用機序の面ではむしろ病態を悪化させる方向であり、この予測は治療効果を示すものとは考えにくい状況です。
現在、関連する臨床試験はなく、**20 編の文献**は診断検査や症例報告が中心で、治療効果を支持するものではありません。

## この予測が妥当でない可能性が高い理由

現在、詳細な作用機序データはありません。ただし、ベンズブロマロンは URAT1 (SLC22A12) を阻害して腎臓での尿酸排泄を高める尿酸排泄促進薬として知られています。

遺伝性の腎性低尿酸血症は、URAT1 の機能喪失型変異により、尿酸が尿中に過剰に失われることで起こります。ベンズブロマロンの作用はこの病態をさらに悪化させる方向であり、治療薬としては機序的に不整合です。

TxGNN の高スコアは、薬物・標的・疾患の関連性を反映したもので、治療的な関連を示したものではない可能性が高いと考えられます。文献でも、ベンズブロマロンは治療ではなく、尿酸輸送欠損の型を判別する負荷試験（ピラジナミドとの併用試験）に使われています。

## 結論と次のステップ

**決定：Hold**

**理由：**
ベンズブロマロンは URAT1 を阻害して尿酸排泄を促進する薬であり、URAT1 機能喪失が原因の腎性低尿酸血症を悪化させる方向に働くため、機序的に治療効果は期待できません。臨床試験もなく、文献は診断試験や症例報告のみで、エビデンスはモデル予測のみ (L5) です。

**進める場合に必要なもの：**
- 詳細な薬物作用機序データ（MOA）の確認
- 添付文書の警告・禁忌情報の取得
- 予測が治療的関連ではなく、薬物・標的・疾患の関連に由来するのかの再検証
- 再評価する場合は、同じ標的の別の疾患（例：高尿酸血症関連）での適応可能性の検討

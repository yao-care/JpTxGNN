# リチウム（クエン酸リチウム）：躁病および躁うつ病の躁状態から マラン過成長症候群へ

## 一言要約

リチウムは、元々躁病および躁うつ病の躁状態の治療に使用されてきた薬です。
TxGNN モデルは**マラン過成長症候群 (Malan overgrowth syndrome)** に有効である可能性を予測していますが、
この予測を直接支持する**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、リチウムは躁病および躁うつ病の躁状態で有効性が確立された気分安定薬です。

マラン過成長症候群は NFIX 遺伝子に関連する成長障害です。リチウムは GSK-3 を阻害し、Wnt/β-カテニンシグナルを調節することが知られています。このため、成長に関わる経路に理論上は影響しうると考えられます。ただし、この関連は推測の域を出ず、根拠は TxGNN の予測のみです。

既存適応症（精神疾患）と予測適応症（遺伝性の成長障害）は疾患領域が大きく異なります。両者の類似性は評価が未実施です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、裏付けとなる臨床試験も文献もなく、機序上の関連も推測にとどまります。加えて、安全性の確認に必須の PMDA 添付文書情報が未取得で、安全性スクリーニングに進めません。

なお、同じ Evidence Pack の他の予測では、トリコチロマニア（抜毛症）で、リチウムが阻害するイノシトール経路に関わるイノシトールの第 2 相試験が 1 件見つかっています。ただしリチウム自体の試験ではなく、位置づけは「研究課題」にとどまります。

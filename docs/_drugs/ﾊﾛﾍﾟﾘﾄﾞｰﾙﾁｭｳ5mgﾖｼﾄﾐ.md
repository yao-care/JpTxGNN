# ハロペリドールチュウ5MG（ヨシトミ）：評価データ不足により分析保留

## 一言要約

本薬物（ﾊﾛﾍﾟﾘﾄﾞｰﾙﾁｭｳ5MGﾖｼﾄﾐ）は PMDA データベース照会において承認情報が 0 件、DrugBank ID も未解決のままです。
TxGNN モデルによる予測適応症が生成されなかったため、老藥新用候補としての評価を実施する基盤データが揃っていません。
現時点では評価を保留し、薬物識別情報の正規化とデータ補完が優先課題です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測適応症・既存適応症・安全性情報のいずれも取得できておらず、薬物再利用評価を行うための基盤データが存在しません。DrugBank への照会では 1 件の一致が確認されているにもかかわらず DrugBank ID が解決されていない点が、後続処理全体のボトルネックになっています。

**進める場合に必要なもの：**
- 薬物名の正規化：半角カタカナ「ﾊﾛﾍﾟﾘﾄﾞｰﾙﾁｭｳ5MGﾖｼﾄﾐ」をシステムが処理可能な INN（例：`Haloperidol`）へ変換
- DrugBank ID の解決：照会で 1 件一致済みのため、マッチング結果を確認して `DB00502` 等の ID を紐付け
- PMDA 承認情報の再照会：正規化後の INN または成分名で再検索し、適応症・剤形・承認番号を取得
- 作用機序（MOA）データの補完：DrugBank ID 解決後に API で取得
- 安全性情報の補完：PMDA 添付文書 PDF をダウンロードして警告・禁忌を抽出
- TxGNN 予測の再実行：上記データ補完後、モデルへ再投入して予測適応症を生成
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

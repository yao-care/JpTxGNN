# プロピルチオウラシル：甲状腺機能亢進症から甲状腺ホルモン受容体β変異による甲状腺ホルモン不応症へ

## 一言要約

プロピルチオウラシル (PTU) は抗甲状腺薬で、元々甲状腺機能亢進症の治療に使用されていました。
TxGNN モデルは**甲状腺ホルモン受容体β変異による甲状腺ホルモン不応症 (Resistance to Thyroid Hormone)** に有効である可能性を予測しています。しかし、この疾患に対する臨床試験と文献は **0 件**で、モデル予測のみです。機序面ではむしろ悪化のおそれがあり、現時点では保留が妥当です。

## この予測が妥当である理由

現在、詳細な作用機序データ (DrugBank) はありません。既知の情報によると、PTU は甲状腺ペルオキシダーゼを阻害してホルモン合成を抑え、末梢での T4 から T3 への変換も抑える薬です。甲状腺機能亢進症では、これによってホルモン量を下げます。

不応症は、ホルモン過剰ではなく受容体側の異常で起こります。ホルモンを下げても受容体の反応は改善しません。TSH が上昇して甲状腺腫が悪化する可能性が、むしろ懸念されます。実際、関連文献 (PMID: [3097618](https://pubmed.ncbi.nlm.nih.gov/3097618/)) には、不応症を甲状腺機能亢進症と誤診して PTU を投与された小児例があります。この報告では、投与後も TSH が抑制されにくく、甲状腺腫が増大した例が記されています。

したがって、高スコアの予測ですが、機序的な裏付けは弱く、治療候補というより「誤投与に注意すべき疾患」と見るべきです。

**新生児甲状腺中毒症**
- 関連試験は [NCT03066076](https://clinicaltrials.gov/study/NCT03066076) (Phase 3、状態不明、60 名) の 1 件です。バセドウ眼症で甲状腺全摘とチオナミド系抗甲状腺薬を比較した試験で、新生児や PTU 単独を対象にしていません。関連度は B です。
- 文献は妊娠中の甲状腺機能亢進症の管理に関するレビューが中心です。新生児への直接投与を検証した研究ではありません。
- 機序は整合的ですが、エビデンスは母体・成人のバセドウ病型に関するもので、新生児治療の直接的な裏付けではありません。
- 胎盤を通過した PTU による新生児肝炎の症例報告 (PMID: [2090674](https://pubmed.ncbi.nlm.nih.gov/2090674/)) があり、安全性の確認が必要です。

**高サイロキシン血症**
- 臨床試験はありません。文献は症例報告、動物実験、生化学研究が中心です。
- 高サイロキシン血症は検査所見であり、原因が多様です。結合蛋白異常や受容体不応の型では、ホルモンを下げる治療の適応が明確ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測疾患である甲状腺ホルモン不応症は、臨床試験と文献が 0 件でモデル予測のみ (L5) です。さらに、受容体の異常であるためホルモンを下げても改善しにくく、悪化の可能性もあります。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。これがないと安全性スクリーニングに進めません。
- 詳細な作用機序データ (MOA) の補充
- 不応症で抗甲状腺薬により甲状腺腫が悪化した症例の系統的な確認
- 投与経路の適合性評価
- 研究を続ける場合は、より根拠のある新生児甲状腺中毒症（順位 2）への絞り込みを検討

*本レポートは研究参考用であり、医療上の助言ではありません。老薬新用の候補は、臨床的な検証を経て初めて応用できます。*

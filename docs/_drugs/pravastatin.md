# プラバスタチン：脂質異常症から家族性高コレステロール血症（ホモ接合体型）へ

## 一言要約

プラバスタチンは HMG-CoA 還元酵素阻害薬（スタチン）で、元々高脂血症および家族性高コレステロール血症の治療に使われていました。
TxGNN モデルは**ホモ接合体家族性高コレステロール血症 (homozygous familial hypercholesterolemia)** に有効である可能性を予測しています。
この疾患そのものに対するプラバスタチンの直接的な試験はなく、関連する臨床試験 1 件（別薬の試験）と文献 13 編がありますが、エビデンスは間接的です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 高脂血症、家族性高コレステロール血症 |
| 予測新規適応症 | ホモ接合体家族性高コレステロール血症 (homozygous familial hypercholesterolemia) |
| TxGNN 予測スコア | 99.95% |
| エビデンスレベル | L3 |
| 日本市販状況 | 現在市販中の承認なし（失効・取消のみ） |
| 承認番号数 | 20 件（すべて取消済み） |
| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、プラバスタチンは HMG-CoA 還元酵素を競合的に阻害するスタチンとして知られています。肝臓でのコレステロール合成を抑え、肝 LDL 受容体の発現を高めて LDL コレステロールを下げます。

既存適応症の家族性高コレステロール血症と、予測された新規適応症のホモ接合体型は同じ疾患群に属します。一方で、ホモ接合体型では LDL 受容体の残存活性が必要なため、効果は限定的・間接的にとどまると考えられます。

この点は予測の弱点です。小児の家族性高コレステロール血症に対するスタチンの有効性は Cochrane レビューなどで示されていますが、多くはヘテロ接合体型を対象としています。

## 安全性に関する考慮事項

- **主要な警告・禁忌**：添付文書の警告・禁忌のデータは取得できていません。添付文書を参照してください。
- **知識グラフ上の禁忌関連疾患**（添付文書ではなくモデルの知識グラフ由来）：腎疾患、肝疾患、胆嚢疾患、ミオパチー、横紋筋融解症、血小板減少症、消化性潰瘍、痛風などが挙げられています。
- **薬物相互作用**（DDInter、全 100 件、うち中等度を抜粋）：
  - メトロニダゾール
  - クラリスロマイシン
  - エルクサドリン
  - ナルトレキソン
  - ペクチン
  - ロスバスタチン
  - シンバスタチン
  - チニダゾール

他のスタチンとの併用は重複作用に注意が必要です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 既存適応症（家族性高コレステロール血症）と同じ疾患群で、作用機序も整合します。
- ただし、ホモ接合体型に対するプラバスタチンの直接的な臨床エビデンスはなく、LDL 受容体の残存活性に依存するため、効果は限定的と見込まれます。
- 日本では現在有効な承認がありません。

**進める場合に必要なもの：**
- 添付文書（PMDA）から警告・禁忌情報を取得すること（現状は安全性審査の障害となっています）
- 作用機序データを補完すること
- ホモ接合体 FH に対するプラバスタチンの直接的な有効性データ（LDL 受容体の残存活性別の層別解析を含む）
- 日本での承認状況（失効の経緯）と再申請・導入の可否の確認
- 筋障害、肝機能、腎機能のモニタリング計画と、併用薬との相互作用の確認

なお、同じ予測リストに上がった HIV 感染症（HIV 関連脂質異常症で L2）、ヘテロ接合体型（常染色体優性）の家族性高コレステロール血症（L1）の方が、現状ではエビデンスが厚い候補です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

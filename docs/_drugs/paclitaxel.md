# パクリタキセル：乳癌・胃癌などの悪性腫瘍から女性乳癌へ

## 一言要約

パクリタキセルは微小管に作用する抗悪性腫瘍薬で、日本では乳癌・胃癌・非小細胞肺癌など多くの癌に使われています。
TxGNN モデルは**女性乳癌 (female breast carcinoma)** への有効性を高スコアで予測しており、Evidence Pack には **50 件の臨床試験**と **20 編の文献**が収載されています。
ただし乳癌は日本の既存適応にすでに含まれるため、この予測は新規適応の発見というより既存適応の裏付けに近いものです。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。パクリタキセルはタキサン系の細胞毒性抗悪性腫瘍薬です。日本の承認情報でも「微小管脱重合阻害薬」に分類されています。

微小管を安定化して有糸分裂紡錘体の動きを止め、G2/M 期停止とアポトーシスを起こすと考えられます。この作用は増殖の速い腫瘍細胞に共通して効くため、乳癌のような増殖性の高い腫瘍に機序的に適合します。ホルモン受容体のシグナルに依存しないため、ER 陰性やトリプルネガティブ乳癌にも使えます。

日本では乳癌がすでに承認適応に含まれており、TxGNN の予測は既存の臨床的位置づけと整合しています。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
乳癌に対する完了済みの Phase 3 試験が複数あり、日本でも乳癌がすでに承認適応に含まれるため、有効性の裏付けは十分です。一方、日本の添付文書に基づく警告・禁忌が未取得で、作用機序データも欠けているため、条件付きで進めます。

**進める場合に必要なもの：**
- PMDA 添付文書から警告・禁忌・相互作用を取得し、安全性スクリーニングを実施する
- DrugBank から作用機序（MOA）データを取得する
- 乳癌が日本で承認済みであることを踏まえ、新規性の位置づけ（サブタイプ別の拡大か、既存適応の裏付けか）を整理する
- nab-パクリタキセル試験と、日本承認の溶媒型注射液を区別してエビデンスを評価する
- 骨髄抑制・末梢神経障害・過敏反応のモニタリング計画を策定する

なお、他の予測候補のうち、傍髄膜胚型横紋筋肉腫と膣ブドウ状胚型横紋筋肉腫は、試験・文献がなくモデル予測のみ（L5）のため Hold です。

※本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経てから応用してください。

## Paclitaxel: Parameningeal embryonal rhabdomyosarcoma
{: .text-alpha }

## 一言要約

パクリタキセルは微小管の脱重合を阻害する抗悪性腫瘍薬で、日本では乳癌、胃癌、非小細胞肺癌、卵巣癌などの治療に使われてきました。
この予測を支持するものとして、データに **40 件超の臨床試験**と **20 編弱の文献**があり、完了した Phase 3 試験も含まれています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、パクリタキセルはタキサン系の微小管脱重合阻害薬です。微小管を安定化させて有糸分裂を停止させ、増殖の速い腫瘍細胞をアポトーシスに導きます。

作用が内分泌シグナルに依存しないため、ホルモン受容体陰性例、ホルモン抵抗性例、トリプルネガティブ乳癌でも基本となる化学療法薬として使われています。

予測リストの他の疾患（ER 陰性、ER 陽性、ホルモン抵抗性乳癌など）も、同じ機序で説明できます。一方、両側乳癌、乳頭癌、横紋筋肉腫は、症例報告か予測のみで裏付けが弱い状況です。

## 安全性に関する考慮事項

- **禁忌・慎重投与が示唆される疾患（知識グラフ上の情報、添付文書の記載ではありません）**：好中球減少、無顆粒球症、血小板減少、貧血、肝疾患、腎疾患、末梢神経障害、心筋梗塞、喘息、糖尿病、高ビリルビン血症（ギルバート症候群を含む）など
- **薬物相互作用**（併用の確認が必要）：
  - 中等度：アプレピタント、シメチジン、クラリスロマイシン、クロトリマゾール、デキサメタゾン、エリグルスタット、メトロニダゾール、ミコナゾール、ロラピタント、ロスバスタチン、シンバスタチン、チニダゾール、トログリタゾン
  - 軽度：アスコルビン酸、レボフロキサシン
  - 相互作用の総件数は 100 件で、上記は取得した一覧の一部です

添付文書の警告・禁忌の詳細については、PMDA の添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
女性乳癌はすでに日本で承認されている適応症であり、完了した Phase 3 試験が複数あるため、エビデンスは十分です。ただし、これらの多くはパクリタキセルを併用基盤とする試験です。また、日本での有効な承認は現在ありません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを行うこと
- 作用機序（MOA）データの補完（DrugBank などから）
- 有効な販売承認の有無の確認
- 骨髄抑制、末梢神経障害、過敏反応に対するモニタリング計画
- 相互作用が中等度の併用薬（CYP 関連薬など）の管理方針

**他の予測疾患の扱い（参考）：**
- ER 陰性乳癌、ER 陽性乳癌、ホルモン抵抗性乳癌：Proceed with Guardrails
- 両側乳癌、乳房遺伝子発現プロファイル別乳癌：Research Question
- Ehrlich 腫瘍（マウス）、乳頭癌：Hold（前臨床または症例報告のみ）
- 傍髄膜胎児型横紋筋肉腫、膣ぶどう状胎児型横紋筋肉腫：Hold（モデル予測のみ）
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ロルラチニブ：ALK陽性非小細胞肺癌から歯肉線維腫症へ

## 一言要約

ロルラチニブは第三世代の ALK/ROS1 チロシンキナーゼ阻害薬で、文献上は ALK 陽性の進行・転移性非小細胞肺癌の治療に使われています。
TxGNN モデルは**歯肉線維腫症 (Fibromatosis, gingival)** に有効である可能性を予測していますが、この疾患を対象とした**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ロルラチニブは脳移行性のある第三世代 ALK/ROS1 阻害薬で、ALK 陽性肺癌で有効性が示されています。

ただし、歯肉線維腫症に ALK/ROS1 シグナルが関与するという機序は確立されていません。既存適応症は ALK/ROS1 依存性の悪性腫瘍であり、歯肉線維腫症は良性の線維性増殖性疾患です。両者を結ぶ機序的な根拠は、現時点では TxGNN の予測スコアだけです。予測スコアが高くても、機序的に適用可能とは言えません。

## 結論と次のステップ

**決定：Hold**

**理由：**
歯肉線維腫症に対する臨床試験も文献もなく、ALK/ROS1 阻害との機序的な関連も確立されていません。エビデンスはモデル予測のみ（L5）です。また、日本の添付文書に基づく警告・禁忌が未取得（Blocking）のため、安全性スクリーニング（S1）に進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（Blocking）
- DrugBank からの作用機序（MOA）データ取得
- 歯肉線維腫症とキナーゼシグナル（ALK/ROS1 を含む）の関連を示す基礎研究や症例の探索
- 予測候補の優先順位の見直し（参考：他候補のうち「肺門部癌」は L4 で、ALK 再構成陽性の場合に限り妥当性があります。ただし根拠は症例報告 1 件のみです）

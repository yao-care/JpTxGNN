# ロルラチニブ：非小細胞肺癌から線維腫性歯肉増殖症（歯肉線維腫症）へ

## 一言要約

ロルラチニブは脳移行性のある ALK/ROS1 チロシンキナーゼ阻害薬で、元々は非小細胞肺癌（ALK 陽性）の治療に使用されていました。
TxGNN モデルは**遺伝性歯肉線維腫症 (fibromatosis, gingival)** に有効である可能性を予測していますが、この疾患に直接関連する臨床試験・文献はなく、予測はモデルのみに基づいています。
なお、予測順位の下位には肺関連腫瘍（肺門部癌、肺良性腫瘍など）があり、これらでは ALK 陽性肺癌に関する文献が間接的な裏付けとなっています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 非小細胞肺癌（ALK 陽性） |
| 予測新規適応症 | 遺伝性歯肉線維腫症 (fibromatosis, gingival) |
| TxGNN 予測スコア | 99.81% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は失効（市販中の承認なし） |
| 承認番号数 | 2 件（いずれも失効） |
| 推奨決定 | Hold |

注：日本の承認情報には適応症の記載がないため、既存適応症は薬物の既知の用途（ALK 陽性非小細胞肺癌）から記載しています。

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。既知の情報によると、ロルラチニブは第三世代の ALK/ROS1 チロシンキナーゼ阻害薬であり、ALK 陽性非小細胞肺癌では Phase 3 の CROWN 試験で、クリゾチニブに対する無増悪生存期間の改善と頭蓋内活性が示されています。

一方、遺伝性歯肉線維腫症で ALK/ROS1 が病因として関与するという根拠は確立されていません。したがって、この予測は計算モデル上の関連性にとどまり、機序的な裏付けは弱いと評価します。

## 臨床試験エビデンス

現在、関連する臨床試験の登録はありません。

## 文献エビデンス

現在、関連する文献はありません。

参考として、予測順位 4 位の「肺門部癌 (lung hilum carcinoma)」には、ALK 陽性肺癌に対するネオアジュバント療法で病理学的完全奏効が得られた症例報告が 1 件あります（[37934724](https://pubmed.ncbi.nlm.nih.gov/37934724/)、2023 年、The American Journal of Case Reports）。ただし単一症例であり、本疾患の予測を裏付けるものではありません。

## 安全性に関する考慮事項

- **薬物相互作用**：100 件の相互作用が検出されています。主なものは以下のとおりです。
  - **Major**：デキサメタゾン、クラリスロマイシン
  - **Moderate**：ヒドロコルチゾン、トリアムシノロン、ベタメタゾン、ブプロピオン、アプレピタント、モルヒネ、シメチジン、アロセトロン、ダパグリフロジン、エンパグリフロジン、サキサグリプチン、リナグリプチン、グリメピリド、クロルプロパミド、ドロナビノール、エリグルスタット、ナルデメジン、ナロキセゴル
- **文献で報告されている有害事象**：高脂血症・複合型脂質異常症、急性呼吸窮迫症候群、Sweet 症候群、神経芽腫患者での抗 GD2 抗体併用時の肺毒性など。

警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、遺伝性歯肉線維腫症に対する臨床試験・文献がなく、ALK/ROS1 阻害との機序的関連も確立されていません（L5）。
- 日本の承認は失効しており、添付文書の警告・禁忌も未確認です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の取得と安全性評価
- 詳細な作用機序（MOA）データの取得
- 歯肉線維腫症の病態（遺伝子変異など）と ALK/ROS1 経路の関連を検証する前臨床研究
- 投与経路（経口錠のみ）と対象疾患の適合性の検討
- 予測順位の高い他候補のうち、ALK 陽性肺癌に近い疾患（肺門部癌、肺溝腫瘍など）を優先的に再評価すること
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

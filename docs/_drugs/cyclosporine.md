## シクロスポリン：カルシニューリン阻害薬 → 慢性肉芽腫症、常染色体劣性 (granulomatous disease, chronic, autosomal recessive)
{: .text-alpha }

## 一言要約

シクロスポリンはカルシニューリン阻害作用を持つ免疫抑制薬です。
TxGNN モデルは**慢性肉芽腫症、常染色体劣性 (granulomatous disease, chronic, autosomal recessive)** に有効である可能性を予測しています。
ただし、この疾患を直接検討した臨床試験はなく、関連文献は幹細胞移植に関する **1 編**のみで、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、シクロスポリンはカルシニューリン阻害薬で、T 細胞の活性化を抑制します。

慢性肉芽腫症は食細胞の機能不全を本態とする疾患です。シクロスポリンがこの基礎的欠陥を治療する根拠は示されていません。関連が考えられるのは造血幹細胞移植の場面で、移植片対宿主病（GVHD）の予防に用いられる可能性があるという点に限られます。つまり、疾患そのものへの効果というより、移植を支える補助的な役割と考えられます。

今回の文献は、同胞または非血縁ドナーからの幹細胞移植で良好な生存が得られたという報告です。シクロスポリンの効果を直接検証したものではなく、この予測を直接支持するエビデンスとは言えません。そのため、エビデンスレベルは L5 と判定します。

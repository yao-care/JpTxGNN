# スボレキサント：不眠症から入眠・睡眠維持障害へ

## 一言要約

スボレキサントはデュアルオレキシン受容体拮抗薬で、元々不眠症の治療に使用されていました。
TxGNN モデルは**入眠・睡眠維持障害 (sleep disorder, initiating and maintaining sleep)** に有効である可能性を予測していますが、これは既存適応症とほぼ同じ領域であり、新規の再利用というより既知の使用を再確認した予測です。
現在、臨床試験の登録はありませんが、**19 編の文献**（ネットワークメタアナリシスやレビューを含む）がこの方向性を支持しています。

## この予測が妥当である理由

スボレキサントはオレキシン受容体（OX1R／OX2R）の拮抗薬です。オレキシンによる覚醒シグナルを抑えることで、入眠までの時間と中途覚醒を減らします。現在、詳細な作用機序データ（DrugBank 由来）は取得できていませんが、上記の機序は既知の情報に基づくものです。

予測された「入眠・睡眠維持障害」は、不眠症の中核的な症状である入眠困難と睡眠維持困難を指します。そのため、既存適応症との関連性は非常に高くなります。0.997 という高いスコアは、新しい適応症の発見ではなく、すでに知られた適応症の再現と解釈するのが適切です。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではありません）：ナルコレプシー、ナルコレプシー・カタプレキシー症候群、中枢神経系疾患、バロ同心円硬化症、X 連鎖副腎白質ジストロフィー。
- **薬物相互作用**（DDI データベースで 100 件を確認。主なもの）：
  - 重大（Major）：アプレピタント、モルヒネ、クラリスロマイシン
  - 中等度（Moderate）：デキサメタゾン、シメチジン、シンバスタチン、ミコナゾール、クロトリマゾール、メトクロプラミドなど
  - 軽微（Minor）：ナロキセゴール、プルカロプリド

  CYP3A 阻害薬との併用や、中枢神経抑制薬との併用には注意が必要です。

警告・禁忌の添付文書情報は今回のデータに含まれていないため、添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 複数のネットワークメタアナリシスと Phase 3 試験の報告が、不眠症に対するスボレキサントの有効性を支持しています。
- ただし、予測された適応症は既存適応症と実質的に同じで、真の再利用ではありません。また、日本の承認はすべて整理済みであり、安全性の根拠となる添付文書情報も未取得です。

**進める場合に必要なもの：**
- 日本での現在の販売・承認状況の確認（承認番号がすべて整理済みとなっている理由を含む）
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを実施
- DrugBank から作用機序データを補完
- 真に新規の適応症（例：精神疾患に合併する不眠症など）を検討する場合は、別途予測と評価を実施

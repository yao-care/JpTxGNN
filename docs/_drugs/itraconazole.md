# イトラコナゾール：真菌症から ニューモシスチス症 (Pneumocystosis) へ

## 一言要約

イトラコナゾールはエルゴステロール合成阻害作用を持つ抗真菌薬で、日本ではスポロトリコーシス、白癬、カンジダ症などの真菌症に使われています。
TxGNN モデルは**ニューモシスチス症 (Pneumocystosis)** に有効である可能性を高スコアで予測していますが、**関連する臨床試験は 0 件**で、文献 20 編にもこの適応を直接支持する知見は見当たりません。
作用機序の面でも整合性が低く、予測の信頼性は限定的です。

## この予測が妥当である理由

イトラコナゾールは真菌の CYP51（ラノステロール 14α-デメチラーゼ）を阻害し、細胞膜成分であるエルゴステロールの合成を妨げます。現在、詳細な作用機序データの登録はありませんが、日本の承認情報にも「エルゴステロール合成阻害薬」と明記されています。

一方、ニューモシスチス（*Pneumocystis jirovecii*）はエルゴステロールを持たないため、この機序は生物学的に当てはまりにくいと考えられます。基礎研究（PMID 12606318）でも、ニューモシスチスはアゾール系抗真菌薬に本来耐性であると報告されています。

高いスコアは、HIV 感染症や移植後などの免疫不全患者で他の日和見真菌症と併発しやすいという、疾患間の共起関係を反映している可能性があります。文献中の唯一の RCT（PMID 11737382）も、HIV 感染者の深在性真菌症の予防が対象で、ニューモシスチス症そのものを評価したものではありません。

## 臨床試験エビデンス

現在、関連する臨床試験の登録はありません。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

なお、相互作用データは未取得（登録 0 件）です。イトラコナゾールは強力な CYP3A4 阻害薬として知られているため、これは実際に相互作用がないという意味ではなく、データ不足と考えられます。

## 結論と次のステップ

**決定：Hold**

**理由：**
- TxGNN スコアは 99.34% と高い一方、臨床試験は 0 件で、文献にもニューモシスチス症に対するイトラコナゾールの有効性を示す知見がありません。
- ニューモシスチスはエルゴステロールを持たず、アゾール系薬に本来耐性という報告もあるため、作用機序の整合性が低いと判断します。

**進める場合に必要なもの：**
- 日本の添付文書（警告・禁忌）の確認（未完了で、次の安全性スクリーニングに進むための必須項目）
- 詳細な作用機序データ（DrugBank など）の取得
- CYP3A4 を介した相互作用データの整備
- ニューモシスチス症に対する in vitro・動物での有効性データの有無の確認
- 同じ予測リストのうち、クリプトコックス髄膜炎やペニシリウム症など臨床データのある適応症の優先的な検討

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて応用できます。*

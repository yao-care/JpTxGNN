# エスシタロプラム：抗うつ薬（SSRI）から気分変調症へ

## 一言要約

エスシタロプラムは選択的セロトニン再取り込み阻害薬（SSRI）で、元々は抗うつ薬として使用されていました。
TxGNN モデルの予測順位 1 位は希少疾患（Ohdo 症候群）でしたが、エビデンスの裏付けがありません。そのため本レポートでは、エビデンスのある **気分変調症 (Dysthymic Disorder)** を中心に評価します。気分変調症には **7 件の臨床試験**と **6 編の文献**があります。
なお、強迫症 (OCD) では **12 件の臨床試験**と **20 編の文献**があり、より強いエビデンスが確認されています。

## クイック概要

|------|------|
| 既存適応症 | 抗うつ薬、選択的セロトニン再取り込み阻害薬 |
| 予測新規適応症 | 気分変調症 (Dysthymic Disorder)（予測順位 2 位。1 位の Ohdo 症候群は臨床試験・文献ともになく、機序的関連も乏しいため Hold） |

| エビデンスレベル | L2 |

| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、エスシタロプラムは SSRI に分類され、セロトニントランスポーター (SERT) を選択的に阻害してシナプス間のセロトニンを増加させると考えられています。抗うつ薬としての有効性は確立しています。

気分変調症は慢性の軽症うつ状態（低強度の慢性うつ病）であり、既存の適応症であるうつ病と症状・病態が近い疾患です。SSRI は慢性うつ病性障害に対して使われる標準的な薬剤群であり、同じセロトニン系の機序で作用すると考えられます。

そのため、機序的に気分変調症へ適用できる可能性は高いといえます。実際にエスシタロプラム単独のプラセボ対照試験も行われています。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、予測モデルの知識グラフに基づく）：てんかん、双極性障害、大うつ病性障害、肝疾患、胆嚢疾患、血液凝固障害、心疾患、心血管疾患、悪性症候群、ADH 不適切分泌症候群、腎性抗利尿ホルモン不適切分泌症候群、セロトニン症候群
- **薬物相互作用**：100 件の相互作用が確認されています。主な重大 (Major) なものは次の通りです。
  - ブプロピオン
  - ロルカセリン
  - クラリスロマイシン
  - ジエチルプロピオン
  - ドラセトロン
  - パロノセトロン
  - フェンテルミン
  
  中等度 (Moderate) にはアスピリン、モルヒネ、シメチジン、オメプラゾールなどがあります。
- 強迫症で高用量を使う場合は、QT 延長リスクにも注意が必要です。

警告・禁忌の詳細については添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails（気分変調症）**

**理由：**
- 気分変調症に対して、エスシタロプラムのプラセボ対照 RCT と抗うつ薬のメタアナリシスがあり、機序的にも妥当です。ただし試験は小規模（36〜40 名）で、完了した Phase 3 RCT はないため、エビデンスレベルは L2 にとどまります。
- 予測順位 1 位の Ohdo 症候群などはエビデンスがなく、機序的関連も乏しいため **Hold** です。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の確認（現時点では未取得で、安全性スクリーニングの前提となります）
- 詳細な作用機序データ (MOA) の補充
- 100 件の薬物相互作用、特に Major 相互作用（ブプロピオン、クラリスロマイシンなど）のレビュー
- 日本の承認がすべて取消済みのため、現在の販売・承認状況の再確認
- より大規模な気分変調症の臨床試験データの確認

**参考：他の予測適応症**
- **強迫症 (OCD)**：エビデンスレベル L1、Proceed with Guardrails。再発予防 RCT や Phase 3/4 試験があり、予測の中で最も強いエビデンスです。高用量使用時の QT リスクと DDI に注意が必要です。
- **広場恐怖症**：エビデンスレベル L2、Proceed with Guardrails。エビデンスの多くはパニック障害・不安障害の集団によるものです。
- **その他**（Ohdo 症候群、小児良性発作性斜頸、各種パーソナリティ障害など）：エビデンスレベル L5、Hold。
## 免責事項

臨床応用の前に臨床的検証が必要です。

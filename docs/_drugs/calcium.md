# カルシウム：制酸・高リン血症から血栓性疾患へ

## 一言要約

カルシウムは日本で制酸薬・高リン血症治療薬（胃・十二指腸潰瘍など）として市販されています。
TxGNN モデルは**血栓性疾患 (Thrombotic Disease)** に有効である可能性を予測しています。
ただし、検索された 40 件の臨床試験と 20 編の文献に、カルシウム自体を介入とした試験は確認されていません。エビデンスは機序上の推測にとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、カルシウムは制酸薬・高リン血症治療薬として使われるミネラルです。

一方、イオン化カルシウムは凝固カスケードと血小板活性化に必要な補因子です。この点で血栓性疾患とは機序上の接点があり、予測の根拠はこの推測に限られます。

ただし、外部から補充したカルシウムが血栓症を治療する方向に働くとは考えにくく、中立か、むしろ血栓形成を促す方向に働くことも想定されます。予測される効果の向きは不明です。既存適応症（消化性潰瘍・高リン血症）との機序的な関連も確認できません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測の根拠は「カルシウムは凝固の補因子である」という機序上の推測のみです。カルシウム自体を用いた試験は確認されていません。外部から補充したカルシウムは中立か血栓促進的と考えられ、治療効果の向きが不明です。安全性データも欠落しており、次の段階（S1 安全性スクリーニング）に進めません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析（ブロッキング項目、DG001）
- 作用機序データ（MOA）の補充（DrugBank API の照会、DG002）
- カルシウム投与と血栓リスクの直接的な臨床エビデンスの検索（現在は低分子ヘパリンのカルシウム塩などの別薬剤が混在）
- 血栓性疾患患者へのカルシウム投与が有害でないことの安全性評価

なお、予測順位 2 位（ヘモグロビン異常症）と 5 位（β サラセミア）は、カルシウム代謝との関連が文献で示されています。検証は主にカルシウム拮抗薬（アムロジピン）の研究によるもので、カルシウム自体は未検証です。パック上の判定は「Research Question」で、別途検討する価値があります。

*本レポートは研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的な検証を経て初めて実用化できます。*

# カルシウム：低カルシウム血症・胃十二指腸潰瘍から血栓性疾患へ

## 一言要約

カルシウムは、日本では制酸薬・高リン血症治療薬、低カルシウム血症治療薬（カルシウム補充薬）、鉛中毒の解毒薬として使われてきました。
TxGNN モデルは**血栓性疾患 (thrombotic disease)** に有効である可能性を予測しています（予測スコア 98.3%）。
ただし、カルシウム自体を使った臨床試験や裏付けとなる文献は確認できず、エビデンスはモデル予測の段階にとどまります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 制酸薬、高リン血症治療薬（胃・十二指腸潰瘍） |
| 予測新規適応症 | 血栓性疾患 (thrombotic disease) |
| TxGNN 予測スコア | 98.25% |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、カルシウムは血液凝固の補因子であり、血小板活性化のシグナルにも関わります。一方で、日本での既存の用途は、胃酸の中和、リン吸着、カルシウム補充、金属のキレートです。

既存適応症と血栓性疾患の間に直接の治療上の関連はありません。血小板生物学に関する前臨床の報告はありますが、カルシウム投与による介入データはありません。補充によって血栓が予防されるとは考えにくく、むしろ中立か血栓を促す方向に働く可能性があります。したがって、機序面での裏付けは弱いと判断します。

安全性情報については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、カルシウムを用いた臨床試験も治療効果を示す文献もなく、エビデンスはモデル予測のみ（L5）です。
- 機序面でも、カルシウム補充は血栓に対して保護的とは考えにくく、日本では販売中の承認もありません。

**進める場合に必要なもの：**
- 詳細な作用機序データ（MOA）の補完
- 添付文書の警告・禁忌の確認（安全性スクリーニングの前提）
- 血栓性疾患におけるカルシウム投与の影響を評価する臨床・疫学データ
- 血栓リスクを悪化させない根拠の確認

**参考（他の予測候補）：**
- 女性乳癌（エビデンスレベル L4）：カルシウムとビタミン D の疫学研究や、乳癌治療中の骨保護に関する研究はありますが、間接的で結果は一定していません。
- β サラセミア関連症状（エビデンスレベル L4）：サラセミアでは副甲状腺機能低下症が起こりうるため、カルシウム補充が二次的な症状に役立つ可能性があります。ただし、直接の試験データはありません。
- この 2 件は、現段階では研究課題として扱うのが適切です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# アテノロール：本態性高血圧症・狭心症・期外収縮から後下壁心筋梗塞へ

## 一言要約

アテノロールは β1 選択的遮断薬で、元々本態性高血圧症、狭心症、期外収縮の治療に使用されていました。
TxGNN モデルは**後外側心筋梗塞 (Posterolateral Myocardial Infarction)** に有効である可能性を予測していますが、この疾患に対する臨床試験・文献は確認できていません。
なお、隣接する**後下壁心筋梗塞**には小規模な無作為化試験 1 件（1985 年）があり、全体として**モデル予測が中心のエビデンス**にとどまります。

| 既存適応症 | 本態性高血圧症、狭心症、期外収縮（抗不整脈薬・血圧降下薬・血管拡張薬・β1遮断薬） |
| 予測新規適応症 | 後外側心筋梗塞 (Posterolateral Myocardial Infarction) |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アテノロールは β1 選択的遮断薬で、心拍数と心筋収縮力を下げ、心筋酸素需要を減らします。この作用は、既存適応症である狭心症や期外収縮の治療と共通しています。

心筋梗塞は心筋の虚血と酸素需要・供給の不均衡が本態であり、酸素需要を下げる β1 遮断は機序的に適用可能と考えられます。ただし、後外側心筋梗塞そのものを対象とした試験や文献は提供されておらず、根拠は TxGNN の予測のみです。

同じ予測スコアで並ぶ関連疾患（後下壁心筋梗塞、中隔心筋梗塞）では、小規模な研究が少数あるだけで、決定的な根拠にはなりません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書ではなくモデルの知識グラフに基づく）：喘息（内因性・アレルギー性を含む）、房室ブロック、レイノー病、糖尿病（1 型・2 型、糖尿病性ケトアシドーシス）、痛風、乾癬、全身性エリテマトーデス、肝不全、膵炎、無尿、アナフィラキシーなど。
- **薬物相互作用**（100 件の報告のうち主なもの）：
  - 中等度：エピネフリン、ヒドロコルチゾン、ヒヨスチアミン、ブプロピオン、トリアムシノロン、モルヒネ、アセトヘキサミド、アトロピン、ベタメタゾン、ブデソニド、各種カルシウム製剤
  - 軽度：アセチルサリチル酸、水酸化アルミニウム、アタパルジャイト

警告・禁忌の正式な内容は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 後外側心筋梗塞に対する根拠は TxGNN の予測のみ（L5）で、臨床試験も文献もありません。
- 国内の承認はすべて取消扱いで、安全性の添付文書データも未取得です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現時点で安全性評価の妨げになっています）
- DrugBank からの作用機序データの補完
- 心筋梗塞の亜型を含めた β遮断薬の既存臨床エビデンス（梗塞後の二次予防試験やメタアナリシス）の体系的な調査
- 国内で供給可能な製剤の確認と、投与経路の適合性評価
- 梗塞後の使用に伴う安全性（房室ブロック、心不全、喘息など）の評価計画

なお、次点の後下壁心筋梗塞と中隔心筋梗塞（いずれも L3、Research Question）の方が、既存研究が少しあるため、研究課題としては優先度が高いと考えられます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

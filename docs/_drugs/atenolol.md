# アテノロール：本態性高血圧症・狭心症から後外側心筋梗塞へ

## 一言要約

アテノロールはβ1選択的遮断薬で、日本では本態性高血圧症、狭心症、期外収縮の治療に使われています。
TxGNN モデルは**後外側心筋梗塞 (posterolateral myocardial infarction)** に有効な可能性を予測しています。ただしこの適応症に対する臨床試験と文献は **0 件**で、根拠はモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) は登録されていません。既知の情報によると、アテノロールはβ1選択的遮断薬で、心拍数と心筋酸素需要を下げます。高血圧症や狭心症での有効性は確立しています。

心筋梗塞は心筋の酸素需給バランスの破綻が本態です。そのため心筋酸素需要を下げる作用は、機序的に後外側心筋梗塞にも適用できる可能性があります。

ただし今回の検索では、この病型に特化した試験も文献も見つかっていません。妥当性は薬理学的な推測にとどまります。

# デキサメタゾン：乾癬などの皮膚疾患から円形脱毛症へ

## 一言要約

デキサメタゾンは合成グルココルチコイドで、日本では皮膚の炎症性疾患（乾癬、天疱瘡群など）を含む多数の製剤が承認されています。
TxGNN モデルは**円形脱毛症 (Alopecia Areata)** に有効である可能性を予測しており（スコア 99.99%）、経口ミニパルス療法などを扱う **RCT 1 件、メタアナリシス 1 件、コホート研究数件**が方向性を支持しています。
一方、提供された臨床試験 15 件はいずれも円形脱毛症を対象としておらず、直接の裏付けにはなりません。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、デキサメタゾンはグルココルチコイド受容体作動薬に分類される抗炎症薬です。乾癬や天疱瘡群などの皮膚の炎症・自己免疫性疾患での使用が確立されており、機序的に円形脱毛症にも適用可能である可能性があります。

円形脱毛症は、毛包に対する T 細胞介在性の自己免疫攻撃で起こる非瘢痕性の脱毛です。グルココルチコイドはこの免疫反応を抑えるため、既存の皮膚自己免疫疾患への使用と機序的に連続しています。実際に、中等症〜重症の円形脱毛症に対する全身ステロイドの経口ミニパルス療法が、複数の研究で検討されています。

なお、日本で承認されているデキサメタゾン製剤には、経口錠と注射液のほか、点眼液、軟膏、クリーム、ローションがあります。文献で検討されているのは主に経口ミニパルスと静注パルスです。円形脱毛症への使用は、現時点では適応外使用の検討になります。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
デキサメタゾンの経口・静注パルス療法は、RCT、メタアナリシス、複数のコホート研究で円形脱毛症への使用が検討されており、機序的な妥当性もあります。ただし、提供された臨床試験には円形脱毛症を対象としたものがなく、安全性データも不足しています（PMDA 添付文書情報が未取得で、S1 安全性スクリーニングに進めない状態です）。したがって、以下の条件を満たすことを前提に進めます。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（ブロッキングなデータギャップ）
- 詳細な作用機序（MOA）データの取得（DrugBank API など）
- 日本での円形脱毛症に対する承認状況の確認（適応外使用の位置づけ）
- 円形脱毛症を対象とした臨床試験の追加調査（ClinicalTrials.gov、JPRN など）
- 反復パルス投与時の副作用（特に小児）と、中止後の再発に関するモニタリング計画

※ 予測順位 2〜10 位（alopecia mucinosa、telogen effluvium など）は、いずれもモデル予測のみ（L5）で実際の研究がなく、現時点では Hold です。

※ 本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は、臨床的な検証を経てから適用してください。

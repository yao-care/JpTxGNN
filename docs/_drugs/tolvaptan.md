# トルバプタン：抗利尿ホルモン不適合分泌症候群から多発性嚢胞腎（PKD3型）へ

## 一言要約

トルバプタンはバソプレシン V2 受容体拮抗薬で、日本では元々抗利尿ホルモン不適合分泌症候群（SIADH）に関連する適応で使用されていました。
TxGNN モデルは**多発性嚢胞腎 3 型（多発性嚢胞肝を伴う場合を含む）**に有効である可能性を予測しており、この方向性を支持する文献が **19 編**あります（うち 2 編は大規模 RCT：TEMPO 3:4 関連と後期 ADPKD 試験）。登録された臨床試験はありません。

| 予測新規適応症 | 多発性嚢胞腎 3 型（多発性嚢胞肝を伴う場合を含む） |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、既知の情報によると、トルバプタンは集合管細胞のバソプレシン V2 受容体を遮断し、細胞内 cAMP を低下させます。これにより嚢胞液の分泌と嚢胞の増大が抑えられると考えられています。

既存適応症（SIADH）は V2 受容体を介した水代謝の異常です。多発性嚢胞腎でも、同じ V2 受容体–cAMP 経路が嚢胞形成を促します。そのため機序的に適用可能です。

ただし注意点があります。第 3 相 RCT（TEMPO 3:4、REPRISE）の対象は主に PKD1/PKD2 型の ADPKD 全般です。今回予測された PKD3 型（GANAB 関連）に特化した試験ではありません。そのため、エビデンスは外挿であり、L2 と保守的に評価しています。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではありません）：肝不全、肝硬変、物質乱用・依存、活動性消化性潰瘍、脱髄疾患
- **薬物相互作用**（合計 100 件の相互作用が検出されました。主なもの）：
  - **重大（Major）**：クラリスロマイシン
  - **中等度（Moderate）**：アプレピタント、デキサメタゾン、エンパグリフロジン、ロペラミド、ミコナゾール、ナルトレキソン、リファキシミン、各種カリウム製剤（クエン酸カリウム、塩化カリウムなど）
- **肝障害リスク**：上記の ADPKD 試験で、トルバプタンにより肝酵素・ビリルビン上昇が増加したと報告されています。肝機能のモニタリングが重要です。

添付文書の警告・禁忌の詳細は今回のデータに含まれていないため、PMDA の添付文書で確認してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
ADPKD に対しては大規模な第 3 相 RCT があり、トルバプタンの有効性は確立しています。一方、今回予測された PKD3 型（GANAB 関連）に特化した試験はなく、日本の有効な承認も現在ありません。また、肝障害リスクが知られているため、条件付きで進めることを推奨します。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（現在は未取得で、安全性評価の前提となるブロッキング項目）
- 詳細な作用機序データ（DrugBank からの取得）
- PKD3 型（GANAB 関連）患者での有効性を示す、またはサブグループ解析可能なデータ
- 肝機能の定期モニタリング計画と、併用禁忌・注意薬（特にクラリスロマイシンなど CYP3A 阻害薬）の管理方針
- 日本での承認状況の再確認（現在は有効な承認なし）

# イルベサルタン：高血圧症から悪性腎血管性高血圧へ

## 一言要約

イルベサルタンはアンジオテンシンII受容体拮抗薬で、元々高血圧症の治療に使用されていました。
TxGNN モデルは**悪性腎血管性高血圧 (malignant renovascular hypertension)** に有効である可能性を予測していますが、この疾患を直接支持する臨床試験・文献はなく、**モデル予測のみ（エビデンスレベル L5）**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 高血圧症 |
| 予測新規適応症 | 悪性腎血管性高血圧 (malignant renovascular hypertension) |
| TxGNN 予測スコア | 99.31% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認は全て整理・取消済み（現在有効な承認なし） |
| 承認番号数 | 20 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、イルベサルタンはアンジオテンシンII受容体拮抗薬（ARB）に分類され、高血圧症での有効性が確立されています。

ARB は AT1 受容体を遮断し、アンジオテンシンII による血管収縮を抑えます。これは腎血管性高血圧の中心的な機序であり、機序的に悪性腎血管性高血圧にも適用できる可能性があります。ただし、この根拠は薬理学的な推論に基づくものです。

同じ上位予測には、悪性高血圧性腎疾患（スコア 99.31%）や肺高血圧症（スコア 99.25%）も含まれます。いずれも臨床試験・文献による裏付けはありません。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の関連）**：ラベルの記載ではなく、知識グラフ上の薬物-疾患禁忌関係です。主なものは血管性浮腫（ARB 誘発性を含む）、膵炎、全身性エリテマトーデス、糖尿病・糖尿病性ケトアシドーシス、無尿、肝性昏睡・肝性脳症、痛風、高カルシウム血症、腎動脈閉塞、横紋筋融解症、低血圧性疾患などです。
- **薬物相互作用**：100 件の相互作用が確認されています。主要（Major）なものはカリウム製剤（クエン酸カリウム、炭酸水素カリウム）で、高カリウム血症のリスクがあります。中等度（Moderate）には、副腎皮質ステロイド（ヒドロコルチゾン、デキサメタゾンなど）、SGLT2阻害薬（カナグリフロジン、ダパグリフロジン、エンパグリフロジン）、アスピリン、インスリン製剤、モルヒネ、ブプロピオン、アプレピタントなどがあります。

添付文書の警告・禁忌は今回取得できていないため、添付文書で確認してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測第1位の悪性腎血管性高血圧には臨床試験も文献もなく、モデル予測のみ（L5）です。日本の承認もすべて取消済みで、添付文書の安全性情報も未取得です。機序的には妥当ですが、現時点で先に進める根拠は不十分です。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と安全性スクリーニング
- 詳細な作用機序データ（MOA）の補充
- 悪性腎血管性高血圧・悪性高血圧性腎疾患に関する臨床・文献の調査（ARB の既存データを含む）
- 現在有効な承認がないことを踏まえた、日本での供給・承認状況の確認
- 腎動脈狭窄に伴う腎機能低下や高カリウム血症など、腎血管性病態に特有のリスク評価
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。

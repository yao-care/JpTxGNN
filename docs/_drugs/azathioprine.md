# アザチオプリン：臓器移植の拒絶反応・自己免疫疾患から コロボーマ性小眼球症-近位肢節異形成症候群 へ

## 一言要約

アザチオプリンは核酸合成を阻害する免疫抑制薬で、日本では臓器移植の拒絶反応、クローン病、潰瘍性大腸炎などの治療に使われています。
TxGNN モデルは予測1位として**コロボーマ性小眼球症-近位肢節異形成症候群 (colobomatous microphthalmia-rhizomelic dysplasia syndrome)** を挙げましたが、この予測を支える**臨床試験は 0 件、文献も 0 編**です。
予測スコアは高いものの、機序的な裏付けはなく、現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。アザチオプリンはプリン代謝拮抗型の免疫抑制薬（核酸合成阻害薬）に分類され、臓器移植や自己免疫疾患など、免疫が関わる病態での使用実績があります。

一方、予測された疾患は先天性の発生異常症候群で、免疫が病態の中心にある疾患ではありません。アザチオプリンのリンパ球抑制作用が、この疾患の標的に結びつく根拠は入力データにありません。TxGNN のスコアのみが根拠で、既存適応症との類似性も未評価です。

そのため、機序的に適用可能とは言えません。予測スコアが非常に高くても、生物学的な妥当性を示す材料が不足しています。

参考までに、予測順位の上位10件の中には、炎症性腸疾患（5位）と潰瘍性大腸炎（9位）があります。どちらもアザチオプリンの作用機序と整合し、文献や試験の裏付けもあります。ただし、クローン病と潰瘍性大腸炎（ステロイド依存性）は日本で既に承認された適応症です。そのため、新規の再利用候補ではなく、既存適応症の再確認にあたります。

**決定：Hold**

**理由：**
予測疾患を支持する試験や文献がなく、機序的な関連性も確認できません。エビデンスはモデル予測のみ (L5) で、優先して検討する根拠がありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現状、安全性審査に進めない阻害要因）
- 詳細な薬物作用機序データ（MOA）の補充
- 薬物相互作用の再確認（現在の登録は 0 件で、未確認の可能性が高い。アロプリノールなど既知の相互作用がある）

- 新規再利用候補を検討する場合は、既承認適応症と重ならない予測を優先して再抽出

# ドキソルビシン：悪性リンパ腫・乳癌などの悪性腫瘍から ユーイング肉腫へ

## 一言要約

ドキソルビシンはアントラサイクリン系の抗悪性腫瘍薬で、日本では悪性リンパ腫、肺癌、乳癌、骨肉腫、軟部腫瘍など幅広い悪性腫瘍に使われています。
TxGNN モデルは**ユーイング肉腫 (Ewing sarcoma)** に有効である可能性を予測しており、**48 件の臨床試験**と **20 編の文献**が関連しています。
ただし、日本の承認適応症テキストにはすでに「ユーイング肉腫ファミリー腫瘍」が含まれています。今回の予測は、未承認領域の発見ではなく、既存適応症をモデルが再現したものと読むのが妥当です。

## この予測が妥当である理由

ドキソルビシンはトポイソメラーゼ II 阻害薬であり、DNA に結合（インターカレート）して DNA 二本鎖切断を起こします。この作用で、増殖の速い腫瘍細胞に強い細胞傷害性を示します。
DrugBank の作用機序データは取得できていません。上記の機序は、日本の承認情報にある薬効分類と、エビデンスパックの機序的根拠の記載に基づきます。

ユーイング肉腫は化学療法への感受性が高い骨・軟部の小円形細胞肉腫です。標準治療は、ビンクリスチン、ドキソルビシン、シクロホスファミドの VDC と、イホスファミド、エトポシドの IE を交互に行う多剤併用療法です。
ドキソルビシンは、すでに骨肉腫や軟部腫瘍など他の肉腫で使われています。そのため、既存適応症と予測適応症は機序的にも臨床的にも近い関係にあります。

注意点として、多くの第 3 相試験は多剤併用レジメン全体を評価しています。ドキソルビシン単独の寄与を切り分けた試験は、提供された範囲にはありません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
ユーイング肉腫では、完了済みの Phase 3 ランダム化試験が複数あり（NCT02063022、NCT01231906、NCT00006734）、ドキソルビシンを含む多剤併用は標準治療の中核です。日本の承認適応症テキストにもすでに含まれています。
一方で、ドキソルビシン単独の寄与は分離されていません。また、日本の添付文書に基づく安全性確認が終わっていません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（現在ブロッキング項目。S1 の安全性スクリーニングに進むために必須）
- 日本の承認適応症の記載が、ユーイング肉腫に関して現行の添付文書と一致するかの照合
- DrugBank の作用機序データの補完
- 心毒性（累積用量管理）と骨髄抑制のモニタリング計画

**参考：** 同じ薬物の他の予測候補では、横纹筋肉腫が L2 で次点です（ただし、この報告書では主たる予測としては扱っていません）。それ以外の候補は、エビデンスが乏しく、保留が妥当です。

# エゼチミブ：脂質異常症から高リポタンパク血症へ

## 一言要約

エゼチミブは小腸でのコレステロール吸収を抑える薬で、元々は高コレステロール血症、家族性高コレステロール血症、ホモ接合体性シトステロール血症の治療に使用されていました。
TxGNN モデルは**高リポタンパク血症 (hyperlipoproteinemia)** に有効である可能性を予測していますが、これは既存適応症とほぼ同じ領域であり、真の新規適応というより承認内容に近い予測です。
この方向性については、**40 件の臨床試験**と **20 編の文献**が集まっています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 脂質異常症治療薬、コレステロール吸収阻害薬（高コレステロール血症、家族性高コレステロール血症、ホモ接合体性シトステロール血症） |
| 予測新規適応症 | 高リポタンパク血症 (hyperlipoproteinemia) |
| TxGNN 予測スコア | 99.63% |
| エビデンスレベル | L1 |
| 日本市販状況 | 現在有効な承認なし（取消済みのみ） |

| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、エゼチミブは NPC1L1 を介した小腸でのコレステロール吸収を阻害し、LDL コレステロールを下げる薬として知られています。

予測された高リポタンパク血症は、既存の適応症（高コレステロール血症など）と同じ脂質代謝異常の領域です。そのため、これは新しい疾患への展開というより、既存適応の延長または重複と考えるのが適切です。

家族性高コレステロール血症では、LDL 受容体の機能が低下しています。エゼチミブはスタチンに上乗せして LDL コレステロールをさらに下げられます。この機序は、高リポタンパク血症にも適用できると考えられます。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**：膵炎、肝疾患、胆嚢疾患、ミオパチー、筋疾患、骨格筋疾患、家族性周期性四肢麻痺、物質乱用／依存、横紋筋融解症、結節性筋膜炎（添付文書の記載ではなく、TxGNN の知識グラフに基づく情報）
- **薬物相互作用**：データ上 100 件が報告されています。中等度とされたものは、ケノデオキシコール酸、エルキサドリン、ロスバスタチン、シンバスタチンです。そのほかにも、重要度が不明な相互作用が多数あります。

添付文書の警告・禁忌の詳細は、現時点で確認できていません。添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 高リポタンパク血症は、エゼチミブの既存適応症（高コレステロール血症、家族性高コレステロール血症）と同じ領域です。Phase 3 試験を含む複数の完了試験があり、エビデンスは L1 に相当します。
- ただし、これは実質的に既存適応の範囲です。本来の新規適応症としての価値は限定的です。また、日本の承認はすべて取消済みで、添付文書の警告・禁忌と作用機序のデータも不足しています。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の確認（ブロッキング項目）
- DrugBank などからの詳細な作用機序データの補充
- 日本での販売・承認状況の再確認（現在有効な承認がない理由の確認）
- 併用薬（特にスタチン類）との相互作用、および肝疾患や筋疾患を持つ患者での安全性モニタリング計画

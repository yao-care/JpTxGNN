# エゼチミブ：脂質異常症から高リポタンパク血症へ

## 一言要約

エゼチミブは小腸のコレステロール吸収を抑える薬で、日本では高コレステロール血症、家族性高コレステロール血症、ホモ接合体性シトステロール血症の治療に使われています。
TxGNN モデルは**高リポタンパク血症 (hyperlipoproteinemia)** に有効である可能性を予測しています（予測スコア 99.63%）。現在 **50 件の臨床試験**と **19 編の文献**がこの方向性に紐づいています。
ただし、この予測は既存の適応症とほぼ同じ領域です。新規の再利用というより、既存効能の確認に近いものです。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データは取得できていません。Evidence Pack の機序解析によると、エゼチミブは小腸コレステロールトランスポーター NPC1L1 を阻害し、食事由来・胆汁由来のコレステロール吸収を減らして LDL-C を下げます。これは確立した脂質低下機序です。

既存適応症の高コレステロール血症と、予測された高リポタンパク血症は、どちらも血中リポタンパク質、特に LDL の異常な上昇を病態の中心とします。機序的に同じ標的で説明できるため、予測は妥当です。ここで言う「新規適応症」は、実質的には既存適応症の延長にあたります。

エゼチミブはスタチンや PCSK9 阻害薬と作用点が異なり、併用で LDL-C をさらに下げます。スタチンとの併用、ロスバスタチンやアトルバスタチンとの配合剤、ベムペド酸やオビセトラピブとの配合剤の臨床試験も多数あります。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 完了した Phase 3 試験が複数あり、日本でも高コレステロール血症などで承認済みのため、エビデンスは十分です（L1）。
- 一方で、予測された高リポタンパク血症は既存適応症とほぼ重なるため、新規適応症としての追加価値は限定的です。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性の確認を完了する（未取得のため現時点では安全性審査に進めません）。
- DrugBank から詳細な作用機序データを補完する。
- 「高リポタンパク血症」と既承認病名（高コレステロール血症など）の対応関係を整理し、効能追加が本当に必要かを判断する。
- 他の予測候補の扱いを決める。家族性高コレステロール血症（2位）と常染色体優性高コレステロール血症（6位）も既存効能に近く、L1 で同様に進められます。HIV 関連脂質異常症（5位）は L2 で、研究課題として追跡します。それ以外の 3・4・7〜10位は根拠が乏しく（L4〜L5）、Hold とします。

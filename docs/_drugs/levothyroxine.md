# レボチロキシン：甲状腺機能低下症から風土病性甲状腺腫へ

## 一言要約

レボチロキシンは合成甲状腺ホルモン製剤で、元々甲状腺機能低下症の補充療法に使用されていました。
TxGNN モデルは**風土病性甲状腺腫 (Endemic Goiter)** に有効である可能性を予測しており、この疾患について **20 編の文献**が関連する方向性を示しています（臨床試験の登録はありません）。
なお、エビデンスが最も充実しているのは予測第 3 位の**結節性甲状腺腫**（臨床試験 2 件、文献 20 編）で、こちらが実用面で最有力の候補です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、レボチロキシンは甲状腺ホルモン（T4）の補充薬であり、甲状腺機能低下症での有効性が確立しています。

甲状腺腫は、ヨウ素欠乏などで甲状腺ホルモンが不足し、下垂体からの TSH が増えて甲状腺組織の増殖が促されることで起こります。レボチロキシンは TSH 分泌を抑え、TSH 依存性の甲状腺の成長を抑えると考えられます。そのため、機序的には風土病性甲状腺腫にも適用可能と推定されます。

ただし、ヨウ素欠乏という根本原因はレボチロキシン単独では改善しません。文献でもヨウ素との併用が推奨されています。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**：高血圧、下垂体機能低下症、成長ホルモン欠乏症、低ゴナドトロピン性性腺機能低下症、骨粗しょう症（閉経後を含む）、糖尿病・糖尿病性ケトアシドーシス、冠動脈疾患、心筋梗塞など。これは添付文書の記載ではなく、知識グラフ上の関連情報です。
- **薬物相互作用**（合計 100 件のうち主なもの）：
  - 糖尿病治療薬（メトホルミン、ピオグリタゾン、アカルボース、アログリプチン、カナグリフロジン、ダパグリフロジン、エンパグリフロジン、ドゥラグルチド、アルビグルチド、クロルプロパミド）：中等度
  - プロトンポンプ阻害薬（オメプラゾール、ラベプラゾール、デクスランソプラゾール）：中等度
  - カルシウム製剤、酸化マグネシウム：中等度（吸収への影響）
  - エピネフリン、イソメテプテン、ジエチルプロピオン：中等度
  - シメチジン：軽度
- 過剰な TSH 抑制による心血管系への影響や骨密度低下に注意が必要です。

詳細な警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold（風土病性甲状腺腫）／ 結節性甲状腺腫は Proceed with Guardrails**

**理由：**
- 風土病性甲状腺腫は、臨床試験の登録がなく、文献もコホート研究が中心です（L3）。ヨウ素併用が前提で、レボチロキシン単独の有用性は限定的です。
- 結節性甲状腺腫および非中毒性甲状腺腫は、完了したランダム化試験やレビューがあり、エビデンスが比較的充実しています（L2）。ただし日本では全承認が取消済みで、効果も放射性ヨウ素より限定的とされています。
- 腎低形成・両側腎無形成・ポッター連鎖・カーニー複合の予測は、機序的な根拠がなくモデル予測のみ（L5）で、Hold です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得（現在は安全性スクリーニングの阻害要因）
- 詳細な作用機序データ（MOA）の補充
- 日本における現行の販売状況と製剤の再確認（今回のデータでは全承認が取消済み）
- ヨウ素併用レジメンの設計と、TSH 過抑制を避けるモニタリング計画（心血管・骨密度）
- 糖尿病、冠動脈疾患、骨粗しょう症など、知識グラフ上で禁忌関連とされる患者集団の除外基準の設定

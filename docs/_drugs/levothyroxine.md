## レボチロキシン：甲状腺機能低下症から腎低形成/無形成へ
{: .text-alpha }

## 一言要約

レボチロキシンは甲状腺ホルモン補充薬で、日本では甲状腺機能低下症の治療に使われています。
TxGNN モデルは**腎低形成/無形成 (renal hypodysplasia/aplasia)** に有効である可能性を予測していますが、
現在、この方向性を支持する**臨床試験は 0 件、文献は 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、レボチロキシンは甲状腺ホルモン（T4）の補充薬で、甲状腺機能低下症での有効性が確立しています。甲状腺ホルモンは正常な成長や臓器発達を支える役割を持ちます。

しかし、腎低形成/無形成は先天的な構造発達異常であり、レボチロキシンがこれを治療できるという確立した機序はありません。今回の関連付けは TxGNN モデル（深層学習）の予測のみに依拠しており、そのスコアはモデルが関連する疾患間で学習した類似性を反映している可能性があるにとどまり、生物学的な根拠ではありません。機序的な妥当性は現時点で裏付けられていません。

上位候補の他の疾患についても同様です。両側腎無形成は臓器そのものが欠損しており、ホルモン補充では構造を回復できません。ポッター系列は腎不全や腎無形成に伴う羊水過少が原因で、レボチロキシンは根本原因に作用しません。カーニー複合は内分泌腫瘍を伴い、甲状腺との緩やかな関連はあるものの、原因である PKA シグナル異常を標的とせず、有効性を示す根拠もありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測された 4 疾患のいずれにも臨床試験や文献がなく、エビデンスは L5（モデル予測のみ）です。また、腎の先天的構造異常に対してレボチロキシンが作用する機序は想定しにくい状況です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と整理
- 詳細な作用機序データ（MOA）の取得
- 腎低形成/無形成に対する前臨床研究や機序研究による裏付け
- 甲状腺ホルモンと腎発達の関連を示す文献調査
- 投与経路や対象集団の適合性評価

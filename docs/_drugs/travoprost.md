# トラボプロスト：緑内障から血管疾患へ

## 一言要約

トラボプロストはプロスタグランジン F 受容体作動薬で、元々緑内障の治療（眼圧下降）に使用されていました。
TxGNN モデルは**血管疾患 (Vascular Disease)** に有効である可能性を予測していますが、関連する臨床試験は緑内障患者を対象としたもので、血管疾患に対する治療効果を直接検証した研究はありません。エビデンスは **モデル予測と間接的な観察知見** にとどまります。

※ TxGNN スコアが最上位の「内臓カルシフィラキシー (visceral calciphylaxis)」は臨床試験・文献がなく (L5)、本レポートでは、臨床試験と文献が存在する「血管疾患」を中心に評価します。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、トラボプロストは FP 受容体作動薬（プロドラッグ）で、緑内障での眼圧下降効果が確認されています。

血管疾患との関連としては、眼組織での血管作用（結膜充血、脈絡膜血流や網膜血管径への影響の可能性）が観察されています。ただし、これらは緑内障患者における間接的な所見であり、血管疾患の治療効果を示すものではありません。

その他の予測疾患（動脈性・静脈性・神経原性胸郭出口症候群、胃血管異形成、ブルートー症候群、リンパ管拡張症、特発性冠動脈解離、血管内皮腫）についても、薬理学的・臨床的な裏付けは確認されておらず、グラフに基づく予測にとどまります。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、TxGNN 知識グラフに基づく）：ぶどう膜炎、虹彩疾患、毛様体疾患、汎ぶどう膜炎、虹彩炎、嚢胞様黄斑浮腫、黄斑網膜浮腫
- **薬物相互作用**：49 件が登録されています（カルシトリオール、パントプラゾール、モルヒネ、メトホルミン、プレドニゾンなど。いずれも重症度は未分類）。
- **関連する安全性の知見**：結膜充血（トラボプロストでは頻度が高い）、虹彩色素変化、血管奇形のある患者でのぶどう膜滲出の症例報告があります。

詳細な警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは非常に高いものの、血管疾患をはじめとする予測疾患に対して直接の臨床試験・文献はなく、エビデンスはモデル予測と間接的な眼内血管作用の観察（L4〜L5）にとどまります。また、点眼薬である点、日本の承認がすべて取消されている点、添付文書の警告・禁忌が未取得でありブロッキングのデータ欠落がある点から、現時点での推進は適切ではありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングの前提）
- DrugBank からの作用機序（MOA）データの取得
- FP 受容体作動と血管病態（血管緊張、リンパ管機能など）との機序的関連の前臨床検証
- 点眼剤形から対象疾患への投与経路の適合性評価（全身投与の必要性を含む）
- 対象疾患の絞り込み（具体的な疾患ごとの文献・試験の再調査）
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

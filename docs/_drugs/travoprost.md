# Travoprost：從降低眼壓到內臟鈣化皮炎

## 一言まとめ

Travoprost 原本用於降低隅角開放性青光眼和高眼壓患者的眼壓。
TxGNN 模型預測它可能對**內臟鈣化皮炎 (Visceral Calciphylaxis)** 有效，
目前僅有模型預測支持，缺乏臨床試驗和文獻證據。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 降低隅角開放性青光眼、慢性隅角閉鎖性青光眼患者的眼壓 |
| 予測新適応症 | 內臟鈣化皮炎 (Visceral Calciphylaxis) |
| TxGNN 予測スコア | 99.9998% |
| エビデンスレベル | L5 |
| 日本上市 | ✓ 已上市 |
| 承認数 | 11 張 |
| 推奨判断 | Hold |

## この予測が妥当な理由

目前缺乏詳細的作用機轉資料。根據已知資訊，Travoprost 是青光眼治療藥物的一部分，
其成分在降低眼壓中的療效已被證實，但機轉上適用於內臟鈣化皮炎的可能性尚不明確。

## 安全性に関する考慮事項

- **藥物交互作用**：與多種藥物如 Calcitriol、Pantoprazole、Sucralfate 等有未知等級的交互作用。

## 結論と次のステップ

**判断：Hold**

**理由：**
目前僅有模型預測支持，缺乏臨床試驗和文獻證據來支持 travoprost 用於內臟鈣化皮炎的有效性。

**推進に必要な事項：**
- 詳細的藥物作用機轉資料（MOA）
- 相關臨床試驗和文獻證據的支持
- 評估藥物交互作用對新適應症的影響

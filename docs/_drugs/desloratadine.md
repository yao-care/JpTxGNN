# デスロラタジン：アレルギー性鼻炎などから寒冷蕁麻疹へ

## 一言要約

デスロラタジンは選択的な末梢性 H1 受容体拮抗薬で、元々アレルギー性鼻炎や蕁麻疹などの治療に使用されていました。
TxGNN モデルは**寒冷蕁麻疹 (Cold Urticaria)** に有効である可能性を予測しており、
現在 **2 件の臨床試験**と **6 編の文献**がこの方向性に関連しています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、デスロラタジンは選択的な末梢性 H1 受容体のインバースアゴニストで、ヒスタミンによる膨疹と紅斑の形成を抑えます。

寒冷蕁麻疹では、寒冷刺激で肥満細胞が脱顆粒し、ヒスタミンが主なエフェクターとして働きます。これは既存の適応症である蕁麻疹やアレルギー性鼻炎と同じ経路です。そのため、機序的にも寒冷蕁麻疹に適用できると考えられます。

標準用量で効果が不十分な患者に対して、最大 20 mg までの増量が検討されています。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではありません）：高血圧、腎疾患、肝疾患、胆嚢疾患、糖尿病、糖尿病性ケトアシドーシス、前立腺肥大症、冠動脈疾患、動脈硬化症、閉塞隅角緑内障、甲状腺機能亢進症（バセドウ病）など
- **薬物相互作用**：100 件が登録されています（カルシトリオール、フェンテルミン、パントプラゾール、ドキシサイクリン、モルヒネ、メトホルミン、オメプラゾール、シメチジンなど）。いずれも重症度の分類は不明です。

警告・禁忌の詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 寒冷蕁麻疹に対して、完了した Phase 4 試験 2 件と RCT 文献 3 編があり、機序も既存の抗ヒスタミン作用と整合します。
- 一方、日本の承認は整理済みで、添付文書の警告・禁忌が未確認のため、条件付きで進めます。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と、安全性スクリーニングの実施
- 作用機序データ（MOA）の補充
- 増量（20 mg）使用時の安全性評価と、高血圧・腎肝疾患などの併存疾患に対するモニタリング計画
- 日本での販売再開または代替製剤の有無の確認

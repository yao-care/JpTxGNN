# セチリジン：アレルギー性鼻炎からアレルギー性蕁麻疹へ

## 一言要約

セチリジンは H1 受容体拮抗薬（抗アレルギー薬）で、日本ではアレルギー性鼻炎の治療に使われています。
TxGNN モデルは**アレルギー性蕁麻疹 (Allergic Urticaria)** に有効である可能性を予測しています（予測スコア 99.99%）。
この方向性を支持する根拠として **3 件の臨床試験**と **17 編の文献**があります。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) はありません。既知の情報によると、セチリジンは末梢 H1 受容体の逆作動薬で、アレルギー性鼻炎での有効性が確立されています。ヒスタミンによる血管拡張、血管透過性亢進、かゆみを抑えるため、機序的にアレルギー性蕁麻疹にも適用できる可能性があります。

蕁麻疹の膨疹（みみず腫れ）は、主にマスト細胞から放出されたヒスタミンが起こす反応です。アレルギー性鼻炎も同じヒスタミン依存の症状（くしゃみ、鼻汁、かゆみ）が中心です。そのため、H1 遮断という同じ作用点で両方の症状を抑えられると考えられます。

文献でも、H1 抗ヒスタミン薬は蕁麻疹治療の第一選択薬とされています（PMID: 33030434、7530629）。静注セチリジンは急性蕁麻疹の治療薬として 2019 年に米国で承認されたことも報告されています（PMID: 34862952）。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
アレルギー性蕁麻疹には完了した Phase 3 試験（実施可能性パイロット、n=36）が 1 件あり、H1 遮断という機序も明確で、文献上も抗ヒスタミン薬は蕁麻疹の標準治療です。一方で、安全性情報（添付文書）が未取得で、Phase 3 試験は日本で未承認の静注製剤を対象としているため、条件付きで進めるのが妥当です。

なお、Evidence Pack 上のエビデンスレベルは L1 でしたが、完了した Phase 3 RCT が 1 件のみのため、本レポートの判定基準では L2 としました。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（現時点でブロッキング課題）
- DrugBank から詳細な作用機序データ (MOA) を補完
- 日本の承認剤形（経口錠・シロップ）と、試験で用いられた静注製剤との投与経路の整合性確認
- 経口セチリジンによるアレルギー性蕁麻疹の RCT 追加調査（今回の試験は静注製剤かつ実施可能性検討が中心）
- 他の予測候補では、寒冷蕁麻疹が L3（症例報告・小規模クロスオーバー試験など）で、次点の検討対象です。急性咽喉頭炎などの L5 候補は現時点では Hold とします。

本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的検証を経て初めて適用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

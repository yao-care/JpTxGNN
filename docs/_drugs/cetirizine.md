# セチリジン：アレルギー性鼻炎からアレルギー性蕁麻疹へ

## 一言要約

セチリジンは H1 受容体拮抗薬（抗アレルギー薬）で、元々アレルギー性鼻炎の治療に使用されていました。
TxGNN モデルは**アレルギー性蕁麻疹 (Allergic Urticaria)** に有効である可能性を予測しており、
現在 **1 件の臨床試験**と **18 編の文献**がこの方向性を支持しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | アレルギー性鼻炎 |
| 予測新規適応症 | アレルギー性蕁麻疹 (Allergic Urticaria) |
| TxGNN 予測スコア | 99.99% |

| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、セチリジンは選択的な末梢 H1 受容体拮抗薬で、ヒドロキシジンのカルボキシル化代謝物です。ヒスタミンによる膨疹・紅斑・かゆみを抑えることで、アレルギー性鼻炎での有効性が確認されています。

アレルギー性鼻炎と蕁麻疹は、どちらもマスト細胞からのヒスタミン放出が中心的な病態です。そのため、H1 遮断という同じ作用が蕁麻疹にも当てはまると考えられます。実際、文献ではセチリジンが慢性特発性蕁麻疹にも有効な治療薬として扱われています。

なお、静注製剤のセチリジンは急性蕁麻疹の治療薬として海外で承認されたとの文献記載があります（2019 年）。

## 安全性に関する考慮事項

- **禁忌に関連しうる疾患（知識グラフ上の情報、添付文書の記載ではありません）**：高血圧、腎疾患（慢性腎臓病・腎不全を含む）、肝疾患、胆嚢疾患、糖尿病（糖尿病性ケトアシドーシスを含む）、前立腺肥大症、冠動脈疾患・動脈硬化、閉塞隅角緑内障、甲状腺機能亢進症（バセドウ病を含む）。
- **薬物相互作用**：100 件の相互作用が登録されており、中等度のものとして、ブプロピオン、ドロナビノール、ロペラミド、メトクロプラミド、モルヒネ、ナビロン、アヘン、シブトラミン、ジフェノキシン、ジフェノキシレートなどがあります。中枢神経抑制作用が重なる薬剤との併用には注意が必要です。
- **関連する副作用報告**：セチリジンによる胆汁うっ滞の症例報告（PMID 11034010）、抗ヒスタミン薬自体による過敏症反応の報告があります。

添付文書の警告・禁忌については、今回のデータでは確認できていません。必ず最新の添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 蕁麻疹に対しては H1 遮断という明確な作用機序があり、完了した Phase 3 の小規模パイロット試験と複数の文献が支持しています。ただしこの試験は実施可能性の評価が目的で、有効性の確証にはなりません。
- 日本の承認はすべて取消済みのため、日本で進めるには再承認や適応追加の手続きが前提となります。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と安全性スクリーニング（現状は未確認で、進行上の障害となるデータ不足）
- 詳細な作用機序データ（DrugBank 等から取得）
- 蕁麻疹に対する十分な規模の無作為化比較試験の根拠整理
- 取消済み承認の経緯（市場撤退の理由）と、現在の日本での製剤入手可能性の確認
- 腎機能・肝機能障害、緑内障、前立腺肥大症などを持つ患者の安全性モニタリング計画

# Hydroxyprogesterone Caproate：流産予防から子宮内膜癌へ

## 一言まとめ

Hydroxyprogesterone caproate（ヒドロキシプロゲステロンカプロン酸エステル） は、もともと習慣性流産の予防と機能性子宮出血の治療に用いられてきた薬剤です。
TxGNN モデルは、本剤が**子宮内膜癌 (endometrial cancer)** に有効である可能性を予測しており、
現在 **1 件の臨床試験**と **20 報を超える文献**がこの方向性を支持しています。

## この予測が妥当な理由

Hydroxyprogesterone caproate（17-OHP caproate）は持効性のプロゲステロン製剤で、
プロゲステロン受容体に結合することで、子宮内膜の増殖を抑制し、分化を誘導します。

**予測の妥当性の分析：**
- 子宮内膜癌の多くはホルモン依存性腫瘍であり、プロゲステロン治療は有効性が知られた戦略である
- 高分化型の子宮内膜癌は、プロゲステロン治療への反応が良好である
- プロゲステロンは子宮内膜癌細胞の分化とアポトーシスを誘導しうる
- この予測は、すでに豊富な臨床経験のある適応症を反映したものである

**作用機序の裏付け：**
- エストロゲンによる子宮内膜増殖の刺激を抑制する
- 子宮内膜癌細胞の分化を誘導する（PMID: 6836982 など複数の文献が支持）
- Tamoxifen との併用により効果が増強しうる（PMID: 2815695）

## 安全性に関する考慮事項

- **薬物相互作用**：DDI データベースでは重大な相互作用は見つかっていない
- **注意事項**：
  - 血栓塞栓症のリスクを高める可能性がある
  - 長期使用時は肝機能のモニタリングが必要
  - ホルモン療法の前に、腫瘍のホルモン受容体の状態を確認する必要がある
- **子宮内膜癌での適用条件**：
  - 高分化型（Grade 1）の腫瘍が対象
  - プロゲステロン受容体陽性の場合に反応が良好
  - 手術の代替（妊孕性温存）または補助療法として用いうる

安全性情報は添付文書をご参照ください。

## 結論と次のステップ

**判断：Proceed with Guardrails**

**理由：**
- 子宮内膜癌治療におけるプロゲステロンの使用を支持する臨床文献が豊富である
- Cochrane システマティックレビューでこの適応症がすでに評価されている
- 若年女性の妊孕性温存という場面で明確な役割がある
- ただし、この適応症は承認適応症には含まれない。

**推進に必要な事項：**
- 適応症の拡大申請を行うかどうかを評価する
- 既存のプロゲステロン製剤（MPA など）との効果比較を確認する
- 適切な患者選択基準（腫瘍の分化度、受容体の状態）を設定する
- 再発率および生存率のデータを長期にわたって追跡する

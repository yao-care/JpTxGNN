# リドカイン：表面麻酔・抗不整脈から点状表層角結膜炎へ

## 一言要約

リドカインはナトリウムチャネル遮断薬で、日本では表面麻酔薬・局所麻酔薬・抗不整脈薬として使われてきました。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測していますが、この疾患を直接支持する臨床試験・文献は **0 件**で、**モデル予測のみ (L5)** の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 表面麻酔薬、抗不整脈薬、ナトリウムチャネル遮断薬 |
| 予測新規適応症 | 点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis) |
| TxGNN 予測スコア | 99.99% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は整理済みのみ（現在有効な承認なし） |
| 承認番号数 | 20 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、リドカインは電位依存性ナトリウムチャネルを遮断する局所麻酔薬・抗不整脈薬です。眼表面の知覚神経の信号伝達を抑え、痛みを和らげる可能性があります。

ただし、この作用は疼痛の緩和に限られます。点状表層角結膜炎そのものを改善する機序は確認されておらず、既存適応症（麻酔・不整脈）との関連も間接的です。今回のシグナルは TxGNN の予測にとどまり、疾患修飾効果を示す根拠はありません。

また、点眼麻酔薬は一般に角膜の治癒を妨げるおそれがあります。角膜上皮障害のある疾患への長期使用には慎重な検討が必要です。

## 安全性に関する考慮事項

- **薬物相互作用**：相互作用データベースで 100 件が検出されています。主なものは次のとおりです。
  - 重大 (Major)：ブプロピオン
  - 中等度 (Moderate)：アプレピタント、シメチジン、モルヒネ（リポソーム製剤）、オベチコール酸、ポリエチレングリコール（電解質配合）、ピコスルファート、硫酸ナトリウム
- **知識グラフ上の禁忌関連疾患**：高血圧、肝不全、てんかん、腎疾患、肝硬変、副腎皮質機能不全、甲状腺機能低下症、開放隅角緑内障、精神疾患などが挙がっています。これは添付文書の記載ではなく、知識グラフ上の関連情報です。
- **眼科用途での注意**：眼表面への局所麻酔薬は角膜治癒を妨げる可能性があります。

添付文書の警告・禁忌は今回のデータに含まれていないため、添付文書で確認してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
点状表層角結膜炎については、臨床試験も文献もなく、根拠は TxGNN の予測だけです。リドカインの作用は疼痛緩和にとどまり、疾患修飾の機序は支持されていません。日本では現在有効な承認もありません。

**進める場合に必要なもの：**
- 点状表層角結膜炎に対する前臨床データまたは臨床研究
- 添付文書の警告・禁忌情報（PMDA）
- 詳細な作用機序データ（DrugBank）
- 眼科用剤形（点眼・ゲルなど）の入手可否と投与経路の適合性評価
- 角膜上皮への影響（治癒遅延）を含む眼局所の安全性評価

参考として、同じ眼表面領域の予測「結膜疾患 (conjunctival disorder)」では、翼状片手術での局所麻酔に関する Phase 4 試験や文献があります（L3）。ただしこれは手術時の麻酔としての根拠で、疾患治療の根拠ではありません。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# リドカイン：局所麻酔薬 から 点状上皮角結膜炎 へ

## 一言要約

リドカインは電圧依存性ナトリウムチャネルを可逆的に遮断する局所麻酔薬・抗不整脈薬として、局所麻酔や不整脈治療に幅広く使用されています。TxGNN モデルは**点状上皮角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性をスコア 99.99% で予測していますが、この適応症を直接支持する**臨床試験・文献はいずれも存在せず**、現時点ではモデル予測のみのエビデンス（L5）にとどまります。

## この予測が妥当である理由

現在、本レポートで参照できる詳細な作用機序データ（MOA）はありません。一般的な薬理学知識によると、リドカインは電圧依存性ナトリウムイオンチャネル（Nav1.x）を可逆的に阻害することで、神経軸索における活動電位の発生・伝導を抑制します。この膜安定化作用が局所麻酔および抗不整脈効果の共通基盤です。

点状上皮角結膜炎は角膜上皮の点状びらんを特徴とし、疼痛・羞明・異物感を主症状とする眼表面疾患です。リドカインのナトリウムチャネル遮断作用による角膜感覚神経の伝導抑制は、理論上これらの症状を短期的に緩和しうる可能性があります。

ただし、**重大な安全上の懸念**が機序的妥当性を大きく損なっています。局所麻酔薬の反復・長期的な角膜への使用は角膜上皮細胞の有糸分裂を抑制し、上皮修復を障害することが知られており、点状上皮角結膜炎の病態そのものを悪化させるリスクがあります。症状緩和の期待効益よりも理論的リスクの方が上回ると判断されます。

## 結論と次のステップ

**決定：Hold**

**理由：**
点状上皮角結膜炎に対するリドカインの有効性を支持する臨床試験・文献が皆無であり（エビデンスレベル L5）、かつ局所麻酔薬の長期角膜適用による上皮毒性という既知の安全上のリスクが存在するため、現時点での再利用開発推進は推奨されません。

**進める場合に必要なもの：**
- PMDA 承認データの再取得（データ欠損 DG001 の解消）
- 作用機序データ（MOA）の正式取得（DrugBank API 照会、データ欠損 DG002 の解消）
- 点状上皮角結膜炎モデルを用いた前臨床安全性試験（角膜上皮毒性評価を必須項目として含む）
- 局所麻酔薬の角膜毒性に関する既存エビデンスの系統的レビュー

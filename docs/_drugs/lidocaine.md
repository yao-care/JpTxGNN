# リドカイン：局所麻酔薬から点状表層角結膜炎へ

## 一言要約

リドカインはナトリウムチャネル遮断作用を持つ局所麻酔薬で、日本では注射剤、ゼリー、スプレー、テープなど多様な剤形が市販されています。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測していますが、この疾患を直接支持する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当性に欠ける理由（機序の検討）

現在、詳細な作用機序データはありません。既知の情報では、リドカインはナトリウムチャネル遮断薬として局所麻酔に使われ、眼表面の疼痛を和らげることができます。

一方、点状表層角結膜炎の本体は感染や炎症であり、リドカインはその原因に作用しません。さらに、局所麻酔薬は角膜上皮の治癒を妨げる可能性があります。そのため、モデルの高スコアに対して機序的な裏付けは明確ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
点状表層角結膜炎については臨床試験も文献もなく、根拠はモデルスコアのみです。リドカインは疼痛緩和にとどまり、角膜上皮の治癒を妨げる懸念もあるため、現時点で進める根拠はありません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と安全性スクリーニング
- DrugBank からの作用機序データの補完
- 点状表層角結膜炎に対する前臨床または臨床の直接的エビデンス
- 眼局所投与の剤形・投与経路の適合性評価

**参考：** 同じ予測リストの**アレルギー性結膜炎**は、感覚神経と杯細胞の連関を示す前臨床研究があり（L4）、「Research Question」として検討する余地があります。ただし臨床の有効性・安全性データはありません。

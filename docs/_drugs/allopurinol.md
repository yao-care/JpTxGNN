# アロプリノール：痛風から肝性ポルフィリン症へ

## 一言要約

アロプリノールはキサンチンオキシダーゼ阻害薬で、元々痛風の治療（尿酸生合成の抑制）に使用されていました。
TxGNN モデルは**肝性ポルフィリン症 (Hepatic Porphyria)** に有効である可能性を予測していますが、関連する臨床試験の登録はなく、裏付けとなる文献は仮説論文と動物実験のみの **2 編**です。
現時点では、モデル予測に前臨床レベルの間接的な情報が加わった段階にとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アロプリノールはキサンチンオキシダーゼを阻害して尿酸の生成を抑える薬で、痛風での有効性は確立されています。ただし、この機序が肝性ポルフィリン症に直接結びつくわけではありません。

一方、文献ではアロプリノールが肝臓のヘム代謝や 5-アミノレブリン酸合成酵素（5-ALAS）の調節に影響しうると報告されています。5-ALAS はヘム合成の律速酵素で、急性肝性ポルフィリン症の発作に深く関わります。このため、ヘム代謝を介した関連の可能性はあります。

ただし、根拠は仮説論文と前臨床の報告に限られます。痛風とポルフィリン症は病態も異なり、既存適応症との機序的な近さは限定的です。現段階では、検証すべき研究上の問いと位置づけるのが妥当です。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、TxGNN 知識グラフに基づく情報）：肝疾患、胆嚢疾患、腎機能障害、過敏性血管炎、皮膚白血球破砕性血管炎、アレルギー性皮膚血管炎、抗糸球体基底膜病
- **薬物相互作用**：計 100 件の相互作用が確認されています。主なものは次のとおりです。
  - 中等度：水酸化アルミニウム、アタパルジャイト、カオリン、マガルドラート、スクラルファート
  - 軽度：アモキシシリン、クロルプロパミド
  - 影響度不明：カルシトリオール、ビタミン A、パントプラゾール、グリメピリド、メトホルミン、オメプラゾールなど

肝疾患は禁忌関連として挙がっています。予測適応症が肝性疾患であるため、特に慎重な検討が必要です。詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験はなく、文献も仮説論文と動物実験にとどまります。また、肝疾患が知識グラフ上の禁忌関連疾患に含まれています。現時点で開発を進める根拠は不十分です。

**進める場合に必要なもの：**
- 詳細な作用機序データ（MOA）の取得と、ヘム代謝・5-ALAS 調節との関連の機序的検証
- アロプリノール自体がヘム代謝に与える影響を調べる前臨床試験（in vitro / 動物モデル）
- 添付文書の警告・禁忌情報の取得と、肝疾患に関する安全性評価
- 日本では販売中の承認がないため、国内での供給と承認の状況の確認
- 上位の他の予測適応症は根拠がモデル予測のみ（L5）で、機序の裏付けも乏しいため、優先度は低い
## 免責事項

# アロプリノール：痛風から肝性ポルフィリン症へ

## 一言要約

アロプリノールはキサンチンオキシダーゼ阻害薬で、元々は痛風の治療（尿酸生合成の抑制）に使用されていました。
TxGNN モデルは**肝性ポルフィリン症 (Hepatic Porphyria)** に有効である可能性を予測していますが、裏付けは**臨床試験 0 件**、**文献 2 編**（仮説論文 1 編、動物実験 1 編）にとどまり、エビデンスは前臨床レベルです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報では、アロプリノールは「痛風治療薬・尿酸生合成抑制薬・キサンチンオキシダーゼ阻害薬」に分類されています。

機序面の手がかりは間接的です。アロプリノールは肝臓のヘムおよびシトクロム P450 代謝回転に影響することが報告されています。仮説論文（2019 年）は、ヘム経路の調節が急性肝性ポルフィリン症の鍵酵素 ALAS1（5-アミノレブリン酸合成酵素）の制御に関わると論じています。ただし、アロプリノールとポルフィリン症の直接的な関連を示すデータはありません。

安全面にも懸念があります。アロプリノール自体がヘム代謝を乱す可能性があり、ポルフィリン症患者での安全性は確立していません。予測スコアは高いものの、現時点では仮説段階の候補です。

## 結論と次のステップ

**決定：Hold**

**理由：**
臨床試験がなく、文献も仮説論文と間接的な動物実験のみで、エビデンスは L4 にとどまります。また、アロプリノールがヘム代謝に影響し得るため、ポルフィリン症では安全性の懸念があります。なお、他の予測候補 9 件（特発性銅関連肝硬変、肝門脈硬化症など）は、いずれもモデル予測のみで L5、Hold です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現時点で安全性スクリーニングに進めない重大なデータ欠落）
- 詳細な作用機序データ（MOA）の補完（DrugBank API など）
- アロプリノールとヘム経路・ALAS1 の関係を直接検証する前臨床データ
- ポルフィリン症患者での安全性評価（ヘム代謝への悪影響の確認）

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて応用できます。*

# ジクロフェナクＮＡ坐剤 12.5mg：再利用評価データ不足のため Hold

ジクロフェナクＮＡ坐剤 12.5mg（ジクロフェナクナトリウム坐剤）の Evidence Pack が受信されましたが、PMDA 検索が 0 件となり DrugBank ID も未確定のまま、TxGNN モデルによる再利用予測が実行されていません。現時点では評価レポートを完成させることができず、**データ収集フェーズからのやり直し**が必要です。

## データ収集の問題点

Evidence Pack を精査すると、パイプラインの上流で三つの問題が連鎖していることが確認されました。

### 問題 1：PMDA 検索ヒット 0 件

クエリパラメータ `ジクロフェナクＮＡ坐剤１２．５ＭＧ`（全角英数字を含む）で PMDA を検索したところ、一致レコードが得られませんでした。ジクロフェナクナトリウムは日本国内で広く流通している NSAID 製剤であるため、これは薬品名エンコーディング（全角 vs 半角）の不一致によるマッチングエラーの可能性が高く、**実際に未承認であることを意味しない**と判断されます。

### 問題 2：DrugBank ID 未確定

クエリログでは DrugBank 検索が「成功（result_count: 1）」と記録されているにもかかわらず、`drugbank_id` フィールドは `null` のままです。DrugBank の返却結果が Evidence Pack に反映されておらず、MOA・安全性情報・ターゲット情報がすべて欠落しています。

### 問題 3：TxGNN 予測未実行

上記二問題の結果、DrugBank ID が確定せず TxGNN パイプラインへの入力ができなかったと推定されます。`predicted_indications` は空配列であり、再利用候補の評価自体が開始されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
PMDA 検索ヒット 0 件および DrugBank ID 未確定により、TxGNN 予測が実行されていません。本来であれば有効な再利用候補が存在する可能性がありますが、現状では評価の根拠となるデータがゼロです。

**再評価を進めるために必要な対処：**

1. **薬品名の正規化**：全角文字を半角に変換した `ジクロフェナクNA坐剤12.5mg` でPMDA 再検索
2. **有効成分名でのリトライ**：`ジクロフェナクナトリウム` または英名 `diclofenac sodium` を使用して PMDA・DrugBank を再クエリ
3. **DrugBank ID の手動確認**：DrugBank で `diclofenac` を検索し、該当 ID（例：DB00586）を `drugbank_id` フィールドに設定
4. **Evidence Pack の再生成**：上記修正後にパイプラインを再実行し、TxGNN 予測と証拠収集（臨床試験・文献）を完了させる
5. **DG001・DG002 の解消**：DrugBank から MOA を取得し、PMDA 仿単 PDF から警語・禁忌を抽出して安全性初評を実施

# アスピリンヨシダ：評価データ不足により老薬新用予測不可

---

## 一言要約

`ｱｽﾋﾟﾘﾝﾖｼﾀﾞ`（アスピリンヨシダ）は、PMDA 照会でヒット件数ゼロ、日本国内での承認記録が確認できない薬物です。
TxGNN モデルによる新規適応症予測は**結果なし**であり、DrugBank ID も未確定のため、老薬新用評価を実施するための基礎データが揃っていません。
現時点では評価を進める条件を満たしておらず、**データ補完が先決**です。

## この評価が進められない理由

アスピリンヨシダは、PMDA データベースへの照会結果が 0 件であり、日本国内における承認薬として識別できませんでした。DrugBank への照会では 1 件の結果が返されたものの、DrugBank ID への正式なマッピングには至っておらず、知識グラフへの接続ができていない状態です。

DrugBank ID が未確定であるため、TxGNN モデルによる薬物−疾病ネットワーク上のノード特定ができず、深層学習予測・知識グラフ予測ともに実行されていません。予測候補リスト（`predicted_indications`）が空であることはこの理由によるものです。

薬物名 `ｱｽﾋﾟﾘﾝﾖｼﾀﾞ`（半角カタカナ）は、`アスピリン`（Aspirin）に製造販売業者名またはブランド接尾辞「ヨシダ」が付いた形式と推察されます。アスピリン自体はよく知られた NSAID ですが、このブランド表記では国際データベースへの照会が正常に機能しない可能性があります。**INN（国際一般名）への正規化が必要**です。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID 未確定・PMDA 承認記録なし・TxGNN 予測結果ゼロという三重のデータ欠落があり、老薬新用評価の前提条件をいずれも満たしていません。評価継続にはまずデータ補完が必要です。

**進める場合に必要なもの：**

1. **INN 正規化**：`ｱｽﾋﾟﾘﾝﾖｼﾀﾞ` → `Aspirin`（INN）に変換し、DrugBank 照会を再実行する
2. **DrugBank ID 確定**：DrugBank API または手動検索で `DB00945`（Aspirin）との紐付けを確認する
3. **PMDA 再照会**：正規化された INN または一般名（アスピリン）で PMDA を再照会し、承認記録を確認する
4. **MOA データ取得**：DrugBank の Mechanism of Action フィールドから作用機序を補完する（DG002 対応）
5. **安全性データ取得**：PMDA 仿單 PDF または DrugBank の警告・禁忌セクションを解析する（DG001 対応）
6. **TxGNN 再予測**：DrugBank ID 確定後、KG 予測スクリプトを再実行して予測候補を生成する

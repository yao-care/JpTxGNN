# 過酸化ベンゾイル：毛包系皮膚疾患への再利用評価

## 一言要約

過酸化ベンゾイル（Benzoyl peroxide）は、日本で外用のゲル・ローションとして 3 件の承認番号を持つ薬です。
TxGNN モデルは 4 つの新規適応症候補を予測しましたが、上位 3 件は臨床試験も文献もなく、**モデル予測のみ (L5)** です。
唯一、**ケロイド性ざ瘡 (acne keloid)** に間接的な資料（臨床試験 1 件、文献 2 編）があります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、過酸化ベンゾイルには酸化ラジカルの放出による外用抗菌作用、角質溶解作用、面皰溶解作用があります。毛包単位の炎症や角化異常に関わる疾患では、機序的に適用できる可能性があります。

**ケロイド性ざ瘡（4 位）**は、C. acnes に対する抗菌作用と、毛包の炎症を抑える作用が、この疾患の背景にある毛包炎と関連するため、最も筋が通っています。ただし根拠は、尋常性ざ瘡や偽毛包炎に関する間接的な資料にとどまります。

**外陰部逆毛包性角化症（1 位）**は、毛包の角化に対する作用から推測できる程度です。臨床・文献の裏付けはありません。

**2 位と 3 位は妥当性が低いと考えます。**
- **2-ヒドロキシエチルメタクリレート感作**：過酸化ベンゾイルはアクリル系・メタクリレート系樹脂の重合開始剤として使われる酸化剤です。グラフ上の関連は治療効果ではなく、化学的関連または接触アレルギーのリスクを反映している可能性があります。治療機会ではなく、安全性上の注意点として扱うべきです。
- **慢性萎縮性肢端皮膚炎**：ボレリア感染の晩期病変で、全身性抗菌薬が必要です。外用の抗菌作用では機序的に届きません。

## 結論と次のステップ

**決定：Hold**

**理由：**
最上位を含む 3 候補は TxGNN の予測のみで、臨床・文献の裏付けがありません。うち 2 位は治療効果ではなく感作リスクを反映している可能性があります。ケロイド性ざ瘡は機序的に最も妥当ですが、根拠が間接的で、安全性の評価も未実施のため、S0 段階の研究課題にとどめます。

**進める場合に必要なもの：**
- 日本の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提となる不足項目）
- DrugBank からの作用機序データ（MOA）の補完
- ケロイド性ざ瘡および毛包炎関連疾患に対する、過酸化ベンゾイルを直接評価した臨床・文献の探索
- 外用製剤と対象疾患との剤形・投与経路の適合性の確認
- 2 位の候補について、接触アレルギー（感作）リスクとしての整理

本評価は研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証が必要です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

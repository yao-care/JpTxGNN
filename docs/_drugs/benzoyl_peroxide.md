## 過酸化ベンゾイル：ざ瘡・皮膚炎から外陰部逆転性毛包性角化症へ
{: .text-alpha }

## 一言要約

過酸化ベンゾイル（Benzoyl peroxide）は、元々ざ瘡（にきび）や各種皮膚炎などの皮膚疾患に外用で使用されてきた薬です。
TxGNN モデルは**外陰部逆転性毛包性角化症 (vulvar inverted follicular keratosis)** に有効である可能性を予測していますが、
この予測を直接支持する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | ざ瘡（尋常性ざ瘡）、アトピー性皮膚炎、接触皮膚炎、脂漏性皮膚炎など（知識グラフ上の適応症） |
| 予測新規適応症 | 外陰部逆転性毛包性角化症 (vulvar inverted follicular keratosis) |
| TxGNN 予測スコア | 99.92% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は全て整理済み（現在市販中の承認なし） |
| 承認番号数 | 3 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、過酸化ベンゾイルは角質溶解作用、抗菌作用、面皰溶解作用を持つ外用剤であり、毛包の角化に影響しうると考えられます。

ざ瘡は毛包の角化異常と炎症を伴う疾患で、外陰部逆転性毛包性角化症も毛包系の角化性病変です。この点で機序的な接点は想定できます。ただし、この関連は推測の域を出ず、TxGNN の予測のみに基づいています。臨床的・文献的な裏付けはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測は TxGNN モデルのみに基づき、臨床試験・文献が一切ありません（L5）。また、日本の承認はすべて整理済みで、現在市販中の製品がありません。

**進める場合に必要なもの：**
- 外陰部逆転性毛包性角化症に関する症例報告・文献の調査
- 詳細な作用機序データ（MOA）の取得
- 添付文書の警告・禁忌の確認（PMDA 資料の取得）
- 外陰部粘膜・皮膚への外用適用に対する安全性（刺激性・感作性）の評価
- 投与経路の適合性評価

---

**参考：他の予測候補（いずれも Hold 相当または研究課題段階）**

- **ざ瘡ケロイド (acne keloid)**（スコア 99.06%、L4）：支持する文献は黒人小児のざ瘡に関する一般的なレビュー 1 編（PMID: [39090034](https://pubmed.ncbi.nlm.nih.gov/39090034/)、2024 年）のみで、ざ瘡ケロイドに特異的ではありません。研究課題（Research Question）として扱うのが妥当です。
- **2-ヒドロキシエチルメタクリレート感作 (HEMA sensitization)**（スコア 99.43%、L5）：過酸化ベンゾイル自体が接触感作物質であり、治療効果よりも交差反応や悪化のリスクの可能性が高いと考えられます。
- **慢性萎縮性肢端皮膚炎 (acrodermatitis chronica atrophicans)**（スコア 99.17%、L5）：ボレリア感染症の晩期皮膚症状で、全身性抗菌薬が標準です。外用の過酸化ベンゾイルでは組織到達性が乏しく、機序的関連は弱いです。
## 免責事項

臨床応用の前に臨床的検証が必要です。

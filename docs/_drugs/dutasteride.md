# デュタステリド：前立腺肥大症からアンブラス型先天性全身性多毛症へ

## 一言要約

デュタステリドは 5α還元酵素阻害薬で、元々前立腺肥大症の治療に使用されていました。
TxGNN モデルは **アンブラス型先天性全身性多毛症 (Ambras type hypertrichosis universalis congenita)** に有効である可能性を予測していますが、この適応症に直接関連する臨床試験・文献はありません。
現時点のエビデンスはモデル予測のみ（**臨床試験 0 件、文献 0 編**）です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、デュタステリドは 5α還元酵素（1型・2型）を阻害してジヒドロテストステロン (DHT) を低下させる薬剤で、前立腺肥大症での有効性が確立されています。

DHT の抑制は理論上、アンドロゲン依存性の毛髪成長に影響し得ます。実際、男性型脱毛症では適応外で使用されることがあります。ただし、アンブラス症候群は染色体・調節領域の遺伝的変化による先天性の毛髪成長異常です。DHT 抑制との関連を示す臨床的・機序的な根拠はなく、今回のスコアはナレッジグラフに基づく予測にとどまります。機序的な妥当性は弱いと考えられます。

なお、上位 10 件の予測はいずれも直接的な臨床エビデンスを欠いています。次点の「多毛症」も、大部分が非アンドロゲン依存性であるため、根拠は限定的です。

## 安全性に関する考慮事項

- **禁忌（ナレッジグラフ由来、添付文書の記載ではありません）**：多系統萎縮症、体位性頻脈症候群、起立性低血圧、肝疾患、胆嚢疾患、持続勃起症、術中虹彩緊張低下症候群
- **妊娠に関する注意**：デュタステリドは胎児の発育への影響のため妊娠中は禁忌です。先天性疾患（ダンディ・ウォーカー症候群など）を対象とする場合は特に重大な懸念となります。
- **薬物相互作用**（合計 100 件、うち主要なもの）：
  - 中等度：アプレピタント、シメチジン、クラリスロマイシン、クロトリマゾール、ミコナゾール
  - 上記以外は重症度が不明です。

警告および禁忌の詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは非常に高いものの、裏付けとなる臨床試験や文献がなく、機序的な関連性も弱いため、現時点では評価を進める根拠が不足しています。
- 日本の承認はすべて取消されており、市販品の流通も確認できません。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と解析
- 詳細な作用機序データ（MOA）の補充
- DHT 抑制と多毛症・毛幹異常との関連を示す前臨床・機序研究
- より機序的に妥当な予測候補（毛髪関連の適応症など）の再評価
- 妊娠・胎児への影響を踏まえた対象集団の安全性評価

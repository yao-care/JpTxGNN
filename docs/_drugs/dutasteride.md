# デュタステリド：前立腺肥大症から Ambras型先天性汎発性多毛症へ

## 一言要約

デュタステリドは 5α還元酵素阻害薬で、元々は前立腺肥大症の治療に使用されていました。
TxGNN モデルは **Ambras型先天性汎発性多毛症 (Ambras type hypertrichosis universalis congenita)** に有効である可能性を予測していますが、現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、デュタステリドは 1 型および 2 型の 5α還元酵素を阻害し、ジヒドロテストステロン (DHT) を低下させる薬剤で、前立腺肥大症での有効性が確立されています。

一方、Ambras症候群は毛髪の成長制御に関わる先天性疾患で、アンドロゲンが原因とは考えられていません。DHT 抑制との機序的なつながりは推測の域を出ず、現時点の根拠は TxGNN の予測のみです。したがって、この予測の妥当性は低いと評価します。

## 結論と次のステップ

**決定：Hold**

**理由：**
臨床試験も文献もなく、根拠は TxGNN の予測スコアのみ（L5）です。Ambras症候群はアンドロゲン非依存の先天性疾患のため、機序面の裏付けも弱い状況です。加えて、日本の添付文書に基づく安全性情報が未確認で、安全性スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析
- DrugBank からの作用機序 (MOA) データの補完
- Ambras症候群の病態とアンドロゲン経路の関連を示す前臨床・機序研究の探索
- 関連する臨床試験や症例報告の再検索
- 経路適合性（投与経路）の評価

なお、同じ予測リストの中で「びまん性円形脱毛症」は、間接的な文献（アンドロゲン性脱毛症のレビュー）があり L4 でした。ただし円形脱毛症は自己免疫性疾患であり、機序の妥当性は限定的です。

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は、臨床的な検証を経てはじめて応用できます。*

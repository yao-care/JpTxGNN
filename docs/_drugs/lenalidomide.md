# レナリドミド：多発性骨髄腫・del(5q) 骨髄異形成症候群から骨髄性白血病へ

## 一言要約

レナリドミドは免疫調節薬（抗悪性腫瘍薬）で、日本では元々**多発性骨髄腫**と**5番染色体長腕部欠失を伴う骨髄異形成症候群 (MDS)** の治療に使用されています。
TxGNN モデルは**骨髄性白血病 (Myeloid Leukemia)** に有効である可能性を予測しており、関連する **50 件の臨床試験**と **20 編の文献**が登録されています。ただし関連度が高い試験の多くは第 I/II 相の併用試験で、この適応症を直接検証した第 III 相試験は確認できません。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank）はありません。添付文書上、レナリドミドは「抗悪性腫瘍薬・免疫調節薬・TNFα阻害薬」に分類されます。エビデンスパックの機序解析によると、セレブロン (cereblon) E3 リガーゼ調節薬として IKZF1/3 と CK1α を分解し、免疫調節作用も持ちます。

既存適応症の MDS (del(5q)) と骨髄性白血病はどちらも骨髄系造血幹細胞由来の腫瘍で、MDS は約 3 分の 1 の症例が急性骨髄性白血病 (AML) に進展します。このため、機序的には骨髄性白血病にも適用できる可能性があります。特にアザシチジンなどの低メチル化薬や化学療法との併用で、その可能性が検討されています。

ただし、支持するエビデンスの多くは第 I/II 相の併用試験で、第 III 相試験は確認できていません。予測スコアが高くても有効性は確定していません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 日本の添付文書に基づく警告・禁忌の確認（安全性スクリーニング）が未了で、先に進めない状態です。
- 骨髄性白血病に対する証拠は第 I/II 相の併用試験が中心で、この適応症を直接検証した完了済み第 III 相試験はありません。TxGNN の高スコア（99.49%）と合わせ、現時点では研究課題として位置づけるのが妥当です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・相互作用）の取得と解析
- DrugBank からの作用機序 (MOA) データの補完
- 関連度が未判定の試験（約 40 件）のレビュー
- 骨髄性白血病を直接対象とする第 II/III 相試験の結果確認（NCT04490707 など）
- 病型（AML／CMML／del(5q)）と併用薬ごとの有効性の整理

本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床検証を経て初めて臨床応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

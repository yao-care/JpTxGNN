# レナリドミド：多発性骨髄腫・5番染色体長腕部欠失を伴う骨髄異形成症候群から骨髄性白血病へ

## 一言要約

レナリドミドは免疫調節薬で、元々多発性骨髄腫と 5q 欠失を伴う骨髄異形成症候群 (MDS) の治療に使用されていました。
TxGNN モデルは**骨髄性白血病 (Myeloid Leukemia)** に有効である可能性を予測しており、現在 **45 件の臨床試験**と **18 編の文献**がこの方向性に関連しています。ただし、文献の多くは総説で、ランダム化比較試験による確証はまだありません。

## この予測が妥当である理由

レナリドミドはサリドマイド誘導体で、セレブロン (CRL4-CRBN E3 ユビキチンリガーゼ) に結合し、IKZF1/IKZF3 や CSNK1A1 の分解を促します。さらに NK 細胞・T 細胞の免疫調節作用と TNF-α 阻害作用を持ちます。なお、今回まとめたデータには詳細な作用機序の記載がないため、ここでの機序説明は予測の根拠としてまとめられた情報に基づきます。

既存適応症の 5q 欠失 MDS は、骨髄系の腫瘍性疾患で、急性骨髄性白血病 (AML) へ移行することがあります。骨髄性白血病は MDS と病態が近く、del(5q) 細胞では CSNK1A1 の片アレル欠失により、レナリドミドによる分解に特に感受性が高まります。この点は、5q 異常を伴う AML でも機序的に適用できる可能性を示します。

実際に、AML や高リスク MDS を対象に、アザシチジンや従来の化学療法との併用、寛解後の維持療法、移植後の維持療法など、多くの試験が行われています。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- AML・高リスク MDS を対象に、完了済みの Phase 2 試験が複数あり、機序的にも整合します。ただし、確証的な Phase 3 試験の結果はなく、各試験の規模も小さいです。
- 日本の承認は全件が取消済みで、添付文書の警告・禁忌データも欠けているため、安全性面のガードレールが必要です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と安全性スクリーニング
- 詳細な作用機序データ（MOA）の補完
- Phase 2 試験の有効性結果（寛解率、生存期間）の精査
- 骨髄抑制、血栓塞栓症、催奇形性（胎児毒性）に対するモニタリング計画
- 日本での承認取消の経緯の確認と、供給体制の確認

# オキシコドン：麻薬性鎮痛薬からメトヘモグロビン血症へ

## 一言要約

オキシコドンは、日本で麻薬性鎮痛薬（オピオイド受容体作動薬）として市販されている薬です。
TxGNN モデルは **メトヘモグロビン血症 (Methemoglobinemia)** に有効である可能性を予測しています。ただし、この予測を支持する臨床試験・文献は **0 件**で、モデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。オキシコドンはミュー・オピオイド受容体作動薬で、鎮痛を目的に使われています。

メトヘモグロビン血症は、ヘモグロビンの鉄が酸化されて酸素運搬能が落ちる疾患です。ミュー・オピオイド受容体の作動には、メトヘモグロビンを還元する作用や、その産生を抑える作用を示す根拠が見当たりません。この予測は TxGNN のスコアだけに基づいており、機序面の裏付けはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
メトヘモグロビン血症に対する臨床試験も文献もなく、機序的なつながりも見当たりません。TxGNN のスコアだけでは、開発や臨床応用に進む根拠として足りません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得する（現時点で安全性審査に進めない、ブロッキングのデータ欠損）
- DrugBank から作用機序（MOA）データを取得する
- メトヘモグロビン血症との機序的関連を裏付ける前臨床データを得る

**参考（同じ予測リスト内の他の候補）：**
むずむず脚症候群（スコア 90.35%、順位 2）には、完了済み Phase 3 RCT の [NCT01112644](https://clinicaltrials.gov/study/NCT01112644)（n=205）と、複数の総説・ガイドラインがあります。Evidence Pack はこれを L1 と判定していますが、L1 の条件（完了した Phase 3 RCT が 2 件以上）を満たすのは 1 件だけなので、ルール上は L2 相当と考えられます。Evidence Pack は Proceed with Guardrails を推奨しており、依存・悪化（augmentation）・呼吸抑制のリスクに対する厳格な安全管理が前提です。この候補は別レポートで評価することを推奨します。

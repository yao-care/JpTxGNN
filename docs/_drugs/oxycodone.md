# オキシコドン：麻薬性鎮痛薬から むずむず脚症候群へ

## 一言要約

オキシコドンは mu オピオイド受容体作動薬で、元々は強い痛みの治療や鎮咳に使用されていました。
TxGNN モデルは**むずむず脚症候群 (Restless Legs Syndrome)** に有効である可能性を予測しています（予測スコア順位では 2 位）。
この方向性を支持する資料として、**完了した Phase 3 試験 1 件**と **18 編の文献**があります。

> 予測順位 1 位は「メトヘモグロビン血症」でしたが、機序的な裏付けも臨床研究もなく、モデル予測のみのため評価を保留としました。本レポートでは、エビデンスが最も充実したむずむず脚症候群を主な評価対象とします。

※ L1 の判定基準は「完了した Phase 3 RCT が 2 件以上」ですが、今回確認できた完了 Phase 3 試験は 1 件です。データ上の評価は L1 ですが、厳密な基準では L2 相当となる点にご注意ください。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、オキシコドンは mu オピオイド受容体作動薬で、鎮痛・鎮咳目的の麻薬性鎮痛薬として使用されてきました。

mu オピオイド受容体の作動は、中枢のドパミン系や感覚伝達経路を調節すると考えられ、これらはむずむず脚症候群の病態に関与するとされています。実際に、ドパミン作動薬で効果不十分な難治例に対して、オピオイドが使用されています。ただし、オピオイドがむずむず脚症候群に効く詳しい仕組みは、文献でも推測の段階とされています。

欧州ではオキシコドン/ナロキソン徐放製剤が、ドパミン作動薬で効果不十分な重症の特発性むずむず脚症候群の二次治療として承認されています。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の関連）**：添付文書の記載ではなく、知識グラフ上の薬物・疾患の禁忌関係です。主なものは、呼吸不全、肝不全・肝疾患、腎疾患、てんかん、炎症性腸疾患、甲状腺機能低下症、物質乱用/依存、低血圧・高血圧性疾患、心筋梗塞、突然の心停止、心伝導障害、血液凝固異常などです。
- **薬物相互作用**：100 件の相互作用が確認されています。
  - 重大（Major）：アルビモパン、ブプロピオン、アプレピタント、モルヒネ、デキサメタゾン、シメチジン、クラリスロマイシン、クロトリマゾール
  - 中等度（Moderate）：ヒヨスチアミン、ロペラミド、アトロピン、グリコピロニウム、ジシクロミンなど
- **その他の注意点**：オキシコドンは依存性・乱用リスクが高いとする文献があります。むずむず脚症候群では、長期使用に伴う耐性や症状増悪にも注意が必要です。

詳細な警告・禁忌は添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 完了した Phase 3 のプラセボ対照二重盲検試験（205 例）があり、ガイドラインやレビューでもオキシコドン/ナロキソンが二次治療として位置づけられています。
- 一方で、作用機序データが不足し、日本では有効な承認がなく、乱用リスクや相互作用の負担が大きいため、安全対策を前提とした進行が妥当です。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の取得と確認（安全性スクリーニングの前提）
- 作用機序データの補充（DrugBank など）
- Phase 3 試験の結果詳細（有効性・安全性・長期使用）の確認
- 乱用・依存・augmentation への対策計画と、相互作用のモニタリング計画
- 日本での製剤・剤形の適合性評価（現在の承認は取消のみ）
- 対象は、ドパミン作動薬や α2δ リガンドで効果不十分な重症例に限定する方針の検討

**その他の予測適応症について：**
- メトヘモグロビン血症（1 位）、同 α 型、腎性抗利尿ホルモン不適合分泌症候群、特発性肉芽腫性筋炎、線維性筋炎：機序的根拠も研究もなく、いずれも **Hold**
- 筋筋膜性疼痛症候群、頭痛、腱炎：対症的な鎮痛にとどまり、疾患特異的な根拠が乏しいため **Hold**
- 感冒：文献は実験的疼痛モデルが中心で、疾患特異的な根拠がなく **Hold**
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# クロモグリク酸：アレルギー性疾患から潰瘍性直腸S状結腸炎へ

## 一言要約

クロモグリク酸は肥満細胞安定化薬で、元々は気管支喘息、アレルギー性鼻炎、アレルギー性結膜炎、肥満細胞症などの治療に使用されていました。
TxGNN モデルは**潰瘍性直腸S状結腸炎 (Ulcerative Proctosigmoiditis)** に有効である可能性を予測していますが、
現在、この予測を直接支持する臨床試験や文献は**ありません**（モデル予測のみ）。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 気管支喘息、アレルギー性鼻炎、アレルギー性結膜炎、肥満細胞症など（日本の承認適応症テキストはデータなし） |
| 予測新規適応症 | 潰瘍性直腸S状結腸炎 (Ulcerative Proctosigmoiditis) |
| TxGNN 予測スコア | 99.99% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認整理済みのみ（現在市販中の製品なし） |
| 承認番号数 | 12 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、クロモグリク酸は肥満細胞安定化薬であり、肥満細胞からのヒスタミンなどの化学伝達物質の放出を抑えることで、アレルギー性疾患での有効性が知られています。

潰瘍性大腸炎では、腸粘膜の炎症に肥満細胞の活性化が関与している可能性が指摘されており、機序的に適用可能である可能性があります。ただし、これは間接的な推測にとどまり、この適応症を直接支持する臨床データは今回提供されていません。

なお、予測上位10疾患のうち、アレルギー性蕁麻疹は既存のアレルギー適応症と機序が最も近く、研究課題として注目に値します（エビデンスレベル L4、臨床試験・文献なし）。一方、ノカルジア症やニューモシスチス症などの感染症は、機序的な裏付けがなく、ナレッジグラフ上のアーティファクトである可能性が高いと考えられます。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではありません）：肝不全、腎疾患、膿尿管症、肝疾患、胆嚢疾患、鼻腔ポリープ
- **薬物相互作用**：100件の相互作用が検出されました。重要度が分類されているものでは、吸入インスリン（速効型）が「中等度」です。そのほか、テオフィリン、フルコナゾール、エリスロマイシン、トラマドール、メトプロロールなど多数が「不明」と分類されています。

詳細な警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高い（99.99%）ものの、臨床試験も文献もなく、モデル予測のみに基づくエビデンスレベル L5 です。日本では現在市販中の製品もなく、添付文書の警告・禁忌データも未取得のため、現時点では先に進められません。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の取得と解析（安全性スクリーニングの前提条件）
- 詳細な薬物作用機序データ（DrugBank など）
- 潰瘍性大腸炎における肥満細胞安定化薬の前臨床・臨床文献の調査
- 投与経路の適合性の評価（現在の日本の製剤は点眼液のみで、腸管への投与には別の剤形が必要）
- 機序的に妥当性の高いアレルギー性蕁麻疹など、他の候補の優先的な検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ロピニロール徐放錠 8mg：予測データ未生成 — 評価保留

## 一言要約

ロピニロール（ropinirole）はドパミン受容体アゴニストとして知られる成分で、パーキンソン病などの治療に使用されています。
今回の Evidence Pack は製品記述形式「ロピニロール徐放錠８ＭＧ」で照会されましたが、PMDA データベースとのマッピングに失敗し、
DrugBank ID も未確定のまま TxGNN 予測モデルが実行されなかったため、**新規適応症の予測は生成されていません**。

## パイプラインエラーの原因分析

データが取得できなかった原因は二点あります。

**1. 検索クエリの形式不一致**
`ロピニロール徐放錠８ＭＧ` は規格・剤形・用量を含んだ製品記述であり、INN（国際一般名）ではありません。PMDA は通常、承認品名（例：レキップ®、レキップCR® など）または一般名での照合を行うため、この形式ではヒットしなかったと考えられます。検索クエリを **INN「ロピニロール」** に切り替えて再照会が必要です。

**2. DrugBank ID の未確定**
クエリログでは DrugBank 検索が 1 件ヒットしています（`result_count: 1`）が、`drugbank_id` フィールドが `null` のまま Evidence Pack に登録されています。DrugBank ID が確定しないと TxGNN KG 予測・DL 予測の両モデルが実行できず、予測適応症がゼロになります。

---

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID のマッピングが未完了であり、TxGNN による新規適応症予測が一件も生成されていないため、現時点では再利用評価を進める段階にありません。データ取得エラーの修正が最優先です。

**進める場合に必要なもの：**
1. **PMDA 再検索**：クエリを `ロピニロール`（INN）または承認品名に変更して再照会する
2. **DrugBank ID の確定**：DrugBank 検索でヒットした 1 件の ID を特定し、`drugbank_id` フィールドに登録する
3. **MOA データの取得**：確定した DrugBank ID を用いて API から作用機序情報を取得する（現在 DG002: High）
4. **TxGNN 再実行**：正しい DrugBank ID で KG 予測・DL 予測を再実行し、予測候補を生成する
5. **安全性データの取得**：PMDA または添付文書から警告・禁忌を取得し、DG001（Blocking）を解消する

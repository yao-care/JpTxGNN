# アスピリンホエイ：評価データ不足により判定保留

## 一言要約

アスピリンホエイ（ｱｽﾋﾟﾘﾝﾎｴｲ）は PMDA データベースに承認記録が存在しない薬物です。
TxGNN モデルによる予測適応症が生成されておらず、DrugBank ID も未同定のため、老薬新用評価を実施できません。
現時点では**データ収集フェーズの完了**が必要です。

---

| TxGNN 予測スコア | — |

| 日本市販状況 | 未上市（PMDA 承認 0 件） |
| 承認番号数 | 0 件 |
| 推奨決定 | **Hold** |

---

## この予測が妥当である理由

現在、TxGNN による予測適応症が存在しないため、機序的妥当性の評価は実施できません。

DrugBank クエリは 1 件のヒットを返していますが（`query_log` ID:2）、DrugBank ID への紐付けに失敗しており、MOA データも未取得です。PMDA クエリでは承認記録が 0 件でした。

薬物名 `ｱｽﾋﾟﾘﾝﾎｴｲ`（アスピリンホエイ）は半角カタカナで入力されており、PMDA での名称マッチングに失敗した可能性があります。正規化後の名称（例：`アスピリン`、`Aspirin`）での再クエリを推奨します。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN 予測適応症が存在せず、DrugBank ID・MOA・日本市販情報・安全性データのいずれも未取得であるため、老薬新用評価の実施に必要な最低限のデータが揃っていません。

**進める前に必要なもの：**

1. **薬物名の正規化**：半角カタカナ `ｱｽﾋﾟﾘﾝﾎｴｲ` を全角・ローマ字（`アスピリンホエイ`、`Aspirin Hoei`）に変換して PMDA・DrugBank を再クエリ
2. **DrugBank ID の確定**：INN または有効成分名で DrugBank を再検索し、`drugbank_id` を取得
3. **TxGNN 予測の再実行**：DrugBank ID 確定後、KG/DL 予測を実行して `predicted_indications` を生成
4. **MOA データの取得**：DrugBank API から作用機序を取得（Data Gap DG002 の解消）
5. **PMDA 仿単の取得**：警語・禁忌データの取得（Data Gap DG001 の解消）

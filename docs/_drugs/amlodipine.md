# アムロジピン：降圧薬から脳幹梗塞へ

## 一言要約

アムロジピンはカルシウムチャネル遮断薬で、日本では降圧薬・血管拡張薬として市販されています。
TxGNN モデルは**脳幹梗塞 (Brain Stem Infarction)** に有効である可能性を予測していますが、この疾患に対する**臨床試験・文献はどちらも 0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アムロジピンは L 型カルシウムチャネル遮断薬で、血管平滑筋を弛緩させて血圧を下げます。脳血管のれん縮を抑える可能性も理論上は考えられます。

脳幹梗塞は脳血管の虚血性疾患で、血圧管理や血管の状態が予後に関わります。そのため、降圧・血管拡張作用が関連する可能性はあります。ただし、この関連性は TxGNN の予測に基づくものです。この疾患を対象とした臨床・文献の裏付けは確認できていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
脳幹梗塞については臨床試験も文献もなく、根拠は TxGNN のスコアだけです（L5）。さらに、添付文書の警告・禁忌が未取得で、安全性スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（ブロッキング項目）
- DrugBank からの作用機序 (MOA) データの補充
- 脳幹梗塞を対象とした文献・臨床試験の追加検索
- 評価の優先度を、エビデンスのある脳出血・脳動脈閉塞の方向へ移すかの検討

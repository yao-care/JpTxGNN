# アマンタジン：パーキンソン症候群・A型インフルエンザからラスムッセン亜急性脳炎へ

## 一言要約

アマンタジンは、元々パーキンソン症候群とA型インフルエンザウイルス感染症の治療に使われてきた薬です。
TxGNN モデルは**ラスムッセン亜急性脳炎 (Rasmussen subacute encephalitis)** に有効である可能性を予測しています。
ただし、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報では、アマンタジンは抗ウイルス薬（M2タンパク阻害薬）かつパーキンソン病治療薬（ドパミン分泌促進薬）に分類されています。
この分類に加えて、NMDA 受容体拮抗作用が知られています。

ラスムッセン脳炎では、グルタミン酸受容体を介した興奮毒性が病態に関わると考えられています。
NMDA 受容体拮抗作用によって、この興奮毒性を理論上は抑えられる可能性があります。
ただし、これは推測の域を出ません。根拠は TxGNN の予測のみで、臨床試験も文献もなく、現時点で機序的な裏付けは確認できていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
ラスムッセン亜急性脳炎については、TxGNN のスコアは高いものの、臨床試験も文献もなく、エビデンスレベルは L5 です。
また、日本の添付文書に基づく警告・禁忌の情報が未取得で、安全性スクリーニングに進めません。

なお、同じ予測リストの他の候補には、関連文献があります。
- 脊髄炎 (myelitis)：L3。ポストポリオ症候群の疲労に対する RCT などがありますが、明確な有効性は示されていません。
- PLA2G6 関連神経変性症：L4。近縁疾患 PKAN での歩行障害の症例集積があるのみで、間接的な根拠にとどまります。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（安全性スクリーニングに必須）
- 詳細な薬物作用機序データ（DrugBank からの取得）
- ラスムッセン脳炎に対する NMDA 拮抗薬の前臨床・症例報告の文献調査
- 投与経路の適合性評価（現在は未評価）

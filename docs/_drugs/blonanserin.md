# ブロナンセリン：統合失調症から網膜ジストロフィーへ

## 一言要約

ブロナンセリンはドパミン D2/セロトニン 5-HT2A 受容体拮抗薬で、元々統合失調症の治療に使用されていました。
TxGNN モデルは**遺伝性網膜ジストロフィー（retinal dystrophy with or without extraocular anomalies）**に有効である可能性を予測していますが、現時点で裏付けとなる臨床試験や文献は **0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 統合失調症 |
| 予測新規適応症 | 眼外異常を伴う、または伴わない網膜ジストロフィー (retinal dystrophy with or without extraocular anomalies) |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データは今回まとめたデータにはありません。ただし薬理情報によると、ブロナンセリンはドパミン D2 受容体と 5-HT2A 受容体に作用する薬剤で、日本では統合失調症の治療薬として承認されています。

統合失調症と遺伝性網膜ジストロフィーの間に、確立した機序的なつながりは見当たりません。網膜変性の病態経路にドパミン・セロトニン受容体拮抗が関与するという根拠はなく、この関連は TxGNN の予測のみに基づいています。したがって、現段階で機序的な妥当性を支持することはできません。

参考として、予測上位の他の疾患（先天性グリコシル化異常症、シャルコー・マリー・トゥース病 1G 型、水無脳症、多小脳回、近視関連疾患、非典型グリシン脳症）についても、臨床試験・文献はなく、機序的な裏付けも乏しい状況です。近視関連疾患のみ、網膜ドパミンが眼球成長に関与するという弱い間接的な仮説がありますが、拮抗薬では逆に不利と考えられます。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測は TxGNN のモデル出力のみに基づき、臨床試験・文献が一切なく、機序的な裏付けもありません。また、日本で現在有効な承認がなく、添付文書の安全性情報も未確認です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と確認
- 詳細な作用機序（MOA）データの補充
- 網膜ジストロフィーとの機序的関連を示す前臨床研究や文献の調査
- 現時点で有効な承認がない点を踏まえた、開発・供給体制の確認

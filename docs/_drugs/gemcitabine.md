# ゲムシタビン：非小細胞肺癌・膵癌などから女性乳癌へ

## 一言要約

ゲムシタビンは代謝拮抗薬に分類される抗悪性腫瘍薬で、元々は非小細胞肺癌、膵癌、尿路上皮癌、乳癌、卵巣癌、悪性リンパ腫などの治療に使用されていました。
TxGNN モデルは**女性乳癌 (female breast carcinoma)** に有効である可能性を予測しており、今回のデータでは **39 件の臨床試験**と **20 編の文献**が関連づけられています。うち Phase 3 試験として、パクリタキセルとの併用試験などが完了しています。

|------|------|
| 既存適応症 | 非小細胞肺癌、膵癌、尿路上皮癌、乳癌、卵巣癌、悪性リンパ腫 |

| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ゲムシタビンはデオキシシチジン類似体の代謝拮抗薬で、活性代謝物がリボヌクレオチド還元酵素を阻害し、DNA に取り込まれて鎖の伸長を止め、アポトーシスを引き起こすと考えられます。

乳癌は、すでに既存適応症に含まれる疾患です。急速に増殖する腫瘍細胞の DNA 合成を妨げるという作用は乳癌にも当てはまり、機序的に適用可能です。

なお、今回の候補は日本の承認情報と整合する面があります。ただし日本の承認記録は、すべて失効の状態です。この点は後述の結論で扱います。

## 安全性に関する考慮事項

- **禁忌に関連する疾患（ナレッジグラフ上の関連）**：腎疾患、肝疾患、胆嚢疾患、血小板減少症、白血球減少症、貧血（大球性貧血を含む）、感染症、間質性肺疾患、溶血性尿毒症症候群、膿尿管症。これは添付文書の記載ではなく、知識グラフの関連に基づく情報です。
- **薬物相互作用**：相互作用は合計 100 件が確認されています。そのうち重症度が明確なのは、ナルトレキソン（中等度）とレボフロキサシン（軽度）です。ほかにも、プレドニゾン、メトホルミン、オメプラゾール、モルヒネ、アプレピタント、シンバスタチンなど多数の薬剤が挙がっていますが、重症度は不明です。

正式な警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 乳癌に対するゲムシタビン＋パクリタキセルの Phase 3 試験が完了しており、複数の Phase 2 試験や総説でも活性が報告されています。そのためエビデンスは L1 と評価できます。
- 一方で、日本の承認はすべて失効しており、添付文書の警告・禁忌データも取得できていません。そのため、無条件では進められません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌情報を取得し、安全性スクリーニングを実施する
- 作用機序データを DrugBank などで補完する
- 日本での現在の承認・供給状況を確認する（現行の有効な承認があるか）
- 完了した Phase 3 試験の結果を確認し、有効性・安全性の評価を行う
- 骨髄抑制や間質性肺疾患などの重大リスクに対するモニタリング計画を策定する

なお、次点以降の予測（直腸粘液性腺癌、結腸粘液性腺癌など）は、いずれも Hold または Research Question の段階で、臨床的な裏付けは限定的です。

# エンパグリフロジン：SGLT2 阻害薬から限局性スティッフリム症候群へ

## 一言要約

エンパグリフロジンは SGLT2 阻害薬で、日本では「ジャディアンス錠」として市販されています。
TxGNN モデルは**限局性スティッフリム症候群 (focal stiff limb syndrome)** に有効である可能性を予測しています（スコア 99.06%）。
ただし現時点で裏付けとなる臨床試験も文献もなく、根拠はモデル予測のみ（**エビデンスレベル L5**）です。

## この予測が妥当である理由

エンパグリフロジンは腎臓での糖再吸収を抑える SGLT2 阻害薬です。現在、詳細な作用機序データはありません。

限局性スティッフリム症候群は、スティッフパーソン症候群スペクトラムに含まれる疾患です。自己免疫（抗 GAD65 抗体など）と GABA 作動性神経の機能異常が関わるとされます。SGLT2 阻害とこの病態を直接結ぶ機序は見当たりません。現状の根拠は TxGNN の予測スコア（0.991）だけで、機序面の裏付けは弱い状態です。

同じスコアで予測された次点の候補にも、同様の限界があります。

- **古典的スティッフパーソン症候群**（スコア 99.06%）：GABA 系や自己免疫経路への既知の作用はありません。自己免疫性糖尿病の合併が多いという間接的な接点はありますが、提示された証拠では裏付けられていません。
- **オプシスモディスプラジア**（スコア 99.03%）：INPPL1 (SHIP2) の機能喪失による稀少骨系統疾患で、PI3K／インスリンシグナルに関わります。SGLT2 阻害との関連は推測の域を出ません。

## 結論と次のステップ

**決定：Hold**

**理由：**
根拠は TxGNN のスコアのみで、臨床試験も文献もありません。SGLT2 阻害とスティッフパーソン症候群スペクトラムの病態を結ぶ機序も確認できないため、評価を先に進められません。安全性情報も未取得です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングの前提）
- 作用機序データの補充（DrugBank など）

# プロプラノロール：高血圧・不整脈などから館山型遠位型ミオパチーへ

## 一言要約

プロプラノロールは非選択的β遮断薬で、日本では本態性高血圧症、狭心症、不整脈、乳児血管腫などの治療に使われています。
TxGNN モデルは**館山型遠位型ミオパチー (distal myopathy, Tateyama type)** に有効である可能性を第1位で予測しましたが、この疾患に関する**臨床試験は 0 件、文献も 0 編**で、予測のみが根拠です。

## この予測が妥当であるかどうか

現在、詳細な作用機序データはありません。プロプラノロールはβ遮断薬に分類され、心拍数と心筋収縮力を下げる作用により、高血圧、狭心症、頻脈性不整脈で有効性が確立されています。

一方、館山型遠位型ミオパチーは、四肢の遠位筋が障害される稀な遺伝性ミオパチーです。β アドレナリン受容体の遮断とこの疾患の病態を結ぶ機序は、現時点で確認できていません。そのため、この予測は TxGNN モデルの出力だけに支えられており、機序面でも臨床面でも裏付けがありません。スコアが高くても、それだけで有効性を示すものではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
第1位の予測（館山型遠位型ミオパチー）には、臨床試験・文献・機序上の根拠がいずれもなく、モデル予測だけでは検討を進められません。日本の添付文書（警告・禁忌）も未取得のため、安全性の確認もできていません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現状、安全性評価の妨げになっています）
- 作用機序（MOA）データの補充（DrugBank から取得）
- 館山型遠位型ミオパチーおよび遠位型ミオパチー全般について、文献・症例報告を再検索
- 研究課題として優先度が高いのは、エビデンスのある心筋症（L3）、肝硬変性心筋症（L3）、血管腫の各種サブタイプ（L3〜L4）です。血管腫は既に乳児血管腫で承認されているため、適応拡大の検討にあたります。

本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経てから応用する必要があります。

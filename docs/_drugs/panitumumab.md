# パニツムマブ：抗 EGFR 抗体から薬剤誘発性骨粗鬆症へ

## 一言要約

パニツムマブは抗 EGFR モノクローナル抗体で、日本ではベクティビックスとして市販されています。ただし、今回のデータには既存適応症の記載がありません。
TxGNN モデルは**薬剤誘発性骨粗鬆症 (Drug-induced Osteoporosis)** に有効である可能性を予測していますが、関連する臨床試験・文献は **0 件**で、根拠はモデル予測のみです（エビデンスレベル L5）。

## この予測が妥当である理由

詳細な作用機序（MOA）データは現在ありません。既知の情報では、パニツムマブは EGFR（上皮成長因子受容体）を阻害する抗体医薬です。EGFR シグナルは骨芽細胞・破骨細胞の調節や骨リモデリングに関わるため、骨代謝疾患との間に理論上の接点があります。

ただし、効果の方向性は不明です。EGFR を阻害すると、むしろ骨形成が低下するおそれがあります。また、パニツムマブによる低マグネシウム血症や低カルシウム血症が骨に悪影響を及ぼす可能性もあります。この関連付けは TxGNN の予測だけに基づいており、臨床データによる裏付けはありません。

なお、次点の予測は**重症非増殖糖尿病網膜症**（スコア 99.05%）です。EGFR は VEGF や炎症経路と相互作用し、網膜血管の透過性や新生血管に関与するため、理論上は EGFR 阻害が候補になります。しかしパニツムマブは全身投与の大型抗体で、眼・皮膚毒性が知られています。この適応症も臨床的な裏付けはなく、L5 で Hold です。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。薬物相互作用のデータも見つかっていません。

機序上の留意点として、本剤には皮膚・眼の毒性や低マグネシウム血症・低カルシウム血症が知られています。骨疾患を対象にする場合は、これらが特に問題になります。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験・文献がなく、エビデンスは L5（モデル予測のみ）です。EGFR 阻害が骨に有利に働くか不利に働くかも不明で、電解質異常による骨への悪影響も懸念されます。現時点では次の段階に進める根拠がありません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提となる必須項目）
- 詳細な作用機序データ（MOA）の補完
- EGFR 阻害と骨代謝の関係について、前臨床・機序研究の文献調査（作用の方向性の確認）
- 関連する臨床試験・観察研究の有無の再確認
- 投与経路の適合性評価（現状は未評価）

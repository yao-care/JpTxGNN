# ネキシウム懸濁用顆粒分包：データ不足により再利用評価保留

## 一言要約

ネキシウム懸濁用顆粒分包（エソメプラゾール系プロトンポンプ阻害薬）は、PMDA データベースとの照合で結果が得られなかった薬物です。
TxGNN モデルによる新規適応症の予測は現時点で存在せず、作用機序・安全性・市販情報のいずれもデータが取得できていないため、
再利用評価を前進させるには**データパイプラインの修正と再実行**が必要です。

## データ品質上の問題

本 Evidence Pack には複数の根本的なデータ欠損が確認されています。

### 薬物識別子の問題

`inn` フィールドに格納されている値 `ﾈｷｼｳﾑｹﾝﾀﾞｸﾖｳｶﾘｭｳﾌﾞﾝﾎ` を全角カタカナに変換すると **「ネキシウム懸濁用顆粒分包」** となります。これは**製品名と剤形の複合文字列**であり、国際一般名（INN）ではありません。

| 問題点 | 内容 |
|--------|------|
| 入力値 | ネキシウム懸濁用顆粒分包（製品名＋剤形） |
| 期待値 | エソメプラゾール（Esomeprazole）など |
| 影響 | PMDA 照合 0 件・DrugBank ID 未取得・TxGNN 予測なし |

### クエリログ

| # | ソース | 日付 | 結果件数 | 備考 |
|---|--------|------|----------|------|
| 1 | PMDA | 2026-03-26 | 0 件 | 製品名＋剤形での検索は不一致 |
| 2 | DrugBank | 2026-03-26 | 1 件 | ヒットしたが ID 未設定のまま |

DrugBank では 1 件ヒットしているにもかかわらず `drugbank_id` が `null` のままになっており、マッピングロジックに問題がある可能性があります。

## 結論と次のステップ

**決定：Hold**

**理由：**
`inn` フィールドに INN ではなく製品名＋剤形が混入したため、PMDA 照合・DrugBank マッピング・TxGNN 予測のすべてが正常に実行されていません。現状のデータでは再利用評価の根拠が存在しないため、まずデータパイプラインの修正が必要です。

**進める場合に必要なもの：**

- **INN の正確な特定**：「ネキシウム懸濁用顆粒分包」から有効成分名（例：エソメプラゾール / Esomeprazole）を分離し、INN フィールドに格納する
- **DrugBank ID の取得**：DrugBank に 1 件ヒットしているため、マッピングロジックを修正して `DB00736`（エソメプラゾール）等の正確な ID を設定する
- **データパイプラインの再実行**：正規の INN で PMDA・DrugBank・TxGNN の各ステージを再実行する
- **安全性情報の収集**：PMDA 仿単 PDF を取得・解析し、警告・禁忌・DDI を補完する（DG001・DG002 の解消）
- **市販状況の再確認**：エソメプラゾールは日本で広く使用されているため、「未上市」の判定はパイプラインエラーである可能性が高く、再照合が必要

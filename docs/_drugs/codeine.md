# コデイン：鎮痛・鎮咳から鼻腔疾患へ

## 一言要約

コデインは麻薬性鎮痛薬・鎮咳薬（オピオイド受容体作動薬）として使われてきた薬です。TxGNN モデルは**鼻腔疾患 (Nasal Cavity Disease)** に有効である可能性を予測しています。しかし、裏付けとなるのは**臨床試験 0 件**と**症例報告 2 編**だけです。この 2 編はいずれもオピオイド乱用による鼻腔の障害を報告したもので、治療効果を示す文献はありません。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。コデインはミュー・オピオイド受容体作動薬で、中枢での鎮痛作用と鎮咳作用が既知です。

鼻腔疾患に対する治療上の役割は確立されておらず、この予測を機序面から支持する根拠は見つかっていません。取得できた文献は、オピオイドの鼻腔内乱用による壊死や、コデインとアヘンの混合物を核とした鼻石の症例といった**有害事象の報告**です。予測スコアは非常に高いものの、実際には治療上の関連ではなく、薬物と鼻腔病変が一緒に語られやすいことを反映している可能性があります。

## 結論と次のステップ

**決定：Hold**

**理由：**
鼻腔疾患に対する臨床試験はなく、文献も有害事象の症例報告のみで、治療効果を支持する根拠がありません。機序面でも適用可能性は示されていません。

なお、同じ Evidence Pack の別候補である**気管支疾患**は、鎮咳作用に関する観察研究や比較研究があり、L3 の「Research Question」と評価されています。コデインの再利用を検討するなら、こちらの方が優先度は高いと考えられます。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（現在、安全性の審査に進めないブロッキング項目）
- DrugBank からの作用機序 (MOA) データの取得
- 鼻腔疾患でコデインの治療効果を検討した臨床研究の有無の再確認

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床での検証を経て初めて適用できます。*

## 一言要約

ジアゼパム（Diazepam）10mg 錠は一般的なベンゾジアゼピン系向精神薬として知られていますが、今回の Evidence Pack では PMDA クエリが 0 件を返しており、承認適応症・安全性情報・TxGNN 予測のいずれも取得できていません。このため、**老薬新用評価を実施できる状態にありません**。なお、クエリが製品名フォーマット「ジアゼパム錠１０ＭＧ」で実行されていることが 0 件の主因と考えられ、INN「ジアゼパム」での再クエリが先決です。

## データ品質上の問題

今回の Evidence Pack には構造的な問題が 2 点あります。

**クエリ名称の問題**：`inn` フィールドに「ジアゼパム錠１０ＭＧ」と記載されていますが、これは INN（一般名）ではなく、剤形・規格を含んだ製品名フォーマットです。PMDA の検索では INN である「ジアゼパム」でクエリを実行する必要があります。これが PMDA クエリ結果 0 件の主因と考えられます。

**DrugBank マッピングの問題**：クエリログでは DrugBank クエリが `result_count: 1` を返していますが、`drugbank_id` は `null` のままです。DrugBank ID（ジアゼパムは DB00829）が正しく収録されていないため、MOA・安全性情報・DDI データがすべて欠落しています。

---

## 結論と次のステップ

**決定：Hold**

**理由：**
承認適応症・MOA・安全性情報・TxGNN 予測のすべてが欠落しており、老薬新用評価の基礎データが揃っていません。クエリの修正と再実行が必要です。

**進める前に必要なもの：**
- PMDA クエリを INN「ジアゼパム」で再実行し、承認適応症・承認番号・市販情報を取得
- DrugBank ID（DB00829）を手動で設定し、API から MOA・安全性・DDI 情報を取得
- 正確な薬物情報を元に TxGNN 予測パイプラインを再実行
- 再取得後、安全性情報（警告・禁忌・DDI）を確認してから評価フローを再開

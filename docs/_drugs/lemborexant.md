# レンボレキサント：既存適応症の登録なし（文献上は成人の不眠症）から 入眠・睡眠維持障害へ

## 一言要約

レンボレキサントは、デエビゴ錠として日本で市販されている二重オレキシン受容体拮抗薬（DORA）です。日本の承認情報には適応症の文言が登録されていませんが、文献では成人の不眠症治療薬として承認済みと記載されています。TxGNN モデルは**入眠・睡眠維持障害 (sleep disorder, initiating and maintaining sleep)** に有効である可能性を予測しています。これを支持するのは **1 件の臨床試験**と **20 編の文献**で、文献には複数の Phase 3 RCT とネットワークメタアナリシスが含まれます。ただし、予測された疾患は既存の不眠症とほぼ同じ領域にあるため、新規性の高い再利用候補とは言えません。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データは取得できていません。ただし、評価用の機序説明と文献（PMID 32096020 など）から、レンボレキサントはオレキシン受容体 OX1R／OX2R（OX2R への親和性が高い）に対する可逆的な競合拮抗薬であることが分かります。

オレキシンは覚醒を促すシグナルです。これを抑えることで、入眠と睡眠の維持が促されると考えられます。慢性不眠症では覚醒系の過剰な働き（過覚醒）が病態に関わるとされており（PMID 37086045）、予測された疾患の表現型と機序が直接対応します。

この関連は Phase 3 RCT（SUNRISE 2 など）とネットワークメタアナリシスによって裏付けられています。予測疾患は既存適応症とほぼ同一領域なので、機序的な適用可能性は高いと考えられます。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 完了した Phase 3 RCT の報告が複数あり、ネットワークメタアナリシスも豊富で、エビデンスの強さは L1 です。
- 一方で、予測疾患は既存の不眠症とほぼ同一で、新規性は限定的です。安全性データ（警告・禁忌）は未取得で、相互作用の検索結果もゼロ件（未検出）のため、安全性の確認が必要です。

**進める場合に必要なもの：**
- PMDA 添付文書から警告・禁忌を取得し、安全性スクリーニングを完了する
- 相互作用（DDI）の再確認。CYP3A で代謝される薬剤でありながら検索結果が 0 件なのは不自然で、未検証の可能性が高い
- DrugBank から作用機序（MOA）データを取得する
- 承認適応症の文言を日本の承認情報に補完する
- 新規性のある方向として、OSA 合併不眠 (COMISA) や精神疾患合併不眠での有効性を進行中の試験（NCT06928766）などで確認する

*本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床的な検証を経て初めて応用できます。*

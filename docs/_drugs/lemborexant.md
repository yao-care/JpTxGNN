# レンボレキサント：不眠症から入眠・睡眠維持障害へ

## 一言要約

レンボレキサントは、元々不眠症の治療に使用されている二重オレキシン受容体拮抗薬です。
TxGNN モデルは**入眠・睡眠維持障害 (sleep disorder, initiating and maintaining sleep)** に有効である可能性を予測しています。
ただし、この予測は既存の不眠症適応とほぼ同じ内容で、実質的な新規適応症ではありません。関連する文献は **20 編**あり、臨床試験の登録データはありません。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 不眠症（承認適応症の本文は、今回のデータでは確認できません） |
| 予測新規適応症 | 入眠・睡眠維持障害 (sleep disorder, initiating and maintaining sleep) |
| TxGNN 予測スコア | 99.75% |
| エビデンスレベル | L1 |
| 日本市販状況 | 承認は取消のみ（現在有効な承認なし） |
| 承認番号数 | 3 件（すべて取消） |
| 推奨決定 | Proceed with Guardrails |

> **エビデンスレベルについて：** L1 は、本来「完了した Phase 3 RCT が 2 件以上」を条件とします。今回のデータには臨床試験の登録がなく、文献側に Phase 3 RCT が 2 本あります（SUNRISE-2 など）。さらに複数のネットワークメタアナリシスがあるため L1 としましたが、試験登録による裏付けは未確認です。

## この予測が妥当である理由

DrugBank の作用機序データは現在ありません。文献によると、レンボレキサントは OX1R/OX2R に可逆的かつ競合的に拮抗する二重オレキシン受容体拮抗薬です（OX2R への親和性がより高い）。覚醒を促すオレキシンのシグナルを抑えることで、入眠と睡眠維持の困難を改善すると考えられます。

予測された「入眠・睡眠維持障害」は、既存の不眠症とほぼ同じ病態です。そのため、これは真の意味での再利用ではなく、既存適応症の言い換えに近い予測です。機序的な妥当性は高いものの、新規性は低いと言えます。

## 安全性に関する考慮事項

- **禁忌（ナレッジグラフ上の関連疾患。添付文書の記載ではありません）：** ナルコレプシー、ナルコレプシー・カタプレキシー症候群、中枢神経系疾患、バロ同心円硬化症、X 連鎖副腎白質ジストロフィー
- **薬物相互作用：** 100 件が報告されています。主なものは次のとおりです。
  - **Major：** ラニチジン、シメチジン、クラリスロマイシン、クロトリマゾール、アプレピタント、モルヒネ（リポソーム製剤を含む）
  - **Moderate：** ピオグリタゾン、ブプロピオン、デキサメタゾン、サキサグリプチン、ドロナビノール、ナビロン、メトクロプラミドなど

  CYP3A を阻害する薬剤や、中枢神経抑制作用のある薬剤との併用には注意が必要です。

警告・禁忌の添付文書情報は、今回のデータにはありません。詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 不眠症に対する Phase 3 RCT と複数のメタアナリシスがあり、有効性のエビデンスは十分です。
- 一方で、予測は既存適応症とほぼ同じで、新規性は低い状態です。日本での承認状況と添付文書の安全性情報も未確認です。

**進める場合に必要なもの：**
- PMDA の添付文書を入手し、警告・禁忌を確認する（必須。現状では安全性スクリーニングに進めません）
- 日本での承認状況（取消表示の理由と、現在の販売状況）を確認する
- DrugBank から作用機序データを補う
- 真の新規適応症（例：睡眠関連疾患に合併する不眠症など）が対象か、評価の範囲を再定義する
- CYP3A 阻害薬などとの併用に関する相互作用管理の計画を作る
## 免責事項

臨床応用の前に臨床的検証が必要です。

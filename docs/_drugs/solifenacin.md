# ソリフェナシン：過活動膀胱から多発性嚢胞腎（PKD3）へ

## 一言要約

ソリフェナシンは選択的ムスカリン M3 受容体拮抗薬で、元々過活動膀胱の治療に使用されていました。
TxGNN モデルは**多発性嚢胞腎 3 型（多発性嚢胞肝を伴う場合を含む）**に有効である可能性を予測していますが、この予測を支持する臨床試験・文献は現在ありません。
予測スコア上位の疾患はいずれもモデル予測のみで、実際の研究に裏付けられているのは、10 位以内では「低コンプライアンス膀胱」だけです。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 過活動膀胱 |
| 予測新規適応症 | 多発性嚢胞腎 3 型（多発性嚢胞肝を伴う場合を含む） |
| TxGNN 予測スコア | 97.13% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認整理済みのみ（現在市販中の承認なし） |
| 承認番号数 | 20 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ソリフェナシンは選択的ムスカリン M3 受容体拮抗薬で、膀胱の排尿筋にある M3 受容体を遮断し、過活動膀胱の尿意切迫感・頻尿・切迫性尿失禁を改善します。

一方、多発性嚢胞腎 3 型（GANAB 関連）の病態と、ムスカリン受容体遮断との間に確立した機序的関連は見つかっていません。嚢胞の成長は cAMP シグナルと尿細管上皮細胞の増殖が関与するとされ、M3 拮抗作用の役割は示されていません。したがって、この予測は TxGNN モデルのみを根拠としており、機序面での裏付けは現時点で弱いと言えます。

なお、予測スコア上位 10 件のうち、機序的にもっとも妥当なのは第 7 位の**低コンプライアンス膀胱**（スコア 95.37%）です。M3 遮断による排尿筋の不随意収縮の抑制で、膀胱容量やコンプライアンスの改善が期待でき、神経因性排尿筋過活動のデータも間接的に支持します。ただし、低コンプライアンス膀胱そのものを対象にした直接的なエビデンスは限られています。

## 臨床試験エビデンス

現在、関連する臨床試験の登録はありません。

## 安全性に関する考慮事項

- **禁忌（疾患関連の情報）**：添付文書の記載ではなく知識グラフ上の情報ですが、以下の疾患との関連が示されています。
  - QT 延長症候群（先天性を含む）、torsades de pointes
  - 肝不全、肝疾患、胆嚢疾患
  - 閉塞隅角緑内障
  - 膀胱頸部閉塞
- **薬物相互作用**：100 件の相互作用が確認されています。主な重要度「Major」のものは以下です。
  - クラリスロマイシン
  - ドラセトロン
  - クエン酸カリウム
- 重要度「Moderate」には、他の抗コリン薬（アトロピン、ヒヨスチアミン、グリコピロニウム、ジサイクロミンなど）、ロペラミド、モルヒネ、アプレピタント、デキサメタゾン、H2 受容体拮抗薬（ファモチジン、シメチジン）などがあります。抗コリン作用の重複には特に注意が必要です。

添付文書の警告・禁忌の詳細は今回のデータに含まれていないため、添付文書をご確認ください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 多発性嚢胞腎 3 型への予測は TxGNN のスコア（97.13%）のみが根拠で、臨床試験・文献はなく、ムスカリン M3 拮抗作用との機序的関連も確認できません（L5）。
- 日本では現在、市販中の承認がありません。
- 上位 10 件の予測疾患はいずれも L5 で、同様に Hold です。ただし、第 7 位の低コンプライアンス膀胱（L3）は機序的に妥当で、研究課題（Research Question）として検討する価値があります。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現状、安全性スクリーニングに進めないブロッキング項目）
- DrugBank から詳細な作用機序（MOA）データの取得
- 低コンプライアンス膀胱を優先候補とする場合は、その病態を直接評価した研究のレビュー
- 多発性嚢胞腎を検討する場合は、前臨床の機序研究（M3 受容体と cAMP シグナルや嚢胞形成の関連）
- 承認整理済みの現状を踏まえた、供給・剤形（投与経路の適合性）の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

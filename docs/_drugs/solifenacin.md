  - QT 延長症候群（先天性を含む）、torsades de pointes
  - 肝不全、肝疾患、胆嚢疾患
  - 閉塞隅角緑内障
  - 膀胱頸部閉塞
- **薬物相互作用**：100 件の相互作用が確認されています。主な重要度「Major」のものは以下です。
  - クラリスロマイシン
  - ドラセトロン

- 重要度「Moderate」には、他の抗コリン薬（アトロピン、ヒヨスチアミン、グリコピロニウム、ジサイクロミンなど）、ロペラミド、モルヒネ、アプレピタント、デキサメタゾン、H2 受容体拮抗薬（ファモチジン、シメチジン）などがあります。抗コリン作用の重複には特に注意が必要です。

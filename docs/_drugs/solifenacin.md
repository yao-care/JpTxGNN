# ソリフェナシン：過活動膀胱から多発性嚢胞腎（PKD3）へ

## 一言要約

ソリフェナシンは選択的 M3 ムスカリン受容体拮抗薬で、元々は過活動膀胱の治療に使われてきました。
TxGNN モデルは**多発性嚢胞腎 3 型（多発性嚢胞肝の合併の有無を問わない）(polycystic kidney disease 3 with or without polycystic liver disease)** に有効である可能性を予測しています。ただし、これを支持する臨床試験・文献は **0 件**で、予測のみの段階（L5）です。

## この予測が妥当である理由

ソリフェナシンは膀胱の排尿筋にある M3 受容体を遮断し、不随意収縮を抑えて膀胱容量を増やします。詳細な作用機序データ（DrugBank の MOA）は現在ありませんが、上記は薬物の分類から分かる範囲の情報です。

この作用は、嚢胞形成を起こす経路とは結びつきません。多発性嚢胞腎の嚢胞増大は、cAMP シグナルと尿細管上皮の増殖が主な要因です。ムスカリン受容体を介したシグナルは関与しません。既存適応症（下部尿路症状）と新規適応症（遺伝性の嚢胞性腎疾患）は、病態の面でほとんど関連がありません。

したがって、この予測は機序的に妥当とは言えません。スコアは高いものの、モデルの出力にとどまり、裏付けとなる研究がありません。上位 10 件の予測のうち、機序的に説明できるのは「低コンプライアンス膀胱」のみです。

## 参考：エビデンスのある別の予測候補

予測 7 位の**低コンプライアンス膀胱 (low compliance bladder)** には、機序的な説明がつきます（TxGNN スコア 95.37%、エビデンスレベル L3）。

- **臨床試験**：2 件ありますが、ソリフェナシンの有効性を直接検証したものではありません。
  - [NCT04819360](https://clinicaltrials.gov/study/NCT04819360)（Phase 4）は、多発性硬化症に伴う神経因性過活動膀胱で、ボツリヌス毒素と抗コリン薬を第一選択として比較した試験です。参加者 1 名で中止され、使えるデータはありません。
  - [NCT04477265](https://clinicaltrials.gov/study/NCT04477265) は、女性の過活動膀胱に対する骨盤底筋トレーニングの試験です（完了、140 名）。薬物療法は検証していません。
- **文献**：
  - 小児の神経因性排尿筋過活動に対する、ソリフェナシンの長期有効性・安全性を検討した Phase 3 の非盲検試験（[PMID 32007426](https://pubmed.ncbi.nlm.nih.gov/32007426/)、2020 年）があります。
  - 抗コリン薬抵抗性の神経因性膀胱で、ミラベグロン併用の効果を検討した後ろ向き研究（[PMID 25656013](https://pubmed.ncbi.nlm.nih.gov/25656013/)、2015 年）もあります。

エビデンスは主に過活動膀胱と小児の神経因性排尿筋過活動からの間接的なものです。「推奨」ではなく、検証すべき研究課題（Research Question）にあたります。

## 結論と次のステップ

**決定：Hold**

**理由：**
多発性嚢胞腎 3 型の予測は TxGNN のスコアのみが根拠で、臨床試験も文献もありません。ムスカリン受容体拮抗作用と嚢胞形成の病態にも機序的なつながりがなく、開発を進める根拠は現時点でありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現状ではこの欠落が安全性スクリーニングを進めるうえでの阻害要因）
- DrugBank の作用機序（MOA）データの補完
- 多発性嚢胞腎について、機序を支持する前臨床データの有無の確認
- 研究資源を割くなら、機序的に妥当な「低コンプライアンス膀胱」（神経因性膀胱）を優先し、ソリフェナシン単剤を直接検証した研究を精査

※本レポートは研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的な検証を経て初めて実用できます。

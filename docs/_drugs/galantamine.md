# ガランタミン：認知症から心因性運動障害へ

## 一言要約

ガランタミンはアセチルコリンエステラーゼ阻害薬で、日本では認知症治療薬として使用されています。
TxGNN モデルは**心因性運動障害 (Psychogenic Movement Disorders)** に有効である可能性を予測していますが、この疾患に関する**臨床試験は 0 件、文献も 0 編**で、根拠はモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ガランタミンは可逆的なアセチルコリンエステラーゼ阻害薬であり、ニコチン受容体のアロステリック調節作用も持つとされます。認知症の治療薬として使われており、コリン作動性およびニコチン性のシグナルを高める薬です。

心因性運動障害（機能性運動障害）との機序的なつながりは**推測の域を出ません**。根拠は TxGNN の予測だけで、ガランタミン固有の機序研究や臨床データは確認できていません。予測スコアは高いものの、それだけで有効性を示すものではありません。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

参考として、アセチルコリンエステラーゼ阻害薬にはアルツハイマー型認知症で運動障害が関連するとの系統的レビューがあります（[PMID 40224553](https://pubmed.ncbi.nlm.nih.gov/40224553/)、2025 年）。運動障害を対象にする場合は、この点が特に重要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
心因性運動障害については、臨床試験も文献もなく、エビデンスはモデル予測のみ (L5) です。機序的なつながりも推測にとどまります。PMDA 添付文書の警告・禁忌情報も未取得のため、安全性の評価に進めません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌・相互作用）の取得と解析
- DrugBank からの作用機序 (MOA) データの取得
- 心因性運動障害を対象とした文献・臨床試験の再検索
- 同じ予測結果の中でエビデンスのある候補の優先検討
  - **遅発性ジスキネジア（口舌顔面ジスキネジア）**：ガランタミンのランダム化クロスオーバー試験（[PMID 17388711](https://pubmed.ncbi.nlm.nih.gov/17388711/)）とコリン作動薬の Cochrane レビューがあります。結論は本パックの情報だけでは確認できていません。
  - **錐体外路・運動疾患**：前臨床研究と 2025 年の系統的レビュー (L4) があります。安全性シグナルが利益を上回る可能性があります。

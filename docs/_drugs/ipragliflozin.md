# イプラグリフロジン：2型糖尿病から オプシスモ異形成症 へ

## 一言要約

イプラグリフロジンは SGLT2 阻害薬で、元々 2 型糖尿病の治療に使用されていました。
TxGNN モデルは**オプシスモ異形成症 (Opsismodysplasia)** に有効である可能性を予測していますが、
現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、イプラグリフロジンは SGLT2 阻害薬で、腎臓でのグルコース再吸収を抑えて血糖を下げます。日本、韓国、タイで 2 型糖尿病の治療薬として承認されています。薬理学データ上の標的は SGLT2 (SLC5A2) と SGLT1 (SLC5A1) です。

オプシスモ異形成症は INPPL1 遺伝子に関連する骨格異形成症です。SGLT2 阻害による糖排泄の仕組みと、この疾患の経路との間に、明確な機序的つながりは確認できていません。

そのため、この予測は TxGNN のネットワーク解析によるシグナルにとどまります。臨床的な裏付けはなく、仮説生成の段階として扱うのが適切です。

なお、他の上位予測（チアミン反応性機能不全症候群、限局性スティッフリム症候群、古典的スティッフパーソン症候群、薬剤性限局性リポジストロフィー、遠心性リポジストロフィー、圧迫性限局性脂肪萎縮）も、すべてエビデンスレベル L5 で Hold です。

## 安全性に関する考慮事項

- **薬物相互作用**：今回の照会では、薬理学データ上の標的として SGLT1 と SGLT2 が挙がっています。個別の併用禁忌薬や相互作用レベルのデータはありません。

警告や禁忌の詳細については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高い（99.39%）ものの、臨床試験も文献もなく、機序的な関連も見えません。
- 日本の販売承認はすべて取消済みで、安全性の確認に必要な添付文書情報も不足しています。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現状は安全性評価を進められない状態）
- 詳細な作用機序データ（MOA）の補完
- INPPL1 関連経路と SGLT2 阻害との関連を検証する前臨床研究
- 日本での販売状況（取消の経緯）の確認
- 他の予測疾患も含めた、機序的に妥当性の高い候補の再選定
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

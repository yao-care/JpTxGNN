# カボザンチニブ：腎細胞癌から脂肪肉腫へ

## 一言要約

カボザンチニブは VEGFR2、MET、AXL などを阻害するマルチキナーゼ阻害薬で、元々は腎細胞癌や甲状腺髄様癌の治療に使われていました。
TxGNN モデルは**脂肪肉腫 (Liposarcoma)** に有効である可能性を予測しています。
現時点の裏付けは **1 件の臨床試験**（軟部肉腫全般を対象とした Phase 2）と **1 編の文献**（Phase 1）にとどまり、脂肪肉腫に特化した有効性データはまだ限られています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 腎細胞癌、明細胞型腎細胞癌、甲状腺髄様癌（日本の承認情報には適応症の記載がないため、知識グラフの適応症情報による） |
| 予測新規適応症 | 脂肪肉腫 (Liposarcoma) |
| TxGNN 予測スコア | 99.83% |
| エビデンスレベル | L3 |
| 日本市販状況 | 販売中止のみ（有効な承認なし） |
| 承認番号数 | 2 件（いずれも取消済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

カボザンチニブは VEGFR2、MET、AXL を阻害します。これらは血管新生と腫瘍・間質のシグナル伝達に関わり、軟部肉腫の増殖を支える経路でもあります。薬物の詳細な作用機序データは、今回まとめたデータには含まれていません。そのため、以下は予測の根拠として整理された機序の説明に基づきます。

腎細胞癌では、これらの経路への阻害作用が実際の治療効果につながっています。脂肪肉腫を含む軟部肉腫も血管新生に依存する腫瘍であり、同じ阻害作用が効く可能性は理論上あります。

ただし、脂肪肉腫そのものを対象とした直接的なエビデンスは限られています。現時点では「機序的にもっともらしい」という段階です。

## 安全性に関する考慮事項

- **薬物相互作用**：相互作用データベースで 100 件が確認されています。主なものは次のとおりです。
  - **Major**：アスピリン、シサプリド、クラリスロマイシン、ドラセトロン、グラニセトロン、レボフロキサシン
  - **Moderate**：ロペラミド、アプレピタント、デキサメタゾン、ビサコジル、ラクツロースなど
- **放射線療法との併用**：肉腫領域の Phase 1 試験で、放射線療法との併用時の瘻孔や穿孔のリスクが懸念事項として挙げられています。

その他の警告・禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 脂肪肉腫に特化した試験や結果はなく、裏付けは軟部肉腫全般を対象とした進行中の Phase 2 と Phase 1 のみです。完了した RCT もありません。
- 日本の承認はすべて取消済みで、国内で使える有効な製品がありません。

**進める場合に必要なもの：**
- 脂肪肉腫サブタイプ別の有効性データ（NCT05836571 の結果公表の確認、脂肪肉腫を対象とした試験の計画）
- 日本の添付文書（警告・禁忌）の取得と安全性の確認
- 詳細な作用機序データの補完
- 日本での承認・供給状況の再確認

**参考：同じ薬物の他の予測候補**
- 腎細胞癌（renal carcinoma）：Phase 3 RCT が複数あり、L1、Proceed with Guardrails
- 分類不能腎細胞癌（unclassified renal cell carcinoma）：Phase 2 試験が複数あり、L2、Proceed with Guardrails

これらは既存適応症に近い領域のため、エビデンスは脂肪肉腫より充実しています。

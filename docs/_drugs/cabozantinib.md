# カボザンチニブ：日本承認薬から脂肪肉腫へ

## 一言要約

カボザンチニブは日本で「カボメティクス錠」として承認・市販されている経口キナーゼ阻害薬です。ただし、今回のデータでは承認適応症の記載を取得できていません。
TxGNN モデルは**脂肪肉腫 (Liposarcoma)** に有効である可能性を予測しています（スコア 99.83%）。
現在、この方向性に関わる情報は **1 件の臨床試験**（軟部肉腫全般を対象）と **1 編の文献**（Phase 1）にとどまり、直接的なエビデンスはまだ限られています。

## この予測が妥当である理由

カボザンチニブは VEGFR2、MET、AXL を阻害するマルチキナーゼ阻害薬です。これらは腫瘍の血管新生や増殖に関わる経路で、軟部肉腫の生物学にも関与すると考えられています。詳細な作用機序データ（DrugBank の MOA 項目）は現在ありません。上記の標的情報は、Evidence Pack の機序に関する記載に基づきます。

脂肪肉腫は軟部肉腫の一亜型です。血管新生や MET/AXL 経路を標的とする薬剤が、この疾患群で効果を示す可能性は、機序の面から筋が通っています。実際に、軟部肉腫の複数の亜型で活性が報告されています。

ただし、現時点の研究は軟部肉腫全体を対象としたものです。脂肪肉腫に特化した有効性データはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
機序上の妥当性はあり、軟部肉腫を対象とした Phase 2 試験も進行中です。しかし脂肪肉腫に特化した有効性データがなく、日本の添付文書に基づく安全性確認も未了のため、現時点では研究課題として保留するのが適切です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と、安全性スクリーニング（最優先）
- NCT05836571 の結果報告、および脂肪肉腫サブグループのデータ確認
- 詳細な作用機序（MOA）データの補充（DrugBank から取得）
- 放射線併用時の瘻孔・穿孔リスクなど、併用療法に固有の安全性の整理

なお、予測順位 7 位の「腎癌 (Renal carcinoma)」には、複数の Phase 3 RCT に基づく L1 のエビデンスがあります（推奨は Proceed with Guardrails）。再利用の優先度を検討する際は、この候補も併せて評価することをお勧めします。

> 本レポートは研究参考のみを目的としており、医療上の助言ではありません。予測結果は臨床での検証を経る必要があります。

# レベチラセタム：抗てんかん薬から視覚てんかんへ

## 一言要約

レベチラセタムは、日本で抗てんかん薬として承認されてきた薬です。
TxGNN モデルは**視覚てんかん (Visual Epilepsy)** に有効である可能性を高いスコアで予測しています。
ただし、この疾患を直接対象とした臨床試験は **0 件**です。関連文献 **20 編**もてんかん全般や他の発作集団が中心で、この疾患への裏付けは間接的です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 抗てんかん薬 |
| 予測新規適応症 | 視覚てんかん (Visual Epilepsy) |
| TxGNN 予測スコア | 99.98% |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、関連する解析では、レベチラセタムはシナプス小胞タンパク質 SV2A に結合すると整理されています。これにより神経伝達物質の放出と神経の過興奮が抑えられると考えられます。

視覚てんかんは、視覚刺激で誘発される反射性発作です。既存適応症のてんかんと同じく、神経の過興奮が発作の背景にあります。そのため、SV2A を介した抑制作用が反射性発作にも働く可能性は、機序の面ではもっともらしいといえます。

ただし、今回集めた文献は新生児発作、脳出血後の発作予防、てんかん全般の治療など、一般的な発作集団を扱ったものです。視覚てんかんに特化した知見はなく、裏付けは間接的です。

## 安全性に関する考慮事項

- **薬物相互作用**：相互作用の検索結果は 100 件でした。中等度とされた主なものは、モルヒネ、ドロナビノール、メトクロプラミド、ナビロン、アヘン、シブトラミンです。
- **知識グラフ上の禁忌関係**：知識グラフ上で、レベチラセタムと次の疾患の間に禁忌の関係が示されています。これは添付文書の記載ではなく、参考情報です。
  - 腎疾患、肝疾患、胆嚢疾患
  - 不安障害、気分変調症、精神病性障害、統合失調症様障害などの精神疾患
  - 好中球減少、無顆粒球症、白血球減少、汎血球減少などの血球減少

警告・禁忌の正式な内容は、添付文書で確認してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN のスコアは非常に高く、SV2A を介した機序にももっともらしさがあります。しかし、視覚てんかんを直接対象とした臨床試験も文献もなく、エビデンスは間接的です。また、日本では現在有効な承認がありません。

**進める場合に必要なもの：**
- 視覚てんかん（光感受性てんかんなど）におけるレベチラセタムの直接的な臨床データ
- 添付文書の警告・禁忌情報の取得と、安全性の確認
- 詳細な作用機序データ
- 日本での現在の承認・市販状況の再確認

**参考（同じ予測リスト内の別候補）：**
予測リストの別候補である**てんかん重積状態 (Status Epilepticus)** は、エビデンスの強さが L1 でした。ESETT 試験（NCT01960075、Phase 3、478 例）をはじめ、完了した複数の Phase 3 試験と RCT があります。優先度の高い検討対象として、別途評価することを推奨します。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

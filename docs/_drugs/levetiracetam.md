# レベチラセタム：抗てんかん薬から視覚誘発てんかんへ

## 一言要約

レベチラセタムは日本で抗てんかん薬として市販されている薬です。
TxGNN モデルは**視覚誘発てんかん (Visual Epilepsy)** に有効である可能性を予測しています（スコア 99.98%）。
ただし、視覚誘発てんかんを直接対象にした臨床試験や文献はなく、根拠は一般的なてんかん・発作領域の **9 件の臨床試験**と **20 編の文献**による間接的なものです。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank）はありません。予測根拠の資料によると、レベチラセタムはシナプス小胞タンパク質 SV2A に結合し、神経伝達物質の放出と神経の過興奮を抑えます。

視覚誘発てんかんは、光や視覚刺激で発作が誘発される反射てんかんです。既存適応症のてんかんと同じく、神経の過興奮が発作の背景にあります。そのため、SV2A を介した抑制作用が視覚刺激で誘発される発作にも働く可能性があります。

ただし、これは機序上の仮説にとどまります。提示された試験・文献に、視覚誘発てんかんを直接検証したものはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
視覚誘発てんかんを直接検証した試験や文献がなく、根拠は TxGNN の予測と一般的なてんかん領域の間接的なエビデンスにとどまります（L4）。また、日本の添付文書に基づく安全性情報が未整備で、安全性スクリーニングに進めません。

なお、同じ Evidence Pack 内では、**てんかん重積状態 (Status Epilepticus)** に Phase 3 RCT（ESETT）による直接的な裏付けがあり（L1、Proceed with Guardrails）、驚愕てんかん (Startle Epilepsy) にも小規模な観察研究があります（L3）。優先度を検討する場合は、これらの適応症が先行候補になります。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と、安全性スクリーニングの実施
- DrugBank からの作用機序（MOA）データの補完
- 視覚誘発てんかん（光感受性てんかんなど）を対象とした臨床データの収集、または小規模な探索試験の設計
- 投与経路の適合性の確認

本レポートは研究参考用であり、医療上の助言ではありません。予測された適応症は臨床的な検証を経て初めて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

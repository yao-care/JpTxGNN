# テルミサルタン：高血圧症から Prinzmetal 狭心症へ

## 一言要約

テルミサルタンはアンジオテンシンII受容体拮抗薬（ARB）で、元々高血圧症の治療に使用されていました。
TxGNN モデルは **Prinzmetal 狭心症 (Prinzmetal angina)** に有効である可能性を予測していますが、この疾患について現時点で裏付けとなる臨床試験や文献はなく、**モデル予測のみ**の段階です。
なお、予測順位 4 位の脳動脈閉塞と 9 位の脳出血には一定のエビデンスがあるため、補足情報として後述します。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 高血圧症（血圧降下薬、アンジオテンシンII受容体拮抗薬） |
| 予測新規適応症 | Prinzmetal 狭心症 (Prinzmetal angina) |
| TxGNN 予測スコア | 99.98% |
| エビデンスレベル | L5 |
| 日本市販状況 | 市販中の承認なし（20 件すべて承認整理済み） |
| 承認番号数 | 20 件（有効 0 件、整理済み 20 件） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、テルミサルタンは AT1 受容体を遮断する ARB であり、PPAR-γ 部分作動薬としての活性も持つとされています。高血圧症での有効性は確立しています。

血管の緊張を和らげる作用により、血管攣縮性の疾患である Prinzmetal 狭心症にも機序的に適用できる可能性があります。ただし、これは仮説の段階です。この疾患について臨床試験や文献は提供されておらず、根拠は TxGNN の予測のみです。

## 臨床試験・文献エビデンス（Prinzmetal 狭心症）

現在、関連する臨床試験の登録および関連する文献はありません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**：肝不全、腎疾患、無尿、膵炎、胆汁うっ滞、糖尿病（糖尿病性ケトアシドーシス含む）、低血圧、痛風、カリウム欠乏症、高カルシウム血症、腎動脈閉塞などが挙げられています（添付文書の記載ではなく、知識グラフ由来の情報です）。
- **薬物相互作用**：100 件が確認されています。主要（Major）なものは**クエン酸カリウム**と**炭酸水素カリウム**で、高カリウム血症のリスクに注意が必要です。中等度のものには、ステロイド（ヒドロコルチゾン、デキサメタゾンなど）、アセチルサリチル酸、SGLT2 阻害薬（カナグリフロジン、ダパグリフロジン、エンパグリフロジン）、インスリン、エキセナチド、モルヒネ、ブプロピオンなどがあります。

添付文書の警告・禁忌については、正式な確認が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 第 1 位の Prinzmetal 狭心症は、臨床試験・文献ともになく、TxGNN のスコアだけが根拠です。
- 現在有効な日本の承認がない点と、添付文書の警告・禁忌が未確認である点も、先に進めない要因です。

**進める場合に必要なもの：**
- Prinzmetal 狭心症に関する文献調査（血管攣縮に対する ARB の知見）と、前臨床・小規模臨床の検討
- PMDA 添付文書の警告・禁忌の取得と確認
- 詳細な作用機序データ（MOA）の補充
- 日本での承認整理済みの状況を踏まえた、開発・供給体制の確認
- エビデンスが比較的充実している脳出血（TRIDENT 試験の結果の精査）を、優先的な評価候補として検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# テルミサルタン：高血圧症から異型狭心症へ

## 一言要約

テルミサルタンはアンジオテンシンII受容体拮抗薬（ARB）で、元々は高血圧症の治療に使用されています。
TxGNN モデルは**異型狭心症 (Prinzmetal angina)** に有効である可能性を予測しています。ただし、この疾患に関する臨床試験と文献はいずれも **0 件**で、モデル予測のみの段階（L5）です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、テルミサルタンは AT1 受容体を遮断する ARB で、部分的な PPARγ 活性も持つとされています。これらの作用により血管収縮の緊張が下がる可能性があり、冠動脈攣縮に対しても理論上は作用しうると考えられます。

ただし、冠動脈攣縮は ARB の確立した治療標的ではありません。この機序仮説を裏付けるデータも、今回のエビデンスには含まれていません。現時点では、TxGNN のスコアが唯一の根拠です。

## 結論と次のステップ

**決定：Hold**

**理由：**
異型狭心症については、臨床試験も文献もなく、機序面の裏付けも乏しいため、モデル予測だけでは判断できません。なお、同じ Evidence Pack 内では、脳出血（L3）と脳動脈閉塞（L4）の予測にのみ、TRIDENT 試験や前臨床研究といった実際の研究がありました。優先的に検討するなら、こちらのほうが現実的です。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と確認（安全性スクリーニングの前提となる不足データ）
- 詳細な作用機序データ（MOA）の補充
- 異型狭心症（冠攣縮性狭心症）とテルミサルタン、または ARB に関する文献・臨床試験の再検索
- ARB の血管収縮抑制作用が冠動脈攣縮に及ぶかどうかの機序的検討

※本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経てから適用する必要があります。

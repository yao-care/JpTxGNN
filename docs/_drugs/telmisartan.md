# テルミサルタン：高血圧（ARB）から異型狭心症 (Prinzmetal Angina) へ

## 一言要約

テルミサルタンはアンジオテンシン II 1型受容体遮断薬（ARB）クラスの薬物で、高血圧治療に使用されるクラスに属します。TxGNN モデルは**異型狭心症 (Prinzmetal Angina)** への有効性をスコア **99.98%** で予測しています。ただし、現時点では関連する臨床試験・文献エビデンスがともにゼロであり、エビデンスレベルは **L5**（モデル予測のみ）です。

## この予測が妥当である理由

現在、DrugBank からの詳細な作用機序（MOA）データは収集できていません。各適応症の機序的考察から得られた情報によると、テルミサルタンはアンジオテンシン II 1型受容体（AT1）を選択的に遮断し、レニン-アンジオテンシン-アルドステロン系（RAAS）を介した血管収縮・アルドステロン分泌を抑制します。加えて、PPARγ（ペルオキシソーム増殖剤活性化受容体 γ）の部分アゴニスト活性も有しており、代謝改善作用から「メタボサルタン」と称されることもあります。

異型狭心症（プリンズメタル型狭心症）は、アテローム硬化とは独立した冠状動脈スパズム（一過性痙攣）を主な病態とします。テルミサルタンの AT1 遮断作用は、アンジオテンシン II 介在性の冠状動脈収縮を抑制することで、理論上スパズムの発生頻度や重症度を軽減できる可能性があります。PPARγ 促効活性による血管内皮保護・抗炎症効果も、冠状動脈スパズムの素地となる血管炎症を緩和する観点から補助的な役割を果たすと考えられます。

しかしながら、**これらはあくまで機序的推論にとどまります**。異型狭心症を直接対象とした前臨床研究・臨床試験は現時点で皆無であり、TxGNN の高スコア（99.98%）は知識グラフ上の関係性を反映するものに過ぎず、実際の治療有効性を保証するものではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
異型狭心症に対するテルミサルタンの有効性を支持する臨床・前臨床エビデンスが皆無（L5）であり、機序的な合理性は認められるものの、直接的なデータなしに開発段階へ進めることはできません。

**進める場合に必要なもの：**
- 冠状動脈スパズム動物モデルを用いた前臨床探索研究の立案
- ARB クラス薬と冠状動脈痙攣に関する系統的文献調査の実施
- 詳細な MOA データの取得（DrugBank API 照会、DG002 解消）
- 日本添付文書（仿単）の安全性情報収集（DG001 解消：警告・禁忌データの取得）
- 日本 PMDA 承認データの再確認（テルミサルタンは国際的に広く販売されている ARB であり、承認情報ゼロは要検証）

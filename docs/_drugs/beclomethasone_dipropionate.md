# ベクロメタゾンプロピオン酸エステル：気管支喘息（国際用途）からアトピー性湿疹へ

## 一言要約

ベクロメタゾンプロピオン酸エステル（BDP）は国際的に気管支喘息・アレルギー性鼻炎の治療に広く使用されている強効力吸入・局所ステロイド薬ですが、日本では現在未承認です。TxGNN モデルは**アトピー性湿疹（Atopic Eczema）**への有効性を予測しており、現在 **1 件の RCT** を含む **18 編の文献**がこの方向性を支持しています。

## この予測が妥当である理由

BDP は強効力合成糖皮質激素であり、NF-κB 経路の阻害および Th2 細胞サイトカイン（IL-4、IL-13）分泌の抑制を通じて好酸球とマスト細胞の活性化を抑制します。アトピー性湿疹の病態はまさにこの Th2 偏向性炎症が中心であり、BDP の抗炎症メカニズムは疾患の根本的な免疫異常に直接作用します。

アトピー性湿疹と BDP の既存用途（気管支喘息・アレルギー性鼻炎）はいずれも共通の Th2 免疫応答異常という基盤を持ち、同一の作用機序が横断的に適用可能です。BDP は外用（局所塗布）・経口・鼻腔内など複数の投与経路で国際的な使用実績があり、皮膚科領域への応用経路も確保されています。

1984 年の RCT（PMID 6434024）では、重症アトピー性湿疹を持つ小児 26 名を対象とした二重盲検プラセボ対照クロスオーバー試験において、口腔内・鼻腔内 BDP 4 週間投与がプラセボと比較して有意な改善をもたらすことが直接確認されています。この結果は、BDP の全身性吸収を介した抗炎症効果がアトピー性湿疹に有効であることを示す最も直接的な臨床エビデンスです。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
1984 年の RCT を含む複数の臨床研究がアトピー性湿疹に対する BDP の直接的な有効性を示しており、Th2 炎症を介した機序的妥当性も高い。ただし、日本での承認実績がなく詳細な安全性データも未整備であるため、条件付きで推進が適切と判断します。

**進める場合に必要なもの：**
- 日本 PMDA に相当する安全性情報（警告・禁忌・副作用）の取得（PMDA 仿単 PDF の解析）
- 詳細な作用機序（MOA）データの補充（DrugBank API 照会）
- 現代的な外用製剤（クリーム・ローション・テープ剤）での有効性・安全性を確認するための追加臨床試験の設計
- 日本国内における薬事承認パスウェイ（新規申請 vs. 既承認成分の効能追加）の法規制検討

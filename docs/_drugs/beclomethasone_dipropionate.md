## ベクロメタゾンジプロピオン酸エステル：副腎皮質ステロイド（グルココルチコイド受容体作動薬） → アトピー性皮膚炎 (atopic eczema)
{: .text-alpha }

## 一言要約

ベクロメタゾンジプロピオン酸エステルは、グルココルチコイド受容体に作用する副腎皮質ステロイドで、日本では点鼻液や吸入パウダーとして使われてきました。
TxGNN モデルは**アトピー性皮膚炎 (atopic eczema)** に有効である可能性を予測しています。
ただし、この疾患を直接検討した臨床試験の登録はなく、文献は **9 編**（小規模・古い観察研究やレビューが中心）にとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。一般的な薬理学の知見によると、ベクロメタゾンジプロピオン酸エステルはグルココルチコイド受容体作動薬であり、Th2 型の炎症反応を抑える作用が知られています。

アトピー性皮膚炎は Th2 優位の皮膚炎症を特徴とするため、局所ステロイドの抗炎症作用は機序的に適用可能と考えられます。小児の重症アトピー性皮膚炎に対する経口ベクロメタゾンの検討など、古い小規模研究がこの方向性を示しています。

一方で、全身への吸収や副腎抑制、成長への影響が報告されており、有効性だけでなく安全性の検討が不可欠です。

## 結論と次のステップ

**決定：Hold**

**理由：**
この疾患を直接検討した臨床試験はなく、文献も小規模で古い観察研究が中心のため、現時点では研究課題の段階です。小児での副腎抑制や成長への影響も懸念されます。

**進める場合に必要なもの：**
- アトピー性皮膚炎を対象とした、ベクロメタゾン外用または適切な剤形での比較試験データ
- 日本の添付文書に基づく警告・禁忌の確認
- 詳細な作用機序データ（MOA）
- 剤形・投与経路の適合性評価（現在の国内製剤は点鼻液と吸入パウダーのみ）
- 副腎機能や成長に関する安全性モニタリング計画

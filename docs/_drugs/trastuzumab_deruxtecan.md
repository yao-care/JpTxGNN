# Trastuzumab Deruxtecan：HER2陽性腫瘍から薬剤性骨粗鬆症まで

## 一言まとめ

Trastuzumab deruxtecan（トラスツズマブ デルクステカン、エンハーツ） は、もともとHER2陽性の乳癌、非小細胞肺癌、胃癌などの腫瘍の治療に用いられる薬剤です。
TxGNNモデルは、本剤が**薬剤性骨粗鬆症 (drug-induced osteoporosis)** に有効である可能性を予測しています。
ただし現時点では、この方向性を支持する**臨床試験や文献はありません**。

## この予測が妥当でない可能性がある理由

Trastuzumab deruxtecan は抗体薬物複合体 (ADC) の一種で、抗HER2モノクローナル抗体とトポイソメラーゼI阻害薬を結合させたものです。その設計上の狙いは次のとおりです。

1. **HER2を標的とする**：抗体部分によってHER2陽性の腫瘍細胞を認識する
2. **細胞傷害作用**：薬物ペイロードが細胞内に取り込まれた後に放出され、腫瘍細胞を死滅させる
3. **バイスタンダー効果**：近傍のHER2低発現細胞にも影響を及ぼしうる

薬剤性骨粗鬆症とHER2シグナル伝達との間に明確な関連はなく、また抗腫瘍薬は通常、骨粗鬆症を改善するどころか悪化させます。この予測は、知識グラフに由来する偽陽性の結果である可能性があります。

## 安全性に関する考慮事項

- **間質性肺疾患 (ILD)**：最も重篤な副作用で、致死的となる可能性がある
- **心毒性**：左室駆出率を低下させる可能性がある
- **骨髄抑制**：好中球減少、貧血、血小板減少
- **主な相互作用 (Major)**：
  - Deferiprone（好中球減少のリスクを増加）
  - TNF-alpha 阻害薬（Adalimumab、Etanercept、Infliximab、Golimumab）
  - JAK 阻害薬（Baricitinib、Tofacitinib、Upadacitinib）
  - その他の免疫抑制薬

## 結論と次のステップ

**判断：Not Recommended**

**理由：**
この予測には生物学的な妥当性がありません。Trastuzumab deruxtecan はHER2を標的とする細胞毒性の抗体薬物複合体であり、その作用機序は骨粗鬆症の病態生理とは関連しません。抗腫瘍治療は通常、骨量減少を引き起こすことはあっても、改善することはありません。

**推進を推奨しない理由：**
- 臨床・基礎研究のいずれにおいても、エビデンスが一切ない
- 作用機序と適応症との間に生物学的な関連がない
- 薬剤自体が骨粗鬆症を悪化させる可能性がある
- 強い細胞毒性のため、非腫瘍性の適応症には適さない

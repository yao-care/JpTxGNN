# アスコルビン酸：アスコルビン酸欠乏症・壊血病から非症候性食道奇形へ

## 一言要約

アスコルビン酸（ビタミン C）は、元々アスコルビン酸欠乏症と壊血病の治療に使われてきた薬です。
TxGNN モデルは**非症候性食道奇形 (non-syndromic esophageal malformation)** に有効である可能性を高いスコアで予測しています。
ただし、この予測を裏付ける**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみです。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | アスコルビン酸欠乏症、壊血病 |
| 予測新規適応症 | 非症候性食道奇形 (Non-syndromic esophageal malformation) |
| TxGNN 予測スコア | 99.96% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認はすべて失効（現在市販中の承認なし） |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。アスコルビン酸は必須ビタミンで、コラーゲン合成に関わる水酸化酵素の補因子として働き、抗酸化物質でもあります。欠乏症である壊血病に対する有効性は確立しています。

一方、非症候性食道奇形は、食道が先天的に構造異常を起こす疾患です。アスコルビン酸との機序的な接点は見当たりません。栄養素の補充や抗酸化作用で、胎生期に決まる構造異常を是正できるとは考えにくいです。

高いスコアは知識グラフ上の関係性から導かれた予測にすぎません。臨床的・機序的な裏付けは確認できず、妥当性は低いと評価します。

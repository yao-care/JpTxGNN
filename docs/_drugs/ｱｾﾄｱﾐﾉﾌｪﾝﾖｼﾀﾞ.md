## 一言要約

`ｱｾﾄｱﾐﾉﾌｪﾝﾖｼﾀﾞ`（アセトアミノフェンヨシダ、以下「本薬」）は、PMDA データベースへの照会で承認レコードが存在せず、DrugBank でも照合は 1 件のみでした。既存適応症・作用機序・安全性情報のいずれも取得できておらず、TxGNN モデルによる新規適応症の予測結果も **0 件** です。現時点では再利用評価を実施できる状態ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
PMDA データベースに承認レコードが存在せず、TxGNN による予測適応症も生成されていません。薬物の基本情報（DrugBank ID・作用機序・既存適応症）が揃っていない状態では、再利用評価の開始条件を満たしません。

**進める前に必要なもの：**

- **薬物名の確認**：`ｱｾﾄｱﾐﾉﾌｪﾝﾖｼﾀﾞ`（半角カタカナ）が正規の INN か確認する。製造会社名（ヨシダ）が混入している可能性があり、正確な INN（例：`acetaminophen`）で再クエリが必要
- **DrugBank ID の取得**：DrugBank 照合 1 件の詳細を確認し、正確な `drugbank_id` を記録する
- **MOA データの補完**：DrugBank API から作用機序（DG002）を取得する
- **PMDA 再照会**：正規化した薬物名で PMDA に再クエリし、承認状況を確認する
- **TxGNN 再予測**：DrugBank ID が確定してから予測パイプラインを再実行する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ロキソプロフェン：消炎鎮痛薬から 小眼球症・コロボーマ・根幹型四肢短縮異形成症候群 へ

## 一言要約

ロキソプロフェンは、プロドラッグとして働く非ステロイド性抗炎症薬（NSAID）で、日本では痛みや炎症の治療に広く使われています。
TxGNN モデルは**小眼球症・コロボーマ・根幹型四肢短縮異形成症候群 (colobomatous microphthalmia-rhizomelic dysplasia syndrome)** に有効である可能性を予測しています。ただし、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データはありません。既知の情報によると、ロキソプロフェンはプロドラッグで、体内で生じる活性代謝物が COX-1 と COX-2 を非選択的に阻害し、プロスタグランジンの産生を抑えます。

一方、予測された疾患は、発生過程の異常による先天性の奇形症候群です。COX 阻害との機序的な接点は見当たりません。TxGNN のスコアは非常に高いものの、知識グラフ上の関連から算出された値にすぎず、臨床的・文献的な裏付けはありません。このため、**機序面からは妥当性を支持できない予測**です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測疾患は遺伝的な発生異常で、COX 阻害による治療の機序的根拠がなく、臨床試験・文献もないため、L5（モデル予測のみ）にとどまります。上位 10 件の予測候補はすべて Hold です。

このうち、変形性関節症の感受性（osteoarthritis susceptibility、スコア 96.36%）だけは、プロスタグランジン抑制による症状緩和という妥当な機序を想定できます。ただし、これは疾患感受性であって発症後の治療ではなく、裏付けとなる根拠もありません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析。現状では安全性スクリーニングに進めない要因です。
- DrugBank API による作用機序（MOA）データの補完
- 予測疾患に関する臨床試験・文献の系統的検索。評価対象は、機序的に妥当な変形性関節症関連の候補を優先することを推奨します。
- 投与経路の適合性評価（経口・外用の別）

※本結果は研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的な検証を経て初めて応用できます。

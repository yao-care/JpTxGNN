# アリメマジン：アレルギー性鼻炎・蕁麻疹などから アレルギー性蕁麻疹 へ

## 一言要約

アリメマジン（アリメジン）はフェノチアジン系の抗ヒスタミン薬で、元々は血管性浮腫、アレルギー性鼻炎、蕁麻疹、結膜炎などの治療に用いられていました。
TxGNN モデルは**アレルギー性蕁麻疹 (allergic urticaria)** に有効である可能性を高いスコアで予測していますが、現時点で裏付けとなる臨床試験や文献は**ありません**（モデル予測のみ）。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アリメマジンはフェノチアジン系の H1 抗ヒスタミン薬で、ヒスタミンによる膨疹・紅斑の抑制が期待できます。抗コリン作用も併せ持つとされています。

既存適応症にはすでに蕁麻疹が含まれており、アレルギー性蕁麻疹はこれに近い疾患です。肥満細胞から放出されるヒスタミンを H1 受容体で遮断するという機序は、既存適応症と共通しています。

ただし、この妥当性はクラス共通の薬理に基づく推定であり、個別の臨床的裏付けはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、臨床試験・文献が一件もなく、モデル予測のみ（L5）です。
- 日本では承認が整理済みで現在市販されていません。
- 添付文書の警告・禁忌が未確認です（ブロッキング）。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを実施する
- DrugBank などから作用機序（MOA）データを補充する
- アレルギー性・寒冷蕁麻疹における抗ヒスタミン薬の臨床試験・文献を調査する
- 既存の蕁麻疹適応との差分を整理し、新規適応としての意義を確認する
- 販売終了の経緯を確認し、剤形・投与経路の適合性を評価する
- QT 延長や血液障害など、知識グラフ上の禁忌リスクを評価する

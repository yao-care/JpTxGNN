# アキシチニブ：未分類腎細胞癌への適応拡大予測

## 一言要約

アキシチニブは VEGFR-1/2/3 を選択的に阻害するチロシンキナーゼ阻害薬で、日本では「インライタ錠」として市販されています。ただし、Evidence Pack には既存適応症の記載がありません。
TxGNN モデルは**未分類腎細胞癌 (unclassified renal cell carcinoma)** に有効である可能性を予測しています。この予測を支える根拠は **2 件の観察研究**のみで、対象疾患に直接関連する文献はありません。

## クイック概要

|------|------|
| 予測新規適応症 | 未分類腎細胞癌 (unclassified renal cell carcinoma) |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。アキシチニブは VEGFR-1/2/3 を阻害して腫瘍血管新生を抑える薬剤です。血管新生は腎細胞癌の大半のサブタイプで中心的な駆動因子であり、この点が予測の機序的な根拠になります。

一方、「未分類」という組織型は定義上、特定のサブタイプに分類できない群です。そのため VEGF 依存性が共通しているかどうかは確認できていません。現時点のエビデンスは観察研究に限られ、機序が妥当であることと有効性が示されていることは別です。

## 結論と次のステップ

**決定：Hold**

**理由：**
未分類腎細胞癌については、実臨床の観察研究 2 件しかなく、有効性を検証する介入試験や文献がありません。また、PMDA 添付文書の警告・禁忌が未取得で安全性評価に進めない状態です。
参考として、同じパック内の「腎癌 (renal carcinoma)」では Phase 3 RCT（KEYNOTE-426、JAVELIN Renal 101、RENOTORCH）があり、L1 で Proceed with Guardrails と評価されています。ただし、この結果は未分類組織型へ直接外挿できません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌・相互作用情報の取得（現時点でブロッキング）
- 詳細な作用機序データ（MOA）の補完
- 既存承認適応症の確認（承認適応症テキストが未取得）
- 未分類組織型を対象とした介入試験または症例集積の探索

# アキシチニブ：腎細胞癌から未分類腎細胞癌へ

## 一言要約

アキシチニブは VEGFR1〜3 を選択的に阻害するチロシンキナーゼ阻害薬で、元々は腎細胞癌の治療に使われてきました。
TxGNN モデルは **未分類腎細胞癌 (unclassified renal cell carcinoma)** への有効性を高スコアで予測していますが、この疾患名に直接対応する臨床試験・文献は **0 件** で、予測のみの段階 (L5) です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 腎細胞癌（淡明細胞型腎細胞癌、非乳頭状腎細胞癌など） |
| 予測新規適応症 | 未分類腎細胞癌 (Unclassified Renal Cell Carcinoma) |
| TxGNN 予測スコア | 99.90% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は取り消し済みのみ（現在有効な承認なし） |
| 承認番号数 | 2 件（いずれも取り消し） |
| 推奨決定 | Hold |

※既存適応症は、日本の承認書に適応症の記載がなかったため、知識グラフ上の適応症情報から記載しています。

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。ただし、今回まとめたデータによると、アキシチニブは VEGFR1〜3 を選択的に阻害し、PDGFR や c-KIT にも活性を持つチロシンキナーゼ阻害薬です。血管新生を抑えることで、血管に富む淡明細胞型腎細胞癌で効果を発揮します。

未分類腎細胞癌は、既存適応症である腎細胞癌の大きな分類に含まれます。そのため、血管新生阻害という機序が当てはまる可能性があります。ただし、これは真の「再利用」というより同一疾患群内の適応拡張に近い予測です。この疾患名に限った試験や文献は今回のデータにはなく、妥当性はモデルスコアと機序からの推定にとどまります。

## 安全性に関する考慮事項

- **薬物相互作用**：100 件の相互作用が報告されており、うち詳細を確認できた 20 件の内訳は次のとおりです。
  - **Major（2 件）**：クラリスロマイシン、デキサメタゾン
  - **Moderate（4 件）**：アプレピタント、クロトリマゾール、ミコナゾール、ナルトレキソン
  - **Minor（14 件）**：H2 受容体拮抗薬（ファモチジン、ラニチジン、シメチジン、ニザチジン）、プロトンポンプ阻害薬（ラベプラゾール、エソメプラゾール、ランソプラゾール、デクスランソプラゾール）、制酸薬（水酸化アルミニウム、炭酸カルシウム、マガルドラート、各種マグネシウム製剤）

警告・禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 「未分類腎細胞癌」を直接支持する試験・文献がなく、根拠は TxGNN スコアと機序からの推定のみです。
- 日本での承認がすべて取り消し済みで、安全性の主要データ（警告・禁忌）と作用機序データも不足しています。

**進める場合に必要なもの：**
- 日本の添付文書（警告・禁忌）の取得と確認
- 詳細な作用機序データ（MOA）の補完
- 未分類腎細胞癌を対象とした臨床・文献エビデンスの調査
- 日本での供給・承認状況の再確認（取り消し済みのため）
- 相互作用（特に CYP3A4 に関わる Major・Moderate の薬剤）の管理計画の策定
- 評価の優先対象を、エビデンスのある TFE3 転座型腎細胞癌や集合管癌に切り替えるかの検討
## 免責事項

# ピリドキシン：ビタミンB6補充（脂漏性湿疹・接触皮膚炎）から Ureaplasma 尿道炎へ

## 一言要約

ピリドキシン（ビタミンB6）は、日本ではビタミンB6補充薬として、脂漏性湿疹や接触皮膚炎などに使用されています。
TxGNN モデルは **Ureaplasma 尿道炎 (Ureaplasma urethritis)** に有効である可能性を予測していますが、**臨床試験・文献はいずれも 0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ピリドキシンは補酵素であるピリドキサールリン酸（PLP）の前駆体となるビタミンで、ビタミンB6欠乏の補充に使われています。

Ureaplasma 尿道炎は細菌感染症です。ピリドキシンには Ureaplasma に対する抗菌活性が知られておらず、既存適応症との機序的な関連も確認できません。この予測は現時点で **TxGNN のスコアのみに基づいており、機序面の裏付けはありません**。

同じ尿路・性感染症領域の候補（淋菌性尿道炎など）も上位に並んでいますが、どれも同様にモデル予測のみです。共通の知識グラフ上の関連が反映された可能性はありますが、臨床的な意味は確認されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高い（93.87%）ものの、臨床試験も文献もなく、抗菌活性などの機序的根拠もありません。エビデンスは L5（モデル予測のみ）のため、現時点で開発を進める根拠はありません。

なお、同じ予測リストの別候補である**ビタミン欠乏症 (vitamin deficiency disorder)** は、スコア 85.50%、エビデンスレベル L3 です。ビタミンB6欠乏の補充はピリドキシンの本来の役割に近く、関連する臨床試験と文献が多数あります。ただし、試験の多くは複数栄養素の併用で、ピリドキシン単独の試験ではありません。この候補は Ureaplasma 尿道炎より、優先して調べる価値があります。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現状は安全性審査に進めない未取得項目）
- 作用機序（MOA）データの補完（DrugBank）
- Ureaplasma に対する in vitro 抗菌活性など、前臨床の機序的根拠の確認
- 投与経路の適合性の評価（現在は未評価）

※ 本結果は研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的検証を経てはじめて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

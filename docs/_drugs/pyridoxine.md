# ピリドキシン：ビタミンB6欠乏症（日本未承認）から Ureaplasma 尿道炎 へ

## 一言要約

> ピリドキシン（ビタミンB6）はアミノ酸代謝・神経伝達物質合成・免疫機能に関わる必須水溶性ビタミンであり、ビタミンB6欠乏症の補充療法として世界的に広く用いられていますが、日本（PMDA）には現在承認記録がありません。
> TxGNN モデルは **Ureaplasma 尿道炎 (Ureaplasma urethritis)** への有効性を予測（スコア 93.87%）していますが、
> この方向性を支持する**臨床試験・文献はいずれも存在せず**、エビデンスはモデル予測のみ（L5）です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません（Data Gap）。既知の情報によると、ピリドキシンはビタミンB6ファミリーの一形態であり、体内で活性型のリン酸ピリドキサール（PLP）に変換されます。PLP は 100 種以上の酵素反応（アミノ酸転換・神経伝達物質合成・脂質代謝・免疫応答）の補酵素として機能し、特にリンパ球の増殖とサイトカイン合成への関与が知られています。

Ureaplasma urethritis は Ureaplasma 属（主に *U. urealyticum*）による性感染症関連の尿道炎であり、宿主の免疫状態が感染制御に影響を与えます。理論上、ピリドキシンの免疫調節作用が宿主防御を間接的に補助できるという仮説は構築できます。しかしながら、ピリドキシンには Ureaplasma に対する直接の抗菌活性は報告されておらず、免疫補助による臨床的有益性を示す実験的・臨床的根拠もありません。

この予測は TxGNN 知識グラフ上の構造的類似性から導かれたものであり、臨床再利用の合理性は非常に限定的です。

## 結論と次のステップ

**決定：Hold**

**理由：**
Ureaplasma 尿道炎に対するピリドキシンの有効性を支持する臨床試験・文献がまったく存在せず、直接の抗菌機序も確認されていません。エビデンスレベル L5（モデル予測のみ）であり、現段階では再利用候補として積極的に進める科学的根拠が不十分です。

**進める場合に必要なもの：**
- *Ureaplasma urealyticum* に対する in vitro 抗菌活性試験
- ピリドキシンの免疫調節作用が Ureaplasma 感染制御に与える影響の機序研究
- 詳細な MOA データ取得（DrugBank API 照会で DG002 を解消）
- 日本 PMDA 仿単 PDF の入手・解析による安全性情報の確認（DG001 を解消）

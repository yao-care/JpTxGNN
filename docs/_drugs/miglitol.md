# ミグリトール：糖尿病から巣状スティフリム症候群へ

## 一言要約

ミグリトールは α-グルコシダーゼ阻害薬で、元々は糖尿病の食後高血糖の改善に使用されていました。
TxGNN モデルは**巣状スティフリム症候群 (focal stiff limb syndrome)** に有効である可能性を予測していますが、関連する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。
なお、予測上位 10 位の 1 型糖尿病にはまとまったエビデンスがあり、後述の補足にまとめました。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 糖尿病（α-グルコシダーゼ阻害薬） |
| 予測新規適応症 | 巣状スティフリム症候群 (Focal Stiff Limb Syndrome) |
| TxGNN 予測スコア | 99.87% |
| エビデンスレベル | L5 |

## この予測が妥当である理由

現在、詳細な作用機序データは収録されていません。ミグリトールは小腸の α-グルコシダーゼを阻害して炭水化物の消化・吸収を遅らせ、食後血糖の急上昇を抑える薬剤として知られています。

一方、巣状スティフリム症候群は、抗 GAD 抗体などの自己免疫や GABA 系の異常が関わるとされる神経疾患です。ミグリトールの作用はこれらの病態に直接関係せず、**機序的な裏付けは確認できません**。この予測は、糖尿病との併存関係といった知識グラフ上の近接性から生じたものと考えられます。同じ理由で、スティフパーソン症候群（99.87%）など上位の他の予測にも機序的根拠はありません。

## 補足：エビデンスのある予測候補（1 型糖尿病）

予測順位 10 位の**1 型糖尿病**（スコア 99.60%）には、臨床試験と文献があります。インスリン療法の補助としての位置づけで、既存適応症の糖尿病の範囲内に近く、厳密には新規適応症とはいえません。

作用機序は、小腸での炭水化物消化を遅らせて食後血糖の急上昇を抑えるというものです。インスリンの代替ではなく併用が前提です。

エビデンスレベルは、完了した Phase 3 試験が 1 件のため、判定ルール上は **L2 相当**です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 最上位の予測である巣状スティフリム症候群には、臨床試験も文献もなく、機序的な根拠も見当たらないため、現時点で開発を進める根拠がありません。
- 日本では全承認が整理済みで、現在市販されている製剤もありません。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と確認
- 詳細な作用機序データの補充
- 巣状スティフリム症候群との生物学的関連を示す前臨床データ
- 1 型糖尿病の補助療法を優先候補とする場合は、現行の臨床ガイドラインとの整合確認、Phase 3 試験の結果の精査、低血糖リスクを含む安全性評価（その場合は Proceed with Guardrails が妥当）

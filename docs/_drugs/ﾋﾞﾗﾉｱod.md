# ビラノアOD：評価データ不足により保留

## 一言要約

`ﾋﾞﾗﾉｱOD`（ビラノアOD）は今回の Evidence Pack において PMDA 照会結果が 0 件であり、既存適応症・作用機序ともに確認できませんでした。
TxGNN モデルによる新規適応症の予測も生成されておらず、再利用候補としての評価を進めることができません。
有意義な評価を実施するには、PMDA 仿単の取得・DrugBank 情報補充・薬物名の正規化確認が先決です。

## 結論と次のステップ

**決定：Hold**

**理由：**
PMDA データベースへの照会で承認情報が取得できず、TxGNN パイプラインによる新規適応症予測も生成されていないため、現時点では再利用評価を継続する根拠がありません。

**進める場合に必要なもの：**

- **薬物名の正規化確認**：半角カタカナ `ﾋﾞﾗﾉｱOD` を正式名称（全角カタカナまたは一般名）に変換し、PMDA 再照会を実施
- **PMDA 仿単取得**：添付文書 PDF をダウンロード・解析し、承認適応症・警告・禁忌を取得（Blocking 項目）
- **DrugBank 情報補充**：DrugBank API より作用機序（MOA）・薬物カテゴリ・薬物間相互作用を取得（DrugBank 照会では 1 件ヒットしており、データ取得は実現可能）
- **TxGNN 予測の再実行**：上記情報補充後、既存適応症を特定してから予測パイプラインを再実行

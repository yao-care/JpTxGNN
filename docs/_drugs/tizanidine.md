# チザニジン：脊髄小脳変性症・多発性硬化症などから片頭痛へ

## 一言要約

チザニジンはα2アドレナリン受容体作動薬の筋弛緩薬で、日本では脊髄小脳変性症、多発性硬化症、筋萎縮性側索硬化症などの領域で承認されています。
TxGNN モデルは**片頭痛 (Migraine Disorder)** に有効である可能性を予測しています。
関連する臨床試験は **2 件**（うち Phase 3 が 1 件で、状態は「不明」）、文献は **18 編**ですが、確定的な有効性を示す結果はまだありません。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank）はありません。既知の情報によると、チザニジンは中枢性のα2アドレナリン受容体作動薬であり、筋緊張や痙縮の治療に使われています。

α2作動薬は、三叉神経系や中枢の痛み伝達を弱める可能性があります。また、頭部・頸部の筋緊張を和らげることも期待できます。これらが片頭痛の予防に役立つという仮説が、機序的な根拠です。ただし、この根拠は一般的な薬理学に基づくもので、チザニジン固有の機序データで裏付けられたものではありません。

既存適応症（痙縮など）と片頭痛は病態が異なりますが、筋緊張の緩和と痛み伝達の調整という点でつながります。文献では、慢性連日性頭痛の予防薬候補としてチザニジンが繰り返し取り上げられています。

## 結論と次のステップ

**決定：Hold**

**理由：**
片頭痛予防を直接検証する Phase 3 試験（NCT05484349）はありますが、状態が「不明」で結果も出ていません。文献も総説や小規模・非盲検の研究が中心で、エビデンスは L3 に留まります。さらに、日本の添付文書に基づく安全性確認が未了で、安全性スクリーニングに進めません。現時点では研究課題として位置づけるのが妥当です。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌・相互作用を取得し、安全性スクリーニングを行う
- NCT05484349 の実施状況と結果を確認する
- 慢性連日性頭痛の二重盲検試験（PMID 12167135）の全文を確認し、結果を評価する
- DrugBank から詳細な作用機序データ（MOA）を取得し、機序的な根拠を補強する
- 他の予測（片頭痛の亜型や遺伝的感受性、トゥレット症候群など）は、証拠が L4〜L5 で機序的な裏付けも乏しいため、当面は保留とする
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

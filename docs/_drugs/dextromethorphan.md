# デキストロメトルファン：咳嗽から鼻腔疾患へ

## 一言要約

デキストロメトルファン（Dextromethorphan）は、世界的に非オピオイド系中枢性鎮咳薬として広く使用されてきた薬物ですが、本データソース上では市販承認記録が登録されていません。TxGNN モデルは**鼻腔疾患 (Nasal Cavity Disease)** に有効である可能性を予測しており、現在 **1 件の臨床試験**がデキストロメトルファンを使用した研究として確認されています（鼻腔疾患に特化した文献は未登録）。

## この予測が妥当である理由

本 Evidence Pack には詳細な作用機序データ（MOA）が収録されていませんが、デキストロメトルファンは延髄の咳嗽中枢を抑制する中枢性鎮咳薬として薬理学的に広く知られており、**NMDA 受体（N-methyl-D-aspartate receptor）拮抗作用**と **sigma-1 受体激動作用**を有することが複数の研究で確認されています。

鼻腔疾患においては、粘膜感覚神経の過敏化や神経性炎症が症状の持続・増悪に深く関与します。NMDA 受体拮抗作用は脊髄および末梢感覚神経の興奮性を低下させる効果があるため、鼻腔粘膜における神経性刺激症状（過敏、分泌亢進など）を調節する薬理学的根拠が存在します。また、sigma-1 受体の活性化は局所免疫応答の修飾に関与する可能性があり、鼻腔粘膜炎症に対する追加的なメカニズムとして想定されます。

咳嗽（上気道刺激による反射）と鼻腔疾患はともに上気道の神経過敏・粘膜炎症という共通した病態機序を持ちます。既存の中枢性・末梢性神経調節機序が鼻腔疾患へも適用できるという推論は機序的に一貫しており、既存適応症から予測新規適応症への橋渡しが合理的に説明できます。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
TxGNN モデルによる高スコア予測（99.98%）が確認されているものの、Evidence Pack 内で確認された唯一の臨床試験（NCT06958692）は大うつ病性障害を主対象としており、鼻腔疾患に直接特化したエビデンスは現時点で不在です。さらに作用機序データ（MOA）と安全性情報（警告・禁忌）がいずれも未収録であり、リスク管理下での慎重な進行が必要です。

**進める場合に必要なもの：**
- 作用機序データの取得（DrugBank API による MOA 情報の収集）
- 安全性情報の確認（PMDA 仿単 PDF の解析による警告・禁忌の明確化）
- 鼻腔疾患を直接対象とした臨床試験・文献の探索（ClinicalTrials.gov および PubMed での追加クエリ）
- 鼻腔粘膜における NMDA 受体拮抗作用に関する前臨床研究データの収集

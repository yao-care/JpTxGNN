# デキストロメトルファン：咳嗽（鎮咳）から鼻腔疾患へ

## 一言要約

デキストロメトルファンは中枢性の鎮咳薬で、日本では気管支拡張症などに伴う咳嗽の治療に使われています。
TxGNN モデルは**鼻腔疾患 (Nasal Cavity Disease)** に有効である可能性を予測していますが、直接これを支持する文献はありません。
関連付けられた臨床試験は **1 件**のみで、対象は大うつ病性障害のため、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、予測の根拠として整理された情報では、デキストロメトルファンは NMDA 受容体拮抗作用とシグマ-1 受容体作動作用を持つ薬剤で、中枢で咳反射を抑えます。

既存適応症の咳嗽は気道の刺激に伴う症状であり、鼻腔を含む上気道の疾患とは症状面で接点があります。そのため、上気道への関連は機序的には考えられます。ただし間接的な関連にとどまり、鼻腔疾患そのものを治療する機序が示されているわけではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
鼻腔疾患に対する予測はスコアこそ高いものの、直接の臨床試験も文献もなく、モデル予測にとどまります。関連付けられた Phase 3 試験は対象が大うつ病性障害で、根拠になりません。

なお、他の予測候補では気管疾患（rank 7）のみ、動物・in vitro の前臨床研究が 2 編あります（L4）。ただし臨床エビデンスはなく、こちらも Hold です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と確認（安全性スクリーニングの前提）
- DrugBank からの作用機序（MOA）データの取得
- 鼻腔疾患に対象を絞った臨床試験・文献の再検索
- 対象疾患の具体化（アレルギー性鼻炎、副鼻腔炎など）と、剤形・投与経路の適合性の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

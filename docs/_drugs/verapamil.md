# ベラパミル：心房細動・狭心症・心筋梗塞から閉塞性脚ブロック（obsolete bundle branch block）へ

## 一言要約

ベラパミルはカルシウムチャネル遮断薬で、元々は心房細動・狭心症・心筋梗塞などの治療に使用されていました。
TxGNN モデルは **閉塞性脚ブロック (obsolete bundle branch block)** に有効である可能性を予測していますが、関連する臨床試験・文献は **0 件** で、モデル予測のみの段階です。
なお、上位 10 件の予測の中では、**肺高血圧症（低酸素・肺疾患に伴うもの）** と **不整脈原性右室心筋症** に前臨床・間接的な文献があり、相対的に検討しやすい候補です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ベラパミルは L 型カルシウムチャネルを遮断し、房室結節の伝導を遅らせる薬剤です。この作用により、心房細動などの上室性不整脈、狭心症で有効性が示されてきました。

ただし、脚ブロックは房室結節より下位の伝導系の障害です。ベラパミルにこれを改善する機序的根拠は見当たらず、むしろ伝導障害を悪化させるおそれがあります。この予測はモデルのスコアのみに基づいており、機序的な裏付けは弱いと判断します。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測 1 位の閉塞性脚ブロックには臨床試験も文献もなく、機序的にも支持されず、ベラパミルが伝導障害を悪化させる懸念があります。
- 日本では現在有効な承認がなく、添付文書の安全性情報も未取得のため、先に進める根拠が不足しています。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（安全性スクリーニングの前提）
- DrugBank からの詳細な作用機序データの取得
- 肺高血圧症（低酸素・肺疾患に伴うもの）や不整脈原性右室心筋症を優先候補とする再評価（L4 のため研究課題として検討可）
- 房室ブロック・心不全など伝導障害や心機能低下のある集団に対するリスク評価
- 日本での承認取消の経緯の確認と、投与経路・剤形の適合性評価

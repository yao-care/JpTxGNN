# ベラパミル：心房細動・狭心症・心筋梗塞から脚ブロック（廃止用語）へ

## 一言要約

ベラパミルはカルシウムチャネル遮断薬で、日本では抗不整脈薬・血管拡張薬として心房細動、狭心症、心筋梗塞に使用されています。
TxGNN モデルは**脚ブロック (obsolete bundle branch block)** に有効である可能性を予測していますが、この病名は廃止された用語です。
関連する臨床試験・文献は **0 件**で、エビデンスはモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。Evidence Pack の情報では、ベラパミルは L-type カルシウムチャネルを遮断し、房室結節の伝導を遅らせる薬剤です。日本では心房細動、狭心症、心筋梗塞の適応があります。

脚ブロックは心室内の刺激伝導の異常で、ベラパミルの伝導抑制作用とは領域が近く見えます。しかしこの薬は伝導を遅らせる方向に働くため、脚ブロックを改善する根拠にはなりません。加えて、この病名は廃止用語です。現時点でこの予測を支持するのは TxGNN のスコアだけで、機序面の裏付けはありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（**ブロッキング項目**。これがないと S1 安全性スクリーニングに進めません）

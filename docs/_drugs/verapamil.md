# ベラパミル：不整脈・高血圧 から 脚ブロック（Bundle Branch Block）へ

## 一言要約

ベラパミル（Verapamil）はL型カルシウムイオンチャネル拮抗薬として、上室性頻拍・高血圧・狭心症などの心臓疾患治療に広く用いられてきた薬物です。TxGNNモデルは**脚ブロック（Bundle Branch Block）** への有効性を最上位（スコア 99.62%）で予測していますが、この疾患名は医療オントロジー上「廃棄済み（obsolete）」の用語であり、現在の臨床分類との対応が不明確です。現時点では直接支持する臨床試験・文献エビデンスは存在せず（エビデンスレベル L5）、推奨は **Hold** です。

## この予測が妥当である理由

現在のEvidence Packでは詳細な作用機序データは未取得です。薬理学的に知られている情報によると、ベラパミルはL型電位依存性カルシウムチャネルを遮断することで、①房室結節の伝導速度を遅延させ（Class IV抗不整脈薬）、②血管平滑筋の収縮を抑制して末梢血管抵抗を低下させ（降圧効果）、③心筋の酸素消費量を軽減します（抗狭心症効果）。これらの効果はいずれも、心臓の電気的・機械的活動の調節を通じて発現します。

脚ブロック（束枝ブロック）は刺激伝導系のヒス束枝における伝導障害であり、カルシウム依存性の膜電位変化と関連します。ベラパミルがAV結節伝導を修飾できるという点から、TxGNNモデルは伝導系疾患との関連を推定したと考えられます。ただし、脚ブロックに対するカルシウム拮抗薬の有用性は現在の臨床ガイドラインでは確立されておらず、機序的適用の妥当性には疑問が残ります。

なお、予測された疾患名「obsolete bundle branch block」は医療オントロジー上の廃棄用語であり、現在の臨床分類（右脚ブロック・左脚ブロック等）に対応する再検索がなされていません。廃棄用語への高スコア予測は、知識グラフ上の遠距離推論に起因する偽陽性である可能性があり、本予測の臨床的転換可能性は現時点では不明確です。

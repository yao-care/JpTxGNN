## ドセタキセル：微小管安定化薬 → ユーイング肉腫 (Ewing sarcoma)
{: .text-alpha }

## 一言要約

ドセタキセルは微小管を安定化して細胞分裂を止めるタキサン系の抗悪性腫瘍薬です。
TxGNN モデルは**ユーイング肉腫 (Ewing sarcoma)** に有効である可能性を予測しており、現在 **8 件の臨床試験**と **20 編の文献**がこの方向性に関連しています。ただし、活性は主にゲムシタビンなどとの併用レジメンで報告されており、単剤での効果は限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。一般的な薬理知識として、ドセタキセルは微小管の脱重合を抑え、有糸分裂の停止を引き起こすことで、増殖の速い腫瘍細胞に細胞傷害性を示します。

ユーイング肉腫は増殖が速い小児・若年成人の骨・軟部腫瘍であり、抗有糸分裂薬の作用が及ぶ可能性があります。前臨床研究では、ゲムシタビンの後にドセタキセルを投与する逐次投与で相乗的な細胞傷害性が示唆されています。

ただし、ユーイング肉腫での臨床活性は控えめで、主に併用レジメンに由来します。単剤の再発・難治例を対象とした第 II 相試験や、ゲムシタビン併用の試験が報告されています。

## 細胞毒性

| 項目 | 内容 |
|------|------|
| 細胞毒性分類 | 従来型細胞毒性薬（タキサン系微小管阻害薬） |
| 骨髄抑制リスク | 高（好中球減少、血小板減少、貧血が懸念される） |
| 催吐性分類 | 低〜中等度 |
| モニタリング項目 | CBC（分画含む）、肝機能（ビリルビン等）、末梢神経症状、体液貯留 |
| 取り扱い防護 | 細胞毒性薬取り扱い規程に従った防護措置が必要 |

## 安全性に関する考慮事項

- **薬物相互作用**：主要な相互作用としてクラリスロマイシン（Major）があります。中等度ではアプレピタント、シメチジン、メトロニダゾール、ミコナゾール、ロラピタント、ロスバスタチン、シンバスタチン、チニダゾール、トログリタゾン、エリグルスタットが挙げられます。デキサメタゾン、プレドニゾロン、プレドニゾン、レボフロキサシンは軽微（Minor）です。

その他の警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 再発ユーイング肉腫を対象とした完了済みの第 II 相試験や複数のコホート研究があり、ゲムシタビン併用を中心に一定の臨床的知見があります。一方、活性は控えめで、無作為化第 III 相試験による確証はありません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の確認（現時点で未取得）
- 詳細な作用機序データの補充
- 単剤と併用レジメンの有効性を切り分ける比較データ
- 骨髄抑制、好中球減少、末梢神経障害に対する安全性モニタリング計画

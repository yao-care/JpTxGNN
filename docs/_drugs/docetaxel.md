# ドセタキセル：承認済み抗悪性腫瘍薬から女性乳癌へ

## 一言要約

ドセタキセルはタキサン系の抗悪性腫瘍薬で、日本では複数の後発品を含む注射剤が市販されています。
TxGNN モデルは**女性乳癌 (female breast carcinoma)** に有効である可能性を予測しており、現在 **50 件の臨床試験**と **20 編の文献**がこの方向性に関連しています。
完了した Phase 3 試験が複数あり、エビデンスは比較的充実しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 予測新規適応症 | 女性乳癌 (female breast carcinoma) |
| TxGNN 予測スコア | 99.90% |
| エビデンスレベル | L1 |

| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、ドセタキセルは一般的なタキサン系薬理から、微小管を安定化して脱重合を妨げることが知られています。その結果、有糸分裂が停止し、増殖の速い腫瘍細胞でアポトーシスが誘導されます。

乳癌は増殖の速い上皮性腫瘍であり、この機序が適用できると考えられます。実際に、AC 療法（ドキソルビシン＋シクロホスファミド）との併用や逐次投与、カペシタビンとの併用、トラスツズマブ併用など、ドセタキセルを組み込んだ多くの乳癌レジメンが Phase 3 まで検討されています。

なお、以下の臨床試験の多くは併用レジメンの試験です。ドセタキセル単剤の効果を直接示すものではありません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
乳癌でドセタキセルを含むレジメンを評価した完了済み Phase 3 試験が複数あり、日本で 20 件の承認番号を持つ市販薬でもあるため、エビデンスは十分です。ただし、日本の添付文書に基づく安全性情報が未確認であり、作用機序データも不足しているため、これらを補う条件付きで進めます。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）を取得して確認する（この安全性スクリーニングが未実施のため、次の段階へ進む前に必須）
- 日本での承認適応症の内容を確認し、乳癌が既承認かどうかを整理する
- DrugBank から詳細な作用機序データ（MOA）を補完する
- 骨髄抑制、浮腫、末梢神経障害に対するモニタリング計画を策定する

本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床での検証が必要です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ドセタキセル：乳癌・肺癌・前立腺癌などから女性乳癌 (Female Breast Carcinoma) へ

## 一言要約

ドセタキセルは微小管を安定化させる細胞毒性の抗悪性腫瘍薬で、元々は非小細胞肺癌、前立腺癌、頭頸部癌、胃癌、乳癌などの治療に使われていました。
TxGNN モデルは**女性乳癌 (Female Breast Carcinoma)** に有効である可能性を予測しています（スコア 99.90%）。
ただし乳癌はすでに既存適応症に含まれるため、今回の予測は新規適応の発見というより、既知の有効性を裏付ける結果です。現在、**Phase 3 試験を含む多数の臨床試験**と**文献**が支持しています。

| 予測新規適応症 | 女性乳癌 (Female Breast Carcinoma) |

## この予測が妥当である理由

詳細な作用機序データは現在ありません。ただし既知の情報では、ドセタキセルはβチューブリンに結合して微小管を安定化させ、細胞分裂を停止させてアポトーシスを誘導するタキサン系薬剤です。増殖の速い腫瘍細胞に強く作用します。

乳癌はすでにドセタキセルの標準的な適応疾患の一つです。そのため今回の予測は、真の再利用というより既知の有効性の確認にあたります。アントラサイクリン系との併用、トラスツズマブやベバシズマブなど分子標的薬との併用でも広く使われています。

## 細胞毒性

| 項目 | 内容 |
|------|------|
| 細胞毒性分類 | 従来型細胞毒性薬（タキサン系、微小管安定化薬） |
| 骨髄抑制リスク | 高（知識グラフ上、好中球減少、血小板減少、無顆粒球症、貧血が禁忌関連疾患として挙がる） |
| 催吐性分類 | 低〜中 |
| モニタリング項目 | CBC（好中球数・血小板数）、肝機能（ビリルビン等）、末梢神経症状、体液貯留（浮腫・肺水腫） |
| 取り扱い防護 | 細胞毒性薬取り扱い規程に従った防護が必要 |

## 安全性に関する考慮事項

- **禁忌に関連する疾患（知識グラフ由来、添付文書の記載ではありません）**：肝疾患、胆嚢疾患、血小板減少症、好中球減少症、無顆粒球症、末梢神経障害、貧血、高ビリルビン血症、ギルバート症候群、下痢性疾患、肺水腫、口内炎、神経炎、心タンポナーデ
- **薬物相互作用**（100 件中の主なもの）：
  - 重大 (Major)：クラリスロマイシン
  - 中等度 (Moderate)：アプレピタント、メトロニダゾール、シメチジン、エリグルスタット、ミコナゾール、ロラピタント、ロスバスタチン、シンバスタチン、チニダゾール、トログリタゾン
  - 軽微 (Minor)：デキサメタゾン、レボフロキサシン、プレドニゾロン、プレドニゾン

警告・禁忌の正式な記載は添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 複数の大規模 Phase 3 試験（術後補助療法、転移性、HER2 陽性/陰性）が乳癌におけるドセタキセルの有効性を支持しており、エビデンスは十分です。
- 乳癌は既知の適応症で、今回は新規再利用ではなく確認的な位置づけです。日本の販売承認はすべて取消のため、導入には承認状況の確認が必要です。

**進める場合に必要なもの：**
- 日本の添付文書（警告・禁忌）の確認と解析（現状は安全性評価を進められない）
- 日本における承認状況の確認（現在すべて取消）
- 詳細な作用機序データ（MOA）の補完
- 骨髄抑制・末梢神経障害・体液貯留に対する安全性モニタリング計画
- CYP3A4 阻害薬（クラリスロマイシンなど）との併用管理方針

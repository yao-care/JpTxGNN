# ビンクリスチン：造血器腫瘍・リンパ腫から神経節芽腫へ

## 一言要約

ビンクリスチンは微小管の重合を阻害する抗腫瘍薬で、元々急性リンパ芽球性白血病、ホジキンリンパ腫、非ホジキンリンパ腫などの治療に使用されていました。
TxGNN モデルは**神経節芽腫 (Ganglioneuroblastoma)** に有効である可能性を予測しています。
現在、関連する臨床試験の登録はなく、**6 編の文献**（大半が症例報告）がこの方向性を示すにとどまります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 急性リンパ芽球性白血病、ホジキンリンパ腫、非ホジキンリンパ腫、マントル細胞リンパ腫、ランゲルハンス細胞組織球症など（日本の承認適応症の記載はなく、知識グラフ上の適応症） |
| 予測新規適応症 | 神経節芽腫 (Ganglioneuroblastoma) |

## この予測が妥当である理由

現在、詳細な作用機序データ（MOA）は登録されていません。ただし一般的な知見として、ビンクリスチンは微小管を構成するチューブリンに結合し、重合を阻害します。その結果、分裂の盛んな細胞が中期で停止します。

既存適応症の血液腫瘍は増殖の速い腫瘍であり、神経節芽腫を含む神経芽細胞性腫瘍も増殖性の腫瘍です。ビンクリスチンは神経芽細胞性腫瘍に対する多剤併用レジメンの標準的な構成薬の一つで、抗有糸分裂作用が適用できると考えられます。

ただし、取得された文献の大半は症例報告です。前向き試験が 1 件ありますが、ビンクリスチン単独の効果を切り分けたものではありません。そのため、機序上の妥当性はあっても、有効性を示す直接的な根拠は限られています。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 臨床試験の登録がなく、文献も大半が症例報告です。ビンクリスチン単独の効果を示す根拠がなく、神経節芽腫では既に多剤併用レジメンの一部として使われています。
- 日本の承認は取消のみで、市販されている製剤がありません。添付文書の警告・禁忌も取得できていません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性評価に必須）
- 詳細な作用機序データ（MOA）の補充
- 神経芽細胞性腫瘍の標準レジメンにおけるビンクリスチンの位置づけを示す、ガイドラインや前向き試験の整理
- 日本での供給状況と承認状況の再確認

なお、予測順位 2 位（脊椎異常を伴う内分泌・T 細胞機能異常症候群）は機序的関連性も文献もなく、Hold です。順位 3 位（後腹膜腫瘍）は、横紋筋肉腫や傍神経節腫などの症例報告と小規模シリーズのみで、疾患特異的な対照データがなく、研究課題の段階です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ビンクリスチン：（既存適応症データなし）から神経節芽腫へ

## 一言要約

ビンクリスチンは微小管を阻害する細胞毒性の抗悪性腫瘍薬です。今回の入力データには既存適応症の記載がありません。
TxGNN モデルは**神経節芽腫 (ganglioneuroblastoma)** に有効である可能性を予測しています（スコア 99.31%）。
関連する臨床試験は **5 件**、文献は **6 編**ありますが、いずれもビンクリスチン自体を検証した試験ではありません。試験は併用化学療法の一部として関わるにとどまり、文献は症例報告が中心です。

## この予測が妥当である理由

現在、DrugBank の詳細な作用機序データは入力に含まれていません。ただし、ビンクリスチンはチューブリンに結合して微小管の重合を阻害し、分裂期の細胞を停止させることが知られています。この作用により、神経堤由来の腫瘍のように増殖の速い細胞が標的になり得ます。

神経芽腫スペクトラム（神経芽腫・神経節芽腫）の多剤併用療法では、ビンクリスチンは化学療法の基盤薬の一つとして使われてきました。今回の予測は、真の意味での「再利用」というより、既に確立している使われ方に近いと考えられます。

ただし、既存適応症と作用機序のデータが入力にありません。臨床試験のタイトルも一部切れているため、各レジメンでビンクリスチンが実際にどう使われているかは確認できていません。既存適応症との類似性の評価も未実施です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 神経節芽腫を含む神経芽腫スペクトラムでは多剤併用療法にビンクリスチンが使われるため、予測は臨床的に自然です。
- 一方で、ビンクリスチン単独の有効性を検証した試験はなく、文献も症例報告が中心です。
- 安全性の添付文書情報は未取得（Blocking）で、安全性スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析
- DrugBank からの作用機序（MOA）データの取得
- 日本での承認適応症の確認（現在は記載なし）
- 各試験プロトコルでのビンクリスチンの位置づけの確認（併用レジメンの詳細）
- 同じ薬の他の予測（後腹膜腫瘍など）は文献が異種混在で間接的な根拠にとどまるため、別途評価が必要

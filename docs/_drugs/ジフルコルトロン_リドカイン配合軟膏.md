## 一言要約

ジフルコルトロン・リドカイン配合軟膏は、コルチコステロイド（ジフルコルトロン）と局所麻酔薬（リドカイン）を組み合わせた外用複合製剤です。
今回の評価では **TxGNN モデルによる新規適応症の予測結果が得られておらず**、再利用候補の特定には至りませんでした。
PMDA データベースへの登録もなく、**日本国内での承認・市販実績は確認されていません**。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN モデルによる新規適応症予測が得られておらず、PMDA 承認記録も存在しないため、現段階では再利用評価を進めるための基礎データが不足しています。DrugBank への問い合わせでは 1 件のヒットがあったものの DrugBank ID の特定に至らず、作用機序の分析も実施できていません。

**進める場合に必要なもの：**
- **DG001（Blocking）**：添付文書 PDF の入手と警語・禁忌の解析（TFDA/各国規制機関）
- **DG002（High）**：DrugBank API を用いた作用機序データの取得（配合成分ごとに個別検索を推奨）
- ジフルコルトロン単剤・リドカイン単剤それぞれでの TxGNN 予測再実行（配合剤は DrugBank ID が存在しないケースが多く、成分単位での解析が有効）
- 海外規制機関（EMA・FDA など）での承認状況の追加確認

# アカルボース：糖尿病から focal stiff limb syndrome へ

## 一言要約

アカルボースは α-グルコシダーゼ阻害薬で、元々糖尿病の治療に使用されていました。
TxGNN モデルは **focal stiff limb syndrome** に有効である可能性を予測していますが、関連する臨床試験・文献はなく、**モデル予測のみ**の段階です。
予測の機序的な裏付けも乏しく、現時点では保留が妥当です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 糖尿病（α-グルコシダーゼ阻害薬） |
| 予測新規適応症 | focal stiff limb syndrome |
| TxGNN 予測スコア | 99.65% |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、アカルボースは小腸の α-グルコシダーゼを阻害して炭水化物の消化・吸収を遅らせ、食後血糖の上昇を抑える薬です。

一方、focal stiff limb syndrome は神経免疫性または脊髄介在ニューロンの異常が関わる疾患です。アカルボースの作用はこの病態と結びつきません。予測は TxGNN による関連づけのみで、機序的な根拠は確認できていません。

同じ予測スコアで上位に挙がった classic stiff person syndrome についても、抗 GAD 自己免疫や GABA 作動性伝達への作用は知られていません。共通点は糖尿病の合併が多いことだけで、治療効果を支持するものではありません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書ではなく TxGNN の知識グラフに基づく）：腎疾患、膿尿管症、肝疾患、胆嚢疾患、肝硬変、炎症性腸疾患、低血糖、外傷
- **薬物相互作用**：100 件の相互作用が登録されています。主なものは次のとおりです。
  - 中等度：アセタゾラミド、サルブタモール、アロエベラ葉、アルペリシブ、アンプレナビル、アリピプラゾール、アセナピン、アタザナビル、ベダキリン、ベタメタゾンなど
  - 軽度：アルビグルチド、アルクロメタゾン（外用）、リポ酸、アムシノニド、アニンジオンなど

詳細な警告・禁忌は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 臨床試験・文献がなく、エビデンスはモデル予測のみ（L5）です。
- アカルボースの作用機序と focal stiff limb syndrome の病態に妥当な接点がありません。
- 日本の販売承認も全て取消となっています。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得（現時点で安全性スクリーニングに進めない状態です）
- 作用機序データの補充
- 予測疾患に対する機序的仮説の提示と、前臨床または症例レベルの裏付け
- 他の予測候補を含めた再評価。ただし、上位候補にも同様に根拠がありません。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# カルテオロール：既存適応症から原発性遺伝性緑内障へ

## 一言要約

カルテオロールは非選択性β遮断薬で、日本では細粒とカプセルの2剤形が承認されています。
TxGNN モデルは**原発性遺伝性緑内障 (Primary Hereditary Glaucoma)** に有効である可能性を予測していますが、
現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、根拠はモデル予測のみです。

## この予測が妥当である理由

カルテオロールはβアドレナリン受容体を非選択的に遮断します。眼では房水の産生を抑えて眼圧を下げると考えられ、緑内障の治療原理と生物学的に整合します。

ただし、今回のデータには詳細な作用機序 (MOA) の情報がなく、機序面の裏付けは限定的です。さらに、予測対象は「遺伝性」の亜型です。眼圧下降による一般的な緑内障治療の理屈が、この亜型にもそのまま当てはまるかは確認できていません。

日本の承認剤形は細粒とカプセルで、いずれも経口剤です。緑内障では点眼など局所投与が一般的なため、投与経路の適合性は未評価です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験も文献もなく、エビデンスは L5（モデル予測のみ）にとどまります。加えて、PMDA 添付文書の警告・禁忌情報が未取得のため、安全性スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析（進行を妨げる最優先の課題）
- 詳細な作用機序 (MOA) データの補完（DrugBank など）
- 緑内障（特に遺伝性亜型）に関する臨床試験・文献の探索
- 承認適応症の情報の補完と、投与経路（経口剤か局所投与か）の適合性評価
## 免責事項

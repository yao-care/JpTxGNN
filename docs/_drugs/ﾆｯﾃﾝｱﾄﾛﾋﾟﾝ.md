# ニッテンアトロピン：予測適応症なし（データ不足）

---

## 一言要約

ニッテンアトロピン（ﾆｯﾃﾝｱﾄﾛﾋﾟﾝ）はアトロピンを主成分とする製剤と推測されますが、PMDA データベースでの検索結果は 0 件であり、承認情報が確認できていません。TxGNN モデルによる新規適応症の予測も得られておらず、DrugBank ID の取得も未完了です。現時点では再利用候補を特定するための基礎データが不足しており、追加のデータ収集が必要です。

## データギャップ詳細

現在の Evidence Pack には以下の重大な欠落があります。

| 優先度 | 欠落項目 | 影響 | 補完方法 |
|--------|---------|------|---------|
| 重大 | PMDA 仿單（警語・禁忌） | 安全性初評が実施不可 | PMDA 官網から PDF を取得・解析 |
| 高 | 作用機序（MOA） | 機序関連性分析が実施不可 | DrugBank API で DrugBank ID を確認後に取得 |
| 高 | DrugBank ID | TxGNN 予測の入力情報が不完全 | DrugBank 検索（1 件ヒット済み）から ID を確定 |

> **注記**：DrugBank 検索ではすでに 1 件がヒットしています。薬品名の半角カタカナ（ﾆｯﾃﾝｱﾄﾛﾋﾟﾝ）が原因でマッピングが完了していない可能性があります。全角カタカナ（ニッテンアトロピン）または英語名（Atropine）で再検索することを推奨します。

---

## 結論と次のステップ

**決定：Hold**

**理由：**  
PMDA 承認情報・DrugBank ID・MOA のいずれも未確定であり、TxGNN モデルへの入力が揃っていないため、有効な再利用予測が生成されていません。現段階でエビデンス評価を進めることはできません。

**進める場合に必要なもの：**

1. **薬品名の正規化**：半角カタカナ → 全角カタカナ（ニッテンアトロピン）または英語名（Atropine / Nitten Atropine）へ変換し、PMDA・DrugBank で再検索
2. **DrugBank ID の確定**：すでに 1 件ヒット済みの DrugBank レコードから ID を取得
3. **MOA の取得**：DrugBank API または添付文書から作用機序を確認
4. **TxGNN 予測の再実行**：正確な DrugBank ID を用いて予測パイプラインを再実行
5. **PMDA 仿單 PDF の取得**：安全性情報（警語・禁忌・薬物相互作用）を解析

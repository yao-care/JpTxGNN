## フェキソフェナジン：アレルギー性鼻炎・アトピー性皮膚炎から酒さ性結膜炎へ
{: .text-alpha }

## 一言要約

フェキソフェナジンは末梢選択性の H1 受容体拮抗薬で、元々アレルギー性鼻炎とアトピー性皮膚炎の治療に使用されていました。
TxGNN モデルは**酒さ性結膜炎 (Rosacea Conjunctivitis)** に有効である可能性を予測していますが、
現時点で支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | アレルギー性鼻炎、アトピー性皮膚炎（抗アレルギー薬、H1 受容体拮抗薬） |
| 予測新規適応症 | 酒さ性結膜炎 (Rosacea Conjunctivitis) |
| TxGNN 予測スコア | 99.85% |
| エビデンスレベル | L5 |
| 日本市販状況 | 取消のみ（現在有効な承認なし） |
| 承認番号数 | 20 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フェキソフェナジンは末梢選択性の H1 受容体拮抗薬で、アレルギー性鼻炎とアトピー性皮膚炎での使用実績があります。ヒスタミンが関与する眼表面の炎症を抑える可能性があるため、機序的に酒さ性結膜炎にも適用できる可能性があります。

ただし、酒さ性結膜炎の主な病態は、マイボーム腺機能不全と自然免疫の調節異常です。ヒスタミン経路の遮断だけで十分な効果が得られるかは不明です。この関連性は TxGNN の予測のみに基づいており、臨床的な裏付けはありません。

参考として、予測上位の他の疾患も、いずれもエビデンスは L5 です。

| 順位 | 予測疾患 | スコア | 妥当性のコメント |
|------|---------|--------|----------------|
| 2 | 点状表層角結膜炎 | 98.63% | 経口薬は眼への移行性が限られる |
| 3 | 眼瞼結膜炎 | 98.40% | アレルギー成分には有効かもしれないが、細菌性や脂漏性が多い |
| 4 | ウイルス性結膜炎 | 98.17% | 抗ウイルス作用はなく、かゆみの緩和にとどまる可能性 |
| 10 | 眼瞼の非感染性皮膚疾患 | 95.84% | 既存適応症のアトピー性皮膚炎に最も近く、生物学的に最も妥当 |

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、モデルの知識グラフに基づく情報）：高血圧、腎疾患、糖尿病、糖尿病性ケトアシドーシス、前立腺肥大症、冠動脈疾患、動脈硬化、閉塞隅角緑内障、甲状腺機能亢進症（バセドウ病を含む）など。
- **薬物相互作用**：100 件が確認されています。主なものは以下のとおりです。
  - 中等度：エリグルスタット、エルクサドリン、ロラピタント、水酸化マグネシウム、水酸化アルミニウム、マガルドレート、炭酸マグネシウム（制酸薬は吸収に影響する可能性があります）
  - 軽度：クラリスロマイシン、ミコナゾール、クロトリマゾール

警告・禁忌の詳細については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 臨床試験も文献もなく、予測はモデルのスコアのみに基づいています（L5）。
- 日本の承認はすべて取消されており、作用機序データと添付文書の安全性情報も不足しています。

**進める場合に必要なもの：**
- 作用機序（MOA）データの補充
- PMDA 添付文書の警告・禁忌情報の取得
- 酒さ性結膜炎に関する前臨床研究または文献調査
- 眼への投与経路（点眼剤など）の適合性評価
- エビデンスの観点から、既存適応症に近い「眼瞼の非感染性皮膚疾患」を優先的に検討すること
## 免責事項

# フェキソフェナジン：アレルギー性鼻炎・アトピー性皮膚炎から酒さ性結膜炎へ

## 一言要約

フェキソフェナジンは末梢性 H1 受容体拮抗薬（抗アレルギー薬）で、日本ではアレルギー性鼻炎やアトピー性皮膚炎の治療に使われています。
TxGNN モデルは**酒さ性結膜炎 (Rosacea Conjunctivitis)** に有効である可能性を予測していますが、現在この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フェキソフェナジンは末梢性 H1 受容体拮抗薬に分類され、アレルギー性鼻炎やアトピー性皮膚炎など、ヒスタミンが関与する疾患での有効性が確認されています。

酒さ性結膜炎は、眼表面の炎症性疾患です。H1 遮断によってアレルギー性・炎症性の要素が和らぐ可能性は考えられます。ただし、ヒスタミンが酒さに伴う眼表面疾患の主な原因であるとは確立されていません。機序面の裏付けは弱く、推測の域を出ません。

TxGNN のスコアは高い（全体順位 419 位）ものの、これはモデルによる予測値です。実際の研究成果ではありません。機序の類似性や投与経路の適合性も未評価です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測を支持する臨床試験も文献もなく、根拠は TxGNN のスコアのみ（L5）です。機序面でも、酒さ性結膜炎における H1 遮断の意義は確立されていません。今回は上位 1 件目のみを評価しました。上位 10 件の予測の中では、眼瞼の非感染性皮膚疾患（アレルギー性・アトピー性）が、ヒスタミン性のかゆみを介した機序としては最も筋が通っています。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（安全性スクリーニングに必須）
- 作用機序（MOA）データの補完（DrugBank など）
- ClinicalTrials.gov、PubMed、JPRN での酒さ性結膜炎に関する体系的な検索
- 適応症間の機序的類似性の評価と、投与経路（経口か点眼か）の適合性確認
- 機序的に妥当性の高い候補（眼瞼のアレルギー性・アトピー性皮膚疾患など）の優先的な再評価

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて応用できます。*

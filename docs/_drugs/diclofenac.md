# ジクロフェナク：鎮痛・抗炎症から頭皮の単純性乏毛症へ

## 一言要約

ジクロフェナクは非ステロイド性抗炎症薬 (NSAID) で、シクロオキシゲナーゼ (COX) 阻害による鎮痛・抗炎症・解熱を目的に使われてきました。
TxGNN モデルは**頭皮の単純性乏毛症 (hypotrichosis simplex of the scalp)** に有効である可能性を予測しましたが、**関連する臨床試験・文献はどちらも 0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 鎮痛薬、抗炎症薬、解熱薬、シクロオキシゲナーゼ阻害薬 |
| 予測新規適応症 | 頭皮の単純性乏毛症 (hypotrichosis simplex of the scalp) |
| TxGNN 予測スコア | 99.69% |
| エビデンスレベル | L5 |
| 日本市販状況 | 現在有効な承認なし（承認はすべて整理済み） |
| 承認番号数 | 20 件（すべて整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ジクロフェナクは非選択的 COX 阻害薬として知られ、プロスタグランジン産生を抑えて炎症と疼痛を軽減します。

一方、頭皮の単純性乏毛症は遺伝性の毛包疾患で、COX 阻害やプロスタグランジン経路との関連は知られていません。既存適応症との機序上のつながりも確認できず、予測を裏付ける臨床的・機序的根拠はありません。スコアは高いものの、現時点ではモデル由来の仮説にとどまります。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、TxGNN の知識グラフに基づく）：
  - 高血圧、うっ血性心不全、心筋梗塞などの心血管疾患
  - 脳卒中・脳梗塞などの脳血管疾患
  - 活動性消化性潰瘍、炎症性腸疾患
  - 肝不全、肝疾患、薬剤性肝障害
  - 喘息（内因性・アレルギー性を含む）
  - 糖尿病、糖尿病性ケトアシドーシス
  - 血液凝固疾患、貧血、ヘモグロビン異常症
  - 胆嚢疾患、角膜炎、物質乱用・依存
- **薬物相互作用**：相互作用は計 100 件が確認されており、そのうち取得できた上位 20 件の内訳は次のとおりです。
  - 中等度 (Moderate)：アセチルサリチル酸、ヒドロコルチゾン、デキサメタゾン、ベタメタゾン、ブデソニド、トリアムシノロン、メトホルミン、メサラジン、バルサラジド、アプレピタント、グリメピリド、グリピジドなど
  - 軽度 (Minor)：ファモチジン、ラニチジン、シメチジン

  ステロイドや他の NSAID との併用では消化管障害の増強に注意が必要です。血糖降下薬との併用では血糖コントロールへの影響が懸念されます。

添付文書上の警告・禁忌については未確認のため、必ず添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、臨床試験・文献がなく、作用機序上の根拠も見当たりません（L5）。
- 日本の承認はすべて整理済みで、現在有効な製品がありません。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と確認
- 詳細な作用機序データ (MOA) の補充
- 毛包でのプロスタグランジン関与を示す前臨床データ

**参考：同じ予測リスト内で唯一エビデンスのある候補（若年性特発性関節炎）**
- 若年性特発性関節炎 (JIA) の予測スコアは 99.25% です。
- 小児を対象としたジクロフェナク関連の文献が複数あります。例として、1988 年のナプロキセン・トルメチンとの単盲検クロスオーバー試験（28 例）と、1983 年の小児コホート研究があります。いずれも古く小規模で、エビデンスレベルは L3 です。
- 機序（COX 阻害による関節の炎症・疼痛の症状緩和）とは整合します。ただし既存の抗炎症・鎮痛作用の延長にあたり、新規性は限定的です。
- 再利用候補として優先的に検討する場合は、こちらを独立して評価するのが現実的です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

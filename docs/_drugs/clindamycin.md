# クリンダマイシン：抗菌薬から点状表層角結膜炎へ

## 一言要約

クリンダマイシンは細菌の 50S リボソームでのタンパク質合成を阻害する抗菌薬で、日本ではダラシン等の製品名で市販されています。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測していますが、この疾患を直接支持する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

| 項目 | 内容 |
|------|------|
| 予測新規適応症 | 点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis) |

| エビデンスレベル | L5 |

| 承認番号数 | 5 件 |

## この予測が妥当である理由

クリンダマイシンは細菌の 50S リボソームに作用してタンパク質合成を阻害する抗菌薬です。詳細な作用機序データは今回の入力に含まれていません。

点状表層角結膜炎は、主に非細菌性の眼表面疾患です。抗菌作用と直接結びつく機序は示されておらず、この予測は TxGNN のスコアだけに依存しています。

## 結論と次のステップ

**決定：Hold**

**理由：**
最上位の予測（点状表層角結膜炎）には臨床試験も文献もなく、根拠は TxGNN のスコアのみ（L5）です。安全性データも未取得のため、S0 段階から先に進められません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現時点で安全性スクリーニングの妨げ）
- DrugBank から詳細な作用機序データ（MOA）を取得
- 点状表層角結膜炎に対する臨床試験・文献の再検索
- 眼科用途に必要な投与経路（点眼など）と、日本の既存剤形（経口・注射・ローション）との適合性評価

本結果は研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的な検証を経て初めて適用できます。

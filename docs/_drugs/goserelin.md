# ゴセレリン：無月経（化学療法に伴う卵巣機能不全の予防）への再利用評価

## 一言要約

ゴセレリンは GnRH アゴニストで、日本では「ゾラデックス」として 3 製剤が市販されています。ただし、Evidence Pack には既存適応症の記載がありません。
TxGNN モデルは**無月経 (amenorrhea)** を最上位に予測しています。実際の内容は「無月経の治療」ではなく、**化学療法中の卵巣保護・卵巣機能抑制**で、無月経は治療中に起きる効果であり評価指標でもあります。
この方向性を **7 件の臨床試験**と **19 編の文献**が支持しており、完了済みの Phase 3 試験が 3 件あります。

## この予測が妥当である理由

ゴセレリンは GnRH アゴニストで、下垂体-性腺軸を抑制し、可逆的な卵巣機能の休止を引き起こします。DrugBank の作用機序 (MOA) フィールドは未取得ですが、この作用は文献でも確認されています。

無月経はこの作用の結果として現れる現象です。そのため本予測は、抗癌化学療法を受ける閉経前女性の卵巣を保護する用途（早発閉経・卵巣不全の予防）と、月経を止める目的での卵巣抑制に限って妥当と考えられます。文献にも、乳癌の術後療法での卵巣抑制、子宮内膜症、思春期の重度子宮出血での月経抑制といった使用例があります。

一方、卵巣機能がすでに失われた早発卵巣不全に対しては、ゴセレリンによるゴナドトロピン抑制で回復しなかったという報告があります（PMID 2522795）。適用範囲は「予防・抑制」に限定する必要があります。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
化学療法中の卵巣保護について、完了した Phase 3 試験が 3 件あり、エビデンスレベルは L1 です。ただし、無月経は治療対象の疾患ではなく作用の結果であり、適用は「閉経前女性の化学療法中の卵巣保護・卵巣抑制」に限定すべきです。

なお、TxGNN の 2 位・3 位の予測（腎低形成、両側腎低形成）は、臨床試験も文献もなく、機序的な関連も知られていないため、**Hold（L5）**とします。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得する（現状は安全性スクリーニングを進められないブロッキング項目）
- DrugBank から作用機序 (MOA) を取得し、機序面の裏付けを補う
- 日本の承認適応症（承認番号ごとの効能・効果）を確認し、適用範囲との関係を整理する
- 薬物相互作用の照会結果が 0 件（not_found）のため、再照会して確認する
- 剤形・投与経路の適合性を確認する
- 適用対象を「化学療法中の卵巣保護・卵巣抑制」に限定する運用条件を明記する

なお、本結果は研究参考用であり、医療上の助言ではありません。予測される適応症は臨床的な検証を経て初めて実用に供されます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

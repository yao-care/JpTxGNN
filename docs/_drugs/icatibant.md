# Icatibant：遺伝性血管性浮腫から C1 Inhibitor Deficiency へ

## 一言まとめ

Icatibant（イカチバント） は、もともと遺伝性血管性浮腫(HAE)の急性発作に対する症状治療に用いられています。
TxGNN モデルは、本剤が **C1 Inhibitor Deficiency** に有効である可能性を予測しています。
現在、**22 件の臨床試験** と **13 件の文献** がこの方向性を支持しており、エビデンスは十分です。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 日本の承認適応症は本サイトのデータに未収載（知識グラフ上の適応症：hereditary angioedema、hereditary angioedema with C1Inh deficiency） |
| 予測新適応症 | C1 Inhibitor Deficiency |
| TxGNN 予測スコア | 99.99% |
| エビデンスレベル | L1 |
| 日本市販状況 | 本サイトのデータに未収載 |
| 承認番号数 | — |
| 推奨判断 | Proceed |

## この予測が妥当な理由

Icatibant はブラジキニン B2 受容体拮抗薬(Bradykinin B2 Receptor Antagonist)であり、ブラジキニンの作用を阻害することで、血管透過性の亢進に起因する浮腫を軽減します。C1 エステラーゼ阻害因子が欠乏すると、血漿中のブラジキニン系が異常に活性化され、過剰なブラジキニンが産生されて血管性浮腫を引き起こします。

この予測は、作用機序の面から非常に妥当です。その理由は次のとおりです。
1. C1 Inhibitor Deficiency は、遺伝性血管性浮腫の根本的な原因である
2. Icatibant は、ブラジキニンを介した血管透過性の亢進を直接阻害する
3. この適応症は、本来の承認適応症(HAE 急性発作)と病態生理学的に完全に一致している

## 安全性に関する考慮事項

- **薬物相互作用**：
  - **主な相互作用**：ACE 阻害薬(Benazepril、Captopril、Enalapril、Lisinopril、Perindopril、Trandolapril、Moexipril)（中等度）
  - **作用機序の説明**：Icatibant は ACE 阻害薬の降圧効果を低下させる可能性がある

- **よくみられる副作用**：注射部位反応（紅斑、腫脹）

## 結論と次のステップ

**判断：Proceed**

**理由：**
この予測は、本来の承認適応症と高い一致を示しています。Icatibant は C1 エステラーゼ阻害因子の欠乏による HAE 急性発作に対して承認されており、C1 Inhibitor Deficiency はまさにこの疾患の根本的な原因です。多数の臨床試験および文献が、その有効性と安全性を支持しています。

**現在の状況：**
- 十分な臨床的エビデンスによる裏付けがある
- 海外の一部の国では承認されている適応症であり、日本での承認は本サイトのデータでは確認できない
- 臨床実践に直接応用できる

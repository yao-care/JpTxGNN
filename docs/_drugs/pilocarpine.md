# ピロカルピン：緑内障・シェーグレン症候群から原発性遺伝性緑内障へ

## 一言要約

ピロカルピンはムスカリン受容体作動薬で、元々緑内障およびシェーグレン症候群（唾液分泌促進）に使用されていました。
TxGNN モデルは**原発性遺伝性緑内障 (Primary Hereditary Glaucoma)** に有効である可能性を予測していますが、
現時点で支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

| 既存適応症 | 緑内障、シェーグレン症候群 |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、ピロカルピンはムスカリン受容体作動薬として知られています。毛様体筋と虹彩括約筋を収縮させ、線維柱帯からの房水流出を広げて眼圧を下げます。この作用は緑内障全般に対して機序的に妥当です。

既存適応症の緑内障と、予測された原発性遺伝性緑内障は、どちらも眼圧上昇による視神経障害を特徴とする疾患群です。そのため、眼圧を下げる作用が応用できる可能性があります。

ただし、原発性遺伝性緑内障（先天性・若年性など）に特化したエビデンスは今回のデータにありません。TxGNN スコアも予測値にとどまります。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の関連）**：TxGNN の知識グラフ (PrimeKG) では、以下の疾患との禁忌関係が示されています。添付文書の記載ではないため、確認が必要です。
  - 眼疾患：閉塞隅角緑内障（急性閉塞隅角を含む）、虹彩炎、虹彩毛様体炎、ぶどう膜炎、角膜炎、角結膜炎、網膜剥離
  - 呼吸器疾患：喘息、慢性閉塞性肺疾患（COPD）、気管支疾患
  - 胆道・肝疾患：胆石症（胆嚢結石、総胆管結石を含む）、胆嚢炎、胆道疾患、閉塞性黄疸、肝不全
  - 腎疾患：腎結石、急性尿酸腎症
- **薬物相互作用**：データ上、100 件の相互作用が登録されています。主なものは以下のとおりです。
  - 中等度：抗コリン薬（ヒヨスチアミン、アトロピン（点眼を含む）、グリコピロニウム、クリジニウム、ジシクロベリン、メペンゾラート、メスコポラミン、プロパンテリン、スコポラミン（点眼を含む）、トロスピウム）
  - 重症度不明：パントプラゾール、クロトリマゾール、モルヒネ、メトホルミン、オメプラゾール、ランソプラゾール、エピネフリン

  ムスカリン作動薬と抗コリン薬は作用が拮抗するため、併用時は効果の減弱に注意が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、支持する臨床試験・文献がなく、エビデンスはモデル予測のみ（L5）です。
- 日本での承認は取り消し済みで、添付文書の警告・禁忌も未確認のため、安全性評価に進めません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（ブロッキング事項）
- DrugBank からの詳細な作用機序データ（MOA）の取得
- 原発性遺伝性緑内障に関する臨床試験・文献の調査
- 閉塞隅角緑内障など、眼科領域の禁忌関連の精査
- 剤形（点眼など）と投与経路の適合性の評価

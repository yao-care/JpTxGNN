# ピロカルピン：緑内障から原発性遺伝性緑内障へ

## 一言要約

ピロカルピンはムスカリン受容体作動薬で、日本ではすでに緑内障とシェーグレン症候群の治療に使われています。
TxGNN モデルは**原発性遺伝性緑内障 (Primary Hereditary Glaucoma)** に有効である可能性を予測しています。
ただし、支持する臨床試験と文献は **0 件**で、モデル予測のみの段階です。
また、既承認の「緑内障」と重なる部分が大きく、新規性は限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) は Evidence Pack に含まれていません。日本の承認情報では、ピロカルピンはムスカリン受容体作動薬に分類されています。

ピロカルピンはムスカリン M3 受容体を刺激して毛様体筋を収縮させ、線維柱帯からの房水流出を増やして眼圧を下げると考えられます。この機序は緑内障全般に当てはまるため、原発性遺伝性緑内障にも機序的には適用可能です。

ただし、日本ではすでに「緑内障」の適応があります。今回の予測は、その一般的な適応の下位にあたる病型を指している可能性があります。これは新しい疾患領域への再利用というより、既存適応の細分化に近いと考えられます。この点は、実際の価値を評価する際に考慮が必要です。

# Naftifine：皮膚真菌症から皮膚カンジダ症へ

## 一言まとめ

Naftifine（ナフチフィン）はアリルアミン系の外用抗真菌薬で、皮膚真菌感染症の治療に用いられます。**皮膚カンジダ症 (cutaneous candidiasis)** と**癜風 (pityriasis versicolor)** は TxGNN が予測した適応症で、海外の一部の国では承認されている適応症ですが、日本での承認は本サイトのデータでは確認できません。十分な文献的裏付けがあります。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 日本の承認適応症は本サイトのデータに未収載（知識グラフ上の適応症：tinea pedis、tinea corporis、tinea infection、dermatophytosis of groin and perianal area） |
| 予測新適応症 | 皮膚カンジダ症、癜風、Majocchi 肉芽腫 |
| TxGNN 予測スコア | 99.84% (皮膚カンジダ症), 99.68% (癜風) |
| エビデンスレベル | L1 |
| 日本市販状況 | 本サイトのデータに未収載 |
| 承認番号数 | — |
| 推奨判断 | Validate |

## この予測が妥当な理由

Naftifine はスクアレンエポキシダーゼ（squalene epoxidase）を阻害することでエルゴステロールの合成を遮断し、真菌の細胞膜の完全性を損ないます。

**作用機序による裏付け：**
- 皮膚糸状菌（dermatophytes）に対して強力な殺菌活性を示す
- カンジダ属（Candida spp.）に対して静菌活性を示す
- マラセチア（Malassezia）に有効で、癜風の治療が可能
- 軽度の抗炎症作用を有する

これらの予測適応症は、海外の一部の国では承認されている適応症であり、日本での承認は本サイトのデータでは確認できません。

## 臨床試験エビデンス

専用の RCT 登録はないものの、複数の非盲検試験で有効性が確認されています。

## 安全性に関する考慮事項

**主な副作用：**
- 局所の灼熱感（6.8%）
- 局所刺激
- 皮膚乾燥
- 紅斑

**禁忌：**
- Naftifine または他のアリルアミン系薬剤に対する過敏症

**使用上の注意：**
- 外用のみ
- 眼および粘膜への接触を避ける
- 著しい刺激が現れた場合は中止する

## 結論と次のステップ

**判断：Validate**

**理由：**
TxGNN が予測した「皮膚カンジダ症」と「癜風」は、naftifine について海外の一部の国では承認されている適応症（「表皮カンジダ症」と「癜風」）であり、日本での承認は本サイトのデータでは確認できません。文献は有効性を裏付ける十分なエビデンスを提供しています。この予測は新発見というよりも、既存適応症の確認といえます。

**推進に必要な事項：**
- この薬剤はすでに予測適応症に対して承認されている
- 追加の検証研究は不要
- 添付文書に従ってそのまま使用可能

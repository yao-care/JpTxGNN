# ポナチニブ：慢性骨髄性白血病から歯肉線維腫症へ

## 一言要約

ポナチニブは多標的チロシンキナーゼ阻害薬で、元々 BCR-ABL1 陽性の慢性骨髄性白血病の治療に使用されていました。
TxGNN モデルは**歯肉線維腫症 (Fibromatosis, Gingival)** に有効である可能性を予測していますが、この予測を裏付ける臨床試験・文献は現時点でありません。
なお、2 番目の予測候補である**脂肪肉腫 (Liposarcoma)** については、前臨床（in vitro）の文献が 1 編あります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 慢性骨髄性白血病（BCR-ABL1 陽性） |
| 予測新規適応症 | 歯肉線維腫症 (Fibromatosis, Gingival) |
| TxGNN 予測スコア | 99.04% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認整理済みのみ（現在は市販されていません） |
| 承認番号数 | 1 件（失効・整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ポナチニブは BCR-ABL、FGFR、PDGFR、VEGFR、SRC を標的とする多標的チロシンキナーゼ阻害薬として知られており、慢性骨髄性白血病での有効性が示されています。

これらのキナーゼは線維芽細胞の増殖や細胞外マトリックスの沈着にも関与するため、理論上は歯肉線維腫症の病態に影響し得ます。ただし、この関連付けは TxGNN の予測に基づくもので、臨床・文献による裏付けはありません。

### 参考：第 2 候補（脂肪肉腫）

脂肪肉腫 (Liposarcoma) の TxGNN 予測スコアは 99.00% です。ポナチニブが阻害する FGFR、PDGFR、SRC ファミリーキナーゼは、前臨床のキナーゼプロファイリング研究で脂肪肉腫の治療標的候補とされており、間接的な前臨床の裏付けがあります（エビデンスレベル L4、推奨は Hold）。

## 文献エビデンス（参考：脂肪肉腫）

歯肉線維腫症については、現在、関連する臨床試験の登録および文献はありません。第 2 候補の脂肪肉腫については次の文献が 1 編あります。

## 細胞毒性

ポナチニブは抗腫瘍薬（分子標的薬：チロシンキナーゼ阻害薬）です。詳細な細胞毒性関連データはないため、添付文書の警告および注意事項を参照してください。

## 安全性に関する考慮事項

**薬物相互作用**（100 件の相互作用情報のうち、主なもの）：
- **Major**：アセチルサリチル酸、クラリスロマイシン
- **Moderate**：ロペラミド、アプレピタント、デキサメタゾン、ナルデメジン、ナルトレキソン、メトロニダゾール、ミコナゾール
- **Minor**：H2 ブロッカー（ファモチジン、ラニチジン、シメチジン、ニザチジン）、プロトンポンプ阻害薬（オメプラゾール、ランソプラゾール、ラベプラゾール、パントプラゾール、デクスランソプラゾール）、酸化マグネシウム、ナロキセゴル

## 結論と次のステップ

**決定：Hold**

**理由：**
歯肉線維腫症への適用は TxGNN の予測のみで、臨床試験も文献もなく（L5）、日本での承認も整理済みです。安全性の根拠となる添付文書情報も未確認のため、現段階で先に進めることはできません。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と安全性スクリーニング
- 詳細な作用機序データ（MOA）の取得（DrugBank）
- 歯肉線維腫症におけるキナーゼ経路の関与を示す前臨床研究
- 第 2 候補（脂肪肉腫）についても、前臨床エビデンスの追加と臨床的関連性の評価
- 日本での供給・承認状況の再確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

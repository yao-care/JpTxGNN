# ケトチフェン 1mg カプセル：評価実施不可 — データ不足により TxGNN 予測未実施

## 一言要約

ケトチフェン（Ketotifen）は抗ヒスタミン薬・肥満細胞安定薬として、アレルギー性疾患の予防に広く用いられる薬物です。今回の評価では、日本 PMDA での承認記録が 0 件、かつ TxGNN 予測に必要な既存適応症データが取得できなかったため、**老薬新用予測を実施できませんでした**。DrugBank では 1 件の検索ヒットが確認されましたが、DrugBank ID の紐付けに失敗しており、評価継続にはデータ補完が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
PMDA 検索ヒットが 0 件のため既存適応症が特定できず、TxGNN 老薬新用予測のインプットとなるデータが揃っていません。DrugBank では 1 件のレコードが検索されましたが DrugBank ID の取得に失敗しており、MOA・安全性・適応症のいずれも未取得の状態です。評価を開始できる状態にありません。

**進める場合に必要なもの：**

- **PMDA 再検索**：クエリを一般名「ケトチフェン」に変更し、承認番号・適応症・仿単を取得する
- **DrugBank ID の特定**：「Ketotifen」（英文 INN）で DrugBank API を再クエリし、DrugBank ID（例：DB00920）を確定させる
- **MOA データの取得**：DrugBank の mechanism of action フィールドから作用機序を補完する（H1 受容体拮抗・肥満細胞安定化の確認）
- **安全性データの補完**：PMDA 仿単 PDF をダウンロードし、警告・禁忌・相互作用を解析する（DG001 解消）
- **TxGNN 予測の再実施**：上記データ取得後、承認適応症を入力として予測パイプラインを再実行する

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による予測適応症が存在せず、DrugBank から取得したデータも Evidence Pack に反映されていないため、老藥新用評価の根拠となる情報が揃っていません。日本での承認実績もないことから、現段階では評価を進めることができません。

**進めるために必要なもの：**

2. **TxGNN 予測の再実行** — DrugBank ID（例：`DB00741` / ketotifen）が取得できれば、KG 予測・DL 予測いずれも実行可能
3. **PMDA 添付文書の取得** — 承認記録なしの場合、海外（例：EMA・FDA）の添付文書で代替安全性データを収集する
4. **薬物名の正規化確認** — 入力値 `ケトチフェン点鼻液０．０５％` は剤形・濃度を含む商品記述であり、INN（国際一般名）`ketotifen` への変換が各収集器で正しく行われているか確認する

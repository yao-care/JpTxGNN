# ロキソプロフェンナトリウムパップ1：評価データ不足により判定保留

## 一言要約

ロキソプロフェンナトリウムパップ1は薬物再利用評価の対象として登録されましたが、現時点では既存適応症・予測新規適応症ともにデータが存在しません。日本での市販情報も確認されておらず、安全性データも未取得のため、評価を進めるには追加データの収集が必要です。なお、DrugBank クエリでは 1 件のヒットが確認されており、ID の確定後に予測を再実行できる可能性があります。

---

| 項目 | 内容 |
|------|------|
| 既存適応症 | データなし |
| 予測新規適応症 | データなし（TxGNN 予測未実施） |
| TxGNN 予測スコア | — |
| エビデンスレベル | 評価不可 |
| 日本市販状況 | 未上市 |
| 承認番号数 | 0 件 |
| 推奨決定 | Hold |

## 結論と次のステップ

**決定：Hold**

**理由：**
既存適応症・TxGNN 予測結果・安全性データのいずれも取得できておらず、再利用可能性の評価を行うための基礎データが揃っていません。また、PMDA クエリが 0 件を返しており、クエリ文字列（半角カタカナ＋末尾の「1」）の正規化が必要な可能性があります。

**進める場合に必要なもの：**
- **DrugBank ID の確定**：DrugBank クエリでは 1 件ヒット済み（`query_log` id=2）。マッチした候補を確認し `drugbank_id` を登録する
- **クエリ文字列の正規化**：`ﾛｷｿﾌﾟﾛﾌｪﾝﾅﾄﾘｳﾑﾊﾟｯﾌﾟ1` を全角カタカナ（ロキソプロフェンナトリウムパップ）に変換し、末尾の「1」が規格番号かどうかを確認した上で PMDA を再クエリする
- **作用機序（MOA）データの取得**：DrugBank API から pharmacology/mechanism-of-action を取得する
- **安全性情報の取得**：PMDA 仿単 PDF をダウンロードして警語・禁忌・相互作用を解析する
- **TxGNN 予測の再実行**：DrugBank ID 確定後、`run_kg_prediction.py` を再実行して予測候補を生成する

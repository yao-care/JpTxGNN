## 一言要約

ニカルジピンエン（`ﾆｶﾙｼﾞﾋﾟﾝｴﾝ`）は PMDA データベースへの照会で承認情報が 0 件でした。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による新規適応症予測が得られておらず、既存適応症・作用機序・安全性データのいずれも確認できないため、老藥新用の評価を進める根拠がありません。なお、薬物名 `ﾆｶﾙｼﾞﾋﾟﾝｴﾝ`（半角カタカナ）は PMDA の正式表記と一致していない可能性があり、データ取得失敗の主因として疑われます。

**進める場合に必要なもの：**

- **【最優先】薬物名の確認**：`ﾆｶﾙｼﾞﾋﾟﾝｴﾝ` が正しい INN かを検証（ニカルジピン塩酸塩 `nicardipine hydrochloride` と同一か？）し、全角カタカナで PMDA を再クエリ
- **DG001 解消**（Blocking）：PMDA 仿単 PDF をダウンロードし、警語・禁忌を解析
- **DG002 解消**（High）：DrugBank API で作用機序（MOA）を取得（DrugBank では 1 件のヒットあり）
- **TxGNN 再実行**：上記情報補完後、KG 予測および DL 予測パイプラインを再実行して適応症候補を生成

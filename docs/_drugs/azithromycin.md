# アジスロマイシン：歯周組織炎・MAC症などの感染症から高アミラーゼ血症へ

## 一言要約

アジスロマイシンはマクロライド系の抗生物質（タンパク質合成阻害薬）で、日本では歯周組織炎、マイコバクテリウム・アビウムコンプレックス（MAC）症、結膜炎、眼瞼炎などに使われています。
TxGNN モデルは**高アミラーゼ血症 (Hyperamylasemia)** に有効な可能性を予測していますが、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。アジスロマイシンはマクロライド系抗生物質で、細菌のタンパク質合成を阻害します。これは日本の承認情報にある分類「抗生物質、タンパク質合成阻害薬」と一致します。

一方、高アミラーゼ血症は血中アミラーゼ値が高いという検査上の異常で、感染症のように病原体を標的にする疾患ではありません。アジスロマイシンとこの状態を結ぶ確立した機序はなく、今回の関連付けは知識グラフに基づくモデル予測だけが根拠です。スコアが非常に高くても、機序的な裏付けにはなりません。

同じ 99.8% 台には、多クローン性高粘稠度症候群など性質の異なる候補も並んでいます。スコアの高さだけで有望と判断するのは避け、まず機序仮説の検討と文献調査が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
高アミラーゼ血症については臨床試験も文献もなく、機序的な根拠もないため、L5（モデル予測のみ）にとどまります。日本の添付文書に基づく安全性情報も未取得で、次の段階に進める状態ではありません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と整理。これが未取得のため安全性スクリーニングに進めません（最優先）
- DrugBank などからの作用機序データ取得
- 高アミラーゼ血症とアジスロマイシンに関する PubMed・臨床試験の再検索
- 高アミラーゼ血症が治療対象の疾患として妥当かの確認（原因疾患の治療と検査値異常のどちらを狙うのかの整理）

参考として、同じ予測リスト内には、多発性骨髄腫細胞でマクロライドがオートファジーを阻害しボルテゾミブの効果を高めるという in vitro 研究がある**単クローン性ガンマグロブリン血症**（L4）があります。鎌状赤血球症の試験（いずれも登録 0 名で中止）がある**先天性血液疾患**（L4）も、別途検討する価値があります。

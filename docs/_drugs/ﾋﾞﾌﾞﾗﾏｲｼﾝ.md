# ビブラマイシン：評価不能 ― データ不足により予測適応症なし

## 一言要約

ビブラマイシン（ﾋﾞﾌﾞﾗﾏｲｼﾝ）は PMDA データベースで登録情報が見当たらず、DrugBank では 1 件のマッチが確認されましたが、DrugBank ID・既存適応症・作用機序のいずれも本 Evidence Pack には含まれていません。TxGNN モデルによる予測適応症は生成されておらず、現時点では老薬新用評価を実施できる情報基盤が整っていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID・既存適応症・作用機序・TxGNN 予測適応症のいずれも取得できていないため、老薬新用評価を実施する基盤情報が根本的に不足しています。

**進める場合に必要なもの：**
- 薬物名の確認：ﾋﾞﾌﾞﾗﾏｲｼﾝ が正規 INN または品名として正しいかどうかを確認（全角カタカナ / CAS 番号 / 英語名での再検索）
- DrugBank ID の特定および MOA データの取得（DrugBank API 経由）
- PMDA 照会による既存適応症・警告・禁忌の確認（PMDA 仿単 PDF 解析）
- 上記情報が揃った後、TxGNN モデルへ再投入し予測適応症を生成
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

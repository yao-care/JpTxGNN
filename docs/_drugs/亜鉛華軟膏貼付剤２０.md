# 亜鉛華軟膏貼付剤２０％：新規適応症の予測データなし

## 一言要約

亜鉛華軟膏貼付剤２０％は酸化亜鉛（Zinc Oxide）を主成分とする外用貼付剤です。
今回の評価では、TxGNN モデルによる新規適応症の予測が得られず、日本国内での承認実績も確認されませんでした。
DrugBank への照合で 1 件のマッチが得られたものの、DrugBank ID の紐付けが完了しておらず、現時点では再利用候補としての定量的評価が困難な状況です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN モデルによる新規適応症の予測が得られておらず、日本での承認実績・安全性データ・作用機序データのいずれも未取得であるため、現時点での再利用評価を進めることができません。

**進める場合に必要なもの：**
- DrugBank ID の確定（照合結果 1 件あり、手動確認が必要）
- 作用機序（MOA）データの取得（DrugBank API より）
- PMDA 承認情報の再確認（一般名「酸化亜鉛」「亜鉛華」などで再クエリ）
- TxGNN モデルへの再投入（DrugBank ID 確定後）
- 安全性情報の収集（PMDA 添付文書 PDF の解析）

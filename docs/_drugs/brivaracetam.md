## Brivaracetam：局所てんかんから視覚性てんかんへ
{: .text-alpha }

## 一言まとめ
Brivaracetam（ブリバラセタム） は本来、局所てんかん発作の治療に用いられる第三世代の抗てんかん薬ですが、TxGNN は視覚性てんかん (visual epilepsy) に対する治療の可能性を予測しています。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 日本の承認適応症は本サイトのデータに未収載（知識グラフ上の適応症：partial epilepsy、partial motor epilepsy） |
| 予測新適応症 | 視覚性てんかん (visual epilepsy) |
| TxGNN 予測スコア | 99.51% |
| エビデンスレベル | L3 (観察研究／光感受性研究) |
| 日本市販状況 | 本サイトのデータに未収載 |
| 承認番号数 | — |
| 推奨判断 | Proceed |

## この予測が妥当な理由
Brivaracetam は levetiracetam の構造類似体であり、独自の作用機序を有します。

1. **SV2A への高親和性結合**：brivaracetam のシナプス小胞タンパク質 2A (SV2A) に対する親和性は、levetiracetam の 15-30 倍です
2. **速やかな脳内移行**：高い脂溶性により、中枢神経系へ速やかに移行します
3. **光感受性てんかんの研究**：brivaracetam が光刺激により誘発される脳波異常反応 (PPR) を抑制することが、臨床研究で確認されています
4. **広域スペクトルの抗てんかん活性**：非臨床研究で、多様なてんかんモデルに有効であることが示されています

視覚性てんかんは光感受性てんかんと関連しており、この領域では brivaracetam を支持する予備的な臨床エビデンスがあります。

## 臨床試験エビデンス
視覚性てんかんを直接対象とした臨床試験はありませんが、関連する光感受性の研究が支持的なエビデンスを提供しています。

**第II相 光感受性モデル研究 (2007)**
- Kasteleijn-Nolst Trenite らが *Neurology* に発表
- brivaracetam が光刺激により誘発される異常脳波反応を有効に抑制することを確認
- 中枢神経系への速やかな作用を示した

**Levetiracetam との比較研究 (2020)**
- Reed RC らが *CNS Drugs* に発表
- 二重盲検、無作為化、クロスオーバー試験
- 光感受性てんかん患者において、brivaracetam の速やかな効果発現時間を確認

## 文献エビデンス
PubMed の検索で、複数の関連文献が見つかりました。

   - brivaracetam の高い脳内移行性と速やかな効果発現の特性を確認

## 安全性に関する考慮事項
### 主な副作用
- 傾眠、めまい
- 疲労感
- 悪心

### 利点
- levetiracetam より副作用が軽度
- 行動・精神面の副作用の発現率が低い
- 用量調整なしで目標用量から開始可能

### 薬物相互作用
- CYP2C19 が関与する代謝を受ける
- rifampin により血中濃度が低下する可能性がある
- アルコールとの併用を避ける

## 結論と次のステップ
**エビデンスレベル**：L3 (光感受性てんかんの臨床研究による間接的な支持)

**推奨**：
1. 光感受性てんかんまたは視覚誘発性てんかんの患者では、brivaracetam は妥当な治療選択肢である
2. levetiracetam からの切り替えを検討できる。特に患者に行動面の副作用がある場合
3. 推奨用量：成人で1日 50-200 mg、1日2回に分けて服用

**今後の研究の方向性**：
- 視覚性てんかんのサブタイプを対象とした前向き臨床試験
- 本適応症における brivaracetam と他の第三世代抗てんかん薬との比較有効性の評価
- 適応拡大を裏付けるリアルワールドデータの収集

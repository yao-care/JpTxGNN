# ペムブロリズマブ：非小細胞肺癌・悪性黒色腫から歯肉線維腫症へ

## 一言要約

ペムブロリズマブは抗 PD-1 抗体で、元々非小細胞肺癌（NSCLC）や転移性悪性黒色腫などの治療に使用されていました。
TxGNN モデルは**歯肉線維腫症 (Fibromatosis, Gingival)** に有効である可能性を予測していますが、この予測を支持する臨床試験や文献は今回のデータにはなく、**モデル予測のみ**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 非小細胞肺癌、肺癌、転移性悪性黒色腫（知識グラフ上の適応症。日本の承認適応症テキストは未登録） |
| 予測新規適応症 | 歯肉線維腫症 (Fibromatosis, Gingival) |
| TxGNN 予測スコア | 99.40% |
| エビデンスレベル | L5 |
| 日本市販状況 | 取消のみ（有効な承認なし） |
| 承認番号数 | 1 件（取消済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データは登録されていません。ただし既知の情報では、ペムブロリズマブは PD-1（PDCD1、CD279）を標的とするヒト化抗体で、PD-1 を阻害して腫瘍に対する T 細胞の抗腫瘍活性を回復させる免疫チェックポイント阻害薬です。

一方、歯肉線維腫症は腫瘍ではない線維性の過成長です。PD-1 シグナルとの機序的なつながりを示す根拠はなく、既存適応症（悪性腫瘍）との関連性も見いだせません。TxGNN のスコアは高いものの、機序面・臨床面の裏付けはなく、予測の妥当性は現時点で支持されません。

## 安全性に関する考慮事項

- **薬物相互作用**（13 件を確認）：
  - **重大 (Major)**：レナリドミド、ポマリドミド、サリドマイド
  - **中等度 (Moderate)**：コルチコステロイド系薬（ヒドロコルチゾン、トリアムシノロン、デキサメタゾン、ベタメタゾン、ブデソニド、プレドニゾロン、プレドニゾン、メチルプレドニゾロン、デフラザコート）。免疫抑制作用により効果が減弱する可能性があります。
- その他の警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測を支持する臨床試験・文献がなく、モデル予測のみ（L5）です。歯肉線維腫症は非腫瘍性の線維性疾患で、PD-1 阻害との機序的関連も見られません。また、日本の承認は取消済みで、添付文書ベースの安全性情報も未確認です。

**進める場合に必要なもの：**
- 歯肉線維腫症と PD-1 経路を結ぶ機序的・前臨床エビデンス
- 詳細な薬物作用機序データ（MOA）の補充
- 添付文書（警告・禁忌）の確認と安全性スクリーニング
- 関連する臨床試験・文献の再検索

**参考：他の予測候補について**
同じ薬物の予測上位 10 件のうち、肺門部肺癌（L4、症例報告のみ）、肺良性腫瘍（L4、悪性 NSCLC/SCLC の文献は間接的）、肺胚細胞腫瘍（L4、間接的な試験のみ）などの肺関連疾患は、歯肉線維腫症よりも機序的な関連性があります。ただし、いずれも直接的な臨床エビデンスは不十分で、推奨は Hold または Research Question にとどまります。

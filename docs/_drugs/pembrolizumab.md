# ペムブロリズマブ：抗 PD-1 抗体（がん免疫療法）から歯肉線維腫症へ

## 一言要約

ペムブロリズマブは抗 PD-1 抗体で、日本では「キイトルーダ」として市販されている、がん免疫療法薬です。
TxGNN モデルは**歯肉線維腫症 (Fibromatosis, Gingival)** に有効である可能性を予測しています（予測スコア 99.40%）。
ただし、この方向性を支持する**臨床試験は 0 件、文献も 0 編**で、根拠はモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ペムブロリズマブは PD-1 と PD-L1/PD-L2 の結合を阻害し、T 細胞の抗腫瘍免疫を回復させる抗体医薬です。がんでの有効性は確立していますが、その機序が歯肉線維腫症に当てはまるかどうかはわかりません。

歯肉線維腫症は、歯肉が良性の線維性組織で過剰に増殖する疾患です。PD-1 遮断が関与する免疫回避や腫瘍免疫の機序は、この疾患では確認されていません。今回の予測は知識グラフ上の関連性に基づくもので、機序的な裏付けは現時点で見当たりません。

## 結論と次のステップ

**決定：Hold**

**理由：**
歯肉線維腫症に対する臨床試験も文献もなく、機序的な根拠も示されていません（L5）。良性疾患に免疫関連有害事象のリスクがある薬剤を使う正当性は、現状では説明できません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現状は安全性スクリーニングに進めない状態です）
- DrugBank からの作用機序データの補充
- 歯肉線維腫症における PD-1/PD-L1 経路の関与を示す前臨床データまたは機序研究
- 同じ Evidence Pack 内の他の候補（肺門部肺癌、肺胚細胞腫瘍などの胸部悪性腫瘍）は L4 で、機序的な妥当性が高くなっています。優先的に評価する価値があります。

# バンコマイシン点滴：評価データ不足のため予測不能

## 一言要約

バンコマイシン点滴（`ﾊﾞﾝｺﾏｲｼﾝﾃﾝﾃｷ`）は、本 Evidence Pack において PMDA クエリが 0 件を返したため、規制情報・安全性情報ともに取得できていません。TxGNN モデルによる新規適応症予測も生成されておらず、薬物再利用評価を継続するための十分なデータがない状態です。薬物名の**半角カタカナエンコーディング**が検索失敗の主因と推測されます。

---

| 項目 | 内容 |
|------|------|

| 日本市販状況 | 未上市（クエリ結果 0 件） |
| 承認番号数 | 0 件 |
| 推奨決定 | Hold |

---

## データ品質診断

本 Evidence Pack には構造的な問題があり、通常の評価レポートを生成できません。以下に問題を整理します。

### 薬物名エンコーディング問題

クエリに使用された薬物名は半角カタカナ（`ﾊﾞﾝｺﾏｲｼﾝﾃﾝﾃｷ`）で、全角に変換すると **バンコマイシン点滴**（Vancomycin injection）となります。PMDA データベースは全角カタカナでの検索を前提としているため、0 件ヒットは検索クエリの文字コード不一致によるものと考えられます。

### クエリ結果サマリー

| クエリ対象 | 結果 | 考察 |
|-----------|------|------|
| PMDA | 0 件 | 半角カタカナが原因の検索失敗と推定 |
| DrugBank | 1 件ヒット（ID 未取得） | 紐付けが完了していない |

### 欠損データ一覧

| データ項目 | 重要度 | 影響 |
|-----------|--------|------|
| PMDA 承認情報 | Blocking | 日本市販状況・適応症が不明 |
| 作用機序（MOA） | High | 機序関連性分析不能 |
| 警告・禁忌 | Blocking | 安全性初評価不能 |
| TxGNN 予測結果 | Blocking | 新規適応症候補なし |

---

## 結論と次のステップ

**決定：Hold**

**理由：**
予測結果・規制データ・安全性情報のいずれも取得できておらず、薬物再利用評価を進める前提条件が満たされていません。データパイプラインの修正が先決です。

**進める場合に必要なもの：**
- **【最優先】薬物名の正規化**：クエリを半角カタカナ `ﾊﾞﾝｺﾏｲｼﾝﾃﾝﾃｷ` から全角 `バンコマイシン` または INN 名 `vancomycin` に変換して PMDA を再検索する
- **DrugBank ID の確定**：DrugBank クエリで 1 件ヒットしているため、該当レコードから ID（推定：`DB00512`）を取得して紐付けを完了する
- **TxGNN 予測の再実行**：薬物名正規化後、DrugBank ID を用いて KG/DL 予測を再実行する
- **安全性情報の補充**：PMDA 仿単 PDF をダウンロードし警告・禁忌を解析する

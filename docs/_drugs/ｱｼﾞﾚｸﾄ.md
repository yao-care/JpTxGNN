# アジレクト：評価保留（予測データなし）

## 一言要約

アジレクト（ｱｼﾞﾚｸﾄ）は日本で未承認の薬物です。今回の Evidence Pack には TxGNN による新規適応症の予測結果が含まれておらず、既存適応症・作用機序・安全性のデータもいずれも未取得のため、現時点では再利用評価を完結させることができません。なお、クエリログによると DrugBank に 1 件の照合結果が存在しており、DrugBank ID の確定と TxGNN 予測の再実行が最優先の次のステップとなります。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による新規適応症の予測データが存在せず、既存適応症・作用機序・安全性データも未取得のため、評価を開始できる状態にありません。日本（PMDA）での承認実績もゼロです。

**評価を再開するために必要なもの：**
- DrugBank ID の確定（DrugBank クエリで 1 件照合済み、内容の展開が必要）
- 作用機序（MOA）データの取得（DrugBank API 照会）
- PMDA 仿単 PDF からの警語・禁忌データの収集
- DrugBank ID 確定後、TxGNN 予測パイプラインの再実行

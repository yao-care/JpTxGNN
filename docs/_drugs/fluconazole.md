# フルコナゾール：カンジダ症・クリプトコッカス症から点状表層角結膜炎へ

## 一言要約

フルコナゾールは抗真菌薬（エルゴステロール合成阻害薬）で、元々カンジダ症とクリプトコッカス症の治療に使用されていました。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測していますが、現時点で裏付けとなる**臨床試験・文献はありません**（モデル予測のみ）。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | カンジダ症、クリプトコッカス症 |
| 予測新規適応症 | 点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis) |
| TxGNN 予測スコア | 99.24% |
| エビデンスレベル | L5 |
| 日本市販状況 | 市販中の承認なし（取消のみ） |
| 承認番号数 | 20 件（すべて取消済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フルコナゾールは真菌の CYP51（ラノステロール 14α-デメチラーゼ）を阻害してエルゴステロール合成を遮断するアゾール系抗真菌薬で、カンジダ症やクリプトコッカス症での有効性が確立しています。

ただし、この機序が関与するのは真菌が原因の病態に限られます。点状表層角結膜炎は、通常ウイルス性（アデノウイルスなど）または中毒性・炎症性であり、抗真菌作用が有効に働く機序的根拠は確立していません。TxGNN の高スコア（99.24%）は、現時点では裏付けのない計算上の予測と考えるべきです。真菌性の症例に限れば、限定的に妥当性を検討する余地はあります。

その他の安全性情報については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測は TxGNN のモデルスコアのみに基づき、臨床試験も文献もありません。さらに、抗真菌機序が非真菌性の角結膜炎に当てはまる根拠が乏しく、日本では有効な承認も残っていません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得（PMDA の添付文書を入手して解析）
- 詳細な作用機序データ（MOA）の補完（DrugBank）
- 点状表層角結膜炎のうち、真菌性など抗真菌薬が合理的に作用しうる病型の特定
- 前臨床・観察研究・症例報告などの文献調査
- 眼科用途に適した投与経路・剤形の検討（現状は経口・注射のみ）
- QT延長や肝腎機能に関する安全性評価、併用薬の相互作用の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

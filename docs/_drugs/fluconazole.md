# フルコナゾール：カンジダ症・クリプトコッカス症から点状表層角結膜炎へ

## 一言要約

フルコナゾールは抗真菌薬（エルゴステロール合成阻害薬）で、元々カンジダ症やクリプトコッカス症の治療に使用されています。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測していますが、
現時点で裏付けとなる臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フルコナゾールは真菌のラノステロール 14α-デメチラーゼ (CYP51) を阻害する抗真菌薬で、カンジダ症やクリプトコッカス症での有効性が確立されています。

一方、点状表層角結膜炎は多くがウイルス性（アデノウイルスなど）または炎症性であり、抗真菌作用と直接結びつく根拠は現時点で見当たりません。機序面での妥当性は確認できていません。

TxGNN の予測スコア（99.24%、順位 4444）は高いものの、これはモデルによる予測にすぎません。実際の研究による裏付けはなく、既存適応症との類似性評価も未実施です。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測はモデル出力のみ（L5）で、臨床試験も文献もありません。フルコナゾールの抗真菌機序と、主にウイルス性・炎症性の点状表層角結膜炎との間に直接の関連も確認できていません。安全性の添付文書情報も未取得のため、現段階では次の評価段階へ進められません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングの前提）
- DrugBank からの作用機序 (MOA) データの取得

# トコフェロール：抗酸化栄養素から硬化性胆管炎へ

## 一言要約

トコフェロール（ビタミン E）は脂溶性抗酸化剤として広く知られており、栄養補助成分として利用されていますが、日本では現時点で医薬品としての承認はありません。
TxGNN モデルは**硬化性胆管炎 (Sclerosing Cholangitis)** に有効である可能性を予測しており、現在 **1 件の臨床試験**と **1 編の文献**がこの方向性を支持しています。
エビデンスは機序的考察と限定的な観察データに留まり、直接的なヒト臨床介入試験は存在しません。

## この予測が妥当である理由

現在、詳細な作用機序データ（MOA）は取得できていません。既知の情報によると、トコフェロールは脂溶性ビタミン E 群に属し、細胞膜の脂質過酸化を抑制してフリーラジカルによる組織傷害を防御することが主な機能です。この抗酸化・抗炎症特性が、硬化性胆管炎の病態との機序的関連性の根拠となります。

硬化性胆管炎では、胆汁うっ滞による脂溶性ビタミン（A・D・E・K）の吸収障害が高頻度に生じ、患者の血中トコフェロール濃度は慢性的に低下しやすい状態にあります。Floreani ら（2000 年）が慢性胆汁うっ滞性肝疾患患者において血漿抗酸化剤レベルの低下を実証したように、酸化由来フリーラジカルが慢性胆管傷害の病因に関与すると考えられています。

機序的には、トコフェロール補充が胆管上皮の酸化損傷を軽減し、進行性の線維化プロセスを緩和できる可能性があります。ただし、これは理論的推論の域を出ておらず、硬化性胆管炎を主要エンドポイントとしたヒト介入試験によるエビデンスは現時点では存在しません。

## 結論と次のステップ

**決定：Hold**

**理由：**
硬化性胆管炎に対するトコフェロールの機序的妥当性は認められるものの、直接的なヒト臨床介入エビデンスが皆無であり（エビデンスレベル L4）、現時点では研究仮説の段階に留まります。日本での承認・市販実績もなく、エビデンス基盤の構築が先決です。

**進める場合に必要なもの：**
- 硬化性胆管炎患者における血清トコフェロール値と疾患進行（ALP・胆管線維化マーカー等）の相関を評価する前向き観察研究
- トコフェロール補充が PSC の炎症・線維化指標に与える影響を検討する探索的 Phase 1/2 試験
- 作用機序（MOA）の詳細データ取得（DrugBank API 照会により DG002 を解消）
- 安全性情報の整備（PMDA 添付文書・警告・禁忌の確認により DG001 を解消）

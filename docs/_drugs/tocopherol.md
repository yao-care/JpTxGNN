# トコフェロール：ビタミンE補充（糖尿病性網膜症・凍瘡）から硬化性胆管炎へ

## 一言要約

トコフェロール（ビタミンE）は、元々ビタミンE補充薬として糖尿病性網膜症や凍瘡の治療に使用されていました。
TxGNN モデルは**硬化性胆管炎 (Sclerosing Cholangitis)** に有効である可能性を予測していますが、現時点で関連する臨床試験はなく、裏付けとなる文献は **1 編**（症例対照研究）にとどまります。
そのため、エビデンスは限定的です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | ビタミンE補充薬（糖尿病性網膜症、凍瘡） |
| 予測新規適応症 | 硬化性胆管炎 (Sclerosing Cholangitis) |
| TxGNN 予測スコア | 98.84% |
| エビデンスレベル | L4 |
| 日本市販状況 | 販売中止のみ（現在市販中の承認なし） |
| 承認番号数 | 5 件（すべて承認整理済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、トコフェロールは脂溶性の抗酸化ビタミンで、脂質の過酸化を抑える働きがあります。ビタミンE補充薬として、糖尿病性網膜症や凍瘡などの酸化ストレス・微小循環が関わる病態で使われてきました。

慢性の胆汁うっ滞性肝疾患では、脂溶性ビタミン（A、D、E、K）の吸収障害が起こり、血漿中の抗酸化物質が低下することが報告されています。また、酸素由来のフリーラジカルが慢性肝障害の発症に関わる可能性も指摘されています。このため、酸化ストレスの軽減という点で、機序的に適用できる可能性があります。

ただし、この関連は間接的な推測です。現時点で、硬化性胆管炎に対するトコフェロールの介入試験はありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
硬化性胆管炎については、臨床試験がなく、文献も胆汁うっ滞性肝疾患での抗酸化物質低下を示す観察研究 1 編のみです。日本では現在市販中の承認もないため、推進するには根拠が不足しています。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得（現状は未確認で、安全性評価に進めない）
- 詳細な薬物作用機序データ（MOA）
- 硬化性胆管炎患者でのビタミンE状態や補充効果を調べる臨床研究・介入試験
- 日本での市販状況の確認（現在は承認整理済みのみ）

# エピナスチン：気管支喘息・アレルギー性鼻炎・尋常性乾癬から酒さ性結膜炎へ

## 一言要約

エピナスチンは H1 受容体拮抗薬（抗アレルギー薬）で、日本では気管支喘息、アレルギー性鼻炎、尋常性乾癬などに使用されています。
TxGNN モデルは**酒さ性結膜炎 (Rosacea Conjunctivitis)** に有効である可能性を予測しています。ただし、現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、エピナスチンは H1 受容体拮抗作用とマスト細胞安定化作用を持つ抗アレルギー薬です。アレルギー性結膜炎の点眼薬としても使われており、アレルギー性疾患での有効性は確立しています。

一方、眼の酒さ（酒さ性結膜炎）の主因は、マイボーム腺機能不全と炎症です。ヒスタミンが主役ではないため、機序上のつながりは間接的です。この予測は、現時点では TxGNN のスコアに依存しています。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測は TxGNN モデルのみに基づいており、臨床試験・文献ともにありません（L5）。機序上のつながりも間接的です。さらに、日本の添付文書の警告・禁忌が未取得のため、安全性評価に進めません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（進行を妨げているデータ不足）
- DrugBank から作用機序 (MOA) データを取得
- 酒さ性結膜炎に関する文献と臨床試験の検索
- 投与経路の適合性確認（日本には点眼液の製品が既にあります）
- 参考：予測順位 2 位の**アレルギー性蕁麻疹 (Allergic Urticaria)**（スコア 99.28%）は、H1 拮抗作用と直接的な機序の一致があります。国内の製造販売後調査 2 件（成人錠剤 2,001 例、小児ドライシロップ 3,793 例）も存在し、L3 相当です。ただしいずれも非ランダム化の観察研究のため、有効性の根拠にはなりません。別途評価する価値があります。

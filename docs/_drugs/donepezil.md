# ドネペジル：アルツハイマー型認知症から心因性運動障害へ

## 一言要約

ドネペジルはアセチルコリンエステラーゼ阻害薬で、元々アルツハイマー型認知症とレビー小体型認知症の治療に使用されています。
TxGNN モデルは**心因性運動障害 (Psychogenic Movement Disorders)** に有効である可能性を予測していますが、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報では、ドネペジルはアセチルコリンエステラーゼ阻害薬に分類され、アルツハイマー型認知症とレビー小体型認知症での有効性が確立されています。この酵素を阻害すると脳内のコリン作動性の働きが高まります。大脳基底核の回路でもこの働きが高まると考えられます。

ただし、認知症と心因性運動障害（機能性運動障害）の間に、機序上の直接的なつながりを示す根拠は見つかっていません。上記のコリン作動性の変化は一般的な薬理作用にすぎず、この疾患に特異的な理由や臨床的な裏づけはありません。

したがって、この予測は現時点ではモデルによる関連付けにとどまります。妥当性を判断するには、機序面と臨床面の追加検証が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
心因性運動障害については、臨床試験も文献もなく、機序上の根拠も乏しいため、TxGNN のスコアが高くても L5（モデル予測のみ）にとどまります。日本の添付文書に基づく警告・禁忌の確認も未完了のため、現時点では先に進められません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。これが未完了のため、安全性スクリーニングに進めません
- 詳細な作用機序データ（MOA）の補充
- 心因性運動障害に特化した文献・臨床試験の再調査
- 剤形・投与経路の適合性の確認

**参考（同じ薬の他の予測候補）：**
今回の予測より、次の 2 つの方が文献の裏づけがあります。優先的に検討する価値があります。
- **慢性チック障害**（L3）：小児での小規模な非盲検試験、症例報告、マウス試験があります。ただし対照群のない小規模データです。
- **舌・顔面・口部ジスキネジア（遅発性ジスキネジア）**（L4）：コクランレビューがありますが、結論は出ていません。ドネペジル単独では症例報告が中心です。

コリンエステラーゼ阻害薬は、パーキンソニズムや振戦を誘発・悪化させる可能性が、2025 年のシステマティックレビューで報告されています。運動障害を対象にする場合は、この安全性シグナルの評価が必要です。

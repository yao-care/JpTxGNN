# ペルツズマブ：既存適応症データなしから 正常乳房様サブタイプ乳癌へ

## 一言要約

ペルツズマブは日本で「パージェタ」として市販されていますが、今回の Evidence Pack には既存適応症の記載がありません。
TxGNN モデルは**正常乳房様サブタイプの乳癌 (normal breast-like subtype of breast carcinoma)** に有効である可能性を予測しています。
このサブタイプを直接検証した研究はなく、**5 件の臨床試験**（いずれも HER2 陽性乳癌が対象）と**文献 0 編**が間接的な根拠です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 予測新規適応症 | 正常乳房様サブタイプの乳癌 (normal breast-like subtype of breast carcinoma) |
| TxGNN 予測スコア | 99.93% |
| エビデンスレベル | L2（Evidence Pack の判定。ただし該当試験は単群 Phase 2 で RCT ではありません） |
| 日本市販状況 | ✓ 市販中 |
| 承認番号数 | 1 件 |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) はありません。Evidence Pack の機序仮説によると、ペルツズマブは HER2 のヘテロ二量体形成を阻害し、下流の PI3K/MAPK シグナルを抑えます。

ただし、正常乳房様は乳癌の内因性サブタイプの分類です。このラベル自体は HER2 依存性を意味しません。登録試験の対象も HER2 陽性乳癌であるため、予測との関連は**間接的**です。

## 結論と次のステップ

**決定：Hold**

**理由：**
このサブタイプは HER2 依存性が確立しておらず、機序上の関連が間接的です。直接の文献もありません。安全性の一次情報（PMDA 添付文書）が未取得で、S1 の安全性スクリーニングに進めません。

**他の予測適応症（参考）：**

| 予測適応症 | エビデンスレベル | Evidence Pack の推奨 |
|-----------|----------------|-------------------|
| プロゲステロン受容体陽性乳癌 | L1 | Proceed with Guardrails |
| プロゲステロン受容体陰性乳癌 | L1 | Proceed with Guardrails |
| 乳腺腫瘍 luminal A/B | L2 | Research Question |
| 外胚葉間葉腫、悪性皮膚顆粒細胞腫瘍など（rank 5–10） | L4–L5 | Hold |

- 上表の乳癌サブタイプ 2 件は、Phase 3 試験や NeoSphere、PERTAIN などの RCT／Phase 2 試験が根拠になっています。優先的に評価する価値があります。
- ただし、これらはいずれも HER2 陽性乳癌という既知の使用領域に重なっている可能性が高く、純粋な新規適応症かどうかは既存適応症の確認が前提です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（ブロッキング項目 DG001）
- パージェタの承認適応症の確認（現在は Evidence Pack が空のため、既存適応症との比較ができません）
- 作用機序データ (MOA) の補完（DrugBank から取得）
- 正常乳房様サブタイプにおける HER2 発現・依存性を示すデータ
- 上位候補を、L1 の乳癌サブタイプ（PR 陽性／陰性）の評価へ振り替えるかの検討

本結果は研究参考用であり、医療上の助言ではありません。予測は臨床での検証を経て初めて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ヒドロコルチゾン：自己免疫疾患・副腎皮質機能不全から円形脱毛症へ

## 一言要約

ヒドロコルチゾンは糖質コルチコイドで、元々は自己免疫疾患、副腎皮質機能不全（アジソン病）、クローン病などの治療に使われてきました。
TxGNN モデルは**円形脱毛症 (Alopecia Areata)** に有効である可能性を予測しています。
ただし、裏付けとなるのは **1 件の臨床試験**（ヒドロコルチゾンは比較対照薬）と文献のみで、直接的な有効性の証拠は限られています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 副腎皮質機能不全、アジソン病、クローン病、自己免疫疾患など（承認適応症の記載はなく、知識グラフ上の適応症） |
| 予測新規適応症 | 円形脱毛症 (Alopecia Areata) |
| TxGNN 予測スコア | 99.97% |
| エビデンスレベル | L3 |
| 日本市販状況 | 販売中の承認なし（承認はすべて取り消し済み） |
| 承認番号数 | 14 件（すべて取り消し） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし、ヒドロコルチゾンは糖質コルチコイド受容体に作用する副腎皮質ステロイドで、抗炎症作用と免疫抑制作用を持つことが知られています。

円形脱毛症は、毛包に対する T 細胞介在性の自己免疫攻撃で起こると考えられています。ヒドロコルチゾンの既存適応症には自己免疫疾患や炎症性腸疾患が含まれ、免疫・炎症を抑えるという点で機序的な関連があります。

ただし、唯一の第 3 相 RCT ではヒドロコルチゾンは低力価の比較対照薬として使われ、クロベタゾールとの比較でした。そのため、この試験は本剤自体の有効性を示すものではありません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではありません）：高血圧、てんかん、胃潰瘍、腎疾患、肝疾患、胆嚢疾患、高血糖、麻疹、単純ヘルペスウイルス角膜炎、肛門性器ヒトパピローマウイルス感染症、尋常性疣贅、下垂体機能低下症など。
- **薬物相互作用**（合計 100 件、うち一部を抜粋）：
  - 重大（Major）：アダリムマブ
  - 中等度（Moderate）：ジドブジン、イソトレチノイン、アカルボース、アセタゾラミド、ケトロラク、ニフェジピン、イブプロフェン、エチニルエストラジオール、アルデスロイキン、アレムツズマブなど
  - 軽度（Minor）：ホルモテロール、サルブタモール

詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 円形脱毛症では、唯一の第 3 相 RCT でヒドロコルチゾンが比較対照にとどまり、本剤自体の有効性を示すエビデンスがありません。
- 日本の承認はすべて取り消されています。
- 添付文書の警告・禁忌が未取得で、安全性評価を進められない状態です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析
- 詳細な作用機序データ（MOA）の補完
- 円形脱毛症でヒドロコルチゾンを試験薬とした比較試験の有無の確認
- 外用・局所注射など投与経路の適合性評価
- 日本での販売再開または新規承認の可能性の調査
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

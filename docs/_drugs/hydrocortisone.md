# ヒドロコルチゾン：副腎皮質ステロイド製剤から円形脱毛症へ

## 一言要約

ヒドロコルチゾンは糖質コルチコイド（副腎皮質ステロイド）で、日本では軟膏や注射剤など複数の剤形が市販されています。
TxGNN モデルは**円形脱毛症 (alopecia areata)** に有効である可能性を予測しています。関連する **4 件の臨床試験**と **20 編の文献**がありますが、ヒドロコルチゾン自体の有効性を直接示す試験は乏しいのが現状です。唯一の Phase 3 RCT では、ヒドロコルチゾン 1% クリームは対照薬として使われています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ヒドロコルチゾンは糖質コルチコイド受容体に作用する副腎皮質ステロイドで、抗炎症作用と免疫抑制作用を持ちます。

円形脱毛症は、毛包に対する T 細胞介在性の自己免疫攻撃が関与すると考えられています。ステロイドの外用や局所注射は、この疾患で以前から使われてきた治療です。ヒドロコルチゾンの皮内注射に関する 1950〜60 年代の報告も複数あります。このため、免疫抑制作用が病態に届く可能性は機序的に説明できます。

ただし、直接の根拠は小児を対象とした Phase 3 RCT 1 件だけです。この試験ではクロベタゾール 0.05% が比較され、ヒドロコルチゾン 1% は対照群でした。ヒドロコルチゾンは弱いステロイドであるため、主たる治療薬としての有効性が支持されているとは言えません。

## 結論と次のステップ

**決定：Hold**

**理由：**
円形脱毛症に対する直接的なエビデンスは、ヒドロコルチゾンを対照群とした小児の Phase 3 RCT 1 件に限られます。それ以外は古い症例報告や関連ステロイドの試験です。よりよい選択肢が確立している疾患で、ヒドロコルチゾン単独を主たる治療薬として支持する根拠はまだありません。

**進める場合に必要なもの：**
- 日本の添付文書（警告・禁忌）の取得と安全性スクリーニング（現在は未実施のためブロッキング要因）
- 詳細な作用機序（MOA）データの補充
- NCT01453686 / PMID 24226568 の群別結果を精査し、ヒドロコルチゾン群の効果量を確認
- 日本国内の承認適応症の整理と、外用・局所注射など投与経路の適合性評価
- 他の予測候補では、特発性ステロイド感受性ネフローゼ症候群（L3）が観察研究の支持を持つ。ただし試験はなく、古い観察研究が中心

※本結果は研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的検証を経て初めて適用できます。

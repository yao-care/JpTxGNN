# シンバスタチン：脂質異常症から家族性高コレステロール血症へ

## 一言要約

シンバスタチンは HMG-CoA 還元酵素阻害薬（スタチン）で、元々は高脂血症や家族性高コレステロール血症の治療に使用されていました。
TxGNN モデルは**家族性高コレステロール血症 (Familial Hypercholesterolemia)** に有効である可能性を最上位で予測しています。ただしこれは既存適応症と重なる疾患です。
現在、**8 件の臨床試験**と **17 編の文献**がこの方向性を支持しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 高脂血症、家族性高コレステロール血症（脂質異常症治療薬、HMG-CoA 還元酵素阻害薬） |
| 予測新規適応症 | 家族性高コレステロール血症 (Familial Hypercholesterolemia) |
| TxGNN 予測スコア | 99.63% |
| エビデンスレベル | L1 |
| 日本市販状況 | 販売中の承認なし（20 件すべて取消・整理済み） |
| 承認番号数 | 20 件 |
| 推奨決定 | Proceed with Guardrails |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、シンバスタチンは HMG-CoA 還元酵素阻害薬に分類され、肝臓でのコレステロール合成を抑え、LDL 受容体の発現を高めて LDL コレステロールを下げます。

予測された家族性高コレステロール血症は、日本での既存適応症にすでに含まれています。そのため今回の予測は、新しい疾患への展開というより、既存適応症をモデルが再現したものと考えるのが妥当です。

臨床試験では、シンバスタチンが基礎治療または比較対照として使われた試験が中心で、シンバスタチン単独の有効性を直接検証した試験は限られます。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、予測モデルの知識グラフに基づく）：肝疾患、膵炎、横紋筋融解症、ミオパチー、糖尿病、痛風、血小板減少症など
- **薬物相互作用**（計 100 件中の主なもの）：
  - 重大（Major）：アミオダロン、アムロジピン、フェノフィブラート
  - 中等度（Moderate）：パクリタキセル、ニフェジピン、オメプラゾール、エタノールなど
  - HIV 治療薬のプロテアーゼ阻害薬は CYP3A4 を阻害するため、横紋筋融解症のリスクに注意が必要です。

警告および禁忌の詳細は、添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
家族性高コレステロール血症に対しては、完了した Phase 3 試験が複数あり、Cochrane レビューも存在します。ただし、この疾患は既存適応症と重なるため、真の新規適応症ではありません。他の予測疾患（脳幹梗塞、HIV 感染症など）は、エビデンスが乏しいか薬物相互作用の検討が中心で、保留（Hold）または研究課題の段階です。

**進める場合に必要なもの：**
- 日本の販売状況の確認（取消済みのため、現行の承認製剤の有無を確認する）
- 添付文書の警告・禁忌の取得と解析
- 詳細な作用機序データの補充
- 既存適応症と重ならない疾患への展開を狙う場合は、新規適応症の候補の再選定
- 相互作用（特に CYP3A4 阻害薬）と筋障害のモニタリング計画
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

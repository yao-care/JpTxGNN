# シンバスタチン：脂質異常症から家族性高コレステロール血症へ

## 一言要約

シンバスタチンは HMG-CoA 還元酵素阻害薬（スタチン）で、元々高脂血症などの脂質異常症の治療に使われてきました。
TxGNN モデルは**家族性高コレステロール血症 (Familial Hypercholesterolemia)** に有効である可能性を予測しています。
現在 **19 件の臨床試験**と **18 編の文献**が関連しており、そのうちシンバスタチン自体を直接扱う Phase 3 試験は 2 件です。
なお、日本の承認適応症にはすでに家族性高コレステロール血症が含まれています。この予測は新規適応の発見というより、既存適応をモデルが再現したものです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、シンバスタチンは HMG-CoA 還元酵素を阻害するスタチン系薬剤で、脂質異常症での有効性が証明されています。

この酵素を阻害すると肝臓のコレステロール合成が低下し、肝細胞の LDL 受容体が増加して血中 LDL-C が下がります。家族性高コレステロール血症の中心的な病態は LDL-C の著明な上昇です。特に LDL 受容体機能が一部残る常染色体優性型では、この作用が機序的によく適合します。

予測の妥当性は日本での承認状況とも一致します。承認適応症に家族性高コレステロール血症が記載されており、文献でも小児から成人まで使用実績が報告されています。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
家族性高コレステロール血症については、シンバスタチンを直接扱う完了済み Phase 3 試験が 2 件（ENHANCE、思春期試験）あり、RCT 論文も複数あります。日本でもすでに承認適応に含まれています。ただし、PMDA 添付文書の警告・禁忌が未取得で、作用機序データも未整備のため、条件付きで進めます。

**進める場合に必要なもの：**
- PMDA 添付文書から警告・禁忌・相互作用情報を取得（安全性スクリーニングの前提条件）
- DrugBank から作用機序（MOA）データを取得
- 相互作用データの再確認（現在の検索結果は 0 件で、未検証の可能性があります）

**予測順位 2〜10 位の扱い（参考）：**
- 常染色体優性高コレステロール血症（4 位）は同様に L1 で、Proceed with Guardrails の判定です。
- HIV 感染症（6 位）は L3 で、Research Question の判定です。証拠は HIV 関連脂質異常症の管理と薬物相互作用に関するものです。シンバスタチンは CYP3A4 基質であり、ブーストされたプロテアーゼ阻害薬やコビシスタットとの併用は禁忌に該当し、スタチンの切り替えや用量制限が必要です。
- その他（脳幹梗塞、CETP 欠損症、7α-ヒドロキシラーゼ欠損症、ABri アミロイドーシスなど）は L4〜L5 で、Hold の判定です。

> 本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床的検証を経て初めて実用に移せます。

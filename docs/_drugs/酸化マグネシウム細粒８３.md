## 評価が進められない理由

薬物名「酸化マグネシウム細粒８３％」は剤形（細粒）と濃度（83%）を含む商品規格名であるため、データベースが一般名（酸化マグネシウム、Magnesium Oxide）と照合できず、PMDA クエリが 0 件に終わっています。

なお、クエリログによると DrugBank クエリは 1 件の結果を返していますが、DrugBank ID の抽出には至っていません。これはパイプラインの名称正規化ステップで薬物名が一般名に変換されなかったことを示しており、TxGNN 予測に必要な以下のデータがすべて欠損しています：

- **DrugBank ID**：作用機序・安全性データのアンカー
- **承認済み適応症テキスト**：予測の基準点
- **MOA データ**：機序関連性の分析基盤

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が未特定のため TxGNN 予測を実行できず、評価に必要な基礎データが揃っていません。名称正規化の修正が最優先事項です。

**進める場合に必要なもの：**

- **薬物名の正規化ルール追加**：「酸化マグネシウム細粒８３％」→ 一般名「酸化マグネシウム」へのマッピングを `normalizer.py` または `disease_mapper.py` に相当する薬物名正規化モジュールに追記する
- **DrugBank ID の確定**：クエリログでは DrugBank が 1 件ヒットしているため、返却された候補エントリから正しい DB ID（例：DB01397）を抽出・登録する
- **PMDA 再クエリ**：正規化した一般名「酸化マグネシウム」で PMDA を再検索し、承認情報・適応症テキストを取得する
- **MOA データ取得**：DrugBank API から作用機序（制酸・緩下作用など）を取得する
- **安全性データ取得**：PMDA 添付文書の警告・禁忌セクションを解析する

# アシクロビル3%眼軟膏：再利用候補の評価データ不足

## 一言要約

`ｱｼｸﾛﾋﾞﾙ3%ｶﾞﾝﾅﾝｺｳ`（アシクロビル3%眼軟膏）は抗ウイルス薬アシクロビルの眼用製剤であり、通常ヘルペスウイルスによる角膜炎の治療に使用されます。今回の Evidence Pack では、**TxGNN モデルによる予測適応症が存在せず**、また日本市販情報・安全性データも取得できていないため、再利用候補としての評価を実施できない状態です。PMDA クエリが半角カタカナ入力により 0 件を返しており、**データ品質の問題がブロッカー**となっています。

---

| 項目 | 内容 |
|------|------|
| 既存適応症 | 取得不可（PMDA クエリ 0 件） |

| 承認番号数 | 0 件（要再確認） |
| 推奨決定 | **Hold** |

---

## データギャップ分析

このレポートは通常の評価フローを完結できません。以下の 2 つの根本的な問題が原因です。

### 問題 1：薬物識別の失敗

クエリ入力 `ｱｼｸﾛﾋﾞﾙ3%ｶﾞﾝﾅﾝｺｳ`（半角カタカナ）は PMDA 検索で 0 件を返しています。アシクロビル眼軟膏（Zovirax® 眼軟膏等）は日本で承認実績のある製剤であり、**検索失敗はエンコーディング問題が原因**と考えられます。DrugBank クエリは 1 件ヒットしていますが、DrugBank ID が null のままとなっており、マッピングが完了していません。

| クエリソース | 結果件数 | 判断 |
|------------|---------|------|
| PMDA | 0 件 | 半角カタカナによる検索失敗の可能性大 |
| DrugBank | 1 件ヒット | DrugBank ID 未取得 → マッピング未完了 |

### 問題 2：予測適応症がゼロ

DrugBank ID が特定されていないため、TxGNN モデルへの入力が実行されておらず、予測適応症リストが空です。これにより、再利用評価レポートの本体となる以下のセクションがすべて生成不可となります：

- この予測が妥当である理由
- 臨床試験エビデンス
- 文献エビデンス

---

## 結論と次のステップ

**決定：Hold**

**理由：**
薬物識別が未完了のため TxGNN 予測が実行されておらず、評価の出発点となる予測適応症が存在しません。まず薬物の正規化と DrugBank マッピングを完了させることが必須です。

**進める前に必要なもの：**

1. **薬物名の正規化**
   - 半角カタカナ → 全角変換：`アシクロビル3%眼軟膏`
   - INN（国際一般名）での再クエリ：`acyclovir`
   - PMDA を `アシクロビル` または `aciclovir` で再検索

2. **DrugBank ID の確定**
   - DrugBank で `acyclovir` を検索し ID を確定（正しい ID：`DB00787`）
   - Evidence Pack の `drugbank_id` フィールドを更新

3. **TxGNN 予測の実行**
   - DrugBank ID 確定後、KG 予測・DL 予測を実行
   - 予測適応症リストを Evidence Pack に追加

4. **安全性データの取得**
   - PMDA 仿単 PDF からの警語・禁忌抽出
   - DDI 情報の補完

5. **再評価の実施**
   - 上記データが揃った段階で本レポートを再生成

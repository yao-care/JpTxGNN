# シプロフロキサシン：細菌感染症からびまん性強皮症へ

## 一言要約

シプロフロキサシンはフルオロキノロン系の抗菌薬で、元々は腸チフス、サルモネラ症、細菌性肺炎、緑膿菌感染症、炭疽などの細菌感染症の治療に使われていました。
TxGNN モデルは**びまん性強皮症 (Diffuse Scleroderma)** に有効である可能性を予測しています。ただし、関連する臨床試験の登録はなく、文献は **2 編**のみで、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報では、シプロフロキサシンは細菌の DNA ジャイレースとトポイソメラーゼ IV を阻害するフルオロキノロン系抗菌薬です。上記の細菌感染症で有効性が確立されています。

強皮症との関連は、間接的な2つの経路です。

- **抗線維化作用**：強皮症由来の皮膚細胞で、線維芽細胞のコラーゲン産生を抑えるという報告があります。
- **小腸細菌過剰増殖への対処**：全身性強皮症では小腸細菌過剰増殖がしばしば合併し、慢性下痢や体重減少の原因になります。抗菌薬による治療が支持療法として働く可能性があります。

どちらの関連も間接的で、強皮症に対する臨床的な有効性データは確認されていません。現時点では、モデル予測に文献による弱い裏付けが加わった仮説段階の候補です。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌・注意疾患**（添付文書の記載ではありません）：QT延長症候群（先天性を含む）、トルサード・ド・ポワンツ、てんかん、腎疾患、低カリウム血症、腱炎・アキレス腱滑液包炎などの腱関連疾患、末梢神経障害、重症筋無力症、*Clostridium difficile* 大腸炎など。
- **薬物相互作用**：100 件の相互作用が登録されています。確認できた範囲の重大 (Major) なものは、ヒドロコルチゾン、デキサメタゾン、ベタメタゾン、トリアムシノロン（いずれもコルチコステロイド）とブプロピオンです。
- メトホルミン、ピオグリタゾン、アカルボース、アスピリンなどとは中等度 (Moderate) の相互作用があります。

強皮症患者はコルチコステロイドを併用することが多いため、相互作用の評価が特に重要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
強皮症に対する臨床試験の登録がなく、文献も2編にとどまります。機序的な関連も間接的です。日本の承認はすべて失効しており、添付文書の警告・禁忌データも未取得のため、現段階で開発を進める根拠は不十分です。

**進める場合に必要なもの：**
- 文献 PMID 20507401 の試験結果（主要評価項目、有効性、安全性）の詳細確認
- 強皮症に対する前向き臨床試験（皮膚線維化や消化管症状を評価項目とするもの）の設計検討
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを実施
- 詳細な作用機序データの補充と、抗線維化作用の機序検証
- コルチコステロイド併用時の腱障害リスクを含む、強皮症患者向けの安全性モニタリング計画

**参考：** 同じ薬物の予測候補のうち、**敗血症性ペスト**（TxGNN スコア 99.64%）は、ペストを対象とした無作為化試験と非ヒト霊長類のデータがあり、エビデンスレベル L2 で Proceed with Guardrails と評価されています。薬物再利用の優先度としては、そちらを先に検討する価値があります。

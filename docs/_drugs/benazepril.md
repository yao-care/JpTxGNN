# Benazepril：原発性高血圧から悪性腎血管性高血圧へ

## 一言まとめ
Benazepril（ベナゼプリル） は ACE 阻害薬で、高血圧の治療に用いられる。TxGNN は悪性腎血管性高血圧および悪性高血圧性腎症に有効と予測しているが、これらの疾患では ACE 阻害薬に禁忌があるため注意が必要である。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 日本の承認適応症は本サイトのデータに未収載（知識グラフ上の適応症：hypertensive disorder、hypertension） |
| 予測新適応症 | 悪性腎血管性高血圧 (malignant renovascular hypertension) |

## この予測に慎重さが必要な理由
ACE 阻害薬は高血圧や腎保護に対する効果が明確である一方、腎血管性高血圧への適用には重要な制限がある。

**期待される利点：**
- レニン-アンジオテンシン-アルドステロン系 (RAAS) の抑制
- 血管リモデリングと線維化の抑制
- 腎保護作用

**重大なリスク：**
- **両側腎動脈狭窄は禁忌**：ACE 阻害薬により急性腎不全を起こす可能性がある
- **単機能腎に腎動脈狭窄を合併する場合は禁忌**：同様に急性腎不全を起こす可能性がある
- 悪性高血圧は重度の腎機能障害を伴うことが多く、慎重な評価が必要

## 安全性に関する考慮事項
- **Moderate 相互作用**：
  - Hydrocortisone：降圧効果を低下させる可能性
  - Alogliptin などの血糖降下薬：低血糖リスクを増強する可能性
  - その他多数の薬剤
- **特別な警告**：
  - 両側腎動脈狭窄の患者には禁忌
  - 単機能腎に腎動脈狭窄を合併する患者には禁忌
  - 妊婦には禁忌 (催奇形性リスク)
  - 血管浮腫のリスク

## 結論と次のステップ
**判断：Hold**
**理由：** TxGNN の予測は薬理学的には部分的に妥当性があるが、臨床実務では、腎血管性高血圧（特に両側腎動脈狭窄）は ACE 阻害薬の相対的禁忌である。悪性高血圧の治療では速やかかつ調節可能な降圧が必要であり、通常は静注降圧薬が用いられる。この予測は、特定の適応症を推奨するものではなく、ACE 阻害薬の高血圧関連腎症に対する一般的な有益性を反映している可能性がある。
**推進に必要な事項：**
1. 予測が想定する臨床状況を明確にする：腎血管性高血圧の術後または介入後の管理を指すのか？
2. 両側腎動脈狭窄を除外したうえで、初めて使用を検討できる
3. 悪性高血圧の急性期には静注降圧薬を用い、病状が安定してから経口 ACE 阻害薬を検討する
4. この予測を臨床判断に直接用いることは推奨されない

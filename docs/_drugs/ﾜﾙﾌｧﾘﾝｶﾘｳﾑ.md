# ワルファリンカリウム：規制・予測データ未取得により評価保留

## 一言要約

ワルファリンカリウム（ﾜﾙﾌｧﾘﾝｶﾘｳﾑ）は、ビタミン K 拮抗型の古典的抗凝固薬として広く知られています。
しかし今回の Evidence Pack では、薬名が**半角カタカナ**でエンコードされていたため PMDA クエリが 0 件を返し、規制情報・安全性情報・TxGNN 予測適応症のいずれも取得できていません。
データ収集自体が失敗している状態であり、老薬新用評価を実施できる段階にありません。

## データ収集状況の分析

### 薬名エンコード問題

今回の Evidence Pack における薬名は **半角カタカナ（ﾜﾙﾌｧﾘﾝｶﾘｳﾑ）** で登録されており、PMDA 検索システムとの文字コード不一致が発生している可能性があります。

| 確認項目 | 状況 |

| PMDA クエリ | 成功ステータス・結果 0 件（エンコード問題の疑い） |

| 安全性情報 | すべて Data Gap |
| TxGNN 予測 | 未実行（predicted_indications = [] ） |

### 既知の背景情報

ワルファリンカリウム（Warfarin Potassium）は、ビタミン K 依存性凝固因子（II・VII・IX・X）の活性化を阻害する古典的な経口抗凝固薬です。日本では **ワーファリン** 等の商品名で長年承認・流通しており、「未上市」という判定は **クエリ失敗による誤判定** の可能性が高いと考えられます。DrugBank の国際識別子は DB00682 として公知ですが、今回の Pipeline では DrugBank ID が null のまま残っています。

本 Evidence Pack には MOA・規制情報・安全性情報・予測結果のすべてが欠落しているため、機序的妥当性の分析を行う根拠がありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
薬名の半角カタカナエンコードが原因で PMDA クエリが失敗している疑いが強く、規制情報・安全性情報・TxGNN 予測適応症のいずれも取得されていません。現状では老薬新用候補を評価する根拠データが存在しないため、データ収集パイプラインの修正が先決です。

**進める場合に必要なもの：**
- 薬名表記を**全角カタカナ（ワルファリンカリウム）**または英語（`warfarin`）に統一し、PMDA を再クエリ
- DrugBank API にて DB00682（Warfarin）を直接参照し、MOA・警告・禁忌・薬物相互作用を補充
- PMDA 添付文書 PDF を取得・解析し、承認適応症・用法・禁忌を構造化データとして登録
- 規制・安全性データ補充後に TxGNN KG/DL 予測を実行し、新規適応症候補を生成
- 上記すべて完了後に Evidence Pack を v5 として再生成し、評価レポートを再発行

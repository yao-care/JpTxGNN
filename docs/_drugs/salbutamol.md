# サルブタモール：喘息から乳頭結膜炎へ

## 一言要約

サルブタモールは短時間作用型のβ2刺激薬で、元々は喘息や気管支疾患の治療に使われていました。
TxGNN モデルは**乳頭結膜炎 (Papillary Conjunctivitis)** に有効である可能性を予測していますが、この予測を直接支持する**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみの段階です。

## クイック概要

既存適応症は、日本の承認情報に適応症の記載がなかったため、知識グラフ上の適応症情報に基づいています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、サルブタモールはβ2アドレナリン受容体作動薬で、気道平滑筋を弛緩させて喘息や気管支疾患の症状を和らげる薬剤です。

結膜にもβ2受容体が存在し、マスト細胞が関与する炎症反応を調節する可能性があります。乳頭結膜炎はアレルギー性の炎症が関わる疾患のため、機序の上では理論的に関連づけられます。

ただし、これはモデル予測に基づく仮説にすぎません。臨床試験や文献による裏付けはなく、既存適応症との類似性の評価も完了していません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 乳頭結膜炎については、TxGNN の予測スコアは非常に高いものの、臨床試験も文献も存在せず、エビデンスは L5（モデル予測のみ）です。
- 日本の承認も取り消し済みで、結膜への適用に向けた剤形（点眼など）も整っていません。

**進める場合に必要なもの：**
- 詳細な作用機序データ（MOA）の取得
- 添付文書の警告・禁忌の確認（現時点で未確認）
- 結膜炎に対するβ2刺激薬の前臨床研究と文献の体系的な調査
- 眼局所投与の剤形・投与経路の適合性評価
- 眼局所投与時の全身性の心血管系影響など、安全性の検討

参考として、同じデータで予測された閉塞性肺疾患（COPD を含む）はエビデンスレベル L1 で、Phase 3 試験が複数あります。ただし、これは既存適応症の延長にあたり、新規の再利用候補とは性質が異なります。

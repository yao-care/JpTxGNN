# サルブタモール：β2刺激薬（気道疾患）から乳頭状結膜炎へ

## 一言要約

サルブタモールは選択的β2アドレナリン受容体刺激薬で、日本では吸入液とシロップが市販されています。
TxGNN モデルは**乳頭状結膜炎 (Papillary Conjunctivitis)** に有効である可能性を予測していますが、
現在、関連する臨床試験と文献は **どちらも 0 件**で、根拠はモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、サルブタモールは選択的β2アドレナリン受容体刺激薬です。日本ではベネトリンとして吸入液とシロップが承認されています。日本の承認適応症のテキストは、今回のデータでは取得できていません。

機序面では、β2刺激を局所で作用させると、肥満細胞が介在する眼の炎症を抑える可能性が考えられます。ただし、これは仮説にすぎません。乳頭状結膜炎を対象とした臨床試験や文献はなく、予測は TxGNN のスコアだけに基づいています。

既存適応症（気道疾患）と結膜炎の類似性についての評価は、まだ実施されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
乳頭状結膜炎に対する臨床試験も文献もなく、根拠は TxGNN の予測スコアだけです（L5）。作用機序データと添付文書の安全性情報も未取得のため、次の段階には進めません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得する（安全性スクリーニングの前提条件です）
- DrugBank から作用機序（MOA）を取得し、結膜炎との機序的な関連を検証する
- 眼局所投与の適合性を確認する（承認済みの剤形は吸入液とシロップのみで、点眼剤形はありません）
- 前臨床データ（結膜モデルなど）や臨床試験を調査し、エビデンスを補強する
- 参考：同じ薬物の他の予測候補である閉塞性肺疾患は、エビデンスレベルが L2 で、より根拠が強くなっています。優先順位の検討材料になります。

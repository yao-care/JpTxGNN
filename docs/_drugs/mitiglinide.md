# ミチグリニド：2型糖尿病から オプシスモ異形成症 へ

## 一言要約

ミチグリニドは、元々2型糖尿病の治療に使用されていた薬です。
TxGNN モデルは**オプシスモ異形成症 (Opsismodysplasia)** に有効である可能性を予測していますが、
現在、関連する臨床試験や文献は**ありません**。モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。一般に、ミチグリニドは膵β細胞の K-ATP チャネル (Kir6.2/SUR1) を遮断してインスリン分泌を促す速効型インスリン分泌促進薬として知られており、2型糖尿病での使用が確立されています。

オプシスモ異形成症は、INPPL1 遺伝子の変異によって生じる骨系統疾患です。INPPL1 がコードする SHIP2 は、PI3K／インスリンシグナルに関わっています。このため、インスリンシグナルという点では接点が考えられます。ただし、ミチグリニドとの直接的な関連を示す根拠は確認されておらず、あくまで推測の域を出ません。この予測は TxGNN のスコアだけに基づいています。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測を裏付ける臨床試験も文献もなく、作用機序上のつながりも確認できません。また、日本では有効な承認がすべて失われており、安全性情報（警告・禁忌）も未確認です。そのため、現時点で再利用を進める根拠は不十分です。

**進める場合に必要なもの：**
- ミチグリニドの詳細な作用機序データ（MOA）の取得
- 添付文書の警告・禁忌情報の確認（PMDA の添付文書を取得して解析）
- ミチグリニドと INPPL1／SHIP2／PI3K 経路との関連を調べる前臨床研究
- オプシスモ異形成症に関する既存の文献および臨床試験の再調査
- 市販が終了している状況での供給・開発の可能性の検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

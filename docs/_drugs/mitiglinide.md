# ミチグリニド:2型糖尿病からオプシスモディスプラジアへ

## 一言要約

ミチグリニドは速効型のインスリン分泌促進薬で、日本では2型糖尿病治療薬として市販されています。
TxGNN モデルは**オプシスモディスプラジア (Opsismodysplasia)** に有効である可能性を高スコアで予測していますが、
現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

ミチグリニドは膵β細胞の K-ATP チャネル (Kir6.2/SUR1) を阻害し、短時間作用でインスリン分泌を促進します。
詳細な作用機序データは Evidence Pack に収載されていません。上記の内容は予測の根拠として付記された機序説明によるものです。

オプシスモディスプラジアは稀な骨系統疾患で、主に INPPL1 (SHIP2) の機能喪失が原因とされています。
この変異により PI3K/AKT シグナルと軟骨内骨化が障害されます。

ミチグリニドの作用経路とこの疾患の病態経路の間に、直接の機序的つながりは確認されていません。
スコアが 0.99 と高くても、これはグラフベースの予測にすぎず、現時点で妥当性を支持する実証的根拠はありません。

# オロパタジン：アレルギー性鼻炎から酒さ性結膜炎へ

## 一言要約

オロパタジンは選択的 H1 受容体拮抗薬で、日本ではアレルギー性鼻炎などの抗アレルギー薬として使用されています。
TxGNN モデルは**酒さ性結膜炎 (Rosacea Conjunctivitis)** に有効である可能性を予測していますが、
現在、この方向性を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、オロパタジンは H1 受容体拮抗薬に分類され、肥満細胞安定化作用も併せ持つとされています。
ヒスタミンが関与する眼表面の痒みや充血を抑える可能性があるため、機序的には眼の炎症症状に適用できる余地があります。

ただし、酒さ性結膜炎の主因はアレルギーではなく、マイボーム腺機能不全とそれに伴う炎症です。
抗ヒスタミン作用だけでは病態の中心に届かない可能性があります。
この薬物と本疾患を結びつける臨床的・文献的な根拠は現時点でなく、支持材料は TxGNN の予測スコア (0.994) のみです。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測を裏づける臨床試験・文献がなく、エビデンスはモデル予測のみ (L5) です。
また、酒さ性結膜炎の病態はアレルギー性ではないため、抗ヒスタミン作用による効果は限定的と考えられます。
さらに、安全性の確認に必要な添付文書情報が未取得のため、次の段階には進めません。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析（安全性スクリーニングに必須）
- DrugBank からの作用機序 (MOA) データの取得
- 酒さ性結膜炎に関する臨床試験・文献の系統的な検索（ClinicalTrials.gov、PubMed、JPRN）
- 投与経路の適合性評価（現在の経口錠と点眼液のどちらが本疾患に適するか）
- 既存適応症のうち尋常性乾癬の記載について、承認情報との整合性確認

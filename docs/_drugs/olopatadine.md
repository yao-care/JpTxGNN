# オロパタジン：アレルギー性鼻炎・尋常性乾癬から酒さ性結膜炎へ

## 一言要約

オロパタジンは H1 受容体拮抗薬（抗アレルギー薬）で、元々アレルギー性鼻炎および尋常性乾癬の治療に使用されていました。
TxGNN モデルは**酒さ性結膜炎 (Rosacea Conjunctivitis)** に有効である可能性を予測していますが、
現時点で関連する**臨床試験・文献は確認されておらず**、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | アレルギー性鼻炎、尋常性乾癬（抗アレルギー薬、H1 受容体拮抗薬） |
| 予測新規適応症 | 酒さ性結膜炎 (Rosacea Conjunctivitis) |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、オロパタジンは H1 受容体拮抗作用とマスト細胞安定化作用を持つ抗アレルギー薬で、アレルギー性結膜炎などヒスタミン関連の疾患で使用されてきました。そのため、ヒスタミンが関与する眼表面の炎症を和らげる可能性があります。

一方で、酒さに伴う眼の炎症は、主にマイボーム腺機能不全や涙液層の不安定化、ヒスタミン以外の経路によって生じます。アレルギー性疾患との機序的な重なりは限定的で、効果は一部の症状に限られる可能性があります。

TxGNN の高いスコア（0.994）は予測値にすぎません。これを裏付ける臨床試験や文献は、現時点ではありません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書の記載ではなく、TxGNN 知識グラフ由来）：下気道疾患、副鼻腔疾患、鼻腔疾患、上気道疾患
- **薬物相互作用**：相互作用データベースで 100 件が報告されています。主なものはパントプラゾール、ドキシサイクリン、メトホルミン、オメプラゾール、シメチジン、プレドニゾンなどですが、重症度は「不明」のため、臨床的な重要度は評価できません。

詳細な警告・禁忌は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、裏付ける臨床試験・文献がなく、エビデンスは L5（モデル予測のみ）です。
- 日本の承認がすべて取消済みで、酒さ性結膜炎の病態にはヒスタミン以外の要因が大きく関わるため、現時点で進める根拠は不足しています。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と安全性スクリーニング
- 作用機序（MOA）データの補充（DrugBank など）
- 酒さ性結膜炎に関する臨床試験・文献の系統的調査
- 投与経路（点眼剤など）の適合性評価
- 既存適応症との類似性の評価
- 取消済み承認の経緯の確認と、現在の日本での供給状況の確認

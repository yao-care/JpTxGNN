# リバーロキサバン：抗血栓薬（第Xa因子阻害薬）から関節リウマチへ

## 一言要約

リバーロキサバンは第Xa因子阻害薬で、元々は抗血栓薬として使用されています。
TxGNN モデルは**関節リウマチ (Rheumatoid Arthritis)** に有効である可能性を予測していますが、関連する臨床試験は **0 件**です。文献は **3 編**ありますが、いずれも血栓症や自己免疫疾患における凝固との関連を扱う間接的なもので、関節リウマチへの有効性を直接示すものではありません。

## この予測が妥当である理由

リバーロキサバンは第Xa因子を直接阻害する経口抗凝固薬です。現在、DrugBank の詳細な作用機序データは取得できていません。

自己免疫性の炎症では、凝固の活性化やトロンビン産生の変化が報告されています。この点が、予測の機序的な手がかりと考えられます。ただし今回収集された文献は、血栓症との間接的な関連を示すにとどまります。関節リウマチの疾患修飾作用を示す根拠は確認できていません。

TxGNN のスコアは非常に高いものの、これはモデル上の近さを反映したものです。臨床的な有効性を裏付けるものではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
関節リウマチに対する臨床試験がなく、文献も間接的な関連にとどまります。予測の根拠はモデルスコアが中心で、抗凝固薬としての機序から疾患修飾作用を導く根拠も現時点では乏しいです。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。これがないと安全性の一次スクリーニングに進めません
- DrugBank からの作用機序（MOA）データの補完
- 関節リウマチにおける凝固・第Xa因子経路の関与を示す前臨床または臨床研究の検索
- 関節リウマチ患者での出血リスクと、併用薬との相互作用の評価

※ 本レポートは研究参考用であり、医療上の助言ではありません。臨床応用には臨床的な検証が必要です。

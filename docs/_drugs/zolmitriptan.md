# ゾルミトリプタン：片頭痛から脳幹性前兆を伴う片頭痛へ

## 一言要約

ゾルミトリプタンは 5-HT1B/1D 受容体作動薬（トリプタン系）で、元々片頭痛の急性期治療に使用されていました。
TxGNN モデルは**脳幹性前兆を伴う片頭痛 (migraine with brainstem aura)** に有効である可能性を予測しています。
このサブタイプを直接対象とした臨床試験はなく、片頭痛全般を扱う **19 編の文献**が間接的に関連するのみです。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 抗片頭痛薬、血管収縮薬、セロトニン受容体作動薬 |
| 予測新規適応症 | 脳幹性前兆を伴う片頭痛 (migraine with brainstem aura) |
| TxGNN 予測スコア | 99.99% |
| エビデンスレベル | L4 |
| 日本市販状況 | 販売中の承認なし（取消のみ） |
| 承認番号数 | 11 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データ（original_moa）は登録されていません。文献によると、ゾルミトリプタンは選択的な 5-HT1B/1D 受容体作動薬で、頭蓋血管の収縮と三叉神経系の CGRP 放出抑制を通じて片頭痛発作を抑えます。前臨床の報告では、末梢だけでなく中枢での三叉神経血管系の活性化抑制も示されています。

既存適応症の片頭痛と予測された脳幹性前兆を伴う片頭痛は、同じ片頭痛スペクトラムに属します。そのため、片頭痛全般への有効性が機序的な根拠になります。

ただし、このサブタイプに特異的なエビデンスは間接的です。従来、トリプタン系の添付文書では血管収縮のリスクから、脳底型や片麻痺性片頭痛への使用に注意が促されてきました。機序上の関連性はあるものの、安全性の懸念が大きい予測です。

## 安全性に関する考慮事項

- **禁忌となりうる疾患（知識グラフ上の情報）**：添付文書の記載ではなく、知識グラフの薬物・疾患間の禁忌関係に基づく情報です。
  - 心血管系：高血圧、冠動脈疾患、心筋梗塞、プリンツメタル狭心症、心筋虚血、ウォルフ・パーキンソン・ホワイト症候群、末梢血管疾患、レイノー病、虚血性腸疾患
  - 脳血管系：脳卒中、脳梗塞、一過性脳虚血発作、脳虚血、椎骨脳底動脈循環不全、頭蓋内動脈硬化
  - 肝・腎・その他：腎疾患、肝疾患、胆嚢疾患、ヘモグロビン異常症
  - 片頭痛関連：家族性または孤発性片麻痺性片頭痛
- **薬物相互作用**：82 件が報告されています。主なものは次のとおりです。
  - 重大（Major）：ロルカセリン、ドラセトロン、パロノセトロン、オンダンセトロン、グラニセトロン、デクスフェンフルラミン、フェンフルラミン、シブトラミン（主にセロトニン作用の増強に関連）
  - 中等度（Moderate）：モルヒネ、シメチジン、オベチコール酸
- 脳幹性前兆を伴う片頭痛は脳底動脈領域の症状を伴うため、血管収縮作用による虚血リスクが特に懸念されます。ゾルミトリプタンによる心筋梗塞の症例報告もあります。

## 結論と次のステップ

**決定：Hold**

**理由：**
このサブタイプを直接検証した臨床試験はなく、エビデンスは前臨床と間接的な文献に限られます。さらに、血管収縮作用による虚血リスクがあり、日本では有効な承認もありません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得（PMDA の添付文書を確認し、安全性スクリーニングを実施）
- 詳細な作用機序データ（MOA）の補充
- 脳幹性前兆を伴う片頭痛を対象とした臨床データまたは専門家の評価
- 脳血管系・心血管系リスクに関する評価と、対象患者の選定基準の設定
- 日本での承認状況の再確認（現在は取消のみ）

---

**補足：** 他の予測適応症（萎縮性皮膚症 vermiculata、眉毛部紅斑性毛包性角化症）は、TxGNN の予測のみで、臨床試験も文献もなく、機序的な関連も確認できません。評価はいずれも Hold（L5）です。

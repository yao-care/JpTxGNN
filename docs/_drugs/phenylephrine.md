# フェニレフリン：アレルギー性鼻炎・鼻炎から鼻腔疾患へ

## 一言要約

フェニレフリンは α1 アドレナリン受容体作動薬で、元々アレルギー性鼻炎、血管運動性鼻炎、風邪、咽頭炎、結膜炎、痔核などの治療に関連づけられてきました。
TxGNN モデルは**鼻腔疾患 (Nasal Cavity Disease)** に有効である可能性を予測していますが、臨床試験の登録はなく、**5 編の文献**（多くは配合剤や手術時の使用に関するもの）が間接的に関連するのみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、フェニレフリンは α1 アドレナリン受容体作動薬で、粘膜血管を収縮させ、鼻づまりや粘膜出血を軽減します。

既存の適応症（鼻炎、風邪、咽頭炎）はいずれも鼻・上気道粘膜の充血や浮腫を伴う疾患です。そのため、血管収縮作用が鼻腔疾患全般にも適用できる可能性があります。

ただし、鼻腔疾患に関するエビデンスは間接的です。主なものは、配合点鼻薬（Polydexa）の使用や内視鏡下副鼻腔手術での術野管理に関する報告で、フェニレフリン単剤の有効性を直接示したものではありません。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の関連疾患）**：高血圧、肝不全、てんかん、慢性閉塞性肺疾患、腎疾患、膵炎、血小板減少症、副腎皮質機能不全、甲状腺機能低下症、消化性潰瘍、炎症性腸疾患、精神疾患など。これは添付文書の記載ではなく、知識グラフ上の薬物・疾患間の関係です。
- **薬物相互作用**：100 件が検出されました。そのうち確認できた 20 件はすべて中等度（Moderate）です。主なものは次のとおりです。
  - 糖尿病治療薬（アカルボース、グリメピリド、グリピジド、グリブリド、ダパグリフロジン、エンパグリフロジン、エキセナチド、インスリン製剤など）
  - 抗コリン薬（アトロピン点眼、ヒヨスチアミン、クリジニウム）
  - ジエチルプロピオン

警告や禁忌の添付文書情報は確認できていないため、詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験がなく、文献も配合剤や術中使用に関する間接的なものにとどまります。日本の承認もすべて取り消されており、現時点で再利用を進める根拠は不十分です。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌情報を取得し、安全性スクリーニングを実施する
- DrugBank から作用機序（MOA）データを取得し、機序面の裏付けを補強する
- フェニレフリン単剤による鼻腔疾患への効果を直接評価した臨床試験・文献を調査する
- 剤形・投与経路（点鼻など）の適合性を確認する
- 日本で承認が取り消された経緯を確認する

# Tetryzoline：眼科用薬から鼻腔疾患へ

## 一言まとめ

Tetryzoline（テトラヒドロゾリン）は血管収縮薬であり、主に点眼薬の成分として、眼の充血やかゆみなどの症状を緩和する目的で用いられています。TxGNN モデルは、本剤が**鼻腔疾患 (Nasal Cavity Disease)** に有効である可能性を予測しており、現在この方向性を支持する文献が **4 件**ありますが、臨床試験の登録はありません。

## この予測が妥当な理由

Tetryzoline（Tetrahydrozoline とも呼ばれます）は imidazoline 系のα-アドレナリン受容体作動薬で、血管収縮作用を有します。眼科領域では、結膜血管を収縮させることで眼の充血を緩和します。

この予測は作用機序の面から妥当です。同じ血管収縮の機序を鼻粘膜にも応用でき、鼻閉症状を緩和できるためです。実際、Tetryzoline は海外（米国の Tyzine など）ですでに鼻充血除去薬として用いられており、海外の一部の国では承認されている適応症であり、日本での承認は本サイトのデータでは確認できません。一方、鼻腔疾患は承認適応症には含まれず、承認されているのは眼科用途のみです。

## 結論と次のステップ

**判断：Hold**

**理由：**
Tetryzoline を鼻充血除去に用いることは作用機序の面で妥当であり、海外ではすでに関連する使用例もありますが、現存する文献はいずれも 1950 年代のものであり、現代の臨床試験データが不足しています。

**推進に必要な事項：**
- 現代の臨床試験データ
- 鼻腔用剤形の薬物動態試験
- 既存の鼻充血除去薬（oxymetazoline など）との比較研究

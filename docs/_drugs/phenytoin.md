# フェニトイン：抗てんかん薬から三叉神経腫瘍へ

## 一言要約

フェニトインは元々、抗てんかん薬として使用されていました。
TxGNN モデルは**三叉神経腫瘍 (Trigeminal Nerve Neoplasm)** に有効である可能性を予測していますが、関連する臨床試験は **0 件**、文献は **2 編**（いずれも三叉神経痛やスタージ・ウェーバー症候群に関するもので、腫瘍に対する効果を示すものではありません）にとどまります。現時点ではモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。一般的な薬理知識では、フェニトインは電位依存性ナトリウムチャネルを遮断し、神経細胞の反復発火を抑える抗てんかん薬です。三叉神経痛などの神経障害性疼痛にも使われてきました。

ただし、この作用は神経の過剰興奮を抑えるもので、抗腫瘍効果を示すものではありません。今回の予測は、三叉神経に関わる疾患（三叉神経痛）との症状面での重なりを反映している可能性が高く、腫瘍そのものに対する機序的な裏付けは確認できません。

## 安全性に関する考慮事項

- **禁忌に関連する疾患（知識グラフ上の情報）**：QT延長症候群・トルサード・ド・ポワント、肝不全・肝疾患・肝性脳症、ポルフィリン症、腎疾患、血小板減少症、好中球減少症・無顆粒球症、高血糖・糖尿病（糖尿病性ケトアシドーシス含む）、全身性エリテマトーデス、低血圧、睡眠時無呼吸症候群などが挙げられています。これは添付文書の記載ではなく、知識グラフ上の関連情報です。
- **薬物相互作用**：100 件の相互作用が確認されています。主なものは中等度で、アカルボース、ファモチジン、ラニチジン、ドキシサイクリン、ヒドロコルチゾン、メトホルミン、ピオグリタゾン、ブプロピオン、アプレピタント、デキサメタゾン、メトロニダゾール、オメプラゾールなどです。アセチルサリチル酸は軽度です。

添付文書の警告・禁忌については、PMDA の添付文書を確認してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 三叉神経腫瘍に対しては臨床試験・直接的な文献がなく、機序的にも抗腫瘍効果を支持する根拠がありません。エビデンスはモデル予測のみ（L5）で、日本ではすべての承認が整理済みです。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の取得（PMDA）
- 詳細な作用機序データ（DrugBank）
- 三叉神経腫瘍に対する前臨床データまたは機序的根拠
- 参考として、同じ予測リストの中で**三叉神経痛**（L3、観察研究あり）や**反射性てんかん**（驚愕てんかん、読書てんかんなど、L4）は、既存の抗てんかん作用との関連性が高く、優先的に検討する価値があります。

# フェニトイン：てんかんから三叉神経腫瘍へ

## 一言要約

フェニトインは抗てんかん薬として日本で広く使われている薬剤です。
TxGNN モデルは**三叉神経腫瘍 (Trigeminal Nerve Neoplasm)** に有効である可能性を予測していますが、現在 **臨床試験は 0 件**、**文献は 5 編**にとどまります。文献はいずれも三叉神経痛や Sturge-Weber 症候群などを扱っており、腫瘍への効果を直接支持するものではありません。

## この予測が妥当である理由

現在、詳細な作用機序データは登録されていません。一般的な薬理学的知見では、フェニトインは電位依存性ナトリウムチャネルを遮断し、神経細胞の高頻度な反復発火を抑えます。この作用により、てんかん発作の伝播が抑えられます。

同じ機序から、三叉神経の異常な興奮に伴う神経痛様の痛みを和らげる可能性は理論上考えられます。ただし、この機序は抗腫瘍作用を裏付けるものではありません。今回取得された文献も、腫瘍ではなく三叉神経痛や Sturge-Weber 症候群に関するものです。

したがって、今回の予測は「三叉神経に関連する神経症状」との連想に基づいている可能性があり、腫瘍そのものへの有効性が機序的に支持されているとは言えません。

## 結論と次のステップ

**決定：Hold**

**理由：**
三叉神経腫瘍に対する臨床試験はなく、文献も腫瘍を直接扱っていません。機序的にも抗腫瘍作用の根拠がなく、モデル予測のみの段階です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（安全性スクリーニングに必須）
- DrugBank からの作用機序（MOA）データの補完
- 三叉神経腫瘍に特化した文献・試験の再検索と、予測の妥当性の再評価
- 参考：同じ Evidence Pack 内の**三叉神経痛**（L3、完了した小規模試験 NCT03712254 と 2026 年の RCT 報告あり）は、エビデンスが相対的に厚いため、別途優先的に評価する価値があります

本レポートは研究参考用であり、医療上の助言ではありません。老薬新用の候補は臨床的検証が必要です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

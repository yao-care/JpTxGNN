# モルヒネ：麻薬性鎮痛薬（オピオイド受容体作動薬）から筋筋膜性疼痛症候群へ

## 一言要約

モルヒネは麻薬性鎮痛薬（オピオイド受容体作動薬）で、日本では注射液・細粒・錠剤として市販されています。
TxGNN モデルは**筋筋膜性疼痛症候群 (Myofascial Pain Syndrome)** に有効である可能性を予測しています。関連する臨床試験は **33 件**、文献は **17 編**ありますが、モルヒネそのものを筋筋膜性疼痛症候群に用いた直接的な試験はなく、エビデンスは間接的なものにとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank）はありません。既知の情報によると、モルヒネは μ オピオイド受容体作動薬で、痛覚伝達を抑制します。そのため、筋骨格系の痛みにも機序的に適用できる可能性があります。

既存の鎮痛作用と筋筋膜性疼痛症候群の痛みは、どちらも侵害受容の抑制で説明できます。ただし、筋筋膜性疼痛症候群の中心病態はトリガーポイントと中枢性感作です。オピオイドが有効かどうかは、これまで十分に検証されていません。

直接的なヒト由来のエビデンスは、脊椎固定術での筋膜浸潤にモルヒネを補助薬として使った小規模な試験程度です。慢性的なオピオイド使用には、痛覚過敏（オピオイド誘発性痛覚過敏）や依存のリスクもあります。予測スコアは高いものの、機序面の裏付けは限定的です。

## 結論と次のステップ

**決定：Hold**

**理由：**
モルヒネを筋筋膜性疼痛症候群に用いた直接的な臨床試験はなく、現時点のエビデンスは間接的なものばかりです。日本の添付文書に基づく安全性の確認も済んでいません。依存や痛覚過敏のリスクを考えると、現段階で進めるのは適切ではありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌・相互作用情報の取得と整理（安全性スクリーニングに必須）
- DrugBank からの作用機序（MOA）データの補充
- モルヒネ（特に局所浸潤など投与経路を限定した場合）を筋筋膜性疼痛症候群で評価する、対照付き臨床試験の有無の精査
- 非オピオイド治療（トリガーポイント注射、ドライニードリングなど）との比較検討
- 依存・痛覚過敏・呼吸抑制を踏まえた、対象患者の限定と投与期間・用量の上限設定

本結果は研究参考用であり、医療上の助言ではありません。老藥新用の候補は、臨床的な検証を経てはじめて応用できます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

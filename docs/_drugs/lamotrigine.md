# ラモトリギン：てんかん・双極性障害から三叉神経腫瘍へ

## 一言要約

ラモトリギンは元々、Lennox-Gastaut 症候群などのてんかんと、双極性障害の気分エピソードの再発・再燃抑制に使われてきた薬です。
TxGNN モデルは**三叉神経腫瘍 (Trigeminal Nerve Neoplasm)** に有効である可能性を予測していますが、**臨床試験は 0 件**です。文献 2 編もラモトリギンの抗腫瘍効果を示すものではなく、実質的にはモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ラモトリギンは電位依存性ナトリウムチャネルを遮断し、グルタミン酸の放出を抑える抗てんかん薬です。てんかんや双極性障害での有効性は確立しています。

ただし、この作用機序は神経の過剰興奮や神経障害性疼痛を抑えるもので、腫瘍細胞の増殖を抑える抗腫瘍作用は知られていません。スコアが高い理由は、腫瘍生物学ではなく**三叉神経痛**との関連をモデルが拾った可能性が高いと考えられます。三叉神経腫瘍を機序的に支持する根拠は現時点でありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
三叉神経腫瘍については臨床試験がなく、文献にも抗腫瘍効果を示す根拠がありません。機序面でも抗腫瘍作用は確認されておらず、モデル予測のみの L5 です。

同じ予測リストの**三叉神経痛**には、ラモトリギン自体を対象とした Phase 2/3 試験（NCT00913107、カルバマゼピンとの比較、21 例）とプラセボ対照の追加投与試験（NCT00203229、20 例）があり、L2 と評価されています。こちらは別の研究課題として検討する価値があります。

**進める場合に必要なもの：**
- 三叉神経腫瘍に対するラモトリギンの前臨床（細胞・動物）データの確認
- PMDA の添付文書から警告・禁忌情報を取得（安全性スクリーニングの前提）
- DrugBank から詳細な作用機序（MOA）データを取得
- 薬物相互作用データの確認
- 三叉神経痛を別候補として独立に評価するかの判断
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ラモトリギン：双極性障害・Lennox-Gastaut 症候群から三叉神経腫瘍へ

## 一言要約

ラモトリギンは元々、双極性障害の気分エピソードの再発抑制と、Lennox-Gastaut 症候群を含むてんかんの治療に使われてきた薬です。
TxGNN モデルは**三叉神経腫瘍 (Trigeminal Nerve Neoplasm)** に有効である可能性を予測しています。ただし、この疾患を直接検証した臨床試験は **0 件**、文献は **2 編**で、2 編とも三叉神経痛に関する内容です。ラモトリギンを三叉神経腫瘍に使った研究はなく、エビデンスは実質的にモデル予測のみです。

## クイック概要

|------|------|
| 既存適応症 | 双極性障害における気分エピソードの再発・再燃抑制、Lennox-Gastaut 症候群（抗てんかん薬） |
| 予測新規適応症 | 三叉神経腫瘍 (Trigeminal Nerve Neoplasm) |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。一般的な知見では、ラモトリギンは電位依存性ナトリウムチャネルを遮断し、グルタミン酸の放出を抑えます。この作用で神経の異常な興奮が鎮まり、てんかんや双極性障害に効果を示します。

ただしこの機序は抗腫瘍作用ではありません。ラモトリギンに既知の抗腫瘍作用はなく、三叉神経腫瘍に適用できる機序的な根拠は確認できません。スコアが高い主な理由は、ラモトリギンが三叉神経痛（神経障害性の顔面痛）と関連していることだと考えられます。この予測は腫瘍そのものの治療効果を示すものとは言えません。

**参考：三叉神経痛について**
同じ解析で 2 番目に予測された**三叉神経痛**（スコア 99.89%）には、直接のエビデンスがあります。

- ラモトリギンを検証した臨床試験が 2 件あります。
  - 20 例の二重盲検プラセボ対照アドオン試験（NCT00203229、完了）
  - カルバマゼピンと比較した Phase 2/3 試験（NCT00913107、完了、21 例）
- 神経障害性の顔面痛に対するナトリウムチャネル遮断の機序は、妥当と考えられます。
- 診療ガイドラインでは、ラモトリギンはアドオンまたは二次選択肢として位置づけられています。
- エビデンスレベルは L2 で、推奨は Proceed with Guardrails です。
- ただし、どちらの試験も被験者数が 20 例前後と小規模です。

再利用の方向性としては、三叉神経腫瘍よりも三叉神経痛のほうが現実的です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 三叉神経腫瘍に対するラモトリギンの研究は臨床・文献ともになく、ラモトリギンに既知の抗腫瘍作用もありません。
- 高いスコアは、三叉神経痛との関連を反映している可能性が高いです。

**進める場合に必要なもの：**
- 腫瘍細胞や動物モデルでの前臨床データ（抗腫瘍作用の有無）
- 詳細な作用機序データ
- 添付文書の警告・禁忌の確認（安全性スクリーニングに必須）
- 現在日本で販売中の製剤の有無の確認（承認はすべて整理済み）
- 評価対象の見直し：三叉神経痛（L2、Proceed with Guardrails）を優先候補として検討する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

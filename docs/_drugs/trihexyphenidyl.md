# トリヘキシフェニジル：パーキンソニズムから注意欠如・多動症 (ADHD) へ

## 一言要約

トリヘキシフェニジルは、元々パーキンソニズム（特発性パーキンソニズムなど）の治療に使われてきたムスカリン受容体拮抗薬です。
TxGNN モデルは**注意欠如・多動症 (attention deficit-hyperactivity disorder)** への有効性を予測していますが、支持する**臨床試験は 0 件**です。文献も **1 編**のみで、ADHD に対する本剤の効果を直接検証したものではありません。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。日本の承認情報では、トリヘキシフェニジルはムスカリン受容体拮抗薬に分類され、パーキンソニズムでの使用実績があります。

Evidence Pack の機序評価によると、本剤は中枢性の M1 優位ムスカリン拮抗薬で、ジストニアやパーキンソニズムに用いられます。ADHD との関連は間接的で、チック・ジストニアの併存を介した関係にとどまります。

コリン作動系は注意機能に関わるため、生物学的には関連を想定できます。しかし、抗コリン作用は注意や認知を改善するどころか、ADHD の症状を悪化させる可能性があります。したがって、この予測の機序的な妥当性は限定的です。高いスコアは、モデル上の関連性を示すものと考えるのが適切です。

## 結論と次のステップ

**決定：Hold**

**理由：**
ADHD を支持する臨床試験はなく、文献も 1 編（チック・ジストニアの症例集積）だけで、本剤の効果を検証したものではありません。加えて、抗コリン作用が注意機能を悪化させる懸念があります。PMDA 添付文書の警告・禁忌が未取得（ブロッキング）のため、安全性の一次評価にも進めません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌・相互作用）の取得と解析
- DrugBank からの作用機序 (MOA) データの補完
- トリヘキシフェニジルと ADHD を直接対象とした文献の再検索と評価
- 抗コリン作用による認知・注意への影響に関する安全性評価
- 参考：同じ予測リストの PLA2G6 関連神経変性症（順位 5、ジストニア・パーキンソニズムに対する対症的効果）は、Research Question として別途検討する余地があります。

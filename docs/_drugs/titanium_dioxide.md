# Titanium dioxide：從外用抗刺激劑到藥物誘發的骨質疏鬆

## 一言まとめ

Titanium dioxide 原本用作於外用抗刺激劑。
TxGNN 模型預測它可能對**藥物誘發的骨質疏鬆 (drug-induced osteoporosis)** 有效，
但目前缺乏臨床試驗和文獻支持。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 外用抗刺激劑 |
| 予測新適応症 | 藥物誘發的骨質疏鬆 |
| TxGNN 予測スコア | 99.99% |
| エビデンスレベル | L5 |
| 日本上市 | ✗ 已註銷 |
| 承認数 | 8 張 |
| 推奨判断 | Hold |

## この予測が妥当な理由

目前缺乏詳細的作用機轉資料。根據已知資訊，Titanium dioxide 是一種常用的外用抗刺激劑，其在保護皮膚方面的效果已被證實，但機轉上可能不適用於全身性疾病如藥物誘發的骨質疏鬆。由於現有劑型無法達到全身性療效，需開發新劑型以進一步評估其潛在的適應症。

## 結論と次のステップ

**判断：Hold**

**理由：**
目前缺乏足夠的臨床證據和機轉資料支持 Titanium dioxide 作為藥物誘發的骨質疏鬆治療，且現有劑型無法達到全身性療效。

**推進に必要な事項：**
- 開發可達到全身性療效的新劑型
- 補充詳細的藥物作用機轉資料（MOA）
- 進行相關臨床試驗以獲得更多證據

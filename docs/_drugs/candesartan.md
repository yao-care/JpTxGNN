# カンデサルタン：降圧薬（ARB）から片頭痛へ

## 一言要約

カンデサルタンはアンジオテンシンII受容体拮抗薬（ARB）で、日本では血圧降下薬として市販されています。
TxGNN モデルは**片頭痛 (migraine disorder)** に有効である可能性を予測しており、現在 **4 件の臨床試験**（うちカンデサルタンを直接評価したものは 3 件）と **20 編の文献**がこの方向性に関連しています。
完了済みの Phase 2 と Phase 2/3 の二重盲検試験があり、エビデンスレベルは L2 です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、カンデサルタンは ARB に分類され、降圧薬としての有効性が確立されています。

カンデサルタンはアンジオテンシンII 1 型（AT1）受容体を遮断します。片頭痛では、三叉神経血管系や脳血管の収縮、神経炎症、酸化ストレスが関与すると考えられています。AT1 遮断はこれらの経路に作用しうるため、機序の面から片頭痛予防への応用に一定の妥当性があります。

文献でも、カンデサルタンは片頭痛予防の選択肢の一つとして繰り返し取り上げられています。これは TxGNN の予測を裏づける材料です。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

なお、収集した文献には、ARB の妊娠中投与による胎児への影響（羊水過少、肺低形成など）の症例報告やレビューが含まれます（例：[PMID 15669052](https://pubmed.ncbi.nlm.nih.gov/15669052/)、[PMID 21271514](https://pubmed.ncbi.nlm.nih.gov/21271514/)）。妊娠可能年齢の片頭痛患者に適用する場合は、特に注意が必要です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
完了済みの三重盲検 Phase 2 試験（450 例、Lancet Neurol 2025 に論文化）と Phase 2/3 の二重盲検比較試験があり、片頭痛予防の根拠は比較的しっかりしています。一方、日本の承認情報の範囲では片頭痛の適応は確認できず、添付文書の安全性情報も未取得のため、条件付きで進めます。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（現時点で安全性スクリーニングの阻害要因）
- DrugBank からの作用機序（MOA）データの補完
- 妊娠可能年齢の患者、低血圧、腎機能障害を含む対象集団ごとの安全性モニタリング計画
- NCT04574713 の主要評価項目の結果確認と、日本人集団での外挿可能性の検討

**その他の予測適応症：**
- 片頭痛の亜型 2 件（前兆を伴う脳幹性片頭痛、片頭痛の感受性）は L4 で、間接的な根拠のみです。位置づけは研究課題 (Research Question) です。
- 肺高血圧症、プリンツメタル狭心症、良性前立腺肥大症、脱毛症など 7 件は L5 で、予測のみか臨床的根拠がなく、保留 (Hold) とします。

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて実用化できます。*

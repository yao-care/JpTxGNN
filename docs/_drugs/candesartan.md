# カンデサルタン：高血圧から片頭痛へ

## 一言要約

カンデサルタンはアンジオテンシンII受容体拮抗薬（ARB）で、元々は高血圧の治療に使用されていました。
TxGNN モデルは**片頭痛 (migraine disorder)** に有効である可能性を予測しており、現在 **4 件の臨床試験**と **20 編の文献**がこの方向性を支持しています。そのうち 2025 年に Lancet Neurology で報告された第2相ランダム化比較試験が含まれます。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 血圧降下薬、アンジオテンシンII受容体拮抗薬 |
| 予測新規適応症 | 片頭痛 (migraine disorder) |
| TxGNN 予測スコア | 99.97% |
| エビデンスレベル | L2 |
| 日本市販状況 | 販売承認は整理済み（現在有効な承認は 0 件） |
| 承認番号数 | 20 件（すべて整理済み） |
| 推奨決定 | Proceed with Guardrails |

※ 完了した Phase 3 RCT は確認できず、Phase 2/3 および Phase 2 の完了 RCT があるため L2 と判定しました。

## この予測が妥当である理由

現在、詳細な作用機序データは薬物データベース上にありません。ただし薬理学的には、カンデサルタンはアンジオテンシンII 1 型（AT1）受容体を遮断し、血管収縮を抑えて血圧を下げる薬です。

アンジオテンシンII の作用は、血管収縮、酸化ストレス、三叉神経血管系の感作を介して片頭痛の病態に関与すると考えられています。AT1 受容体を遮断することで、これらの経路が抑えられる可能性があります。

血管系の調節という観点で、高血圧と片頭痛には機序的な接点があります。さらに、プラセボ対照のランダム化試験やシステマティックレビューが片頭痛予防での有用性を支持しており、予測の妥当性を裏付けています。

## 安全性に関する考慮事項

- **薬理学的情報**：主な標的は AT1 受容体（AGTR1）で、臨床では単独または他剤との併用で高血圧の治療に用いられます。

その他の安全性情報については添付文書を参照してください。なお、文献には ARB の妊娠中使用による胎児への影響（羊水過少、肺低形成など）の報告があり、妊娠可能な女性への適用には注意が必要です。また、降圧作用による低血圧にも留意が必要です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
片頭痛予防について、完了した第2相のプラセボ対照 RCT（450 例）と Lancet Neurology での公表、複数のメタアナリシスがあり、エビデンスは比較的強い状況です。一方で、完了した Phase 3 試験はなく、日本では現在有効な承認がなく、添付文書の安全性情報も未確認です。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得と確認（現時点では安全性スクリーニングに進めない状態です）
- 詳細な薬物作用機序データの補充
- 片頭痛を対象とした Phase 3 試験での検証
- 日本での販売・承認状況の再確認（現行品の有無と製造販売業者）
- 低血圧リスクの高い患者や妊娠可能な女性に対する安全性モニタリング計画

**その他の予測について：**
片頭痛に関連する予測（脳幹性前兆を伴う片頭痛、片頭痛の感受性）は片頭痛全般のデータからの類推であり、サブタイプ別の試験はありません（研究課題段階）。肺高血圧症は動物実験のみで臨床エビデンスがなく、プリンツメタル狭心症、脊柱後側弯性心疾患、蛇行状皮膚萎縮症、眉毛部紅斑性毛包性角化症、前立腺肥大症、脱毛症は TxGNN の予測のみ、または間接的な報告にとどまるため、現時点では保留（Hold）が妥当です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

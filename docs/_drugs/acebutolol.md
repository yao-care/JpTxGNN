# Acebutolol：高血圧・不整脈から悪性腎血管性高血圧へ

## 一言まとめ

Acebutolol（アセブトロール） は本来、高血圧、狭心症および不整脈に用いられる薬剤です。
TxGNN モデルは、本剤が**悪性腎血管性高血圧 (malignant renovascular hypertension)** に有効である可能性を予測しており、
現在、この方向性を支持する**文献が1件**あります。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 日本の承認適応症は本サイトのデータに未収載（知識グラフ上の適応症：hypertensive disorder、hypertension） |
| 予測新適応症 | 悪性腎血管性高血圧 (malignant renovascular hypertension) |
| TxGNN 予測スコア | 99.10% |
| エビデンスレベル | L4 |
| 日本市販状況 | 本サイトのデータに未収載 |
| 承認番号数 | — |
| 推奨判断 | Hold |

## この予測が妥当な理由

Acebutolol は選択的な beta-1 交感神経遮断薬で、内因性交感神経刺激作用 (ISA) を有します。降圧機序としては、心拍出量の減少、レニン放出の抑制、および中枢性の降圧作用が挙げられます。

腎血管性高血圧の病態では、レニン・アンジオテンシン系 (RAS) の過剰な活性化が重要な役割を果たします。Beta 遮断薬はレニン分泌を抑制するため、理論上は腎血管性高血圧に対して補助的な効果を示す可能性があります。1975年のフランスの研究 (PMID: 768911) では、血漿レニン活性が上昇した腎血管性高血圧患者において、acebutolol が良好な効果を示したと報告されています。

しかし、現在の臨床では悪性腎血管性高血圧の第一選択は血管インターベンションまたは手術が中心であり、薬物療法では ACE 阻害薬または ARB が第一選択となることが多いです。

## 臨床試験エビデンス

現在、acebutolol と悪性腎血管性高血圧に関する登録済みの臨床試験はありません。

## 安全性に関する考慮事項

### 重要な薬物相互作用

**Major 相互作用：**
- Dolasetron：QT 延長のリスクを増加させる可能性

**Moderate 相互作用：**
- 血糖降下薬（Glimepiride、Glipizide、Glyburide、各種インスリン）：低血糖症状を隠す可能性
- ステロイド（Betamethasone、Dexamethasone、Hydrocortisone、Prednisolone、Prednisone）：降圧効果を減弱させる可能性
- カルシウム製剤：心臓の伝導に影響する可能性
- アドレナリン（Epinephrine）：重度の高血圧反応を起こす可能性
- Bupropion：降圧効果を増強する可能性
- Cimetidine：acebutolol の血中濃度を上昇させる可能性

**Minor 相互作用：**
- 制酸薬（Aluminum hydroxide、Magnesium hydroxide）：吸収を減少させる可能性
- Aspirin：降圧効果にわずかに影響

### 禁忌
- 洞性徐脈
- 二度または三度房室ブロック
- 明らかな心不全
- 心原性ショック

安全性情報は添付文書をご参照ください。

## 結論と次のステップ

**判断：Hold**

**理由：**
Acebutolol の薬理作用（レニン放出の抑制）は、理論上は腎血管性高血圧に有益である可能性がありますが、現時点で支持する文献は1975年の1件のみです。また、現行の臨床ガイドラインでは、悪性腎血管性高血圧に対してインターベンション治療と RAS 阻害薬が優先的に推奨されています。

**推進に必要な事項：**
- 腎血管性高血圧において acebutolol と標準治療の効果を比較する前向き臨床試験を設計する
- 高レニン状態における beta 遮断薬の役割を探る機序研究をさらに行う
- 血管インターベンションまたは手術治療との併用戦略を検討する

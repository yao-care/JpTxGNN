## メロキシカム：関節リウマチから先天性骨系統疾患（acromesomelic dysplasia, Hunter-Thompson type）へ
{: .text-alpha }

## 一言要約

メロキシカムは COX-2 を選択的に阻害する鎮痛・抗炎症薬で、元々は関節リウマチの治療に使用されていました。
TxGNN モデルは**肢中間部異形成症 Hunter-Thompson 型 (acromesomelic dysplasia, Hunter-Thompson type)** に有効である可能性を予測していますが、この予測に対応する臨床試験・文献は **0 件**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 関節リウマチ（鎮痛薬、抗炎症薬、シクロオキシゲナーゼ2阻害薬） |
| 予測新規適応症 | 肢中間部異形成症 Hunter-Thompson 型 (acromesomelic dysplasia, Hunter-Thompson type) |
| TxGNN 予測スコア | 0.9992 |
| エビデンスレベル | L5 |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、メロキシカムは COX-2 を優先的に阻害する非ステロイド性抗炎症薬（NSAID）で、プロスタグランジンを介した炎症と疼痛を抑えます。関節リウマチでの使用が既存適応症です。

一方、予測された疾患は CDMP1/GDF5 の異常による遺伝性の骨格形成異常で、COX-2 を介した炎症が主な病態とは考えられていません。そのため、機序面からこの予測を裏付ける根拠は乏しく、TxGNN のスコアは高いものの生物学的な裏付けは弱いといえます。

参考として、上位 10 件の予測の中には機序的にやや説明しやすいものもあります。
- **脊椎関節症（感受性）**：NSAID は脊椎関節炎の対症療法として確立されていますが、この項目に対する試験・文献はありません。
- **リウマトイド因子陽性多関節型若年性特発性関節炎**：唯一、関連文献が 1 編あります（下記参照）。ただし、セレコキシブと非選択的 NSAID の安全性を扱うもので、メロキシカムに直接関わるものではありません。

## 安全性に関する考慮事項

- **禁忌に関連する疾患（知識グラフ上の情報、添付文書の記載ではありません）**：高血圧、腎疾患・腎機能障害、うっ血性心不全、胃炎、活動性消化性潰瘍、糖尿病、血液凝固障害、脳血管障害・脳梗塞、心筋梗塞、心血管疾患、貧血、高脂血症などが挙げられています。NSAID に共通するリスクと整合しますが、実際の禁忌は添付文書で確認が必要です。
- **薬物相互作用**：100 件の相互作用が確認されており、ほとんどが中等度です。主なものは以下のとおりです。

  - アセチルサリチル酸
  - メトホルミン、グリメピリド、クロルプロパミドなどの糖尿病治療薬
  - メサラジン、バルサラジド
  - バンコマイシン、カナマイシン
  - カリウム製剤、塩類下剤

## 結論と次のステップ

**決定：Hold**

**理由：**
予測第 1 位の疾患には臨床試験も文献もなく（L5）、機序的にも COX-2 阻害との関連が見いだせません。日本では販売されており有効な販売承認が 20 件ありますが、添付文書の安全性情報は未確認のため、現時点で先に進める根拠はありません。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と安全性評価
- メロキシカムの詳細な作用機序データ（MOA）
- 予測疾患に対する前臨床研究や機序研究
- 機序的に妥当性のある候補（脊椎関節症、若年性特発性関節炎など）への優先順位の見直しと、メロキシカム自体を扱った文献・試験の調査
- 日本で承認が取り消されている経緯の確認

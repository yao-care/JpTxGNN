# メロキシカム：関節リウマチから肢端中間肢異形成症（Hunter-Thompson型）へ

## 一言要約

メロキシカムは COX-2 を優先的に阻害する非ステロイド性抗炎症薬（NSAID）で、日本では関節リウマチなどの鎮痛・抗炎症に使用されています。
TxGNN モデルは**肢端中間肢異形成症 Hunter-Thompson 型 (acromesomelic dysplasia, Hunter-Thompson type)** に有効である可能性を予測していますが、
現在この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、メロキシカムは COX-2 を優先的に阻害し、プロスタグランジン介在性の炎症と疼痛を抑える NSAID です。関節リウマチでの有効性は確立されています。

一方、Hunter-Thompson 型は CDMP1/GDF5 に関連する骨格異形成症で、炎症が主体の疾患ではありません。COX-2 阻害との機序的な接点は確認されておらず、この予測は TxGNN の知識グラフ上の関連にのみ基づいています。スコアは高いものの、機序面・臨床面の裏付けは現時点でありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
臨床試験も文献もなく、機序的な根拠も乏しいため、モデル予測のみで評価を進める根拠がありません。なお、同じ予測リストの中では、RF 陽性多関節型若年性特発性関節炎（スコア 99.44%）が唯一、関連文献（NSAID の安全性に関する観察研究 1 編）を持つ候補で、エビデンスレベルは L4 です。優先して検討する価値があります。

**進める場合に必要なもの：**
- 日本の添付文書（PMDA）から警告・禁忌を取得し、安全性を確認すること
- 詳細な作用機序データ（MOA）の取得（DrugBank など）
- GDF5/CDMP1 関連の骨格異形成症と COX-2 経路の関連を示す前臨床・機序研究の調査
- 若年性特発性関節炎など、エビデンスのある候補を優先して再評価すること

※本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床での検証が必要です。

# センノシド：下剤から頭皮の単純性乏毛症へ

## 一言要約

センノシドはアントラキノン系の刺激性下剤で、元々は便秘の治療（下剤）に使用されていました。
TxGNN モデルは**頭皮の単純性乏毛症 (hypotrichosis simplex of the scalp)** に有効である可能性を予測していますが、
現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、センノシドはアントラキノン系の刺激性下剤で、大腸の運動と分泌に作用して排便を促すとされています。

一方、乏毛症は毛包の発生・機能に関わる疾患です。センノシドの下剤作用と毛包生物学との間に、確立した機序的な関連は見つかっていません。したがって、この予測の妥当性を裏付ける根拠は現時点でなく、TxGNN のスコアのみに基づく仮説にとどまります。

同じ予測群には、先天性乏毛症・稗粒腫、びまん性円形脱毛症、脱毛症、開放隅角緑内障、原発性遺伝性緑内障、食道静脈瘤（出血あり／なし）も含まれます。いずれも臨床試験・文献がなく、センノシドとの機序的な関連も示されていません。

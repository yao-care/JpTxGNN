# ニフェジピン：本態性高血圧症・狭心症から脳幹性前兆を伴う片頭痛へ

## 一言要約

ニフェジピンはカルシウムチャネル遮断薬で、日本では本態性高血圧症と狭心症の治療に使われています。
TxGNN モデルは**脳幹性前兆を伴う片頭痛 (Migraine with brainstem aura)** に有効である可能性を予測しています。ただし、裏付けは **臨床試験 0 件**、**文献 2 編**（前兆を伴う片頭痛全般を対象とした RCT 1 編とレビュー 1 編）にとどまります。しかもその RCT では、急性期治療としてニフェジピンが頭痛を悪化させました。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ニフェジピンは L 型カルシウムチャネルを遮断する血管拡張性のカルシウムチャネル遮断薬です。血圧降下薬として、本態性高血圧症と狭心症での有効性が確立しています。

片頭痛の病態には、脳血管攣縮や皮質拡延性抑制、神経の過興奮が関わると考えられています。カルシウムチャネル遮断によってこれらが抑えられれば、機序的には適用可能かもしれません。

ただし、入手できた文献は片頭痛全般、または前兆を伴う片頭痛全般を扱っています。脳幹性前兆というサブタイプに特化したエビデンスはありません。レビューでも、ニフェジピンを含むカルシウム拮抗薬の予防効果は「確立されたとは言えない」とされています。

## 結論と次のステップ

**決定：Hold**

**理由：**
最上位の予測（脳幹性前兆を伴う片頭痛）には臨床試験がなく、唯一の RCT は前兆を伴う片頭痛の急性発作で頭痛の増悪を示しています。加えて、日本の添付文書に基づく安全性確認が未完了のため、現時点では研究上の問いにとどまります。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングに必須）
- DrugBank からの作用機序（MOA）データの取得
- 脳幹性前兆を伴う片頭痛に特化した臨床・症例エビデンスの調査
- 同時に予測されている「片頭痛 (migraine disorder)」で、予防投与を対象とした小規模 RCT と、フルナリジンに劣る可能性を示す報告の精査

※ 本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的な検証を経て初めて応用できます。

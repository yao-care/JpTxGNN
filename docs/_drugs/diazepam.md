# ジアゼパム：不安・てんかんから不眠症へ

## 一言要約

ジアゼパム（Diazepam）は GABA-A 受容体の正のアロステリック調節薬として、世界的に不安障害・てんかん・筋痙攣治療に使用されているベンゾジアゼピン系薬剤です。TxGNN モデルは**不眠症 (Insomnia)** に有効である可能性を予測しており、現在 **24 件の臨床試験**と **18 編の文献**がこの方向性を支持しています。日本では市販実績がないものの、ベンゾジアゼピン系薬剤の不眠症への鎮静催眠効果については豊富なエビデンスが存在します。

## この予測が妥当である理由

ジアゼパムは GABA-A 受容体のベンゾジアゼピン結合部位に作用し、クロライドイオンチャネルの開口頻率を増強することで中枢神経系活動を広範に抑制します。この機序は入眠潜時の短縮と総睡眠時間の延長をもたらし、不眠症治療に対する直接的な薬理学的根拠となっています。詳細な MOA データは現時点で未取得ですが、PMID 39581171 のレビューはジアゼパムを代表的 GABA-A 受容体正のアロステリック調節薬として詳述しており、てんかん・不安・不眠・運動障害への治療応用を系統的に整理しています。

不眠症とジアゼパムの関連性を直接示す証拠として、PMID 6113175（1981 年）は外来不眠患者 100 名を対象とした 7 日間二重盲検 RCT であり、ジアゼパム（5 mg）が入眠時間の短縮と睡眠持続時間の延長においてロルメタゼパム（1 mg）と同等の効果を示すことを確認しています。これはジアゼパムの不眠症適応に対する最も直接的な臨床エビデンスです。また、多数の不眠症動物モデル研究においてジアゼパムが陽性対照薬として標準的に使用されている事実（PMID 29479317、PMID 37776625 等）も、その不眠症への薬理効果が研究コミュニティで広く認知されていることを示しています。

一方で、PMID 40570297（2025 年）のコホート研究は、慢性的なベンゾジアゼピン使用が高齢者の Non-REM 徐波振動・睡眠紡錘波を抑制し睡眠の質を長期的に低下させるリスクを示しています。PMID 7525193 のガイドラインもベンゾジアゼピン系催眠薬は一過性・短期不眠に適用を限定することを推奨しており、依存性・耐性形成・認知機能への影響を考慮したリスク管理が不可欠です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
ジアゼパムは GABA-A 受容体を介した確立した鎮静催眠機序を有し、PMID 6113175 の直接比較 RCT と複数のコホート研究・臨床試験群がベンゾジアゼピン系薬剤の不眠症への効果を支持しています。ただし、依存性・耐性・慢性使用による睡眠構造変容リスクが明確であり、適切な使用期間の管理と定期的なリスク評価が必須条件です。

**進める場合に必要なもの：**
- 日本 PMDA 添付文書の入手と警告・禁忌情報の確認（DG001：現在 Blocking データギャップ）
- DrugBank API による詳細 MOA データの補完（DG002：High データギャップ）
- 短期・間欠使用に限定した投与プロトコルの策定（使用期間・漸減スケジュールを含む）
- 依存性・乱用リスクのモニタリング計画の立案
- 高齢者・認知機能低下リスク群に対する特別な安全性評価の実施

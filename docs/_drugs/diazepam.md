# ジアゼパム：神経症における不安から 不眠症 へ

## 一言要約

ジアゼパムはベンゾジアゼピン系の抗不安薬で、日本では神経症における不安、うつ病、熱性けいれんなどに使用されてきました。
TxGNN モデルは**不眠症 (insomnia)** に有効である可能性を予測しています（スコア 99.99%）。
ただし、現時点で関連する臨床試験の登録はなく、裏付けとなるのは**文献 18 編**（多くは総説や前臨床研究）にとどまります。

| 既存適応症 | 神経症における不安、うつ病、熱性けいれん（抗不安薬・抗てんかん薬・催眠鎮静薬） |
| 予測新規適応症 | 不眠症 (insomnia) |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし文献によると、ジアゼパムは GABA-A 受容体の陽性アロステリックモジュレーター（PAM）で、抑制性神経伝達を高めて鎮静・催眠作用を示します。

既存の適応症である神経症における不安は、不眠と併存することが多く、日本での承認分類にも「催眠鎮静薬」が含まれます。同じ GABA-A 増強作用が入眠を助けると考えられ、機序面では不眠症への適用に無理はありません。

一方、長期使用では睡眠構造の乱れ、依存、認知機能への影響が報告されています。不眠症に対する有効性を直接検証した新しい研究は、今回のデータにはありません。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**：肝不全・肝疾患、緑内障（開放隅角・閉塞隅角）、重症筋無力症、睡眠時無呼吸症候群、呼吸不全、肺疾患、物質関連障害・依存などが挙げられています。これは添付文書の記載ではなく、予測モデルの知識グラフに基づく情報です。
- **薬物相互作用**：100 件の相互作用が登録されています。主なものは次のとおりです。
  - 重大（Major）：モルヒネ（中枢抑制・呼吸抑制の増強）
  - 中等度（Moderate）：ブプロピオン、アプレピタント、オメプラゾール、シメチジン、クラリスロマイシン、シサプリド、ミコナゾール、メトクロプラミドなど
- **文献上の安全性シグナル**：長期使用による依存、睡眠構造の変化、高齢者の転倒・認知機能への影響、乳癌リスク増加の可能性が報告されています。

添付文書の警告・禁忌の詳細は、今回のデータでは確認できていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- GABA-A 増強による鎮静作用という機序上の裏付けはありますが、臨床試験の登録がなく、文献も総説・前臨床研究・安全性報告が中心です。
- 日本では有効な承認が残っておらず、依存や睡眠構造への悪影響も懸念されます。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得（現状は安全性評価の前提となる情報が不足）
- 詳細な作用機序データ（DrugBank など）の補完
- 不眠症に対するジアゼパムの無作為化比較試験データの調査、または新規試験の計画
- オレキシン受容体拮抗薬など新規睡眠薬との位置づけ比較
- 依存・離脱・高齢者での安全性を考慮した使用条件の設定

なお、予測順位 2 位以降（馬尾症候群、ADHD、各種薬物乱用、神経因性膀胱など）は、臨床試験がなく、機序上の根拠も乏しいか間接的です。現時点では Hold が妥当です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ベネトクラクス：既存適応症（データ未取得）から前胚中心型慢性リンパ性白血病/小リンパ球性リンパ腫へ

## 一言要約

ベネトクラクス（日本の商品名：ベネクレクスタ錠）は選択的 BCL-2 阻害薬で、日本では市販されています。TxGNN モデルは、最上位の予測新規適応症として**前胚中心型の慢性リンパ性白血病/小リンパ球性リンパ腫（pregerminal center CLL/SLL）**を挙げています。ただし、直接の裏付けとなる臨床試験は **0 件**で、文献は **1 編**（間接的な総説）にとどまります。エビデンスは限定的で、現時点の判断は **Hold** です。

## この予測が妥当である理由

ベネトクラクスは BCL-2 を選択的に阻害する BH3 ミメティクスです。BCL-2 に依存して生き残っている CLL/SLL 細胞で、アポトーシスを回復させます。詳細な作用機序データ（DrugBank の MOA 項目）は現在ありません。上記は予測根拠として提示された機序の説明です。

CLL/SLL は BCL-2 依存性の B 細胞腫瘍です。予測対象の「前胚中心型」は、免疫グロブリン重鎖可変領域遺伝子が未変異の CLL/SLL 亜型（U-CLL）に対応します。したがって機序的には適用可能である可能性があります。

ただし、今回提示された根拠は腫瘍 B 細胞受容体の生物学を扱う総説 1 編だけです。この亜型に対するベネトクラクス固有のデータは含まれていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
この亜型を直接検証した臨床試験がなく、文献も間接的な総説 1 編のみです。加えて、添付文書の警告・禁忌が未取得のため、安全性スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析（進行を止める要因）
- DrugBank からの作用機序（MOA）データの補完
- 前胚中心型（IGHV 未変異）CLL/SLL でのベネトクラクス固有の臨床成績または後方視データの確認
- 既存適応症（承認適応症）の情報の補完

なお、同じ予測リストの「骨髄性白血病」は、ベネトクラクス併用の臨床試験が複数あり、エビデンスレベルは L2 です。優先的に評価する候補として別途検討する価値があります。

本結果は研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床的検証を経る必要があります。

# ベネトクラクス：急性リンパ性白血病・リヒター症候群から 胚中心前型慢性リンパ性白血病/小リンパ球性リンパ腫へ

## 一言要約

ベネトクラクスは BCL-2 を選択的に阻害する経口薬で、知識グラフ上の既存適応症は急性リンパ性白血病とリヒター症候群です。
TxGNN モデルは**胚中心前型慢性リンパ性白血病/小リンパ球性リンパ腫（pregerminal center CLL/SLL）**に有効である可能性を予測しています。
ただし、この疾患に直接対応する臨床試験は **0 件**、文献は **1 編**（B 細胞受容体の構造と機能に関する基礎的な解析で、ベネトクラクスは検証されていません）にとどまり、エビデンスは限定的です。

## この予測が妥当である理由

現在、詳細な作用機序データは取得できていません。ただし、ベネトクラクスは BCL-2 を選択的に阻害する薬剤として知られています。BCL-2 はミトコンドリア経路のアポトーシスを抑える生存タンパク質で、CLL/SLL 細胞はこれに強く依存しています。BCL-2 を阻害すれば、がん細胞のアポトーシスが回復すると考えられます。

既存適応症の急性リンパ性白血病とリヒター症候群は、いずれもリンパ系腫瘍です。CLL/SLL もリンパ系腫瘍で、BCL-2 依存性という共通の生物学的基盤があります。そのため、機序の面では新規適応症として自然な候補です。

一方、今回提示された唯一の文献は、腫瘍 B 細胞受容体の構造と機能を扱った解析です。CLL の生物学的理解には役立ちますが、ベネトクラクスの効果を直接検証したものではありません。機序上の裏付けは間接的です。

## 結論と次のステップ

**決定：Hold**

**理由：**
この予測疾患に直接対応する臨床試験がなく、文献も BCR の基礎解析 1 編のみで、エビデンスは L4 にとどまります。また、日本の添付文書の警告・禁忌が未確認で、安全性スクリーニングに進めない状態です。

なお、同じ薬剤の他の予測候補では、より強いエビデンスが確認されています。
- **骨髄性白血病（AML）**：L1 で、Phase 3 試験を含む多数の試験があります。
- **慢性骨髄性白血病（BCR-ABL1 陽性）**および**濾胞性リンパ腫**：L2 です。
- **CLL 全般**：間接的な支持として、再発・難治性 CLL を対象とした Phase 3 試験 MURANO（PMID 40009494）の最終解析があります。ベネトクラクス＋リツキシマブがベンダムスチン＋リツキシマブより無増悪生存期間・全生存期間で優れていたと報告されています。

優先順位を検討する際は、これらの候補を先に評価するのが現実的です。

**進める場合に必要なもの：**
- 日本の添付文書（警告・禁忌・用法用量）の取得と確認
- 詳細な作用機序データの補充
- IGHV 未変異/変異などの CLL/SLL サブタイプ別のベネトクラクスのデータ収集
- 日本での承認整理の経緯と現在の供給・承認状況の確認
- CYP3A 関連の併用薬管理と、腫瘍崩壊症候群に対するモニタリング計画の策定

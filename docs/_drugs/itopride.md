# イトプリド：消化管運動改善薬から小腸クローン病へ

## 一言要約

イトプリドは、ドパミン受容体拮抗薬に分類される消化管運動改善薬です。
TxGNN モデルは**小腸クローン病 (small bowel Crohn disease)** に有効である可能性を予測しています。
ただし、関連する臨床試験や文献はなく、**モデル予測のみ**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 消化管運動改善薬、ドパミン受容体拮抗薬 |
| 予測新規適応症 | 小腸クローン病 (small bowel Crohn disease) |
| TxGNN 予測スコア | 99.90% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認は全て取り消し済み（市販中の製品なし） |
| 承認番号数 | 4 件（すべて取り消し） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、イトプリドはドパミン D2 受容体拮抗作用とアセチルコリンエステラーゼ阻害作用を併せ持つ消化管運動改善薬で、消化管運動の亢進を目的に使われてきました。

一方、クローン病は炎症性の腸疾患であり、イトプリドの作用機序と炎症の病態との間に確立した関連は見当たりません。スコアは高いものの、あくまでモデル上の予測です。仮に効果があるとしても、運動機能の改善による症状緩和にとどまる可能性が高いと考えられます。

### その他の予測候補

同じモデルは、以下の疾患も予測していますが、いずれも臨床試験・文献はなく、L5（Hold）です。

| 順位 | 予測疾患 | TxGNN スコア | 機序面の評価 |
|------|---------|-------------|-------------|
| 2 | 静脈不全 (venous insufficiency) | 99.23% | 消化管での D2 拮抗・AChE 阻害と静脈血管機能障害との間に妥当な関連は見当たらない |
| 3 | 無酸症 (achlorhydria) | 99.16% | 上部消化管運動や胃排出は改善しうるが、胃酸分泌は回復しない。効果があっても運動不全の症状緩和に限られる |
| 4 | 食道裂孔ヘルニア (hiatus hernia) | 99.02% | 下部食道括約筋の緊張や胃排出を高め、逆流症状に理論上は有用かもしれないが、構造的な欠損は改善しない |

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測スコアは高いものの、臨床試験・文献がなく、エビデンスレベルは L5 です。
- 作用機序面でもクローン病の炎症病態との関連は確認できません。
- 日本の承認も全て取り消されており、現時点で再利用を進める根拠は乏しい状況です。

**進める場合に必要なもの：**
- 詳細な作用機序データ（MOA）の取得
- 添付文書の警告・禁忌情報の確認と安全性スクリーニング
- 小腸クローン病に対する前臨床研究や機序研究によるエビデンスの構築
- 承認取り消しの経緯の確認と、剤形・投与経路の適合性評価

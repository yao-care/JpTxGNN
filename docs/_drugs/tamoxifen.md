# タモキシフェン：乳癌から乳腺上皮内癌（Breast Carcinoma in Situ）へ

## 一言要約

タモキシフェンはエストロゲン受容体調節薬で、元々乳癌の治療に使用されていました。
TxGNN モデルの最上位予測は乳房パジェット病 (Mammary Paget Disease) ですが、エビデンスが最も充実しているのは**乳腺上皮内癌 (Breast Carcinoma in Situ)** です。この疾患には **37 件の臨床試験**と **20 編の文献**があり、うち複数の Phase 3 RCT が支持しています。

> 補足：予測順位 1 位の乳房パジェット病は、臨床試験 1 件（タモキシフェンの有効性を検証したものではない）と症例報告中心の文献のみで、エビデンスレベルは L4 です。本レポートでは、エビデンスが最も強い上皮内癌を主な評価対象とし、他の予測は末尾にまとめます。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、タモキシフェンは抗悪性腫瘍薬に分類されるエストロゲン受容体調節薬で、ER 陽性乳癌での有効性が確立しています。

乳腺上皮内癌（DCIS など）は浸潤性乳癌の前駆病変であり、ER 陽性例ではエストロゲン刺激で増殖します。タモキシフェンは ER シグナルを遮断するため、同側・対側の再発を抑える機序的な根拠があります。

この予測はランダム化試験でも裏付けられています。NSABP B-24 や TAM-01 などが、DCIS・乳腺上皮内腫瘍での再発抑制効果を示しています。

## 安全性に関する考慮事項

- **禁忌関連疾患（ナレッジグラフ上の関連、添付文書の記載ではありません）**：血小板減少症、白血球減少症、脳卒中・脳血管障害・脳梗塞、肺塞栓症、高カルシウム血症、腎石灰化症、リン代謝異常、視覚障害・失明。
- **薬物相互作用**：100 件が確認されています。主な **Major** は、ブプロピオン、シメチジン、ロルカセリン、ドラセトロン、エリグルスタット、シサプリド、デクスフェンフルラミン、フェンフルラミンです。**Moderate** には、ファモチジン、ロペラミド、アプレピタント、デキサメタゾン、クラリスロマイシン、グラニセトロン、レボフロキサシンなどがあります。CYP2D6 関連の相互作用に特に注意が必要です。

警告・禁忌の添付文書情報は、今回のデータには含まれていません。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
乳腺上皮内癌では、TAM-01 や NSABP B-24 などの Phase 3 RCT が再発抑制を示しており、エビデンスは L1 です。ただし、日本の承認はすべて整理済みで市販品がなく、安全性の添付文書情報も未確認のため、条件付きでの前進とします。

**進める場合に必要なもの：**
- 日本国内での製品入手可否の確認（現在は承認が整理済み）
- 添付文書（警告・禁忌）の入手と確認（PMDA）
- 作用機序データの補充（DrugBank）
- ER 状態の確認、血栓塞栓症・子宮内膜リスクの評価、CYP2D6 関連の相互作用レビュー
- 日本人集団での用量（5 mg/日と 20 mg/日）と投与期間の検討

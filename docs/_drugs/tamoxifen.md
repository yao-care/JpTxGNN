# タモキシフェン：乳癌から乳房パジェット病へ

## 一言要約

タモキシフェンは選択的エストロゲン受容体調節薬（SERM）で、日本では元々乳癌の治療に使用されています。
TxGNN モデルは**乳房パジェット病 (mammary Paget disease)** に有効である可能性を予測しています。ただし、裏付けとなるのは **1 件の間接的な臨床試験**と **12 編の文献**で、タモキシフェンの効果を直接示すのは症例報告レベルにとどまります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報では、タモキシフェンは「抗悪性腫瘍薬、エストロゲン受容体調節薬」に分類され、乳癌に対する有効性が確立しています。

乳房パジェット病は、乳頭・乳輪部に現れる稀な乳癌の一型です。多くは乳管内癌や浸潤性乳管癌を伴います。タモキシフェンはエストロゲン受容体 (ER) を拮抗的に阻害するため、パジェット細胞や背景の癌細胞がホルモン受容体陽性の場合に限り、機序的に適用可能と考えられます。

ただし、根拠は症例レベルの報告に限られます。標準治療は手術（乳房切除、または乳房温存手術＋放射線療法）で、薬物療法の位置づけは確立していません。

## 結論と次のステップ

**決定：Hold**

**理由：**
乳房パジェット病に対するタモキシフェンの根拠は少数の症例報告のみで、前向き試験はありません。唯一の Phase 3 試験（NCT00002920）も、子宮内膜の安全性を扱うもので、パジェット病への有効性を評価したものではありません。

**進める場合に必要なもの：**
- ER・PgR・HER2 の受容体状態別に、タモキシフェンの効果を評価する症例集積または前向き研究
- PMDA の添付文書に基づく警告・禁忌の確認（CYP2D6/CYP3A4 関連の薬物相互作用を含む）
- 詳細な作用機序データ（MOA）の整備

**参考：** 同じ Evidence Pack 内の **乳房上皮内癌**（L1、Proceed with Guardrails）と **エストロゲン受容体陽性乳癌**（L1、Proceed with Guardrails）は、無作為化試験による裏付けがより強く、優先的な検討候補です。

*本レポートは研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床での検証が必要です。*

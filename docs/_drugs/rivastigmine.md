# リバスチグミン：アルツハイマー型認知症から緑内障へ

## 一言要約

リバスチグミンはアセチルコリンエステラーゼ阻害薬で、元々アルツハイマー型認知症の治療に使用されています。
TxGNN モデルは**緑内障 (Glaucoma)** に有効である可能性を予測していますが、現時点では臨床試験はなく、**3 編の文献**（ウサギ試験、in vitro、総説）があるのみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、リバスチグミンはコリンエステラーゼ阻害薬に分類され、アルツハイマー型認知症での有効性が確立されています。機序的には緑内障にも適用できる可能性があります。

眼内でアセチルコリンが増えると、房水の流出が促進されて眼圧が下がる可能性があります。眼圧は緑内障で唯一、介入可能な主要リスク因子です。

ただし、この根拠はウサギの点眼試験と in silico / in vitro 研究にとどまり、ヒトでの検証はありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
緑内障に対する根拠は、ウサギ試験と in vitro / 総説にとどまり（L4）、ヒトでの臨床試験がありません。また、PMDA 添付文書に基づく安全性確認が未完了で、これが先へ進めない阻害要因になっています。

**進める場合に必要なもの：**
- PMDA 添付文書（警告・禁忌）の取得と解析による安全性スクリーニング
- 詳細な作用機序データ（DrugBank 等からの MOA 取得）
- 投与経路の適合性評価。国内の既存剤形はすべて経皮吸収型のテープ剤で、緑内障に必要な眼局所投与とは異なります
- ヒトでの眼圧低下を検証する前臨床・臨床エビデンスの追加

本結果は研究参考用であり、医療上の助言ではありません。臨床での検証を経るまで、診療への適用はできません。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

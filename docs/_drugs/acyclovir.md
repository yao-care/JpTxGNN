# アシクロビル：単純ヘルペス感染症から点状表層角結膜炎へ

## 一言要約

アシクロビルは抗ヘルペスウイルス薬（DNAポリメラーゼ阻害薬）で、単純ヘルペス、帯状疱疹、水痘、性器ヘルペス、単純ヘルペスウイルス性角膜炎の治療に使われています。
TxGNN モデルは**点状表層角結膜炎 (Punctate Epithelial Keratoconjunctivitis)** に有効である可能性を予測しています。しかし、この予測を支持する臨床試験は **0 件**で、文献は **2 編**（いずれも直接の裏付けにならない症例集積）にとどまり、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）は取得できていません。承認情報では、アシクロビルは「抗ウイルス薬、DNAポリメラーゼ阻害薬」に分類されています。一般に、ヘルペスウイルス感染細胞内でウイルスのチミジンキナーゼによって活性化され、ウイルスDNA合成を阻害します。

既存適応症にはヘルペス性角膜炎があり、眼軟膏（3%）も国内で承認されています。このため、眼表面のウイルス感染症という点では TxGNN の予測に一定の連想性があります。

一方、点状表層角結膜炎は多くの場合アデノウイルスや微胞子虫などが原因で、ヘルペスウイルスではありません。アシクロビルの活性化にはヘルペスウイルス由来のチミジンキナーゼが必要なので、現時点で機序的な裏付けは確立していません。スコアは高いものの、あくまでモデル上の予測です。

## 結論と次のステップ

**決定：Hold**

**理由：**
点状表層角結膜炎については、臨床試験がなく、文献も直接の裏付けにならず、原因ウイルスの面でも機序的なつながりが弱いためです。エビデンスはモデル予測のみ（L5）で、現時点では進める根拠が足りません。

なお、同じ Evidence Pack の他の予測候補には、より根拠のあるものがあります。
- **尋常性疣贅（common wart）**：病巣内アシクロビルを対象とした比較試験が複数あり、L2 です。
- **眼窩領域疾患（disease of orbital region）**：眼ヘルペスでの Phase 3 試験（HEDS II）があり、L2 です。ただし、この根拠は眼窩疾患そのものではなく眼ヘルペス亜型に対するものです。

優先順位を付けるなら、まずこれらの検討が現実的です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（現在は未取得で、安全性スクリーニングの前提となる）
- DrugBank からの作用機序（MOA）データの取得
- 点状表層角結膜炎の原因（ヘルペス性かどうか）を整理し、アシクロビルとの機序的関連を再評価すること
- 眼軟膏（3%）の既承認剤形との投与経路の適合性確認
- 直接の臨床エビデンス（症例報告や前向き試験）の探索
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

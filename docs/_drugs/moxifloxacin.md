# モキシフロキサシン：眼瞼炎・結膜炎から高アミラーゼ血症へ

## 一言要約

モキシフロキサシンはフルオロキノロン系の抗菌薬で、日本では主に眼瞼炎・結膜炎の点眼液として使われています。
TxGNN モデルは**高アミラーゼ血症 (Hyperamylasemia)** に有効な可能性を予測していますが、**臨床試験も文献も 0 件**で、モデル予測のみの段階です。
なお、予測リスト全体では**腺ペスト (Bubonic plague)** に前臨床の裏付け（in vitro・動物試験）があります。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。一般に、モキシフロキサシンは細菌の DNA ジャイレースとトポイソメラーゼ IV を阻害する抗菌薬です。日本の点眼液は眼瞼炎・結膜炎で承認されており、経口錠（アベロックス）も市販されています。

一方、高アミラーゼ血症は臨床検査値の異常所見です。抗菌作用との間に、妥当な機序的つながりは見当たりません。スコアは高いものの、モデルの予測にとどまります。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測第 1 位の高アミラーゼ血症には、臨床試験・文献のいずれもなく、機序的な根拠もありません（L5）。高いスコアはモデル予測のみに基づきます。また、安全性情報（添付文書の警告・禁忌）が未取得のため、安全性の初期スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（進行のブロック要因）
- DrugBank からの作用機序 (MOA) データの取得
- 予測第 1 位の高アミラーゼ血症について、機序仮説の再検討と文献の再調査
- 研究を進める場合は、エビデンスのある腺ペスト（前臨床）を優先候補として検討し、ヒトデータの有無を確認する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

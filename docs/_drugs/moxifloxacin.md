# モキシフロキサシン：眼瞼炎・結膜炎から高アミラーゼ血症へ

## 一言要約

モキシフロキサシンは抗菌薬（核酸合成阻害薬）で、日本では元々眼瞼炎・結膜炎の治療に点眼薬として使用されていました。
TxGNN モデルは**高アミラーゼ血症 (Hyperamylasemia)** に有効である可能性を予測していますが、この疾患を直接支持する臨床試験・文献はありません。
予測スコアは非常に高いものの、実際のエビデンスは**ゼロ**で、モデル予測のみの段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 眼瞼炎、結膜炎 |
| 予測新規適応症 | 高アミラーゼ血症 (Hyperamylasemia) |
| TxGNN 予測スコア | 99.98% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売終了のみ（有効な承認なし） |
| 承認番号数 | 6 件（すべて整理済み・失効） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、モキシフロキサシンはフルオロキノロン系抗菌薬で、細菌の DNA ジャイレースとトポイソメラーゼ IV を阻害することで抗菌作用を示します。

一方、高アミラーゼ血症は感染症ではなく検査値の異常であり、抗菌薬の作用機序との間に妥当な関連は見いだせません。今回のスコアは知識グラフに基づく計算上の予測にとどまり、機序面での裏付けはありません。

参考までに、同じく上位に挙がった他の予測候補のうち、**腺ペスト (Bubonic plague)** は抗菌作用に基づく妥当な理由があります。in vitro 薬力学モデルや動物実験でペスト菌（*Yersinia pestis*）への有効性が示されており、再利用の研究課題としてはこちらの方が現実的です（スコア 99.41%、エビデンスレベル L3、ヒトでの臨床エビデンスは未確認）。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**（添付文書ではなくモデルの知識グラフに基づく）：QT延長症候群（先天性を含む）、トルサード・ド・ポワンの、突然の心停止、心伝導障害、心筋虚血、冠動脈疾患、てんかん、肝硬変、薬剤性肝障害、低カリウム血症、腱炎、末梢神経障害、重症筋無力症、偽膜性大腸炎（*C. difficile* 大腸炎）など。
- **薬物相互作用**（100 件の相互作用が確認されています。主なもの）：
  - 重大（Major）：ヒドロコルチゾン、デキサメタゾン、ベタメタゾン、トリアムシノロン（コルチコステロイド類）、ブプロピオン、クロルプロパミド
  - 中等度（Moderate）：メトホルミン、ピオグリタゾン、アカルボースなどの糖尿病治療薬、ファモチジン、アスピリン、カルシウム製剤など

## 結論と次のステップ

**決定：Hold**

**理由：**
- 高アミラーゼ血症は検査値の異常で、抗菌薬との機序的関連が見いだせず、臨床試験・文献のいずれもありません。
- さらに日本では有効な承認がなく、添付文書に基づく安全性情報も未確認のため、現時点で再利用検討を進める根拠はありません。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌の確認（安全性評価の前提条件）
- 詳細な作用機序データの整備
- 高アミラーゼ血症との関連を示す前臨床または臨床データ
- 代替候補として、腺ペスト（Bubonic plague）など抗菌作用に基づく適応の優先的な検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

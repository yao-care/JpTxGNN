# Homatropine Methylbromide：從胃腸道疾病到胃十二指腸炎

## 一言まとめ

Homatropine methylbromide 原本用於治療胃酸過多、胃潰瘍及胃腸道痙攣。
TxGNN 模型預測它可能對**胃十二指腸炎 (gastroduodenitis)** 有效，
但目前**尚無臨床試驗或文獻**直接支持這個新適應症。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 胃酸過多、消化性潰瘍、胃腸道痙攣 |
| 予測新適応症 | 胃十二指腸炎 (gastroduodenitis) |
| TxGNN 予測スコア | 99.39% |
| エビデンスレベル | L5 |
| 日本上市 | 有效許可證 |
| 承認数 | 105 張（多為複方） |
| 推奨判断 | Hold |

## この予測が妥当な理由

Homatropine methylbromide 是一種抗膽鹼藥物（副交感神經抑制劑），
透過阻斷乙醯膽鹼對 M 型蕈毒鹼受體的作用，減少胃酸分泌並緩解平滑肌痙攣。

**預測合理性分析：**
- 胃十二指腸炎（gastroduodenitis）是胃和十二指腸黏膜的發炎狀態
- 該藥物現有適應症已包括「胃炎」，與胃十二指腸炎有高度相似性
- 抗膽鹼作用可減少胃酸分泌，理論上有助於減輕黏膜刺激
- 預測分數高達 99.39%，顯示知識圖譜中藥物-疾病關聯強

**機轉關聯：**
此預測屬於適應症的自然延伸，而非全新的老藥新用方向。

## 安全性に関する考慮事項

- **藥物交互作用**：未在 DDI 資料庫中找到相關交互作用資訊
- **禁忌症**：抗膽鹼藥物一般禁用於青光眼、尿滯留、重症肌無力患者
- **副作用**：口乾、視力模糊、便秘、心跳加快等抗膽鹼效應

安全性情報は添付文書をご参照ください。

## 結論と次のステップ

**判断：Hold**

**理由：**
- 預測適應症（胃十二指腸炎）與現有適應症（胃炎）高度重疊，臨床新穎性有限
- 缺乏直接的臨床試驗和文獻證據支持
- 抗膽鹼藥物在胃腸道疾病的角色已逐漸被 PPI 等新藥取代

**推進に必要な事項：**
- 確認此適應症是否已在臨床實務中使用
- 與現有治療（如 PPI、H2 受體拮抗劑）進行療效比較研究
- 評估此適應症在健保給付或藥證擴展方面的價值

# ボノプラザン：胃・十二指腸潰瘍から活動性消化性潰瘍へ

## 一言要約

ボノプラザンはカリウム競合型アシッドブロッカー（P-CAB）で、元々胃潰瘍、十二指腸潰瘍、逆流性食道炎などの治療に使用されていました。
TxGNN モデルは**活動性消化性潰瘍 (active peptic ulcer disease)** に有効である可能性を予測しています。
この予測に関する臨床試験の登録はありませんが、**メタアナリシスや RCT を含む文献**が方向性を支持しています。

## クイック概要

|------|------|
| 既存適応症 | 胃潰瘍、十二指腸潰瘍、逆流性食道炎、胃食道逆流症 |
| 予測新規適応症 | 活動性消化性潰瘍 (active peptic ulcer disease) |

## この予測が妥当である理由

ボノプラザンは胃のプロトンポンプ（H+/K+-ATPase）を可逆的に阻害し、強力で持続的な胃酸抑制をもたらします。プロトンポンプ阻害薬（PPI）と異なり、酸による活性化を必要としません。現在、詳細な作用機序データはありませんが、上記の薬理作用は文献から確認できます。

既存適応症の胃潰瘍・十二指腸潰瘍と、予測された活動性消化性潰瘍は、どちらも酸依存性の上部消化管粘膜障害です。そのため、胃酸抑制による治癒促進や H. pylori 除菌療法での併用という機序が共通して適用できます。

同じ機序から、上位の予測には吻合部（胃空腸）潰瘍、出血性十二指腸炎なども挙がっています。ただし、無酸症、ディーラフォイ病変、幽門痙攣、胃拡張、カスケード胃は、機序的関連が乏しいか、むしろ逆効果になり得ます。

## 安全性に関する考慮事項

- **薬物相互作用**：現在の相互作用データは薬理学的標的（ATP4A、胃プロトンポンプ）に関する情報のみで、具体的な併用禁忌薬は確認されていません。
- **長期使用の留意点**：長期使用後に胃粘膜の変化、反跳性の胃酸過剰分泌、十二指腸粘膜病変が報告された症例があります。また、ボノプラザンに関連する胃粘膜発赤や白色球状外観病変の症例報告もあります。

その他の警告・禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
- 活動性消化性潰瘍は既存適応症（胃・十二指腸潰瘍）と機序的にほぼ重なり、メタアナリシスや RCT を含む文献が支持しています。一方、このレポートの範囲では臨床試験登録がなく、日本の承認は取り消し済みで、安全性の一次情報も不足しているため、条件付きの推進が妥当です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得と安全性スクリーニング
- 詳細な作用機序データ（DrugBank など）の補完
- 日本での承認取り消しの経緯と現在の販売状況の確認
- 活動性消化性潰瘍を対象とした臨床試験デザインの検討
- 長期使用時の反跳性酸分泌や胃粘膜変化に対するモニタリング計画

なお、順位の低い予測（無酸症、ディーラフォイ病変、幽門痙攣、胃拡張、カスケード胃）は保留（Hold）とします。吻合部潰瘍、消化性潰瘍穿孔、食道裂孔ヘルニア、出血性十二指腸炎は、機序的な妥当性はあるものの直接的エビデンスが限られ、研究課題（Research Question）の段階です。

# ボノプラザン：胃・十二指腸潰瘍、逆流性食道炎から活動性消化性潰瘍へ

## 一言要約

ボノプラザンはカリウム競合型アシッドブロッカー（P-CAB）で、日本では胃・十二指腸潰瘍や逆流性食道炎などの治療に使われています。
TxGNN モデルは**活動性消化性潰瘍 (Active Peptic Ulcer Disease)** に有効である可能性を予測しています。ただし、この疾患は既存適応症とほぼ重なるため、「新規適応症」というより既存用途の再確認に近い予測です。
根拠は **2 件の臨床試験**と **20 編の文献**で、ボノプラザンの潰瘍に対する第 3 相 RCT も含まれます。

## この予測が妥当である理由

DrugBank の作用機序（MOA）データは入力に含まれていません。文献によると、ボノプラザンは胃壁細胞の H⁺/K⁺-ATPase を可逆的に阻害します。PPI と違って酸による活性化が不要で、速やかに効き、24 時間にわたって酸分泌を抑えます。CYP2C19 の多型や食事のタイミングの影響も受けにくいとされています（PMID 42084149）。

消化性潰瘍は胃酸による粘膜傷害が主因なので、強力で持続的な酸分泌抑制は潰瘍治癒と再発予防に直結します。既存適応症（胃・十二指腸潰瘍）と予測された疾患は病態がほぼ同じです。第 3 相 RCT（PMID 28988197）でも、NSAID 潰瘍の二次予防でランソプラゾールに対する非劣性が検証されています。

このため、機序面の妥当性は高いといえます。一方で、予測が既存適応症の言い換えに近い点は、次の判断で考慮が必要です。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
潰瘍に対する有効性を支持する第 3 相 RCT があり、機序も明確で、日本ではすでに市販されています。ただし、予測疾患が既存適応症とほぼ重なること、添付文書（警告・禁忌）と作用機序データが未取得であること、DDI データが空であることから、安全性の最終評価（S3）は保留です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌・適応症本文の取得（現在の最優先の不足データ）
- DrugBank からの作用機序（MOA）データの取得
- 相互作用（DDI）の再照会
- 「活動性消化性潰瘍」が既存の承認適応症（胃潰瘍・十二指腸潰瘍）と重複するかの確認。重複する場合は、新規適応症ではなく既存用途の裏付けとして位置づける
- 長期使用時のリスク（反跳性の酸分泌亢進、胃粘膜変化に関する症例報告など）のモニタリング計画

なお、他の予測候補のうち、消化性潰瘍穿孔・胃空腸潰瘍・食道裂孔ヘルニア・出血性十二指腸炎は間接的な根拠のみ（L4）で、研究課題の段階です。無酸症、Dieulafoy 病変、幽門痙攣、胃拡張、滝状胃はモデル予測のみ（L5）で、保留とします。特に無酸症は、酸分泌を抑える薬理から機序的に成り立ちません。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

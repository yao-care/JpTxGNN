# アレクチニブ：ALK陽性非小細胞肺癌から歯肉線維腫症へ

## 一言要約

アレクチニブは ALK/RET チロシンキナーゼ阻害薬で、元々 ALK 陽性非小細胞肺癌の治療に使用されています。
TxGNN モデルは**歯肉線維腫症 (fibromatosis, gingival)** に有効である可能性を予測していますが、現在この予測を支持する**臨床試験は 0 件、文献も 0 編**です。
根拠はモデル予測のみ（エビデンスレベル L5）です。

## この予測が妥当かどうか

現在、詳細な作用機序データ（DrugBank の MOA）はありません。Evidence Pack の記述によると、アレクチニブは ALK/RET チロシンキナーゼ阻害薬で、ALK 陽性非小細胞肺癌で有効性が確認されています。

一方、歯肉線維腫症には ALK 依存性の病態機序は知られていません。既存適応症（肺癌）との機序的な関連も示されておらず、この予測は TxGNN の計算上の関連性だけに基づいています。予測スコアは非常に高いものの、機序面で妥当と判断できる材料は現時点でありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
歯肉線維腫症に対する臨床試験・文献がなく、ALK/RET 阻害との機序的な接点も確認できません。予測はモデル出力のみで、エビデンスレベルは L5 にとどまります。

なお、同じ Evidence Pack の別候補である**肺胚細胞腫瘍 (lung germ cell tumor)**（TxGNN スコア 99.95%）は、ALK 陽性の肺神経内分泌腫瘍でアレクチニブが奏効した症例報告や、Phase 2/3 のバスケット試験 (NCT05770037) があり、L4 の「Research Question」と評価されています。今回の予測より優先度が高い候補です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（安全性スクリーニングの前提条件）
- 詳細な作用機序データ（DrugBank MOA）の取得
- 歯肉線維腫症における ALK/RET 経路の関与を示す前臨床・機序研究
- 投与経路の適合性評価（現時点は未評価）
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# アレクチニブ：非小細胞肺癌から歯肉線維腫症へ

## 一言要約

アレクチニブは ALK 阻害薬で、元々 ALK 陽性の非小細胞肺癌（肺癌）の治療に使用されていました。
TxGNN モデルは**歯肉線維腫症 (Fibromatosis, Gingival)** に有効である可能性を予測していますが、この予測を支持する臨床試験や文献は**ありません**（モデル予測のみ）。
なお、上位 10 件の予測のうち、肺の悪性腫瘍に近い「肺門部癌」「肺胚細胞腫瘍」では、間接的な文献や症例報告が見つかっています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 非小細胞肺癌、肺癌（承認文書の適応症テキストは、今回のデータにはありません） |
| 予測新規適応症 | 歯肉線維腫症 (Fibromatosis, Gingival) |
| TxGNN 予測スコア | 99.97% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認整理済みのみ（現在、有効な承認なし） |
| 承認番号数 | 1 件（失効・整理済み 1 件） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アレクチニブは ALK（および RET）キナーゼを阻害する分子標的薬で、ALK 融合遺伝子陽性の非小細胞肺癌で有効性が確立しています。

しかし、歯肉線維腫症は ALK や RET のシグナルに依存する疾患として知られておらず、既存適応症との機序的な関連は確認できません。この予測は TxGNN モデルのスコアのみに基づいており、現時点では妥当性を裏付ける根拠は乏しい状況です。

## 安全性に関する考慮事項

- **薬物相互作用**：92 件の相互作用が登録されています。Major は **アミノレブリン酸**（光線過敏のリスク）が確認されています。Moderate には、ドラセトロン、ナルトレキソン、エドロホニウム、フィゾスチグミン、メフロキン、キニーネ、メトキサレン、アテノロール、ビソプロロール、アタザナビルなどが含まれ、QT 延長や徐脈に関連する薬剤が目立ちます。
- **文献で報告された有害事象**：高トリグリセリド血症性膵炎、溶血性貧血、DRESS 症候群、多形紅斑、体重増加などの症例報告があります。

警告・禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
第 1 位の歯肉線維腫症を含め、上位予測の多くは TxGNN のスコアのみに基づいており、臨床試験・文献による裏付けも機序的関連もありません。また、日本での販売承認は現在失効・整理済みの状態です。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の確認（安全性評価の前提となる不足データ）
- DrugBank からの作用機序（MOA）データの補完
- 予測疾患のうち ALK/RET の関与が示唆されるもの（肺門部癌、肺胚細胞腫瘍など）を優先して、ALK 陽性例の有無を調べる
- 優先候補について、ALK 陽性腫瘍を対象にした症例集積や前臨床研究の実施
- 日本での承認状況の再確認（現行製品の有無）
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

## Nitrofurantoin：尿路感染から関節リウマチへ
{: .text-alpha }

## 一言まとめ

Nitrofurantoin（ニトロフラントイン）は、尿路感染の治療に用いられる合成抗菌薬です。TxGNN モデルは、本剤が**関節リウマチ (rheumatoid arthritis)** と関連する可能性を予測しました。しかし文献上の証拠では、この関連は主に併存疾患の関係または薬剤の副作用報告によるものであり、治療効果を示すものではありません。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 尿路感染（膀胱炎、腎盂炎、尿道炎） |
| 予測新適応症 | 関節リウマチ (rheumatoid arthritis) |
| TxGNN 予測スコア | 99.89% |

| 日本市販状況 | 本サイトのデータに未収載 |

## この予測が疑似相関の可能性がある理由

Nitrofurantoin は、細菌の DNA を損傷し、酵素活性を阻害することで殺菌作用を示します。グラム陽性菌・陰性菌の両方に有効です。作用は尿路に限られ、全身への吸収は限定的です。

**文献レビューの結果：**
- nitrofurantoin と関節リウマチの関係に言及する文献は複数ありますが、その内容は主に次のとおりです。
  1. **薬剤性肺線維症**：Nitrofurantoin は肺線維症を起こすことが知られている薬剤であり、肺線維症は関節リウマチの合併症でもあります
  2. **併存症の報告**：関節リウマチ患者が尿路感染の治療に nitrofurantoin を使用した症例報告
  3. **抗菌薬と RA 増悪**：一部の抗菌薬が RA の増悪を誘発する可能性を示した研究

**治療上の証拠の欠如：**
- nitrofurantoin が RA に対して抗炎症作用や免疫調節作用を持つことを示す証拠はありません
- Nitrofurantoin は主に尿路に作用が限られるため、全身性疾患の治療には適しません

## 安全性に関する考慮事項

**重要な警告：**
- **肺毒性**：急性、亜急性および慢性の肺反応（肺線維症を含む）
- 長期使用（>6ヶ月）で肺線維症のリスクが上昇します
- 肝毒性（まれ）
- 神経障害（長期使用時）

**RA 患者への注意：**
- RA そのものが間質性肺疾患を引き起こすことがあります
- methotrexate との併用は肺毒性のリスクを高めます
- RA 患者への nitrofurantoin の長期使用は推奨されません

## 結論と次のステップ

**判断：Hold**

**理由：**
文献の分析によると、nitrofurantoin と関節リウマチの関連は、（1）両者に共通する肺線維症という副作用／合併症、（2）RA 患者が尿路感染の治療に nitrofurantoin を使用した症例報告、に由来しています。これは知識グラフ上の疑似相関であり、真の治療関係ではありません。さらに、nitrofurantoin は全身への分布が限られるため、全身性の自己免疫疾患への使用には適しません。

**推進に必要な事項：**
- この適応症についてこれ以上探索することは推奨されません
- この予測が反映しているのは併存疾患／副作用の関係であり、治療の可能性ではありません

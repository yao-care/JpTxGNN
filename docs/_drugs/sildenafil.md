# シルデナフィル：肺動脈性肺高血圧症から Ambras 型汎発性先天性多毛症へ

## 一言要約

シルデナフィルは PDE5 阻害薬で、元々は肺動脈性肺高血圧症などの治療に使用されていました。
TxGNN モデルは **Ambras 型汎発性先天性多毛症 (Ambras type hypertrichosis universalis congenita)** に有効である可能性を予測していますが、この疾患を直接支持する臨床試験や文献はありません。
現時点の根拠はモデル予測のみ（エビデンスレベル L5）です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、シルデナフィルは PDE5 阻害薬に分類され、cGMP を増加させて血管拡張を促します。肺動脈性肺高血圧症での有効性は確立されています。

Ambras 症候群は、8 番染色体 q 領域の調節領域の再編成により TRPS1 の発現が変化して起こる遺伝性疾患です。PDE5/cGMP 経路との直接の関連は確立されておらず、**機序的な妥当性は現時点では示されていません**。この予測はモデルによるものにとどまります。

参考として、予測上位の他の疾患も同様に根拠は限られています。
- **多毛症 (hypertrichosis)**（スコア 97.83%）：Cantú 症候群は K-ATP チャネルの機能獲得変異で起こり、ミノキシジルと同様の K-ATP 関連の血管拡張との間接的な機序的関連が考えられます。ただし、取得された文献はグリベンクラミドに関するもので、シルデナフィルの試験ではありません。
- **遺伝性脱毛症 (genetic alopecia)**（スコア 75.03%）：シルデナフィルによる毛包周囲の血流増加と成長期の延長が示唆されています。前臨床の報告が 1 件あり、機序的にはもっとも妥当性があります。ただし臨床エビデンスは不足しています。

## 結論と次のステップ

**決定：Hold**

**理由：**
- Ambras 型汎発性先天性多毛症に対する臨床試験も文献もなく、根拠はモデル予測のみです。PDE5/cGMP 経路との機序的関連も示されていません。
- 日本では有効な承認がなく、安全性の基礎データ（添付文書の警告・禁忌）も未確認です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の取得と解析
- DrugBank からの詳細な作用機序データ（MOA）の取得
- 機序的により妥当性のある **遺伝性脱毛症** や **多毛症** を、優先的に検討すべき研究課題として評価（前臨床データの確認、ヒトでの検証）
- Ambras 症候群での TRPS1 経路とシルデナフィルの関係を検証する前臨床研究
- 剤形・投与経路の適合性評価（毛髪関連の適応では外用などの検討を含む）

# エトスクシミド：欠神てんかんから腎性抗利尿ホルモン不適合分泌症候群へ

## 一言要約

エトスクシミドは T 型カルシウムチャネル阻害薬で、元々欠神てんかんの治療に使用されていました。
TxGNN モデルは**腎性抗利尿ホルモン不適合分泌症候群 (Nephrogenic Syndrome of Inappropriate Antidiuresis)** に有効である可能性を予測していますが、関連する臨床試験・文献は**どちらも 0 件**で、モデル予測のみの段階です。

|------|------|
| 既存適応症 | 欠神てんかん |
| 予測新規適応症 | 腎性抗利尿ホルモン不適合分泌症候群 (Nephrogenic Syndrome of Inappropriate Antidiuresis) |
| TxGNN 予測スコア | 99.91% |
| エビデンスレベル | L5 |

| 推奨決定 | Hold |

## この予測が妥当である理由

エトスクシミドは T 型カルシウムチャネルを阻害し、欠神てんかんの治療に用いられてきました。ただし、現在、詳細な作用機序データはありません。

腎性抗利尿ホルモン不適合分泌症候群は、バソプレシン V2 受容体 (AVPR2) の機能獲得型変異、まれに GNAS の変異により、腎集合管で受容体シグナルが持続的に活性化して起こります。

T 型カルシウムチャネル阻害から V2 受容体経路へつながる確立した機序は見つかっていません。そのため、高い予測スコア (0.999) にもかかわらず、現時点でこの予測を裏付ける生物学的根拠は確認できません。既存適応症との類似性についても、評価は未実施です。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の禁忌関連疾患）**：添付文書の記載ではなく、TxGNN 知識グラフの薬物－疾患禁忌情報に基づきます。
  - 血液・免疫系：血液疾患、好中球減少症、無顆粒球症、全身性エリテマトーデス（小児期発症を含む）
  - 臓器障害：腎疾患、肝疾患、胆嚢疾患、膿尿管症
  - 代謝：急性間欠性ポルフィリン症
  - 精神系：不安障害、神経症性障害、気分変調性障害
- **薬物相互作用**：92 件が報告されています。代表例（いずれも中等度）は次のとおりです。
  - 中枢抑制作用の増強が懸念される薬剤：モルヒネ、オピウム、エタノール、プロメタジン、クロルフェニラミン
  - 制吐薬・関連薬：アプレピタント、メトクロプラミド、ドロナビノール、ナビロン
  - 抗マラリア薬：クロロキン、メフロキン、ヒドロキシクロロキン
  - 葉酸関連：葉酸、ロイコボリン、レボロイコボリン
  - その他：コビシスタット、デフェラシロクス、ホスタマチニブ、シブトラミン

添付文書の警告・禁忌の情報は、今回取得できていません。詳細は添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験・文献が一切なく、機序的な裏付けも確認できません。日本では承認が失効しており、現時点でこの方向性を進める根拠は不十分です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得（安全性スクリーニングの前提）
- 詳細な作用機序データ（MOA）の補充
- T 型カルシウムチャネル阻害と AVPR2/GNAS 経路の関連を示す前臨床・機序研究の探索
- 既存適応症との類似性評価と、投与経路の適合性評価
- 腎疾患・血液疾患などの禁忌関連疾患を考慮した、対象集団の安全性評価
## 免責事項

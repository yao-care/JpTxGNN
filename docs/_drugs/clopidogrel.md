# クロピドグレル：血栓塞栓症予防から脳幹前兆を伴う片頭痛へ

## 一言要約

クロピドグレルは ADP 受容体（P2Y12）を拮抗する抗血小板薬で、国際的には急性冠症候群・脳梗塞・末梢動脈疾患の血栓塞栓症予防に広く使用されていますが、日本での市販承認は現時点で未確認です。
TxGNN モデルは**脳幹前兆を伴う片頭痛 (Migraine with Brainstem Aura)** に有効である可能性を予測しており、現在 **16 編の文献**がこの方向性を支持しています。
なお、より広義の偏頭痛（Migraine Disorder, Rank 2）では **8 件の臨床試験**と **20 編の文献**が存在し、特に卵円孔開存（PFO）合併患者サブグループにおける有効性が示されています。

## この予測が妥当である理由

クロピドグレルは血小板上の P2Y12 受容体を不可逆的に阻害することで、ADP 依存性の血小板凝集を抑制します。本 Evidence Pack には詳細な MOA データは含まれていませんが、世界的に確立された抗血小板薬として広く認識されており、その機序は repurposing rationale からも確認できます。

脳幹前兆を伴う片頭痛（旧称：基底型片頭痛）は、脳幹・後頭部領域の血管神経炎症と皮質拡延性脱分極（CSD）を基盤とした病態で、卵円孔開存（PFO）による右向左シャントとの関連が特に強いとされています。クロピドグレルによる P2Y12 拮抗は、PFO から生じる微小塞栓を減少させることで CSD 誘発の閾値を上昇させる可能性があります。加えて、三叉神経尾側核に発現するミクログリアの P2Y12 受容体を阻害することで、中枢性の神経炎症を抑制する機序も理論的に提唱されています。

ただし、この特定亜型（脳幹前兆）を対象とした Phase 2 以上の専用臨床試験は現時点で存在せず、利用可能なエビデンスはいずれも PFO 関連偏頭痛全般に関するものです。脳幹前兆を伴う片頭痛への外挿は病態的合理性を有しますが、直接的な臨床的裏付けはまだ不足しています。

## 結論と次のステップ

**決定：Hold**

**理由：**
脳幹前兆を伴う片頭痛を直接対象とした臨床試験は現時点で存在せず、エビデンスは観察研究・ケースシリーズを主体とした L3 水準に留まります。より広義の PFO 合併偏頭痛において有望なデータは蓄積されていますが、「脳幹前兆」という特定亜型への外挿には追加の臨床的根拠が必要であり、現時点では研究課題（Research Question）としての位置付けが適切です。

**進める場合に必要なもの：**
- クロピドグレルの詳細な作用機序データ（MOA）の補完（DrugBank API から取得）
- 安全性データの確認（日本の添付文書相当資料、主要警告・禁忌・薬物相互作用）
- 脳幹前兆を伴う片頭痛患者における PFO 合併率と右向左シャント重症度の文献的評価
- 状態不明の COMPETE 試験（NCT05546320）および NCT02938182 の最新ステータス確認
- PFO 合併の脳幹前兆片頭痛を対象とした前向きパイロット試験のフィージビリティ検討

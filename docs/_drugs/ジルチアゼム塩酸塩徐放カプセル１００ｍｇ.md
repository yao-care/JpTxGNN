## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による新規適応症の予測結果が存在せず、PMDA 承認情報・原適応症・MOA のいずれも未取得のため、再利用候補としての有効性・安全性評価を進める根拠がありません。

**進める場合に必要なもの：**

- **PMDA クエリの再実行**：全角文字・剤形名を除いた正規 INN「ジルチアゼム」または「diltiazem」で検索し直す
- **DrugBank ID の特定**：DrugBank クエリは成功（1 件）しているため、対応 ID（例：DB00343）をエビデンスパックに反映させる
- **MOA データの補充**：DrugBank API から作用機序（L 型カルシウムチャネル遮断）を取得し、機序関連性分析を再実行する
- **添付文書の取得**：PMDA 仿單 PDF をダウンロードし、承認適応症・警告・禁忌を解析して安全性初評（S1）を完了させる
- **TxGNN 予測の再生成**：DrugBank ID が確定後、KG 予測および DL 予測を実行して `predicted_indications` を生成する

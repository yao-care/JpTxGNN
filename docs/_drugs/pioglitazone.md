# ピオグリタゾン：2型糖尿病から オプシスモ異形成症 へ

## 一言要約

ピオグリタゾンは PPARγ 作動薬で、元々 2 型糖尿病の治療に使用されていました。
TxGNN モデルは **オプシスモ異形成症 (Opsismodysplasia)** に有効である可能性を予測していますが、
現時点でこの予測を直接支持する臨床試験や文献はなく、**モデル予測のみ**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 2型糖尿病（PPARγ 作動薬） |
| 予測新規適応症 | オプシスモ異形成症 (Opsismodysplasia) |
| TxGNN 予測スコア | 99.59% |
| エビデンスレベル | L5 |
| 日本市販状況 | 承認は全て取消（現在市販中の承認なし） |
| 承認番号数 | 20 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ピオグリタゾンはチアゾリジン系の PPARγ 作動薬で、インスリン抵抗性を改善することで 2 型糖尿病に有効性が示されています。

オプシスモ異形成症は、INPPL1 (SHIP2) の変異によって PI3K／インスリンシグナルが影響を受ける骨異形成症です。インスリンシグナルという共通の経路を介した関連は考えられますが、あくまで推測の域を出ず、根拠は TxGNN の予測のみです。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測を裏付ける臨床試験も文献もなく、エビデンスはモデル予測のみ（L5）です。また、日本の承認がすべて取消されており、安全性の主要データ（添付文書の警告・禁忌）も未入手のため、現時点では先に進められません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングに必須）
- 詳細な作用機序データ（MOA）の取得
- オプシスモ異形成症（INPPL1/SHIP2 経路）とピオグリタゾンの機序的関連を示す前臨床データ
- 疾患に特異的な文献・臨床試験の調査
- 剤形・投与経路の適合性の確認
- 上位候補のうち、リポジストロフィー系疾患は機序上の妥当性が比較的高いため、優先的な再評価を検討
## 免責事項

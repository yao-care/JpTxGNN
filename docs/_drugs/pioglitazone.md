# ピオグリタゾン：2型糖尿病からオプシスモ異形成症へ

## 一言要約

ピオグリタゾンは PPARγ 作動薬で、元々は2型糖尿病の治療に使用されてきました。
TxGNN モデルは**オプシスモ異形成症 (Opsismodysplasia)** に有効である可能性を予測していますが、
現在のところ**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報によると、ピオグリタゾンは糖尿病治療薬で、ペルオキシソーム増殖因子活性化受容体 (PPAR) γ 作動薬に分類されます。2型糖尿病での有効性は確立しています。

オプシスモ異形成症は INPPL1 遺伝子に関連する骨系統疾患です。PPARγ 作動作用との間に確立した関連は見つかっていません。この関連づけは TxGNN の予測だけに基づいており、機序面の裏付けは現時点で示せません。

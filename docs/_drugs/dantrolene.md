# ダントロレン：悪性高熱症（感受性）への予測

## 一言要約

ダントロレンは日本でカプセル剤と静注用製剤が市販されている骨格筋弛緩薬です。既存適応症のデータは今回のエビデンスに含まれていません。
TxGNN モデルは**悪性高熱症の感受性 (malignant hyperthermia, susceptibility to)** に有効である可能性を、99.93% のスコアで予測しています。
関連する臨床試験は 0 件ですが、**19 編の文献**（ガイドライン・レビュー中心）があり、エビデンスレベルは L3 です。文献ではダントロレンはすでに標準的な治療薬として扱われているため、「新規」というより既存知見の再確認に近い予測です。

## この予測が妥当である理由

ダントロレンは、骨格筋の筋小胞体にあるリアノジン受容体 1 (RyR1) を介した Ca²⁺ 放出を抑える薬です。悪性高熱症は、揮発性吸入麻酔薬や脱分極性筋弛緩薬（スキサメトニウム）をきっかけに、骨格筋で Ca²⁺ が制御不能に放出されて起こります。主な原因は RYR1 遺伝子の変異です。ダントロレンはこの異常な Ca²⁺ 放出を直接抑えるため、機序的な整合性は高いといえます。基礎研究（PNAS, 2017）では、ダントロレンが悪性高熱症を抑えるには Mg²⁺ が必要であることが示されています。

複数のレビューが、ダントロレンを悪性高熱症の治療の要としています。たとえば 1998 年の総説は、決定的な治療薬はダントロレンナトリウムだと述べています。したがって今回の予測は、新しい可能性の発見というより、既存の臨床知見を TxGNN が再現したものと考えられます。

なお、詳細な作用機序データ（original_moa）と既存適応症の情報は、今回のデータにありません。上記の機序は予測根拠として付された説明と文献に基づいています。

## 結論と次のステップ

**決定：Proceed with Guardrails**

**理由：**
RyR1 阻害という機序は悪性高熱症の病態と直接つながり、ガイドラインやレビューでも治療薬として位置づけられています。一方、臨床試験は 0 件で、日本の承認適応症と添付文書の安全性情報が未確認のため、確認を前提に進めるのが妥当です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌・承認適応症）の取得と確認（現時点で安全性審査に進めないブロッキング項目）
- 日本の承認適応症に悪性高熱症が含まれるかの確認。含まれていれば、これは新規適応ではなく既存適応の再確認になります
- DrugBank からの作用機序データと薬物相互作用データの補完
- 経口剤と静注剤の適用場面の整理（急性期は静注、感受性者の管理は周術期ガイドラインに基づく）

**参考：他の予測適応症**
King-Denborough 症候群と中心コア病（いずれも L4）は、RYR1 関連の筋疾患という点で機序上の関連があります。ただし根拠は症例報告・基礎研究・遺伝学的報告にとどまり、研究課題の段階です。多小コア病、心筋管ミオパチー、低カリウム性周期性四肢麻痺、甲状腺中毒性周期性四肢麻痺は、根拠が間接的または欠如しているため保留とします。

本レポートは研究参考用であり、医療上の助言ではありません。臨床応用には臨床的な検証が必要です。

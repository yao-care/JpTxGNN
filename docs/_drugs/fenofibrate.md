# フェノフィブラート：高脂血症から ホモ接合型家族性高コレステロール血症へ

## 一言要約

フェノフィブラートは PPARα 作動薬で、日本では高脂血症・家族性高脂血症の治療に使われています。
TxGNN モデルは**ホモ接合型家族性高コレステロール血症 (Homozygous Familial Hypercholesterolemia, HoFH)** に有効である可能性を予測しています。
ただし、登録された臨床試験 **1 件**は別の薬剤（アリロクマブ）の試験で、フェノフィブラートを直接検証した根拠はなく、文献 **10 編**も間接的な内容が中心です。

## この予測が妥当である理由

現在、詳細な作用機序データ（DrugBank の MOA）はありません。日本の承認情報では、フェノフィブラートは「トリグリセリド合成阻害薬」かつ「PPARα 作動薬」に分類されています。PPARα を活性化するとリポ蛋白リパーゼ活性と脂肪酸酸化が高まり、肝臓からの VLDL 産生が減ります。その結果、トリグリセリドが下がり HDL-C が上がります。LDL-C の低下は穏やかです。

HoFH は LDL 受容体の機能不全が原因で、LDL-C が著しく高くなります。フェノフィブラートは LDL 受容体を介さない経路で脂質を調整するため、補助的な効果は理論上あり得ます。しかし主要な病態を直接標的にはしないため、単独での有効性を裏付ける機序上の根拠は乏しいと考えられます。

既存適応症（家族性高脂血症を含む高脂血症）とは脂質異常という点で関連します。ただし、予測スコアが非常に高いことと、実際に臨床で有効であることは別です。フェノフィブラートを HoFH で検証した無作為化試験はありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
HoFH に対するフェノフィブラートの直接的な臨床エビデンスはなく、唯一の試験も別薬剤のものです。機序上も、LDL 受容体機能不全が原因の HoFH では有効性が期待しにくいため、予測スコアが高くても保留が妥当です。なお、同じ予測リストの「高リポ蛋白血症」には Phase 3 RCT が複数あり、L1 と評価されています。ただしこれは既存適応症に近い領域です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。現時点で欠けており、安全性スクリーニングに進めません
- DrugBank からの作用機序（MOA）データの補完
- HoFH 患者でのフェノフィブラート（単独または LDL 低下薬との併用）の有効性を示す臨床データ
- HoFH の標準治療（スタチン、エゼチミブ、PCSK9 阻害薬、ロミタピドなど）に対する上乗せ効果の検討

*本レポートは研究参考用で、医療上の助言ではありません。予測結果は臨床的な検証を経て初めて利用できます。*
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

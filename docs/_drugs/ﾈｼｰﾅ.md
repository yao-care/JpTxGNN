# ネシーナ：評価データ不足のため処理不可

## 一言要約

ネシーナ（`ﾈｼｰﾅ`）は PMDA クエリで承認情報が 0 件しか返されず、既存適応症・作用機序ともにデータが確認できませんでした。TxGNN モデルによる新規適応症の予測結果も存在しないため、老薬新用の評価対象が成立しない状態です。現時点では薬物を特定し直し、必要データを補完するまで評価を進めることができません。

---

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | データなし |
| 予測新規適応症 | データなし（予測結果ゼロ件） |
| TxGNN 予測スコア | データなし |
| エビデンスレベル | 評価不可 |
| 日本市販状況 | 未上市（PMDA 0 件） |
| 承認番号数 | 0 件 |
| 推奨決定 | **Hold** |

---

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

---

## 結論と次のステップ

**決定：Hold**

**理由：**
`predicted_indications` が空であり評価対象の疾病が存在しない。また PMDA クエリが 0 件を返しており、薬物の承認実態・既存適応症・MOA のいずれも確認できていないため、機序的妥当性・安全性のいかなる評価も行えない。

**進める場合に必要なもの：**

- **薬物名の確認**：半角カタカナ `ﾈｼｰﾅ` を全角 `ネシーナ` に統一し、PMDA を再クエリする
- **DrugBank ID の特定**：DrugBank クエリが 1 件ヒットしているにもかかわらず `drugbank_id` が `null` になっている原因を調査し、正しい ID を確定させる
- **MOA の取得**：DrugBank API で作用機序・薬物分類・適応症を取得する（DG002 解消）
- **添付文書の解析**：PMDA 添付文書 PDF から警語・禁忌を抽出する（DG001 解消）
- **TxGNN 予測の実行**：DrugBank ID 確定後、KG 予測または DL 予測を実行し `predicted_indications` を生成する

# ビダラビン：ヘルペス感染症から光線性口唇炎へ

## 一言要約

ビダラビンは DNA ポリメラーゼ阻害作用を持つ抗ウイルス薬で、元々帯状疱疹、単純疱疹、単純ヘルペス脳炎の治療に使用されていました。
TxGNN モデルは**光線性口唇炎 (Actinic Cheilitis)** に有効である可能性を高いスコアで予測していますが、この予測を直接支持する臨床試験や文献はなく、**モデル予測のみ**の段階です。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 帯状疱疹、単純疱疹、単純ヘルペス脳炎（抗ウイルス薬、DNA ポリメラーゼ阻害薬） |
| 予測新規適応症 | 光線性口唇炎 (Actinic Cheilitis) |
| TxGNN 予測スコア | 99.55% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売承認は全て取消済み（現在市販なし） |
| 承認番号数 | 12 件（すべて取消） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ビダラビンはアデニンヌクレオシド類似体で、ウイルスの DNA ポリメラーゼを阻害する外用抗ウイルス薬です。帯状疱疹や単純疱疹での使用実績があります。

一方、光線性口唇炎は紫外線によって生じる前癌性病変で、ウイルス性疾患ではありません。そのため、ビダラビンの抗ウイルス作用と直接結びつく機序は確認できません。この予測は、TxGNN の高スコアのみに基づいています。

参考として、予測第 2 位の**口角炎 (Angular Cheilitis)** については、単純ヘルペスが関与する口周囲病変であれば機序的に適用できる可能性があります。ただし、口角炎の主な原因はカンジダ、ブドウ球菌、栄養因子であり、関連は間接的です。第 3 位の薬剤性骨粗鬆症は、機序的なつながりが見られません。

## 臨床試験エビデンス

現在、関連する臨床試験の登録はありません。

## 文献エビデンス

光線性口唇炎に対する文献はありません。参考として、予測第 2 位（口角炎）に関連する文献を示します。

| PMID | 年 | タイプ | ジャーナル | 主な知見 |
|------|-----|------|------|---------|
| [38895086](https://pubmed.ncbi.nlm.nih.gov/38895086/) | 2024 | Case report | EJHaem | 臍帯血移植後の患者に生じた口角炎で、アシクロビル、ガンシクロビル、ビダラビン軟膏は、アシクロビル耐性の単純ヘルペスウイルス 1 型の変異のため無効でした。アメナメビルで治療に成功しました。 |

この症例ではビダラビンは無効でした。そのため、新規適応症を支持する根拠にはなりません。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測は TxGNN の高スコアのみに基づき、臨床試験も文献もなく、機序的な裏付けもありません。
- 日本の承認はすべて取消済みで、現在は市販されていません。
- 口角炎に関する唯一の文献では、ビダラビンは無効でした。

**進める場合に必要なもの：**
- 詳細な作用機序データ（MOA）の取得
- 添付文書の警告・禁忌情報の確認（PMDA）
- 光線性口唇炎に対する前臨床研究や機序研究の調査
- 外用での適用可能性の評価（投与経路の適合性）
- 販売再開や供給体制の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

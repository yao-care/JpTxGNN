# ブロムペリドール：統合失調症から不眠症へ

## 一言要約

ブロムペリドールはブチロフェノン系のドパミン D2 受容体拮抗薬で、元々統合失調症の治療に使用されていました。
TxGNN モデルは**不眠症 (Insomnia)** に有効である可能性を予測していますが、現時点で裏付けとなる**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ブロムペリドールはブチロフェノン系の抗精神病薬で、ドパミン D2 受容体を遮断することで統合失調症に用いられてきました。

鎮静作用を持つ抗精神病薬は、D2 遮断に加え、抗ヒスタミン作用やα アドレナリン遮断作用といった D2 以外の作用を介して、間接的に睡眠を改善する可能性があります。ただし、これはあくまで推測であり、ブロムペリドール自体でこれらの作用が確認されているわけではありません。

TxGNN のスコアは高い（99.85%）ものの、計算上の予測にすぎず、現時点では臨床試験も文献も裏付けとなっていません。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
不眠症に対する予測は TxGNN のモデルスコアのみに基づいており、臨床試験・文献の裏付けがありません（L5）。さらに、日本では現在販売中の製剤がなく、安全性情報（警告・禁忌）も確認できていないため、先に進める段階にはありません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌情報を取得し、安全性スクリーニングを実施する
- DrugBank などから詳細な作用機序（MOA）データを取得し、睡眠に関わる受容体親和性（ヒスタミン H1、α1 アドレナリンなど）を検証する
- 不眠症に関する臨床試験・文献を再調査し、前臨床または観察研究レベルのエビデンスを確認する
- 販売中の製剤がない現状を踏まえ、供給体制や他の D2 拮抗薬との比較を検討する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

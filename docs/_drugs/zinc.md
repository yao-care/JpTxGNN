# 亜鉛：ウィルソン病から フィラリア症 へ

## 一言要約

亜鉛は、元々ウィルソン病（肝レンズ核変性症）で銅の吸収を抑える解毒薬として使われていました。
TxGNN モデルは**フィラリア症 (Filariasis)** に有効である可能性を予測していますが、
関連する臨床試験は **0 件**で、文献 20 編も治療効果を支持する内容ではなく、モデル予測の段階にとどまっています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 解毒薬（銅吸収阻害）：ウィルソン病、肝レンズ核変性症 |
| 予測新規適応症 | フィラリア症 (Filariasis) |
| TxGNN 予測スコア | 93.19% |
| エビデンスレベル | L5 |
| 日本市販状況 | 販売終了のみ（現在有効な承認なし） |
| 承認番号数 | 20 件（すべて取消済み） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、亜鉛は酢酸亜鉛製剤として、メタロチオネインの誘導を介して腸管での銅吸収を抑え、ウィルソン病で有効性が確認されています。

一方、フィラリア症は寄生虫（糸状虫）による感染症で、銅代謝の阻害とは機序的なつながりが見当たりません。取得できた文献は、酸化亜鉛ナノ粒子による蚊の幼虫駆除や、寄生虫の亜鉛結合タンパク質の基礎研究が中心で、亜鉛の治療的役割を支持するものではありません。高スコアはモデル上の関連にとどまり、機序的な裏付けは弱いと判断します。

## 結論と次のステップ

**決定：Hold**

**理由：**
フィラリア症に対する臨床試験はなく、文献も蚊の防除や寄生虫の基礎研究が中心で、亜鉛の治療的役割を支持していません。機序的な関連も不明確で、エビデンスはモデル予測のみ（L5）です。さらに、日本の承認は現在すべて取消済みです。

**進める場合に必要なもの：**
- 詳細な作用機序データ（MOA）の取得
- 添付文書の警告・禁忌情報の取得と安全性の確認
- 亜鉛とフィラリア症の関連を検証する前臨床研究（in vitro・動物モデル）
- 上位候補の中では、皮膚炎（エビデンスレベル L3）と腸炎（L3）が相対的に根拠を持つため、それらの評価を優先することを検討
## 免責事項

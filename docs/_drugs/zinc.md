# Zinc（亜鉛）：微量元素 から フィラリア症 へ

## 一言要約

Zinc（亜鉛）は人体に不可欠な微量元素ですが、本 Evidence Pack では日本での既承認適応症は記録されていません（日本未承認）。
TxGNN モデルは**フィラリア症（Filariasis）**に有効である可能性を予測しており、
現在 **1 件の臨床試験**と **20 編の文献**が収集されていますが、大部分は機序的背景研究にとどまります。

## この予測が妥当である理由

亜鉛は宿主免疫において多面的な調節機能を担います。T 細胞分化の促進、Toll 様受容体（TLR）経由の自然免疫応答の制御、そして活性酸素消去に関与する銅/亜鉛 SOD（SOD1）の補因子として機能します。ガーナの流行地コホート研究では、機械学習解析によってリンパ性フィラリア症（LF）の進展と血清亜鉛濃度の低下に有意な関連が確認されており（PMID 40138337）、これが TxGNN 予測の生物学的根拠を部分的に支持しています。

寄生虫学的側面では、Setaria digitata や Brugia malayi 等のフィラリア寄生虫の体内に亜鉛依存性システインプロテアーゼ（PMID 8522762）や亜鉛依存性ロイシンアミノペプチダーゼ（PMID 18262499）が存在することが実証されており、亜鉛が宿主−寄生虫の生化学的相互作用に直接関与する可能性が示唆されます。また、Acanthocheilonema viteae の感染時に細胞外 Cu/Zn SOD（AVSOD2）が高発現することは、寄生虫自身が宿主の酸化ストレスに対して亜鉛依存性の適応機構を備えていることを示します（PMID 10579430）。

ただし、これらはすべて機序的または間接的な証拠です。亜鉛をフィラリア症患者に直接投与した介入試験は現時点で皆無であり、TxGNN スコア 93.19%（Rank 7981）は統計モデルの出力であることを踏まえ、臨床的有効性の判断には慎重な姿勢が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
フィラリア症に対する亜鉛の直接的な治療有効性を示す介入試験は現時点で存在せず、収集されたエビデンスは寄生虫内の亜鉛依存性酵素の同定、ZnO NPs の媒介蚊幼虫への殺虫活性、流行地コホートにおける亜鉛欠乏と LF 進展の関連性など、機序的背景研究に限られます（エビデンスレベル L4）。

**進める場合に必要なもの：**
- 亜鉛補充がフィラリア症患者の寄生虫負荷・臨床転帰・免疫応答に与える影響を評価する前臨床動物実験の実施
- 流行地における亜鉛欠乏とフィラリア症感染率・重症度の因果関係を検証するプロスペクティブ観察研究
- ZnO NPs 媒介蚊駆除効果の野外試験への橋渡し（in vitro → in vivo）
- 作用機序（MOA）の詳細確認（DrugBank API 照会を推奨）
- 安全性プロファイルの確認（PMDA 添付文書 PDF の解析）

## 評価が保留される理由

本 Evidence Pack には以下の重大なデータ不足が存在します。

**DrugBank ID が未取得**であるため、TxGNN モデルへのインプットとなる薬物ノードの識別ができていません。DrugBank クエリでは 1 件のヒットが記録されていますが（`query_log` ID 2）、DrugBank ID フィールドは `null` のままです。この不一致はマッピング処理の問題を示唆しており、まず DrugBank ID を正しく取得・設定することが必要です。

**TxGNN 予測が生成されていない**ため、評価の核心である「新規適応症候補」が存在しません。DrugBank ID の補完後、KG 予測または DL 予測を再実行する必要があります。

**安全性情報が取得できていない**ため、DDI・警告・禁忌いずれも評価不能です。

## 次のステップ

**決定：Hold**

**理由：**
TxGNN 予測が生成されておらず、DrugBank ID も未確定であるため、老薬新用の評価を開始できる状態にない。

**進めるために必要なアクション：**

1. **DrugBank ID の確定**：`query_log` ID 2 の成功ヒットから DrugBank ID（例：`DB01201`）を取得し、Evidence Pack の `drug.drugbank_id` フィールドを更新する
2. **INN 正規化**：入力値「ロペラミド塩酸塩カプセル１ＭＧ」は剤形・規格を含む製品名表記であり、クエリには INN の「ロペラミド塩酸塩」または英語 INN「Loperamide」を使用することを推奨
3. **TxGNN 予測の再実行**：DrugBank ID 確定後、`run_kg_prediction.py` および `txgnn_model.py` を再実行
4. **PMDA 仿単の取得**：[PMDA 添付文書検索](https://www.pmda.go.jp/PmdaSearch/iyakuSearch/) でロペラミド塩酸塩を検索し、警告・禁忌・相互作用を取得
5. **Evidence Pack v5 の再生成**：上記補完後に Evidence Pack を更新し、レポート生成を再実施

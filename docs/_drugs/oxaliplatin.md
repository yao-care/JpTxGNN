# オキサリプラチン：白金系抗悪性腫瘍薬から悪性胸膜中皮腫へ

## 一言要約

オキサリプラチンは白金系の抗悪性腫瘍薬で、日本ではエルプラット点滴静注液として市販されています。ただし、Evidence Pack には承認適応症の記載がありません。
TxGNN モデルは**悪性胸膜中皮腫 (malignant pleural mesothelioma)** に有効である可能性を予測しています。この方向性を支持するのは **6 件の臨床試験**と **20 編の文献**ですが、いずれも第 II 相の単群試験や観察研究が中心で、第 III 相 RCT はありません。

## クイック概要

| 項目 | 内容 |
|------|------|
| 予測新規適応症 | 悪性胸膜中皮腫 (malignant pleural mesothelioma) |
| TxGNN 予測スコア | 99.68% |
| エビデンスレベル | L3（第 II 相の単群試験・観察研究のみで RCT なし） |
| 日本市販状況 | ✓ 市販中 |
| 承認番号数 | 6 件 |

※ 入力データ側の評価は L2 でした。判定ルール（L2 は完了した Phase 2/3 の **RCT** が必要）に照らすと、該当する RCT がないため L3 としています。

## この予測が妥当である理由

オキサリプラチンは DNA に白金付加体と架橋を形成し、DNA 複製と転写を阻害してアポトーシスを誘導します。悪性胸膜中皮腫で既に使われている白金系薬剤（シスプラチンなど）と同じ作用機序です。現在、DrugBank の詳細な作用機序データは取得できていません。上記の機序は Evidence Pack の再利用根拠の記述に基づきます。

悪性胸膜中皮腫の標準治療はペメトレキセドと白金製剤の併用です。オキサリプラチンは、ゲムシタビン、ビノレルビン、ラルチトレキセドなどとの併用で第 II 相試験が複数報告されています。ただし、標準治療に対する優位性を示すデータはありません。位置づけは「標準治療が使えない、または効果が不十分な場合の代替候補」にとどまります。

同じ予測群には、類上皮型中皮腫（スコア 99.49%、L3）、肉腫型中皮腫（スコア 99.44%、L4）、悪性臓側胸膜腫瘍（スコア 99.26%、L5）もあります。これらは主に腹膜中皮腫での HIPEC や PIPAC の報告に基づく間接的な根拠で、胸膜での直接的な臨床データはありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
悪性胸膜中皮腫については、小規模な第 II 相試験と観察研究しかなく、標準治療に対する優位性は示されていません。また、日本の添付文書の警告・禁忌が未取得で、安全性スクリーニング（S1）に進めない状態です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告、禁忌、承認適応症）の取得と内容確認
- DrugBank からの作用機序データの補完
- ペメトレキセド＋白金製剤との比較データ、または第 III 相 RCT の有無の調査
- 完了済み試験 NCT00859469 の結果（奏効率・安全性）の確認
- 腹膜中皮腫（HIPEC/PIPAC）のデータを胸膜に外挿できるかの検討
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

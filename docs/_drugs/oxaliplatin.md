# オキサリプラチン：結腸癌の転移から悪性胸膜中皮腫へ

## 一言要約

オキサリプラチンは白金系の抗がん剤で、元々は結腸癌（転移性）の治療に使用されていました。
TxGNN モデルは**悪性胸膜中皮腫 (Malignant Pleural Mesothelioma)** に有効である可能性を予測しており、
現在 **3 件の臨床試験**（うち直接関連が高いのは 2 件）と **20 編の文献**がこの方向性に関連しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 結腸癌の転移（承認適応症の記載データはありません。知識グラフ上の情報） |
| 予測新規適応症 | 悪性胸膜中皮腫 (Malignant Pleural Mesothelioma) |
| TxGNN 予測スコア | 99.68% |
| エビデンスレベル | L3 |
| 日本市販状況 | 販売承認はすべて整理済み（取消）。現在の市販品なし |
| 承認番号数 | 6 件（すべて取消） |
| 推奨決定 | Hold |

※エビデンスレベルは、判定ルールに基づき L3 としました。完了した RCT はなく、第 II 相の単群試験と観察研究・レビューが中心です。データ上のスコアリングは L2 ですが、完了した Phase 2/3 の RCT は確認できないため、より保守的に判定しています。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、オキサリプラチンは第三世代の白金系抗がん剤で、DNA 付加体と架橋を形成し、複製と転写を阻害してアポトーシスを誘導します。

結腸癌と中皮腫は組織型こそ異なりますが、どちらも白金系薬剤を含む化学療法に反応しうる腫瘍です。中皮腫は白金感受性があるとされ、オキサリプラチンをゲムシタビン、ラルチトレキセド、ビノレルビンなどと併用した第 II 相試験で活性が報告されています。

ただし、第 III 相試験やランダム化試験のデータはなく、ラルチトレキセド併用の二次治療で奏効が得られなかった報告（PMID 15893013）もあります。有効性は併用レジメンや治療ラインによって異なる可能性があります。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 中皮腫に対する第 II 相試験や観察研究は複数ありますが、完了したランダム化比較試験や第 III 相試験はなく、既存の標準治療と比べた優位性は示されていません。
- 日本ではすべての承認が取消となっており、添付文書の警告・禁忌データも未確認のため、安全性評価に進める状態ではありません。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌情報の取得
- 作用機序（MOA）データの補充（DrugBank など）
- 現在の標準治療（ペメトレキセド＋白金製剤など）と比較した位置づけの整理
- 比較試験または大規模な後ろ向き研究によるエビデンス補強
- 日本での供給状況・承認状況の再確認

なお、組織型別の予測（類上皮型中皮腫、肉腫型中皮腫、悪性臓側胸膜腫瘍）は、組織型特異的なデータが乏しく（腹膜腔内化学療法の報告が中心）、現時点では研究課題または保留の段階です。

## 一言要約

ケトプロフェンは非ステロイド性抗炎症薬（NSAID）の一般名であり、解熱・鎮痛・抗炎症を目的とした坐剤製剤として広く使用されている成分です。今回の Evidence Pack では TxGNN による予測適応症が生成されておらず、PMDA 照会でも承認情報が取得できなかったため、老薬新用候補の評価を実施できません。評価を進めるには、DrugBank ID の確定・適応症データの補完・安全性情報の取得が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
TxGNN による予測適応症が存在せず、PMDA 承認情報・作用機序・安全性データのいずれも取得できていないため、現時点では老薬新用評価を実施する根拠がありません。

**進める場合に必要なもの：**

- **DrugBank ID の確定**：全角文字を INN 表記（`ketoprofen`）に正規化して DrugBank を再照会し、DB14945 等の正確な ID を取得する
- **PMDA 再照会**：検索クエリを全角「ケトプロフェン坐剤７５ＭＧ」から半角・一般名「ケトプロフェン」に変更して再検索し、承認適応症を取得する
- **MOA データの取得**：DrugBank API で `mechanism_of_action` フィールドを取得し、プロスタグランジン合成阻害（COX-1/COX-2 阻害）などの機序情報を確定する
- **安全性情報の補完**：PMDA 仿単 PDF をダウンロードして警告・禁忌・薬物相互作用を解析する（DG001 対応）
- **TxGNN 再予測の実行**：上記データが揃った段階で `run_kg_prediction.py` を再実行し、老薬新用候補を生成する

# セリチニブ：ALK陽性非小細胞肺癌から歯肉線維腫症へ

## 一言要約

セリチニブは ALK 阻害薬で、ALK 陽性の非小細胞肺癌（NSCLC）の治療に使われてきました。TxGNN モデルは**歯肉線維腫症 (Fibromatosis, gingival)** に有効な可能性を予測していますが、この疾患を直接支持する**臨床試験は 0 件、文献も 0 件**です。根拠はモデルのスコアのみで、現時点では保留が妥当です。

## この予測が妥当かどうか

現在、詳細な作用機序データはありません。既知の情報では、セリチニブは ALK を阻害し、ROS1 と IGF-1R にも活性を持つ薬です。臨床での使用は、ALK 再構成を持つ悪性腫瘍に限られています。

歯肉線維腫症で ALK が病態を駆動するという根拠は確認できません。したがって、既存適応症との機序的なつながりは示せておらず、この関連は TxGNN の予測にのみ基づいています。

なお、予測上位 10 件のスコアは 99.77〜99.86% にほぼ集中しています。スコアの差だけで候補の優劣を判断するのは適切ではありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
最上位の予測である歯肉線維腫症には、臨床試験も文献もなく、ALK との機序的な関連も確認できません。エビデンスはモデル予測のみ（L5）のため、現時点では検討を進める根拠がありません。

**進める場合に必要なもの：**

# セリチニブ：非小細胞肺癌から線維腫症（歯肉）へ

## 一言要約

セリチニブは ALK 阻害薬で、元々非小細胞肺癌（肺癌）の治療に使用されていました。
TxGNN モデルは**歯肉線維腫症 (Fibromatosis, gingival)** に有効である可能性を予測していますが、関連する臨床試験や文献は **0 件**で、予測のみの段階です。
なお、他の予測候補（良性肺腫瘍など）には ALK 関連の間接的な文献がありますが、いずれも直接の裏付けにはなっていません。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 非小細胞肺癌（肺癌） |
| 予測新規適応症 | 歯肉線維腫症 (Fibromatosis, gingival) |
| TxGNN 予測スコア | 99.86% |

| 日本市販状況 | 販売承認は取消済み |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、セリチニブは ALK・IGF-1R・ROS1 を阻害するチロシンキナーゼ阻害薬で、ALK 陽性非小細胞肺癌での有効性が確立されています。

一方、ALK シグナルと歯肉線維腫症との間に確立された関連は見当たりません。この予測は TxGNN モデルのスコアのみに基づいており、機序的な裏付けは現時点で確認できません。

## 結論と次のステップ

**決定：Hold**

**理由：**
歯肉線維腫症に対する臨床試験も文献もなく、ALK 阻害との機序的な関連も確認できません。TxGNN の予測スコアのみで、エビデンスレベルは L5 です。さらに、日本での販売承認は取消済みです。

**進める場合に必要なもの：**
- 添付文書の警告・禁忌情報の取得と解析（PMDA）
- 詳細な作用機序データ（MOA）の補完
- 歯肉線維腫症と ALK/IGF-1R/ROS1 シグナルの関連を検討する前臨床・機序研究
- 日本での承認取消の経緯の確認と、投与経路の適合性評価
- 予測候補のうち、ALK 陽性肺癌に近い疾患（肺門部癌、肺溝腫瘍など）を ALK 変異の有無で絞り込む再評価
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

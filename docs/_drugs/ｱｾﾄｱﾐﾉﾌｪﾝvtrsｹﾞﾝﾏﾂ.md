## 一言要約

「アセトアミノフェン VTRS 原末（ｱｾﾄｱﾐﾉﾌｪﾝVTRSｹﾞﾝﾏﾂ）」は解析パイプラインに登録されている薬物ですが、現時点では承認適応症・DrugBank ID・市販情報のいずれも取得できていません。TxGNN モデルによる新規適応症の予測も未実施であるため、再利用評価を進めるための十分なエビデンスが揃っていない状態です。

## 現状評価

薬物名の表記「ｱｾﾄｱﾐﾉﾌｪﾝVTRSｹﾞﾝﾏﾂ」は、アセトアミノフェン（パラセタモール）の原体（原末）と推察されます。VTRS はメーカーコードと考えられますが、DrugBank への照会でヒットが 1 件確認されているにもかかわらず、DrugBank ID の紐付けは完了していません。

アセトアミノフェンは一般的に解熱・鎮痛薬として広く使用される薬物であり、原末（バルク原料）としての登録は製造目的の場合が多く、単独の医薬品承認とは区別が必要です。PMDA の照会では承認情報がヒットしておらず（result_count: 0）、配合剤の成分として存在する可能性が高いと考えられます。

機序的な関連性の分析および TxGNN による再利用候補予測は、DrugBank ID が確定してから実施可能となります。

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID・承認適応症・作用機序（MOA）のいずれも未取得であり、TxGNN 予測が実施できていないため、再利用評価に必要な最低限のエビデンスが揃っていません。

**進める場合に必要なもの：**
- DrugBank ID の確定（薬物名の正規化・INN 照合：おそらく `DB00316` Acetaminophen）
- PMDA 承認情報の再照会（「アセトアミノフェン」単独または配合剤での検索に切り替え）
- 作用機序（MOA）データの補充（DrugBank API または添付文書より取得）
- 警告・禁忌情報の取得（Blocking データギャップの解消）
- TxGNN 予測の再実行（上記データ確定後）

## アナストロゾール：エストロゲン生合成阻害薬 → 神経芽腫 (neuroblastoma)
{: .text-alpha }

## 一言要約

アナストロゾールは、エストロゲン生合成を阻害する抗悪性腫瘍薬で、日本で市販されています。
TxGNN モデルは**神経芽腫 (neuroblastoma)** に有効である可能性を予測しています（スコア 0.9953）。
ただし、この予測を直接裏付ける臨床試験や文献は今回のデータにはなく、エビデンスはモデル予測のみ（L5）です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。日本の承認情報では、アナストロゾールは「エストロゲン生合成阻害薬」に分類されています。

一方で、アロマターゼ阻害と神経芽腫の生物学との間に確立した関連は、今回のデータでは確認できません。神経芽腫は神経堤由来の小児に多い腫瘍で、エストロゲンシグナルへの依存性は示されていません。この予測は、高いモデルスコアのみに基づく仮説の段階です。

既存の剤形は経口錠で、投与経路の適合性はまだ評価されていません。

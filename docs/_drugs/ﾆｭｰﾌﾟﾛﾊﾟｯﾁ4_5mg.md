# ニュープロパッチ4.5MG：評価データ不足により老薬新用評価を保留

## 一言要約

「ﾆｭｰﾌﾟﾛﾊﾟｯﾁ4.5MG」は、入力された識別子が INN（国際一般名）ではなく販売名（品名＋用量）である可能性が高く、DrugBank ID の紐付けに失敗しています。
TxGNN パイプラインから予測適応症が返されておらず、**老薬新用の評価を実施できる状態にありません**。
現時点ではデータ品質の修正と再クエリが必要であり、推奨決定は **Hold** です。

## データ品質の問題

### 問題 1：INN フィールドに品名が入力されている

入力された `inn` 値「`ﾆｭｰﾌﾟﾛﾊﾟｯﾁ4.5MG`」は、以下の特徴から INN ではなく販売名と判断されます：

| 判断根拠 | 詳細 |
|---------|------|
| 表記形式 | 半角カタカナ（PMDA 品名表記の典型形式） |
| 用量情報が混在 | `4.5MG` は用量表記であり INN には含まれない |
| 推定される INN | **ロチゴチン（rotigotine、DB00728）** |

「ニュープロパッチ」は塩野義製薬／UCB が製造するロチゴチン経皮吸収型製剤であり、パーキンソン病およびレストレスレッグス症候群を対象とした製品です。PMDA クエリが 0 件を返した理由は、品名＋用量の文字列で検索されたためと推測されます。

### 問題 2：DrugBank マッピング失敗

`drugbank_id` が null のため、TxGNN モデルへの入力ができず、予測適応症がゼロとなっています。INN「rotigotine」で再クエリすれば DrugBank ID（DB00728）の取得が見込まれます。

---

## 結論と次のステップ

**決定：Hold**

**理由：**
入力識別子が INN ではなく品名形式であるため DrugBank マッピングに失敗しており、TxGNN 予測が実行されていません。基礎データが揃っていない状態では老薬新用の評価を行えません。

**進める場合に必要なもの：**

- [ ] `inn` フィールドを INN 表記「**rotigotine**」に修正して Evidence Pack を再生成
- [ ] DrugBank ID「**DB00728**」を明示的に指定して再クエリ
- [ ] PMDA を「ロチゴチン」または「rotigotine」で再検索し、承認情報（ニュープロパッチ 2.25mg / 4.5mg / 6.75mg / 9mg / 13.5mg / 18mg 各剤形）を取得
- [ ] MOA データを DrugBank API から補完（ドパミン D1/D2/D3 受容体作動薬）
- [ ] 安全性情報（警告・禁忌・DDI）を PMDA 添付文書 PDF から取得

## 照会結果とデータギャップの整理

### PMDA 照会（2026-03-26）

薬物名 `ｱｽﾋﾟﾘﾝｹﾞﾝﾏﾂﾏﾙｲｼ` で照会したところ、PMDA 承認データベースへの一致が **0 件** でした。考えられる原因は以下のとおりです：

- 半角カタカナ → 全角変換後の照合が必要（例：`アスピリン原末「丸石」`）
- 製品名の表記ゆれ（「丸石」と「マルイシ」、括弧の種類など）
- 承認取消・未収載の可能性

### DrugBank 照会（2026-03-26）

同名で照会し **1 件ヒット**しましたが、`drugbank_id` の紐付けは未解決のままです。アスピリン（Aspirin）の DrugBank ID は **DB00945** が候補として有力ですが、確定前に再照会が必要です。

DrugBank ID が未解決の状態では以下が実行できません：
- TxGNN 知識グラフ予測（薬物ノードが特定できないため）
- MOA データの取得
- 薬物相互作用（DDI）の解析

---

## 結論と次のステップ

**決定：Hold**

**理由：**
DrugBank ID が未解決のため TxGNN 予測を実行できず、PMDA での承認記録も確認できていません。安全性・機序・適応症のいずれのデータも欠損しており、老藥新用評価の最低限の条件を満たしていない状態です。

**進める前に必要なもの：**

1. **薬物名の正規化と再照会**
   - 半角カタカナを全角に変換した「アスピリン原末「丸石」」等の表記で PMDA を再検索
   - 承認番号・販売名を特定する

2. **DrugBank ID の確定**
   - Aspirin（アスピリン）の ID `DB00945` と照合し、同一薬物であれば紐付けを更新
   - 確定後に TxGNN 予測を再実行

3. **MOA・安全性情報の取得**
   - DrugBank API または PMDA 添付文書（PDF）から作用機序・警告・禁忌を取得
   - データギャップ DG001（警告/禁忌）および DG002（MOA）を解消

4. **TxGNN 予測の再実行**
   - DrugBank ID 確定後、知識グラフ予測と深層学習予測を実行し Evidence Pack を再生成

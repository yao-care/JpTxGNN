# プラスグレル：狭心症・心筋梗塞から肺高血圧症へ

## 一言要約

プラスグレルは P2Y12 阻害薬（血小板凝集抑制薬）で、元々は狭心症・心筋梗塞の治療に使用されていました。
TxGNN モデルは**肺高血圧症 (Pulmonary Hypertension)** に有効である可能性を予測していますが、検索で見つかった **2 件の臨床試験**と **2 編の文献**はいずれもプラスグレルや肺高血圧症を直接扱っておらず、エビデンスは実質的にモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、プラスグレルは血小板の P2Y12 受容体を不可逆的に阻害するチエノピリジン系の抗血小板薬で、狭心症・心筋梗塞での有効性が確立されています。

肺高血圧症では、血小板活性化が肺血管の血栓形成やリモデリングに関与している可能性が推測されています。このため、P2Y12 阻害によって血小板依存的な病態を抑えられる可能性はあります。ただしこれは仮説段階の推測で、この関連を直接裏付けるエビデンスはありません。

## 安全性に関する考慮事項

安全性情報については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
肺高血圧症に対する根拠は TxGNN のモデル予測のみ（L5）です。検索された試験・文献はいずれも無関係で、日本の添付文書に基づく安全性情報も未確認です。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と安全性スクリーニング
- 詳細な作用機序データ（DrugBank など）の取得
- 肺高血圧症と P2Y12 阻害・血小板活性化の関連を示す前臨床または臨床データの探索
- 参考：同じ予測リストの**片頭痛 (Migraine Disorder)** には、卵円孔開存 (PFO) を伴う患者でのチエノピリジン系薬剤（クロピドグレル、プラスグレル）の後ろ向きレビューや、チカグレロルの小規模パイロット試験があります（エビデンスレベル L3）。優先的に検討する価値があります。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# ヘパリン：汎発性血管内血液凝固症候群・心筋梗塞から常染色体劣性プロテインC欠乏性血栓性素因へ

## 一言要約

ヘパリンは抗凝固薬で、日本では汎発性血管内血液凝固症候群（DIC）や心筋梗塞症などに使われています。
TxGNN モデルは **常染色体劣性プロテインC欠乏性血栓性素因 (Thrombophilia due to protein C deficiency, autosomal recessive)** に有効である可能性を予測しています。ただし、この疾患に直接関連する**臨床試験は 0 件、文献も 0 編**で、現時点ではモデル予測のみです。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ヘパリンはアンチトロンビンの働きを高める抗凝固薬で、第 Xa 因子とトロンビンを阻害します。

プロテインC欠乏症では、体内の抗凝固経路であるプロテインC系が働かず、血栓ができやすくなります。ヘパリンは別の経路（アンチトロンビン経路）で凝固を抑えるため、理論上は失われたプロテインC系の働きを補える可能性があります。DIC など既存適応症も凝固亢進状態であり、病態に共通点があります。

ただし、これは機序からの推測にとどまります。裏付けとなる臨床・文献エビデンスは提供されていません。

予測スコアは高い（99.29%）ものの、臨床試験・文献がともに 0 件で、エビデンスは L5（モデル予測のみ）です。PMDA 添付文書の警告・禁忌も未取得のため、安全性審査（S1）に進めません。

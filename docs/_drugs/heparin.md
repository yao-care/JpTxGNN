# ヘパリン：抗凝固療法（汎発性血管内血液凝固症候群・心筋梗塞症）から椎骨動脈閉塞症へ

## 一言要約

ヘパリンは抗凝固薬で、日本では汎発性血管内血液凝固症候群や心筋梗塞症などに使用されてきました。
TxGNN モデルの最上位予測は**プロテイン C 欠損による血栓性素因（常染色体劣性）**ですが、裏付けるデータはなく、エビデンスレベルは L5 です。
エビデンスが最も多く、現実的な候補は**椎骨動脈閉塞症 (Vertebral artery occlusion)** で、関連する臨床試験 1 件と文献 19 編がありますが、いずれも間接的な根拠にとどまります。

> 注：タイトルの新規適応症は、エビデンスが最も充実している椎骨動脈閉塞症としました。TxGNN の予測順位は 9 位です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ヘパリンはアンチトロンビンを介してトロンビンと活性化第 X 因子を阻害する抗凝固薬です。血栓の伸展や塞栓を抑える作用があり、血栓形成が関わる疾患に適用できる可能性があります。

椎骨動脈の閉塞や解離では、血管内に血栓ができやすく、塞栓症や狭窄・閉塞が起こりえます。ヘパリンの抗血栓作用は、この病態と機序的に整合します。

ただし、支持するエビデンスは間接的です。頸動脈・椎骨動脈解離での抗血小板療法と抗凝固療法を比較した無作為化試験（CADISS）や観察研究があるものの、ヘパリン自体を直接検証したものではありません。

## 安全性に関する考慮事項

- **禁忌となりうる疾患（知識グラフ上の情報）**：添付文書の記載ではなく、知識グラフに基づく情報です。
  - 出血性疾患：血友病、血液凝固障害、血小板減少症、ヘパリン起因性血小板減少症、頭蓋内出血、脳出血、常位胎盤早期剥離、血小板機能異常（Glanzmann 血小板無力症など）
  - 臓器・基礎疾患：肝不全、活動性消化性潰瘍、潰瘍性大腸炎・炎症性腸疾患、感染性心内膜炎、糖尿病性網膜症・高血圧性網膜症などの網膜疾患、アンチトロンビンIII欠乏症
- **薬物相互作用**：100 件が報告されています。
  - 中等度：アセチルサリチル酸、スルホニル尿素系薬（グリメピリド、グリピジド、グリベンクラミドなど）、速効型インスリン分泌促進薬（レパグリニド、ナテグリニド）、フェンフルラミン、シブトラミンなど
  - 重篤度不明：レボカルニチン、マンニトール、カルシトリオール、パントプラゾール、メサラジン、ドキシサイクリンなど

## 結論と次のステップ

**決定：Hold**

**理由：**
- 椎骨動脈閉塞症は、検討した予測の中で最もエビデンスが多い（L3）ものの、ヘパリンを直接検証した試験はなく、根拠は解離に関する間接的な報告と別の抗凝固薬の試験にとどまります。
- 予測スコア最上位のプロテイン C 欠損症を含め、他の予測はデータがほぼなく L5 です。血小板機能異常や網膜疾患では出血リスクのため、むしろ推奨できません。
- 日本ではヘパリン関連の承認 20 件がすべて取消済みで、現在有効な承認がありません。

**進める場合に必要なもの：**
- PMDA の添付文書から警告・禁忌を取得し、安全性スクリーニングを行う（最優先）
- DrugBank から作用機序データを取得する
- 椎骨動脈閉塞症・解離でのヘパリン使用に関する直接的な臨床データ（後ろ向きコホートなど）を調べる
- 現行の有効な販売製品と承認状況を確認する
- 投与経路と剤形の適合性を評価する
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

# メロペネム：細菌感染症・髄膜炎から尿路感染症へ

## 一言要約

メロペネムはカルバペネム系の注射用抗菌薬で、元々は緑膿菌感染症、髄膜炎菌感染症、腹膜炎、細菌性髄膜炎などの治療に使われていました。
TxGNN モデルは複数の新規適応症を予測しており、最上位は**細菌性関節炎 (bacterial arthritis)** ですが、臨床試験を含むエビデンスが最も充実しているのは **尿路感染症 (urinary tract infection)** です。
尿路感染症については **9 件の臨床試験**と **20 編の文献**があり、本レポートではこの適応症を中心に評価します。

> 補足：予測スコア最上位の細菌性関節炎には臨床試験がなく、文献も症例報告・観察研究・総説が中心です。

## クイック概要

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ただし既知の情報によると、メロペネムはカルバペネム系抗菌薬で、ペニシリン結合タンパク質（PBP）に結合して細菌の細胞壁合成を阻害します。多くのβ-ラクタマーゼに安定で、腸内細菌目や緑膿菌に対して信頼できる活性を示します。

既存適応症（緑膿菌感染症、腹膜炎、髄膜炎など）はいずれもグラム陰性菌・陽性菌による重症細菌感染症です。複雑性尿路感染症の主な起因菌は腸内細菌目と緑膿菌であり、既存適応症と病原体のスペクトラムが大きく重なります。このため機序的にも適用可能性が高いと考えられます。

なお、予測上位の他の疾患では妥当性に差があります。細菌性関節炎はメロペネム感受性のメリオイドーシス（類鼻疽）の報告などで間接的に支持されます。一方、**Ureaplasma 尿道炎**は、細胞壁を持たない菌であるため機序的に成り立たず、偽陽性の可能性が高いと判断されます。

## 安全性に関する考慮事項

- **禁忌（ナレッジグラフ上の関連疾患）**：てんかん、腎疾患、尿管膿瘍、血小板減少症、*Clostridium difficile* 大腸炎、周産期壊死性腸炎。添付文書の記載ではなくナレッジグラフ由来のため、確認が必要です。
- **薬物相互作用**：計 14 件が記録されています。
  - **Major（重大）**：ブプロピオン、イオヘキソール、イオパミドール
  - **Moderate（中等度）**：ピコスルファート、ポリエチレングリコール（電解質配合）、ニチシノン、硫酸ナトリウム、リンデン、エチニルエストラジオール、アルペリシブ、エンコラフェニブ、ミコフェノール酸、ペメトレキセド、テリフルノミド

警告・禁忌の添付文書情報は取得できていないため、添付文書を参照してください。

## 結論と次のステップ

**決定：Proceed with Guardrails（尿路感染症）**

**理由：**
- 複雑性尿路感染症では、メロペネムを比較薬または背景治療とした複数の Phase 3 RCT とメタ解析があり、エビデンスレベルは L1 です。ただしメロペネム自体の適応拡大を直接検証した試験ではなく、日本の承認も全て失効しています。
- 他の予測疾患（喉頭炎、ライム病、淋菌性尿道炎、Peptostreptococcus 感染症など）は L5 で **Hold** です。細菌性関節炎と黄色ブドウ球菌感染症は L4 で、さらなる研究課題の段階です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の取得と、安全性スクリーニングの実施（現在の重大なデータ不足）
- 作用機序データの補完（DrugBank）
- 日本での市販状況の確認（現在は失効のみ）と、現行の同系統薬の承認適応症との照合
- カルバペネムの適正使用（抗菌薬スチュワードシップ）に基づく使用制限の整理
- 重大な相互作用（ブプロピオン、ヨード造影剤）や、てんかん・腎機能低下患者でのモニタリング計画
- 細菌性関節炎については、メリオイドーシスなど特定の病原体に絞った追加検証
## 免責事項

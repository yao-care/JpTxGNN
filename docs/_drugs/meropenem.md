# メロペネム：カルバペネム系抗菌薬から細菌性関節炎へ

## 一言要約

メロペネムは広域スペクトラムのカルバペネム系抗菌薬で、日本では点滴用製剤として市販されています。
TxGNN モデルは**細菌性関節炎 (Bacterial Arthritis)** に有効である可能性を予測していますが、支持するのは症例報告、レビュー、薬物動態データが中心です。
関連する臨床試験は **1 件**（関連性が低い）、文献は **20 編**で、メロペネムの有効性を直接検証した試験はありません。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、メロペネムはペニシリン結合タンパク質 (PBP) に結合して細菌の細胞壁合成を阻害するカルバペネム系抗菌薬です。

グラム陰性菌や ESBL 産生菌など、関節感染の原因菌に対する活性が期待できるため、機序的には細菌性関節炎にも適用できる可能性があります。ただし、支持データは症例報告、レビュー、薬物動態データに限られます。たとえば ESBL 産生肺炎桿菌による化膿性関節炎の 2 例では、メロペネムとアミカシンの併用に関節鏡下洗浄を加えて治療に成功しています。

なお、既存の承認適応症のテキストがデータに含まれていないため、既存適応症との関連性は評価できていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
メロペネムを細菌性関節炎に用いる直接的な臨床試験はなく、支持データは症例報告とレビュー中心です。日本の添付文書に基づく安全性確認も未完了のため、現時点では保留とします。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と解析。現在は安全性スクリーニングを進められない状態です
- DrugBank からの作用機序 (MOA) データの補完
- 細菌性関節炎に対するメロペネムの比較データ（既存の標準治療との比較）の探索
- 参考：同じ Evidence Pack の**尿路感染症**（順位 6）は、複雑性尿路感染症を対象とした Phase 3 RCT が複数あり（例：NCT02486627 でメロペネムを対照薬として使用）、エビデンスレベルは L1 です。ただし、これらの試験ではメロペネムは主に対照薬・基盤薬として使われています。優先度の比較検討をお勧めします

本評価は研究参考用であり、医療上の助言ではありません。予測された適応症は臨床的な検証を経て初めて実用に移せます。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

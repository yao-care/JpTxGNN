# Threonine：栄養補給剤から胃不全麻痺への潜在的応用

## 一言まとめ

Threonine（トレオニン） は本来、栄養補給およびアミノ酸補給に用いられています。
TxGNN モデルは、本剤が **Gastroparesis（胃不全麻痺）** に有効である可能性を予測しており、
現時点で **1 件の文献**が間接的な裏付けを示していますが、直接的な臨床試験のエビデンスはありません。

## この予測が妥当な理由

Threonine（スレオニン）は必須アミノ酸の一種で、タンパク質合成や種々の代謝経路に関与します。

**想定される作用機序（推測）：**
1. **PI3K-AKT-mTOR シグナル伝達経路**：関連文献によると、糖尿病性胃不全麻痺は、胃平滑筋細胞のアポトーシスおよび PI3K-AKT-mTOR シグナル伝達経路の異常と関連しています。アミノ酸（Threonine を含む）は、mTOR シグナルの調節を介して胃平滑筋の機能に影響する可能性があります。
2. **タンパク質代謝の支持**：Threonine は必須アミノ酸として、胃平滑筋細胞の維持や修復に役立つ可能性があります。
3. **腸粘膜の完全性**：Threonine は腸管ムチン合成の重要な構成成分であり、消化管機能に対して保護的に働く可能性があります。

ただし、現時点では、Threonine の胃不全麻痺に対する有効性を直接裏付けるエビデンスはありません。

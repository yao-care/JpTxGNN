## アテゾリズマブ：移行上皮癌から子宮靭帯腺癌へ
{: .text-alpha }

## 一言要約

アテゾリズマブは抗 PD-L1 抗体で、ナレッジグラフ上では移行上皮癌（尿路上皮癌）との関係が記録されています。
TxGNN モデルは**子宮靭帯腺癌 (uterine ligament adenocarcinoma)** に有効である可能性を予測しています。
ただし、この疾患を直接検討した臨床試験や文献は **0 件**で、根拠はモデル予測のみです。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | ナレッジグラフ上で記録されている関係：移行上皮癌（承認適応症としては、ライセンス情報から確認できませんでした） |
| 予測新規適応症 | 子宮靭帯腺癌 |
| TxGNN 予測スコア | 0.9993 |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。アテゾリズマブは PD-L1 を阻害する抗体医薬であり、PD-L1 を発現する腫瘍で T 細胞の抗腫瘍活性を回復させる可能性があります。

移行上皮癌は、ナレッジグラフに記録された関係にすぎません。子宮靭帯腺癌は、PD-L1 を発現する腺癌という点で機序的な接点が想定できます。ただし、この疾患に対する臨床的・文献的な裏づけはなく、現時点の妥当性はモデル予測に依存しています。

## 臨床試験エビデンス

現在、関連する臨床試験の登録はありません。

参考：同じ薬物の別の予測候補である**子宮頸部腺癌（endocervical carcinoma）**には、完了した試験が 2 件あります。
- Phase 2：アテゾリズマブとベバシズマブの併用、11 例（NCT02921269）
- Phase 1：化学放射線療法との併用、40 例（NCT03738228）

これらは本候補（子宮靭帯腺癌）を直接検討したものではないため、本候補のエビデンスには含めていません。

## 安全性に関する考慮事項

- **薬物相互作用**：75 件の相互作用が登録されています。
  - **Major**：アダリムマブ、バリシチニブ、BCG 生菌ワクチン（Bacillus Calmette-Guérin）
  - **Moderate（主なもの）**：副腎皮質ステロイド（ヒドロコルチゾン、プレドニゾロン、デキサメタゾンなど）、アザチオプリン、アレムツズマブ、アナキンラ、炭疽ワクチン、破傷風トキソイド

警告・禁忌については、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
子宮靭帯腺癌を直接検討した臨床試験・文献が一件もなく、エビデンスはモデル予測のみ（L5）です。現時点では開発や適応拡大の判断材料が不足しています。

**進める場合に必要なもの：**
- 子宮靭帯腺癌での PD-L1 発現状況を示す前臨床・病理学的データ
- 類縁疾患（子宮頸部腺癌など）の試験結果に基づく、本疾患への外挿可能性の評価
- 添付文書（PMDA）にもとづく警告・禁忌の整理と安全性評価
- 詳細な作用機序データの補完
- 投与経路や剤形の適合性の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

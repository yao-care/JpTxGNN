# アテゾリズマブ：既存適応症の記載なしから前立腺部尿道尿路上皮癌へ

## 一言要約

アテゾリズマブは PD-L1 を標的とする抗体医薬品で、日本では「テセントリク点滴静注」として市販されています。今回のデータには既存適応症の記載がありません。
TxGNN モデルは**前立腺部尿道尿路上皮癌 (Prostatic Urethra Urothelial Carcinoma)** に有効な可能性を予測しており、関連する臨床試験は **2 件**（いずれも隣接疾患を対象）、この疾患を直接扱う文献は **0 編**です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、アテゾリズマブは PD-L1 阻害抗体で、腫瘍による免疫回避を解除し、T 細胞の抗腫瘍活性を回復させると考えられます。

尿路上皮癌は膀胱、腎盂、尿管、尿道に共通する組織型です。前立腺部尿道の尿路上皮癌も同じ組織学的背景を持つため、PD-L1 阻害が機序的に適用できる可能性があります。ただし、この部位だけを対象とした試験はありません。

## 結論と次のステップ

**決定：Hold**

**理由：**
支持する試験は、隣接疾患（BCG 不応の非筋層浸潤性膀胱癌）の単群 Phase 2 と、混合固形がん対象の Phase 1b 併用試験のみです。前立腺部尿道尿路上皮癌を直接検証した試験も文献もありません。また、添付文書の警告・禁忌が未確認で（Blocking の欠落データ）、安全性スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と確認（DG001、Blocking）
- 作用機序データの補完（DG002、DrugBank API で取得可能）
- 前立腺部尿道または尿路上皮癌のサブ集団解析データ、および関連する文献の調査
- 既存の承認適応症の情報整備

なお、同一 Evidence Pack 内では、子宮頸部の子宮内膜腺癌（endocervical carcinoma、rank 6）に対して、完了済みの子宮頸癌 Phase 1 と Phase 2 の 2 試験があります。ただし、Phase 2 の被験者数は 11 名と少ないです。この候補の優先度も併せて検討する価値があります。

本レポートは研究参考用であり、医療上の助言ではありません。予測結果は臨床的な検証を経て初めて適用できます。

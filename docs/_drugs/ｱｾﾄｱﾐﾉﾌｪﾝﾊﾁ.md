# アセトアミノフェンハチ：データ不足により再利用評価不可

## 一言要約

アセトアミノフェンハチ（`ｱｾﾄｱﾐﾉﾌｪﾝﾊﾁ`）は日本の PMDA データベースに承認情報が存在せず、既存適応症を確認できませんでした。TxGNN モデルによる新規適応症予測も実施されていないため、現時点では再利用評価に必要なデータが揃っておらず、評価続行は困難な状況です。DrugBank 情報の完全取得と PMDA 仿単の精査が先決です。

## この予測が妥当である理由

作用機序（MOA）データおよび既存適応症情報がいずれも取得できていません。PMDA への照会（2026-03-26）では該当薬物が 0 件、DrugBank 照会では 1 件のヒットが返されたものの、DrugBank ID の紐付けには至っておらず、再利用可能性の機序的根拠を示せる状態ではありません。

また、薬物名 `ｱｾﾄｱﾐﾉﾌｪﾝﾊﾁ`（アセトアミノフェンハチ）は標準的な INN 表記と一致しない可能性があります。PMDA でヒットしなかった主因が名称の不一致にある可能性も排除できないため、正式な INN または PMDA 収載名の確認を最優先すべきです。

## 結論と次のステップ

**決定：Hold**

**理由：**
PMDA データベースで承認情報が確認できず、TxGNN による新規適応症予測も完了していないため、現時点での再利用評価は実施不可能です。

**進める場合に必要なもの：**

- **薬物名の確認**：`ｱｾﾄｱﾐﾉﾌｪﾝﾊﾁ` が正式な INN・PMDA 収載名と一致するか確認し、必要であれば正規化された薬物名で再検索する
- **DG001 解消**：PMDA 仿単 PDF をダウンロードし、警語・禁忌情報を解析する
- **DG002 解消**：DrugBank API で MOA・安全性情報を完全取得し、DrugBank ID を確定する
- **TxGNN 再実行**：上記データ補完後、新規適応症予測を実施して Evidence Pack を更新する

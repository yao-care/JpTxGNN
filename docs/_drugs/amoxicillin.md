# アモキシシリン：細菌感染症から高アミラーゼ血症へ

## 一言要約

アモキシシリンはペニシリン系の抗生物質で、元々は淋菌感染症、梅毒、歯周組織炎、猩紅熱、ヘリコバクター・ピロリ感染症などの治療に使われていました。
TxGNN モデルは**高アミラーゼ血症 (Hyperamylasemia)** に有効である可能性を予測していますが、関連する**臨床試験は 0 件、文献も 0 編**で、裏付けはモデル予測のみです。

## この予測が妥当かどうか

現在、詳細な作用機序データはありません。既知の情報によると、アモキシシリンは細菌の細胞壁合成を阻害するβ-ラクタム系抗生物質で、上記の細菌感染症での有効性が確立されています。

一方、高アミラーゼ血症は血清アミラーゼ値が高い状態で、細菌のペニシリン結合タンパク質を標的とする本薬との間に、既知の薬理学的なつながりはありません。予測スコアは非常に高いものの、機序面の裏付けも臨床・文献の裏付けもなく、現時点ではモデル出力のみのシグナルです。したがって、機序的に適用可能とは言えません。

## 結論と次のステップ

**理由：**
高アミラーゼ血症については、臨床試験も文献もなく、機序的なつながりも確認できません。エビデンスはモデル予測のみ (L5) のため、開発を進める根拠が不足しています。

なお、同じ予測リスト内には、エピグロッティス（喉頭蓋炎）や単クローン性ガンマグロブリン血症のように、文献や試験が見つかっている候補もあります。ただし、いずれも症例報告や間接的な知見が中心で、追加の精査が必要です。

**進める場合に必要なもの：**

## 結論と次のステップ

**決定：Hold**

**理由：**
クエリ名称「ケトプロフェンテープ２０ＭＧ」は剤形・規格を含む商品名形式であり、PMDA の INN 検索では承認記録が一致しませんでした。作用機序・安全性・適応症のすべてが未取得のため、TxGNN 予測を実行できる状態にありません。

**進める場合に必要なもの：**

- **INN の確認**：ケトプロフェン（Ketoprofen）として再クエリ、DrugBank ID `DB01009` で照合
- **PMDA 仿單 PDF の取得**（DG001 解消）：[PMDA 医薬品情報ページ](https://www.pmda.go.jp/PmdaSearch/iyakuSearch/) で「ケトプロフェンテープ」を検索し、警語・禁忌を抽出
- **DrugBank API による MOA データ取得**（DG002 解消）：Ketoprofen の作用機序（COX-1/COX-2 阻害）を取得
- **Evidence Pack の再生成**：INN ベースで再実行し、TxGNN 予測を起動
- **外用剤としての注意**：テープ剤は全身曝露が経口剤より低いため、再利用対象として適切か事前に検討が必要

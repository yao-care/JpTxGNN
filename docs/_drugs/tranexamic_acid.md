# Tranexamic Acid：止血剤から無月経治療へ

## 一言まとめ

トラネキサム酸 (Tranexamic acid（トラネキサム酸）、断血炎) は、もともと全身及び局所の出血または出血性疾患に用いられる薬剤です。
TxGNN モデルは、本剤が**無月経 (amenorrhea)** に有効である可能性を予測しており、
現時点でこの方向性を支持する**文献が 2 件**あります。

## 概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 全身及び局所の出血または出血性疾患 |
| 予測新適応症 | 無月経 (amenorrhea) |
| TxGNN 予測スコア | 99.19% |
| エビデンスレベル | 評価待ち |
| 日本市販状況 | 本サイトのデータに未収載 |

## この予測が妥当な理由

トラネキサム酸は抗線溶薬であり、線維素溶解(線溶)を抑制することで止血効果を発揮します。婦人科領域での用途には以下があります。

1. **過多月経の治療**：月経出血量を 40-60% 減少させることが確認されています
2. **血液悪性腫瘍患者の月経管理**：化学療法中の月経出血の予防・抑制に用いられます
3. **ホルモン療法との併用**：月経抑制戦略の一部として用いられます

ただし、無月経とは通常、月経がないことを指し、止血治療を必要とする状態ではない点に注意が必要です。今回の予測は、月経調節が必要な状況における間接的な関連を反映している可能性があります。

## 臨床試験エビデンス

## 安全性に関する考慮事項

- **血栓リスク**：エストロゲン製剤との併用時は特に注意が必要です
- **主な相互作用 (Major)**：
  - エチニルエストラジオール、エストラジオール、結合型エストロゲン(血栓リスクの増加)
  - ドロスピレノン、レボノルゲストレル、ノルエチステロン(経口避妊薬の成分)
  - 抗インヒビター凝固複合体、第IX因子複合体
  - タモキシフェン、ラロキシフェン、トレミフェン(選択的エストロゲン受容体モジュレーター)
- **中等度の相互作用 (Moderate)**：アルテプラーゼ、ストレプトキナーゼ、ウロキナーゼ(プラスミノーゲン活性化薬)
- **禁忌**：活動性の血栓塞栓性疾患

## 結論と次のステップ

**判断：Needs Further Investigation**

**理由：**
トラネキサム酸は過多月経の治療では明確な効果が認められていますが、無月経との関連性についてはさらなる検討が必要です。現時点の文献エビデンスは、無月経の治療ではなく月経抑制に主に集中しています。

**推進に必要な事項：**
- 無月経適応症の臨床的定義と治療目標を明確にする
- 特定の臨床状況(化学療法関連の月経管理など)での応用を評価する
- 血栓リスクとホルモン療法併用時の安全性を考慮する

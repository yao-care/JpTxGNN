# ファンギゾンシロップ 100MG/ML：評価データ不足のため再処理が必要

---

## 一言要約

本薬物はクエリ名「ﾌｧﾝｷﾞｿﾞﾝｼﾛｯﾌﾟ100MG/M」として処理されており、商品名・剤形・用量が混在した入力形式のためシステムが正規化に失敗した可能性があります。
TxGNN モデルによる予測適応症は**0 件**であり、DrugBank マッピングも未完了のため、現時点では老薬新用評価を実施できません。
**推奨決定は Hold** とし、INN（一般名）の特定とデータ再収集を優先することを提言します。

## この評価が進められない理由

入力された薬物識別子「ﾌｧﾝｷﾞｿﾞﾝｼﾛｯﾌﾟ100MG/M」には、**商品名（Fungizone）・剤形（シロップ）・濃度（100MG/ML）** が一つの文字列に混在しており、さらに半角カタカナ形式であるため、以下の処理が失敗しています：

1. **PMDA 照会**：0 件ヒット。正規の承認番号検索に必要な INN または承認販売名との一致なし
2. **DrugBank マッピング**：DrugBank クエリでは 1 件がヒットしているものの、`drugbank_id` が null のままであり正式にリンクされていない
3. **TxGNN 予測**：DrugBank ID が取得できなかったため、知識グラフへの入力ができず予測結果が 0 件

ファンギゾン（Fungizone）は**アムホテリシン B（Amphotericin B）**の商品名であることが知られており、抗真菌薬として広く使用されています。ただし、本レポートは入力データのみに基づいており、この推定は確認が必要です。

---

## 結論と次のステップ

**決定：Hold**

**理由：**
薬物識別子の正規化に失敗しており、TxGNN 予測が 0 件のため老薬新用の候補適応症が存在しません。評価を進めるためにはまず入力データの品質を修正する必要があります。

**進める前に必要なもの：**

- **[最優先]** INN の確定：入力名を「アムホテリシン B」または「Amphotericin B」に修正し、DrugBank ID（DB00681）を明示的に設定する
- **[必須]** 薬物識別子の再正規化：商品名・剤形・濃度を分離し、INN のみをクエリキーとして再投入する
- **[必須]** PMDA 再照会：正規 INN で再検索し、日本国内の承認状況を確認する
- **[必須]** TxGNN 再予測：正しい DrugBank ID を使用して KG 予測および DL 予測を実行する
- **[推奨]** MOA データ取得：DrugBank API 経由でアムホテリシン B の作用機序（エルゴステロール結合、細胞膜破壊）を取得しエビデンスパックに補充する
- **[推奨]** 安全性情報の取得：PMDA 仿単 PDF より警語・禁忌・薬物相互作用を抽出する

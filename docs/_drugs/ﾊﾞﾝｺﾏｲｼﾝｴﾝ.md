# バンコマイシン塩酸塩：データ不足により評価保留

## 一言要約

バンコマイシン塩酸塩（INN クエリ：ﾊﾞﾝｺﾏｲｼﾝｴﾝ）は、PMDA データベースへの検索で承認記録が取得できず、DrugBank ID も未紐付けの状態です。TxGNN による新規適応症予測が実行されていないため、老薬新用候補を提示することができません。薬物名の正規化とデータギャップの解消を優先してから再評価が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
PMDA 検索で 0 件となった原因は薬物名の正規化失敗（半角カタカナ）の可能性が高く、実際には日本市場に承認が存在する可能性があります。TxGNN 予測が実行されておらず、安全性・MOA データもいずれも未取得のため、現時点では老薬新用評価を進める基盤がありません。

**進める場合に必要なもの：**
- PMDA 再検索：半角カタカナを全角に変換（`ﾊﾞﾝｺﾏｲｼﾝｴﾝ` → `バンコマイシン塩酸塩`）して再実行
- DrugBank マッピング修正：1 件ヒットしているにもかかわらず `drugbank_id` が `null` となっている原因を調査し、ID を正しく取得
- DrugBank ID 取得後に MOA・安全性情報・DDI を収集
- PMDA 添付文書 PDF のダウンロードと警語・禁忌の解析
- 上記完了後に TxGNN 予測パイプラインを再実行

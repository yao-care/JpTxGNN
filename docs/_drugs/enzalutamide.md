# エンザルタミド：前立腺癌から前立腺癌/脳腫瘍感受性へ

## 一言要約

エンザルタミドは元々、前立腺癌の治療に使われてきたアンドロゲン受容体 (AR) 阻害薬です。
TxGNN モデルは **前立腺癌/脳腫瘍感受性 (prostate cancer/brain cancer susceptibility)** への有効性を高スコアで予測しています。ただし、この予測を直接支持する臨床試験や文献は **0 件** で、モデル予測のみの段階です。

## この予測が妥当である理由

エンザルタミドは第二世代の AR 阻害薬です。AR へのリガンド結合、核内移行、DNA 結合を阻害します。現在、詳細な作用機序データは手元にありません。上記は薬物の一般的な薬理に基づく整理です。

予測された「前立腺癌/脳腫瘍感受性」は、前立腺癌を含む遺伝的な感受性症候群のラベルです。前立腺癌の部分は AR 阻害の機序と整合します。一方、脳腫瘍の部分については、AR 阻害と直接結びつく機序は確認できません。

高いスコアは、知識グラフ上で既存適応症の前立腺癌と近い位置にあることを反映している可能性があります。機序面から新たな効果が裏付けられたとは言えません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測適応症を直接支持する臨床試験も文献もなく、エビデンスはモデル予測のみ (L5) です。脳腫瘍の要素には機序的な裏付けもありません。

**進める場合に必要なもの：**
- 添付文書（警告・禁忌）の取得と確認。これが未完了のため、安全性スクリーニングに進めません。
- 詳細な作用機序データ (MOA) の補充。
- 「前立腺癌/脳腫瘍感受性」という疾患定義の整理。既存適応症の前立腺癌との差分を明確にし、新規性のある評価対象かどうかを判断する必要があります。
- 日本では有効な承認がないため、販売・承認状況の再確認。

**参考：** 同じ予測リストの「男性生殖器癌 (male reproductive organ cancer)」には多数の臨床試験と文献があります（Phase 3 の ENZAMET 試験など）。ただし中身は既存適応症である前立腺癌のエビデンスであり、新規再利用の根拠とは言えません。

# ダナゾール：子宮内膜症・乳腺線維嚢胞症から無月経へ

## 一言要約

ダナゾールは合成ステロイドで、元々子宮内膜症や乳腺線維嚢胞症の治療に使用されていました。
TxGNN モデルは**無月経 (Amenorrhea)** に対する有効性を最上位の予測として示しています。ただし、これは疾患の治療というより、抗ゴナドトロピン作用による月経抑制という薬理作用に近いものです。
現在、臨床試験の登録はなく、**20 編の文献**（レビュー、コホート研究、RCT など）が関連しています。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 子宮内膜症、子宮の子宮内膜症、乳腺線維嚢胞症（知識グラフ上の情報。日本の承認適応症の記載はありません） |
| 予測新規適応症 | 無月経 (Amenorrhea) |
| TxGNN 予測スコア | 99.9995% |
| エビデンスレベル | L3 |
| 日本市販状況 | 販売終了（承認は取消のみ） |
| 承認番号数 | 2 件（いずれも取消） |
| 推奨決定 | Hold |

> 補足：予測順位 1 位の無月経は薬理作用の延長にすぎません。実質的な再利用候補としては、**良性乳腺異形成**と**乳腺症 (Breast adenosis)** が、いずれも L3・Proceed with Guardrails と評価されています。ただしこれらは、既存適応症の乳腺線維嚢胞症と近い領域です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。文献によると、ダナゾールは 17α-エチニルテストステロン由来の合成ステロイドです。下垂体のゴナドトロピン（FSH/LH）を抑制し、卵巣のステロイド合成も抑えます。さらに、アンドロゲン受容体やプロゲステロン受容体に結合するほか、免疫調節作用も示します。

無月経は、この卵巣機能抑制による予想された薬理効果です。子宮内膜症の治療では、無月経の状態で病変が退縮することが知られています。トランスジェンダーの方の月経抑制にダナゾールが使われた後ろ向きコホート研究（2024 年）もあります。

ただし、無月経は治療対象の疾患というより治療の副次的な効果です。新たな適応症として評価するには、目的（月経抑制）と患者集団を明確にする必要があります。

## 安全性に関する考慮事項

- **禁忌（知識グラフ上の関連疾患、添付文書の記載ではありません）**：てんかん、ポルフィリン症（遺伝性を含む）、腎疾患、肝疾患、胆嚢疾患、乳癌（女性）、片頭痛、家族性複合型高脂血症、膿尿管症
- **薬物相互作用**：100 件が検出されました（DDInter）。主なものは次のとおりです。
  - **Major**：シサプリド
  - **Moderate**：糖尿病治療薬（アカルボース、SGLT2 阻害薬、スルホニル尿素薬、GLP-1 作動薬、インスリン製剤など）、ブデソニド、エリグルスタット
- 文献上の報告として、カルバマゼピンの血中濃度上昇（約 2 倍）や、ロバスタチンとの併用による横紋筋融解症・膵炎があります。
- ダナゾールは妊娠・授乳中は一般に避けられます（アンドロゲン作用のため）。

添付文書の警告・禁忌は今回取得できていないため、正式な安全性評価には添付文書の確認が必要です。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 無月経は卵巣機能抑制による薬理効果であり、独立した疾患への新規適応とは言いにくい状況です。臨床試験の登録もなく、日本では承認がすべて取消されています。
- より有望な候補は、既存適応症に近い**良性乳腺異形成**と**乳腺症**です（L3、Proceed with Guardrails）。これらを優先して評価する価値があります。

**進める場合に必要なもの：**
- PMDA の添付文書（警告・禁忌）の取得と、安全性スクリーニング
- 作用機序（MOA）データの補完（DrugBank）
- 販売終了の経緯の確認と、供給体制・剤形の再評価
- 無月経を目的とする場合は、対象集団（子宮内膜症、月経抑制など）と目的の定義
- 乳腺関連の候補については、無作為化比較試験の有無と最新のガイドラインの確認
- 男性化作用、肝機能障害、血栓リスクなど、ダナゾール特有の有害事象を監視する計画

# ウステキヌマブ：乾癬性関節炎・乾癬から皮膚炎へ

## 一言要約

ウステキヌマブは IL-12/IL-23 の共通 p40 サブユニットを標的とする抗体医薬で、元々は乾癬性関節炎や乾癬の治療に使用されていました。
TxGNN モデルは**皮膚炎 (Dermatitis)** に有効である可能性を予測しており、現在 **6 件の臨床試験**と **20 編の文献**がこの方向性に関連しています。ただし、直接的な有効性を示す中心的な知見は、アトピー性皮膚炎を対象とした Phase 2 試験（効果は限定的）に限られます。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 乾癬性関節炎、乾癬、類乾癬（知識グラフ上の情報。日本の承認適応症の記載はありません） |
| 予測新規適応症 | 皮膚炎 (Dermatitis) |

| エビデンスレベル | L2 |

| 承認番号数 | 2 件（いずれも取り消し） |
| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データは本レポート用に集約されたデータにはありません。一般に知られている情報では、ウステキヌマブは IL-12 と IL-23 に共通する p40 サブユニットを阻害し、Th1 および Th17/Th22 経路の活性化を抑える抗体です。

乾癬はこれらの経路が関与する炎症性皮膚疾患であり、一部の皮膚炎のサブタイプにも同じ経路が関わっています。そのため、皮膚炎への適用には機序的な根拠があります。

一方、アトピー性皮膚炎は主に Th2 優位の疾患です。Phase 2 試験で効果が限定的だったことは、この点で説明できる可能性があります。皮膚炎全般への有効性は、サブタイプごとに慎重に見る必要があります。

## 安全性に関する考慮事項

- **薬物相互作用**（DDInter による。100 件が登録されており、主なものを示します）：
  - 中等度：副腎皮質ステロイド（ヒドロコルチゾン、トリアムシノロン、デキサメタゾン、ベタメタゾン、ブデソニド、プレドニゾン、プレドニゾロン）
  - 中等度：シンバスタチン
  - 中等度：抗凝固薬（アピキサバン、ワルファリン、リバーロキサバン、ジクマロール）
  - 中等度：放射性医薬品・抗体薬（イオベングアン I-131、イブリツモマブ チウキセタン、トシツモマブ）
  - 軽度：亜鉛製剤（硫酸亜鉛、酢酸亜鉛、グルコン酸亜鉛、塩化亜鉛）
- 予測された他の適応症のうち、新生児皮膚筋炎は新生児での安全性と予防接種への懸念があります。ライム病関連の慢性萎縮性肢端皮膚炎や EBV 関連の種痘様水疱症では、免疫抑制が感染制御を悪化させる可能性があります。

警告および禁忌については添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- アトピー性皮膚炎を対象とした Phase 2 試験が 2 件あるものの、効果は限定的です。皮膚炎は主に Th2 優位であり、IL-12/23 阻害との機序的整合性にも限界があります。
- 日本での承認は 2 件とも取り消し済みで、警告・禁忌情報も不足しているため、安全性評価に進める状態ではありません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得と解析（安全性スクリーニングの前提）
- 詳細な作用機序データ（DrugBank など）の補充
- Th1/Th17 優位の皮膚炎サブタイプ（接触皮膚炎など）に絞った有効性の検討
- Phase 2 の結果を再検証する追加試験と、他の予測疾患での機序検証
- 日本での現在の販売状況（承認の取り消し理由と、代替販売名の有無）の確認
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

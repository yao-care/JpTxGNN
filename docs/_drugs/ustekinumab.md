# ウステキヌマブ：乾癬・クローン病などから皮膚炎（アトピー性皮膚炎）へ

## 一言要約

ウステキヌマブは IL-12/23 の共通 p40 サブユニットを標的とする抗体医薬です。文献上は、中等症〜重症の尋常性乾癬、乾癬性関節炎、クローン病、潰瘍性大腸炎に使われています。
TxGNN モデルは**皮膚炎 (Dermatitis)** に有効な可能性を予測しています。関連する臨床試験は **7 件**、文献は **21 編**ありますが、アトピー性皮膚炎での効果を示す結果は一貫していません。

## この予測が妥当である理由

詳細な作用機序データは Evidence Pack にありません。ただし文献では、ウステキヌマブは IL-12 と IL-23 に共通する p40 サブユニットを阻害するヒトモノクローナル抗体とされています。この阻害で Th1、Th17、Th22 の活性化が抑えられます。乾癬ではこの経路が病態の中心です。

アトピー性皮膚炎は主に Th2 型の炎症で、Th1/Th17 経路の関与は部分的です。そのため機序的な関連は「あり得る」程度で、効果の根拠は強くありません。乾癬とアトピー性皮膚炎はどちらも慢性の炎症性皮膚疾患で、免疫経路の一部が重なります。この重なりが予測の背景と考えられます。

## 結論と次のステップ

**決定：Hold**

**理由：**
アトピー性皮膚炎については、完了した Phase 2 の RCT が 2 件あり、エビデンスレベルは L2 です。しかし文献では結果が一貫しておらず、Th2 主体の疾患に対する機序的な裏付けも弱いです。また、PMDA の添付文書に基づく安全性の確認ができておらず、ここが進行を止める要因です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と整理（必須）
- 詳細な作用機序データ（DrugBank から取得）
- 日本人重症アトピー性皮膚炎 Phase 2 試験（NCT01945086、PMID 28338223）の有効性結果の精査
- 相互作用（DDI）のスクリーニング
- TxGNN の他の予測（新生児皮膚筋炎、ケロイド性ざ瘡など、順位 2〜10）は、臨床・文献エビデンスがなくモデル予測のみ（L5）のため、現時点では保留

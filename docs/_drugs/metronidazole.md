# メトロニダゾール：嫌気性菌・原虫感染症からニューモシスチス症へ

## 一言要約

メトロニダゾールは嫌気性菌感染症および原虫感染症（アメーバ症、トリコモナス症、ジアルジア症など）の治療に国際的に広く使用されているニトロイミダゾール系抗微生物薬です。TxGNN モデルは**ニューモシスチス症 (Pneumocystosis)** に有効である可能性を 99.99% の高スコアで予測していますが、収集された臨床試験はすべて無関連と判定されており、文献も間接的な背景情報に留まります。*Pneumocystis jirovecii* は真菌であるため、メトロニダゾールの抗菌スペクトル外であり、現時点では機序的妥当性は認められません。

## この予測が妥当である理由

現在、詳細な作用機序データ（MOA）はありません。既知の情報によると、メトロニダゾールはニトロイミダゾール系抗微生物薬であり、嫌気的環境下で細胞内に取り込まれて活性化し、微生物の DNA 鎖を切断することで殺菌・殺原虫作用を発揮します。主なターゲットは *Entamoeba histolytica*（アメーバ）、*Trichomonas vaginalis*（膣トリコモナス）、*Giardia lamblia*（ジアルジア）などの原虫、および *Bacteroides*、*Clostridium* などの嫌気性菌です。

しかし、ニューモシスチス症の原因菌である *Pneumocystis jirovecii* は**真菌（子嚢菌類）**であり、原虫ではありません。好気性代謝を行う真菌に対しては、ニトロイミダゾールの活性化経路（嫌気性ニトロ基還元）が機能せず、メトロニダゾールは抗真菌活性を持ちません。標準治療はトリメトプリム/スルファメトキサゾール（TMP-SMX）であり、代替としてペンタミジンやアトバコンが使用されます。

TxGNN の高スコア（99.99%）は、知識グラフ内における HIV/AIDS コンテキストでの臨床的共起（アメーバ・トリコモナス等の感染症と PCP が同一免疫抑制患者に発生）から生じた**間接的な統計的関連性**に起因すると考えられます。これは機序的関連性を意味するものではなく、予測の妥当性は低いと判断されます。

## 結論と次のステップ

**決定：Hold**

**理由：**
*Pneumocystis jirovecii* は好気性真菌であり、嫌気性菌・原虫を標的とするメトロニダゾールの抗菌スペクトル外であるため機序的妥当性がなく、関連する臨床試験・文献エビデンスも存在しません（エビデンスレベル L5）。TxGNN の高スコアは知識グラフ内の臨床的共起（HIV/AIDS 患者での複数感染）に由来する統計的アーティファクトである可能性が高く、再利用候補としての優先度は低いと判断されます。

**進める場合に必要なもの：**
- TxGNN 知識グラフにおける予測根拠パスの確認（高スコアの出所の解明）
- メトロニダゾールが *Pneumocystis jirovecii* に対して活性を示すという前臨床（in vitro）データの存在確認
- データパイプラインの検索クエリ修正（ClinicalTrials.gov での試験マッチング精度向上）
- 日本での薬事承認申請可否の事前確認（現時点では未上市）

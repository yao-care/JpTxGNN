# メトロニダゾール：抗菌・抗原虫治療からニューモシスチス症へ

## 一言要約

メトロニダゾールはニトロイミダゾール系の薬で、日本では抗菌薬・抗原虫薬として承認されています。
TxGNN モデルは**ニューモシスチス症 (Pneumocystosis)** に有効である可能性を高スコアで予測しています。
ただし、登録されている **20 件の臨床試験**はすべて無関係と判定され、**10 編の文献**にもメトロニダゾールの有効性を示すものはありません。実質的にはモデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) は取得できていません。既知の情報では、メトロニダゾールは嫌気性菌と原虫に活性を持つニトロイミダゾール系薬です。日本ではフラジール内服錠・腟錠、ロゼックスゲルなどとして市販されています。

一方、ニューモシスチスは真菌に分類される病原体で、メトロニダゾールの抗菌・抗原虫スペクトラムの外にあります。文献でも、ニューモシスチス肺炎の標準薬として挙げられているのはトリメトプリム・スルファメトキサゾール (ST 合剤) です（PMID 7355683）。メトロニダゾールは、アメーバ症やトリコモナス症などの別の疾患で言及されているだけです。

このため、既存適応症と予測適応症の間に、機序面で納得できる関連は見つかっていません。TxGNN のスコアは非常に高いものの、それを裏づける機序や臨床データはなく、予測の妥当性は現時点で支持されません。

## 結論と次のステップ

**決定：Hold**

**理由：**
ニューモシスチスはメトロニダゾールの作用スペクトラム外の病原体です。関連する臨床試験と文献にも支持となる知見がなく、高い TxGNN スコアを裏づけるものはありません。エビデンスはモデル予測のみ (L5) のため、現時点では進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得（安全性スクリーニングの前提で、現在は未取得）
- DrugBank からの作用機序データ (MOA) の取得と、ニューモシスチスとの機序的関連の再評価
- 機序的な裏づけまたは in vitro / 動物データの確認

参考として、同じ薬の他の予測候補には、潰瘍性直腸S状結腸炎、キャップポリポーシス、外陰部潰瘍、ハエ幼虫症があります。これらは症例報告やレビューを中心とする L4 (Research Question) で、ニューモシスチス症よりも機序的な説明がつきやすい状況です。

なお、本結果は研究参考用であり、医療上の助言ではありません。臨床応用には臨床的検証が必要です。
## 免責事項

本コンテンツは研究目的のみであり、医療アドバイスを構成するものではありません。
臨床応用の前に臨床的検証が必要です。

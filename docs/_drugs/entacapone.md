# エンタカポン：パーキンソン病から PLA2G6 関連神経変性症へ

## 一言要約

エンタカポンは COMT 阻害薬で、元々パーキンソン病の治療(レボドパの併用薬)に使用されていました。
TxGNN モデルは **PLA2G6 関連神経変性症 (PLA2G6-associated neurodegeneration)** に有効である可能性を予測していますが、現時点では臨床試験も文献も **0 件**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データ (MOA) はありません。既知の情報によると、エンタカポンは末梢性 COMT 阻害薬で、レボドパの作用を延長することでパーキンソン病の治療を補助します。

PLA2G6 関連神経変性症は、ジストニア・パーキンソニズムを伴うことがあります。そのため、ドパミン系を補う考え方は成り立ち得ます。ただしこの関連は間接的な推論にとどまり、直接の根拠は示されていません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、支持するエビデンスはモデル予測のみ(L5)です。臨床試験も文献もなく、機序上の関連も間接的です。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌情報の取得(安全性スクリーニングの前提となる、ブロッキング項目)
- DrugBank からの作用機序データの補完
- PLA2G6 関連神経変性症に対する症例報告・前臨床研究の調査
- 参考：同じ予測リストのうち、パーキンソン病関連の若年発症型(paralysis agitans, juvenile, of Hunt)とレビー小体型認知症は、機序面の間接的な根拠があり (L4)、別途検討する余地があります。

## ビマトプロスト：緑内障から歯・歯周組織の異常を伴う奇形症候群へ
{: .text-alpha }

## 一言要約

ビマトプロストは、プロスタマイド系（FP受容体作動薬）の点眼薬で、元々は**緑内障**の治療と睫毛の発毛に使われていました。
TxGNN モデルは、最上位の予測として**歯・歯周組織の異常を伴う奇形症候群 (malformation syndrome with odontal and/or periodontal component)** への有効性を挙げています。ただし、この予測を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

ビマトプロストはプロスタグランジン F2α 類似のプロスタマイドで、FP 型受容体を介して作用します。緑内障では眼圧を下げ、毛包では成長期を延長して毛包を大きくすることが知られています。ただし、今回のデータには詳細な作用機序の情報が含まれていません。以下は公表されている薬理知識に基づく説明です。

最上位の予測疾患は、歯・歯周組織の形成に関わる先天性の発生異常です。ビマトプロストの薬理作用とは、機序的につながる根拠が見つかっていません。このスコアはTxGNNモデル（ディープラーニング）によるもので、毛髪や低毛症の表現型など関連疾患間でモデルが学習した類似性を反映した可能性があり、生物学的な裏付けではありません。したがって、この予測は妥当とは言えません。

最上位の予測には根拠がありません。一方、予測 8 位の**脱毛症 (alopecia)**（スコア 1.0000）には、実際の研究が存在します。

脱毛症では、完了した Phase 2 試験が複数あり、エビデンスレベルは L2 です。推奨は Proceed with Guardrails に相当します。ただし、円形脱毛症は自己免疫性で、ビマトプロストは免疫学的な毛包攻撃には作用しません。

同様に、予測 3〜7 位（毛幹異常、頭皮の低毛症、先天性低毛症、びまん性円形脱毛症など）は、毛髪関連の予測です。いずれも疾患特異的な臨床エビデンスがなく、L5 です。Ambras 型汎発性先天性多毛症は、発毛を促す作用が逆効果となるため、有害となる可能性があります。

## 安全性に関する考慮事項

- **知識グラフ上の禁忌関連疾患**：肝疾患、胆嚢疾患、ぶどう膜炎、虹彩疾患、毛様体疾患、汎ぶどう膜炎、黄斑浮腫、嚢胞様黄斑浮腫、虹彩炎。添付文書の記載ではなく、関連疾患として整理されたものです。
- **薬物相互作用**：66 件が報告されています（カルシトリオール、オメプラゾール、メトホルミン、プレドニゾンなど）。いずれも相互作用の重要度は不明です。

その他の安全性情報は、添付文書を参照してください。

## 結論と次のステップ

**決定：Hold**

**理由：**
- 最上位の予測（歯・歯周組織の異常を伴う奇形症候群）には、臨床試験も文献もありません。ビマトプロストの作用機序とのつながりも見いだせず、モデル予測のみの L5 です。
- 日本の販売承認は 8 件すべてが有効で、現在市販されています。

**進める場合に必要なもの：**
- 予測の優先順位の見直し：エビデンスのある脱毛症（男性型・女性型脱毛症、円形脱毛症）を、新規適応症の評価対象として検討します。
- 作用機序データ（MOA）の補充。
- 添付文書の警告・禁忌の確認（PMDA の添付文書を取得して解析）。
- 外用（頭皮）剤形での開発可否の検討：日本で現在有効な承認がなく、剤形・投与経路の適合性も未評価です。

# ゲフィチニブ：非小細胞肺癌から歯肉線維腫症へ

## 一言要約

ゲフィチニブは EGFR チロシンキナーゼ阻害薬で、元々 EGFR 遺伝子変異陽性の非小細胞肺癌の治療に使用されていました。
TxGNN モデルは**歯肉線維腫症 (fibromatosis, gingival)** に有効である可能性を予測していますが、この疾患に対する臨床試験・文献は**ありません**（モデル予測のみ）。
なお、予測上位 10 件のうち、ある程度の文献が得られたのは肺癌関連の疾患に限られ、いずれも間接的な根拠にとどまります。

## クイック概要

| 項目 | 内容 |
|------|------|
| 既存適応症 | 非小細胞肺癌（EGFR 遺伝子変異陽性） |
| 予測新規適応症 | 歯肉線維腫症 (fibromatosis, gingival) |
| TxGNN 予測スコア | 99.89% |
| エビデンスレベル | L5 |

| 推奨決定 | Hold |

## この予測が妥当である理由

現在、詳細な作用機序データはありません。既知の情報によると、ゲフィチニブは受容体型チロシンキナーゼ阻害薬に分類される抗悪性腫瘍薬で、EGFR 遺伝子変異陽性の非小細胞肺癌での有効性が確立されています。EGFR のチロシンキナーゼ経路を阻害することで、細胞増殖シグナルを抑えると考えられます。

歯肉線維腫症は線維芽細胞の過剰な増殖を特徴とする疾患です。EGFR シグナルの阻害が線維芽細胞の増殖を理論上抑える可能性はありますが、これは推測の域を出ません。臨床試験も文献もなく、根拠は TxGNN の予測のみです。既存適応症（肺癌）との類似性についても、現時点では評価できていません。

## 臨床試験エビデンス

## 結論と次のステップ

**決定：Hold**

**理由：**
- 予測 1 位の歯肉線維腫症は、臨床試験・文献がなくモデル予測のみ（L5）で、機序的な裏付けも推測にとどまります。
- 日本の承認は全て取り消し済みで、添付文書の警告・禁忌情報も未取得です。

**進める場合に必要なもの：**
- 添付文書（PMDA）の警告・禁忌の取得と、安全性スクリーニングの実施
- 詳細な作用機序データ（DrugBank など）の補充
- 歯肉線維腫症における EGFR シグナルの関与を示す前臨床データ（線維芽細胞モデルなど）
- 肝疾患・間質性肺疾患など、知識グラフ上の禁忌関連疾患に対するリスク評価
- 現在の国内供給状況の確認（承認が全て取り消し済みのため）

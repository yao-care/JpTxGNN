# ゲフィチニブ：非小細胞肺癌から歯肉線維腫症へ

## 一言要約

ゲフィチニブは EGFR チロシンキナーゼ阻害薬で、元々 EGFR 遺伝子変異陽性の非小細胞肺癌の治療に使用されています。
TxGNN モデルは**歯肉線維腫症 (Fibromatosis, Gingival)** に有効である可能性を予測していますが、現在この方向性を支持する**臨床試験は 0 件、文献も 0 編**で、モデル予測のみの段階です。

## この予測が妥当である理由

現在、詳細な作用機序データはありません。ゲフィチニブは EGFR チロシンキナーゼのシグナルを阻害する抗悪性腫瘍薬（受容体型チロシンキナーゼ阻害薬）で、EGFR 遺伝子変異陽性の非小細胞肺癌での有効性が確立しています。

歯肉線維腫症は線維芽細胞の増殖を特徴とする疾患です。EGFR 阻害が線維芽細胞の増殖を抑える可能性は理論上考えられます。ただし、この疾患とゲフィチニブを結びつける臨床データや文献は見つかっていません。機序的な妥当性は推測の域を出ません。

なお、上位 10 件の予測スコアはすべて 99.8% 台で、スコアの差から候補の優劣は判断できません。

## 結論と次のステップ

**決定：Hold**

**理由：**
予測スコアは高いものの、臨床試験・文献ともに裏付けがなく、機序面の根拠も推測にとどまります（L5）。また、PMDA 添付文書の警告・禁忌が未取得のため、安全性スクリーニングに進めません。

**進める場合に必要なもの：**
- PMDA 添付文書の警告・禁忌の取得と解析（進行を妨げている項目）
- 作用機序（MOA）データの補完（DrugBank）
- 歯肉線維腫症と EGFR シグナルの関連を示す前臨床・機序研究の探索

**参考：** 同じ予測リストの「肺門部癌」と「肺胚細胞腫瘍」は L4（Research Question）です。ただし肺門部癌は既存適応症（肺癌）の延長にあたります。

※本結果は研究参考用であり、医療上の助言ではありません。老藥新用の候補は臨床での検証を経て初めて応用できます。
